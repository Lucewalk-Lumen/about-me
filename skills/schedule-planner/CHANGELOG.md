## 4.0.0 版本发布 🚀(2026-10-21)

- 新增 事实管辖权划线：A 类材料事实与 B 类日历事实分界，B 类（节假日 / 调休上班日 / 教学周次 / 考试周）核验权归 fact-verifier 独占，schedule-architect 只消费已放行的台账编号
- 新增 节假日事实治理：holidays-2026（13 条，含 6 个调休上班日，全部带来源 URL 与抓取日期）与 holidays-2027（预测态，默认不参与排程）双档台账
- 新增 桌面日历与五类可视化：桌面日历 / 周视图 / 学期热力图 / 仪表盘 / 学期成就页，纯手写 SVG+CSS，不引第三方图表库、不挂外链
- 新增 功劳档案：完成任务可记录与汇总，档案落用户目录，包内只读，隐私门禁拦截任何写入包目录的行为
- 新增 学期功劳总结：一学期贡献汇总、连续打卡、徽章进度
- 新增 校历导入：JSON / CSV 校历导入，正负例判定，产出 term-space 学期锚点
- 优化 协作拓扑机读化：plugin.json teamInfo 内嵌 phases / workflows / routing / gates / fact_jurisdiction，README 以 Mermaid 与表格双写
- 优化 成员职责边界：7 个成员全部补齐「管什么 / 不管什么」双清单
- 优化 工时口径统一：完成率按计划加权，工时投入率单列为估时偏差信号，零分母显示「—（无计划工时）」而非 0.0%
- 优化 差异化文案：从通用日历能力转向「核真校历与节假日 + 精力匹配 + 冲突诊断 + 功劳档案」
- 修复 校历导入器 --help 崩溃：argparse 帮助串内裸 % 需转义为 %%
- 修复 学期总结脚本格式化串崩溃：100%）。 落在 % 格式化串内导致运行时报错
- 修复 三渲染脚本工时兜底缺陷：rec_min 把显式 0 当 falsy 回落 minutes，导致零计划工时被算成假完成率
