# 幽灵工作空间猎手 · Ghost Workspace Hunter

> **EN** — A WorkBuddy skill that hunts down the stubborn, repeatedly re-appearing "timestamp ghost workspaces" (`YYYY-MM-DD-HH-MM-SS` entries in the sidebar / `workspaces` table). Cross-platform (macOS / Windows), reversible (moves to Trash/Recycle Bin), backs up the database first, and guards active sessions. Never touches real named workspaces.

猎除 WorkBuddy 中删不掉、反复出现的「时间戳幽灵工作空间」的技能。

- **触发场景**:侧边栏浮现 `YYYY-MM-DD-HH-MM-SS` 格式残留条目,或 `workspaces` 表被写入时间戳路径
- **安全设计**:可逆(移入回收站/废纸篓,不直接删除)、先备份数据库、保护活跃会话,**绝不误伤命名真实的工作空间**
- **跨平台**:macOS / Windows
- **使用**:在 WorkBuddy 中召唤「幽灵工作空间猎手」,按提示确认目标后执行猎除
