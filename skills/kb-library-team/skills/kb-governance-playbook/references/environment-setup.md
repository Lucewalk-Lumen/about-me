# 环境前置准备（environment-setup）

> 适用成员：库正（W5 冷启动搭建 / 首次接库时的环境就绪引导）
> 定位：本文件解决「知识库环境从 0 到 1」——小白用户在出蓝图、收内容**之前**，须先把宿主环境装好、把库建起来。这是 W5 冷启动与一切写操作的前置层。

## 1. 什么时候需要这份指引

- 用户说「我想建个知识库，但什么都没装 / 不知道用哪个工具」。
- W5 冷启动第 0 步：确认目标库**已存在且可访问**，否则先做环境就绪，再走能力地图三步法（capacity-map-bootstrap.md）。
- 判据：环境未就绪时不进入蓝图设计——**先把工具装好、库建起来，再谈体系**。

## 2. 形态中立的环境就绪三步

无论选哪种宿主，都收敛为同一三步：

1. **装工具**：安装宿主客户端，或打开宿主平台（网页/小程序）。
2. **建库 / 定位库**：新建一个知识库（Obsidian 叫 Vault），或打开一个已有库；记下它的**位置**（本地文件夹路径 / 平台内库名）。
3. **跑通最小闭环**：手动放入 1 条真实内容（一篇笔记 / 一个文件），确认能新建、能保存、能重新打开找到——证明环境真的可用。

> 三步未完成前，不进蓝图、不建目录、不做采集。**先有可用的库，再谈治理。**

## 3. 分宿主上手路径

### 3.1 Obsidian（本地 Markdown 库）

1. **下载安装**：官网 `https://obsidian.md/download`（Windows / macOS / Linux / 移动端）。安装后启动一次，确认能正常打开。
2. **创建第一个库（Vault）**：启动后选「创建新库 / Create new vault」→ 起名（如「工作知识库」）→ 选一个**长期可访问的本地文件夹**（避免系统临时目录、下载目录）。这个文件夹就是你的「默认知识库」。
3. **跑通闭环**：新建一篇笔记（如「00-开始这里」），写一行字保存，关闭重开确认还在。
4. **（可选）插件**：核心功能已够用；确需扩展再到 设置 → 第三方插件/社区插件 浏览安装。**新手先不装插件**，把库用稳再说。
5. **WorkBuddy 访问方式**：Obsidian Vault 就是本地文件夹，WorkBuddy 通过本地文件系统直接读写，**无需安装任何连接器**；后续在 WorkBuddy 中提到"我的 Obsidian 库"时，直接提供 Vault 本地路径（如 `/Users/you/Documents/MyVault`）即可。
6. 之后治理细节（四阶段文件夹 / MOC / 双链）见 `hosts/obsidian-host.md`。

### 3.2 腾讯 IMA（平台知识库）

1. **打开平台**：`https://ima.qq.com/`（可用客户端 / 网页 / 微信小程序「ima 知识库」）。
2. **登录**：微信扫码登录（无需额外注册）。
3. **新建知识库**：进入「知识库」→「+ / 新建知识库」→ 填名称与简介 → 创建。这就是你的目标库。
4. **跑通闭环**：手动上传 1 个本地文件（PDF/Word/图片均可）或保存 1 篇公众号文章，确认能在库内看到并被检索到。
5. **（可选，WorkBuddy 侧）若要让 WorkBuddy 直接读写你的 IMA 库**：需安装并授权 **ima-mcp 连接器**——在 WorkBuddy 对话窗口左下角「+」→ 连接器管理中找到 ima，完成授权后，专家团才能经接口操作该库。此属 WorkBuddy 操作，与「你在 IMA 平台手动用库」是两回事。
6. 平台能力边界与接口护栏（批量上限、派生路径等）见 `hosts/ima-host.md`。

### 3.3 LLM Wiki（本地文件库，raw→wiki 三层）

1. **建目录**：在本机选一个长期文件夹，初始化 `raw/ wiki/ index.md log.md` 骨架（结构见 `hosts/llm-wiki-host.md`）。
2. **跑通闭环**：往 `raw/` 放 1 个原件 + 建 1 个同名 `.md` sidecar，确认目录可读可写。
3. **WorkBuddy 访问方式**：LLM Wiki 就是本地文件夹，WorkBuddy 通过本地文件系统直接读写，**无需安装任何连接器**；提供 Wiki 根目录的本地路径即可。
4. 三层编译细节见 `hosts/llm-wiki-host.md`。

### 3.4 腾讯乐享（企业级知识库）

1. **打开平台**：`https://lexiangla.com/`（企业版需企业管理员开通）。
2. **登录**：企业微信扫码或企业账号登录。
3. **定位或新建知识库**：进入「知识库」→ 选择已有 space 或新建 space，记下 space 名称。
4. **跑通闭环**：在该 space 下手动新建一篇文档，确认能保存、能在目录树看到。
5. **（WorkBuddy 侧）若要让 WorkBuddy 直接读写乐享库**：需在 WorkBuddy 连接器管理中授权 **lexiang 连接器**（已内置）——在对话窗口左下角「+」→ 连接器管理中找到乐享，完成 OAuth 授权后即可使用。
6. 平台护栏与批量上限（>20 条分批）见 `hosts/lexiang-host.md`。

## 4. 库正的环境就绪检查清单（接库时逐项确认）

- [ ] 用户已选定宿主（Obsidian / IMA / LLM Wiki / 乐享 / 其他）。
- [ ] 工具已装好、库已建立，用户能说清**库在哪**（本地路径 / 平台库名）。
- [ ] 最小闭环已跑通（库内已有 ≥1 条真实内容，能新建/保存/找回）。
- [ ] （IMA 且需 WorkBuddy 读写）ima-mcp 连接器已授权。
- [ ] （乐享且需 WorkBuddy 读写）lexiang 连接器已授权。
- [ ] （Obsidian / LLM Wiki）已提供本地路径，无需连接器。
- [ ] 以上任一不满足 → 先回 §3 对应宿主路径补齐，**再**进 capacity-map-bootstrap 三步法。

## 5. 纪律

- 环境未就绪不出蓝图、不做写操作——避免「帮用户在还没建好的库里设计空中楼阁」。
- 官方入口（下载/登录/建库）以 §3 所列官网为准；版本号、界面文案以官方实时页面为准，不固化。
- 不替用户做需登录/授权的操作（装客户端、扫码、授权连接器）——这些是**用户本人动作**，专家团只给步骤指引与确认断点。
