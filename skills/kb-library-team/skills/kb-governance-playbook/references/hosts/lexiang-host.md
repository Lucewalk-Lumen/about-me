# 乐享宿主特例（lexiang-host）

> 适用成员：罗采（企业平台护栏/智能表格入库）、苏航（乐享内索引落地）、安档（乐享特有指标口径）
>
> 乐享（lexiangla.com）是腾讯企业级知识库平台，通过 **lexiang 连接器**（已内置于 WorkBuddy）访问，需一次性授权。

## 1. 平台能力边界（2026-10 核实口径）

| 载体 | 直接入库 | 处理 |
|---|---|---|
| 文本文档（Markdown / 富文本） | 可 | 在指定知识库（space）下新建文档，Markdown 经 `markdown-to-block` 转 block 结构 |
| PDF / Word / PPT / 图片 | 可 | 走乐享连接器的文件上传通道；平台侧 AI 解析（`entry_describe_ai_parse_content`），不下载本地再解析 |
| 智能表格（smartsheet） | 可 | 结构化记录增删改查，适合存储入库登记、巡检日志、归档台账 |
| 网页 / 链接 | 可 | 以文本块形式嵌入 |
| 腾讯会议录制 | 可 | 经乐享连接器一键导入，平台 ASR 转写 |
| 视频 / 音频直传 | 受限 | 建议先转写为文本或抽取关键帧，再按文本/图片通道入库 |

**护栏**：文件/条目 > 20 个时必须分批执行（每批 ≤ 20 个），避免 token 超限。

## 2. 接口护栏

- **连接器授权**：首次使用经 WorkBuddy 连接器管理完成 OAuth 授权；401 错误立即停止重试，引导用户在连接器管理中重新授权。
- **写入安全红线**（沿用 lexiang connector 全局规则）：
  - 禁止遍历团队/知识库列表后自行选择写入目标
  - 禁止根据名称"看起来合适"就决定写入位置
  - 未确认前不执行任何写入
- **链接生成**：用 `whoami()` 返回的 `company.company_domain` 作为域名，不用 MCP endpoint 拼接。
- **大批量保护**：批量入库/移动 > 20 条时自动拆批，每批 ≤ 20 条，与全库治理的"每批 ≤ 10 条移动"口径从严执行。

## 3. 入库元数据（每条必备）

`source_file` / `modality` / `locator`（页码/时间戳/block_id）/ `quality_gate` / `derived_from` / `lexiang_entry_id`（乐享侧条目 ID，便于回链与去重）/ `lexiang_space_id`（所属知识库 ID）。

## 4. 乐享特有度量口径（仅作特例，不进形态中立主口径）

- 知识库订阅数、页面访问 UV/PV、评论数——平台侧导出，作为 metrics-methodology.md「采纳漏斗」的输入数据源之一。
- 智能表格记录数、字段完整率——可用于入库登记台账的完成度度量。
- 协作成员数、编辑活跃度——作为团队治理成熟度的代理指标。

## 5. 四池在乐享的落位

乐享无本地文件系统，用**知识库 + 文档分组**模拟四阶段：

- `01-灵感`（idea）：独立 space 或 space 内一级目录，存放草稿与灵感片段
- `02-半成品`（draft）：独立目录，文档标题前缀 `[draft]` 辅助标注
- `03-正式`（official）：独立目录，启用乐享的发布机制（草稿→发布两态）
- `04-归档`（archive）：只读目录，禁止编辑，仅追加归档日志（用智能表格登记）

status 以所在目录为准；乐享文档的 frontmatter 仅作辅助校验，与目录不一致时列为待确认，不擅自移动。

## 6. 索引与导航落地

乐享不像 Obsidian 有"双链"概念，但提供以下机制模拟 MOC：

- **知识库目录树**：主索引 = space 内一级目录；主题索引 = 二级目录
- **文档内链接**：在文档中插入 `https://<company_domain>/pages/<entry_id>` 形式的内部链接，构建交叉引用网
- **智能表格作为 MOC 表**：建一张「知识库总索引」智能表格，列 `entry_id` / `标题` / `所属主题` / `状态` / `最后巡检日期`，作为治理台账与导航入口
- **搜索召回**：齐证做 grounding 问答时，优先调用 `search_kb_embedding_search`（语义检索）+ `search_kb_search`（关键词检索）双通道，确保召回率

## 7. 协作与权限

- **多成员编辑**：乐享天然支持多人协作，巡检与归档操作需提前与库管理员对齐权限，避免越权写入。
- **评论作为反馈通道**：乐享支持文档评论，可作为质量巡检的用户反馈数据源。
- **草稿与发布**：齐证的 grounding 问答产出可保存为草稿，经用户审阅后再发布，符合"确认权在你"的全库纪律。

## 8. 与其他宿主的取舍

| 场景 | 推荐宿主 |
|---|---|
| 个人笔记本地化、纯文本为主 | Obsidian / LLM Wiki |
| 个人云端 + 微信生态 | IMA |
| **企业团队 + 多人协作 + 权限管控** | **乐享** |
| 企业既有腾讯生态（企微、腾讯文档） | 乐享（原生集成） |

选择乐享的典型信号：团队协作场景、需要权限分级、需要与腾讯会议/企业微信打通、需要智能表格做结构化台账。
