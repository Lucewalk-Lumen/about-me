# IMA 宿主特例（ima-host）

> 适用成员：罗采（平台护栏/派生路径）、安档（IMA 特有指标口径）

## 1. 平台能力边界（2026-09 核实口径）

| 载体 | 直接入库 | 处理 |
|---|---|---|
| PDF / Word / PPT / Excel / txt / Markdown | 可 | 结构化解析 |
| 图片（jpg/png） | 可 | 平台 OCR |
| 音频（mp3/wav/m4a/aac） | 可 | 平台 ASR 转写 |
| 网页 / 公众号 / 微信文件 / 笔记 | 可 | 抓取/一键导入 |
| 视频（mp4/avi/mov） | 不可 | 派生：音轨转音频入库 + 关键帧截图入图片 |

**护栏**：单次批量 ≤50 文件；PDF 单文件 <100M；txt <200K；个人库默认 100G。

## 2. 接口护栏

- 列表接口分页：≤50 条/次，翻页上限 10 次（约 500 条黄金窗口）。
- 移动接口：每批 ≤10 条；禁删禁覆盖（接口无删除能力，重复文件只能列清单请用户手动处理）。
- 文件夹创建：记录返回的 folder id 作为移动目标。

## 3. 入库元数据（每条必备）

source_file / modality / locator（页码/时间戳/帧号）/ quality_gate（是否过门限）/ derived_from（派生路径标注，视频→audio_track 或 screenshot）。

## 4. IMA 特有度量口径（仅作特例，不进形态中立主口径）

- 调用量、共享库订阅数、空间占用——平台侧导出，作为 metrics-methodology.md「采纳漏斗」的输入数据源之一。
- 视频派生条目量估算：`max(⌈时长s/60⌉, 时长s × fps)`（音轨段落数与截图条目数取大，同源去重）。

## 5. 四池在 IMA 的落位

IMA 无文件系统，用文件夹模拟四阶段：`01-灵感` `02-半成品` `03-正式` `04-归档`；status 以文件夹为准，条目标题前缀可辅助标注（如 `[draft]`）。
