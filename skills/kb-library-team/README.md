# 智博资料室（kb-library-team）

> **命名说明**：本馆中文显示名为 **智博资料室**，英文显示名与资产 ID 同为 **kb-library-team**。资产 ID `kb-library-team` 为平台历史标识不可修改，其中 `kb` 音译为 **「智博」**——「智」对应智慧、智能管理，「博」对应博学、博采众长；「智博资料室」即 `kb-library-team` 的中文对应名，三层命名（资产 ID / 英文显示名 / 中文显示名）字面同源、语义统一。包内 7 个智能体与技能目录沿用的 `kb-` 前缀，亦按「智博」理解，与资产 ID 保持同源。

一支 7 人专家团，覆盖知识库全生命周期治理：采集入库、分类组织、成熟度晋级、索引导航、基于库的问答、质量巡检、版本归档与价值度量。方法论形态中立，支持本地 Obsidian 库、本地 LLM Wiki、腾讯 IMA 知识库、腾讯乐享企业知识库等多种宿主；宿主相关特例放在技能的 `skills/kb-governance-playbook/references/hosts/` 中。

## 使用示例

- 「先用你的示例库给我演示一次知识库体检。」（**没接自己的库也能看**：主理人检测到未连接库时，会用内置示例库现场演示体检/问答/归档全流程，数字由脚本真实计算，看完可一键引导接入你的库实测）
- 「帮我为这个知识库做一次完整的治理体检，并给出整改建议清单。」
- 「这批资料帮我登记入库，先出清单我确认后再执行。」
- 「基于我的知识库回答这个问题，逐条标注依据来源与置信度。」
- 「这条 idea 够不够格升 draft？给我一份待晋级候选评审。」
- 「产品手册 v2 已发布，帮我把 v1 走归档流程。」

> **首次体验无需准备知识库**：未提供库路径时，专家团自动用 `skills/kb-governance-playbook/references/demo-vault/` 的内置示例库演示核心能力（该示例库为已治理的干净库，演示呈现完整体检流程、四池分布统计与健康分计算，数字真实可复算）；提供你的库路径或授权对应连接器后即可切换为实测。

## 工作原则

- 确认权在你：一切写操作（移动、入库、晋级、归档、索引写入）先列清单，经你确认后执行。
- 只归档不删除：旧版本进归档区并登记替代关系，日志只追加，附回滚路径。
- 答得准：基于库的问答引用先行，逐条标注「库内有据 / 库内无据-外源 / 不确定」与置信度。
- 数字可复算：健康分、重复检测、死链扫描、门槛预检由随附脚本确定性计算。

## 安装

在 WorkBuddy 中导入本包后，settings.json 已将默认 agent 指向主理人库正；直接对团队说出你的知识库路径与诉求即可开始。
