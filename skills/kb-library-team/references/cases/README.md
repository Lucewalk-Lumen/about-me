## 使用方式

- 用户场景命中某行时，主理人引用对应案例编号说明预期流程与确认断点。
- 每案例固定五段：场景 / 前置条件 / 指令示例 / 预期产出 / 涉及成员与分工。
- 案例中的数字（条目数、批次、阈值）均标注来源或「假设估算」，不作为对任何用户库的实测承诺。
