# case-05：产品手册 v2 发布，v1 走归档流程

> 场景分类：版本归档 ｜ 涉及成员：安档（主）、齐证、库正 ｜ 对应 Workflow：W7

## 1. 场景

团队的产品手册发布了 v2 版（正式池新增），v1 版仍在正式池里，且有几篇其他文档引用着 v1 的链接。用户希望 v1 妥善退休：不能删（历史追溯要用）、不能继续被当成有效版本引用、全过程留痕可回滚。

## 2. 前置条件

- 库形态：正式池含 v1 与 v2 两版手册；存在指向 v1 的互链（数量由苏航/脚本实测，本案例不预设数字）。
- 用户需准备：v1/v2 条目路径；归档区位置（或按宿主形态确认 archive 标记方式）。

## 3. 指令示例

> 产品手册 v2 已经发布进正式池了，帮我把 v1 走归档流程：登记替代关系、列出哪些文档还在引用 v1、出归档建议单，我确认后执行，日志只追加，给我回滚路径。

## 4. 预期产出

- 安档：归档建议单（条目 × 归档三件事：时间/原因/替代版本 × 引用方清单 × 回滚路径）+ 只追加日志片段。
- 齐证：归档执行后复核引用完整性（指向 v1 的链接已改指 v2 或标注失效）。
- 确认断点（2 处）：①归档建议单逐条确认 ②引用方链接清理确认（改指 v2 / 标注失效）。

## 5. 涉及成员与分工

| 成员 | 本案例中的职责 | 产出 |
|---|---|---|
| 库正 | 建团、两处确认断点把守、汇总 | 归档结果汇总 + 日志片段 |
| 安档 | 替代关系登记、归档建议单、只追加日志、回滚路径说明 | 归档建议单 + 日志片段 |
| 齐证 | 归档后引用完整性复核 | 引用复核结论 |
