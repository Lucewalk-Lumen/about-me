# CHANGELOG

## 1.0.5 版本发布 🚀（2026-10-22）

- 新增无库演示模式：未提供知识库时自动用内置示例库演示体检、问答、归档全流程，看完可引导接入自己的库实测
- 新增内置示例知识库：客户运营主题示例库含四池七条目、元信息两条目与索引，已治理干净，体检结果由脚本真实计算、可复算
- 新增示例库一键体检：死链孤儿扫描、重复检测、晋级预检、四池分布统计四步一份报告
- 新增缺输入时的降级应答：成员暂时缺库路径或参数时给出待补清单而非没有回应，每轮协作都有可见产出
- 新增采集入库、成熟度晋级两篇场景案例，八条工作流程均有对应案例
- 新增一句话同时命中多个意图时的分流规则，减少路由歧义
- 优化首次引导指令改为先看示例演示再接自己的库，首次打开即可看到完整能力
- 优化说明文档案例计数与实际案例库一致
- 优化示例库演示口径，主理人演示说明与示例库实际条目分布一致
- 优化示例库一键体检脚本的运行环境适配，跨机器开箱即用
- 优化更新日志体例对齐官方规范：版本标题补 🚀 与「版本发布」固定措辞，条目统一动词开头，删除分类小节与开发过程叙述
- 优化包版本与技能版本同步登记，保持单一真源
- 优化展示描述文案，字数符合中文四十至五十字的登记要求
- 优化成员一览表补充各成员负责领域编号，一人兼两职的分工一目了然
- 优化技能加载方式，七位成员统一预置治理方法论，响应更稳定
- 修复晋级预检在传入目录时不识别条目的问题，现支持自动展开目录中的条目并明确提示空目录
- 修复打包目录名与资产标识不一致导致的解析问题，统一为 kb-library-team
- 修复案例库入口不可达的问题，案例改为可点击链接并在工作流表中标注对应案例编号
- 修复索引导航官四类标签写法的分隔不一致

## 1.0.2 版本发布 🚀（2026-10-20）

- 优化中文显示名由「私人图书馆」更名为「智博资料室」，英文显示名与资产标识同源，三层命名统一
- 优化 kb 指代由直译改为音译「智博」（智 = 智慧管理，博 = 博采众长），命名说明同步改写
- 优化主理人职称由「馆长」更名为「首席知识管理官」
- 修复资产标识与平台不一致导致的上传解析失败
- 优化内部标识统一为 kb- 前缀，与资产标识完全对齐
- 新增说明文档开头的命名说明，消除字面直译的拗口读法
- 优化全部八张头像重绘为暖光扁平插画风，成员表情温和专业
- 优化主理人协作规范：补充严禁行为、协同可观测性与协作规则
- 新增六位成员的回传约定，产出统一回传主理人，不直连用户、不互相通信、不代写他人结论
- 新增乐享宿主特例文档，覆盖企业级知识库场景的平台能力边界、批量护栏、智能表格入库与多人协作权限
- 优化四家宿主访问方式说明，说明文档新增访问方式速查表
- 优化环境前置准备文档纳入乐享上手路径与授权说明，环境就绪检查覆盖四家宿主

## 1.0.0 版本发布 🚀（2026-10-18）

- 内置智博资料室专家团（七名专家），把零散资料整理成随问随答的知识库：采集入库、分类编目、晋级沉淀、索引导航、问答溯源、巡检整改、归档度量
- 内置首席知识管理官库正，提供八条预设工作流程与单成员直调路由
- 内置采集入库官罗采，支持多源资料登记、提取与入库护栏校验
- 内置分类组织官林归类，支持分类方案设计、归类映射表与分批移动计划
- 内置晋级评审官关晋，支持四池成熟度门槛评审
- 内置索引导航官苏航，支持总索引、双链建议、标签收敛与死链报告
- 内置问答质量官齐证，支持引用先行问答、三态标注与三级质量巡检
- 内置归档度量官安档，支持只追加式归档日志与健康分度量
- 内置治理方法论技能，涵盖形态中立方法论与宿主特例
- 提供四个确定性脚本：健康分计算、晋级门槛预检、重复检测、死链扫描
- 提供五份产出模板：总索引、晋级评审报告、巡检报告、归档日志、问答引用
- 提供六个真实场景改编案例，覆盖整理归类、治理体检、查询回答、冷启动搭建、版本归档、质量审计
- 优化头像统一为卡通人物插画风格，八张全部重制并压缩至规定大小以内
- 优化说明文档方法论清单补全冷启动能力地图与环境前置准备两篇
- 修复度量方法论中成员名笔误的问题
