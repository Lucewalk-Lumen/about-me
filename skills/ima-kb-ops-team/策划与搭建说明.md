# IMA知识库自动运营专家团 — 策划与搭建说明（v2.0）

## 1. 项目背景

基于 **WorkBuddy开放平台深度指南** 和 **IMA知识库Skill技能全生命周期教程** 两份参考文件，深度拆解 IMA 知识库运营的全链路流程，创建覆盖知识库规划、内容生产、质量检测、Skill 生成、自动更新、检索调优、版本管理、运营监控、提示词解析、知识洞察与 ROI 十大环节的自动运营专家团。

## 2. 团队定位

| 维度 | 说明 |
|------|------|
| **团队名称** | IMA知识库自动运营团（ima-kb-ops-team） |
| **团队类型** | 专家团（expertType: team） |
| **版本** | **v2.0.0**（v1.0.0 → v2.0.0 全面升级） |
| **成员数** | **11 人（1 主理人 + 10 成员）** |
| **拓扑** | 串行流水线 + W10 并行体检支线 |
| **核心能力** | 知识库全生命周期运营 + 确定性指标计算 |

## 4. 预设 Workflow（W1-W10）

| ID | Workflow | 调度序列 | 触发示例 |
|----|----------|----------|----------|
| W1 | 提示词解析与检索改写 | 解析 → 检索验证 | "这句话在问什么" |
| W2 | 知识库冷启动规划 | 规划 → 容量护栏 | "从零搭知识库" |
| W3 | 内容生产流水线 | 生产 → 质检 → 版本 | "素材变条目" |
| W4 | 质量审计专项 | 质检 → 冷门定位 | "哪条最差" |
| W5 | Skill 生成流水线 | Skill 生成 → 触发词验证 | "生成 Skill" |
| W6 | 自动更新管道搭建 | 自动更新 → 告警规则 | "内容自动变新" |
| W7 | 检索调优闭环 | 调优 → bad-case 佐证 | "检索不准" |
| W8 | 版本回滚与变更 | 版本管理 → 回归巡检 | "回滚" |
| W9 | 运营监控巡检 | 监控 → ROI 归因 | "出周报" |
| W10 | 全链路一键体检 | 5 成员并行出报告 + 汇编 | "全面体检" |

调度铁律：Workflow 内成员按序串行（前序产出原文传递）；W10 允许并行 5 成员；TeamCreate 只由主理人执行；意图不匹配任何 W 时走 SOP Phase 1-10 兜底。

## 5. SOP 流程设计（10 阶段）

- Phase 1 规划（kb-planner）→ Phase 2 生产（content-producer）→ Phase 3 质检（quality-auditor）→ Phase 4 Skill 生成（skill-engineer）→ Phase 5 版本（version-manager）→ Phase 6 监控（ops-monitor）——v1.0 原有六阶段
- Phase 7 提示词解析（prompt-analyst，可与 Phase 1 并行的独立支线）
- Phase 8 自动更新管道（auto-sync，依赖 Phase 1 + 内容源清单）
- Phase 9 检索调优（retrieval-tuner，依赖 Phase 2 + Phase 8）
- Phase 10 知识洞察与 ROI（kb-analyst，依赖 Phase 6 + 使用日志）
- 每阶段含：类型/输入 artifact/任务/产出 artifact/完成判定/失败路径（重调度 1 次上限）
