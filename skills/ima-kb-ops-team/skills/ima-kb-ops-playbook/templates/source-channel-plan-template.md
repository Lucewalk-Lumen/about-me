# ima 采集源规划方案模板（Source Channel Plan）

> 产出成员：ima-source（顾采）| 配套脚本：source_channel_calc.py
> 平台前提：腾讯 ima 八大官方导入渠道，视频不支持直接入库

## 填写说明
- 第 3 节分批规划必须引用 source_channel_calc.py 输出（≤50 校验 + 容量护栏）。
- 渠道选型必须落在八大官方渠道白名单内，未知渠道脚本会直接报错。
- 任何"视频直入"表述禁止出现，必须写预转换（音轨/截图）。
