# 多模态入库方案模板（Multimodal Ingestion Plan）

> 产出成员：multimodal-ingest（陈析）| 配套脚本：multimodal_ingest_calc.py
> 平台前提：腾讯 ima 知识库——**视频不支持直接上传，须走派生路径**

## 填写说明
- 第 0 节平台能力核对必须填写，确认视频走派生路径。
- 第 6 节入库量必须引用 multimodal_ingest_calc.py 输出。
- 每条入库条目必须可溯源（source_file + locator），缺则禁止入库。
- 低于质量门限的素材必须打回人工，禁止自动放行。
- 单次批量导入 ≤50 文件（ima 护栏），超限分批。

# 多模态入库方案 — <项目名>

## 0. 平台能力核对（腾讯 ima）
- 直接支持入库：PDF / Word / PPT / Excel / txt / Markdown / 图片(jpg/png,OCR) / 音频(mp3/wav/m4a,ASR) / 网页 / 公众号 / 微信文件 / 笔记 / 腾讯文档 / Xmind
- **视频(.mp4/.avi/.mov)：不支持直接入库**，本方案按「提取音轨→音频 + 关键帧截图→图片」派生路径处理
- 护栏：单次批量 ≤50 文件；PDF <100M；txt <200K；个人库默认 100G

|----------|--------|--------|------|----------|

| 图片 | | OCR / 视觉描述 | ima 内置 | OCR 置信度 ≥ 0.9 |
| 音频 | | ASR+时间戳+说话人 | ima 自动转写 | WER ≤ 10% |
| 视频（派生） | | ① 音轨→音频 ② 截图→图片 | 提取工具 + ima | 截图清晰度 ≥ 阈值 |

## 4. 去重与合并
- hash 去重：内容 SHA-256 相同不重导
- 语义去重：跨模态同源（PPT↔PDF、录音↔转写稿、**视频音轨↔独立录音**）识别合并
- 合并规则：保留信息最全的一份，另一份标注"同源引用"

## 5. 元数据补全规范
