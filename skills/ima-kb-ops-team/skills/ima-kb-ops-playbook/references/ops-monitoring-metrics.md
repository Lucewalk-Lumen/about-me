# 运营监控指标

## 1. 核心指标定义

| 指标 | 计算方式 | 数据源 | 目标值 | 告警阈值 |
|------|----------|--------|--------|----------|
| 知识覆盖率 | 已组织知识/总知识量 | 条目统计 | >90% | <80% |
| 检索命中率@5 | 成功检索次数/总检索次数 | 检索日志 | >85% | <70% |
| 平均响应时间 | 总响应时间/请求数 | 性能监控 | <3秒 | >5秒 |
| 用户满意度 | 满意评价数/总评价数 | 反馈系统 | >4.2/5.0 | <3.5 |
| 知识复用率 | 被Skill引用知识/总知识量 | 引用统计 | >60% | <40% |
| Skill调用成功率 | 成功调用/总调用 | 调用日志 | >95% | <90% |
| 内容过期率 | 过期条目/总条目 | 时效检查 | <10% | >20% |
| 版本回滚率 | 回滚次数/发布次数 | 版本记录 | <5% | >15% |

## 2. 告警规则

| 规则名 | 触发条件 | 严重度 | 通知方式 | 响应 SLA |
|--------|----------|--------|----------|----------|
| 检索命中率下降 | 召回率@5 <70% 持续1小时 | 高 | 即时通知 | 30分钟 |
| 响应时间超标 | 平均响应时间 >5秒 持续30分钟 | 高 | 即时通知 | 15分钟 |
| 内容过期预警 | 过期率 >20% | 中 | 日报 | 24小时 |
| Skill调用失败 | 成功率 <90% 持续1小时 | 高 | 即时通知 | 30分钟 |
| 知识覆盖率不足 | 覆盖率 <80% | 低 | 周报 | 72小时 |
| 版本回滚频繁 | 回滚率 >15% | 中 | 即时通知 | 1小时 |

## 3. 巡检周期

| 巡检项 | 频率 | 负责人 | 输出物 |
|--------|------|--------|--------|
| 检索健康度 | 每日 | ops-monitor | 日报 |
| 内容质量抽检 | 每周 | quality-auditor | 周检报告 |
| 版本状态确认 | 每周 | version-manager | 版本状态表 |
| 运营指标汇总 | 每月 | ops-monitor | 月报 |
| 用户反馈分析 | 每月 | kb-planner | 反馈分析报告 |

## 4. 健康报告模板

### 日报结构
```

## 核心指标
- 检索命中率：{X}%（环比 {+/-Y}%）
- 平均响应时间：{X}s
- Skill调用量：{N} 次
- 成功率：{X}%

## 异常事件
- {事件描述} → {处理状态}

## 待办事项
- [ ] {事项}
```

## 5. 异常处理流程

```
发现异常 → 确认范围 → 根因分析 → 修复 → 验证 → 复盘
    ↑________________________________________________↓
```

**异常分级**：
- P0（紧急）：检索完全不可用、数据泄露 → 15分钟响应
- P1（高）：命中率严重下降、响应时间超标 → 30分钟响应
- P2（中）：内容过期率上升、Skill调用失败 → 2小时响应
- P3（低）：覆盖率不足、用户反馈一般 → 24小时响应
