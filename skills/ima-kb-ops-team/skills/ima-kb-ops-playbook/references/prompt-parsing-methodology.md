# 提示词解析方法论（Prompt Intent Engineering）

> 适用成员：prompt-analyst（顾解）| 脚本：prompt_intent_calc.py

## 核心原则
1. **意图先行**：先判主意图再填槽位，意图错了槽位全白填。
2. **最小追问**：一次追问 ≤3 项，低优先级槽位用默认值兜底并显式标注"默认"。
3. **实体守恒**：检索改写必须保留原文全部实体与限定词，改写覆盖率必须 = 100%。
4. **歧义必消**：多义词必须结合知识库标签体系判定，判定不了就进追问清单。

## 意图六分类（置信度判定基准）
| 意图 | 典型句式 | 处置 |
|------|----------|------|
| 信息查询 | "是什么 / 怎么查" | 直接检索 |
| 操作指令 | "帮我做 / 配置 / 生成" | 触发 Skill |
| 方案生成 | "给我一套 / 设计" | 多成员协作 |
| 对比评估 | "A 和 B 哪个好" | 检索 + 结构化对比 |
| 故障排查 | "报错了 / 不生效" | 定位 + 分步排查 |
| 闲聊兜底 | 无领域实体 | 礼貌降级，不检索 |

## 槽位表设计（对应 Skill 必需参数）
- 每个 Skill 维护一张"必需槽位表"，解析时逐项对号入座。
- 槽位状态三态：已填（有值）/ 默认（用缺省值，须标注）/ 缺失（必须追问）。
- 完整度 = 已填 + 默认 / 总数；< 0.7 触发追问（与 prompt_intent_calc 的 clarify 模式对齐）。

## 检索改写规范
1. 同义扩展：每类实体给 1-2 个领域同义词（用标签体系内的词，不自造词）。
2. 关键词归一：型号统一全大写、中英文并列（"RAG（检索增强生成）"）。
3. 限定词守恒：原文"2026 版""P0 级"等限定词必须出现在改写问法中。

## 交叉校验（对应 prompt-analyst 禁止越界条款）
- 意图置信度 = 低 且 缺失槽位 ≥2 → 必须输出追问清单。
- 改写覆盖率 < 1.0 → 违规，需补回丢失限定词。
- 所有数字引用 prompt_intent_calc.py 输出，禁止手写。
