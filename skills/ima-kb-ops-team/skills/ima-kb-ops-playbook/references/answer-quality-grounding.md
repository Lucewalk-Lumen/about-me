# 问答质量与溯源方法论（Answer Quality & Grounding）

> 适用成员：answer-quality（答谨）| 脚本：answer_quality_calc.py
> 平台前提：ima 核心场景是"基于知识库精准问答——精准召回信源 + 深度思考 + 原文溯源"

## ima 问答的已知局限（必须纳入评估）
- **知识时效性**：回答基于库存内容，无法获取库外最新信息 → 库外问题必须**拒答而非编造**
- **多模态以文本为主**：图片/视频理解有限
- **推理深度依赖库内显式知识**，非模型推理能力

因此：**问答质量 = 召回质量（retrieval-tuner）× 溯源质量（本专家）× 拒答纪律（本专家）**

## 三项核心指标
| 指标 | 定义 | 门禁 |
|------|------|------|
| 溯源命中率 | 带有效溯源（可跳回库存条目）的回答 / 总回答 | **P0 ≥ 0.90** |
| 幻觉率 | 含库内不存在断言的回答 / 总回答（黄金集双盲标注） | **P0 ≤ 0.05** |
| 拒答精准率 | 应拒且实拒 / 应拒 | P1 ≥ 0.80 |

**高危子集**：库外问题被回答（而非拒答）= 幻觉高危，单独计数，出现即强制阻断。

## 黄金集双盲标注（幻觉统计唯一依据）
- 样本 ≥ 30 条，不足则结论降级"参考值"
- 两名标注员独立标注，一致才计为幻觉；单人标注不作数
- 每条幻觉定位到 source_file + locator，回流 quality-auditor（修条目）或 retrieval-tuner（修召回）

## 门禁裁决（answer_quality_calc.py 闭式）
- P0 任一不过（溯源 < 0.90 或 幻觉 > 0.05）→ verdict = **block**（阻断对外发布）
- 仅 P1 不过 → verdict = **fix**（需修复，不阻断）
- 库外被回答 > 0 → 强制 block
- 与 eval-benchmark 联合裁决（W21 共享库发布门禁）

## 交叉校验
- 三项指标引用 answer_quality_calc.py，禁止 LLM 直接估算
- 幻觉必须走双盲标注，单人标注作废
- P0 不过结论必须写"阻断发布"，不得降级"建议"
- 断链条目定位到 source_file + locator，无定位不回流
- 库外被回答单独高危计数
- 报告落款三态标注
