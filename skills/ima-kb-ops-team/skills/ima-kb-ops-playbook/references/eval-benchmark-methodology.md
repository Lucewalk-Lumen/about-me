# 评估与基准方法论（Evaluation & Benchmarking）

> 适用成员：eval-benchmark（沈规）| 脚本：eval_gate_calc.py

## 核心信条
**改动的价值必须能量化，否则就是玄学。** 每次内容/Skill/检索变更，都要能跑一遍黄金集、对照门禁阈值、给出通过/回退/阻断的确定性结论。

## 黄金测试集（Golden Set）
- 规模：30–100 条金标准问题（< 50 条结论置信度降级，必须标注"样本不足"）
- 来源：高频问法 + 历史 bad-case + 专家评审
- 每条标注：期望命中条目、期望答案要点、难度分
- 按场景分组（信息查询/故障排查/方案生成…），保证覆盖面

## 指标体系（按场景绑定）
| 指标 | 含义 | 典型 P 级 | 默认阈值 |
|------|------|-----------|----------|
| accuracy（准确率） | 答案正确率 | P0 | ≥ 0.90 |
| harmlessness（无害性） | 无有害/幻觉 | P0 | ≥ 0.95 |
| mrr（平均倒数排名） | 检索排序质量 | P1 | ≥ 0.60 |
| ndcg@5（排序增益） | 相关性排序 | P1 | ≥ 0.70 |
| completeness（完整性） | 答案覆盖要点 | P1 | ≥ 0.85 |

- **P0 = 阻断级**（任一不过禁止发布）；**P1 = 告警级**（达标率 ≥ 80% 放行）

## 发布门禁判定（对应 eval_gate_calc.py）
1. P0 任一不达标 → **block**（阻断发布）
2. P0 全过 且 P1 达标率 ≥ 0.8 → **pass**（放行）
3. 其余 → **warn**（告警放行，带风险标注）
4. 黄金集规模 < N_req（默认 50）→ 结论加"样本不足"注记

## 回归测试流程
- 触发：每次内容批量更新 / Skill 配置变更 / 检索调优上线
- 跑集：同一黄金集（口径不可变，禁止换集对比）
- 回退判定：任一 P0 回退即阻断；P1 回退 > 5% 告警
- 回滚锚点：联动 version-manager 的快照号

## 标注治理
- Cohen's Kappa 抽检（≥ 0.7 一致性才可用），防止标注噪声淹没真实信号
- 抽检频率：每批次 + 季度全量复核

## 交叉校验
- 黄金集 < 50 条 → 置信度降级，标注"样本不足"
- Kappa < 0.7 → 先修标注再谈指标
- 门禁阈值必须引用 eval_gate_calc.py（P0/P1 分级 + verdict），禁止手拍
- 每次变更必须同集回归
- 报告落款标注三态
