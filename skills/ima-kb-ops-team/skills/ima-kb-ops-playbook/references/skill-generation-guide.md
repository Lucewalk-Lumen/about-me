# Skill 生成指南

## 1. Skill 类型选择

| 类型 | 适用场景 | 核心技术 | 触发词特征 |
|------|----------|----------|------------|
| 问答型 | 技术支持、产品咨询、知识查询 | RAG检索增强 | "什么是""怎么""如何" |
| 生成型 | 文章撰写、报告生成、方案编写 | 模板填充 | "帮我写""生成""起草" |
| 分析型 | 数据分析、竞品对比、趋势预测 | 结构化推理 | "分析""对比""评估" |
| 对话型 | 多轮交互、场景模拟、角色扮演 | 上下文记忆 | "聊聊""讨论""模拟" |

## 2. SKILL.md frontmatter 规范

**必填字段**：
```yaml
name: skill-name              # 小写字母+连字符
description: 英文描述          # 含触发词
version: 1.0.0                # 三段式
author: 合作方名称
```

**可选字段**：
```yaml
allowed-tools: Read,Write,Bash  # 工具白名单
disable-model-invocation: false # 是否禁用模型自动调用
user-invocable: true            # 用户是否可手动调用
```

**触发词设计原则**：
- description 含 ≥3 条触发词
- 覆盖用户常见表述（口语化 + 书面语）
- 中英文双语对齐

## 3. 三件套拆分原则

| 子目录 | 存放内容 | 何时需要 |
|--------|----------|----------|
| references/ | API规范、字段类型表、示例数据、方法论 | 知识量大、需按需加载 |
| scripts/ | 确定性计算脚本、数据处理脚本 | 有数值计算或固定流程 |
| templates/ | 输出模板、报告骨架、工作流模板 | 输出格式固定 |

**决策树**：
```
知识是否 >3000字？
├── 是 → 拆 references/
└── 否 → 放正文

是否有数值计算？
├── 是 → 写 scripts/
└── 否 → 跳过

输出格式是否固定？
├── 是 → 写 templates/
└── 否 → 跳过
```

## 4. 边界与拒绝模板

```markdown
## 边界与拒绝

- **不做资质判断**：涉及XX资质认证时，提示用户由官方渠道核实
- **不做决策建议**：只输出分析与方案，最终决策由用户做出
- **不代发/代操作**：不直接执行外部操作（发邮件、写文件等）
- **不编造数据**：所有数字标注来源或假设前提
- **涉及敏感内容**：涉及隐私/合规时提示用户审查
```

## 5. Skill 生命周期

```
规划 → 创建 → 测试 → 发布 → 迭代
  ↑___________________________↓
              反馈闭环
```

| 阶段 | 核心任务 | 产出物 | 时间占比 |
|------|----------|--------|----------|
| 规划 | 需求分析、知识库评估 | 需求文档、架构图 | 20% |
| 创建 | 提示词编写、配置调试 | Skill配置、提示词模板 | 30% |
| 测试 | 功能验证、性能测试 | 测试报告、优化建议 | 20% |
| 发布 | 上线部署、文档编写 | 上线文档、使用指南 | 10% |
| 迭代 | 数据监控、问题修复 | 迭代日志、版本记录 | 20% |
