# 多模态入库方法论（Multimodal Ingestion）

> 适用成员：multimodal-ingest（陈析）| 脚本：multimodal_ingest_calc.py
> 平台前提：腾讯 ima 知识库（ima.qq.com）——**视频不支持直接上传，须走派生路径**

## 腾讯 ima 能力边界（2026-09 核实）

| 载体 | 直接入库 | 处理 |
|---|---|---|
| PDF / Word(.doc/.docx) / PPT(.ppt/.pptx) / Excel(.xls/.xlsx/.csv) / txt / Markdown | ✅ | 结构化解析 |
| 图片（jpg/png） | ✅ | ima 自动 OCR |
| 音频（mp3/wav/m4a/aac） | ✅ | ima 自动 ASR 转写 + 解读总结 |
| 网页 / 公众号 / 微信文件 / 笔记 / 腾讯文档 / Xmind | ✅ | 抓取 / 一键导入 |
| **视频（.mp4/.avi/.mov）** | ❌ | **派生：音轨转音频入库 + 关键帧截图入图片** |

**护栏**：单次批量 ≤50 文件；PDF 单文件 <100M；txt <200K；个人库默认 100G。

## 核心原则
1. **异构归一**：所有模态最终收敛为"干净条目 + 可溯源元数据"，下游检索层不感知原始格式。
2. **质量门限**：每个模态有质量门限（OCR 置信度 / ASR WER / 表格完整度），不达标打回人工，禁止自动放行。
3. **可溯源**：每条入库条目必须带来源文件 + 定位（页码/时间戳/帧号），无来源不入库。
4. **去重合并**：跨模态同源（PPT↔PDF、录音↔转写稿、视频音轨↔独立录音）hash + 语义双去重，避免同一知识重复占条目。
5. **平台对齐**：禁止假设 ima 能直接存视频本体——凡涉及视频，必须写明派生路径。

## 模态处理链
| 模态 | 处理链 | 关键门限 | 说明 |
|------|--------|----------|------|
| 文档（PDF/Office/MD/txt） | 结构化解析（标题层级/表格/列表）→ Markdown | 表格解析完整度 ≥ 95% | 表格转 Markdown 保留结构 |
| 图片 | 有文字→OCR；纯图形→视觉描述（图生文） | OCR 置信度 ≥ 0.9 | 纯图形才走描述 |
| 音频 | ASR 转写 + 时间戳 + 说话人分离 | WER ≤ 10%（可懂域） | ima 自动转写，按 ~60s 切段落 |
| 视频（派生） | ① 提取音轨→音频链 ② 关键帧截图→图片链 | 音轨 WER≤10%；截图清晰度≥阈值 | **视频本体不入 ima**；fps 越高截图条目越多 |

## 入库量闭式估算（对应 multimodal_ingest_calc.py）
- 文档：条目数 = 文件数 × 每文件主题数（默认 1）；分块数 = 总页数 × 每页分块数
- 图片：每图 1 条目（OCR 或描述）
- 音频：条目数 = ⌈时长s / 60⌉（按段落）
- **视频（派生）：条目数 = max(⌈时长s/60⌉, 时长s × fps)**
  - ⌈时长s/60⌉ = 提取音轨走音频链的段落数
  - 时长s × fps = 关键帧截图走图片链的条目数
  - 取 max 作并集去重上限（同源不重复占条目）
  - 脚本参数：`--video-seconds`（时长）、`--fps`（截图采样率，0=仅音轨）、`--no-audio-track`（仅截图）
- token 预算 = Σ(各模态分块数 × 单块 token)

## 元数据补全规范（每条必备）
| 字段 | 说明 |
|------|------|
| source_file | 来源文件（视频派生条目填源视频文件名） |
| modality | doc/image/audio/video_derived（video 本体不入 ima） |
| locator | 页码 / 时间戳 / 帧号（视频截图填帧序号 + 时间戳） |
| engine_version | 解析引擎版本（可复算） |
| quality_gate | 是否过门限 + 实测值 |
| derived_from | 派生路径标注（视频→audio_track / screenshot） |

## 交叉校验
- 每条入库条目可溯源（source + locator），缺则禁止入库
- 低于门限素材必须打回人工，禁止自动放行
- 视频/音频入库量必须引用 multimodal_ingest_calc.py，禁止拍脑袋，**禁止按"视频本体直接入库"估算**
- 跨模态同源必须合并（含视频音轨与独立录音）
- 单次批量文件数 ≤50（ima 护栏），超限分批
- 报告落款标注三态
