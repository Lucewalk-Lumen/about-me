# 品牌知识库搭建专家团

AI 里问起你们公司，说出来的信息又旧又散，还把竞品和你们混在一起？这个专家团把「品牌该怎么讲清楚」拆成两件必须做扎实的事——**品牌基础信息库**与**差异化能力清单**——由品牌事实官整理事实、差异化能力官提炼能力、事实核验官逐条定证据等级与对外权限，主理人裁决口径后由引用适配官产出**一份可直接投喂给 AI、也可直接贴进内部文档的成品知识库**，最终汇编成一份《品牌知识库搭建方案》。

AI 描述一个品牌时，用的不是"你希望它说的话"，而是它在公开信源里读到过的"品牌事实"。企业没有主动把事实讲清楚，AI 就只能用三样东西拼答案：**竞品说自己时的那套话、第三方零散且过时的信息、平台自己的猜测**。所以知识库不是文档整理，它是**内容工程的地基**——先有事实源，再有内容；事实源没立住，后面写多少稿都是在流沙上盖楼。

## 五大核心能力

| 能力模块 | 解决什么问题 | 交付物（你能拿走的实物） |
|---------|------------|----------------------|
| **01 认知缺口诊断**<br>AI 现在怎么说这个品牌 | 不知道 AI 到底把你的公司说成什么样、问题出在哪一类 | · 认知缺口清单，分「说错的 / 说漏的 / 说偏的」三类，逐条带公开信源出处 |
| **02 品牌基础信息库**<br>八模块事实源 | 公司事实散在官网、PPT、销售话术里，说法还不一致，AI 读不到也没法信 | · 八模块事实卡（主体身份 / 业务范围 / 产品与服务 / 资质与认证 / 组织与团队 / 发展历程 / 客户与合作 / 对外口径），每条带来源与状态 |
| **03 差异化能力清单**<br>人无我有 | 最该被 AI 知道的那点能力，公开信源里根本没有 | · 六栏能力清单（能力主张 ＋ 差异坐标 ＋ 证据线索 ＋ 可比较表述 ＋ 适用场景 ＋ P0/P1/P2 优先级） |
| **04 证据与口径核验**<br>挡住自己会踩的坑 | 写了一条不能对外说的（无出处数字、未授权客户名、绝对化表述），被 AI 原样引用出去 | · 事实核验表（逐条含证据等级、来源、风险类型、修改建议）<br>· 禁用 / 待补证 / 口径冲突三张清单 ＋ 成品终检结论 |
| **05 引用适配产成**<br>AI 摘得出来的写法 | 内容写得不少，AI 一句都摘不出来 | · 成品知识库（品牌实体段 ＋ 标准问答对 12–18 条 ＋ 可引用句库 15–25 句），分对外版与内部版 |
| **汇总交付**<br>两根支柱合一 | 五块单看都是清单，合起来才是"能被 AI 用的知识库" | · 《品牌知识库搭建方案》八大节（含认知缺口、结构框架图、事实库、能力清单、核验表、落地清单、维护机制）<br>· 落地清单每条落到责任角色与动作 ＋ 维护机制（谁更新、多久更新一次） |

> 口径说明：本专家团交付的是**结构、事实源与成品知识库**，不是内容生产与投放。把知识库改写成内容、铺到各渠道、做常态化维护，由客户团队或外部资源完成——这几项分别在能力边界里写明。

## 功能

- **认知缺口诊断**：基于公开信源扫描「AI 现在怎么说这个品牌」，分成说错的 / 说漏的 / 说偏的三类缺口
- **品牌基础信息库**：主体身份、业务范围、产品与服务、资质与认证、组织与团队、发展历程、客户与合作、对外口径共八模块，逐条带来源
- **差异化能力清单**：提炼「人无我有」的能力主张，指明差异坐标（跟谁比），并标出证据在哪
- **证据与口径核验**：逐条给出证据等级与对外权限，拦截无出处数字、绝对化表述、未授权客户名
- **成品终检**：原料合格不等于成品合格——成品产出后由事实核验官二次复核：禁用一个字不残留、待补证逐条标注、改写不引入新内容
- **引用适配产成**：成品按两大板块组织，按核验表筛选内容、按主理人裁决纪要统一口径，输出对外版与内部版两份成品
- **成品可直接使用**：复制就能贴官网、进内部文档，或直接投喂给 AI，不需要二次翻译

## 能力边界

### 能力上限（能做多深）

方案与成品知识库都可直接落地，但五件事不在自动范围内——**真实 AI 认知数据**（提及率、首推率、竞品占位只能基于公开样本观察）、**内部系统数据**（CRM、后台运营数据、内部知识库权限，拿不到）、**客户名与数字的授权**（未获书面授权只能脱敏或标注待授权）、**第三方法定佐证建设**（媒体送测、认证申领、独立来源铺设）、**持续维护与批量更新**（交付的是一次性成果；定期巡检、多市场多语言版本、跨部门常态化对齐不在自动范围内）。这五项需要真实数据、权限与人工介入，本团队只做边界说明，不做承接引导。

### 方法论适用性（什么条件下成立）

与能力上限是两件事——上限说的是"能做多深"，适用性说的是"这套方法在什么情况下有效"：

| 维度 | 适用 | 不适用 |
|------|------|--------|
| 品牌现状 | 业务已经跑起来，有可对外讲述的事实与业务，只是散、旧、不成体系 | 业务本身尚未定型，连内部口径都还在反复变 |
| 材料条件 | 能提供官网 / PPT / 资质文件 / 案例集 / 销售话术 / 白皮书等至少两类一手材料 | 完全拿不出一手材料，只能靠公开信息拼凑 |
| 口径授权 | 能指定对外口径的拍板人，客户名与经营数字能确认授权边界 | 无人拍板，对外口径多头且互相冲突 |
| 预期管理 | 以知识库完备度与口径一致率改善带动 AI 认知 | 期望短期内获得确定的提及率、引用率或排名承诺 |

命中「不适用」时不会拒绝开工，但会在方案开始前说明边界并给出收窄后的范围——例如无人拍板对外口径时，只做事实整理与缺口诊断，不产出对外版本。

## 使用示例

- AI 里问起我们公司，说出来的信息又旧又散，还把竞品和我们混在一起——帮我搭一份完整的品牌知识库
- 我们最拿手的那块能力 AI 从来没提过，销售嘴里那套也写不进官网——帮我把差异化能力梳成一份能对外说、有证据的清单
- 想让内部口径先统一，再喂给 AI 和客户——帮我把散在各部门的品牌资料整理成一份结构化的知识库，人和 AI 都能直接用

## 交付物

- **品牌知识库搭建方案**：单文件 HTML（零脚本、零外链、零外部资源），含一句话结论、认知缺口清单、知识库结构框架图、八模块事实库、六栏能力清单、事实核验表、落地清单、维护机制与口径说明；页脚为出品署名与使用边界两栏（含数据口径与官网），正文与页脚均不含联系方式、跳转链接或资料领取入口，可打印导出 PDF
- **成品知识库**：正文干净、结构完整，按两大板块组织（品牌基础信息库八模块 ＋ 差异化能力清单六栏），品牌实体段、标准问答对、可引用句库挂在各板块下；每条带证据等级，分对外版与内部版，末尾附可删除的「本知识库说明」

## 方法论来源

本专家团的两大支柱（品牌基础信息库八模块 / 差异化能力清单六栏）与四档证据分级，源自数珀AI 的 GEO 内容工程方法，与团体标准 **T/CGCC 119—2026《商贸流通业生成式引擎优化（GEO）智能营销技术服务规范》**（中国商业联合会发布，数珀AI 为起草单位之一）中关于品牌事实源与内容可信度的要求一脉相承。所有事实以可核验来源为准；**拿不到出处的一律标注「待确认」并写明还需要什么材料，禁止用推测值补齐**。涉及位置的概念一律使用提及率指标族，不含任何排名含义。
