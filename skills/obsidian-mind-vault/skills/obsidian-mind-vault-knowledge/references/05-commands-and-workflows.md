# 05 · 命令与工作流编排

## 1. 命令总览（20 条，统一 `om-` 前缀）

| 命令 | 一句话职责 | 输入 | 调用子代理 | 调用脚本 | 主要写入目标 |
|------|-----------|------|-----------|---------|-------------|
| 站会 | 会话开始简报：目标、活跃项目、开放任务、近期变更 | 无 | 否 | 否 | 不写盘（纯简报） |
| 收尾 | 核对改动质量与索引一致性、查孤儿、跑卫生清理、复盘工作方式 | 无 | 是 | 生成自动记忆索引 | 索引、记忆主题、战功、坑 |
| 倾倒 | 自由文本自动分类路由到正确笔记 | 自由文本 | 否 | 否 | 视分类而定 |
| 收件 | 处理会议导出，路由并询问删除 | 文件 / 粘贴 | 否 | 否 | 工作笔记、人物笔记、索引 |
| 1:1 捕获 | 把 1:1 转录转成结构化笔记并回写人物与索引 | 参与者 + 内容 | 否 | 否 | 1:1、人物、工作索引、记忆主题 |
| 事故捕获 | 事故全链路归档（时间线、根因、涉及人员、后评估） | 链接 / 描述 | **是**（考古 + 人物） | 否 | 事故、人物、战功、坑、记忆主题 |
| 消息考古 | 从聊天记录抓取证据（分页全量） | 频道 / 链接 | 否 | 否 | 评审证据 |
| 代码评审深扫 | 深扫代码评审记录并写证据文件 | 人 + 周期 | 否 | 否 | 评审证据 |
| 评审简报 | 聚合战功 + 决策 + 事故 + 能力证据 + 1:1 反馈，产出三档可见度简报 | 周期 + 受众 | **是**（评审准备） | 否 | 评审周期目录 |
| 自评 | 起草自评 | 周期 | 否 | 字数统计 | 草稿区 |
| 同事评审 | 起草同事评审 | 同事名 + 周期 | 否 | 字数统计 | 草稿区 |
| 会前准备 | 1:1 前简报（上次未闭环项、人物近况） | 参与者 | 否 | 否 | 不写盘 |
| 会议 | 会议议程与记录骨架 | 主题 | 否 | 否 | 不写盘（默认） |
| 更正 | 事实更正扫描：找出所有复述并三分类 | 更正后的事实 | **是**（更正扫描） | 否 | 多篇（分类后） |
| 整理 | 卫生执行：归档、聚类、拆分、补链、记忆提升 | 无 | 否 | 确定性修复 | 多篇 + 索引 |
| 库审计 | 结构审计：目录标签一致性、索引漏链、孤儿、断链、陈旧 | 无 | **是**（库管 + 交叉链接） | 否 | 只写报告 |
| 库升级 | 从旧模板迁移：检测 → 清点 → 计划 → 执行 → 验证 | 源库路径 | **是**（迁移） | 否 | 目标库（**源库只读**） |
| 归档 | 项目归档：状态改完结，整体搬进年度归档目录 | 项目名 | 否 | 否 | 归档目录 + 索引 |
| 周报 | 跨日综合与对齐检查 | 无 | **是** | 否 | 战功、目标文档 |
| 拟人化 | 文本去 AI 味（保信息、调节奏、删套话） | 文本 | 否 | 字数统计 | 返回文本 |

## 2. 场景聚类（7 类）

| 类别 | 命令 | 类别定义 |
|------|------|---------|
| 会话生命周期 | 站会、收尾、周报 | 会话的起、止与周期综合 |
| 捕获与路由 | 倾倒、收件、1:1 捕获 | 把外部材料变成库内结构化知识 |
| 会议准备 | 会议、会前准备 | 会前简报与会中骨架 |
| 复盘与绩效 | 代码评审深扫、评审简报、同事评审、自评 | 证据采集与评审材料生产 |
| 事件响应 | 事故捕获、消息考古 | 事故归档与聊天记录取证 |
| 库治理 | 更正、整理、库审计、库升级、归档 | 结构、事实与版本的维护 |
| 写作质量 | 拟人化 | 文本质量 |

## 3. 子代理（10 个）

| 子代理 | 角色 | 权限档 | 被谁调用 |
|--------|------|--------|---------|
| 战功发现 | 从近期会话里找未被记录的战功 | **只读** | 收尾 |
| 上下文加载 | 按需装配上下文 | **只读** | 直接调用 |
| 更正扫描 | 找所有复述并三分类，**只找不改** | **只读** | 更正 |
| 交叉链接 | 找缺失链接、孤儿、坏反链，**不自动修** | 只写草稿区报告 | 库审计、整理 |
| 人物画像 | 为事故/会议涉及的新人建档案 | 写库 | 事故捕获、收件 |
| 评审事实核查 | 逐条核验评审草稿的事实声明 | **只读** | 评审相关命令 |
| 评审准备 | 聚合多源证据产出简报骨架 | 只写草稿区报告 | 评审简报 |
| 消息考古 | 分页读频道 / 私信 / 线程并重建时间线 | 只写草稿区报告 | 事故捕获、消息考古 |
| 库管 | 孤儿、断链、元数据、陈旧笔记巡检，**不自动修** | 只写草稿区报告 | 库审计、整理 |
| 迁移 | 旧库迁移（分类模式 + 执行模式） | 写目标库 | 库升级 |

**写权限三档**（硬约束，不得随意提升）：
- **纯只读** 4 个：战功发现、上下文加载、更正扫描、评审事实核查
- **只写草稿区报告** 3 个：交叉链接、评审准备、消息考古（库管同档）
- **直接写库** 3 个：人物画像、迁移（+ 事故捕获链路）

## 4. 调用矩阵要点

- **7 个命令显式编排子代理**：更正、事故捕获、评审简报、库审计、库升级、周报、收尾
- **5 个命令直接调脚本**：字数统计（拟人化 / 同事评审 / 自评）、确定性修复（整理）、生成自动记忆索引（收尾）
- **默认不写盘的命令 5 个**：会议、会前准备、站会、周报（默认）、收尾（以修小问题为主）

## 5. 硬护栏分布

| 命令 | 护栏 |
|------|------|
| 更正 | **永不删除、永不提交、历史记录不改** |
| 整理 | **永不删除、永不提交、判断类只列不做** |
| 收件 | **删文件前必须确认** |
| 归档 | **只用版本控制感知的移动方式** |
| 库升级 | **源库只读、计划先行、支持试运行** |
| 库审计 | 只写报告，就地修复限于零判断项 |
| 确定性修复 | **只处理零判断的两类**，其余拒绝并指向人工命令 |

## 6. 命名约定（有功能含义）

| 场景 | 约定 | 原因 |
|------|------|------|
| 活体笔记 | **裸标题，不加日期前缀** | 日期前缀会**倒置新鲜度信号** |
| 点时刻记录（1:1） | **日期后缀** | 事件已发生，日期是身份的一部分 |
| 会议收件箱 | **日期前缀** | 它是待处理队列，按时间排序才合理 |
| 临时报告 | `thinking/YYYY-MM-DD-<name>.md` | 明确它是草稿，会被删 |
| 归档笔记 | 名称含 `Archive` | 触发体积豁免 |

## 7. 交接与链式引用

| 链 | 说明 |
|----|------|
| 会前准备 → 1:1 捕获 | 会前简报准备的问题，会后由捕获命令落地 |
| 会议 → 倾倒 | 会议骨架与记录走倾倒命令分类 |
| 代码评审深扫 → 评审简报 | 评审缺证据时先跑深扫 |
| 周报 / 收尾 → 整理 | 漂移发现交给治理命令执行 |
| 更正扫描 → 更正命令 | 代理只找，命令施加 |

## 8. 命令文档的维护规则

- 命令的权威目录（面向**没有技能注入的宿主**）必须手工保持最新
- 操作手册**刻意不维护命令表**——因为它会腐烂，而宿主注入的命令列表不会
- 指令文件里**不写计数**（「N 个命令」会静默过时）
- 有测试断言子代理定义与文档同步（这类同步由测试兜底）
