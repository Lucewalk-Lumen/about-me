# 质检清单 — 知识库智能整理大师

> 用途：交付前最后一道关，逐条打勾；命中"一票否决"即返工，不得带缺陷交付。
> 适用对象：一次"整理知识库"任务的完整交付（含方案、执行清单、整理后结构）。

---

## 一、交付前必查（逐条打勾）

- [ ] **分类前已出完整方案并等用户确认**：方案含文件夹清单 + 收纳范围 + 判定规则 + 预计条数；未获确认不建夹、不移动。用户明确说"直接做"时，方案仍须落地为文字记录。
- [ ] **已留存整理前根目录快照**：记录整理前散件数、文件夹数、media_type 分布，作为对照表基准；快照取自 `get_knowledge_list`，非目测。
- [ ] **移动前已记录每条资源的原路径**：执行清单中每条含 media_id + 原所在位置（根目录或旧文件夹）。无原路径记录不得发起移动。
- [ ] **全程只做"创建文件夹 + 移动"两类写操作**：未执行删除、覆盖、重命名同名夹等动作（本技能调用的 API 不提供删除能力，出现任何删除类动作即为越界）。
- [ ] **临时件与敏感件已单独处置**：标题含"（1）""-副本""_copy""未命名""新建文档"的临时件，以及身份证扫描件、银行账号、农民工工资表、合同签章页等敏感件，已逐条问过用户，未擅自归入通用文件夹。
- [ ] **大库已分批处理**：散件 > 500 条时按主题分批，先处理主题最清晰的类别；每批完成后复扫一次，确认未出现整批丢失。
- [ ] **每批移动条数 ≤ 10**：按目标文件夹分组提交；同夹跨批次的批次号连续可追。
- [ ] **未分类条目已逐条列出并请用户指定**：未分类数超过 5 条时不直接收口进"其他"。
- [ ] **失败项已全部记录**：`ret_code≠0` 的条目均有 media_id、err_msg 原文、处置结果，并写入交付报告的异常节。
- [ ] **整理后已复扫根目录**：确认仅剩文件夹（散件数为 0），并据此填写整理前后对照表。
- [ ] **资源总数整理前后一致**：变化列为 0；对不上时已重新全量扫描核对，未用"大致一致"交付。
- [ ] **文件夹数量在 8-12 个区间**：超过 15 个已回退合并或改为两级结构。

---

## 二、一票否决（FAIL 即返工）

- **未获用户确认就批量移动**：知识库是用户的资产，移动造成的位置变化用户无法自行批量还原；分类口径一旦不合用户查找习惯，等于把库改乱。改法：退回方案确认门，输出分类方案表（模板 1）等用户选一个方案再动手。
- **整理前后资源总数不一致**：说明有资源未纳入清单或漏扫（可能遗留在根目录未被识别为散件、或与文件夹条目混淆）。改法：重新全量分页扫描（翻页上限 10 次），逐类核对到数字一致再交付；未一致的必须显式写清差额与原因。
- **出现删除 / 覆盖 / 清空动作**：包括"删除重复文件""覆盖同名文件夹""清空根目录"等。本技能边界内只有创建与移动，此类动作不可逆且超出授权。改法：重复文件只列清单（含 media_id）交用户手工处理。
- **无原路径记录即执行移动**：失败项将无法定位、无法还原，也无法证明资源去哪了。改法：先落执行清单（模板 2）再发移动请求。
- **跨知识库移动**：`move_knowledge` 的 `src_knowledge_base_id` 与 `dst_knowledge_base_id` 必须为同一知识库 ID；跨库调用会失败或产生异常归属。改法：逐库串行处理，跨库合并交用户自行操作。

---

## 三、常见错误

1. **按媒体类型分类**（PDF 一个夹、公众号一个夹、网页一个夹）→ 得到几个无检索价值的杂物堆，用户仍要靠搜索 → 改用"用途/主题"作主维度，媒体类型只写在方案说明里当参考。
2. **文件夹数量超过 15 个** → 用户在选择夹子时反复犹豫，整理效果反而低于不整理 → 合并同级到 8-12 个；确需细分时用"主夹-子夹"两级。
3. **整理模式下重建文件夹** → 打断用户已有的检索习惯，历史分享链接与记忆路径失效 → 整理模式只把散件归位到已有文件夹，不新建、不改名。
4. **关键词规则硬编码 SKILL.md 中的示例词**（教学/备课/教案）→ 与实际库内容不符，大批条目落入兜底 → 按目标文件夹名动态生成关键词表，专有名词优先。
5. **单批移动超过 10 条** → 接口报错或部分成功，失败项混杂难追溯 → 每批 ≤10 条，按目标文件夹分批提交并逐批校验 ret_code。
6. **未分类条目超过 5 条仍用"其他"收口** → "其他"变成第二个散件堆，用户下次还得再整理一遍 → 逐条询问用户指定归属，或按主题拆分文件夹后重跑匹配。

---

## 四、交付物核对（缺一即未完工）

- [ ] 分类方案表（完整模式）或整理模式说明（含从已有夹名反推的规则）
- [ ] 归类执行清单（建夹回执 + 批次移动记录 + 失败项 + 未分类待定）
- [ ] 整理前后对照表（含最终结构树与异常节）
