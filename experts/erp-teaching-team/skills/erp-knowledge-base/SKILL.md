# ERP 专业知识库

> **十五篇正文，覆盖 ERP 落地的完整链条 + 教学全套工具。** 全部为本团自建，事实依据来自公开行业数据、政策文件与一线调研。

## 使用时机

- 需要**具体教材内容**时（概念怎么讲、某域流程怎么走、TCO 怎么算、题库出题、红线题判分）
- 需要核实某条内容是否属时效性内容（转`14-时效内容实时核验.md`）
- 学生问「详见哪一篇」时，按下方导航表定位

**加载本技能后**必须按导航表打开对应篇目正文——**只读本文件等于没加载**（本文件是导航，不是教材）。

## 为什么是这个结构

ERP 落地有一条不可跳跃的链条：

```
全景（现在该做什么）→ 诊断（哪里不对）→ 选型（买什么）→ 论证（值不值）
→ 业务域（懂业务）→ 集成（怎么接）→ 落地（人用不用）
```

**跳过一环，代价在后面。** 不诊断就选型 = 没量体温就开药；不论证就买 = 五年后才发现贵了；不落地就集成 = 系统上线但没人用。

## 两个机制的关系

**14 与 15 是本库的"活"机制**，其余 13 篇（01-13）是"静态"内容：

```
14 实时核验  ──→  保证内容不过时（对上：内容正确性）
15 学习沉淀  ──→  保证知识变成本能（对学生：能力转化）
```

**缺 14**，知识库会在几个月内失效。**缺 15**，学生读完就忘。

## 教学设计建议

**本库的独特价值是"立场教育"**，不只是知识传递。

| 教学点 | 说明 |
|---|---|
| **身份决定判断** | 甲方顾问敢说"别买"才可信。**没有立场的顾问没有价值** |
| **折扣的诚实** | 省下的时间不是钱。敢打折的测算才可信 |
| **数据祛魅** | 55% 折戟不是技术问题，是人和责任问题（[!] 教学用参考值，未标源） |
| **先让使用者受益** | 颠覆"要求员工改变"的直觉 |
| **自己发现的问题不算问题** | 红蓝对抗的核心 |

**三个必做教学环节**：
1. **角色扮演**（04 的必问五问）—— 学生扮厂商，练追问
2. **实操检验**（02 的诊断输出）—— 找一家真实企业做完整诊断
3. **红蓝对抗**（13）—— 学员互挑，比老师挑有效

## 数据时效声明

**本库不写死任何标准条款、税率数值、政策指标、产品版本号。**

**这不是缺内容，是设计**：写死的内容必然过时。核验路径见 `14-时效内容实时核验.md`。

引用以下内容时**必须实时检索**并标注检索日期：
- 会计准则条文 | 税收政策（税率/优惠/申报口径）| 监管要求（内控/等保）
- 信创目录与自主可控等级 | 厂商产品能力与版本 | 行业数据与使用率

**官方源清单已在 `14` 篇中核实**（财政部、国家税务总局、工信部、国标平台等）。

**方法论、流程框架、概念定义不受时效影响** —— 这部分内容是稳定的，可直接引用。

## 内容边界

**本库不提供**：

- 税务申报计算与税务结论（需 `erp-report` 等专用工具）
- 会计处理判断（合并抵消、科目映射须专业会计人员）
- 劳动法结论
- 法律意见
- 真实系统操作（需 `kingdee-mcp-suite` 等连接器）
- 跨境多地区合规（需 `erp-digital-ai-expert-intl`）

**遇到上述需求，转对应能力包处理。**
