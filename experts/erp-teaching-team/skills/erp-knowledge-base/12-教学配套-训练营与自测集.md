## 训练营设计说明

### 为什么这样排

| 顺序 | 理由 |
|---|---|
| 诊断在最前 | **不会诊断，后面全是空谈** |
| 立场在选型前 | 先有立场，才知道该问什么 |
| TCO 在 ROI 前 | 先懂成本结构，才算得清回报 |
| 业务域在集成前 | 懂业务才知道哪些能自动化 |
| 落地在最后 | 但**不是最重要**，是收尾 |

### 每个练习的目的

- Day 2、3、5：**诊断是核心能力，反复练**
- Day 8、9：**立场教育，最容易错**
- Day 11、12：**最容易算错的地方**
- Day 21：**落地意识收尾**

### 常见教学问题

| 问题 | 处理 |
|---|---|
| 学生觉得概念太多记不住 | 强调"五级成熟度""六维评分""必问五问"这几个就够用 |
| 学生算不清 TCO | 强调"打折"和"别漏内部投入"，这两点决定可信度 |
| 学生不认同"甲方立场" | 用"没有立场的顾问没有价值"引导 |

## 第二部分：高频问答自测集（40 题）

**用法**：先答，再对照要点。**答案要点须自己复述，不能只看。**

## 第一组：诊断（Q1-8）

**Q1. 员工还在用 Excel，是"不配合"还是"真痛"？怎么判断？**
- 要点：看是否有绕路方案并抱怨 → 真痛；没抱怨只是别扭 → 不习惯
- 追问：他们绕路多久了？为什么不换回系统？

**Q2. 两个系统库存对不上，先查什么？**
- 要点：先查**字段定义是否一致**，不是先查数据
- 口径不同的话，清洗是徒劳的

**Q3. 什么是"短板约束"？**
- 要点：关键维（流程/数据/集成）任一 < 2 时，以最低维定级，**防平均掩盖短板**

**Q4. 物料一物多码有什么危害？**
- 要点：库存分散、报表不准、**MRP 失效**、关联单据全错
- 这是所有库存问题的头号根源

**Q5. "公司要上集团级 ERP"这个需求合理吗？**
- 要点：先看规模与成熟度。手工记账企业上平台 = 灾难
- **该劝退时劝退是职责**

**Q6. 五个失败模式有哪些？**
- 要点：表格补丁化、录入惩罚、老员工断层、执行层缺位、需求错位
- 说出每个的**根因**才算过关

**Q7. 什么是"录入惩罚"？为什么最致命？**
- 要点：要求一线多录字段却不减负
- 必然失败，且会持续损失采纳率

**Q8. "全都在用系统了"就等于落地成功吗？**
- 要点：不等于。**看是否还在用 Excel 绕路**
- 用了但被绕过 = 假落地

## 第二组：选型与论证（Q9-18）

**Q9. 必问五问是哪五问？**
- 要点：标准覆盖率、开放 API、数据可导出、五年 TCO、换供应商成本
- **开放 API 最容易漏却最重要**

**Q10. 为什么"没有 API 的系统三年后是死路"？**
- 要点：AI 集成需要接口，没 API 就接不上
- 即使当下不做 AI，三年后想接也接不上

**Q11. "低报价"的陷阱是什么？**
- 要点：低报价配高实施、高二开
- **必须算五年 TCO，不看报价**

**Q12. TCO 有哪几类？最容易漏什么？**
- 要点：许可、实施、运维、基础设施、二开、培训、内部投入
- **内部投入最常被完全忽略**（常占 20-30%，教学经验区间）

**Q13. 为什么效率收益要打折？**
- 要点：省下的时间不等于省下的钱
- 折算系数通常 0.3-0.5

**Q14. 三情景是哪三个？只报一个行不行？**
- 要点：基准/预期/悲观
- **不行，悲观必须报**。老板会问"万一不成呢"

**Q15. 悲观情景为负说明什么？**
- 要点：最坏情况可能永不回本
- 应明确提示"建议延后或轻量方案"

**Q16. 什么是"甲方立场"？**
- 要点：不替厂商说话，也不被话术带走
- **中立来自"不替任何一家说话"，不是"推荐几家"**

**Q17. 什么是 Fit-to-Standard？为什么要克制二开？**
- 要点：优先用标准功能解决
- **二开率高 = 升级噩梦**

**Q18. 自主可控分几级？**
- 要点：完全自主 / 部分自主 / 依赖第三方
- 应要求供应商提供**书面可核验**的说明

## 第三组：业务域（Q19-26）

**Q19. 什么是三单匹配？**
- 要点：PO + GR + Invoice 三单一致才付款
- **把"人盯发票"变成"系统卡发票"**

**Q20. 什么是 ATP？**
- 要点：Available to Promise，可承诺量
- 公式：可用库存 + 在途 + 可用产能 − 已承诺

**Q21. S&OP 解决什么问题？**
- 要点：销售想要的与生产能做的对不上
- **本质是让多部门坐在一张桌上，不是算法**

**Q22. MRP 和 S&OP 的方向有什么不同？**
- 要点：MRP 向下展开（推物料需求），S&OP 向上汇总（定销量）

**Q23. ABC 分类和 XYZ 分类分别按什么分？**
- 要点：ABC 按价值，XYZ 按波动性
- **组合起来才是实用矩阵**

**Q24. 安全库存是什么？**
- 要点：用钱买保险，应对不可预测波动
- 可预测波动用计划消化，不该都堆进安全库存

**Q25. 什么是业财一体？**
- 要点：业务单据自动生成凭证，不用事后补录
- 核心资产是**科目映射表**

**Q26. 集团合并为什么要抵消？**
- 要点：内部交易不是集团的收入/债权
- 三类抵消：内部交易、内部往来、投资与权益

## 第四组：AI 与落地（Q27-35）

**Q27. 为什么"AI 层不碰数据库事务"是红线？**
- 要点：事务逻辑必须统一收敛至业务层
- 否则 AI 的不确定性会污染账务真实性

**Q28. 什么是 Clean Core？**
- 要点：核心记录系统（SoR）保持稳定，AI 作为可插拔能力（SoE）
- **AI 改核心表结构 = 升级噩梦**

**Q29. Agentic ERP 的五大核心能力是什么？**
- 要点：感知、推理、记忆、工具调用、自主执行
- **多数产品只能部分满足**

**Q30. 怎么判断一个产品是否真 Agentic？**
- 要点：问三个问题——记得上次对话吗？能直接调工具改数据吗？出错知道自己知道吗？

**Q31. RAG 分片为什么不能硬切？**
- 要点：机械按字符数切会**切断语义完整性**
- 应按文档结构分片，300-500 字

**Q32. 为什么 RAG 必须写元数据？**
- 要点：召回后无法溯源，用户不信任
- 至少写：文档ID/名称/分类/上传时间/分片序号

**Q33. 什么是"先让使用者受益"？**
- 要点：变革前先给一线减负，让他们感到"系统比我快"
- **反模式**：要求多录字段却不减负

**Q34. 关键用户制为什么有效？**
- 要点：一线先找身边人而非发工单
- 抱怨消化在部门内部

**Q35. 四个核心验收指标是什么？哪个最重要？**
- 要点：订单到出库时长、库存准确率、跨部门交接等待、**一线操作耗时**
- 第四个最重要——**它直接证明一线受益了**

## 第五组：红线（Q36-40）

**Q36. AI 可以自动做凭证决策吗？**
- 要点：**不可以**。须人确认

**Q37. AI 可以决定税务处理吗？**
- 要点：**禁止**。须专业税务人员，有法律责任

**Q38. AI 可以参与招聘决策吗？**
- 要点：**不可以**。涉及人的判断，有法律风险

**Q39. 什么是账务真实性一票否决？**
- 要点：任何"为报表好看调数""绕过审批过账"一律否决
- **ERP 的账是给审计看的**

**Q40. 什么是本团的第一铁律？**
- 要点：**站在甲方，不替厂商说话**
