# 时效内容实时核验机制

> **本篇为自建内容。** 本篇不写具体标准号细节、税率数值、政策条款 —— **只教怎么实时获取**。这不是偷懒，是设计：写死的内容必然过时。

## 为什么不能写死

**一个会过时的知识库比没有知识库更危险。**

| 错误做法 | 后果 |
|---|---|
| 知识库里写"增值税税率 13%" | 政策变了，学生按错的算 |
| 写"某标准 GB/T XXXXX" | 标准被废止，学生引用失效条款 |
| 写"信创目录包含 XX 产品" | 目录调整，结论反了 |
| 写"某软件版本支持 XX 功能" | 版本升级，功能变了 |
| 写"某厂商市场占有率 X%" | 数字过期，误导判断 |

**共同点：都是"当时正确，后来错误"。** 而 ERP 项目动辄跨越数年，用过期数据做决策的代价是真金白银。

**正确做法**：**知识库存方法与路径，事实靠实时获取。**

## 铁律

| # | 铁律 |
|---|---|
| 1 | **凡时效性内容，一律先检索后引用** |
| 2 | **引用必须带检索日期** |
| 3 | **不确定就标"待核验"，不编造** |
| 4 | **检索失败要明说失败，不能用旧数据蒙混** |
| 5 | **知识库不存具体数值，只存获取路径** |

## 核验流程

**五步，缺一不可：**

```
1. 判断时效性 —— 这条信息会变吗？
        ↓
2. 选源 —— 找对应领域的官方入口（见上表）
        ↓
3. 检索 —— 用具体编号/关键词查最新版本
        ↓
4. 核验 —— 确认是否为现行有效，是否有废止/替代
        ↓
5. 记录 —— 标注标准号+版本+条款+检索日
```

### 第 1 步：什么算"时效性内容"

| 类别 | 是否时效 | 举例 |
|---|---|---|
| 会计准则条文 | 是 | 收入确认、资产减值 |
| 税率与优惠 | 是 | 增值税、企业所得税优惠 |
| 监管要求 | 是 | 内控规范、等保、信创目录 |
| 厂商产品能力 | 是 | 功能、版本、停服日 |
| 行业数据 | 是 | 市场规模、渗透率、使用率 |
| 政策目标 | 是 | 各类专项行动的时间表与指标 |
| **管理方法论** | 否（不需核验） | 成熟度模型、TCO 七类、SoD 原则 |
| **流程框架** | 否（不需核验） | P2P 七步、O2C 八步 |
| **概念定义** | 否（不需核验） | MRP 是什么、ATP 是什么 |

**判断口诀**：**会写进红头文件的、会发公告的、会改版本的 → 时效。会写进教科书的 → 不时效。**

### 第 4 步：核验的关键动作

**不要只查到"有这份文件"就完了**，还要确认：

| 检查 | 为什么 |
|---|---|
| 是否**现行有效** | 标准会被废止 |
| 是否有**替代版本** | 换了编号但内容变 |
| **发布日期** | 判断新旧 |
| 适用范围是否覆盖你的场景 | 有些标准只适用特定行业 |
| 是否有**实施细则** | 部委可能有补充通知 |

**最常见的错误**：引用了已废止的标准。这个在合规审查里是硬伤。

### 第 5 步：记录格式

**引用格式（强制）**：

```
【标准/政策名称】（标准号或文号，版本）
  出处：归口部门
  检索日期：YYYY-MM-DD
  状态：现行有效 / 建议复核
  关键条款：<只引与本问题相关的部分>
```

**示例**：

```
【企业会计准则——收入】（财会〔2017〕22 号，2017 年修订）
  出处：财政部
  检索日期：2026-07-24（示例日期，请替换为实际检索日）
  状态：现行有效
  关键条款：履约义务的识别与确认时点
```

> **示例日期为什么写死**：本包知识库基准日为 **2026-07-24**，示例若用"今天"会更晚于基准日，造成"基线之后才有"的错觉。**教学时请统一替换为学生实际检索日。**

## 失效降级策略

**检索失败时怎么办？** 这是必须预设的，不能临场慌。

| 失败情形 | 处理 |
|---|---|
| 未找到官方源 | **明确说"未找到官方来源，无法核实"**，不给结论 |
| 官方源无法访问 | 说明失败，标"待核验"，**不给猜测值** |
| 找到但版本不确定 | 列出可能的版本，让用户确认 |
| 信息冲突 | 列出冲突点，**以更高层级官方源为准**，并说明 |
| 已过时的缓存数据 | **作废，重新检索** |

**最重要的一条**：**宁可说"我不知道"，也不给一个看似合理但可能错误的数字。**

## 课堂实践设计

**这是本篇最实用的部分** —— 让学生自己跑一遍。

### 练习一：查现行有效的税率

**任务**：查询制造业增值税适用税率，标注依据与检索日期。

**步骤**：
1. 判断时效性 → 税率是时效内容
2. 选源 → 国家税务总局
3. 检索 → 找现行有效的增值税规定
4. 核验 → 确认是否现行、有无最新调整
5. 记录 → 按格式写下来

**评分点**：检索日期、官方来源、现行有效性确认。

### 练习二：查一项国家标准的现状

**任务**：任选一项你专业相关的国标（如信息安全类），查其当前状态。

**可能发现**：该标准已被替代或废止。**这个发现本身就是最好的教学** —— 让学生理解"引用失效标准"的真实后果。

### 练习三：查厂商产品能力

**任务**：查某个 ERP 产品的某项能力当前是否支持。

**关键教学点**：**必须查官方文档，不能用搜索引擎摘要或培训材料。** 让学生对比两者差异。

## 自查清单

每次引用时效性内容前过一遍：

- [ ] 这条信息会变吗？
- [ ] 我查的是**官方源**吗？
- [ ] 是**现行有效**的吗？有无废止或替代？
- [ ] 标了**检索日期**吗？
- [ ] 检索失败时我**明说了**，而不是编一个？
- [ ] 知识库里**没有写死数值**？

## 给教师的话

**本篇的教学价值极高，建议安排 2 课时实操。**

- **最有效的教学时刻**：让学生查到一个**已废止的标准**。那一刻他们才真懂什么叫"引用失效标准的代价"
- **不要只讲流程**，一定要**让他们自己查一遍**。查过的人才记得住
- **强调判断时效性的能力** —— 这是可迁移的。任何行业都需要
- **失败降级策略要重点讲** —— 敢于说"我不知道"是专业素养，不是丢脸

**常见学生误区**：
- 用搜索引擎摘要当依据 —— **摘要可能来自过时的培训材料**
- 只查到"有这个文件"就引用 —— **不查是否现行有效**
- 检索失败就凭印象填 —— **这是最危险的**

**课堂设计建议**：分组各查一个不同的标准/政策，然后互相检查。**发现别人的错误，比自己犯错学得快。**
