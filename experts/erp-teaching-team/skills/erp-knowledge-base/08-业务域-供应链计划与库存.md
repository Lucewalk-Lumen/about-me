# 业务域深度（二）：供应链计划与库存优化

> **本篇为自建内容。** 计划与库存是企业最大的隐性成本黑洞，也是 AI 最有价值的用武之地。

## 一、供应链计划体系（S&OP / DP / MPS / MRP / DRP）

### 五层计划的分工

| 层级 | 全称 | 回答什么问题 | 周期 | 决策者 |
|---|---|---|---|---|
| **S&OP** | 销售与运营计划 | 收入与产能怎么配？ | 月/季 | 高管层 |
| **DP** | 需求计划 | 市场要多少？ | 周/月 | 销售+计划 |
| **MPS** | 主生产计划 | 具体产什么、产多少？ | 日/周 | 生产 |
| **MRP** | 物料需求计划 | 买什么料、做哪个部件？ | 日 | 计划 |
| **DRP** | 分销需求计划 | 各个仓该分多少？ | 周 | 供应链 |

**关键理解**：
- **MRP 向下展开（What-if 推演）**：给销量，**算**物料需求
- **S&OP 向上汇总（What do we have）**：给产能，定销量
- 两者的差额，就是**要外购、要加班、要减产**的部分

### S&OP 产销协同

**S&OP 解决的是"销售想要的和生产能做的对不上"。**

**典型场景**：销售说下季度要卖 100 万件，生产算下来产能只够 80 万。怎么办？

| 选择 | 代价 |
|---|---|
| 外协生产 | 成本上升、质量风险 |
| 加班增产 | 边际成本上升、质量可能下降 |
| 提前备货 | 库存积压、资金占用 |
| 调整交期 | 客户体验受损 |
| **协商数量** | **最优解，但需要跨部门共识** |

**S&OP 的真正价值不是算法，是让销售、供应链、生产、财务坐在一张桌子上。**

**常见断点**：
- 销售承诺给客户的量，生产根本不知道 → 交期承诺无依据
- 生产按最乐观预测排产 → 库存爆掉
- 财务不做产能成本参与 → 不知道加班的真实代价
- **S&OP 变成填表会，不做决策**

### MRP 的核心逻辑

```
MRP = f(主生产计划 MPS, 物料清单 BOM, 现有库存, 在途量, 提前期)
```

**MRP 的输出不是采购建议，是"什么时候需要什么、缺多少、什么时候必须下单"**。

| 概念 | 含义 | 为什么重要 |
|---|---|---|
| **净需求** | 毛需求 − 现有库存 − 在途 | 避免重复采购 |
| **毛需求** | MPS 展开 BOM 后的总需求 | 基础 |
| **提前期** | 从下单到入库的时间 | 决定何时下单 |
| **安全库存** | 应对波动的缓冲 | 决定补货点 |
| **再订货点 ROP** | 库存降到多少就补货 | = 平均消耗 × 提前期 + 安全库存 |
| **批量政策** | 一次订多少（EOQ/批量） | 平衡订货与存储成本 |

**常见断点**：
- BOM 版本混乱 → MRP 算出来的需求是错的
- 提前期数据不准（供应商口头报的） → 下单太晚
- 安全库存拍脑袋设 → 要么积压要么断货
- **MRP 只算物料不排产能** → 计划不可执行

### DRP 分销需求计划

**多仓场景的补货逻辑。**

```
各仓需求预测 → 库存分布检查 → 调拨 vs 补货决策 → 订单
```

**DRP 的关键决策**：同样的缺口，**调拨比补货更快更便宜**，但调拨受运输成本约束。

**常见断点**：
- 总部看不到各仓真实库存 → 重复备货
- 调拨审批慢 → 该调的不调，从外部高价急采
- **库存数据不准，调拨决策基于错误数据**

## 二、库存优化

### 库存是钱

**核心认知**：库存不只是货，是**占用的现金 + 仓储成本 + 减值风险**。

**持有成本**（一年）：
- 资金成本（库存金额 × 贷款利率）
- 仓储成本（面积 + 人力）
- 保险与损耗
- 跌价减值准备

**不只是成本，还有风险**：断货损失客户、积压损失现金。

### 三个经典模型

| 模型 | 用于 | 核心逻辑 |
|---|---|---|
| **EOQ**（经济订货批量） | 需求稳定、补货点明确的物料 | 订货批次 = √(2 × 年需求 × 单次订货成本 ÷ 单位年存储成本) |
| **ABC 分类** | 按价值分级管理 | A 类（高价值少数）严管，C 类（低价值多数）放宽 |
| **XYZ 分类** | 按波动性分级 | X 类（稳定）安全库存低，Z 类（波动）安全库存高 |

**ABC × XYZ 组合矩阵**（这才是实用的）：

| | X（需求稳定） | Y（波动中等） | Z（波动大） |
|---|---|---|---|
| **A（高价值）** | 严管，JIT，密切监控 | 严管，滚动预测 | 重点管理，备货策略调整 |
| **B（中价值）** | 常规管理 | 常规管理 | 关注 |
| **C（低价值）** | 简化管理，放宽 | 简化管理 | **简化，批量采购** |

**为什么要有这个矩阵**：A 类物料通常只占 20% 的品种却占 80% 的金额，**管住 A 类就管住了库存**；C 类占多数但金额小，**不值得精细管理**。

### 安全库存

**安全库存是"用钱买保险"**。

```
安全库存 = 该期间需求波动的标准差 × 需求提前期
```

**权衡**：
- 安全库存高 → 服务水平高、不断货，但资金占用高
- 安全库存低 → 资金效率高，但断货风险高

**最贵的错误**：把安全库存当成"应对所有波动"。**应区分两类：**
- **可预测波动**（已知促销、季节）→ 用计划消化
- **不可预测波动**（供应商延迟、需求突变）→ 用安全库存消化

### 库存的 AI 机会

| 场景 | 可行性 | 说明 |
|---|---|---|
| 需求预测 | | 有历史数据时效果好 |
| 安全库存动态调优 | | 需服务水平目标数据 |
| 呆滞料识别 | | 规则明确 + AI 辅助 |
| 补货建议 | | 依赖 MPS 与库存数据准确 |
| 库存周转改善 | | 需跨部门协同，非纯技术 |

**前提**：**AI 预测的前提是数据干净。** 一物多码的历史数据喂给模型，只会得到错误的预测。

## 三、计划与库存的四个断点（诊断重点）

| 断点 | 表现 | 根因 | 对策 |
|---|---|---|---|
| **数据不准** | 库存账实不符，MRP 算错 | 一物多码、收发未及时记账 | **先治理主数据** |
| **口径不一** | 销售一个可用量，仓库另一个 | ATP 口径未统一 | 明确唯一口径 |
| **计划不闭环** | 计划做完不进系统，靠 Excel 推 | 计划与执行脱节 | 计划进系统 |
| **协同缺失** | 销售、生产各做各的 | 无 S&OP 机制 | 建立产销协同会 |

**特别提醒：库存不准的根因通常不在库存模块，而在收发存没及时记账。** 查账务流程比查库存功能更有价值。

## 四、给教师的话

**本篇的教学挑战是概念密集，建议抓三个抓手：**

1. **S&OP 的本质是"让人坐到一起"**，不是算法 —— 讲清了这一点，学生就懂了为什么"开个会"比"上个系统"更难
2. **ABC×XYZ 矩阵是最好用的工具** —— 让学生给自己公司的物料套一遍，立刻理解"为什么不是所有物料都要精管"
3. **安全库存是"用钱买保险"** —— 用这个比喻讲清权衡，比讲公式有效

**常见学生误区**：
- 以为上了 MRP 就有了计划能力 —— **MRP 只是计算器，它依赖准确的主数据与 BOM**
- 追求"零库存" —— **库存是服务水平的成本，不是要消灭的对象**

**动手建议**：让学生找一类物料，手算 EOQ 和 ROP，与系统结果对比。差得多就说明数据有问题。
