# 红蓝对抗演练：蓝军四维挑刺

> **本篇为自建内容。** 用于在交付前发现自己的硬伤。**自己发现的问题，不算问题；被别人挑出来的，才是真问题。**

## 核心思想

**写方案的人看不清自己的盲区。** 蓝军（对抗方，Red Team 视角）的职责是专门挑刺 —— 站在对立面找漏洞。

**这不是找茬，是质量保障。** 一个方案被挑出三个致命问题后还能站住，才算真的扎实。

## 四维挑刺

### 维度一：数据真实性

**蓝军问什么**：
- 这个数字从哪来？是估的还是实的？
- 报表和实际情况对得上吗？对不上差多少？
- 库存账实一致吗？谁盘的、什么时候盘的？
- 这个"提升 30%"怎么算出来的？分母是什么？

**常见硬伤**：
| 硬伤 | 表现 | 级别 |
|---|---|---|
| 数据无来源 | 引用一个数字但说不出出处 | [致命] 致命 |
| 账实不符 | 系统显示的库存和现场不一致 | [致命] 致命 |
| 幸存者偏差 | 只看成功项目，忽略失败样本 | [严重] 严重 |
| 口径不一 | 各部门数据打架 | [严重] 严重 |

### 维度二：合规与内控

**蓝军问什么**：
- 这个方案绕过审批了吗？
- 内控矩阵支持这个流程吗？
- 谁有权做这个操作？两个人能一起做吗？
- 涉及个人信息的，处理合法吗？
- 税务处理谁负责？有专业依据吗？

**常见硬伤**：
| 硬伤 | 表现 | 级别 |
|---|---|---|
| 绕过内控 | "先过账后补审批" | [致命] 致命 |
| SoD 缺失 | 同一人采购又付款 | [致命] 致命 |
| 权限过大 | 给了管理员全权限 | [严重] 严重 |
| 税务越界 | AI 或非专业判断税务处理 | [致命] 致命 |

### 维度三：TCO 与 ROI

**蓝军问什么**：
- 五年总成本算全了吗？内部投入算了吗？
- 二开和升级重做成本算了吗？
- 悲观情景是多少？为什么不敢报？
- 效益打折了吗？折算系数多少？
- 如果效益只达成 60%，还划算吗？

**常见硬伤**：
| 硬伤 | 表现 | 级别 |
|---|---|---|
| 只算首年 | 拿首年报价算 ROI | [致命] 致命 |
| 漏内部投入 | 没算自己人的工时 | [严重] 严重 |
| 不打折 | 效益虚高 2-3 倍 | [严重] 严重 |
| 无悲观 | 只报乐观 | [严重] 严重 |

### 维度四：可执行性

**蓝军问什么**：
- 第一步谁做？什么时候做？
- 需要什么前置条件？具备了吗？
- 谁负责？岗位职责里有没有这件事？
- 出问题谁兜底？
- 一线会怎么用？他们受益还是受损？

**常见硬伤**：
| 硬伤 | 表现 | 级别 |
|---|---|---|
| 无 Owner | "要持续推进"但没指定人 | [致命] 致命 |
| 空话 | "加强管理""优化流程" | [致命] 致命 |
| 一线受损 | 要求多录入不减负 | [致命] 致命 |
| 无兜底 | 出问题没有应对方案 | [严重] 严重 |

## 硬伤分级

| 级别 | 定义 | 处理 |
|---|---|---|
| **致命** | 会导致项目失败、决策错误、或合规风险 | **必须改，不改不出稿** |
| **严重** | 会削弱方案效果，或埋下隐患 | 应当改，或明确说明为何不改 |
| **一般** | 表述不清、细节待补 | 可改可不改 |

**原则**：**有任何一个「致命」级问题（即会导致项目失败、决策错误或合规风险的问题），方案不能出稿。**

## 演练流程

| 阶段 | 时长 | 动作 |
|---|---|---|
| **1. 写方案** | 30 分钟 | 蓝军之外的人写方案（最好是学员） |
| **2. 蓝军挑刺** | 20 分钟 | 另一人按四维清单逐条挑，不留情面 |
| **3. 定级** | 10 分钟 | 给每个问题标 [致命]/[严重]/[一般] |
| **4. 隔离区** | 5 分钟 | [致命] 问题当场决定改还是"改不了但要说清" |
| **5. 改稿** | 20 分钟 | 改致命问题 |
| **6. 复盘** | 15 分钟 | 总结被挑出最多的维度 |

## 蓝军提问清单（可直接打印）

打印出来，方案交付前逐条对照：

### 数据真实性
- [ ] 每个数字有出处吗？
- [ ] 库存账实核过吗？什么时候核的？
- [ ] 数据口径各部门一致吗？
- [ ] 有没有只报成功案例的倾向？

### 合规内控
- [ ] 有没有绕过审批的设计？
- [ ] 内控矩阵支持吗？
- [ ] 关键操作能由一个人做完全程吗？
- [ ] 权限设置合理吗？
- [ ] 涉及个人信息的处理合法吗？
- [ ] 税务处理有专业依据吗？

### TCO 与 ROI
- [ ] 算的是五年还是首年？
- [ ] 内部人员投入算了吗？
- [ ] 二开和升级重做成本算了吗？
- [ ] 效益打折了吗？系数多少？
- [ ] 悲观情景是多少？
- [ ] 效益只达成 60% 还成立吗？

### 可执行性
- [ ] 第一步谁做？什么时候？
- [ ] 前置条件具备吗？
- [ ] 岗位职责里有这件事吗？
- [ ] 出问题谁兜底？
- [ ] 一线受益还是受损？
- [ ] 有没有"加强管理""优化流程"这类空话？

## 常见误区

| 误区 | 纠正 |
|---|---|
| **蓝军是为了通过而挑刺** | 蓝军是为了**找出真问题**。找出问题不是失败，是质量 |
| **致命问题都是小问题** | 绕过内控、只算首年、无 Owner —— **这三个最常见也最致命** |
| **改了就行** | 改不了的要**明确说清为什么改不了、风险是什么** |
| **蓝军要懂业务** | 蓝军只需**按清单问**。不懂业务反而更容易发现假设性问题 |
| **挑刺是最后一步** | 最好**在方案成型前就有人挑** |

## 给教师的话

**红蓝对抗是本训练营最有价值的一课。**

- **为什么重要**：**自己发现的问题不算问题**。学生会惊讶于"我以为很扎实的方案，被挑出三个致命问题"
- **最容易挑出问题的维度**：TCO（只算首年）和可执行性（无 Owner）
- **最培养的能力**：**批判性思维** —— 不轻易接受任何看起来专业的结论
- **课堂用法**：让学员交换方案互相挑，比老师挑效果更好

**常见教学问题**：
| 问题 | 处理 |
|---|---|
| 学生不愿挑刺（怕得罪人） | 强调"挑刺是职责，不是挑毛病" |
| 挑得太狠打击信心 | 强调"发现问题 = 提升质量"，[致命] 问题必须在交付前发现 |
| 时间不够 | 至少做维度三和四（最容易出致命问题） |

**延伸玩法**：让蓝军和作者互换角色再玩一轮 —— **作者变成蓝军，会发现自己的思维盲区**。
