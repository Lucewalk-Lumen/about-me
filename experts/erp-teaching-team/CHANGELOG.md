## 1.0.0 版本发布 🚀（2026-10-03）

首个正式版本。**按首版惯例，本版本仅列举功能，不含修复与优化条目。**

本包是一个**教学型**专家团——不是顾问团。顾问团交付报告与建议书，教学团交付讲解、类比、练习与反馈，并判断学生卡在哪一步、下一步该学什么。

### 团队构成

- **七位专家协同**：1 位主讲人 + 6 位教练。
  - 主讲人（课程主教习）：教学设计、学习路径规划、问题路由
  - 概念教练：概念讲解主力（01 全景、02 诊断方法）
  - 业务域教练：七大业务域（07-10）
  - 选型与论证教练：投资论证与选型评估（03、04）
  - AI 与落地教练：AI 集成、组织落地、供应商生态（05、06、11）
  - 练习与评卷教练：出题、批改、判分
  - 进度与路径教练：进度追踪、卡点诊断、检验安排
- **正式协作流程**：主讲人须走「建立团队 → 调度成员 → 成员回传」流程，成员产出不得由主讲人代写，跨成员信息流一律经主讲人中转。

### 分层教学机制

- **L1-L4 四层讲法**：同一概念按零基础 / 有 IT 基础 / 业务骨干 / 资深从业者四种基础交付不同深度，判断错层即教学浪费。
- **L1 先画面后词**：必给类比，多图少术语，先框架后细节。
- **L2 从系统视角切**：讲数据流向与业务语义。
- **L3 用业务语言**：从学生痛点开场，给全局视野。
- **L4 直接进方法论**：引导自我辩论，不重复学生已会的内容。

### 知识资产

### 四种教学形态

- **备课**：输出教案（目标 / 顺序 / 重点 / 练习 / 答案板 / 误区）
- **自学**：分层讲解 + 即时练习 + 答疑
- **互动**：苏格拉底式提问 → 等回答 → 评判 → 讲评
- **考核**：考题 + 评分标准 + 学习记录

### 练习与评估

- **批改四段结构**：判分（附依据） → 对的部分 → 错在哪（具体到步骤） → 怎么改（给出改后答案）。
- **三档评分制**：满分=2 / 半分=1 / 零分=0，档位名不可直接当分数使用。
- **题库**：40 题自测集分5 组，附批改标准；结业达标线为总分 80% **且**红线题全对，两个条件独立。
- **红线题 6 题**：覆盖 AI 不绕过内控、账务真实性、甲方立场等一票否决项。
- **卡点诊断五类型**：概念不懂 / 方法不会 / 练得不够 / 没迁移 / 不想学，配三问定位（问定义 / 问应用 / 给变式）。

### 教学铁律

- 十条铁律贯穿全团：先判断基础再决定深度、不直接给答案（互动模式）、讲完必须练一道题、用学生的语言、类比必须准确、不确定就说不确定、不编造数据、每个概念必给「记住这一点」、进步要可见、不催进度。
- **教师禁语**：「这个很简单」「显然」「懂了吗」「这考过了」全部禁用。
- **诚实边界**：不写死标准条款、税率与政策指标；时效内容须实时核验并标注检索日；教材未覆盖时禁止凭记忆或常识填补。

### 模板

- **教案模板**：含完整示例教案与常见误区预警。
- **进度台账模板**：掌握度追踪、里程碑、检验安排、红线题清单、沉淀区。
- **选型对比矩阵模板**：需求优先级、候选对比、五年 TCO 七类测算、实施路线图。
- **上线验收模板**：基线采集、30/60/90 天复盘、验收结论。
