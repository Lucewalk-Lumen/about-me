## v1.0.0（包标识 `academic-literature-analysis-team`）

### 命名与定位

包标识为 **`academic-literature-analysis-team`**，展示名为「**文献计量分析团**」。
标识里不出现任何一款文献管理软件的名字，因为本包**不依赖任何一款** ——
支持 **14 种题录来源**，包括 Zotero
（`zotero.sqlite` 只读直读，**无需导出**）、NoteExpress、CNKI、WoS、Scopus、
BibTeX、RIS、CSV。**EndNote 只是最常见的入口，本包并不依赖它。**

### 明确的能力边界

| 做 | 不做 |
|---|---|
| 只读解析本地题录（14 种格式） | 不与文献管理软件对接、不回写 |
| 主题聚类 / 演化 / 突现 / 多维交叉 | 不联网、不抓取外部数据 |
| 生成单文件 HTML 报告 | 不上传任何数据 |
| 综述骨架生成 | 不代写论文正文 |

### 核心能力

- **发文量与趋势**：总发文量、逐年分布、高峰年、趋势方向、拐点年份；
  支持 `--topic` 只分析单个主题的题录（可做子集分析）。
- **多维交叉共现**：关键词×作者、关键词×年份、作者×年份三个交叉表，
  并用 Cramér's V / NMI 衡量关联强度 —— 避免把"高频共现"误读成"强关联"。
- **PDF 全文提取**：从 EndNote 附件或指定目录定位 PDF，抽取摘要与关键词
  回填题录（**仅补原本缺失的字段，不覆盖已有内容**）。
  中文 PDF 优先用 PyMuPDF —— 实测 pypdf 会抽出乱码。
- **依赖引导**：`doctor.py --install` 经授权后自动安装缺失依赖；
  `doctor.py` 始终检测 R + igraph 必需前置条件，缺失即退出码 8（环境不满足），
  须先安装 R 与 igraph 再运行，**默认不可回退**；仅当用户**显式**传
  `--allow-python-fallback` 才降级为纯 Python（产物标注为非标准路径，不可与标准路径混用）。
- **报告视图自检**：自动检查四个视图都能真正渲染出内容，并验证来回切换不出错 —— 防「切换后整页空白」类问题。

### 专家团 5 人分工

| Agent | 名字 | 职责 |
|---|---|---|
| `academic-lit-analysis-lead` | 析文 | 编排全流程；**先问后算** |
| `data-auditor` | 见核 | 拦截"用残缺数据下笃定结论" |
| `trend-analyst` | 鉴势 | 发文量、趋势、拐点、突现词 |
| `network-mapper` | 织网 | 共现解读 |
| `review-outliner` | 构纲 | 综述骨架生成 |

为什么这样分工：文献计量最危险的失败模式**不是算错，而是用残缺数据
得出看似笃定的结论**（摘要覆盖率低、大量缺年份、近似重复被当成独立文献）。
「见核」守数据质量，「鉴势」守时间维度，两者职责不重叠。

### 交互与行为约定

- **先问后算**：收到文献数据后先澄清数据来源、分析目的、
  是否全量，再决定跑哪些分析 —— 不直接跑完整套流程。
- **阅读状态按数据能力判定**：仅当题录确有已读记录时才显示该章节。
  题录文件导出时 `read` 字段缺失（实测 100% 未读），此时该章节是零信息量的伪指标。
- **报告引文声明来源中立**：说明"数据源不含引文信息"，
  并同时覆盖本地题录库与题录文件两种情况。
- **主题名用单个完整概念**：不把两个词拼在一起（"组织 · 工作"那样像碎片堆砌），
  取单个概念（"资质过剩感"），并过滤"调查表""中介效应"这类研究手段词。

### 报告 UI

- **深色科技感主题**（青蓝 + 品红双主色）；画布支持**深/浅色切换**，打印时自动切回浅色
- **移动端优先布局**：所有宽表统一套横向滚动容器，窄屏下不会撑宽页面
- **图例与操作说明置于画布内**
- **连接线支持直线/曲线切换**
- 结论摘要置顶、章节目录按实际生成的章节动态生成（不留死链）
- 重复检测类型中文化并给出判断依据（"标题完全相同 / 题名字符串逐字一致"）

### 数据兼容性要点

- **Zotero 官方导出格式**：完整支持 Zotero「导出文献」得到的官方 `.rdf`
  （`dcterms` / `bibo` 命名空间），实测期刊与作者填充率均为 100%、
  摘要 98%、关键词 95%；其它 RDF 命名空间的写法亦兼容。
- **年轮视图**：切换视图依赖坐标暂存函数，该函数缺失会导致整段脚本中断、
  所有视图失效且页面无提示；已由自检套件中的「视图渲染自检」守住。
- **表格结构**：全部表格补齐 `thead` 与设计令牌样式类
  （缺失会导致时效预警柱状图空白、KPI 文字错位）。
