# 选题方向收敛提示词（Topic Scoping Prompt）

> 用途：在文献阅读（READINGS.md 就绪）、动笔撰写之前，由 LLM 基于已读文献归纳研究缺口方向，供用户选定后展开写作。本文件在综述路径的「选题方向收敛」阶段调用。

## 路径定位
本提示驱动综述路径的「选题方向收敛」专项。目标：基于已读文献识别研究缺口（research gap），把宽泛兴趣收敛为可被文献问答的聚焦综述方向。执行者为综述路径，面向组织行为学与人力资源管理（OB/HRM）文献综述，从已读文献中识别缺口、避免对主题做泛泛概述。

## 输入
- **用户的宽泛主题 / 初步兴趣**：`{{USER_TOPIC}}`
- **文献阅读整理（READINGS.md 节选或摘要）**：`{{READINGS_MD}}`
  - 每条通常含：作者 / 年份、核心发现、缺口标注（如有）
  - 若文献量过大，可仅提供"缺口标注"行 + 各文献一句话核心发现摘要

## 任务
基于上述输入，归纳 **3–5 个**有研究缺口支撑的选题方向。每个方向必须源自文献中**真实存在的张力、矛盾、空白或未被整合的发现**，而非对主题的概述式复述。

## 输出格式（严格按 Markdown）
对每个方向，输出：

### 方向 N：{{一句话定位（≤25 字，须含对象/情境/机制之一，禁用"XX 研究综述"式空泛标题）}}
- **聚焦问题**：用 1 个可回答的研究问题表述（"本文综述旨在厘清/回答：……"）
- **支撑文献**：共 {{k}} 篇（列出 3–5 篇关键文献：作者, 年份 — 核心发现一句话）
- **研究缺口**：现有文献尚未解决 / 相互矛盾 / 缺乏整合之处（≥2 句，点明"为何值得做"）
- **新颖性与缺口类型**：标注该方向的新颖性等级（gap_novelty N1-N4）+ 缺口类型（五类之一：证据/知识/实践-理论/方法/评价缺口）。定义见 `gap_novelty.json`，此处只填等级与类型 + 一句判定理由。若为 N1 需说明与既有直接研究的差异，否则应剔除该方向
- **潜在章节骨架**：3–4 个可展开的综述子主题（用于后续拟定提纲）
- **适配范式提示**：建议的撰写范式（参考 paradigms.json，如 系统梳理 / 某一视角 / 新兴概念式 / 经典回顾 等）

## 输出示例（仅示范格式，内容须来自真实文献）
### 方向 1：远程团队中技术监控对信任的边界条件
- **聚焦问题**：本文综述旨在回答：技术监控在哪些情境与个体特征下会侵蚀 vs. 修复分布式团队信任？
- **支撑文献**：共 5 篇（Bankins & Formosa, 2023 — 提出算法管理信任悖论；Möhlmann et al., 2021 — 零工_worker 信任断裂；…）
- **研究缺口**：现有对技术监控与信任的关系多呈"总体负向"结论，却缺乏对调节变量（任务可见性、可控感、文化）的系统性梳理，导致实践上"一刀切"管控。
- **新颖性与缺口类型**：N3（新变量组合——将技术监控与多类调节变量系统整合）+ 证据缺口（正负向证据并存缺整合）。
- **潜在章节骨架**：① 技术监控的定义与维度 → ② 信任的形成机制 → ③ 边界条件（个体/团队/文化）→ ④ 管理启示
- **适配范式提示**：某一视角（信任视角）或 新兴概念式

## 约束（避免泛化）
1. 不得把"主题概述"当作"方向"——每个方向必须指向一个**具体缺口**。
2. 每个方向至少引用 **3 篇真实文献**支撑，禁止编造；文献须来自 `{{READINGS_MD}}`。
3. 方向之间应**正交**（覆盖不同缺口维度，互不重叠），避免把所有内容塞进一个大而空的主题。
4. 一句话定位须具体（含对象/情境/机制之一），禁用空泛标题。
5. 末尾输出一段 **"收敛建议"**：推荐最聚焦、缺口最清晰的方向及理由，并提示可选组合，供用户决策。

## 收尾
呈现完成后，请用户从 3–5 个方向中**选定 1 个**（或要求合并/微调）。**选定前不进入提纲与正文撰写。**
