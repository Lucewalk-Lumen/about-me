# 综述写作风格规范

> 基于综述写作最佳实践的全量统计分析（55 篇 /管理学高被引综述论文样本）。
> 本文件为写作阶段（load_trigger: writing）的必读规范，与本目录下的
> `templates.json`（章节模板）和 `paradigms.json`（九种综述范式）配套使用。
> 核心原则：综述是批判性分析与理论建构，不是文献罗列；每句论断都需文献支撑。

---

## 一、引用表达规范

### 括号内引文作者连接
- **英文作者**：使用 `&` 连接（55 篇论文中 224 处用 `&`，仅 25 处用 `和/与`，比例 9:1）
  - [通过] `(Smith & Jones, 2020)` / `(Lammers & Stapel, 2011)`
  - [不通过] `(Smith 和 Jones, 2020)` / `(Lammers和Stapel, 2011)`
- **中文作者**：两位作者用 `与` 连接，三人及以上用 `等`
  - [通过] `（张三与李四，2019）` / `（王五等，2021）`
  - [不通过] `（张三和李四，2019）`（"和"不如"与"正式）
- **中英混合**：括号内以第一位作者的语言为准
  - [通过] `(张三 & Smith, 2020)` / `(Smith 与 张三, 2020)`

### 多引文分隔
- 同一括号内多个引用用分号 `;` 分隔
  - [通过] `(A, 2017; B, 2021; C, 2019)`
  - [不通过] `（A, 2017）、（B, 2021）`（分离括号）

### 英文等/et al.
- 55 篇论文中 `et al.` 出现 538 处——英文综述的核心引用模式
- 正文中：首次引用 ≤2 位作者全列，3 位及以上用 `et al.`（斜体）
- 参考文献中：20 位以内全列，超过 20 位列前 19 位 + `…` + 末位

### 等/et al. 转写
- 中文正文：`xxx等（2020）` — 等前无空格
- 英文正文：`xxx et al. (2020)` — et al. 后有句点
- 参考文献中：中文 `等`，英文 `et al.`（不斜体）

## 二、学术短语与论证连接词

### 论证连接词（节制使用，禁无脑堆砌）
> 连接词是学术论证的骨架，**该用时必须用**；但去AI味的关键是"节制、情境化"，而非机械堆砌。判定标准见下方「判定标准」段。
>
> **判定标准**：连接词服务于真实的逻辑关系（递进/对比/因果确实存在）→ 用；仅为凑段落结构、每段开头无脑套用 `首先/其次/综上所述` → 禁。同一篇综述里 `首先……其次……最后` 出现两次以上、或每段都以 `综上所述` 收尾，即为堆砌，须改写。

- 递进展开：`首先……其次……最后……`（**仅当确有三段并列递进关系时使用一次**，避免"A做了X，B做了Y"式罗列，更避免每段套用）
- 对比张力：`与之相对……` / `然而……` / `与此不同……`（对比关系真实存在时优先，最自然）
- 因果推导：`在此基础上……` / `由此……` / `相应地……`
- 总结收束：`综上所述……` / `总体来看……`（**全文限用一次，置于总结段；勿在每个子节末尾滥用**）

### 必备句式模板
- 概括研究现状：`现有关于 xxx 的研究已沿 [维度A / 维度B / 维度C] 若干线索展开`
- 指出分歧：`然而，关于 xxx 学界仍存在分歧：[观点一] 认为……；而 [观点二] 则主张……`
- 定位缺口：`现有研究已考察 X，但尚未涉及 Y / 在 Z 条件下结论矛盾`
- 提出展望：`未来研究可从 [构念重构 / 机制解密 / 边界拓展] 三个层次深入`

### 禁用表达
- `巨大空白` / `完全空缺` / `填补重大空白` — 以精准缺口句式替代
- `开创性` / `革命性` / `前所未有` / `里程碑式` — 断言强度需匹配证据
- `为……提供重要参考` — 自我评价，应删除

## 三、摘要结构规范

基于 55 篇论文的摘要模式统计：
1. **背景句**（1–2 句）：领域现状与核心张力
2. **目的句**（1 句）：本文旨在厘清/回答/整合……
3. **方法句**（1 句，可选）：通过 [方法] 对 [N 篇] 文献进行 [分析方式]
4. **发现句**（2–4 句）：核心主题 + 主要发现 + 关键矛盾
5. **贡献/展望句**（1–2 句）：理论增量 + 实践启示 + 未来方向

字数：200–300 字（中文）/ 150–250 词（英文）

## 四、引言结构规范

引言需在 3–5 段内完成"漏斗式"收敛：
1. **领域定位**（1 段）：该主题为何重要？当前学术关注度如何？
2. **现状矛盾**（1 段）：已有研究在概念/方法/结论上存在何种分歧？
3. **缺口论证**（1 段）：现有研究未能回答的具体问题是什么？
4. **本文定位**（1 段）：本文聚焦于……，采用 [范式] 对 [范围] 文献进行 [分析方式]
5. **贡献预告**（1 段，可选）：本文的理论增量与方法贡献

关键准则：引言的末尾必须明确综述的聚焦研究问题（research question）。

## 五、主体结构层级规范

### 章节标题
- 不超过三级标题（# → ## → ###）
- 标题用名词短语，不用问句——`边界条件与调节机制`，不是 `哪些因素调节了X？`
- 避免"XX 的研究综述"式空泛标题——应含对象 + 维度 + 关系

### 段落组织
- 每段开头一句话概括本段核心论点（topic sentence）
- 段落内以"核心论点 → 支撑文献简述 → 评析/对比"展开
- 相邻段落之间必须有显式逻辑连接词

### 主体四式（按需选用）
- **按问题史**：主题的提出及历史阶段 → 国内外现状 → 不同学者观点 → 作者认识
- **按横向关系**：各方观点 → 方法比较 → 发展方向 → 优劣评价
- **按比较**：系统认识 → 比较路径 → 取向预测 → 选择突破口
- **以理论带动**：框架阐述 → 基于理论的文献梳理 → 整合分析 → 取向预测

## 六、英文术语处理规范

### 首次出现的术语
- 中文正文首次出现英文术语时标注原文
  - [通过] `工作重塑（job crafting）`
  - 之后可省略英文，但全文中英对应须保持一致
- 同一术语不得在不同段落出现不同中文译名
  - [不通过] 前文用 `扎根理论` 后文用 `扎根方法`

### 高危术语（易误译）
| 中文 | 英文 | 注意事项 |
|------|------|----------|
| 员工建言 | employee voice | 绝不译作"声音" |
| 构念 | construct | 区别于 concept（概念） |
| 理论贡献 | theoretical contribution | 亦可用 theoretical implication，需按目标期刊惯例 |
| 研究缺口 | research gap | 流派归属敏感，避免过度宣称 |

### 提交前核对
- [ ] 全文术语中英对应一致
- [ ] 流派归属敏感术语已确认
- [ ] 无自造英文术语/缩写

## 七、参考文献格式怎么办

**本技能不处理引文格式。** 参考文献的排版规范（GB/T 7714、APA、Chicago 等）
由**专用引文工具**负责，本技能只负责搭出论证骨架、把该引用的位置标出来。

交接给引文工具时需要提供的是**位置与意图**，不是格式：

- 骨架里每个章节标注了此处需要何种证据（主张 / 反例 / 界定 / 反驳）
- 每个证据位标注了它支撑哪条主张（`evidence_claim_map.json` 记录映射）
- 哪些文献尚未获取原文、哪些归属未证实（`reading.json` 记录状态）

> [!] 本节不含引文格式规范 —— 引文格式超出本技能职责边界，请交给专用引文工具处理。
- [ ] 无编造引用——每条引用都能回溯到源题录（三态标注：已核实 DOI / 未获取原文 / 未证实归属）
