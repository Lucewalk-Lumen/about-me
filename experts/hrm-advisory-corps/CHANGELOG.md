# 变更日志 · HRM 实战参谋团

> 版本真源：`.codebuddy-plugin/plugin.json` 的 `version`。本文件记录智能体功能变更。

- 新增成员职能分组与成员能力清单、单 agent 直调问法速查与预设 Workflow 场景速览，补齐协同可观测性面板

## 1.0.0 版本发布 🚀（2026-10-05）

首个版本。面向中国大陆市场的九位 HR 智能体：一位主理人统筹调度，八位领域总监分工产出，全部结论经统一合规闸门把关。

### 团队与分工

- 新增 首席参谋官（韩明轩 / Ryan）：纯编排者——按意图路由表分发任务、下发回传契约、验签与质量把关、汇编交付；领域结论 100% 来自成员产出，不代写
- 新增 组织规划总监（邵铭川 / Ethan）：组织架构与定岗定编、管理幅度与层级深度、人力预算与编制缺口测算、组织人效与健康度诊断、经营简报与季度复盘
- 新增 招聘管道总监（唐嘉树 / Kevin）：岗位说明书与 JD 撰写、渠道组合、简历初筛与候选人评分、面试设计与题库、模拟面试陪练与记分卡、Offer 与录用沟通、雇主品牌；亦服务求职者侧（简历诊断与优化、面试准备、薪资谈判、求职进度追踪）
- 新增 人才发展总监（孟启帆 / Aaron）：胜任力模型、人才盘点与九宫格、继任梯队、培训体系设计与课程开发、员工发展与 IDP、导师制与学习项目评估
- 新增 绩效管理总监（宋雨薇 / Grace）：绩效体系选型（KPI / OKR / BSC）、指标库与目标分解、考核流程与校准、结果应用与改进面谈、绩效申诉处理
- 新增 薪酬福利总监（周予安 / Vincent）：岗位价值评估、薪酬带宽与等级、调薪方案、个税与社保实发测算、激励方案（奖金 / 股权 / 提成）、人工成本与人效分析
- 新增 劳动合规总监（郑宜宁 / Jade）：劳动合同审查与解除终止、规章制度合规、社保公积金、工时与休假、劳动争议与仲裁准备；作为跨模块编排的终检方（final_gate），对跨模块产出做合规风险分级，单模块产出由合规闸门脚本把关
- 新增 人才测评总监（柳心悦 / Lily）：32 题作答或职场文字描述生成人格报告、类型码与解读、漫画形象输出；护栏限定测评场景，结果仅供职场参考，不作心理 / 临床 / 医疗诊断
- 新增 寻访拓展总监（齐一鸣 / Leo）：主动寻访与人才库运营、寻访单与目标画像、寻访适配三维评估与 A/B/C 分级、触达话术；位于招聘管道上游，交接后经主理人中转至招聘管道，终检仍由劳动合规负责

### 资产与工具

- 新增 HR 实务工具库：199 份制度与表单模板，按模块归口、七种检索入口，全 ASCII 路径并附清单索引
- 新增 离线计算引擎：薪酬实发与社保个税测算、编制与人效测算、候选人评分、组织健康度评分、OKR 与人力规划跟踪，均为纯标准库实现、跨平台可用
- 新增 主引擎 + 关键词增强引擎：跨模块交接单据串联全流程，输出结构化结果

### 质量与合规机制

- 新增 统一合规闸门：对全部产出做风险分级，拦截项给出教育式改写引导（不参与分级判定）；合规结论须带法条出处、基准日期与核实状态
- 新增 五项回传契约：成员回传须含结论 / 产物 / 依据与来源 / 待确认项 / 建议下一步，并以 HMAC 签名信封封装，主理人验签后方可采信（契约单一基准见共享契约）
- 新增 输出契约校验器：交付前自动校验签名、契约完整性、合规出处、个人信息脱敏与字段完整度，输出机器可读质量报告与综合分，未过必须项即拦截
- 新增 任务生命周期账本：跨阶段状态持久化（创建→派单→回传→校验→闸门→交付），含合法状态迁移校验、重试预算、专家连续失败熔断，失败任务留痕转人工兜底
- 新增 协作过程可见：每个阶段输出一张协作进度表（成员 / 产物 / 该阶段验签与合规结论）
- 新增 交付前终检：逐项核对法条出处与基准日期、需人工核实项是否单列、引擎数字是否附输入快照可追溯、跨模块结论口径是否一致；任一项不满足先回炉再交付
- 新增 个人信息保护：候选人档案只存脱敏视图，跨成员回传经 HMAC 签名鉴权封装（防伪造与重放）；入库强制校验知情同意，检出明文即拒写；删除同步落实删除权并写审计日志
- 新增 版本更新播报：版本更新后用户再次召唤时，主理人主动告知本次改动；同一版本读过一次后不再重复打扰

### 已知限制

- 已知 合规闸对「经第三方代发工资以回避社保」这类间接规避表述仍有召回缺口——该表述字面与合法代发咨询完全相同，补字面词表会误伤合规咨询，故现由主理人在语义层复核；后续应收紧为语义判定或结构化字段
- 已知 寻访硬过滤（排除条件）为自然语言行为条件，档案暂无结构化字段可判定
- 已知 排班脚本的文本回退解析不支持转义引号等极端情形，生产环境建议安装专业解析工具
- 已知 法规条文与税率表以官方最新发布为准，输出中的基准日期须由使用者复核
