# 隐私与数据保护声明（PRIVACY）

> 适用版本：`hrm-advisory-corps` 1.0.0
> 适用范围：**本包自身脚本与数据落盘行为**。宿主平台（WorkBuddy）的大模型推理如何
> 处理会话上下文，请遵循平台自身的隐私政策——本声明不覆盖、也无法代替平台条款。

HRM 实战参谋团处理的是**候选人 / 员工的个人数据（PII）**与敏感的组织、薪酬、合规信息，
因此对隐私作最小必要设计。以下承诺均对应包内脚本的**实际实现**，非空泛声明。

## 1. 数据存哪里、存什么

- **仅本地**：人才库、任务账本、审计日志、测评与薪资测算输入等均落在**本机（工作区及用户级数据目录）**
  （及 `quality/` 质量记录），不写入插件作者服务器、不建云端副本。
- **明文不落普通档案**：`talent-sourcing` 人才库的档案**只存脱敏视图**；脱敏引擎
  （`security/pii.py`）在入库前对手机号、邮箱等打码，人才库本体**不落明文**。跨成员回传经
  HMAC **签名鉴权封装**（`security/envelope.py`，防伪造与重放；密钥以 `secrets.token_bytes(32)`
  生成、文件权限 `0600`）——签名用于完整性与来源鉴权，**不是加密**。「明文 PII 保管区」
  （`pii_vault_ref` 仅存引用）为设计预留位：**当前版本不启用明文存储、无加密保管区实现**。
- **输出最小字段**：检索 / 简报只返回「脱敏视图白名单」内字段（`talent_pool.py`
  `_RE_PHONE` / `_RE_EMAIL` 兜底扫描，命中明文形态即拒写回）。

## 2. 同意与个人权利（个保法对齐）

- **同意前置**：档案 `source.consent.obtained` 非 `true` 时**拒绝入库**（硬校验）。
- **删除权**：删除候选人档案时同步落实删除并**写审计日志**，可追溯。
- **可查**：任务生命周期经 `task_ledger.py` 记录（创建→派单→回传→校验→闸门→交付），
  状态与操作可回溯。

## 3. 网络与外联（已核实）

- **本包脚本不发起任何出站网络请求**：经全量核查，`skills/**` 下的 Python / JS **未 import
  任何网络库**（`requests` / `urllib` / `socket` / `http.client` / `httpx` 等），**也无任何
  外部 URL 字面量**。主动寻访、模板检索、测评、薪资带宽等能力均为**本地计算**。
- **不向第三方传输用户数据**：成员回传只在协作层内以**加签信封**在本地流转
  （见 §4），不含把用户数据发往作者或外部服务器的逻辑；无埋点、无遥测。
- 说明：若你在**宿主平台**启用了联网检索类官方技能，其外联与数据流向由**该官方技能与
  平台政策**约束，不属于本包脚本行为。

## 4. 交付前质量与合规闸门

- 成员回传须经 `quality_gate.py` 校验：**信封签名（QM-01）**、五项回传契约齐全（QM-03）、
  合规结论带**法条出处 + 基准日期 + 核实状态**（QM-04）、**PII 已脱敏（QM-05）**、spec 完整度；
  未过必须项即拦截，不进入汇编。
- 合规结论默认 `PENDING`，**成员不得自行标注 `PASSED`**；P0 阻断自动中止交付、转人工负责人。
- 凡经引擎计算（薪资 / 评分 / 组织健康度 / 测评）的数字，附**输入快照**（参数、城市、基准
  日期）与来源脚本，可复核。

## 5. 如何清除数据

删除本机对应工作区内的 `talent-sourcing` 库目录、`task_ledger` 状态文件与审计日志即可，
无需卸载插件；档案删除后其脱敏视图与 `pii_vault_ref` 引用一并失效。
