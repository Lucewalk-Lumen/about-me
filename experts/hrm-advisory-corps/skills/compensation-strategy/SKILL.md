# compensation-strategy 领域 playbook（私有）

本文件是该 specialist 的领域工作流基准，由 `agents/compensation-strategy.md` 加载。共享契约见 `../hrm-solution/contracts.md`；共享引擎见 `../hrm-solution/scripts/`。

## 核心能力
1. **定薪判断与市场竞争对标**：四层证据强度（official/paid_survey/internal/public）+ 三级置信度；结合市场薪酬数据做竞争力对标，确定有竞争力的薪资区间
2. **薪资计算**：运行 `python3 ../hrm-solution/scripts/payroll_engine.py`（Windows 用 `python`），累计预扣个税 + 五险一金城市费率 + 年终奖优化
3. **申报排雷**：10 字段校验 + 优先级排序 + 追回话术
4. **全面薪酬框架**：固定/浮动/福利/长期激励的组合设计与 P25/P50/P75 市场分位对标

## 置信度纪律
- [通过]正式建议：四条件全满足 → [注意]弱建议 → [要点]仅市场信号（禁止冒充正式建议）

## 分析框架

薪酬类问题按下列六步推演，证据强度决定结论强度：

1. **岗位定位**：岗位职责、职级、城市、汇报关系、稀缺度，确定对标口径与可比样本范围
2. **证据取证与分级**：按四层证据强度取数——official（官方发布）> paid_survey（付费调研）> internal（内部数据）> public（公开信号），逐条标注来源与采集日期
3. **市场分位对标**：P25 / P50 / P75 三档定位，结合公司付薪策略（领先 / 跟随 / 滞后）确定目标分位
4. **置信度判定**：证据层级 + 样本量 + 时效性 + 可比性四条件全满足才可出「正式建议」，否则降为「弱建议」或「仅市场信号」
5. **成本测算**：按累计预扣个税 + 所在城市五险一金费率测算企业总成本与员工到手，年终奖比选单独计税与并入综合所得两种口径
6. **结构复看**：固定 / 浮动 / 福利 / 长期激励四段组合是否匹配岗位性质与激励目标，给出结构调整建议

框架约束：第 4 步的置信度不得跃升——仅有 public 层证据时严禁输出「正式建议」；第 5 步所有费率与基数必须标注适用年度，按 `../hrm-solution/contracts.md`「输出契约」标注出处与基准日期，时效存疑即标「需人工核实」。

## 工作流程
1. **定**（定薪判断）：收齐岗位/职级/城市/汇报关系 → 按四层证据强度（official/paid_survey/internal/public）取证并标注来源 → 结合市场薪酬数据做竞争力对标，输出带置信度的薪资区间
2. **算**（薪资核算）：运行 `python3 ../hrm-solution/scripts/payroll_engine.py`（Windows 用 `python`）→ 累计预扣个税 + 所在城市五险一金费率 → 年终奖单独计税/并入综合所得两种口径比选取优
3. **看**（全面薪酬复看）：固定/浮动/福利/长期激励组合设计，按 P25/P50/P75 市场分位对标，给出结构调整建议
4. **申报排雷**：10 字段校验 → 问题项按优先级排序 → 逐项给出追回话术
> 定/算/看三段必须分步独立执行并各自留痕，严禁合并为一次结论。
