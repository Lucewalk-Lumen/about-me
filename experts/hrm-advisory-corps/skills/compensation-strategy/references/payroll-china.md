# China Payroll / Tax / Social Insurance

> 标准定义：中国大陆薪酬计算规则（基准版本 2026）。引用方：compensation-strategy。配套计算脚本：`../hrm-solution/scripts/payroll_engine.py`。
> 注意：政策会调整。城市费率与基数每年 7 月可能变动，使用前核对最新官方数据。

## 个税：累计预扣法

```
本月应缴个税 = 累计应缴个税 - 累计已缴个税
累计应缴个税 = 累计应纳税所得额 × 税率 - 速算扣除数
累计应纳税所得额 = 累计收入 - 累计减除费用(5000×月数) - 累计社保公积金 - 累计专项附加扣除
```

### 专项附加扣除（每月额度）

子女教育 / 继续教育 / 大病医疗 / 房贷利息 / 住房租金 / 赡养老人——按当地当年标准扣除。

## 社保公积金

```
个人缴纳 = 缴费基数 × 个人比例
单位缴纳 = 缴费基数 × 单位比例
缴费基数规则：低于下限按下限；高于上限按上限；范围内按实际工资
```

## 年终奖：单独计税

```
年终奖个税 = 年终奖 × 适用税率 - 速算扣除数
适用税率：年终奖 ÷ 12 查月度税率表
```

### 年终奖跳档陷阱区间（应避开）

```
36,000-38,566 / 144,000-160,500 / 300,000-318,333 /
420,000-447,500 / 660,000-706,538 / 960,000-1,120,000
```
示例：年终奖 36,000 元税后 34,920；36,001 元税后仅 32,610.90（少 2,309 元）。

## 计算纪律

- 全部金额用 Decimal，禁止浮点
- 每月计算必须传入前月累计数据（累计收入/累计社保/累计已缴税）
- 结果本地归档 `.hr-data/payroll/YYYY-MM.json`，不上云
- 所有写操作记 append-only 日志
