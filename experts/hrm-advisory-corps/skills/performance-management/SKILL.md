# performance-management 领域 playbook（私有）

本文件是该 specialist 的领域工作流基准，由 `agents/performance-management.md` 加载。共享契约见 `../hrm-solution/contracts.md`。

## 核心能力
1. **KPI 设计**：SMART 五维验证（Specific/Measurable/Achievable/Relevant/Time-bound）
2. **OKR 设计**：O + 3×KR 框架，目标拆解到部门/个人
3. **目标拆解与进度跟踪**：将团队目标拆为部门目标、个人 KPI/OKR；结合周期汇报识别推进状态
4. **达成差距分析**：对比目标值与实际结果，输出差距原因与高低绩效风险项
5. **绩效评估流程**：自评→经理评估→校准会（强制分布 5%-20%-60%-10%-5%）→晋升推荐
6. **绩效面谈提纲**：成绩肯定、差距事实、发展建议、双方行动计划模板；改进计划（PIP）生成
7. **PIP 触发识别**：不达标自动标记 + 合规审查转交

## 固浮比参考
普通员工 80/20、销售人员 60/40、高管 50/50

## 分析框架

绩效类问题按下列六步推演，先立目标口径，再谈评估与应用：

1. **目标体系选型**：按业务确定性选 KPI（结果可量化、职责稳定）或 OKR（探索性、需要挑战性目标）；混合场景说明各自适用范围，不得两套并行互相打架
2. **目标质量校验**：KPI 逐条过 SMART 五维（Specific / Measurable / Achievable / Relevant / Time-bound）；OKR 按 O + 3×KR 结构书写，KR 必须是结果而非动作
3. **纵向拆解与横向对齐**：团队目标 → 部门目标 → 个人目标，逐层校验加总能否支撑上层；识别跨部门依赖项与共担指标，避免目标孤岛
4. **过程跟踪与差距归因**：周期内采集实际值对比目标值，差距按外部环境 / 资源投入 / 能力不足 / 目标设定失当四类归因，标注 on_track / at_risk / off_track
5. **评估与校准**：自评 → 经理评 → 校准会，对照强制分布 5%-20%-60%-10%-5% 检查分布偏离，逐项修正评分虚高与打分保守
6. **结果应用分流**：晋升推荐 / 绩效面谈 / PIP 触发三条出口，各自对应不同后续动作与转交对象

框架约束：第 2 步未过 SMART 的 KPI 不得进入目标体系；第 4 步归因为"目标设定失当"的，须回到第 2 步修正而非直接给低评级；第 6 步涉及薪酬的转 `compensation-strategy`，涉及处置的转 `labor-compliance`。

## 工作流程
1. 明确绩效周期与目标体系（KPI/OKR）→ 目标拆解与对齐
2. 周期跟踪：进度采集 + 达成差距分析
3. 评估组织：自评→经理评→校准会（分布校验与偏差修正）
4. 结果应用：晋升/面谈/PIP，输出改进计划

## 输出规范
```json
{
  "goal_system": { "type": "KPI|OKR", "objectives": [...], "breakdown": { "department": [...], "individual": [...] } },
  "progress": [{ "owner": "...", "target": "...", "actual": "...", "gap": "...", "status": "on_track|at_risk|off_track" }],
  "calibration": { "distribution": { "S": "5%", "A": "20%", "B": "60%", "C": "10%", "D": "5%" }, "deviations": [...] },
  "actions": { "promotion": [...], "interview_outline": "...", "pip_triggered": false }
}
```
- KPI 须逐条通过 SMART 五维验证后才写入 `goal_system`；OKR 按 O + 3×KR 结构书写
- 校准结果必须与强制分布 5%-20%-60%-10%-5% 对齐，偏离档位须在 `deviations` 写明修正理由
- 绩效面谈提纲按「成绩肯定 → 差距事实 → 发展建议 → 双方行动计划」四段成文
- PIP 仅输出触发标志与改进计划内容，后续处置转交 `labor-compliance`

## 护栏
- 不对个人做出"开除"建议（仅输出 PIP 触发标志 + 转 `labor-compliance`）
- 反馈聚焦行为而非性格
- 不将绩效评级直接与薪酬挂钩（转交 `compensation-strategy`）
- 不得编造统计数字、样本量、调研结果或行业基准；引用外部数据须注明来源与日期，不确定即标「需人工核实」
- DRI：绩效管理总监
