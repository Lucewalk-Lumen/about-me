# talent-development 领域 playbook（私有）

本文件是该 specialist 的领域工作流基准，由 `agents/talent-development.md` 加载。共享契约见 `../hrm-solution/contracts.md`。

## 核心能力
1. **培训需求诊断**：战略解码、业务痛点映射、胜任力模型（知识/技能/态度）、360 与绩效数据差距分析；紧急度×重要度矩阵排序；培训 ROI 估算
2. **课程体系与教学设计**：
   - 模型：ADDIE（分析→设计→开发→实施→评估）、SAM（快速迭代）
   - 理论：Bloom 认知分类、建构主义、翻转课堂、混合式（OMO）、体验式（Kolb）、游戏化
   - 学习路径：按岗位层级（新人→专员→专家→管理者）渐进式地图
3. **内容开发**：微课（5–15 分钟）、案例教学、沙盘模拟、沉浸式情境训练、标准化课包（大纲/讲师手册/学员手册/课件/题库）、知识萃取（SME 访谈）
4. **新员工培训**：30/60/90 天标准化计划、Day 1 时间线、Buddy 双导师制、90 天成长计划、文化融入、试用期考核
5. **领导力与人才梯队**：管理梯队（一线/中层/高管）、高潜（HIPO）计划与 IDP、行动学习、360 反馈、继任规划与准备度评估
6. **内训师发展（TTT）**：选拔标准、核心模块、授课技巧、认证体系与讲师社群运营
7. **培训评估**：柯氏四级（反应/学习/行为/结果）+ 学习数据看板 + 培训价值报告
8. **合规培训**：信息安全、反腐败、数据隐私（PIPL）、职场安全，年度计划与 100% 覆盖追踪

## 分析框架

培训与发展类问题按下列六步推演，先确认"该不该培训"，再谈怎么培训：

1. **战略解码与问题定性**：业务目标 → 所需能力项；先判定绩效差距的成因是**能不能**（能力缺口，可培训）还是**愿不愿**（动机、流程、资源、管理问题，培训无效），后者直接转对应模块，不做无效课程
2. **胜任力差距分析**：按知识 / 技能 / 态度三层建模目标岗位胜任力，用 360 反馈与绩效数据定位实际水平，输出可量化差距
3. **优先级排序**：差距项按紧急度 × 重要度矩阵排序，结合覆盖人数与业务影响估算培训 ROI，确定本期投入范围
4. **教学策略选型**：按差距性质选 ADDIE（体系化、需求稳定）或 SAM（快速迭代、需求模糊）；按 Bloom 认知层级把差距转写为可衡量学习目标；按受众层级（新人→专员→专家→管理者）铺学习路径
5. **交付形态设计**：微课 / 案例教学 / 沙盘模拟 / 情境训练 / 混合式（OMO）组合，配套课包五件套（大纲、讲师手册、学员手册、课件、题库）
6. **柯氏四级评估回路**：反应→学习→行为→结果逐级设计测量口径，第三级（行为转化）与第四级（业务结果）的指标必须在开课前就定义好，不得事后补测

框架约束：第 1 步判定为非能力问题的，禁止继续往下设计课程；第 4 步的学习目标必须可测，不接受"了解 / 熟悉"这类表述。

## 工作流程
1. 需求诊断（业务目标 + 绩效/胜任力差距 → 可衡量目标与受众）
2. 方案设计（教学策略、课程大纲、学习路径、预算）
3. 内容开发（SME 访谈、课件/案例/题库、试讲与反馈）
4. 培训交付（训前/训中/训后）
5. 效果评估与优化（满意度/学习/行为/业务指标 + 最佳实践沉淀）
