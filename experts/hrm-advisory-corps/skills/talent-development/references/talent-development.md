# Talent Development (Onboarding/Pool/Career Path)

> 标准定义：入职培训、继任规划、职业发展路径。引用方：talent-development。

## 场景 1：新员工入职培训（30/60/90）

**三原则**：Day 1 不超载 / 指定 Buddy / 目标具体可衡量

**入职前准备**：开通账号、采购设备、发送欢迎邮件、指定 Buddy

**Day 1 时间线**：

| 时间 | 活动 | 对接人 |
|------|------|--------|
| 9:00 | 欢迎导向 | 经理 |
| 10:00 | IT 设置 | IT/Buddy |
| 11:00 | 团队介绍 | 团队 |
| 14:00 | 公司介绍 | 经理 |
| 15:30 | 30/60/90 计划对齐 | 经理 |

**里程碑**：Week 1（合规培训/文档阅读/1:1/旁听会议/第一个小任务）→ 30 天学习融入 → 60 天独立贡献 → 90 天全面产出

## 场景 2：人才梯队与继任规划

1. 识别关键岗位（不可替代性高 + 外部招聘周期长）
2. 评估现任者留任风险（低/中/高）
3. 识别高潜继任者，含准备度：ready now / 1-2 年 / 3+ 年
4. 输出继任计划表 + 关键岗位覆盖率分析

**输出结构**：
```json
{ "key_positions": [{"role":"...","incumbent":"...","retention_risk":"low|medium|high","successors":[...]}], "coverage_rate":"N%", "gaps":[...] }
```

## 场景 3：职业发展路径

1. 基于员工能力评估 → 匹配岗位能力模型 → 识别差距
2. 输出个性化路径：培训课程 + 项目实践 + 导师配对
3. 四架构模型下的发展通道选择（职能/事业部/矩阵/扁平）

**输出结构**：
```json
{ "employee":"...", "current_level":"...", "target_level":"...", "skill_gaps":[...], "recommended_actions":[{"type":"training|project|mentoring","detail":"..."}] }
```

## 使用纪律

- 不将职业发展建议与绩效评估挂钩
- 不访问未经员工知情同意的个人能力评估数据
- 不做出晋升承诺（晋升是绩效评估 Agent + 人类 DRI 的联合决策）
- 培训协议/服务期条款涉及劳动法 → 转 labor-compliance
