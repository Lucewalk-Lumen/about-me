# Training Program Design

> 标准定义：员工培训计划构建器（结构化课程模块 + 评估框架 + 完成追踪 + 合规要素 + ROI 指标）。引用方：talent-development。
>
> 适用场景：为任何岗位/部门/合规要求设计结构化培训计划。

## 1. 概述

本笔记提供**结构化培训计划的完整 prompt 框架**，覆盖从单门课程到多模块培训项目的设计需求。核心理念是把"想搞个培训"的需求转化为**可衡量、可追踪、可复盘**的标准结构。

**4 输入 5 输出的标准结构**：
- **4 输入**：角色受众 / 培训目标 / 时间跨度 / 培训形式
- **5 输出**：项目结构（模块化）/ 评估框架（Knowledge + Practical + Rubric）/ 完成追踪表 / 合规要素（适用时）/ ROI 指标

## 2. 4 输入规范

```json
{
 "audience": "受众角色 / 团队（必填）",
 "objective": "培训后应掌握的知识/技能（必填）",
 "timeline": "时间跨度（如 2 周 / 30 天 / 90 天 / 1 年）（必填）",
 "format": "self-paced | instructor-led | blended（必填）"
}
```

## 3. 输出 1：项目结构（模块化模板）

```
PROGRAM: [项目名称]
AUDIENCE: [角色/团队]
DURATION: [X 周]
FORMAT: [Self-paced / Instructor-led / Blended]

MODULE 1: [主题]
- Learning objectives（3-5 个可衡量结果）
- Content outline（主题、子主题）
- Activities（实操练习、案例研究）
- Assessment（测验、实操演示、项目）
- Time estimate: X 小时
- Resources needed: [工具、权限、教材]

MODULE 2: [主题]
...

MODULE N: [主题]
...
```

**每模块必含 6 元素**：
1. **学习目标** — 3-5 个可衡量结果（用动词开头：列出 / 设计 / 演示 / 实施）
2. **内容大纲** — 主题与子主题的层次结构
3. **活动设计** — 实操练习（hands-on）+ 案例研究
4. **评估方式** — 测验（quiz）+ 实操（demo / project）+ 评分量规
5. **时间估算** — 单模块 X 小时（人天）
6. **资源需求** — 工具、账号权限、教材

## 4. 输出 2：评估框架

每模块 3 维度评估：

### 4.1 知识测验（Knowledge check）
- **形式**：选择题 / 简答题 / 情境题
- **及格线**：70%（最低）
- **覆盖范围**：每模块核心概念 5-10 题

### 4.2 实操评估（Practical assessment）
- **形式**：实操演示（demo）或项目交付物（project deliverable）
- **评估人**：直属上级 + 培训师
- **通过标准**：能独立完成指定任务，错误率 < 10%

### 4.3 胜任力评分（Competency rubric）
- **维度**：3-5 个核心技能领域
- **量规**：1-5 分制
 - 1 = 不了解
 - 2 = 了解但需大量指导
 - 3 = 能独立完成
 - 4 = 能辅导他人
 - 5 = 能设计方法论/创新

## 5. 输出 3：完成追踪表

```
| 员工 | 模块 1 | 模块 2 | 模块 3 | 总进度 | 状态 |
|------|--------|--------|--------|--------|------|
| 姓名 | [OK] 92% | [OK] 88% |  进行中 | 60% | On Track |
| 姓名 | [OK] 85% | [!] 60% |  进行中 | 40% | At Risk |
```

**状态分类**：
- [OK] **On Track**：进度 ≥ 80% / 时间进度
- [!] **At Risk**：进度 50-80% / 时间进度
-  **In Progress**：进度 < 50% / 时间进度
- [X] **Overdue**：超过截止日期

## 6. 输出 4：合规培训要素（仅合规类项目必含）

合规类项目（如数据隐私、反腐败、信息安全等）需补充 4 元素：

1. **法规依据引用** — 明确列出对应法规条文（如《数据安全法》第 X 条 / GDPR Article X / HIPAA § X / OSHA Standard X）
2. **复证频率（Recertification）** — 年度 / 半年 / 一次性
3. **文档保留期** — 通常 3-5 年（按法规要求）
4. **审计轨迹格式** — 含完成时间戳 / 培训师签名 / 评估结果 / 反馈

**国内合规培训典型场景**：
- 数据隐私 / 个人信息保护（PIPL / 网络安全法）
- 反贿赂反腐败（《反不正当竞争法》/ 反舞弊）
- 消防与职场安全（《安全生产法》/ 消防法）
- 财务与税务合规
- 反洗钱（金融机构）
- 上市公司信息披露（董监高）

## 7. 输出 5：ROI 指标

4 类核心指标：

### 7.1 生产力加速（Time to productivity）
- **定义**：从培训开始到独立工作的天数
- **基线**：无培训时的典型 Onboard 周期
- **改善**：培训后缩短 X%

### 7.2 错误率下降（Error rate reduction）
- **定义**：培训前后错误率的对比
- **测量**：每千次操作错误数
- **目标**：下降 30%+

### 7.3 留存影响（Retention impact）
- **测量**：参与 vs 未参与培训员工的 1 年留存率对比（以企业自身数据为基准，不引用外部行业统计）

### 7.4 人均成本（Cost per employee）
- **定义**：项目总成本 / 参与人数
- **构成**：培训师时间 + 教材 + 平台费 + 学员工时成本
- **对标**：行业同类项目基准

## 8. 设计原则（10 条）

1. **模块时长 ≤ 45-60 分钟**（注意力甜区）
2. **每模块至少 1 个实操练习**（hands-on 不可省）
3. **反馈循环内置**（每模块后做小调查）
4. **快查卡片**（Quick reference cards）——训后支持
5. **30 天跟进评估**（衡量留存与转化）
6. **学习目标动词开头**（列出/设计/演示/实施，不用"了解/熟悉"）
7. **评估与目标对齐**（每个 learning objective 必须有对应评估题）
8. **时间估算包含练习**（理论 30% + 练习 70% 时间分配）
9. **资源清单提前 1 周**（账号 / 工具 / 教材到位）
10. **90 天整体回顾**（3 个月后做综合复盘）

## 9. 典型场景模板

### 9.1 新员工入职培训（30/60/90 天）

| 阶段 | 天数 | 主题 | 模块 |
|------|------|------|------|
| 入职前 | T-3 | 入职准备 | 1. 行政准备 / 2. 团队介绍 |
| 第一周 | Day 1-5 | 公司文化 + 基础培训 | 3. 公司业务 / 4. 制度与流程 / 5. 系统操作 |
| 30 天 | Day 6-30 | 岗位基础 | 6. 岗位胜任力 / 7. 业务流程 / 8. 协作工具 |
| 60 天 | Day 31-60 | 独立贡献 | 9. 项目实战 1 / 10. 跨部门协作 |
| 90 天 | Day 61-90 | 全面产出 | 11. 项目实战 2 / 12. 试用期评估 |

### 9.2 合规培训（如 PIPL 数据隐私）

| 模块 | 时长 | 内容 |
|------|------|------|
| 1. PIPL 基础 | 45min | 法规框架 + 适用范围 |
| 2. 数据分类 | 60min | 敏感/重要/一般数据 |
| 3. 用户权利 | 45min | 知情/同意/删除 |
| 4. 内部流程 | 60min | 收集/存储/共享 |
| 5. 案例分析 | 45min | 真实案例 + 处置 |
| 6. 评估与认证 | 30min | 测验 + 实操 |

**周期**：每年复证
**保留**：3 年
**覆盖率**：100%（全员）

### 9.3 领导力发展计划

| 模块 | 时长 | 内容 | 评估 |
|------|------|------|------|
| 1. 角色转型 | 2 天 | 从专家到管理者 | 360 反馈 + 教练对话 |
| 2. 团队管理 | 3 天 | 选/用/育/留 | 案例分析 + 实操 |
| 3. 业务思维 | 2 天 | 财务 + 战略 | 商业模拟 |
| 4. 跨部门协作 | 1 天 | 利益相关方管理 | 角色扮演 |
| 5. 行动学习 | 3 个月 | 真实项目 | 业务结果 |

**周期**：1 年
**形式**：Blended（面授 + 在线 + 行动学习）
**评估**：柯氏四级

### 9.4 认证备考（如 PMP / CISSP / 注会）

| 阶段 | 时长 | 内容 | 评估 |
|------|------|------|------|
| 1. 知识体系 | 8 周 | 全教材通读 | 章节测验 |
| 2. 专题精讲 | 6 周 | 重点/难点 | 模拟题 |
| 3. 冲刺刷题 | 4 周 | 历年真题 | 模拟考试 |
| 4. 查漏补缺 | 2 周 | 错题分析 | 1v1 答疑 |
| 5. 考前模拟 | 1 周 | 全真模拟 | 全真测试 |

**总时长**：21 周
**及格线**：模拟测试 ≥ 80% 持续 2 次

## 12. 不适用场景

- **纯 OJT（On-the-Job Training）**：走 talent-development 入职场景，不需本结构化框架
- **非正式分享会/读书会**：走轻量级知识管理，不需 ROI 追踪
- **高管定制培养**：走 IDP（个人发展计划）+ 教练对话，本框架过度结构化
- **新员工 1v1 Buddy 带教**：走 talent-development 场景 1（Day 1 时间线 + 30/60/90）
