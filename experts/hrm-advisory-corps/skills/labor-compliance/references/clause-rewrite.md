# High-Risk Clause Rewrite

> 标准定义：合规条款改写工作流与输出格式。引用方：labor-compliance。
> 前置条件：必须先完成风险诊断（见 `compliance-baseline.md`），再进入改写。

## 工作流

1. 读取风险发现与原条款
2. 识别目标文档类型与适用地区
3. 明确改写目标（三选一）：保守合规 / 兼顾企业管理弹性 / 员工友好表述
4. 起草更安全的条款文本
5. 解释修改了什么、为什么改
6. 列出落地动作

## 落地动作清单

更新模板 / 签署补充协议 / 履行民主程序 / 公示通知收集确认 / 留存证据 / 法务复核

## 输出格式（六段式）

```markdown
## 条款改写

### 原条款
> ...

### 风险
[诊断结论摘要]

### 建议版本
[改写后条款全文]

### 修改说明
- 改了哪句 / 为什么

### 落地实施建议
- 更新模板 / 签署补充协议 / 民主程序 / 公示 / 留证

### 法务复核
必需 / 建议 / 可选
```

## 改写目标说明

| 目标 | 适用场景 | 倾向 |
|------|---------|------|
| 保守合规 | 法定底线敏感场景 | 最小风险敞口 |
| 兼顾管理弹性 | 需要管理权空间 | 合规前提下保留弹性 |
| 员工友好表述 | 雇主品牌导向 | 沟通友好 + 合规 |

## 使用纪律

- 不得起草用于规避法定义务的条款
- 不得建议强迫员工放弃法定权利
- 涉及解除终止/工资扣减/罚款/违约金/竞业限制/员工权利 → 建议 HR/法务复核
- 地方规则可能有差异 → 标记"需要地方适配"
