# China Labor Compliance Pitfalls

> 与正篇 `compliance-baseline.md` 配套使用：正篇给 25+ 主题基线 + 风险分级 + 法规来源白名单，本篇给**高发误用**反例。
> 反例基于公开判例（中国裁判文书网 / 最高人民法院公报）整理，**禁止编造**。
> 高风险事项（解除 / 裁员 / 竞业 / 孕产 / 工伤 / 医疗期 / 派遣 / 集体争议）**必须**走 `legal_review: required`，反例库不替代法务复核。

## 1. 试用期超期（高发致命错）

### 1.1 反例（命中 P0）

```
劳动合同期限：1 年
约定试用期：6 个月
```

### 1.2 错点

违反《中华人民共和国劳动合同法》第十九条：
- 3 个月以上不满 1 年 → 试用期 ≤ 1 个月
- 1 年以上不满 3 年 → 试用期 ≤ 2 个月
- 3 年以上固定期限 / 无固定期限 → 试用期 ≤ 6 个月

> 本反例：1 年合同期 → 法定上限 2 个月，约定 6 个月**超出 4 个月**。

### 1.3 后果

- 由劳动行政部门责令改正
- 违法约定的试用期已经履行的，由用人单位以**劳动者试用期满月工资为标准**，按**已经履行的超过法定试用期的期间**向劳动者**支付赔偿金**（《劳动合同法》第八十三条）
- 实操中往往按 4 个月 × 试用期满月工资估算赔偿

### 1.4 修正方向

- 1 年合同 → 改试用期 1-2 个月
- 已超期部分按 4 个月月工资补差
- 重新签合同 / 签补充协议 + 一次性补偿
- 触发 `legal_review: required`

## 2. 竞业限制未付补偿（高发致命错）

### 2.1 反例（命中 P0）

```
竞业限制协议：离职后 2 年不得入职竞业公司
补偿条款：未约定 / 约定"按公司安排" / 约定低于离职前 12 个月平均工资 30%
离职后 3 个月：未支付任何经济补偿
```

### 2.2 错点

违反《最高人民法院关于审理劳动争议案件适用法律若干问题的解释（一）》第三十六条 / 第三十八条：
- 竞业限制期 **≤ 2 年** [OK]（本反例未超期）
- 补偿通常 **≥ 离职前 12 个月平均工资 30%**
- **超过 3 个月未付** → 劳动者可**单方解除竞业限制协议**（司法解释口径）

### 2.3 后果

- 劳动者解除竞业限制 → 公司无法追究违反竞业责任
- 已支付补偿若不足 30% → 差额需补 + 可能加付
- 触发 `legal_review: required`

### 2.4 修正方向

- 离职当日签发竞业限制**开始通知书** + 按月支付补偿
- 补偿金额公式：max(月工资 × 30%, 当地最低工资 × 某系数)
- 建立 HRIS 定时任务，到点未付即报警

## 3. 经济补偿金计算错误（高发致命错）

### 3.1 反例 1：月薪上限突破

```
劳动者月工资：50,000 元
所在地上年度职工月平均工资：30,000 元
按 N 计算补偿：N × 50,000 = 50,000 × N
```

- 错点：违反《劳动合同法》第四十七条第二款——月工资高于本地区上年度职工月平均工资 3 倍的，**按 3 倍计算**，且**年限最高不超过 12 年**。

### 3.2 反例 2：违法解除只给 N

```
实际：违法解除（无过失性辞退理由不成立）
按 N + 1 计算并支付
```

- 错点：违法解除 = **2N**，不是 N+1。
- 后果：差额需补，且劳动者可主张继续履行。

### 3.3 反例 3：未扣减代通知金情形

```
用人单位依据《劳动合同法》第四十条无过失性辞退
未提前 30 日书面通知
补偿按 N 支付（漏了 +1）
```

- 错点：N+1 中的 "+1" = 代通知金；只有未提前 30 日通知才需要。
- 若已提前 30 日通知 → 只付 N，不付 +1。

### 3.4 修正方向

- 准备计算清单：base 月薪 / 12 月平均 / 当地社平 × 3 倍上限 / 工作年限上限 12 年
- 区分"合法 N+1" / "违法 2N" / "合法 N（已提前通知）"三种情形
- 触发 `legal_review: required`（解除终止属于高风险事项）

## 4. 员工手册未经民主程序（命中 P0）

### 4.1 反例

```
公司单方发布《员工手册 v2.0》
未经职代会 / 全体职工讨论
无协商记录
```

### 4.2 错点

违反《劳动合同法》第四条：
- 制定 / 修订 / 决定直接涉及劳动者切身利益的规章制度或重大事项时，应当**经职工代表大会或者全体职工讨论**，提出方案和意见，与工会或职工代表**平等协商确定**
- 公示 / 告知劳动者（签收、培训记录、邮件回执等留痕）

### 4.3 后果

- 仲裁 / 诉讼中员工手册相关条款**不被采信**（如迟到扣款、绩效考核末位淘汰）
- 整个制度文档合规性坍塌

### 4.4 修正方向

- 走完整民主程序：草案 → 职代会讨论 → 协商修订 → 公示 → 签收留痕
- 所有修订版本归档（不可只留最终版）
- 触发 `legal_review: required`（涉及员工切身利益）

## 5. 加班费计算基数错（高发致命错）

### 5.1 反例

```
劳动合同约定月薪：10,000 元（未拆分基本工资 + 绩效）
加班费基数：当地最低工资 2,000 元
```

- 错点：加班费基数原则上以**劳动者正常工作时间的工资**为准，不应低于最低工资但也不应仅按最低工资。
- 各省口径有差异（部分省份允许约定但不得低于最低工资，部分省份必须按正常工资）。

### 5.2 修正方向

- 劳动合同拆分：基本工资（加班费基数）+ 绩效（浮动）+ 各类津贴
- 跨省项目必须标"适用城市 + 适用年度"，跨年度沿用前提示核对当年口径
- 触发 `legal_review: required`（如涉及历史欠补）

## 6. 常见假性合规（自欺欺人）

| 自欺 | 实际 |
|---|---|
| "我让员工签了放弃声明" | 放弃法定权利的声明无效（《劳动合同法》第二十六条） |
| "我们用派遣规避" | 劳务派遣仅限临时性 / 辅助性 / 替代性岗位，比例 ≤ 10% |
| "员工手册规定末位淘汰" | 末位 ≠ 不胜任，强制解除违法 |
| "试用期可以随便辞退" | 需证明不符合录用条件 + 已公示录用条件 |
| "我发邮件通知就算公示" | 需可证明送达（签收 / 培训 / 工会见证） |

## 使用纪律

- 反例命中 P0 / P1 必须触发 `legal_review: required`
- 反例库不替代法务复核，最终结论须由法务总监 / 员工关系总监签发
- 跨年度沿用前提示核对当年口径（社保 / 公积金 / 最低工资 / 高温津贴 / 残疾人保障金等）
- 地方政策差异须标"适用城市 + 适用年度"
