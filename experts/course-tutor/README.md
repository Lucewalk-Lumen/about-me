## 这是什么

「课程伴学」分两端，各装各的：

- **教师端（蒲公英）**——就是本包。你安装后连自己的腾讯文档，管名册、看学情、算平时分、出周报。
- **学生端（课程伴学精灵 · 耘知）**——学生在平台装一次即可，自己会自动找到你的课程中枢开始伴学。

**课程资料都在你自己的腾讯文档里**，你改完发布新版本，学生下次打开自动拿到最新内容——
你不需要打包、不需要发文件给任何人。本包不含任何服务端代码，也不保存任何密钥。

## 你能做什么

- **建课与名册**：说「带我完成首次设置」，按引导建好课程与数据中枢，导入本学期名册
- **看学情**：按学生、按教学周看谁学了、学到哪、卡在哪
- **学情看板**：一句话生成网页看板，包含十一块内容——总览、每人掌握情况、全班结构、
 教学周走势、学习环节分布、最卡的知识点、错因、活跃度、**学生分层（谁沉默、谁掉队）**、
 无人收敛的知识点、积分榜
- **平时分**：你定基础分与各环节权重，按你的口径算
- **周报月报**：按教学周生成，可直接回写到数据中枢
- **学情洞察**：谁连续卡住、哪里是共性薄弱、还差多少没覆盖
- **积分与排名**：按学习行为计分，期末排名、前三名奖励
- **结课归档 / 整库备份**：学期结束一键打包留存，或把全部数据导出到本机
- **发布课程版本**：改完资料发一版，学生端自动同步

## 三步上手

1. 在 WorkBuddy 里连接**你自己的**腾讯文档（设置 → 连接器 → 腾讯文档，用你的账号授权）；
2. 说「**带我完成首次设置**」——会先问你要开什么课、资料怎么准备，然后帮你在
 **你指定的知识库空间**里建好数据中枢（不会默默建在个人首页），最后问你要不要现在导入名册；
3. 导入名册后就能用了。包里自带的《组织学习理论》只是结构示范，不会动它。

## 学生怎么接入

你只需要做两件事：**把课程资料放进腾讯文档并共享给学生**，然后**发布课程版本**。
剩下的学生端自己做：

1. 你在腾讯文档里准备好课程材料、题库，把所在的知识库空间共享给学生；
2. 你说「发布课程版本」，登记好资料位置并发布；
3. 学生装好学生端，开场自动发现你的课程中枢，核验学号与姓名后开始伴学；
4. 你之后更新材料再发一版，学生下次打开自动同步——**不用重装、不用重发**。

> 学生的复习题来自你的题库，题库也走云端，你更新后发版即生效。

## 其他老师想用

直接让对方从平台安装「课程伴学专家」，连他自己的腾讯文档、说「带我完成首次设置」即可。
你不需要把任何东西打包转给他。

## 数据在哪、怎么流

- 所有读写都通过**你自己的腾讯文档连接器**，访问**你自己拥有**的两个文件（课程中枢 + 学情表）；
- 你是这两个文件的所有者，名册与学情都能读写；
- 学生只能**读中枢、追加自己的学情**；权限通过知识库空间共享来给；
- 学生追加的学情行**只有他自己和你能看到**，同学之间互相不可见。

## 偶尔读得慢或超时

单个文件偶尔会响应慢（提示形如 `code:102` 或超时）。**这不是文件坏了、也不是没连上**，
过一会儿或换种方式重试通常就好。本端的处理是：自动重试几次、必要时换一条通道再试；
写学情时会先确认有没有写进去，避免重复记录。全部重试都失败才如实告诉你「这次稍慢，稍后自动补上」。

> 注意：这种情况下**不要重建数据中枢**——重建会改变位置，反而要让所有学生重新接入，
> 代价远大于等一次重试。

## 想了解更细的口径

各环节怎么记分、学情怎么聚合、看板每块数据怎么算，包内都有对应的说明文档；
你也可以直接问伴学专家，它会把当前口径讲给你听。
