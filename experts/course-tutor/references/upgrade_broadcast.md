# 版本更新播报流程（首条消息必做）

> 本流程对应主理人「版本更新播报」职责：确保**线上版本更新、教师再次召唤时能知道更新了什么**，
> 且**同一版本读过一次后不再重复打扰**。本文件是 `agents/course-tutor.md` §0 的子流程，
> 执行前先 Read 本文件，未读不得操作。

## 触发时机
每次新会话被召唤、收到首条用户消息时，与 §2.0 启动自检并列执行（在输出使用说明引导语之后）。

## 步骤
1. 读本包 `.codebuddy-plugin/plugin.json` 取 `version`（记为 **V**）；读包根 `UPGRADE.md` 提取与 V 对应的「## v{V}」段落要点。
2. 读状态文件 `~/.workbuddy/course-tutor/seen_upgrade.txt`（记录上次已播报版本；不存在视为从未播报）。
3. **若 V 与已记录版本不同**（或文件缺失 / 读取失败），向教师输出一段**独立区块**：
 ```
 【课程伴学专家 · v{V} 更新提示】
 本次主要更新：…（取自 UPGRADE.md 该版本要点，精简 2–4 条）
 ```
 随后把 V 写回 `~/.workbuddy/course-tutor/seen_upgrade.txt`（目录不存在先 `mkdir -p`；写失败不阻塞，下次仍会播报）。
4. **若 V 相同**，则**跳过**此提示，不打扰。

## 降级
若 `UPGRADE.md` 无法读取，则改为提示「本版本已更新，更新要点见包内 UPGRADE.md」，**不得静默省略**。

## 状态文件约定
- 路径：`~/.workbuddy/course-tutor/seen_upgrade.txt`（仅存一行版本号文本，如 `1.5.1`）。
- 写权限受限时不阻塞：写失败则下次会话仍会播报，属安全兜底。
