# 课程资料授权与自动同步（教师职责与同步）

> 本文件是 `agents/course-tutor.md` §2.3 主菜单第 16 项的细则（**先 Read 再操作**）。
> **架构定位（v2.1 修订）**：共 **3 个包**——① 开发包（维护者优化功能用）、
> ② **教师端包**、③ **学生端**（②③ 上传 open WorkBuddy 审核，学生从平台安装，教师不分发任何文件）。
> 教师的工作只有两件事：
> **在腾讯文档建好资料 → 把课程中枢空间授权/邀请给学生**。打包与上平台审核是**开发者职责**（见附录）。

## 一、模型（三包 + 授权）

| 角色 | 职责 | 不做什么 |
|---|---|---|
| **教师** | 在腾讯文档建好全部课程文档（课程资料 / 名册 / 学情表）；建好**中枢文档并授予可编辑权限**，通过小程序 / 二维码 / 链接**邀请学生加入** | 不打包、不发布、不维护任何 zip |
| **学生** | 从平台安装学生端（一次）→ 在 WorkBuddy **连接腾讯文档 MCP** → **自动发现教师课程中枢空间** → 直接开始学习 | 不需要重装：资料更新**自动同步到本地** |
| **开发者** | 维护开发包；把教师端包 / 学生端上传 open WorkBuddy 审核 | — |

**中枢（hub）的本质**：教师建的一个**对外共享、并邀请学生加入的知识库空间**，内容是「学生所需的最小信息集合」——
课程清单、材料清单、Hub/Usage 的定位、版本戳。学生端**自动发现该空间**（`discover_hub.py` 遍历学生侧可见空间），
运行时自己找到全部内容。教师更新资料 → 版本戳变化 → 学生端自动拉取存本地。

## 二、教师侧操作（菜单 16 · 课程资料授权）

1. **建资料**（首次设置 §2.0.1 已完成数据中枢者跳过）：课程材料、名册、学情表都在腾讯文档；
2. **建课程中枢**（每门课一次）：由教师端脚本（`discover_hub.py` / 建课流程）在知识库空间落地该课的 Hub 文件（3 表：`roster` / `course_versions` / `agent_profiles`）与 Usage 文件（2 表：`usage` / `summaries`），并把定位写入学生端本地 `data_hub_config.json` 的 `courses.<course_id>`（键：`hub_file_id` / `hub_sheets` / `usage_file_id` / `usage_sheet`）——**脚本只落盘、不回显，教师无需手工记录任何定位 ID**；
3. **邀请学生**：通过小程序 / 二维码 / 链接把学生加入该空间（已授予可编辑）；学生在 WorkBuddy 中**连接腾讯文档 MCP** 即可使用；
4. **告知学生**：自己的学号 + 姓名（学生端首聊按 §1.1 双因子校验）；
5. **日常更新**：直接改腾讯文档里的资料并更新版本戳——学生端开场自动比对并同步，**无需教师做任何分发动作**。

> 教师侧**不出产任何 zip**。若教师提出「发布课程新版本给学生」之类的诉求，按附录口径引导：
> 打包与上平台审核由包维护者（开发者）完成，教师只需完成上面 1–5。

## 三、学生侧逻辑（学生端 · 平台通用版）

学生端（`course-companion`，**零预置课程信息**，`courses` 初始为空）运行时：

1. **首次**：在 WorkBuddy **连接腾讯文档 MCP** → `discover_hub.py` 遍历学生侧可见的知识库空间、自动发现教师课程中枢 → 读到课程清单 → 选课 → 双因子（学号 + 姓名）校验身份（形态 A，无兜底形态）；
2. **每次开场**：比对中枢「材料版本戳」vs 本地缓存 → 有更新才拉取（幂等）；
3. **更新落地**：学生端把新资料保存到本地缓存，取不到就回退上一版；
 只解析 `*.json` / `*.md`，**绝不执行**包内脚本——这就是「有更新，保存在本地，无需再次安装」；
4. **伴学**：与通用学生端同一套逻辑（苏格拉底引导 / 学情回流 / 会话收尾自动呈现「我的积分」）。

## 四、开发者附录（仅包维护者 · 教师无需关心）

- **学生端构建**：由维护者在源码仓用 `build_student.py` 产出**通用学生端**（零预置课程、不含任何真实定位，
 用于上平台审核），该脚本不随任何上架端分发，教师端无需接触；
- **三包分工**：
 | 包 | 来源 | 用途 |
 |---|---|---|
 | 开发包 | 本工作副本 `03-源码/course-tutor/` | 功能开发与优化（不分发） |
 | 教师端包 | 平台直接安装 | 教师连自己的腾讯文档即用 |
 | 学生端 | `build_student.py` → `dist/course-companion-2.2.2.zip` | 上平台审核，学生从平台安装 |
- 学生端为**平台通用端**：学生从平台安装，自动发现课程中枢；教师不需要分发任何文件给学生。
