# 全书课程内容建设指引（教师端）

> 配套：`../agents/course-tutor.md` § 2.0.1 第 4 步 A（现在就建）。
> 适用场景：教师提供了教材 / 讲义等**整本书规模的资料**，需要填充该课三件套
> （`config.json` / `knowledge_hub.json` / `socratic_testset.md`，可选第四件套 `quiz_bank.md`）。
> 小规模（单章试做）可直接照示例课结构写，不必走全流程；全书规模**必须**按本指引执行。

## 0. 资料取舍（先与教师确认口径）

拿到教师资料后先列清单、逐项问用途，**经教师确认后再动手**。以下是一次完整建库的处置口径：

| 资料 | 处置 | 理由 |
|---|---|---|
| 教材正文（详细版 md） | **唯一正文来源** | 内容最全、结构最规整 |
| 教学大纲 | 结构参照（章节 / KP 划分） | 与教材对齐 |
| 教学计划 | 排课序（单元编号依据） | 决定单元顺序 |
| PPT / 课件 / deck | 不用 | 内容已被教材覆盖 |
| 理论前沿 PDF | 不直接用 | 已被教材相应章整合 |
| 来源核验弱的补充素材 | 不用 | 出处不可靠 |
| 试卷 / 成绩 | 不入学生库 | 测评资料与学生库分离 |

## 1. 流水线（六步，顺序固定）

```text
1. 切分 教材按一级标题（如「## 第X章」）切为 N 个单章文件落 /tmp
2. 抽取 每章 1 个 general-purpose 子代理并行抽取（输入单章文件 + 输出格式契约，
 各写 /tmp/<course>_units/unit_XX.json）——并行度按章数定，4-6 个一批
3. 复核 主会话程序化复核各 unit_XX.json：篇幅上限（超限打回定点压缩）、
 字段齐全、kp_id 命名规范——发现超限逐处定位，两轮内收敛
4. 组装 python 脚本把各单元合并写入三件套（config / knowledge_hub / socratic_testset）
5. 交叉校验（见 §2 清单，全过才算建完）
6. 抽检 随机抽 1-2 个单元人工级复读（事实 / 表述 / 结构），向教师报告抽检结论
```

## 2. 交叉校验清单（程序化，逐项过）

1. **config <-> hub KP 集一致**：`config.json` 的 KP 清单与 `knowledge_hub.json` 的 KP 键集合完全相等（双向差集为空）；
2. **kp_id 全可追溯**：`knowledge_hub.json` 中全部 terms / cases 与 `socratic_testset.md` 中全部题目引用的 `kp_id` 都能命中 config 的 KP 清单（悬空 = 超纲，必须归位或删除）。**命中口径**：hub 的 `kp_id` 用 config 的**完整规范 id**（如 `KP-1.1-definition`）精确相等；testset 题面可写**唯一前缀式**（如 `KP-1.1`），但每个前缀必须恰好对应 config 里**唯一一条** kp_id（前缀有歧义 / 无匹配一律判不通过）；
3. **内嵌 JSON 块可解析**：testset / hub 中内嵌的 JSON 块逐一 `json.loads` 通过；
4. **题型模板一致**：每单元题目按固定题型模板生成（口径：每单元 4 题——比喻唤起 / 情境判定 / 对比辨析 / 迁移应用，布鲁姆理解 → 评价递进）；
5. **seq 全局连续（[!] 全书一盘账）**：`socratic_testset.md` 题目编号是**全书统一连续**的——
 **重排 / 增删题后必须全书重排一遍，禁止按单元各自从 1 计数**。
 按单元各自编号会破坏全局连续性，交付前须终检核对；
6. **重复术语合并**：跨单元同名 / 同义术语只保留一条权威定义（挂主讲章节的 kp_id），
 其余处引用不重复建条（去重后 106 条）；
7. **题库与引导题集分工**（若有 quiz_bank.md）：题库 = 测评用、**附答案与评分要点**；
 引导题集 = 伴学用、**保留「不给答案」设计**——两者不混同、不互相改写；
8. **四件套交叉引用**：config <-> hub <-> testset <-> quiz_bank 的 kp_id 引用全通过。

## 3. 事实保真（建库中的硬规则）

- 教材本身可能有错：引用外部事实（数据 / 年份 / 占比）时**先核实再写入**，
 核实结论与出处落本地档（如 `/tmp/<course>_review/fact_checks.json`）备查；
- 核对案例：教材写灯塔工厂中国占比「接近六成」，核实实为约 42%（截至 2025-09 全球 201 座中中国 85 座，
  来源：世界经济论坛 / 麦肯锡「全球灯塔网络」名单【实测】）——已修正；
 德鲁克《新型组织的出现》教材标注 1990，实际 1988 年 HBR——若交付物引用了该数据则须改；
- 术语书写统一（引号、序号全半角等）在组装阶段一次性规范化。

## 4. 增量修订（建完后的局部改动）

- 新增 / 删除 KP 或题目 → 触发 §2 清单**第 1、2、5 项全书重跑**（KP 集一致性 + 可追溯 + seq 全书重排）；
- 改动完成后提醒教师：**发布新课程版本**（§10.2）；如改了 quiz_bank.md：已上云的课程发版即生效（学生端自动同步，无需重打学生包）。
