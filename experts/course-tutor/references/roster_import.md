# 名册导入操作指引（教师端）

> 配套：`../agents/course-tutor.md` § 2 名册导入。

## 1. 文件格式

### 1.1 xlsx（推荐）

- 第 1 行：表头（必须含「学号」「姓名」两列，可有其他列）
- 第 2 行起：学生数据

| 学号 | 姓名 | 班级 | 邮箱 |
|---|---|---|---|
| 2024001 | 张三 | 2024-OBHRM | zhangsan@example.com |
| 2024002 | 李四 | 2024-OBHRM | lisi@example.com |

### 1.2 csv（备选）

```csv
学号,姓名,班级
2024001,张三,2024-OBHRM
2024002,李四,2024-OBHRM
```

支持 UTF-8 / GBK 编码（自动检测）。

### 1.3 xls（BIFF 老格式，仍会出现）

- 教师从教务系统导出的常是 `.xls`（BIFF 二进制，如「成绩登记表」）——**不要拒收，也不要让教师改后缀**；
- 解析库按扩展名选：`.xlsx` → openpyxl；`.xls` → **xlrd 2.x**（openpyxl 读不了 BIFF）；
 环境缺库时 `pip install xlrd` 装入当前运行环境（xlrd 2.0.2 可用）；
- **非标准模板先探测再解析**：成绩登记表常见「前几行是标题 / 课程信息、真正表头不在第 1 行」——
 先读前 5 行定位「学号」「姓名」表头的真实行列，再从表头下一行取数；列名是近似变体（如混排
 「学号/考生号」）按包含匹配；解析后仍走第 2 节流程（去重 → add_records → 回读验证）。

## 2. 导入流程

```text
1. 教师准备 xlsx/csv
2. 直连读 Hub `roster` 表全量（file_id = data_hub_config.json 的 hub_file_id，
 sheet_id = hub_sheets.roster；分页 limit ≤ 100 直到取完）
3. 按 (sid, course) 去重：已存在的跳过，仅对新增行调 smartsheet.add_records 写入
 - 写入字段均为文本列，**列标题为中文名**（2026-08-31 中文化）：学号 / 姓名 / 课程 / 来源 / 更新时间
 - 「更新时间」列日期型 / 带时区 datetime 均可：读取侧不解析该字段、按原样透传（仅作记录展示）
 - 「来源」填「导入」（测试演练填「测试」）
 - 「学情文件」列**不要写**：该列当前为空（通用版学生统一写共享 Usage 主文件，不再创建专属学情文件）
 自动回写（空 = 尚无专属文件，学情面板聚合时回退共享 Usage 主文件）
4. 统计并提示教师导入结果：
 - imported：成功写入条数
 - skipped：跳过条数（空行 / 重复 sid）
 - errors：错误明细（行号 + 原因）
```

> **写入分批**：行数多时 `add_records` 参数会很大——优先**分批提交（每批 ≤10 行）**；
> 若环境对超长单次参数仍报错，已知稳定解法：把参数 JSON 原样落盘 `/tmp`，由子代理读文件原样提交
> （34 行名册一次提交成功）。

## 3. 去重规则

- 同 course 内 `(sid, course)` 唯一
- 不同 course 视为不同名册（可重名）
- 重复 sid 计入 `skipped`

## 4. 常见错误

| 错误 | 原因 | 修复 |
|---|---|---|
| `missing required column '学号'/'姓名'` | 表头缺列 | 补列名 |
| `invalid xlsx` | 文件格式损坏 | 重新导出 xlsx |
| `empty file` | 文件 0 字节 | 重新上传 |
| 扩展名不在 xlsx / xls / csv 之列 | 扩展名错或文件损坏 | 让教师确认文件真实格式；`.xls` 走 §1.3 解析；**禁止让教师改后缀伪装成 xlsx** |
| BIFF 解析失败 / 表头找不到 | 老格式变体或表头不在前几行 | 按 §1.3 先探测前 5 行再定位表头；仍失败则向教师索要 xlsx/csv 导出 |

## 5. 学生端联动

- 名册更新后，学生端下次启动会**静默**直连读 Hub `roster` 表，按「学号 + 姓名」**双因子**校验
- 双因子命中 → 一句"你的学号已加入最新名册"+ 更新缓存
- **学号存在但姓名不匹配** → **停止伴学**：提示"学号 {{sid}} 与姓名不匹配，请核对后重新输入。若确认无误，请联系老师核对名册登记。"
- 学号不命中 → **停止伴学**：提示"你的学号 {{sid}} 不在最新名册内，无法开始伴学。请核对学号，或联系老师把你的学号导入名册。"

 > [!] **不是"仍可伴学"**。匿名轨已取消：学号 + 姓名双因子命中名册才能进入伴学
 > （学生端是独立分发的另一个包，其话术副本与本端无关）。
 > **两条话术**在 `references/socratic_agent_prompt.md` §10 与本文档 §5 必须**逐字一致**（学生端侧另有自己的副本，与本端无关）。

## 5b. 课程列务必填写（多课自动匹配依赖）

学生端启动时会按名册「课程」列与包内课程清单做**自动匹配**——同一学生多门课即名册多行。
「课程」列留空的行无法参与匹配（学生会被告知名册中无其课程记录）。

> **跨老师场景**：学生端是平台通用单包；同一学生可能接入**多位老师**的课程中枢——每位老师的名册
> 各自独立，本老师名册没有该生**不代表**其他老师处没有；学号在不同老师处也可能不同。
> 学生端自动发现多个课程中枢空间后按课程选课；各老师的名册/学情按各自中枢隔离，你只能看到自己名册与学情，学生的其他课程数据对你不可见。

## 6. 导出当前名册

教师端可直连读 Hub `roster` 表拉回全量名册，存为本地 xlsx 备查。

## 7. 删除名册行

单条删除：直连调 `smartsheet.delete_records`，传 `file_id = hub_file_id`、`sheet_id = hub_sheets.roster`、
`record_ids = ["<row_id>"]`（row_id 来自 list_records 返回）。

## 8. 测试号（教师验库用）

- **来源**：向导收尾（教师端 §2.0.1 第 8 步）自动播种 1 行——学号 `0000` / 姓名 `测试学生` /
 课程 = 该课 / 来源 = `测试`（逐课 1 行；该课已有学号 0000 则跳过不重复写）；
- **用途**：以**通用学生端**验库——从平台安装学生端、在该学生端会话里以
 `0000 / 测试学生` 双因子绑定身份，走完整流程：身份校验 → 课程自动匹配 → KP 伴学 →
 学情写入，逐环节验证建库正确性。
 > [!] 教师端**不打**学生专属包——任何在教师端尝试生成学生专属包的入口都会**安全失败、不产出任何包**；验库只用上述「平台安装学生端 + 双因子绑定」的通用路径。
- **统计豁免**：测试号名下的学情行「学号」= 0000，教师端 §4.2 聚合前过滤会剔除，
 不计入学情面板 / 平时分 / 周报——教师测试不会污染班级统计；
- **[!] 正式开课前建议删除**：学生端双因子只查「学号 + 姓名」，任何学生知悉 `0000 / 测试学生`
 即可绑定该身份进入伴学（不污染统计，但能看到课程内容并产生测试号名下的记录）。
 删除走本文档 §7（按 row_id 删该行即可，无需清理学情——其学情行本就不计入统计）。
