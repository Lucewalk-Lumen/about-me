# 课程伴学专家 · 参考细则（teacher_errors.md）

> 本文件是教师端主指令（`agents/course-tutor.md`）的外置参考细则，与主指令配套使用。
> 引用方式：`${CODEBUDDY_PLUGIN_ROOT}/references/teacher_errors.md`。

## 9. 错误处理

| 错误 | 处理 |
|---|---|
| **腾讯文档连接器不可用**（当前会话没有 smartsheet 工具） | **停止**：按 §2.0 输出「未连接到数据中枢（当前未同步）」，停在待连接状态 |
| 数据中枢文件不可达 / 无权限 | **停止**：提示确认已建库（§2.0.3）且共享权限正确（**不回显 ID**） |
| 建库中途失败（文件建了一半 / 定位未回写） | **不重复建**：重说「帮我建数据中枢」幂等续建——已存在的文件 / 子表自动跳过，只补缺失部分并回写定位（§2.0.3） |
| 需要对子表重命名（如把「智能表1」改名复用） | **不做**：连接器不支持重命名子表（会报 `40037`）——规范做法：新建命名表 + 删除旧的空「智能表1」（删除前先读取确认其为空，非空则向教师请示） |
| 定位 ID 仍是占位符且 `.env` 也没有 | **停止**：提示先建立自己的数据中枢（说「帮我建数据中枢」，见 §2.0.3） |
| 名册导入失败 | 提示具体哪行失败 + 不阻塞（继续导入其余行） |
| usage 查询无数据 | 提示「本周暂无学情」 |
| 课程版本未发布 | 提示「该课程暂无已发布版本」+ **主动引导转 §10.2** 发布 / 灰度——此时学生端该课不可选 |
| 智能体 0 个 | 提示「该课程暂无已发布智能体，请到专家中心发布智能体」 |
| 改表找不到 `record_id` / 改动目标不明确 | **停止**：先回读、复述、由教师指认（不变量 #8 / #9） |
| 结构化列写成原生数组 / 对象 | **停止并改写**：按文本发送序列化后的 JSON 字符串（不变量 #10） |
| 只改了 `状态` 未改 `适用对象`（或反之） | **停止**：两者必须成对写（不变量 #11） |
| `运行开关` 被整列覆盖 | **立即读回原值并补回**其他键（不变量 #12） |
| 课程版本号不是 `YYYY-MM-DD` 或留空 | **停止，不写表**：指出具体不合规处，请教师修正后重试（不变量 #13） |
| 教师要求「用灰度隐藏课程版本」 | **停止并纠正预期**：课程版本灰度不产生隔离，隐藏用 `状态=draft`（不变量 #14） |
| 学生反馈「暂无已发布智能体」但教师确认已发布 | **先查灰度，不要叫教师重新发布**：检查该智能体是否 `gray` + `gray_list` 不含该生（见 §10.1） |

**总原则**：通道不可用 → 停止，不做「降级空转」；局部失败不阻塞整批；改表操作遵循更严口径——数据不合规 → 停止，不写表。
**排障归因纪律**：报错后先核对「对象现状」（表 / 文件还在不在、值是什么）与「谁在什么时间动过文件」两类假设，再下结论——
**禁止按时间邻近性**把原因归给自己上一步操作（表被手动删除、被迁移改动，都可能与上一步无关）。
