# 课程伴学专家 · 参考细则（teacher_reports.md）

> 本文件由 `agents/course-tutor.md` 按无损分片拆出，**内容与原 SKILL 逐字一致**。
> 引用方式：`${CODEBUDDY_PLUGIN_ROOT}/references/teacher_reports.md`。
>
> **report 子表（懒创建）**：首次生成周/月报时，在 Usage 文件新建 `report` 子表（配置键
> `usage_sheet.report`，占位模板已预置）并回写定位；此后每次生成覆盖/追加该表，仅存聚合与匿名化内容。

### 4.4 信息转换分析（原始字段 → 教学洞察）

学情 `usage` 每行 11 个业务字段（列清单见学生端 data_plane.md §0.3（随学生包分发））是原始记录，面板 / 周报 / 平时分
是它们的**转换产物**。转换链路（两端口径必须一致）：

| 原始字段 | 转换产物 | 用途 |
|---|---|---|
| 学号 + 时间 | `sessions` = 去重 `(学号, 时间)` 数 | 面板「会话」列、周报「总会话数」（§4.1 / §6.2） |
| 知识点（每 KP 一行） | `kp_records` = 记录条数 | 面板「KP 行」列（§4.1） |
| 结果（已收敛/部分收敛/卡住） | `converged`/`partial`/`stuck` 计数 | 面板状态列、平时分权重输入（§5） |
| 周次 | 数据周锚定 | 周报按最新有记录的周次生成（§6.1） |
| 智能体 | 智能体使用分布 | 周报「智能体使用情况」（§6.2） |
| 环节（预习/复习/题目生成） | 分环节计分 | 平时分三维加权（§5） |
| 来源（学生端/教师端/测试） | 聚合过滤键 | 教师端行 / 测试行排除出统计（§4.2） |
| 幂等键 | 重试去重 | 网络抖动下去重，不改统计口径 |

> **白名单即契约**：学生端强制 11 业务字段白名单（+ 幂等键）（学生端 data_plane.md §0.3（随学生包分发）强制约束），任何不在白名单的字段
> （对话原文、姓名、成绩等）一律不写——既防隐私泄漏，也保证教师端聚合字段结构稳定、转换可预期。
> 字段结构以数据中枢实际列名为准（列均为文本列），写值一律按文本发送。

### 6.3 教师使用记录

报告生成后向 Usage `usage` 表 `add_records` 追加一条**教师使用记录**：

- 「来源」固定填 **`教师端`**（三值枚举 {学生端, 教师端, 测试} 之一；**不得**新造 `teacher_skill` 等取值）；
- 「学号」留空（教师无学号）——由 §4.2 过滤规则保证它不进任何统计；
- 「知识点」填「周报」；「周次」填报告锚定的数据周；「幂等键」= `sha1(时间 + 知识点 + 学号 + 来源)`
 （小写 hex，「学号」取空字符串参与拼接）；此记录**不计入平时分**。

### 4.5 学生端学习预警（功能十二）

教师按课在 Hub `term_config` 子表配置阈值（`warn_idle_days` 默认 `7` / `warn_deficit_ratio` 默认 `0.7`
/ `warn_enabled` 默认 `true`），学生端每次会话开场自检（不阻塞）用包根 `course_warn.py` 评估：

1. **超期未学**：该生 `summaries` 最后活跃距今天 `> warn_idle_days` → 提醒「第 N 教学周你已 M 天未学习」；
2. **需补学时**：本周（按 `teach_week`）累计 `时长` `< required_hours_per_week × warn_deficit_ratio` → 提醒补学；
3. **不骚扰**：同一预警 24h 内只提示一次（`course_warn.py` 按 `last_warn_time` 去重）；话术分级
 （首次轻提醒 → 连续两次升级提醒并给出口），不阻塞伴学；
4. **上行（可选）**：教师开启「学情异常上报」时，连续两周滞后的学生**匿名**汇总进周报异常模块
 （见 §6.2「需要关注」），仅聚合、不出个人名单。

> `course_warn.py` / `course_calendar.py` 随学生包根分发（与 `course_tdoc.py` 同级），由构建脚本注入。
>
> [!] **预警自动生效，不依赖老师先配置**：`term_config` 缺失或缺键时，`course_warn.py`
> **自动使用内置默认**（`warn_idle_days=7` / `warn_deficit_ratio=0.7` / `required_hours_per_week=3.0`）
> 照常判定。**不需要老师做任何配置就能收到「久未学习」「需补学时」提醒。**
> 教师调阈值只是为了「更贴合自己班」，不是「开启功能」的前置条件。
>
> 每次评估输出带`config_status`，据此可知预警为何没出：
>
> | `config_status` | 含义 | 是否需要老师处理 |
> |---|---|---|
> | `source: builtin_default` | 本次用默认阈值（老师未自定义） | ❌ 不需要，已正常提醒 |
> | `source: term_config` | 用老师配置的阈值 | ❌ 不需要 |
> | `source: disabled_by_teacher` | **老师主动把 `warn_enabled` 设成了 false** | 注意：若非本意，请改回 `true` |
> | `has_calendar: false` | 未录校历，按自然周计算 | 建议走 §2.0.6 录校历以对齐教学周 |
> | 无 `warnings` 且 `suppressed: true` | 24h 内已提醒过（去重） | ❌ 正常，不重复打扰 |

### 4.5b 学生数据可见性排查（教师端读到 0 条学情时必查）

**症状**：学生说「已经传了」，但学情面板 / 积分榜 / 看板读出来是空的。

按 §4.3 三段式读取时，**逐生定位解析结果必须可核对**，不允许「读不到就当没有」：

1. **名册「学情文件」列为空**（最常见）：
 - 该列**恒为空**（通用版学生统一写共享 Usage 主文件，不再创建专属学情文件）；
 - 为空时会**回退读该课共享 Usage 主文件**——这是正常路径，**但必须确认回退读到了行**；
 - **硬要求**：回退读取若返回 0 行，**必须明确告知教师**「该生在共享 Usage 里也没有记录，
 请确认学生端是否成功写入（连接器是否已授权 / 定位是否正确）」，**不得静默显示空面板**。
2. **定位不对**：确认 `courses.<course_id>.usage_file_id` 与 `usage_sheet.usage` / `summaries` 三者配套。
3. **被过滤掉了**（§4.2）：测试号 `0000`、空学号、教师端行会被剔除。若某生数据全被剔除，
 **告知剔除原因**，不要让教师误以为「学生没学」。
4. **连接器未授权**：学生会遇到「连接」卡；未点连接则写入根本没发生——此时应提示学生先连接。

### 4.6 学情洞察（掌握画像 / 匿名基准 / 异常预警 / 覆盖缺口 / 补练路径）

教师说「学情洞察」时，用包根 `course_mastery.py` 对该课 `usage` 表做**本地聚合**（口径同 §4.2 过滤）：

```
python3 "${CODEBUDDY_PLUGIN_ROOT}/course_mastery.py" insight \
 --usage <usage.json> [--prev-usage <上周 usage.json>] \
 [--kp-universe <知识点全集.json>] [--deps <知识点依赖.json>] \
 [--student <学号>] [--out insight.md]
```

输出五个模块（设计稿 对应 A/D/E/F/G）：

1. **异常预警（E）**：连续卡住学生（个人卡住占比 ≥ 50% 且 ≥ 2 行）、班级共性薄弱知识点
 （班级卡住占比 ≥ 50%）、活跃度骤降学生（本周会话数较上周降幅 ≥ 30%）——清单带学号，**仅教师可见**；
2. **班级掌握画像（A）**：每知识点 收敛/部分/卡住 计数与收敛率；
3. **匿名同伴基准（D）**：班级整体收敛率中位 + 每知识点班级中位；学生视角给「较中位领先/落后 N 个百分点」
 （仅聚合，不出他人名单）；
4. **内容覆盖缺口（F）**：提供 `--kp-universe`（JSON list 或 `{"kps":[...]}`）时列出未练到的知识点；
5. **补练路径（G）**：薄弱点「先补 X 再练 Y」——卡住多者优先，提供 `--deps`（`{"kp": ["前置", ...]}`）
 时按依赖拓扑排序（先补前置）。

> 隐私铁律：面向学生的输出只含聚合百分比与匿名基准，**不含任何他人名单**；异常清单仅呈现给教师。
> 未提供知识点全集 / 依赖时，F/G 对应模块自动跳过，不报错。
> 生成周/月报后可用 `course_report.py push` 把报告存址写入 Usage `report` 子表
> （`--kind` / `--period` / `--md` / `--csv`；设 `TDOC_PY` 后 `--exec` 经 `course_tdoc.py` 透传执行）。
