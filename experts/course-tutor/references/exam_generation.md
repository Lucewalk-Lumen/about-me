# 出题 / 组卷操作指引（教师端）

> 配套：`../agents/course-tutor.md` § 10.5。
> 输入 = 命题双向细目表 + 该课课程资产；输出 = 试卷（含答案与评分要点）+ 细目表对照表。
> 试卷只交付教师，不写任何智能表、不进学生包。

## 1. 细目表解析

### 1.1 样例结构（docx 样例：示例高校命题双向细目表 B 卷）

- 表头块：开课单位 / 课程名称 / 课程代码 / 命题老师 / 考试班级 / 学期学年；
- 主体为一张矩阵表：**行 = 知识章节**（教材章节 / 单元），**列 = 能力层次**
 （认识 / 理解 / 应用 / 分析 / 综合 / 合计分），**格 = 「题型 + 题量」（如「选择题 1题」）**，
 末行「合计」= 各能力层次题数 + 总分；
- [!] docx 的合并单元格在 python-docx 里表现为**同一文本在相邻格重复出现**——
 解析时先按行列**去重规范化**再读语义，禁止直接按网格坐标取值；
- 常见题型：选择题 / 简答题 / 案例分析 / 论述题；其他常见：填空 / 判断 / 名词解释 / 计算题。

### 1.2 输入形式与解析库

| 形式 | 处理 |
|---|---|
| docx | python-docx（缺库 `pip install python-docx` 装入当前运行环境） |
| xlsx | openpyxl |
| 口述 / 文本 | 教师直接说结构（如「单选 20×2 分 + 简答 4×5 分 + 案例 2×15 分，覆盖第 1-8 章」）——整理成矩阵后**向教师复述确认**再动手 |

解析产物 = 结构化清单：`[{章节, KP, 能力层次, 题型, 题量, 分值}]` + 合计校验值。

## 2. 出题素材与优先级

1. **优先复用**该课已有题——按 `course_versions` 表的「题集路径」列解析定位（云端 `tdoc:` 优先；包内相对路径仅旧形态兼容），按题型 / KP / 能力层次匹配读取；
2. 不足再**新编**——新编题约束：
 - 考点必须在 `config.json` 的 KP 清单内（**超纲知识点不进卷**）；
 - 难度对齐细目表能力层次：认识/理解 → 选择 / 判断 / 名词解释；应用/分析 → 简答 / 情境判定；综合 → 案例分析 / 论述；
 - 每题附**答案 + 评分要点**（评分要点到给分点粒度）；
3. 题干表述与该课 knowledge_hub 术语口径一致（同一概念全书一个叫法）。

## 3. 热点情境协同（新编情境题必做）

让卷子考「应用」而不是「背诵」：用**近 6-12 个月**的真实热点 / 企业案例做题干情境。

纪律（四条，不可协商）：

1. **热点为考点服务**：热点必须与细目表指定 KP 挂钩，先定考点再找情境——不能为热点而热点；
2. **事实保真**：题干引用的数字 / 时间 / 主体一律经网络搜索核实；**任何带时效的统计（占比、排名、数量）都必须以现场搜索到的最新来源为准，不得沿用任何历史记忆值**；
 核实不到的数字**不写**。（示例教训：某类统计若凭印象写「接近六成」即失实——正确做法是现场搜索核实后再写，并在题干标注来源与统计时点。）
3. **来源标注**：情境化题干末尾加一行来源（格式同学生端联网模板：`资料来源：<标题>（<域名>，<日期>）`）；
4. **隔离**：搜索结果、检索串、来源 URL 一律**不入学生库、不写任何智能表、不落课程资产**。

## 4. 程序化校验（交付前必过，不过不出卷）

| # | 校验项 | 判定 |
|---|---|---|
| 1 | 逐格对细目表 | 每个格的题型 / 题量与细目表一致 |
| 2 | 分值合计 | 各题分值之和 = 细目表合计（通常 100 分）；各能力层次小计亦核对 |
| 3 | 考点可追溯 | 每题标注的 kp_id 全部命中 config KP 清单 |
| 4 | 题型模板 | 客观题选项完整、单选唯一答案、多选答案数 ≥2 |
| 5 | 答案齐全 | 每题有答案 + 评分要点 |
| 6 | 事实核验 | 题干中的外部事实有来源标注且经核实 |

校验不过 → 定位修复后**重跑全套校验**；禁止交付「大体符合」的卷。

## 5. 产出

- **试卷**：docx / markdown（教师指定；docx 走平台文档能力生成），含答案与评分要点（可按教师要求卷面 / 答案分册）；
- **细目表对照表**：逐格「要求 vs 实际」清单，任何偏差显式列出并说明原因；
- **不落库**：试卷与对照表只存本地交付，不写入 Hub / Usage，不进学生包；
 教师若要求把其中题目录入 `quiz_bank.md`（题库更新）→ 已上云的课程改云端文档并发版即生效，学生端自动同步。
