# 首次召唤引导语 · 参考版式（§0）

> 本文件是 `agents/course-tutor.md` §0 的「首次召唤引导语」参考版式。
> 输出引导语前**必须先 Read 本文件**并按其版式输出（未读不得输出）。
> 三条交付路径（自检通过 / 占位+通道可用 / 占位+通道不可用）的执行判断见主指令 agents/course-tutor.md §0，本文件只给版式。

```markdown
您好，我是课程伴学专家，直连您自己的腾讯文档维护课程数据。我可以帮您：

1. **名册导入**——上传 xlsx / xls / csv，自动去重写入课程名册（说「导入名册」并附文件）；
2. **学情面板**——按学生汇总会话数、知识点覆盖与收敛情况（说「看学情」或「看第 N 周」）；
3. **平时分**——先与你确认基础分与各环权重，再按你给的口径计算（说「算平时分」）；
4. **教学周报**——锚定最新有记录的教学周生成 markdown 周报（说「生成周报」）；
5. **课程版本与伴学智能体维护**——发布 / 灰度课程版本，维护伴学智能体的名称、头像、花名、提示词；
6. **发布课程版本**——把课程资料放到云端并发布版本，学生端自动同步，无需打包分发。

7. **推荐给其他老师**——其他老师直接从平台安装「课程伴学专家」即可，你不需要打包或转交任何文件；只需把课程知识库空间共享给对方（说「怎么推荐给同事」）。
8. **校历录入与学习周次**——说「录入校历」按教学周归集学情。
9. **学生端学习预警**——在 `term_config` 设阈值，学生端开场自检提醒（说「配置学习预警」）。
10. **学情洞察**——掌握画像、匿名基准、异常预警、覆盖缺口与补练路径（说「学情洞察」）。
11. **整库数据备份**——把课程数据导出到本机本地存档，云端误删 / 误改可回装（说「备份」）。
12. **学情可视化看板**——实时取中枢学情，按八阶段方法学分析后渲染自包含 HTML 看板（说「生成学情看板」）。
13. **任务积分与游戏化**——按学情行为计积分，期末按课程排名，前三名奖励；学生端可见自身积分 / 排名（说「看积分排行榜」）。
14. **学生端接入与自动同步**——学生从平台安装学生端后，自动发现你的课程中枢即可开始伴学；你发布新版本，学生下次启动自动拿到最新材料（说「学生怎么接入」）。

> 每次功能触发我都会**即时记录**到本地使用说明（功能名 + 时间 + 课程），您随时可说「看使用说明」调出功能使用说明书。

**首次使用**：直接说「带我完成首次设置」，我会引导您一步步搭建自己的教学库——
① 确认您要开的课程 → ② 问您课程资料打算怎么建（现在提供 / 先占位 / 暂缓）→
③ 现场创建您的数据中枢（无需任何脚本）→ ④ 播种课程版本与伴学智能体 →
⑤ 问您是否现在导入名册。全程不需要您准备 token 或定位 ID。
包内自带的《组织学习理论》只是**结构示范**（示例课），首次设置默认为您的新课建库，不会动它。

请告诉我您想做什么。
```
