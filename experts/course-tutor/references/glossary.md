# 课程伴学 · 术语表（glossary.md）

> 本文件是**产品术语的唯一真源**。全包 主指令 / README / 参考细则 / 学生端模板遇到下表术语时，
> 一律使用「规范写法」，不得使用「旧词 / 非规范写法」。发布前会自动扫描文档，
> 出现「禁止词」即视为术语不合规，须改正后再发布。
>
> 本文件自身作为「禁止词的示例说明」而包含禁止词字符串，故被门禁排除在禁止词扫描之外。

## 1. 核心产品术语（全包强一致）

| 规范写法 | 含义 | 禁止 / 非规范写法（门禁拦截） |
|---|---|---|
| **课程伴学**（产品名） | 本智能体产品总称 | 课程中枢伴学、课程伴学中枢、知识库空间 |
| **课程伴学（教师端）** | 教师使用的专家端 | 课程伴学专家（仅作 agent 职业名时可用，产品叙述中统称「课程伴学（教师端）」） |
| **课程伴学（学生端）** | 学生使用的伴学端（由 `student/` 模板产出） | 课程伴学精灵（如非特指学生端产物，统一改「课程伴学（学生端）」；**例外**：作 `agent_profiles` 默认智能体名称 / `teacher_admin.md` 播种值属特指允许） |
| **数据中枢** | 教师自己腾讯文档里的 Hub + Usage 两个智能表文件的总称 | 中枢、知识库空间、中枢文件 |
| **Hub 文件** | 数据中枢里的「名册 / 课程版本 / 智能体档案」文件 | 中枢文件、共享文件（易歧义） |
| **Usage 文件** | 数据中枢里的「学情 / 会话摘要 / 报告」文件 | 学情文件（特指学生专属文件时另说）、中枢文件 |

## 4. 口径备注

- 教学周 ≠ ISO 周：学情记录统一以 `teach_week`（如 `2026-秋-W3`）为准；未录校历时回退
 ISO 周（如 `2026-W39`）并标注「未对齐校历」。报告 / 预警均需携带教学周上下文，避免歧义。
- 「课程伴学专家」是 agent 职业名（`profession.zh`），与产品名「课程伴学」并存不冲突；
 产品叙述中统一称「课程伴学（教师端）」。

## 5. 数据与口径的三态标注约定

为保证「证据可溯源、统计不臆造」，本包对涉及数字的内容统一按三态管理：

- **口径定义**：本包所有百分比阈值——收敛判定（≥80% 已收敛 / 50–79% 部分 / <50% 卡住）、
 学情分层（领先 ≥60% / 跟进 30–60% / 掉队 <30%）、预警占比（卡住占比 ≥50% / 降幅 ≥30%）等——
 是**本产品算法的判定规则（口径）**，非外部统计推断，不构成对任何真实总体的断言，故不逐一标注。
- **【实测】**：标注此记号的数字为**已核验事实**，来源与截止日期随文给出
 （如灯塔工厂中国占比约 42%——截至 2025-09 全球 201 座中中国 85 座，
 来源：世界经济论坛 / 麦肯锡「全球灯塔网络」名单【实测】）。引用外部事实前先核实再写入。
- **【待验证】**：标注此记号的为**未核验项**，核实前不写确定性结论；凡引用外部数字 / 年份 / 占比，
 凡来源未经确证的，一律视为【待验证】处理。

> 简记：阈值是「规则」，不标；【实测】是「已证事实」；【待验证】是「未证待核」。
> 三者区分是教学场景「事实保真」门禁的一部分。
