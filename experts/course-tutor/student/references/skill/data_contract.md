## 7. 与教师端的数据契约

| 数据 | 写者 | 读者 |
|---|---|---|
| 名册 (roster) | 教师端 | 学生端（直读校验学号） |
| 学情 (usage，线上表名 `usage`) | 学生端（直连追加） | 教师端（读聚合；统计时过滤教师端行与空学号行） |
| 会话摘要 (summaries) | 学生端（直连追加） | 教师端（按学号查阅） |
| 课程版本 (course_versions) | 教师端 | 学生端（直读最新） |
| 智能体档案 (agent_profiles) | 教师端 | 学生端（直读选型） |

**隐私边界（务必向教师与学生讲清）**：

- **学情互不可见**：每个学生只能向 Usage 文件**追加**自己的行，无权读取其他学生的学情/
 摘要（权限来自**知识库空间**共享，且本端只调用 `add_records`）。某学生用 API 越界读取他人行
 属于平台共享权限层面的残余风险，非本端可控——教师侧对学情一律按学号隔离聚合，任何学生都看不到
 别人的收敛情况与摘要。
- **名册可见是班级设计**：名册（学号 + 姓名）对全班学生可见是刻意设计（学生需据此校验自己
 身份、确认同班），不属隐私泄露；若教师要求学号对同学隐藏，应改用「每人独立学情文件 + 不共享名册」
 的私密模式（非默认）。
- **教师侧看聚合**：教师只能看到按学号聚合的班级学情与周报，看不到任一学生的对话原文（摘要为
 抽象化转述，见 §7.2 隐私红线）。

### 7.1 安全模型（务必理解）

- 学生能访问的数据范围 = 老师通过**知识库空间**授予的权限（成员邀请或空间权限）：
 - **Hub 表（名册/课程版本/智能体档案）只读取**——本端对 Hub 一律只调用读取；
 - **Usage 表（学情/会话摘要）只追加**——本端只调用 `add_records`，不修改不删除已有行。
 - **可见性（空间行为）**：你追加的学情行**仅自己可见**，同学之间互相不可见，老师全部可见；
 - 即便拿到 Hub 的写权限（如空间「所有人可编辑」），本端也**不越界写**——行为约束在客户端层面独立于空间权限存在。
- 学生端**强制 11 字段白名单 + 幂等键**（`data_plane.md` §0.3 列清单），从客户端层面对抗越字段写入。
- 老师侧读取学情时会做字段校验、来源过滤与重复去重，作为兜底。
- 本端经腾讯文档**连接器**访问，授权属于你的账号，全程**不接触**老师的任何凭据。

### 7.2 定位 ID 保密（红线）

任何 `file_id` / `sheet_id`（`hub_file_id` / `usage_file_id` 及全部子表 ID）只属于包内
`data_hub_config.json` 与本地暂存文件——**不得**出现在与学生的对话、停止话术、错误提示、
日志，或任何写入云端表的内容中。空间发现产生的定位 ID 由脚本**只落盘、不回显**，
学生全程不见；授权属于你的账号，本端不保存、也不索取老师的任何凭据。
