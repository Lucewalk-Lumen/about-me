# 课程伴学精灵 · 参考细则（course_assets.md）

> 引用方式：`${CODEBUDDY_PLUGIN_ROOT}/references/skill/course_assets.md`。下文 `§` 编号沿用学生端 主指令 原有编号。

## 8. 课程资产

每门课最多 4 个资产文件位于 `references/courses/{{course_id}}/`（**路径前缀固定，不要写成 `assets/courses/`**）：

| 文件 | 作用 |
|---|---|
| `config.json` | 课程元信息（version、章节列表、KP 清单） |
| `knowledge_hub.json` | 知识中枢（章节要点、案例、术语） |
| `socratic_testset.md` | 引导式测试集（每章 3-5 个引导问题；**复习 / 预习**环节用） |
| `quiz_bank.md` | 测验题库（按单元分组、六类题型、每单元 9 题，附答案与评分要点；**「题目生成」环节的题源**，可选——示例课无此文件） |

### 8.1 路径真相源 = Hub `course_versions`（运行期优先 · 云端优先）

- **运行期**一律以 §1.2.2 读到的 `course_versions` 行的
 「配置路径 / 知识库路径 / 题集路径」为准；
- **该路径可能是两种形态，按顺序判别**（教师可混用，按逐课逐文件判定）：
 1. **云端定位**（新，**推荐**）：形如 `tdoc:<file_id>` 或 `tdoc://<file_id>`，
 或以 `http`/`docs.qq.com` 开头的文档链接——表示该资产已上云，
 **必须经腾讯文档通道（MCP `smartsheet` / 课程文档读取，或 Skill 形态 `course_tdoc.py`）读取最新内容**，
 **不再读包内文件**，教师改完材料发版学生即得最新；
 2. **包内相对路径**（旧，向后兼容）：形如 `references/courses/<course_id>/config.json`——
 从包内读取（教师包已含则读；未含则视为该资产缺失，如实回报，不静默跳过）。
- 云端读不到且包内也读不到时 → **如实回报该资产缺失，不静默跳过**——不另设注册表兜底；
 教师新建课程时应在 `course_versions` 登记**云端定位**。
- 路径前缀在包内形态统一为 `references/courses/{{course_id}}/`。
- **`quiz_bank.md` 现在也可上云**：登记为 `tdoc:<file_id>` 即走通道读，教师更新题库**不再需要重打包**；
 未上云时仍随包分发（旧行为，向后兼容）。
- **云端资产的「降级目标」= 本地下载缓存，不是包内旧文件**：内容直读不通（txt/json 托管）
 时走导出下载闭环——`python3 "${CODEBUDDY_PLUGIN_ROOT}/scripts/fetch_assets.py" --course <课程> --out-dir <取回材料目录>`，
 脚本完成 export_file → 轮询进度 → 签名 URL 立即下载 → **按资产角色规范命名**落盘
 （配置路径→`config.json`、知识库路径→`knowledge_hub.json`、题库路径→`quiz_bank.md`、
 题集路径→`socratic_testset.md`；json 家族过 json.loads 校验、md 家族拒 HTML 查看器页）。
 版本戳变化时重新执行刷新缓存。
> [!] **txt 资产直读不通是平台能力限制，不要乱撞接口（实测）**
> 托管为 txt 的课程资产（`*_knowledge_hub`、`*_config`）经文档接口直读**一律失败**：
> `doc.get_outline`（file_id 与 file_url 均试）→ `doc version error`；
> `manage.query_file_info` → `file type not support query`。**这是平台侧限制，不是配置错**——
> **不要**反复换 file_id / file_url / 换接口重试，**直接转导出下载闭环**（上一条 `fetch_assets.py`）。
> 全部取回路径都失败时的取材纪律：可基于 `kp_id` 与学科常识做引导，
> 但**必须如实说明取材来源**（「按知识点编号与学科常识取材，未取到知识库原文」），
> **不得**把推断内容当作知识库原文引述。

- **托管形态约定**：云端资产维持 **txt/json 托管**——`.md` 源文件由教师端转 txt 上传
 （上传 .md 可成功但**下载不回**，已核验）；学生端取回后按角色改名回 `.md/.json` 即可，
 内容字节等价，**不要**要求教师端改发布形态。

> **为何要两种形态并存**：`course_versions` 的路径列旧版本（v1.x）存的都是包内相对路径。
> 直接改语义会让已有课程立刻失效，因此**读取端先双判别、上云与否逐个迁移**，
> 迁移完一批再把旧形态的兜底逻辑摘掉（不在本期）。

### 8.2 版本演进

智能体提示词只引用上述路径/字段。教师在教师端编辑 → 发布 →
学生端启动时按 §1.2.2 / §1.2.3 拉取最新版本，**无需重新打包学生包**（资产已上云时）。
上云由教师在教师端完成——**学生端不需要、也不应该执行这一步**，学生端只读到的最新资产即可。

> **边界**：资产**未上云**时（`course_versions` 仍是包内路径），教师更新材料仍需重打包——
> 这时读取端读到的就是包内那份，不会自动变新。**想让学生端自动更新，先把该课资产上云。**

> 本包**不含任何预置课程资产**——所有课程材料均来自教师端通过课程中枢下发；
> 示例课（如教师端随包附带的《组织学习理论》示范课）仅供教师端建课参考，学生端零预置、不内置。
