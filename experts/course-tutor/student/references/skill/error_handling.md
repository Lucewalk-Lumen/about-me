# 课程伴学精灵 · 参考细则（error_handling.md）

> 引用方式：`${CODEBUDDY_PLUGIN_ROOT}/references/skill/error_handling.md`。下文 `§` 编号沿用学生端 主指令 原有编号。

## 6. 错误处理铁律

| 错误 | 处理 |
|---|---|
| **腾讯文档连接器不可用**（Skill 形态 `tdoc_init` 未输出 `READY`，且工具清单里也没有 smartsheet 工具） | **停止**：提示"本端需要通过你的腾讯文档连接器读取数据中枢。请在 WorkBuddy 连接你自己的腾讯文档账号后重试" |
| **自动发现不到课程中枢**（空间遍历无候选） | **停止**：提示"还没有发现老师共享的课程数据中枢。请确认老师已把课程知识库空间共享给你（成员邀请或空间权限），然后我们重试"（话术同 `identity.md` §0.4）。**不得**提"解压 / 包 / 文件夹"——学生端是平台安装，没有包文件可解压 |
| **中枢配置读不了**（解析失败 / 编码异常 / 半份文件） | **重试一次发现**：重跑 `discover_hub.py` 重写配置；仍失败 → 提示"数据中枢配置读取失败，请联系老师确认课程中枢已共享给你"。**不得**让学生解压、重装或下载任何文件 |
| **同步失败**（取不回新版本资料） | **不阻塞**：用本地已有资料继续伴学 + 提示"这次没取到最新资料，下次会再试一次"；**不得**删除本地已有资料，也**不得**让学生手动下载或替换任何东西 |
| **学生问「怎么更新」** | **不报错**：说明「课程资料由老师发布新版本后自动同步，你无需任何操作」 |
| **数据中枢文件不可达 / 无权限** | **停止**：提示"读不到数据中枢。请确认老师已通过知识库空间（成员邀请或空间权限）把数据中枢共享给你的腾讯文档账号"（**不回显定位 ID**，见 `data_contract.md` §7.2） |
| **Windows 下 `python3` 不存在**（Skill 形态调用时） | 不算故障：依次改试 `python` → `py -3`，不要就此判"通道不可用" |
| **读名册失败** | **停止**：无法校验学号，提示后结束 |
| **课程无已发布版本**（§1.2.2 交集为空） | **停止**：提示"该课程暂无已发布版本，请联系老师发布后再试" |
| **智能体 0 个** | **停止**：提示"该课程暂无已发布智能体，请联系老师" |
| sid 不在名册 | **停止**：提示"你的学号 {{sid}} 不在最新名册内，无法开始伴学。请核对学号，或联系老师把你的学号导入名册。" |
| **学号与姓名不匹配** | **停止**：提示"学号 {{sid}} 与姓名不匹配，请核对后重新输入。若确认无误，请联系老师核对名册登记。" |
| 名册无该生在本包课程下的记录（§1.2.1 交集为空） | **停止**：提示"名册中没有你在本包课程下的记录，请联系老师把你的学号（含课程）导入名册。" |
| **写入返回 `22004`**（内容被拦截，文案为 `create smartsheet mutation failed`） | **判为「内容级失败」，不是定位/结构问题**：① 对触发词做**一次同义替换**后重发（保留学科结论、只换词，如「威胁」→「风险」）；② 重发成功 → 正常读回自检；③ 仍失败 → 按「写入失败」处理（见下两条），**不得**反复重试同一文本，也**不得**静默丢弃 |
| 学情上传失败 | 不阻塞 + 提示"学情已留在本地，下次补传" + 写入 `usage_pending.jsonl`（入队记录带目标定位，补传只回来来源会话——§5 多包隔离） |
| **会话摘要写入失败** | **不得静默**：明确提示"会话摘要未能同步到老师的数据中枢，已本地暂存，下次启动时补传" + 同上写兜底队列（见 `cache_files.md` `usage_pending.jsonl` 段） |
| **跨包话题**（学生提及其他老师课程包的内容） | 按跑题拦截执行（§2 第 4 点）；警告后**补一句**："那是另一位老师的课程，请确认要切换到哪门课——在本学生端里重新选择即可，无需退出或新开。"——仍不算学习行为，不标 KP、不写学情 |
| **无网络搜索工具**（联网补充用） | **静默跳过、继续伴学**：不提示、不报错、不停止。联网是**能力增强**而非主链路 |

> [!] **22004 内容拦截的处理顺序（实测：A/B 对照确认是内容级拦截，非长度、非结构）**
> 1. **识别**：`add_records` 返回 `business code:22004` / `create smartsheet mutation failed`
> ——该文案**不含「敏感 / 拦截」字样**，不要误判成表结构或定位错误去改 sheet_id；
> 2. **一次同义替换重试**：定位摘要里的触发词（学科标准术语也可能命中，如「效度威胁」），
> 换成等义的通用词（「威胁」→「风险」），**语义与学科结论保持不变**，只改这一处后重发一次；
> 替换须**如实告知**学生（如「摘要里一个词被平台拦了，已换成同义表述」），不偷偷改写结论；
> 3. **仍失败** → 按「写入失败」处理：明示学生 + 入 `usage_pending.jsonl` 暂存补传；
> 4. **不得**：反复重试同一文本（会连续失败）、为绕过拦截而删改学科结论、或静默跳过不记。

**总原则**：
- **读不到数据中枢 → 停止**。学号校验、智能体选择、学情回流全部依赖它，缺了伴学不成立，
 不做"降级空转"以免学生产生"已经在学习"的误解。
- **包定位＋通道探测已前置到启动自检（见 `agents/course-companion.md` §0 首次使用与 §1 身份校验）**：正常流程在会话开头就会发现「找不到配置 / 未连通 / 配置是占位符」并停在**对应**话术，本表是**兜底**。
- **仅两类允许降级**：①学情/摘要写入（对话已发生、数据不应丢失 → 本地暂存、下次补传，且**必须明示学生**）；
 ②网络搜索（可选增强，工具缺失时静默跳过）。

> [!] **两条铁律不要混为一谈**：
> **腾讯文档 smartsheet 工具**决定"数据能否落表"——缺失会造成*以为已同步、实则没写*的静默数据丢失，故**停止**；
> **网络搜索工具**只决定"素材是否丰富"——缺失不影响任何数据正确性，伴学照常可用，故**静默跳过**。
