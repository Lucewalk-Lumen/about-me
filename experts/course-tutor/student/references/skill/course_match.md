# 课程伴学精灵 · 参考细则（course_match.md）

> 引用方式：`${CODEBUDDY_PLUGIN_ROOT}/references/skill/course_match.md`。下文 `§` 编号沿用学生端 主指令 原有编号。

### 1.2 课程选择（多课时 · 名册自动匹配）

课程对学生可见需要**同时满足两个条件**（缺一不可）：该生名册记录里有这门课 + 线上有已发布版本。

#### 1.2.1 名册课程 × 包内课程自动匹配

取 §1.1 名册命中条目的 course_id 集合 C（在某课名册命中即该生在该课有记录），
与 `data_hub_config.json` 的 `courses` 键（本包已定位课程集合 P）取**交集**：

- **交集恰 1 门** → **自动选中**，一句话告知即可（如「已根据名册自动匹配课程：《X》」），**不让学生选**；
- **交集 ≥ 2 门** → 仅展示交集内的课程让学生选 1 门（默认第 1 个）——名册里没有的课**不出现在候选里**；
- **交集为空** → **停止**："名册中没有你在本包课程下的记录，请联系老师把你的学号（含课程）导入名册。"

> **定位条目绑定**：课程确定后，本会话后续**所有**读写一律取
> `data_hub_config.json` 中 `courses.<course_id>` 条目的定位（该课独立的 Hub/Usage 文件）。
> 若该 course_id 在 `courses` 中**无条目** → **停止**："课程缺少数据中枢定位，请联系老师确认课程中枢已发布。"

> 课程清单以云端 `course_versions` 表为**运行期真相源**，教师发布课程版本即生效，学生端自动发现。
> 本端**不预置任何课程**（`data_hub_config.json` 初始 `courses` 为空）：
> 接入哪位老师的中枢，就看到哪位老师已发布的课程。

> **多老师 / 多课程（数据域隔离）**：学生端从平台安装一次，可接入多位老师的课程中枢；
> 每位老师的课程是**相互独立的数据域**，处理约定：
> - **一会话一课程**：本会话只服务当前选定的课程；要换课请明确说「切换到某某课」；
> - **跨课话题按跑题拦截**：在本课会话里提及其他老师课程的内容 → 按 §2 跑题拦截执行，
> 警告后**补一句跨课指引**（固定话术见 §6 话术表）——提示「那是另一位老师的课程，请确认要切换到哪门课」；
> - **学号缓存跨课复核**：`student_sid.txt` 是全局缓存，换课时按 §1.1 复核；
> 不同老师的学号可能不同，复核失败属正常——清缓存重新输入即可，不代表数据丢失。
> - **授权跨包复用（账号级）**：腾讯文档连接器授权属于**学生自己的账号**，一次授权所有包共用；
> 换包只换「从哪个包读课程清单与定位 ID」（§0 第 1 步读包内 `data_hub_config.json`），
> **不需要**重新授权。本端不含、也不允许保存老师的任何登录凭据。

#### 1.2.2 校验课程已发布版本

**用腾讯文档连接器读 Hub `course_versions` 表**，筛「课程」列 == 当前 course_id 且
「状态」列 ∈ {"published", "gray"} 的行（状态取值保持英文枚举）：

- **交集为空**（该课无任何已发布版本）→ **停止**：提示"该课程暂无已发布版本，请联系老师发布后再试"
- **交集非空** → 进入 §1.3；并记住该版本的「版本号」与三份资产路径（供 §8 使用）

```json
// smartsheet.list_records（has_more=true 时 offset 逐次 +100 翻页读全表）
{ "file_id": "<数据中枢配置：该课 Hub 文件>", "sheet_id": "<数据中枢配置：该课课程版本子表>", "offset": 0, "limit": 100 }
```
> 分页铁律同 `data_plane.md` §0.3：只读第一页就判「无已发布版本」是缺陷，必须翻页读全。

> 这一步打通后，`course_versions` 才真正成为**运行期真相源**：教师发布新版本无需重打学生包，
> 学生端下次启动即可读到新资产路径。

#### 1.2.3 课程资产版本优先级

1. 取 §1.2.2 命中的最新版本行，其「版本号」> 包内 `config.json` 的 `version` →
 提示「发现课程新版本 vX，是否切换」，学生确认后按线上「配置路径 / 知识库路径 / 题集路径」读取；
2. 未命中，或线上版本 ≤ 包内版本，或读取失败 → **回退包内资产**，正常运行，不中断伴学。
