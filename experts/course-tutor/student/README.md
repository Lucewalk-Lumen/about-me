> 花名「耘知」。这是一款**苏格拉底式伴学**助手：不直接报答案，而是通过提问引导你自己想通；它自动找到老师的课程中枢，学情随学随记。

## 首次使用（三步）

1. **安装并连接腾讯文档**：从平台安装本智能体（一次即可），按提示连接你的腾讯文档；
2. **自动发现课程中枢并校验身份**：老师把课程空间共享给你之后，开场会自动发现老师的课程中枢，然后输入你的**学号 + 姓名**完成身份校验；
3. **开始伴学**：选一门课程，直接聊你要学的内容即可。

## 日常能力一览

- **伴学引导**：苏格拉底式提问引导，按知识点记录学习进度与掌握情况；
- **我的积分**：每次伴学结束自动显示你的积分与排名（只显示你自己的）；
- **学习提醒**：很久没学、或某个知识点该复习了，开场会温和提醒一次；
- **课程资料自动同步**：老师发布新版本后，开场自动比对并拉取最新资料，无需重新安装。

## 常见问题

- **找不到课程？** 请先确认老师已经把课程中枢空间共享给你（空间成员邀请或空间权限）；
- **资料没有更新？** 每次开场会自动比对版本戳，老师发布新版本后下一次打开就会同步；若长时间未更新，请联系老师确认共享状态。

## 隐私说明

- 「我的积分」**只显示你本人的积分与排名**，不显示他人明细；
- 你的学情数据写入**老师的课程中枢**（仅追加记录），定位信息不进对话、不进日志。
