# 42 · 汇报规范与引用格式（M6）

> **一条硬约束贯穿全篇**：**所有数值只能来自用户自己提供的 `.out`。**
> 本分片只给**格式与结构**，不给任何示例数值、不代找文献、不代写讨论。

---

## 一、数值来源的三种情形（**唯一硬约束**）

| 情形 | 处置 |
|---|---|
| 用户给了 `.out`，且其中**有**该数值 | 引用，并注明来源区块（如「据 `MODEL FIT INFORMATION`」） |
| 用户给了 `.out`，但其中**没有**该数值 | 写 `<待填：XXX>`，**并告知该值应从哪个区块取** |
| 用户**未给** `.out` | 输出**纯骨架**，所有数值位留 `<待填：…>` |

**绝对禁止**：估算 · 由别的指标推算 · 用「通常约为」填数 · 生成看起来合理的示例值 · 把文献里的数值搬来充数。

> 违反任一条 = **P0-0a 编造统计结果**。这是本包最高危的红线，没有例外。

---

## 二、METHOD 段骨架

```markdown
### 2.x 分析策略

采用 Mplus <版本>（<用户自填或留待填>）进行<模型类型>分析，
估计方法为 <ESTIMATOR>，缺失数据采用 <处理方式> 处理。

模型拟合依据 <指标1>、<指标2>、<指标3> 综合判断；
判断标准采纳 <阈值来源，如：通行惯例 / 某文献 / 自持手册某页>。

<若为混合模型，追加：>
类别数依据 AIC / BIC / aBIC / LMR-LRT / BLRT 与熵值综合确定，
并保证各随机起点数下最优对数似然可复现（增加起点数后最优解不变）。

<若为多层模型，追加：>
报告组内相关系数（ICC）为 <待填>，以说明采用多层模型的必要性。
```

**逐句要求**
1. **版本必写** —— 语法侧基准 9.1 与输出侧实证区间 6.0–8.8 不可混用；正文写用户**实际用的**版本号（如 `8.8` / `9.1` / `9.1.1`）（`../../references/version-notes.md`）。
2. **估计器必写** —— `ML` / `MLR` / `WLSMV` / `BAYES` 的选择直接改变可比性。
3. **缺失处理必写** —— 默认 FIML；若用 `TYPE=IMPUTATION` 须说明插补次数。
4. **阈值来源必写** —— 说清是「通行惯例」还是「某文献」。**不得**把惯例阈值写成「Mplus 官方标准」（见 `21-fit-indices.md` §一）。

## 三、RESULTS 段骨架

```markdown
### 3.x <模型名> 结果

模型拟合可接受，χ²(<df>) = <待填>，p <待填>；
CFI = <待填>，TLI = <待填>，
RMSEA = <待填>（90% CI [<待填>, <待填>]），SRMR = <待填>。

<路径名> 的标准化系数为 <待填>（SE = <待填>，p <待填>）。
```

### 3.1 写法纪律（六条）

1. **χ² 必带 `df` 与 `p`** —— 单独报 χ² 不合格。
2. **RMSEA 必报 90% 置信区间**。
3. **写明是标准化解还是原始解**，两者**不可混用**。
4. **不写「假设成立 / 不成立」** —— 只写「结果与假设方向一致 / 不一致」，
   并提示需结合**效应量**与**置信区间**判断（显著性不等于实质意义）。
5. **未收敛不得报数** —— 若 `QUALITY OF NUMERICAL RESULTS` 显示未收敛，
   RESULTS 段应留空并说明原因（见 `22-reading-frames.md` §一）。
6. **占位符 `<待填：…>` 原样保留**，交付给用户填。**禁止填充**。

### 3.2 表格与呈现

| 对象 | 要求 |
|---|---|
| 拟合指标表 | 每行一个模型；列为 χ²(df) / CFI / TLI / RMSEA(90% CI) / SRMR / 信息准则 |
| 参数估计表 | 列含 Estimate / SE / Est./S.E. 或 p / 标准化解另列；**标明解的类型** |
| 混合模型表 | 追加类别比例、熵、BLRT/LMR p 值 |
| 多层模型 | 分层报告参数（within / between），并给 ICC |

> **不得**只给标准化解而不给 SE；**不得**把 `Est./S.E.` 直接当 p 值叙述。

---

## 四、混合模型专项汇报清单

按顺序检查是否齐全：

1. **类别数依据**：AIC / BIC / aBIC / LMR-LRT / BLRT 的对比结果；
2. **随机起点数**与「最优对数似然已被复制」的证据；
3. **熵值**与**平均后验概率**（`CLASSIFICATION QUALITY`）；
4. **类别比例**，并指出**最小类别占比**；
5. **三套类别计数**（基于估计模型 / 后验概率 / 最可能类别）—— 至少说明采用的是哪一套（见 `22-reading-frames.md` §2.3）。

## 五、审稿自查清单（**只列核查项，不作接受/拒稿判断**）

| # | 核查项 | 检查点 |
|---|---|---|
| 1 | 方法匹配度 | 研究问题 ↔ 模型类型 ↔ 数据结构 是否自洽 |
| 2 | 拟合完整性 | χ²(df, p) / CFI / TLI / RMSEA(90% CI) / SRMR 是否齐备 |
| 3 | 估计量一致 | 汇报的解类型与 `.out` 中的解类型是否对应 |
| 4 | 混合模型完整性 | §四 五条是否齐全 |
| 5 | 异常提示 | 是否出现非正定 / 鞍点 / 局部极大 / 未收敛（对照 `31-warning-taxonomy.md` A 组） |
| 6 | 汇报口径 | 缺失处理、样本量、软件与版本是否交代 |
| 7 | 效应量 | 是否仅报显著性而无效应量或区间 |
| 8 | 多层 | 是否报告 ICC 与分层结果 |
| 9 | 阈值出处 | 拟合阈值是否被误称为「官方标准」 |
| 10 | 数值可追溯 | 每个报告值的 `.out` 来源是否可指认 |

## 六、引用格式（只给格式，**不代找文献**）

### 6.1 Mplus 软件与手册

| 对象 | APA 7th 格式模板 |
|---|---|
| 软件 | `Muthén, L. K., & Muthén, B. O. (<年>). Mplus user's guide (<版次>). Muthén & Muthén.` |
| 某章示例 | 引 UG 章节时给出**章节号 / 页码锚点**，并写「请查阅自持手册」 |

> ⚠ **本包不内置官方手册 / PDF / FAQ 原文**（`INDEX_ONLY`）。
> 输出引用时**只给锚点**，例如：`据 Mplus User's Guide「ANALYSIS Command」章（自持第 8 版 p.603 起）` ——
> **不得**转述成手册原话当作引文。

### 6.2 文献引用

- 只提供 **APA 7th 的条目格式模板**（期刊文章 / 书籍 / 章节 / 预印本 / 学位论文）。
- **不代找文献、不生成看起来真实的文献条目**（伪造引用是学术红线）。
- 用户如给出真实文献，可代为**格式化**；用户未给时**留 `<待填：若无请删除>`**。
