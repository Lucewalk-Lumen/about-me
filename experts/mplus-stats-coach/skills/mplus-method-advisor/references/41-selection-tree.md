## 一、四类必问信息（缺一不可）

1. **研究问题**：估关系 / 分类型 / 建模轨迹 / 检验机制？
2. **数据结构**：横断 or 纵向（几波）；是否嵌套（几层、聚类变量是什么）
3. **样本量**：总 N；若嵌套另给**簇数**（簇数比总 N 更关键）
4. **测量尺度**：连续 / 二分 / 有序 / 计数 / 名义 / 删截 / 生存时间

## 三、决策树全表

| 数据结构 | 首选 | 关键前提 | 违反前提时 |
|---|---|---|---|
| 横断 · 潜变量 · 连续指标 | CFA / SEM / 路径分析 | 指标数与 N 匹配；正态性或改稳健估计 | 改用 `ESTIMATOR=MLR` 或考虑贝叶斯 |
| 横断 · **有序 / 二分指标** | CFA/SEM + `ESTIMATOR=WLSMV` | 有序变量按有序处理（类别 ≥ 3） | 类别过少时勿强行当连续 |
| 横断 · 潜变量**交互** | SEM + `XWITH` | **Tier D，参照极薄** | 明示降级；或退化为观测变量乘积（须说明代价） |
| 横断 · 分**类型**（指标分类） | **LCA** | 需枚举类别数、比信息准则 | 类别数不可识别时降类 |
| 横断 · 分**类型**（指标连续） | **LPA** | 同上 | 同上 |
| 横断 · 检验**机制** | `MODEL INDIRECT` / `MODEL CONSTRAINT` | Tier D（`MODEL INDIRECT` 仅 2 例） | 可用 `MODEL CONSTRAINT` 定义间接效应（34 例，Tier A） |
| 有序/计数/删截结局 | 广义 SEM（`CATEGORICAL` / `COUNT` / `CENSORED`） | 分布假设与链接函数选对 | 分布误设 → 改稳健估计 |
| 纵向 · 连续 · 轨迹 | LGCM | 波数 ≥ 3；时间编码明确 | 波数 < 3 → **不建议**做潜增长 |
| 纵向 · 分**类型**轨迹 | GMM / LCGA | 需多随机起点防局部极大 | 局部极大 → 增 `STARTS`；否则结果不可信 |
| 纵向 · 状态转移 | LTA | 需测量不变性检验 | 时点过少 → 先合并类别 |
| 嵌套（簇/层） | 多层模型 `TYPE=TWOLEVEL` | 须报告 ICC；**簇数不能太少** | 簇数个位数 → **不建议**做多层 |
| 嵌套 + 潜变量 | 多层 SEM | 样本量与簇数**都要**够 | 同上 |
| 嵌套 + 混合 | 多层混合 | Tier B（14 例）；层间类别结构复杂 | 谨慎，先做单层再扩 |
| 小样本 / 复杂模型 | 贝叶斯 | 须报告先验与收敛（PSR） | 先验过强会主导结论 |
| 缺失数据 | FIML（默认）/ `TYPE=IMPUTATION` | 说明缺失机制假设（MCAR/MAR） | 机制不明 → 做敏感性分析 |
| 交叉分类 | 交叉分类多层 | Tier B（10 例） | — |
| 生存 / 事件史 | 生存分析 | Tier C（6 例）→ 提示参照偏薄 | — |

## 四、必须给否定建议的场景

| 情形 | 结论 |
|---|---|
| **簇数个位数** | **不建议**做多层模型 —— 方差成分估计不可靠 |
| **样本量过小 + 类别数多** | **不建议**做 GMM / LCA / LPA —— 类别不可识别 |
| **波数 < 3** | **不建议**做潜增长模型；改横断设计或换问题 |
| **要「帮我跑一下看拟合」** | **拒绝**（本包不运行 Mplus），改给语法骨架 + 自行运行 |
| **只有 `.inp`，问结果如何** | **拒绝**预测结果（P0-0a）；只可做语法层检查 |
| **要求与 lavaan / AMOS / Stata 对比** | **不做**跨软件比较 |
