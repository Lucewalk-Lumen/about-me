### 1.2 `MODEL <标签>:` 变体（**标签不受限**）

实测出现 **21 种**标签，全部合法：

| 变体 | 份数 | 含义 |
|---|---:|---|
| `MODEL C1:` `MODEL C2:` `MODEL C:` `MODEL C3:` `MODEL C4:` | 19 / 19 / 8 / 6 / 2 | 多类别（mixture）**按类别分别建模** |
| `MODEL G2:` `MODEL G1:` `MODEL G3:` | 19 / 3 / 1 | 多组（`GROUPING`）**按组分别建模** |
| `MODEL CB:` `MODEL CG:` `MODEL CW:` `MODEL CU:` `MODEL CY:` `MODEL DZ:` `MODEL FEMALE:` | 4 / 5 / 2 / 2 / 2 / 4 / 4 | 标签为**用户自定的类别名或组名** |
| `MODEL 1988:` `MODEL 1989:` | 1 / 1 | 标签可为**纯数字** |
| **`MODEL PRIOR:`（单数）** | **1** | 与 `MODEL PRIORS` 等价，**单数合法**（`ug/ch5/mcex5.5part4.inp`，正文 `a1-a20~N(1.386,1);`） |

> **实现约定**：判段名用**宽松形态** `MODEL\s+[A-Za-z0-9_]{1,8}`，**不要穷举清单**——
> 穷举必然漏项（本轮即因穷举清单漏掉 `MODEL PRIOR:` 单数而误报）。

## 二、三种形态特性（**解析器必守**）

### 2.1 段名与内容**可同行**

```text
DATA:	FILE IS ex6.1.dat;
ANALYSIS:	ESTIMATOR = ML;
```

只认「段名独占一行」会把 `DATA` / `VARIABLE` / `ANALYSIS` / `MODEL` 大片判空。
**实测影响**：修正前 CFA/SEM 仅识别 14 例，修正后 **89 例**（差 6 倍）。

### 2.2 `TITLE` 是自由文本段

- **不需要分号**（由下一命令终止）。
- 补充集实测最长 **2661 行**（整段研究背景 + 文献出处 + 变量说明）。
- **段内出现的 `Sources:`、`Holzinger, K. J. & Swineford, F. (1939).` 等冒号行都是正文**。
  **在 `TITLE` 段内不得做任何段名判定**，否则会把正文当段名。

### 2.3 一条语句**可跨任意多行**

Mplus 允许在任意位置换行，语句以 `;` 结束。因此：

- **按 `;` 切语句，不要按换行切**（官方常见 `s1-s4 |\n f BY y1-y4;`）。
- **「语句中段漏分号」在无完整语法分析时不可判定** → 只能提示「请核对分号完整性」，
  **不得**当确定结论报出。

### 2.4 块标记 `%…%` 与语句的关系

`%OVERALL%` / `%WITHIN%` / `%BETWEEN%` / `%c#1%` 是**区块标记**，可出现在语句前。
解析时应先剥掉块标记、再用**非行首锚定**匹配：

- 用 `re.search` 而非 `re.match`（语句常以块标记打头）。
- 变量清单正则须加 `(?<!%)…(?!\s*%)`，否则 `%WITHIN%` 会被当成变量清单关键字，
  把块内首条语句吞成「声明」→ 形成**假绿**（掩盖真实缺口，比误报更危险）。

## 三、变量清单关键字（含缩写与单复数）

| 写法 | 份数 | 说明 |
|---|---:|---|
| `NAMES` / `NAMES ARE` | 519 | **唯一不可缩写**的关键字 |
| `USEVARIABLES` | 51 | 完整复数形 |
| **`USEV`** | 42 | **最短缩写，比完整形更常见** |
| **`USEVAR`** | 4 | 缩写 |
| **`USEVARIABLE`** | 1 | **单数亦合法**（`ug/ch9/ex9.16.inp`） |
| `CATEGORICAL` | 209 | 分类 / 有序指标 |
| `CLUSTER` | 78 | 聚类变量 |
| `KNOWNCLASS` | 9 | 已知类别 |
| `AUXILIARY` | 5 | 辅助变量，可带 `(e)` / `(m)` |

> **实现约定**：一律按**单数词干 + `S?`** 收录。
> 本轮实测的坑：只匹配 `USEVARIABLES` / `USEVAR` 会**漏掉 `USEV`（42 份）与 `USEVARIABLE`（1 份）**，
> 导致「引用未声明变量」规则在这些文件上**假绿**。

其他同类关键字（同规则）：`NOMINAL` `COUNT` `CENSORED` `SURVIVAL` `BINARY`
`DESCRIPTIVE` `WITHIN` `BETWEEN` `STRATIFICATION` `IDVARIABLE` `TSCORE` `WEIGHT`
`SUBPOPULATION` `MISSING` `LAGGED` `ALIGN` `CONTINUOUS` `OBSERVED` `CUTPOINT` `GROUPING`。

## 四、语法形态两处**易错写法**

| 写法 | 含义 | 实测例 |
|---|---|---|
| `s* \| y1 ON a1;` | **`*`/`@` 起始值写在 `\|` 左侧**（随机斜率给定起始值） | `ug/ch9/ex9.14.inp`、`mcex9.14.inp`，共 12 处 |
| `s1-s4 \| f BY y1-y4;` | **`\|` 右侧可直接 `BY` 定义潜变量** | 8 处，全在 Ch9：`ex9.19part1/2/3`、`ex9.26`、`ex9.27`、`ex9.40part2`、`mcex9.26`×2 |

不支持这两种写法会分别造成 `s*` 与 `f` 被判「未声明」的误报（实测 9 例）。

## 五、段序

**不存在「标准段序」。** 实测（519 份逐文件）：

- `ANALYSIS` 先于 `MODEL`：1 例
- `VARIABLE` 先于 `DATA`：1 例
- `PLOT` 先于 `OUTPUT`：1 例
- `MODEL POPULATION` 先于 `MODEL`：**蒙特卡洛输入的必然写法**（大量出现）

且 **62 类警告库中没有任何一类与段序有关**。→ **任何顺序都合法**。
仅在极罕见反序（上述三对，各约 1/519）时给 `INFO` 风格提示，**绝不当错误**。

## 六、区间语法（`-` 缩写）

| 形态 | 例 | 说明 |
|---|---|---|
| 数字后缀 | `y1-y15` | 展开为 `y1 … y15` |
| 单字母后缀 | `u1a-u1c` | 展开为 `u1a u1b u1c` |
| 混合 | `hd82-hd89` · `bin1-bin5` | 同数字后缀规则 |

**展开时须限定跨度上限**（如 `b-a < 2000`），否则笔误（`y1-y99999`）会撑爆内存。
