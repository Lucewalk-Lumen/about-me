## 一、A 类：通行惯例阈值（**引用时须说明这是惯例，不是本包实测**）

| 指标 | 良好 | 可接受 | 备注 |
|---|---|---|---|
| χ² | — | — | **对样本量高度敏感**，大样本下几乎必然显著。**必须与 df、p 同时报告** |
| χ²/df | < 2 | < 3 | 经验比值，学界未统一 |
| CFI | ≥ .95 | ≥ .90 | — |
| TLI | ≥ .95 | ≥ .90 | 〔异译〕NNFI |
| RMSEA | ≤ .06 | ≤ .08 | **报 90% 置信区间**；配 `PCLOSE` |
| SRMR | ≤ .08 | ≤ .10 | 连续指标 |
| WRMR | < 1.0 | — | 主要配分类指标 / `WLSMV` |
| AIC / BIC / aBIC | 越小越好 | — | **只在同类模型间比较**；混合模型定类数 |
| LMR-LRT / BLRT | p < .05 | — | k 类 vs k−1 类 |
| Entropy | ≥ .80 | — | 分类质量，越接近 1 越好 |

## 二、B 类：官方语料实测分布（**【实测】** · 来自 `case-facts.jsonl` 516 条）

**重要前提**：**516 条事实中只有 90 条含拟合指标（17.4%）**——官方示例多为蒙特卡洛模拟，
其输出不含常规拟合信息。以下分布仅基于**这 90 条**。

| 指标 | 非空 | min | 25% | **中位** | 75% | max |

| χ² | 87 | 0.000 | 4.319 | 23.536 | 63.815 | **1055.754** |
| df | 87 | 0 | 4 | 17 | 46 | 146 |
| p | 87 | 0.000 | 0.000 | 0.263 | 0.559 | 0.998 |
| CFI | 90 | 0.000 | 0.990 | **0.999** | 1.000 | 1.000 |

| AIC | 184 | −227.890 | 2771.269 | 7430.511 | 16453.979 | 269357.161 |

**达标比例（同 90 条）**：CFI ≥ .95 占 **80%**、≥ .90 占 **84%**；
TLI ≥ .95 占 **81%**；RMSEA < .08 占 **86%**；SRMR < .08 占 **85%**。

**稳健校正**：87 条含 χ² 的记录中，**36 条（41%）** 使用了稳健校正（`chi2_corrected = true`）
—— 与 `ESTIMATOR=MLR/WLSMV` 的主流用法一致。

### 2.1 ⚠ 使用 B 类的三条禁令（**极重要**）

1. **不得当「真实研究的参照区间」**：官方示例多基于**模拟数据**，
   拟合近乎完美（CFI 中位 **.999**、RMSEA 中位 **.010**）。
   **真实研究数据不可能达到这个水平**——拿它当验收线会得出「真实研究全都不合格」的荒谬结论。
2. **不得把极端值当异常报错**：TLI 最小值 **−27.754**、RMSEA 最大值 **1.378** 出现在
   少数模型不拟合或样本极小的示例中，属**合法输出**，不是解析错误。
   TLI 可小于 0、CFI 受限于 [0,1]。
3. **不得跨样本比较信息准则**：AIC/BIC 的绝对值依赖数据与模型规模（实测跨 3 个数量级），
   **只在同一份数据的同类模型之间比较**。

### 2.2 版本差异（**【实测】**）

按输出版本统计 CFI 中位数：`8.8` n=62 → **1.000** · `8` n=7 → 1.000 ·
`6.1` n=8 → **0.972** · `6` n=11 → **0.736** · `6.11` n=1 → 1.000。

> 低版本（`6`）样本的 CFI 明显更低，但**样本量太小（n=11）且与模型类型混杂**，
> **不能**据此断定「版本影响拟合指标」。标 **【推断待验证】**。

## 三、输出规则（**强制**）

1. **`.out` 中未出现的指标 → 只答「该输出未提供」**。**禁止估算、填补、或从其他指标推算**。
2. **引用阈值时必须写明出处**：是 §一 的惯例，还是 §二 的实测。**不得只说「一般认为」**。
3. **χ² 必须与 df、p 同时报**。
4. **RMSEA 必须报 90% 置信区间**（`.out` 的 `MODEL FIT INFORMATION` 有 `90 Percent C.I.`）。
5. **稳健校正要说明**：若 `.out` 显示 `Chi-Square Test of Model Fit ... with correction`，
   必须说明该 χ² 已做 Satorra-Bentler 类校正，**不可与未校正值直接比较**。
6. **不替用户下「拟合好/不好」的终局判断**——给指标读数 + 对照阈值 + 说明
   「是否可接受取决于研究情境与领域惯例」。
7. **不做「假设成立」判断**——只写「结果与假设方向一致 / 不一致」。

## 四、混合模型的定类数指标（**与结构方程拟合指标不同源，不可混用**）

| 指标 | 判读要点 |
|---|---|
| AIC / BIC / aBIC | 越小越好；**BIC 惩罚更重**，样本大时倾向更少类别 |
| LMR-LRT / BLRT | k 类 vs k−1 类的似然比检验；**BLRT 更稳**（需 `TECH14`） |
| Entropy | ≥ .80 尚可；**只反映分类清晰度，不用于选类数** |
| 类别比例 | **任一类占比过小（如 < 5%）需警惕**，可能是过度提取 |
| 局部极大 | `BEST LOGLIKELIHOOD VALUE WAS NOT REPLICATED` 警告 → **加 `STARTS`** 后重跑 |
| 对数似然 | 必须在**多个起点数下可复现**才可采信 |

**纪律**：定类数**不得只看 BIC**——须综合信息准则、LRT、熵值、类别比例与**理论可解释性**，
并**报告所有候选类数的结果**而非只报最终选定的那个。

## 五、常见误用（**回答时主动提醒**）

| 误用 | 为什么错 |
|---|---|
| 只报 χ² 就下结论 | χ² 对 N 敏感，大样本下必显著 |
| 用 CFI/TLI 单独判定 | 指标互相牵连，须成套报告 |
| 拿 AIC 跨数据集比较 | 绝对值不可跨样本比 |
| 把 Entropy 当定类数依据 | Entropy 只反映分类清晰度 |
| 只看 RMSEA 点估计 | 小样本下 RMSEA 置信区间很宽，须看 90% CI |
| 用官方示例的拟合水平当验收线 | 那是模拟数据，拟合近乎完美（见 §2.1 禁令 1） |
