# Mplus 统计教练(Mplus Stats Coach)

面向**心理学与教育学研究者**的 Mplus 统计教练：讲透语法、审查 `.inp`、判读输出、辅助选型、诊断警告与报错，并规范论文方法段与结果段的写法。

**本智能体不运行 Mplus。** 它给出的是可核验的讲解、可复核的检查与可追溯的写作骨架，最终运行与数值以使用者自己的运行结果为准。

---

## 一、它能做什么（六个模块）

| 模块 | 用途 | 典型提问 |
|---|---|---|
| **M1 语法讲解与生成** | 逐段讲解 `.inp` 各命令段；生成可直接运行的语法骨架（含 CFA / 中介 / 调节 / 多层 / 潜剖面 / 潜增长 / 增长混合 / 贝叶斯） | 「这个模型语法怎么写」 |
| **M2 `.inp` 纠错** | 静态检查语法层问题，输出行号、类型、原因与修法 | 「帮我看看这段语法哪里错了」 |
| **M3 输出结果解读** | 按固定区块解读 `.out`：拟合、参数、数值质量、类别计数等 | 「这份输出怎么读」「拟合达标吗」 |
| **M4 统计方法选型** | 按研究问题与数据结构走决策树，给至多三个候选方法与前提假设 | 「我该用横断还是纵向」「样本量够吗」 |
| **M5 警告与报错** | 警告按类解读并给修法方向；报错按阶段分流定位 | 「这个警告什么意思」「为什么跑不出来」 |
| **M6 论文写作** | 生成 METHOD / RESULTS 段落骨架与审稿自查清单 | 「METHOD 怎么写」「论文里怎么报拟合」 |

## 二、它不做什么（边界）

1. **不运行 Mplus** —— 不产出任何"已运行验证通过"的结论。
2. **不内置官方原文** —— 不提供 PDF、`.out` 原文、示例数据文件；只给提取后的事实与自撰讲解。
3. **不替使用者编造数值** —— 论文骨架中的数值一律留占位符，由其自行填入。
4. **不代找文献** —— 只提供引用格式。
5. **不做跨软件迁移** —— 不涉及其他统计软件的等价写法。
6. **不背书使用者的数据结果** —— 学术判断以使用者自己的分析为准。

## 三、怎么用

把问题直接说出来即可。以下三类信息给得越全，回答越准：

1. **研究问题与数据结构**（横断 / 纵向几波 / 是否嵌套）；
2. **样本量与变量测量尺度**（连续 / 二分 / 有序 / 计数 / 名义）；
3. **手头有什么** —— 是只有语法，还是已有输出结果。

若已有 `.out`，请把相关区块一并给出，以便解读有据可依。

## 四、语料与出处

本智能体的讲解建立在**公开可下载的官方 Mplus 输入示例**之上，覆盖官方手册第 3–12 章示例与补充示例，涵盖 21 类模型族；警告解读建立在对官方配对输出的逐条整理之上。

**数据来源声明**（便于逐项核对）：

| 用途 | 依据 | 口径说明 |
|---|---|---|
| 语法权威 | Mplus **9.1 语言代次** · `Version 9.1 Mplus Language Addendum` | 官网当前最新版本号为 **9.1.1**（2026-09-16），属**补丁**、不改语言特性 |
| 命令段与页码锚点 | Mplus **Version 8 User's Guide** | 官方指引中该手册与 9.1 Addendum **并列**，故仍为准 |
| 输出解读实证 | 官方 **555** 份配对输出的逐文件解析 | 版本区间 **6.0 – 8.8** |
| 报错诊断 | 官方 FAQ **条目标题**索引 | 官方输出语料中**无报错样本** |

版本历史与手册入口：`https://www.statmodel.com/verhistory.shtml` · `https://www.statmodel.com/usersguide/`。

所有引用均给出可核验的出处。对官方手册，只给章节与页码锚点，请以**自持版本**核对，不在包内转载原文。

**已知的实证空缺（会主动告知）**：

- 官方示例输出中**没有报错样本**，因此报错诊断只能给出方向性提示，并会明确标注"未经真实运行复现"。
- 输出侧实证版本区间为 **6.0 – 8.8**；若使用的是 9.x 版本输出，本智能体会**显式告警并降级解读**。
- 部分方法族**可对照的官方示例有限**（如潜变量交互、中介的特定写法），此时会主动声明参照有限。

## 五、验证状态

包内所有数字均有实测出处，并标注为**已验证 / 推断待验证 / 缺失**三态之一。
静态检查工具通过**双向证明**：既有"不误报"的全量基线检验，也有"不漏报"的故障注入检验。
