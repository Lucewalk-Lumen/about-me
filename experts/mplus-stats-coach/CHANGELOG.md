# 更新日志

本文件记录各版本的功能变化。版本号以插件清单为准。

---

## 1.0.0

首个发布版本。

### 新增

**语法层**

- Mplus 语法逐段讲解：`TITLE` / `DATA` / `VARIABLE` / `DEFINE` / `ANALYSIS` / `MODEL` 及其各类变体段、`OUTPUT` / `SAVEDATA` / `PLOT` / `MONTECARLO`。
- 语法骨架生成，覆盖验证性因素分析、中介、调节、多层、潜剖面、潜增长、增长混合、贝叶斯等常见模型。
- `.inp` 静态检查：输出问题所在行号、严重级别、原因与修改建议；可选提供数据字典以启用数据层检查。
- 估计量与模型类型选择指引，含兼容性说明。

**输出层**

- 输出结果的区块化解读框架：拟合信息、参数估计、数值质量、类别计数、分类质量、技术输出等。
- 拟合指标解读：区分通行惯例阈值与官方示例实测分布，并对每类指标给出使用限制。
- 警告解读：覆盖官方示例中出现的全部警告类型，按处置优先级分组，并说明每类的成因方向与修法。
- 报错诊断：按故障出现的阶段分流定位，并给出取证据的标准动作。

**方法层**

- 统计方法选型决策树：按研究问题与数据结构给出至多三个候选方法，附前提假设与官方示例参照。
- 参照精度分层：按可对照的官方示例数量分层，样本有限的方法会明确声明。
- 选型决策路径图：把「四类必问信息 → 六条分流 → 三道输出闸 → 硬否定场景」绘成一张可直接用于讲解与讲义的图。
- 论文写作规范：METHOD 与 RESULTS 段落骨架、表格呈现要求、审稿自查清单与引用格式。

**工程层**

- 包级门禁校验，覆盖结构、硬指标、内容红线、跨层一致性、声明字段与文件卫生六个维度。
- 知识索引与事实分层，支持按需检索而非整库加载。

### 资料依据

- 语法权威取自 Mplus **9.1 语言代次**（官方 `Version 9.1 Mplus Language Addendum`）；命令段与页码锚点取自 **Version 8 User's Guide**。
- 输出解读的实证底稿为官方 **555** 份配对输出，版本区间 **6.0 – 8.8**。
- 官网当前最新版本号为 **9.1.1**（2026-09-16，属补丁）。
