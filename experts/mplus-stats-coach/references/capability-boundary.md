> 用途：回答「你能不能做 X」时，**先查本表再回话**。

## 二、六个模块的硬边界

| 模块 | 能做 | **不能做（必须明说）** |
|---|---|---|
| **M1 语法讲解与生成** | 生成 `.inp` 骨架（**≤120 行 / ≤4 KB**）；逐段讲解并给行号范围；硬守 **变量名 ≤8 字符**、**行宽 ≤90 字符**；单次最多引 3 个范例 | **不生成**需真实数据才能定的值（起始值、类别数）→ 只给决策规则；**不做**跨软件迁移 |
| **M2 `.inp` 纠错** | 语法层 **16 条规则**（L01–L16）；提供数据字典后加 **5 条数据层规则**（D01–D05）；输出含行号 + 类型 + 原因 + 修法 | **不判断收敛 / 拟合 / 参数合理性**（需真实运行）；**语句中段漏分号在无完整语法分析时不可判定**——不得当确定结论报 |
| **M3 输出结果解读** | 按 8 个固定区块解读；拟合阈值**固定引用** `21-fit-indices.md`；只用 **`facts_id != null`**（= 有配对 `.out`，等价于 `out_status != null`）的案例 | `.out` 未出现的指标只答「**该输出未提供**」，**禁止估算/填补**；**不**整份贴 `.out` 原文。⚠ 过滤只能用 `cases.jsonl` **实际存在的**字段（**不存在** `pair_confidence` / `unresolved_input`，不得臆造） |
| **M4 方法选型** | 单次给 **≤3 个**候选，各配 ≥1 实例 ID；前提不满足时**给否定建议** | 不做跨软件比较；不为用户的数据下最终结论 |
| **M5-a 警告解读** | 覆盖警告库 62 类 / 39 种消息；每类给实证案例 ID | 未命中**必须**声明「库未覆盖」 |
| **M5-b 报错诊断** | 走官方 FAQ 法理路径给自撰条目 | **无实证样本**：输出**恒定标注「未经真实运行复现」**；**不诊断**硬件 / license / 安装问题 |
| **M6 论文写作** | METHOD / RESULTS 段落草稿；数值**只能来自用户提供的 `.out`**，缺失留 `<待填：XXX>` | **禁止填充占位符**；只给引用**格式**，**不代找文献**；不代写讨论实质论断 |

## 三、静态校验的真实覆盖率（**P0-6 硬约束 · 三口径并列，禁止只报一个数**）

官方实测警告共 **62 类 / 39 种消息 / 219 条**。`check_inp.py`（仅 `.inp`，无 `--dict`）的覆盖：

| 口径 | 已实现 | 语法层**理论可预判** | 说明 |
|---|---|---|---|
| **类键数**（62） | **14（22.6%）** | 21（33.9%） | 类键 = 消息 + 回显片段，会分裂，**偏高** |
| **消息种类**（39） | **2（5.1%）** | **11（28.2%）** | 去重后的真实种类，**最有意义** |
| **出现条数**（219） | **30（13.7%）** | — | 按条数加权 |

> ⚠ **三个口径差别极大（5.1% ↔ 28.2%）**。任何覆盖率表述**必须写明口径**，
> 只抛一个百分比即为不合格表述。本包**不再使用**旧的「约 21%」单一数字（口径不明）。

**已实现的 2 种消息**：`Input line exceeded 90 characters`（L04）· `TECH8 option is available only…`（L10）。

**语法层可预判但尚未实现的 9 种消息**（下版候选规则，**不得**声称已覆盖）：

| 消息 | 可判据 |
|---|---|
| `STANDARDIZED (STD, STDY, STDYX) options are not available for TYPE=EFA` | `TYPE=EFA` + `OUTPUT` 要 STD* |
| `PATTERNS option is available only when there are missing data` | `OUTPUT PATTERNS` 但无缺失处理 |
| `TYPE=RANDOM is used to declare random effect variables… No random effect variables were found` | `TYPE=RANDOM` 但 MODEL 无 `\|` 随机斜率 |
| `AUXILIARY (E) CAN GIVE BIASED RESULTS…` | `AUXILIARY = x(e)` |
| `Duplicate: Y2 WITH Y1` | MODEL 段重复协方差 |
| `Y1 WITH Y1 has no effect` | MODEL 段 `x WITH x` 自指 |
| `TECH1 option is the default for multiple imputation` | `TYPE=IMPUTATION` + `TECH1` |
| `Values given in the MODEL command for EFA factors are used only as population values…` | EFA/ESEM + MODEL 段写值 |
| `Starting with Version 5, TYPE=MISSING is the default for all analyses…` | 版本信息类 |

**不覆盖的 28 种消息**：数据层（簇内无变异、缺失模式、变量间不相关、二分表空格 …）与
运行层（PSI 非正定、鞍点、`BEST LOGLIKELIHOOD NOT REPLICATED`、多次迭代异常 …），
需 `--dict` 或真实运行。

**提供 `--dict`（数据字典）后**：额外启用 **5 条数据层规则**（D01–D05）。

**两个实测硬阈值**：
- 变量名长度上限 **8** 字符 —— **语法约束**。依据：官方 519 份 `.inp` 展开 `NAMES` 后长度 1–8、**最大恰为 8**、**超限 0 个**（约 3,054 个变量名）。⚠ 因语料守规，`.out` 中**无截断警告样本** → 不得声称「必报」。
- 输入行宽上限 **90** 字符 —— **输出阶段截断警告**。依据：官方 `.out` 报出 **4 份**；但超限 `.inp` 共 **6** 份 → `ex5.28`（95 字符）、`ex5.32`（**131 字符**）均**未报** → ⚠ **阈值确证但触发不可预测**，不得承诺必报。

## 四、校验的**双向证明**强度（本包的实测成绩）

| 证明方向 | 断言 | 结果 |
|---|---|---|
| **绿向**（不误报） | 519 份未改动官方 `.inp` 必须 **0 BLOCKER / 0 WARN** | **519 / 519 PASS** |
| **红向**（不漏报） | 17 个故障注入器必须 **100% 命中**目标规则 | **17 / 17 = 100% PASS** |
| **反向**（不靠无脑告警刷召回） | 注入 TECH8-无TYPE 后，`--mplus-version 8` 下 L10 触发 **0** 次 | **PASS**（与官方 8.x 请求 TECH8 的 255 份实测 0 次一致） |

> **方法论纪律（必读）**：**全绿 ≠ 有效**。只有绿向通过**且**红向（故障注入）也命中，
> 才说明扫描器真的会报警。绿向单独通过，无法区分「没有错」与「扫描器根本没工作」。
> 同理，反向断言用来防「把规则放宽到永远报警」这种**刷召回**的假修复。

**耗时**：519 份基线 ≈ **1.2 s**；完整双向证明（含 17×519 次注入）≈ **24 s**。

## 四之二、参照精度分层（**Tier A–D，实测口径**）

「带结果的可对照样本」= 该族中 `kind=example` **且**有配对 `.out` 的官方示例份数。

| Tier | 带结果 example 数 | 措辞 |
|---|---|---|
| A | ≥ 25 | 参照充足 |
| B | 10 – 24 | 参照可用 |
| C | 3 – 9 | 参照偏薄（须提示） |
| D | ≤ 2 | 参照极薄（须明示降级） |

全表见 `../skills/mplus-method-advisor/references/41-selection-tree.md` §二。

> ⚠ **两条实测校正（此前说法无支撑，已更正）**
> 1. **LPA 属 Tier A，不是薄弱项**：连续指标潜剖面有 **25 份** official example，**全部带 `.out`**。
>    此前 `§五` 与 `mplus-method-advisor/SKILL.md` 中「LPA 带结果样本极薄」**不成立**。
> 2. **`XWITH` 是 4 份 `.inp`，不是「5 份语法 / 1 份带结果」**。其中 **2 份 example 带结果**，
>    且实测 `ex5.13.out` 的 `MODEL RESULTS` **含完整交互项**（`F1XF2 = 0.397, SE = 0.062, p < .001`）
>    → 有可用结果范式，降级理由是**样本数少**，不是「无参照」。

## 六、使用本表的硬规则

1. 回答「能不能做」之前**必须先查本表**；本表没有的能力 → 一律答「**不在覆盖范围**」。
2. 引用数字**必须**连同口径一起给（例：「519 份官方 `.inp` 实测」），不得孤立抛数字。
3. 本表与 `knowledge/INDEX.md` / `chapters.md` 冲突时，**以本表为准**（本表是运行时口径的汇总）。
4. 新增能力须同时更新本表与 `CHANGELOG.md`，二者不一致即视为未完成。
