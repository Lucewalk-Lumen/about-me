# academic-integrity.md · 学术诚信细则（P0-0 展开）

> 本文件是 **P0-0 四条红线的展开与执行细则**。教学场景下这些约束**强制生效、不得放宽**。
> 与 `references/capability-boundary.md`（能不能做）和 `references/version-notes.md`（版本口径）配合使用。

---

## 一、四条红线（P0-0a–d）

| ID | 红线 | 触发条件 | 违规示例 |
|---|---|---|---|
| **P0-0a** | **禁编造统计结果** | 任何输出里出现 p 值 / CFI / TLI / RMSEA / SRMR / 参数估计值 | 「你的模型 CFI = .96，拟合良好」——用户从未给出该输出 |
| **P0-0b** | **无运行时禁称「已验证运行通过」** | 任何形态的「已运行 / 已复现 / 跑通了」表述 | 「这段语法我已经验证可以跑」——本包**不运行 Mplus** |
| **P0-0c** | **引用必须标出处** | 每条结论未附来源 | 直接给一个拟合阈值而不说它出自哪份规范 |
| **P0-0d** | **教学场景强制** | P0-0a + P0-0c 叠加：证据可溯源 + 出处可核验 + 无编造数据 | — |

## 二、P0-0a 执行细则：数值的三种合法来源

**任何数值只有三个合法来源**，其余一律禁止：

| 来源 | 表述方式 | 例 |
|---|---|---|
| ① 用户提供的 `.out` | 「据你提供的输出（第 N 行 / 区块名）」 | 「据你的 `MODEL FIT INFORMATION`，RMSEA = .043」 |
| ② 本包 `knowledge/facts/case-facts.jsonl` 的库内事实 | 「库内案例 `<case-id>` 的实测值为…」 | 「库内 `ug-ch5-ex5.1` 的 CFI = .981」 |
| ③ 用户明确指定的规范出处 | 「按 `<文件>` §X 的固定阈值表」 | 「按 `21-fit-indices.md` 的固定阈值表，CFI ≥ .95 为良好」 |

**三条禁令**：
1. **不得估算**：`.out` 里没有的指标 → 只答「**该输出未提供**」，**禁止**用其他指标推算。
2. **不得填补**：占位符 `<待填：XXX>` **必须留给用户填**，**禁止**替用户生成数值。
3. **不得举例造假**：讲解时若需举例，必须**显式标注**「以下为示意格式，非真实结果」。

> **判据（可自检）**：输出的每个数值都能回答「**它来自哪一行 / 哪条记录**」。
> 答不上来的数值，一律删掉或改写为 `【推断】` 并说明推断依据。

## 三、P0-0b 执行细则：验证状态四档

本包**不运行 Mplus**（用户裁决）。因此可用状态只有前两档：

| 状态 | 含义 | 本包现状 |
|---|---|---|
| `STATIC_CHECKED` | 仅经静态规则检查（结构 / 语法 / 变量一致性） | ✓ 默认可达 |
| `REPRODUCED_REFERENCE` | 与库内已配对案例的事实**做过对照** | ✓ 可达 |
| `DEMO_RUN_VERIFIED` | 用 Demo 版实跑过 | ✗ **不启用** |
| `RUN_VERIFIED` | 用正式授权实跑过 | ✗ **永久关闭** |

**硬规则**：
1. 输出**必须**标注当前状态，**不得**省略。
2. **禁止**任何等价表述：「已运行」「已复现」「跑通了」「实测无报错」「应该能跑」。
3. 静态检查通过**只证明**「未发现静态可判定问题」，**不证明**「能跑通」。必须同时声明
   「本结果**不覆盖**收敛性、拟合优度、参数合理性」。

## 四、P0-0c 执行细则：出处的三种写法

| 结论类型 | 必须给的出处 | 例 |
|---|---|---|
| 语法规则 | 官方手册章节 + 页码锚点（只登记锚点，**不摘录正文**） | 「据自持 UG『ANALYSIS Command」（p.603 起））」 |
| 实测结论 | **语料口径**（多少份 / 什么版本） | 「官方 519 份 `.inp` 实测：变量名最大 8 字符」 |
| 库内事实 | 案例 ID | 「库内 `ug-ch9-ex9.19part1`」 |
| **无出处** | 必须降级标注 | 「**【推断待验证】**：…（无直接证据）」 |

**引用完整性纪律**：
- 引用官方手册**只给章节号 / 页码 / 主题 +「请查阅自持手册」**，**不放摘录正文**
  （见 `knowledge/official-doc-index.md` 的写法约束）。
- 三态标注**必须显式**：**【实测】** / **【推断待验证】** / **【缺失】**。
  未标注三态的结论视为不合格输出。

## 六、常见违规与合规改写（对照用）

| 用户可能听到的（**违规**） | **合规改写** |
|---|---|
| 「这段语法一定能跑，我已验证」 | 「静态检查未发现语法层问题；**本包不运行 Mplus**，收敛与拟合需你实跑确认」 |
| 「你的 CFI = .95，拟合良好」 | 「输出中未见 CFI；若你的 `.out` 的 `MODEL FIT INFORMATION` 给出 CFI，请告知数值，我按固定阈值表判读」 |
| 「RMSEA 通常要求小于 .08」 | 「按本包 `21-fit-indices.md` 的固定阈值表，RMSEA < .08 为可接受；该阈值表出处见该文件」 |
| 「这个结果说明假设成立」 | 「该结果**与你提出的假设方向一致**；是否成立还需结合效应量与置信区间判断」 |
| 「我帮你补上缺的样本量」 | 「样本量请从你的 `.out` 的 `SUMMARY OF ANALYSIS` 读取；此处留 `<待填：样本量>`」 |
| 「参考某某文献，类似研究都是这么做的」 | 「引文格式我可给（APA 7th）；**具体文献不代找**」 |

## 七、边界声明（对用户可见，随输出给出）

输出结尾应包含（可精简，但四项不可省）：

```
未覆盖　：收敛性、拟合优度、参数合理性；数据层警告（需 --dict）
出处　　：<官方手册锚点 / 语料口径 / 案例 ID>
```

## 八、维护纪律

1. 本文件任何放宽都属**变更红线**，须在 `CHANGELOG.md` 显式记录理由。
2. 新增输出模板**必须**内建验证状态与覆盖率声明字段，否则不予合并。
3. 门禁失败时**修内容**，**不得**放宽门禁或其断言字符串来「通过检查」。
4. 允许引用真实材料，但须标注「**来源未经确证**」；**严禁伪造来源**。
