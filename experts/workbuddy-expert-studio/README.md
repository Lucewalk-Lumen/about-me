# WorkBuddy 专家开发工坊（workbuddy-expert-studio · 专家团）

一个 Team 型多角色协作专家团，帮你把「开发一个专家包」的想法，走完一条从立项到交付的完整流水线，交付贴合实际开发流程、可直接导入使用的成品包（专家 / 专家团 / 技能均可）。

## 类型

Team 型（多角色协作团队）。由主理人编排流程、统一把关质量，六位专业成员分工协作。

## 团队成员

> 含主理人；专业成员 6 位。

| 成员 ID | 名字 | 职称 | 对应阶段 |
|---|---|---|---|
| workbuddy-expert-studio-team-lead | 齐衡 | 交付总监（主理人） | 编排 + 质量把关 |
| agent-diagnostician | 沈证 | 立项诊断官 | 阶段 1 立项与诊断 |
| agent-architect | 高构 | 结构设计官 | 阶段 2 结构设计 |
| agent-engineer | 柯码 | 实现分片官 | 阶段 3–4 实现与分片 / 质量校验 |
| agent-auditor | 严证 | 取证核查官 | 阶段 5 审计与取证 |
| agent-packager | 包洁 | 干净落位官 | 阶段 6 干净打包 |
| agent-release-chronicler | 史衡 | 验收沉淀官 | 阶段 7–9 验收 / 版本 / 沉淀 |

## 九阶段流水线

立项与诊断 → 结构设计 → 实现与分片 → 质量校验 → 审计与取证 → 干净打包 → 验收放行 → 版本治理 → 沉淀资产。每个阶段都有明确的检查标准，不达标就不放行。

## 方法论

本团方法论以平台官方开发规范为基准，与本团工程实践一并沉淀为 9 篇方法文献，覆盖九阶段流程、阶段勾选清单、质量与体验评估、合规与安全体检（含改名安全规范）、Agent 构成模型与运行框架纪律、需求规格与任务规划、推理与工具行为纪律、交付保障、包开发避坑清单，贯穿流水线的各个阶段。

本团内置平台官方开发规范查询：随时可对照规范核对结构与字段，规范更新时可比对差异并提醒你复核。

## 安装与使用（多专家协作）

本专家团依赖 WorkBuddy 的**多专家协作**能力运行：

1. 打开 WorkBuddy，左侧栏点击 **专家·技能·连接器**，进入「专家」页签（即专家中心）。
2. 点击 **导入专家包**，选择本包交付的 `workbuddy-expert-studio-1.0.2.zip`（文件名中的版本号随发布版本变化）。
3. 安装后在专家中心召唤 **WorkBuddy 专家开发工坊**，描述你的开发需求，主理人会组织六位成员按九阶段流水线协作推进。
4. 你也可以从「我的专家」创建属于自己的变体，或把产物生成到资料库「团队空间」与人协作。

> 覆盖升级与回滚步骤见 `UPGRADE.md`。

## 网页资料采集

本团内置网页采集能力，可稳定抓取网页、检索公开资料，为开发过程提供证据：

- **普通网页**：直接抓取并抽取正文。
- **动态网页**：遇到需要浏览器渲染的页面时，自动调用你电脑上已安装的浏览器完成渲染，无需额外设置。
- **需要登录的页面**：可通过平台的浏览器自动化能力完成登录后采集；若环境不支持，相关页面将尽力采集，可能只能获取部分内容。

网络波动或页面异常时，也会尽量返回可用结果。

## 限制与已知边界

- 本专家团依赖 WorkBuddy 的**多专家协作**能力运行，需在支持该能力的 WorkBuddy 环境中使用。
- 动态或需登录的页面依赖本机浏览器渲染或平台的浏览器自动化能力；环境不支持时，相关页面可能只能取到部分内容。
- 抓取遵守目标站点的 robots 约定，并拒绝内网、回环与云元数据等地址，不采集此类目标。
- 单次协作的产物受平台能完整读取的长度上限约束；过长内容会被自动拆分处理。
- 规范要点以本团内置的官方开发规范为准，规范更新时可比对差异并提醒你复核。
