## 1.0.3 版本发布 🚀（2026-10-22）

- 新增对话交互三项能力：同一话题可接着追问（如「那 XX 呢」），无需重复交代上文；概念有多种理解时会先问你一句再检索（如「公平」指分配公平还是程序公平）；首轮先给概览并提示可深挖方向，你点名哪条就展开哪条的完整内容
- 新增概念的双向词形匹配：问法与库内写法只要对上一个就命中（如「公平性」可命中库内「公平」），并显式标注这是放宽匹配而非精确命中
- 新增结果截断提示：条目多于展示上限时，明确告知该概念下共有多少条、实际展示多少条，不再让你误以为已看全
- 新增缺失信息显式标注：计分方式在原始资料中未载明的量表，现标注「原文未覆盖」并提示回原始文献核对；补充检索命中的条目也补齐维度、题数、核验状态与原文路径
- 新增 2 条量表：职场孤独量表、领导认同量表，均标注来源待核验并附出处
- 新增 11 条理论条目：教材有独立专节、库里却查不到的 11 个概念（古典科学管理理论、霍桑实验与人际关系学说、认知失调理论、平衡理论、MBTI、从众、社会惰化、群体思维、虚拟团队、约哈利之窗、职业倦怠三维模型），现按教材专节补录，教材涵盖的概念已全部可查
- 优化概念检索覆盖率：谏言/建言/进谏、领导认同、心理安全、授权型领导、员工创造力、员工韧性等说法接入既有构念，检索直达对应条目
- 优化 R 方法适用条件：22 个方法此前未写明何时该用，现依据操作对象与模型要求逐条写明
- 优化查不到时的原因说明：检索结果直接写明「为什么不挂某类条目、教材有无专节」，不再只显示「无匹配条目」
- 优化文献缺口表述：原始资料未载明文献的，显式说明「原始资料未载明可核验文献条目」，不再显示为「文献 0 篇」
- 优化资产体积：量表与理论条目正文合并存放，包内文件数由 902 降至 156，内容无损、检索方式与输出格式不变
- 优化成员协作交接：三位专家的回传口径统一为「结论 + 条目原文 + 依据」，来源待核验的条目会显著标注，未回传或检索失败时如实上报
- 优化概念词表存储：概念词表收敛为单一文件承载，消除多处重复维护可能带来的不一致
- 优化团队形象与上手提示：四位专家换上统一风格的全新形象照，首屏的三条引导语改写得更简短、更能说明本团能做什么
- 优化教材外条目的说明口径：超出教材范围的理论与量表条目（如 CNI 模型、SOR 理论等），现明确说明「不挂在教材概念下属正常、而非缺失」，且同样可按名称与构念检索直达
- 修复教材章节引用路径表述：将文档中作为示例的「chXX.md」明确为实际章节文件名范围（ch01.md 至 ch12.md），消除引用歧义
- 修复状态数字与库内真实记录不一致的问题：理论与量表的已核验/待核验条数、正文覆盖数等统计，现均与库内真实记录一致
- 修复版本号不一致的问题：包内各处版本标识现已统一
- 修复更新说明中的路径表述：版本播报文件位置说明现与包内实际结构一致
- 修复待核验理论条目的来源说明不准确：此前称「查不到可核对的文献」，但条目所附参考文献其实真实可查；现如实说明「文献真实可查、但尚未逐条人工核对」，来源待核验的标注保持不变，不夸大为已确证

## 1.0.0 版本发布 🚀（2026-10-13）

四位智能体把组织行为学的教材、理论、量表与分析方法四座知识库联成一张网：输入任一概念，一次给出四重视角。

- 新增成员检索域标注与单专家直调指引：一眼看清每位专家负责哪个知识库，问法对路即可直接找到该找谁

### 团队与分工

- **主理人（程亦楠 / Vivian，首席知识官）**：识别你问的概念后做概念匹配与任务分配，把量表 / 理论 / R 方法的检索交给对应专家，成员各自检索本域知识库并回传，主理人汇编为四库联动的完整回答；跨成员信息流一律经其中转，协作过程向你可见。
- **量表检索专家（顾铭泽 / Felix）**：按量表编号、关键词或构念定位测量工具，给出维度与题号区间、完整题项、计分方式、反向计分标记与取用文献，支撑问卷设计与变量操作化。
- **理论查询专家（江语桐 / Sophia）**：按理论编号、关键词或构念定位理论，给出内容 / 作用机制 / 结构 / 应用四段正文与参考文献，支撑理论框架构建与假设推导。
- **数据分析专家（陆奕辰 / Derek）**：按方法编号或关键词定位分析方法，给出方法族、适用条件、对应 R 脚本路径与门控，支撑分析路径选择。

### 能力与纪律

- **一次给全**：任一概念的检索结果在一次回答中完整呈现，不要求用户分多次追问。
- **协作过程可见**：最终回答附成员分工表（谁检索了哪一库），每完成一环向用户通报进度。
- **数据可信度实时可见**：每次检索输出均附带可信度统计（已核验 / 待核验 / 总数与占比），随检索即时给出。
- **不补写、不编造**：正文缺失的段落显式标注「原文未覆盖」；无法定位的文献引用标注「文献缺失」；来源待核验的条目资料本身真实、可引用出结果，但输出会显著标记「来源未确证」，严禁编造。
- **反向计分显式提示**：量表输出给出反向计分题标记与题号汇总，避免按正向计分得到错误得分。
- **检索健壮性**：全角编号（Ｔ００１ / Ｓ００１）与半角等价；编号按精确相等匹配；命中超过展示上限时显式告知总数与展示数；单条数据异常只跳过该条并提示，不影响其余结果。
- **版本更新播报**：线上版本更新后用户再次召唤时，主理人主动告知本次更新；同一版本读过一次后不再重复打扰。
- **离线运行**：核心能力由纯标准库 Python 脚本提供，零第三方依赖、无安装步骤；资产内不含任何密钥。
