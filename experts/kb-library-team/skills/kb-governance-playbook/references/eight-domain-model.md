# 八域主线模型（eight-domain-model）

> 适用成员：库正（主理人路由判据）

## 1. 八域主线

```text
① 采集入库 → ② 分类组织 → ③ 成熟度晋级 → ④ 索引导航
     ↓                                        ↓
⑧ 价值度量 ← ⑦ 版本归档 ← ⑥ 质量巡检 ← ⑤ 检索问答
```

| 域 | 定义 | 负责成员 | 作用对象 |
|---|---|---|---|
| ① 采集入库 | 多源资料的登记、提取、归一化、入库护栏 | 罗采 | 未入库资料 |
| ② 分类组织 | 目录体系、分类方案、批量归类 | 林归类 | 已入库条目的位置 |
| ③ 成熟度晋级 | idea→draft→official→archive 门禁 | 关晋 | 条目的成熟度状态 |
| ④ 索引导航 | MOC/总索引/双链/标签体系 | 苏航 | 条目间关系 |
| ⑤ 检索问答 | grounding、引用先行、置信度 | 齐证 | 库内容（消费） |
| ⑥ 质量巡检 | 重复/冲突/过期检测、事实纪律 | 齐证 | 库内容（体检） |
| ⑦ 版本归档 | 只归档不删除、替代关系、回滚 | 安档 | 生命周期元数据 |
| ⑧ 价值度量 | 健康指标、晋级率、运营趋势 | 安档 | 生命周期元数据 |

## 2. 互斥性判据

四个「管进/管位/管级/管链」成员的作用对象两两正交：未入库资料（罗采）、位置（林归类）、状态（关晋）、关系（苏航）——不存在两个成员对同一条目同一属性各自下结论的情形。齐证与安档以产出物区分：前者产「答案/巡检报告」，后者产「归档日志/度量报告」。

## 3. 路由判据（主理人用）

1. **判域**：用户意图命中单域 → 直调路由表；命中 ≥2 域或任何批量写操作 → 建团走 W1–W8。
2. **判轻重**：单域、只读、无写操作 = 轻量直调；其余 = 建团编排。
3. **判门禁**：任何写操作（移动/入库/晋级/归档/索引写入）必经确认断点，与域无关。

## 4. 五管分工（域的横切表达）

内容生命周期用「成熟度」管（域③⑦）、业务主题用「索引」管（域④）、知识关联用「链接」管（域④）、辅助检索用「标签」管（域④）、质量靠「定期巡检」管（域⑥）。五件事不混到一层：阶段文件夹只回答「成熟没成熟」，主题归类交给索引。

## 5. 跨域横切纪律

- 最终确认权在用户（一切写操作前置确认）。
- 先判断后建议、先列清单后确认、先确认后操作。
- 机械层脚本化 + 判断层人工：健康分/重复/死链/门槛预检走 scripts/ 闭式脚本，成员不口算。
