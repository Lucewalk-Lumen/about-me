# 客户投诉处理标准动作

处理客户投诉的标准动作分四步：

1. **倾听与记录**：不打断客户，完整记录投诉要点与情绪点；工单字段填写口径以 [[客户投诉工单字段规范]] 为唯一标准。
2. **致歉与确认**：先致歉，再复述确认理解是否准确。
3. **分级响应**：一般问题 24 小时内答复，紧急问题 2 小时内响应（与 [[投诉分级响应细则]] 三级口径一致，2026-10-22 已对齐）。
4. **闭环回访**：解决后 3 天内回访，确认客户满意并归档。

详见 [[投诉分级响应细则]]。
