# 客户投诉工单字段规范

> 唯一标准：所有涉及客户投诉的工单、报表、复盘文档，字段口径一律以本规范为准。

## 必填字段

| 字段 | 类型 | 取值/格式 | 说明 |
|---|---|---|---|
| 工单号 | 字符串 | `TS-YYYYMMDD-NNN` | 系统生成 |
| 客户 ID | 字符串 | 内部客户唯一标识 | 脱敏存储 |
| 投诉类型 | 枚举 | 产品质量 / 服务态度 / 物流交付 / 价格争议 / 其他 | 单选，禁止自填 |
| 紧急级别 | 枚举 | 一级（紧急） / 二级（重要） / 三级（一般） | 与 [[投诉分级响应细则]] 对齐 |
| 首次响应时长 | 数值 | 分钟 | 工单创建到首次人工响应 |
| 答复时长 | 数值 | 小时 | 工单创建到正式答复 |
| 解决时长 | 数值 | 小时 | 工单创建到关闭 |
| 客户满意度 | 枚举 | 满意 / 一般 / 不满意 / 未评价 | 回访后填写 |
