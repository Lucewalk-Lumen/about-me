# 客户回访话术优化

现有回访话术偏生硬（推断，基于个人观察，待客户反馈数据验证），建议改为更口语化的表达：

- 旧：「请问您对本次处理结果是否满意？」
- 新：「这次的问题解决得还顺利吗？有没有什么地方我们能做得更好？」

待补充更多场景的对比话术与客户反馈/AB 测试证据后再考虑晋级。相关背景见 [[客户投诉处理标准动作]]，回访时限口径见 [[客户运营术语对照表]]。
