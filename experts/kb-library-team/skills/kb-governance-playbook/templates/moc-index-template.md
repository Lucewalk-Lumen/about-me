# MOC 索引模板（moc-index-template）

> 使用成员：苏航 ｜ 宿主语法以对应 hosts 篇为准（Obsidian 用 `[[ ]]`，LLM Wiki 用 Markdown 相对链接）

## 总索引 MOC

```markdown
# 总索引（MOC）

> 本库主题导航总入口。条目正文不复制到此，只挂链接。

## 主题索引
- [[主题A索引]] — 一句话说明该主题覆盖什么
- [[主题B索引]] — ……

## 待纳入候选（未定稿内容，非正式资产）
- [[候选条目1]]（当前阶段：draft）

## 维护说明
- 更新触发：新正式条目入库 / 主题拆分合并 / 巡检发现索引缺失
- 维护责任：索引导航官提建议，用户确认后写入
```

## 主题索引

```markdown
# <主题名>索引

> 一句话：本主题回答什么问题、覆盖什么范围。

## 核心条目（official）
- [[条目1]] — 一句话导读
- [[条目2]] — 一句话导读

## 关联主题
- [[另一主题索引]] — 关系：上下游 / 交叉 / 因果

## 待纳入候选
- [[候选条目]]（当前阶段：draft；缺口：……）
```

## 填写纪律

1. 单张主题索引挂条目建议 ≤50 条，超出拆分。
2. 每条挂链附一句话导读；无导读不挂。
3. 待纳入候选区只放非 official 内容，不冒充正式资产。
4. MOC 不复制正文；只增索引关系。
