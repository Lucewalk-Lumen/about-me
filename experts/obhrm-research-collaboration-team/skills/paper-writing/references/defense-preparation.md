# 答辩准备（A7）

## 一、适用边界

- **仅适用于学位论文答辩**：本科/硕士/博士的**开题答辩、中期答辩、预答辩、正式答辩**。
- **期刊 / 会议论文无答辩环节**，不适用本路径；它们走 A6 投稿准备。
- **触发语**：用户说"准备答辩""答辩 PPT""答辩被问到…""导师让我改答辩稿""答辩稿怎么写"。
- **前置**：必须先完成 A5 成稿（至少草稿）。开题答辩则是 A1 选题确认后、正式研究前，此时尚无成稿，按"研究计划答辩"处理（见第六节）。

## 二、与论文路径的关系

```
A0 头脑风暴 → A1 选题 → … → A5 成稿 → ┬─ 期刊/会议 → A6 投稿准备
                                       └─ 学位论文   → A7 答辩准备
```

- 答辩不是写作步骤，而是**成稿后的呈现与捍卫**。核心是把 A5 里已经沉淀的资产"讲出来、答得住"。
- **直接复用资产**（不必重做）：
  - `confirmed_contribution.md`（贡献声明）→ 开场与总结的 30 秒版本
  - A5「贡献→假设→图表→结果」可追溯矩阵 → 被问"这个结论的证据在哪"时秒级定位
  - `stable_id_system.md` 的 S/E/L/R/V/F 编号 → 答辩问答中用稳定 ID 回指主张与证据，避免口头混乱

## 三、答辩 PPT 结构（标准 12–15 页骨架）

> 原则：**一页一主张、图表大于文字、结论前置**。每页只回答一个问题，不堆砌。

| 页序 | 内容 | 要点 |
|------|------|------|
| 1 | 封面 | 题目、姓名、导师、单位、答辩日期 |
| 2–3 | 研究背景与问题 | 引出"真问题"，用 1 句话点明现实/理论张力 |
| 4 | 文献缺口 | 已有→缺口→本研究（复用 A2 文献链） |
| 5 | 研究问题与目标 | 直接放 RQ 卡（A1 产物） |
| 6 | 理论 / 分析框架 | 1 页图，标注核心构念与机制 |
| 7–8 | 研究方法 | 设计、样本、数据来源、分析策略（两页拆开） |
| 9–12 | 研究发现 | 核心图表逐张讲，每张配"这说明了什么" |
| 13 | 讨论与贡献 | 呼应贡献声明，逐条对应 |
| 14 | 局限与展望 | **主动暴露** 2–3 个真实局限 |
| 15 | 致谢 / Q&A | 留白给提问 |

- 时长：严格按院系要求（通常 10–15 分钟）。练到能脱稿讲、且不超时被打断。
- 禁止：把全文粘贴上屏、动画炫技、结论后置。

## 四、委员类型与提问预判

答辩委员会角色不同，关注点不同。准备时按"最可能坐你面前的三位"分配准备权重：

| 委员类型 | 关注点 | 典型开场问 |
|----------|--------|------------|
| **主席 / 资深** | 整体贡献、创新性、与领域关系 | "用一句话说你最大的贡献是什么？" |
| **方法派** | 样本、变量、识别策略、稳健性 | "样本量凭什么够？内生性怎么处理？" |
| **理论派** | 构念、机制、Warrant | "X 和 Y 这两个构念本质区别在哪？" |
| **应用派** | 实践意义、可推广性 | "这对企业管理到底有什么用？" |
| **挑刺派** | 局限、威胁效度、替代解释 | "你最大的漏洞是什么？" |

> 预判练习：给每位（拟任）委员写 3 个"他一定会问"的问题，并备好应答。

## 五、高频陷阱题 + 应答模板

应答通用框架（四步）：**承认 → 定位 → 证据 → 边界**。
- 承认：正面接住问题，不回避。
- 定位：用稳定 ID 或章节回指（"在第 9 页图 3 / 假设 H2"）。
- 证据：调可追溯矩阵里对应的结果。
- 边界：诚实说明适用范围与未及之处。

### 5.1 贡献类
- **"你的创新和已有研究有什么不同？"**
  → 承认差异点；定位文献缺口页；证据：本研究相对已有文献新增的因果识别 / 情境 / 机制；边界：不夸大，点明"在 X 条件下"。
- **"这篇文章如果删掉，领域会少什么？"**
  → 用贡献声明的一句话版本作答，落到"首次发现/证伪/机制"。

### 5.2 方法类
- **"样本量为什么这么小 / 代表性够吗？"**
  → 承认局限；定位抽样设计与理论饱和标准；证据：响应率、检验力事后计算；边界：推广性仅限该群体。
- **"内生性 / 共同方法偏差怎么处理？"**
  → 承认这是威胁；定位已采取的措施（Harman、工具变量、时序分离等）；证据：具体检验结果；边界：哪些偏差未被完全排除。
- **"为什么用 X 方法而不是 Y？"**
  → 定位研究问题与数据约束；对比 X/Y 的适配性；不贬低替代方法。

### 5.3 理论类
- **"X 构念和 Y 构念有什么区别？"**
  → 用操作性定义 + 维度差异作答；回指理论框架页。
- **"机制（Warrant）讲清楚了吗？为什么 X 导致 Y？"**
  → 复现图尔敏 Warrant；若机制是推断，明确标注"机制性解释，需后续实验验证"。

### 5.4 数据 / 证据类
- **"数据怎么来的？可靠吗？"**
  → 定位证据表（E 编号）；说明采集流程、脱敏与授权；证据：信效度指标。
- **"这个结论的依据是哪张表 / 哪个统计？"**
  → 秒级调可追溯矩阵，报图 N / 表 M 与关键统计量。

### 5.5 结果类
- **"H3 不显著，你怎么解释？"**
  → 不回避；定位结果页；给理论或方法层面的合理解释；边界：说明这不影响核心贡献。
- **"有没有做稳健性检验？"**
  → 定位已做的（替换样本 / 变量 / 模型）；若没做，诚实说"下一步补"，不编造。

### 5.6 局限 / 应用类
- **"你最大的局限是什么？"**
  → 主动抛出自已准备的 2–3 个真实局限（见 PPT 第 14 页），并说明如何缓解；**切忌被追问才承认**。
- **"对企业 / 管理实践有什么用？"**
  → 落到具体情境与可操作建议；边界：理论贡献优先，不夸大实践效力。

### 5.7 边界 / 挑衅类
- **"这个结论在 XX 情境下还成立吗？"**
  → 用边界条件作答；若未检验，说"这是有价值的边界问题，作为展望"。
- **"我不同意你的解读。"**
  → 不争辩；感谢并复述对方观点；用证据说明自己的解读依据；保留分歧。

## 六、开题 / 中期答辩的特殊处理

- **开题答辩**（A1 后）：尚无数据，重点是**研究设计的可行性**。准备：问题价值、理论缺口、方法可操作性、时间安排。被问"做不出来怎么办"→ 给备选方案与里程碑。
- **中期答辩**：重点是**进度与初步发现**。准备：已完成模块、遇到的真实困难、下一步计划。
- 这两类同样复用贡献声明雏形与 RQ 卡，只是证据尚弱，应答时明确"目前处于 X 阶段"。

## 七、冷场 / 不会答的兜底话术（学术诚信红线）

- **不会答但可推断**："这个问题我目前没有充分证据，我的初步想法是…，后续我会通过…验证。"——给方向，不编数据。
- **完全不知道**："感谢指出，这是我之前没充分考虑的，我会把这个问题纳入修订。"——诚实优于糊弄。
- **被指出错误**："您说得对，这里确实…我会修正。"——认错不狡辩。
- **禁止**：编造数据、虚构文献、夸大结论、把"不知道"包装成"已证明"。这触碰学术诚信红线，任何情况下不可为。
- 区分"不知道"（知识缺口）与"不赞同"（可讨论分歧），前者认，后者用证据对话。

## 八、答辩前自检清单

- [ ] PPT 页数 / 时长符合院系要求，已脱稿演练 ≥ 2 遍
- [ ] 贡献声明能 30 秒说清（开场 + 总结都用得上）
- [ ] 核心图表（≥3 张）能脱离讲稿解释其"说明了什么"
- [ ] 方法细节（样本 / 识别策略 / 稳健性）能答，证据表 E 编号随手可查
- [ ] 局限已主动准备 2–3 条，且每条有缓解说明
- [ ] 可追溯矩阵已备好，被问"证据在哪"可秒级定位（图 N / 表 M）
- [ ] 拟任委员类型已预判，每人 ≥ 3 个预设问题已备应答
- [ ] 冷场 / 不会答话术已在心里过一遍，明确"不编造"底线
