## 2. 各方法族「何时用 / 关键阈值」速览

- **2.1 SEM**：潜变量建模、路径分析、模型比较；CFI/TLI≥0.90（宽松 0.95）、RMSEA≤0.08（宽松 0.06）、SRMR≤0.08。
- **2.2 测量**：量表验证、构念效度；CFA 载荷≥0.70、CR≥0.70、AVE≥0.50、HTMT<0.85。
- **2.3 MSEM**：团队/嵌套数据 + 中介机制；组内相关 ICC(1) 显著才需多层。
- **2.4 纵向**：增长轨迹 / 交叉滞后；RI-CLPM 区分 trait 与 state，DSEM 处理密集纵向。
- **2.5 以人为中心**：异质性群体分类；LPA 看 BIC/entropy/ BLRT，类别数按理论+统计双判。
- **2.6 中介**：X→M→Y 机制；Bootstrap 95% CI 不含 0 即显著。
- **2.7 调节/RSA**：边界条件、非线性、匹配；RSA 看曲面顶点/主轴显著性。
- **2.8 曲线**：倒 U / 过犹不及；二次项显著且拐点落在数据范围内。
- **2.9 元分析**：效应量聚合；异质性 I²、发表偏倚 Egger's / funnel。
- **2.10 PLS-SEM**：探索/预测、小样本(<200)、非正态、形成型构念；Q²>0、HTMT<0.85。
- **2.11 QCA**：充分/必要条件、案例导向配置；一致性≥0.75（充分）、PRI 解悖论。
- **2.12 扎根理论**：见下方保留专节（唯一深方法族）。
- **2.13 缺失**：缺失率>5% 即系统处理；MCAR/MAR 用 mice 多重插补，MNAR 做敏感性分析。
- **2.14 检验力**：Power≥0.8；a priori 反推 n，投稿常需论证。
- **2.15 LGM**：增长轨迹建模；截距/斜率潜变量，看方差显著性。
- **2.16 LCA**：分类指标异质性分组；BIC/熵/类别可解释性。
- **2.17 SNA**：关系/位置/结构；度/介数/接近中心性 + walktrap 社群（Q>0.3）。
- **2.18 APIM**：成对/对偶数据双向效应；actor/partner 系数 + 可区分性 LR 检验。
- **2.19 混合方法**：单一方法不足时量化+质性互补；须有整合章与优先级声明。

### 3.1 速览卡

| 维度 | 内容 |
|------|------|
| **适用场景** | 理论涌现、过程研究、新现象探索 |
| **前提条件** | 学派前置声明（经典 Glaser / 程序 Strauss / 建构 Charmaz）；理论取样 |
| **检验步骤** | 理论取样→开放编码→主轴编码→核心编码→理论饱和→持续比较→备忘录 |
| **关键阈值** | 理论饱和：新数据不再涌现新范畴；编码员一致性 Kappa ≥ 0.70 |
| **常见陷阱** | 学派混用（经典派"涌现"与程序派"预设框架"互斥）；编码浮于贴标签 |
| **报告要求** | 学派声明 + 三级编码示例 ≥ 3 处 + 理论饱和证据 + 反例 + 三角验证 |

### 3.2 背景与原理

扎根理论由 Glaser 与 Strauss 于 1967 年《The Discovery of Grounded Theory》共同提出，是从经验数据中系统生成理论（而非演绎检验）的质性方法论。三大学派：经典派（Glaser，强调理论自然涌现）、程序派（Strauss & Corbin，6C 主轴编码）、建构派（Charmaz，承认理论建构性）。贾旭东、衡量（2020）系统梳理三大学派与"扎根精神"，提出"中国管理扎根研究范式"（第三次融合，经典派为主体、程序派因果/认知地图为辅助，分定性→定量两阶段）。王璐等（2010）建议预留约 25% 数据用于编码后范畴稳定性检验。

**判定口诀**：*"理论还没长出来、现象还很新——扎根；理论已经成型、要检验假设——回定量。"*

### 3.3 适用场景判定

| 判定维度 | 适用 | 不适用/慎用 |
|----------|------|-------------|
| 研究问题 | 新现象/过程/机制探索、理论涌现 | 已有成熟理论→变量中心检验（2.1/2.6） |
| 理论状态 | 领域理论贫瘠或现有理论无法解释新情境 | 理论饱和领域强行扎根易重复 |
| 数据可得性 | 多源质性资料可得、可理论取样 | 数据单一且无法补充取样 |
| 学派立场 | 须前置声明并全程一致 | 学派混用导致方法论矛盾 |
| 研究目标 | 建构中程/实质理论、为后续量化供假设 | 只想验证假设→定量（2.1–2.11） |

### 3.4 关键阈值与报告要求

- **理论饱和**：新数据不再涌现新范畴、属性与关系不再变化（无统一量化标准，须给证据）。
- **编码员一致性**：Kappa ≥ 0.70（常见报告线）。
- **三级编码示例**：报告 ≥ 3 处；**反例**与**三角验证**（多源互证）必须呈现。
- **学派自洽**比数值指标更重要——方法论不自洽是致命问题。
- **衔接**：扎根生成的范畴/命题可操作化为量表/假设，进入 2.2 测量模型与 2.1 SEM 检验（中国管理扎根研究范式两阶段）；顺序探索型混合方法的"阶段 1"通常即扎根。

### 3.5 常见误区

1. **学派混用**：经典"涌现"与程序"预设框架"互斥，须开篇声明并全程一致。
2. **编码浮于贴标签**：须通过持续比较与备忘录提升抽象层次（Suddaby 警示"扎根理论不是贴标签"）。
3. **把扎根当不完整定性研究**：无理论取样、饱和未达即收笔。
4. **用预设框架强制解释资料**：开放编码阶段不带预设。
5. **饱和判定凭感觉**：须记录新增数据是否产生新范畴。
6. **单一数据源无三角验证**：访谈+观察+档案多源互证。
