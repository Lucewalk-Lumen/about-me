# 中文期刊三线表规范

> **用途**：把分析结果排成中文管理学与应用心理学期刊可直接采用的表格形态。
>
> **适用刊物取向**：《管理世界》《南开管理评论》《管理科学学报》《管理评论》《中国工业经济》《心理学报》《心理科学》等中文核心期刊。
>
> **重要提醒**：英文经济学与管理学期刊的表格惯例**不能整套照搬**。下方第七节列出必须转换的差异点。投稿前仍须以目标期刊最新一期的实际排版与投稿须知为准，本文件给出的是通行底线而非某一刊的细则。

---

## 一、什么是三线表

三线表指全表**只保留三条横线、不使用任何竖线**的表格形态：

| 线 | 位置 | 相对粗细 |
|----|------|---------|
| **顶线** | 表格最上方，位于表题之下、栏目名之上 | 较粗 |
| **栏目线** | 栏目名（表头）与数据主体之间 | 较细 |
| **底线** | 数据主体最下方，位于注释行之上 | 较粗 |

- **不画竖线**，不画数据行之间的横线。
- 唯一允许的额外横线：表头存在两层结构时，在上层合并栏目名之下加一条**短横线**，只跨越其所辖的子栏目，不通栏。
- 表格底部的注释行位于底线之下，注释行本身不加框线。

## 二、整表结构（自上而下）

```
表 1  主要变量的描述性统计与相关系数
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   ← 顶线
 变量        均值    标准差     1        2        3
────────────────────────────────────────────   ← 栏目线
 1. 变量甲   3.82    0.61    (0.87)
 2. 变量乙   3.45    0.72    0.31**   (0.91)
 3. 变量丙   4.06    0.55    0.18*   -0.24**   (0.85)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   ← 底线
注：N = 326。对角线括号内为各量表的内部一致性系数。
    * p < 0.05，** p < 0.01，*** p < 0.001（双尾检验）。
```

## 三、表题（表序与表名）

| 项目 | 中文刊规范 |
|------|-----------|
| **位置** | 表题置于表格**上方**（图题置于图下方，两者位置相反，勿混） |
| **对齐** | 居中；部分刊物用左对齐，以目标刊为准 |
| **编号** | 「表 1」「表 2」全文连续编号；不按章节分编（如「表 3-1」仅学位论文使用） |
| **写法** | 表序与表名之间空一格或用全角空格，**不加冒号、不加句号**。正例：`表 1  主要变量的描述性统计`；反例：`表1：主要变量描述性统计。` |
| **表名要求** | 具体到能脱离正文独立看懂，说明"什么变量、什么分析、什么样本"；避免「回归结果」这类无信息量的表名 |
| **字体** | 通常为黑体或宋体加粗，字号小于正文一号（正文五号则表题小五号），以目标刊为准 |

## 四、栏目（表头）与数据主体

**栏目名**

- 使用中文变量名全称，首次出现的英文缩写在表注中说明。
- 因变量名放在**列**，自变量与控制变量放在**行**，这是中文管理学期刊回归表的通行方向。
- 多个模型并列时，列标题用「模型 1」「模型 2」或「(1)」「(2)」，并在其下一行标明该列的因变量。
- 表头层级最多两层；超过两层说明表格该拆分。

**数据主体**

| 项目 | 规范 |
|------|------|
| **数字对齐** | 同一列按小数点对齐；正负号占位保持一致 |
| **小数位数** | 全表统一。回归系数与标准误通常保留 3 位；均值、标准差通常 2 位；相关系数 2 位；样本量为整数 |
| **前导零** | 中文管理学期刊通常**保留**前导零（写 0.312）；心理学类刊物对理论上不可能超过 1 的统计量（相关系数、显著性概率值）常**省略**前导零（写 .31、p < .05）。按目标刊惯例取其一，全文统一 |
| **括号内容** | 系数下方括号内放**标准误**或 **t 值**，二者择一，并在表注中明确说明是哪一个。这是审稿人必看项，未说明即为缺陷 |
| **空单元格** | 用短横线「—」表示不适用，用「n.a.」或表注说明数据缺失；不留纯空白 |
| **变量顺序** | 核心解释变量在前、控制变量在后、常数项与固定效应说明在最下方，模型统计量（样本量、拟合优度、F 值）置于表格最末几行 |

## 五、显著性标记

- **通行约定**：`*` 表示 p < 0.05，`**` 表示 p < 0.01，`***` 表示 p < 0.001；标记为**上标**，紧跟数值后不空格。
- **经济学取向刊物**常用另一套阈值：`*` p < 0.1，`**` p < 0.05，`***` p < 0.01。《中国工业经济》等经管类刊物多用此套。
- **两套不可混用**：全文统一一套，并在**每一张含显著性标记的表**的注释行中写明所采用的阈值，不能只在第一张表写一次。
- 注明**单尾还是双尾检验**。中文心理学类刊物通常要求明示，默认双尾；使用单尾须给出理由。
- 不用不同符号（如 †、#）标记边缘显著；若确需报告 p 值介于 0.05 与 0.10 之间的结果，在正文中如实说明为"边缘显著"，并谨慎解释，不做等同于显著的论述。

## 六、注释行（表注）

注释行位于底线之下，字号小于表格正文，以「注：」起首（不用「Note:」）。**内容顺序建议固定如下**：

1. **样本量**：`N = 326`；多层数据分别标明各层样本量（如 `员工 N = 326，团队 N = 68`）。
2. **括号内是什么**：`括号内为聚类至企业层面的稳健标准误` 或 `括号内为 t 值`。必写。
3. **标准误处理方式**：是否聚类、聚类层级、是否异方差稳健。
4. **控制项说明**：`所有回归均控制行业与年份固定效应`。
5. **缩写与量表说明**：变量缩写全称、量表内部一致性系数、对角线括号含义。
6. **显著性阈值**：`* p < 0.05，** p < 0.01，*** p < 0.001（双尾检验）`。通常置于注释行最末。
7. **数据来源**（如使用二手数据库）：单列一行 `资料来源：……`。

> 注释行不承担讨论功能。对结果的解释写在正文，不要在表注里展开分析。

## 七、英文期刊惯例到中文期刊的转换清单

以下差异是把英文刊表格直接搬进中文稿件时最常出问题的地方，逐条转换：

| # | 英文期刊常见做法 | 中文期刊应改为 |
|---|----------------|--------------|
| 1 | 表注以 `Notes:` / `Note.` 起首 | 以「注：」起首；数据来源另起「资料来源：」 |
| 2 | 阈值多用 `* p < 0.1, ** p < 0.05, *** p < 0.01`（经济学）| 管理学与心理学取向刊物多用 `* p < 0.05, ** p < 0.01, *** p < 0.001`；经管类刊物可沿用前者。**须核对目标刊并全文统一** |
| 3 | 统计量斜体（*N*、*p*、*R*²、*β*）| 中文排版中英文统计符号仍用斜体，但**中文字符一律不用斜体**；变量的中文名不加斜体 |
| 4 | 列标题用 `Dependent variable: ...` 跨列合并 | 改为中文「因变量：……」，或直接在模型编号下一行标明因变量中文名 |
| 5 | 表格跨页用 `(Continued)` | 改为「续表 1」，并重复表头栏目行 |
| 6 | 变量名直接用英文缩写（如 `LEV`、`SIZE`）| 表中使用中文变量名；确需保留英文缩写时，在表注中给出中英文对照 |
| 7 | 大量结果压缩进一张宽表，正文只作简述 | 中文刊更倾向表格数量适中、每表信息聚焦；宽表拆分为主回归表与稳健性汇总表 |
| 8 | 稳健性检验结果整体放入 Online Appendix | 中文刊通常要求主要稳健性结果**进正文**，附录只放最细节的部分 |
| 9 | 数字千分位加逗号（`1,326`）| 中文刊多数保留千分位逗号，但需全表统一；部分刊物不使用，以目标刊为准 |
| 10 | 使用 `n.s.` 标注不显著 | 中文刊一般不标 `n.s.`，无星号即表示不显著 |

## 八、常见错误（审稿路径「图表呈现」维度直接扣分项）

1. 表格带竖线或满格线框，不是三线表。
2. 表题写在表格下方，或图题写在图上方（位置颠倒）。
3. 括号里是标准误还是 t 值，表注未说明。
4. 显著性阈值两套混用，或只在首表说明一次。
5. 小数位数全表不统一，前导零时有时无。
6. 表格在正文中没有任何一处显式引用（须有「如表 1 所示」这类明确指引）。
7. 表名笼统（如「回归结果」），脱离正文无法独立理解。
8. 表格内容与正文文字大量重复，正文把表里每个数字又念一遍。
9. 变量名在表格与正文中不一致，同一构念出现两种叫法。
10. 表格跨页断裂，续页无表头。

## 九、自检清单

- [ ] 全表只有顶线、栏目线、底线，无竖线（两层表头的短横线除外）
- [ ] 表题在表上方，全文连续编号，表名具体可独立理解
- [ ] 小数位数、前导零风格全文统一
- [ ] 括号内容已在表注中明确说明
- [ ] 显著性阈值全文统一，且每张相关表格的注释行均已注明
- [ ] 表注含样本量、括号说明、标准误处理、控制项、缩写说明、显著性阈值
- [ ] 正文至少有一处显式引用该表
- [ ] 表格未与正文文字重复叙述
- [ ] 已对照目标期刊最近一期的实际排版核验过格式差异
- [ ] 图表已按图表嵌入协议登记编号（见 `skills/obhrm-methodology/domains/visualization/visualization.md`）
