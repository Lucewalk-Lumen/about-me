# 因果识别策略选择（OBHRM 语境）

> **用途**：当研究主张含"影响""促进""导致""驱动"等因果表述时，用本文件选定识别策略、明确识别假设、准备被审稿人追问时的应对证据。
>
> **前置**：本文件服务于数据分析域各分支，使用前须已过 `../SKILL.md` 的 D0 分级试跑；稳健性配套见 `robustness-matrix.md`。
>
> **首要纪律**：OBHRM 的多数问卷研究**不具备因果识别条件**。此时正确做法是把结论语言降级为"关联""预测""与……相联系"，而不是套一个识别策略的名字来装点。策略是用来匹配数据结构的，不是用来匹配期望结论的。

---

## 一、先回答三个前置问题（答不出就不要谈因果）

1. **处理是什么？** 能否明确指出一个在时间上先于结果、边界清晰的"处理"（政策实施、制度变更、岗位调动、培训项目上线、领导更替）？说不清处理是什么，就没有因果可识别。
2. **反事实来自哪里？** 没有接受处理的那批观测对象是谁？他们与处理组在处理发生**之前**是否可比？
3. **谁决定了谁被处理？** 处理分配是外生冲击，还是由个体特征、绩效预期、自选择决定？后者即内生性来源，必须交代。

> 三问齐备才进入下方决策树；任一问答不上，回到研究设计层面，或如实降级结论语言。

---

## 二、识别策略决策树

```
研究主张含因果表述
        │
        ├─ 处理由研究者随机分配？
        │        └─ 是 → 随机实验 / 现场实验（识别力最强，OBHRM 中多见于情境实验、招聘简历实验）
        │
        ├─ 存在某个时点发生、影响部分对象的外生变化（政策、制度、组织事件）？
        │        │
        │        ├─ 有处理组与对照组，且有处理前后多期观测 → 双重差分（DID）
        │        │        └─ 处理时点不一致（分批推行） → 多期 DID / 交错 DID（须处理异质性处理效应问题）
        │        │
        │        └─ 无对照组，只关心事件短窗口内的反应 → 事件研究法
        │
        ├─ 处理资格由某个连续变量是否越过阈值决定（分数线、规模门槛、年龄界限、考核档次分界）？
        │        └─ 是 → 断点回归（RD）
        │
        ├─ 找得到只影响自变量、不直接影响因变量的外生变动来源？
        │        └─ 是 → 工具变量（IV）
        │
        └─ 以上都不满足
                 └─ 不做因果宣称。改用关联性表述 + 交代内生性隐患 + 用稳健性检验降低替代解释空间
```

## 三、四类策略速查

| 策略 | 适用数据结构 | 核心识别假设 | OBHRM 常见应用场景 | 最容易被审稿人打的地方 |
|------|------------|------------|------------------|--------------------|
| **双重差分 DID** | 面板数据，处理组/对照组 × 处理前/后 | **平行趋势**：无处理时两组结果变量走势平行 | 最低工资调整对企业用工与员工留任的影响；国企混改对高管激励的影响；某项人力资源政策在部分分公司先行试点 | 未做事前平行趋势检验；对照组本身受政策溢出影响；处理时点交错却用传统双向固定效应估计 |
| **工具变量 IV** | 截面或面板，存在合适外生变动 | **相关性**（工具与内生变量强相关）+ **排他性**（工具只通过内生变量影响结果） | 用地区行业平均值作为企业层面变量的工具；用历史或地理条件作为制度环境的工具 | 弱工具（第一阶段 F 值偏低）；排他性只靠讲故事、没有可检验证据；工具本身与遗漏变量相关 |
| **断点回归 RD** | 存在明确分配阈值的连续驱动变量 | **局部连续性**：阈值附近个体除处理外其他特征连续，且不能精确操纵驱动变量 | 绩效考核档次分界对晋升与离职的影响；招录分数线对职业发展的影响；企业规模门槛触发的用工规制 | 未做驱动变量密度检验（操纵检验）；带宽选择随意且不做敏感性分析；把局部效应过度外推为总体效应 |
| **事件研究法** | 事件时点明确，事件前后多期观测 | 事件外生且时点准确；事件窗口内无其他重大混淆事件 | 高管变更、重大安全事故、组织重组、政策发布对员工态度与组织绩效的短期冲击 | 事件窗口选择随意；同期存在其他事件未排除；把短窗口反应说成长期因果效应 |

## 四、逐策略的必备验证动作

### 双重差分 DID

- **事前平行趋势检验**：以处理前若干期做动态效应图，处理前各期系数应不显著异于零；这是 DID 的生命线，必须有图。
- **动态效应**：报告处理后逐期效应，说明效应是即时出现还是逐步显现、是否衰减。
- **安慰剂检验**：把处理时点人为提前若干期，或随机指定处理组多次重复估计，观察是否仍得到显著效应。
- **溢出与污染**：说明对照组是否受政策间接影响；若有，需缩小对照组范围或改用更干净的对照。
- **交错处理**：处理时点不一致时，说明是否受异质性处理效应导致的估计偏误影响，并给出对应的稳健估计。

### 工具变量 IV

- **第一阶段强度**：报告第一阶段回归结果与统计量，明确说明是否存在弱工具问题。
- **排他性论证**：不能只讲故事。给出可检验的间接证据（如安慰剂样本中工具对结果无影响）。
- **过度识别检验**：工具数多于内生变量数时报告相应检验结果。
- **结果解释边界**：说明估计的是局部处理效应，适用于哪一部分被工具影响的个体，不等于总体平均效应。

### 断点回归 RD

- **操纵检验**：驱动变量在阈值处的密度是否连续；不连续意味着个体可精确操纵，识别失效。
- **协变量连续性**：阈值两侧的其他特征变量应连续，逐一检验并报告。
- **带宽敏感性**：至少报告三种带宽下的估计结果，说明结论不依赖某一特定带宽。
- **安慰剂断点**：在非真实阈值处做同样估计，应无显著效应。

### 事件研究法

- **窗口设定理由**：说明事件窗口与估计窗口如何确定，理由须与研究问题相关而非结果导向。
- **混淆事件排查**：逐一列出窗口期内可能的其他重大事件并说明排除理由。
- **窗口敏感性**：变换窗口长度重复估计，观察结论是否稳定。

## 五、OBHRM 特有的两类陷阱

**其一，把中介检验当因果链条。** 中介分析本身不提供因果识别。自变量、中介、因变量若同源同时点测量，中介检验的显著性无法排除反向因果与共同方法偏差。写作时须明确：中介分析检验的是**统计上的间接效应**，机制的因果地位取决于设计而非统计方法。

**其二，把面板固定效应当万能解药。** 固定效应只能吸收不随时间变化的遗漏变量。随时间变化的混淆因素（如同期市场环境变化、企业战略调整）依然构成威胁，必须单独交代并尽可能控制。

---

## 六、写作落点

- **方法部分**：明示识别策略名称、识别假设、以及为什么本研究的数据结构满足该假设。
- **结果部分**：主回归之后紧跟识别假设的检验结果（平行趋势图、第一阶段强度、密度检验等），这些不是附录内容，中文管理学期刊通常要求进正文。
- **讨论部分**：如实交代识别策略的适用边界与未被排除的替代解释。
- **结论语言分级**：具备识别策略且假设检验通过，可用"影响""导致"；仅有控制变量的回归，用"与……显著相关""预测"。语言强度与证据等级不匹配，是审稿路径八维中「方法严谨」与「逻辑连接」两维的直接扣分项。
