# 稳健性检验矩阵（面向中文期刊审稿期待）

> **用途**：主结果跑出来之后，用本矩阵系统排布稳健性检验，回答"这个结论稳不稳"。
>
> **与 D0 的分工**：D0 分级试跑回答"分析通道走不走得通"（见 `../SKILL.md`），本文件回答"结论经不经得起换个做法"。识别策略的选择见 `causal-identification.md`。
>
> **中文期刊的现实期待**：《管理世界》《南开管理评论》《管理科学学报》《中国工业经济》等刊，稳健性检验通常**占正文一整节**（多为"稳健性检验与内生性处理"），而非塞进附录。审稿意见中出现频率最高的两类要求就是"请补充稳健性检验"与"请处理内生性问题"。检验做得少不如做得对，但一项不做基本不可能过审。

---

## 一、稳健性检验矩阵（按优先级排布）

| 优先级 | 检验类别 | 具体做法 | 回应的质疑 | 适用分支 |
|-------|---------|---------|-----------|---------|
| **必做** | **替换被解释变量** | 换用同一构念的其他量表、换计分方式（均值分改因子得分）、换客观指标替代自评指标 | "结论只是这个量表的产物" | 定量一手 / 二手 |
| **必做** | **替换核心解释变量** | 换测量口径、换滞后期、换连续变量为分组虚拟变量 | "换个测法就没了" | 定量一手 / 二手 |
| **必做** | **调整控制变量集合** | 逐步加入控制变量报告系数变化；增加行业、地区、年份固定效应 | "遗漏变量导致的伪相关" | 定量一手 / 二手 |
| **必做** | **标准误处理** | 按合理层级做聚类稳健标准误；异方差稳健标准误 | "标准误低估导致假显著" | 定量一手 / 二手 |
| **高** | **子样本检验** | 剔除特殊行业、特殊年份、极端规模企业；分组分别估计 | "结论由某类特殊样本驱动" | 定量一手 / 二手 |
| **高** | **安慰剂检验** | 随机指定处理组多次重复估计；虚构处理时点；用理论上不应受影响的结果变量做检验 | "这个效应是巧合" | 有识别策略的设计 |
| **高** | **内生性处理** | 工具变量、倾向得分匹配、Heckman 两阶段、滞后自变量 | "反向因果与自选择" | 定量一手 / 二手 |
| **高** | **共同方法偏差检验** | Harman 单因子、控制未测量潜在方法因子、标记变量法；更根本的是多时点多来源设计 | "自变量因变量同源同时点" | 定量一手（问卷） |
| **中** | **异常值处理** | 缩尾或截尾处理后重估；剔除强影响点后重估 | "少数极端值撑起了结论" | 定量一手 / 二手 |
| **中** | **更换估计方法** | 线性模型换稳健回归、分位数回归；受限因变量换对应模型；层次数据换多层线性模型 | "模型设定不当" | 定量一手 / 二手 |
| **中** | **缺失值处理方式** | 列表删除、多重插补两种方式并行报告 | "缺失处理方式影响结论" | 定量一手 |
| **中** | **样本期与窗口调整** | 变换研究期间、变换事件窗口长度 | "结论依赖特定时间区间" | 面板 / 事件研究 |
| **元分析专项** | **敏感性分析** | 留一法逐篇剔除；固定效应与随机效应模型并行；剔除低质量研究后重估 | "结论由个别研究驱动" | 定量二手 |
| **元分析专项** | **发表偏倚检验** | 漏斗图对称性、剪补法、失安全系数 | "只有显著结果被发表" | 定量二手 |

## 二、聚类标准误的层级选择（OBHRM 高频出错点）

聚类层级选错，标准误就是错的，显著性也随之失真。选择原则是**按处理分配或抽样的层级聚类**，而不是按数据量最方便的层级。

| 数据结构 | 聚类层级 | 说明 |
|---------|---------|------|
| 员工嵌套于团队，处理在团队层面 | 团队 | 同一团队内个体误差相关，必须聚类到团队 |
| 员工嵌套于企业，多期观测 | 企业 | 面板数据的标准做法；企业数偏少时需注意小样本聚类问题 |
| 政策在省或地区层面实施 | 省 / 地区 | 聚类层级低于政策层级会严重低估标准误 |
| 多时点追踪同一个体 | 个体 | 个体内自相关 |
| 处理同时在两个非嵌套维度变动 | 双向聚类（如企业与年份） | 需说明理由，并与单向聚类结果对照 |

> **聚类单元过少时**（一般少于 30–40 个）：需说明并采用小样本校正或自助法，不能直接照常报告。

## 三、共同方法偏差：中文刊的通行做法与更优做法

**通行做法（最低限度）**：Harman 单因子检验。但需清楚它的检验力很弱，只能说明"没有严重到一个因子解释绝大部分方差"，不能证明不存在共同方法偏差。只做这一项且据此宣称"不存在共同方法偏差"，是审稿路径八维「方法严谨」的常见扣分点。

**更有说服力的做法（按强度递增）**：

1. 加入未测量潜在方法因子的验证性因子分析模型，比较模型拟合与路径系数变化。
2. 使用标记变量法，引入与核心构念理论无关的变量作参照。
3. **设计层面的解决**：自变量与因变量分时点测量（间隔数周至数月）；变量来自不同来源（员工自评与主管他评、客观绩效数据）。

> 事后统计检验的说服力远不及事前设计。写作时应如实说明：统计检验只是缓解性证据，设计层面的措施才是根本。

## 四、稳健性检验的报告纪律

1. **不是越多越好，而是要有针对性**：每项检验都要对应一个具体的质疑。列一堆无关检验而回避核心质疑，审稿人一眼看穿。
2. **如实报告不一致结果**：某项稳健性检验中效应变弱或不显著，必须报告并解释，不得只挑支持性结果呈现（挑选数据是审稿路径列明的六类逻辑谬误之一）。结论随之下调限定语，比隐瞒更安全。
3. **正文给结论，附录给细节**：正文用一段文字加一张汇总表说明做了哪些检验、结论是否稳定；完整回归表可放附录或补充材料，视目标期刊要求。
4. **稳健性汇总表**：建议以一张表汇总各项检验下核心系数的方向、大小与显著性，让审稿人一眼看到稳定性。表格格式遵循 `three-line-table.md`。
5. **与主结果的关系写清楚**：稳健性检验是支撑主结论，不是另起一套结论。若某项检验推翻了主结论，那不是稳健性问题，而是主结论需要重述。

## 五、稳健性小节写作模板（中文刊常见结构）

> 为检验上述结果的可靠性，本文从以下几个方面进行稳健性检验。第一，替换被解释变量的测量方式，采用〔具体做法〕重新估计，结果见表 N 第（1）列。第二，考虑到〔具体质疑〕，本文〔具体做法〕，结果见第（2）列。第三，为缓解内生性问题，本文采用〔识别策略〕，第一阶段结果显示〔工具强度证据〕。上述检验中，核心解释变量的系数方向与显著性均与主回归一致，表明本文结论稳健。〔如有不一致，此处如实说明并解释。〕

## 六、自检清单（进入写作前逐项确认）

- [ ] 四项必做检验全部完成（替换被解释变量 / 替换核心解释变量 / 调整控制变量 / 标准误处理）
- [ ] 聚类层级与处理分配或抽样层级一致，并已在方法部分说明理由
- [ ] 若有因果宣称，识别策略的假设检验已完成（见 `causal-identification.md`）
- [ ] 问卷同源数据已做共同方法偏差检验，并说明其检验力局限
- [ ] 存在不一致结果的检验已如实报告，未选择性省略
- [ ] 稳健性汇总表已按 `three-line-table.md` 规范排版
- [ ] 每项检验都对应一个明确质疑，无凑数项
