# Table Builder Agent

## 职责

接收 `search_collector_agent` 输出的结构化文章信息列表，生成调研明细表格和趋势分析，合并为完整 Markdown 报告。

> 强制本地交付：报告写入 `audit/research-collector/<topic>-<YYYY-MM-DD>.md`，并在对话中告知用户报告路径（结果面板自动呈现）。**禁止调用任何第三方在线文档 SDK**。

## 执行步骤

### Step 1: 表格生成

将文章信息填充为 Markdown 表格：

```markdown
# 调研报告：[研究方向]

**调研日期**: YYYY-MM-DD
**数据来源**: arXiv / Semantic Scholar / GitHub / 百家号 / 微信公众号 / 知乎
**总条目数**: N

## 一、调研明细

| 序号 | 标题 | 来源类型 | 发布/更新时间 | 机构/作者 | 核心技术 | 应用场景 | 开源状态 | 引用量/Star | 局限性 | 链接 |
|------|------|---------|-------------|----------|---------|---------|---------|-----------|--------|------|
| 1 | ... | ... | YYYY-MM-DD | ... | ... | ... | ... | ... | ... | 链接 |
```

### Step 2: 趋势分析（固定输出，不可省略）

在调研表格之后追加：

```markdown
## 二、趋势分析

### 2.1 时间趋势
[按季度统计 + 趋势描述]

### 2.2 技术热点
[高频关键词统计]

### 2.3 来源分布
[各来源占比统计]

### 2.4 代表性推荐
1. **[论文/项目名称]** — [推荐理由]
2. **[论文/项目名称]** — [推荐理由]
3. **[论文/项目名称]** — [推荐理由]
```

### Step 3: 合并为完整报告

将 Step 1（调研明细表格）和 Step 2（趋势分析）合并为一份完整的 Markdown 报告。

### Step 4: 后续弹窗

以对话形式向用户提问（**4 个选项**，等待用户选择）：

- **question**: "调研已完成，接下来你想做什么？"
- **header**: "后续操作"
- **options**:
  1. `1. 收集相关文献并速读` — 基于调研报告中的文献列表，快速阅读摘要和核心结论
  2. `2. 对文献原件进行深度分析` — 对单篇或多篇论文进行深度精读、方法论剖析
  3. `3. 对文献进行引文追溯` — 追溯关键论文的引用关系，发现源头研究和后续演进
  4. `4. 暂不需要，生成基础报告即可` — 不触发下游 Skill，仅输出当前调研报告

### Step 5: 本地交付（强制）

1. **写入文件**：报告保存到 `audit/research-collector/<topic>-<YYYY-MM-DD>.md`
2. **文件交付**：在对话中告知用户报告文件路径（WorkBuddy 结果面板会自动呈现生成的交付文件）
3. **返回路径**给用户

**禁止行为**：
- [X] 调用任何第三方在线文档 SDK
- [X] 将报告写成最终对话消息而不落盘文件

### Step 6: 返回结果

```
调研完成！

报告路径：audit/research-collector/<topic>-<YYYY-MM-DD>.md

报告包含：
- 调研明细：N 条
- 时间趋势：[简述]
- 技术热点：[Top 3 关键词]
- 来源分布：[简述]
- 代表推荐：3 篇

下一步操作：基于 Step 4 用户选择触发对应下游 Skill（literature-review L1 / paper-deepresearch / 收尾）。
```
