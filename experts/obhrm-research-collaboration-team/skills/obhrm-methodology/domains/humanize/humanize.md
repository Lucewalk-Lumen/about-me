# 人文化（humanize · 去AI味 / 文本润色域）

> 本文件是套件内「人文化 / 去AI味」能力的入口与路由：触发词「去AI味 / 降AI味 / 像人话 / 改自然」命中时切入本域，让文本更像真人学者所写。底层方法整合公开的 AI 写作特征模式表（Wikipedia "Signs of AI writing" 等），三份支撑清单在本目录 `references/` 下。当输入命中「去AI味 / 降AI味 / 去AI / 像人话 / 自然一点 / 润色 / 改写得更自然」等意图时，由调度者切入本域。
>
> **一句话定位**：对已成稿文本做"风格级"去AI痕迹处理——不是改错，是改味。

## 〇、与套件内既有去AI资源的分工（先选对层，再动手）

套件内共有四层去AI相关资源，**层级不同、不可互替**：

| 层 | 文件 | 用在什么时候 |
|----|------|--------------|

| 综述专项去AI | `../../../literature-review/references/ai-fingerprint-guide.md` | L 域内部：综述文本的禁用表达、学术过渡词节制 |

分工要点：前三层是"写的时候别写出AI味"与"交之前扫一扫"，本域是"稿子已经写了，现在要把味改掉"。前三层命中的问题清单可以作为本域 Phase 1 扫描的输入。

## 一、强度校准（动手前必须先定档，严禁默认重度）

去AI味是**破坏性操作**，强度选错会把好稿改坏。两档强度：

### A. 学术轻量档（套件内默认档）

适用：论文、基金书、综述、**学术汇报/讲稿**、教学材料等一切学术语体文本。

- 目标语体：**「专业但自然」**——保留庄重感与学术规范，只去机器腔。
- 只做最小必要改动：去口癖（如"说白了"）、去空话套话、个别超长句为换气轻断。
- **严禁引入网文腔强调词**（"更要命""太离谱了""说真的"等），严禁滥用独立短句制造断裂感。
- **必须先出样张**：改 1-2 段给用户对齐强度，确认后再全篇铺开。
- 底子已自然的稿子无需硬改——直接告诉用户"这篇不用改"。

### B. 通用深度档（用户明确要求时）

适用：公众号、科普稿、营销文案、网文等非学术文本，或用户明确说"往自然了改、往口语了改"。

- 才启用完整 Phase 1-4 流程与标点禁令（冒号/破折号/双引号替换）、口语化词组注入、节奏打碎等激进手段。
- 同样先出样张。

**定档规则**：在套件内处理的文本默认 A 档；仅当用户明确要求深度口语化、或文本本身不是学术语体时才升 B 档。不确定就问一句。

## 二、学术保护红线（凌驾于一切改写规则之上）

无论哪一档，以下内容**一个字都不许动**：

1. **引用与数据**：〔R-xx〕〔综述·X〕等引用标记、参考文献条目、统计数字、量表分值、显著性符号——原样保留，不得删除、改写或"顺手清理"。
2. **术语与专名**：构念名、理论名、期刊名、方法名、变量名——不改写、不口语化。
3. **事实与口径**：研究对象、样本口径、方法条件、结论限制——只改"怎么说"，不改"说什么"（去AI化 ≠ 压缩，不为求短删限定条件）。
4. **文档结构**：章节层级、编号体系（A1-A6/①-⑤等）、图表编号与图注。

发现红线内容与去AI目标冲突时，保红线、标 [需复核]，由用户裁决。

## 三、处理流程

### Phase 1：扫描
快速扫描标记问题位置，按优先级：
1. 最毒句式（"不是A而是B""带着...""心中涌起..."）
2. 禁用词（加载本目录 `references/banned-words.md`）
3. 标点违规（仅 B 档：冒号、破折号、双引号；A 档不动标点体系）
4. 结构问题（加载本目录 `references/structures.md`）
5. 节奏/风格问题

### Phase 2：诊断分级

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度（/千字） | ≤5 | 6-15 | >15 |
| 连续排比段数 | ≤2 | 3-4 | ≥5 |
| 心理词占比 | ≤10% | 10-25% | >25% |
| 对话标签密度 | ≤30% | 30-50% | >50% |
| 平均段落句数 | ≤3 | 3-5 | >5 |

取最高档位。任一达重度即按重度处理；无重度时中度≥3项按中度。（A 档下此表只作参考，不触发激进 Pass。）

### Phase 2.5：量化评分（复核定级，A 档参考 / B 档强制）

> 定性诊断后用统计信号与评分体系做量化复核，定位"机器味"的数据层面证据。完整口径、阈值表与打分规则见 `references/scoring-metrics.md`。

**四项统计信号**（burstiness 突发性 / TTR 型符比 / 句长变异系数 / 三元组重复率）：按阈值判读各指标落入"人类区间"还是"AI 区间"，≥3 项落入 AI 区间 → 升级为重度。

**0-100 AI 味综合打分**：基础分 100，按统计信号 / Tier 1 词汇密度 / 套话密度 / 结构套路 / 填充谄媚 / 破折号加粗滥用六项累加扣分，映射轻 / 中 / 重三级（与 Phase 2 取高者）。

**五维质量评分**（改后验自然度）：直接性 / 节奏 / 信任度 / 真实性 / 精炼度，各 10 分满分 50，45+ 交付（A 档可放宽至 40）。

A 档下统计信号仅作参考、不单独触发改写；B 档强制跑完四项统计信号 + 0-100 打分。学术保护红线凌驾于五维评分之上。

### Phase 3：执行

- **轻度** → 仅 Pass 1（去泛化）
- **中度** → Pass 1 + Pass 2（去书面化）
- **重度** → 完整三遍 + 重点段落重写（仅 B 档）

**Pass 1 去泛化**：禁用词替换为具体动作/细节；心理描写外化；连续排比打断（保留1-2个）；对话标签用动作/上下文替代；（B 档）标点修复。
**Pass 2 去书面化**：句式去套路（`references/structures.md`）；"不是A，而是B"→直接写 B；连接词精简；修饰词清扫；系动词恢复；高频踩雷词替换（`references/banned-words.md` 第八节）。
**Pass 3 回自然感**（仅 B 档）：节奏打碎、长短句交错；口语化表达（`references/banned-words.md` 第九节）；结尾去升华；补具体感官细节；允许适度不完美。

### Phase 4：收敛终止
同一段连续两轮无新改动 → 停止该段；全文上限3轮；第3轮仍有≥10处 → 标注 [需复核]；每轮结束前"再检一次"。

## 四、四层自检（L1-L4，B 档全量执行 / A 档只做 L1+L4）

- **L1 硬性规则**：禁用词扫描、（B 档）标点禁令、结构套话、空泛工具名——零命中方过。
- **L2 风格一致**：开头是否具体切入、节奏是否长短交错、（B 档）口语化是否到位。
- **L3 内容质量**：观点是否有具体人/场景/细节/数据支撑；知识是否"顺手掏出"而非"下面科普"。
- **L4 活人感终审**：通读自问"这是真人在聊，还是 AI 在输出？"——A 档改问"这还像不像一位学者在严谨地说话？"庄重感丢了即返工。

## 五、输出格式

```
## AI味检测报告
- AI味等级：{轻度/中度/重度}  ·  强度档：{A 学术轻量 / B 通用深度}
- 主要问题：{1-3 个关键词}

## 样张（先对齐，勿跳过）
{改写前 1-2 段 vs 改写后}

## 修改统计
- 总修改数 / 禁用词替换 / 标点修复 / 句式调整 / 结构优化：各 N 处

## 润色后全文
{用户确认样张后输出}

## 质检报告（L1-L4）
{按四层自检输出}
```

本域作为后置步骤，跨路径协作以「强度校准结果 + 样张 + 全文改写稿」为可交接形态：

- **A5/A6 → 本域**：论文路径在收尾评分中标记「需去AI」后切本域；本域处理完按用户要求回 论文路径或 综述路径续走交付。
- **综述路径 → 本域**：综述成稿需要全文级改写时切入；综述内部的禁用表达纪律仍以 `../../../literature-review/references/ai-fingerprint-guide.md` 为准，本域不替代它。
- **本域 → 蒸馏路径**：强度校准的新教训交接字段见 `../../references/templates/handoff-protocol.md` 链路六；判层后落点 `../../references/governance/method_accumulation.md`（方法论层）或对应 reference（操作层）。
