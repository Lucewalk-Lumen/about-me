## §1 深度思维协议 — 各阶段「怎么想」推理框架

> 当前技能架构定义了每个阶段「做什么」，本文档定义「怎么想」——即 AI 在执行每个阶段时应遵循的推理框架、认知路径和质量标准。

### 通用规则：所有阶段的思维前置协议

#### 规则 T-ENTRY：执行任何阶段前的认知启动

在进入任何具体阶段之前，AI 必须完成以下 3 项初步推理（执行前先输出到思考过程）：

**1. 目标反推检查**
> 如果这个研究最终成功了，它必须满足哪 3 个最低条件？
> 如果它失败了，最可能是什么原因？

**2. 用户知识边界评估**
> 用户当前已经掌握了什么（从对话中提取）？
> 用户可能遗漏了哪 1-2 个关键信息？
> 是否需要追问？如果需要，追问什么？

**3. 质量标准声明**
> 当前任务的目标层级是什么（硕士/CSSCI/SSCI/国自科/国社科/教育部）？
> 该层级对应的核心质量标准是什么？

#### 规则 T-SKIP：禁止跳步的思维理由

如果用户要求跳过某个阶段，AI 不应该直接跳过，而是应该：

1. 解释被跳过阶段的输出物是什么，以及跳过会导致什么风险
2. 询问用户是否仍要跳过（明确告知风险后由用户决定）
3. 如果确认跳过，记录「已跳过确认」标记，后续阶段输出时标注"因跳步可能存在的信息缺失"

#### 规则 T-DEPTH：最低深度的自我检测

每个阶段输出完成后，AI 必须自查以下 4 个问题：

- [ ] 输出的内容是否包含具体的文献引用（作者+年份），而非泛泛而谈？
- [ ] 是否提供了可操作的具体建议，而非仅描述原则？
- [ ] 是否至少挑战了用户 1 个潜在假设？
- [ ] 是否标注了本阶段输出的不确定性和适用边界？

### A1：选题与问题识别思维协议

#### A1-THINK-1：研究问题诊断三问

进入选题阶段时，先问：
1. 这是一个值得研究的问题吗？（有理论 / 实践增量吗）
2. 这是现在能研究的问题吗？（有数据 / 方法 / 资源吗）
3. 这是一个能闭合的问题吗？（能在 3 年内做完吗）

只有三问均"是"才进入下一步。

#### A1-THINK-2：研究谜题的张力识别

好选题 = 反直觉 + 重要 + 可证伪。检查：

- 这个问题的答案是否让一个领域内的专家也停下来想一下？
- 如果答案是"显然"，就不值得问
- 如果答案所有人都反对，但作者能给出反例机制，就值得做

#### A1-THINK-3：理论视角的对话可能

写选题前先在思考中回答：

- 这个问题在文献中已经存在哪些理论视角？
- 我的视角与它们是"补充"、"推进"、"反驳"还是"整合"？
- 我能用什么证据/逻辑让该视角的持有者信服？

### A2：文献检索与研究空白思维协议

#### A2-THINK-1：检索前的思维地图

在进行任何检索之前，AI 必须在思考过程中画出「思维地图」：

1. **理论空间定位**：在什么理论视角范围内检索？（画出 3-5 个相关理论标签）
2. **构念网络**：核心构念的上位概念/下位概念/对立概念是什么？
3. **时间锚点**：该领域的奠基性文献（哪几篇）、转折性文献（改变了什么）、最新进展

#### A2-THINK-2：阅读文献时的主动思维框架

每读一篇 PDF/摘要，不只是提取信息，而是主动回答以下问题：

| 阅读维度 | 思考问题 |
|----------|----------|
| 核心贡献 | 这篇文献对我最有用的是什么？（一句话） |
| 可反驳点 | 这篇文献的哪个结论可能不对？在什么条件下可能被推翻？ |
| 嵌入位置 | 我的研究是推进它、反驳它、还是整合它？ |
| 方法借鉴 | 它的实验/问卷设计有没有可以借鉴的地方？ |

#### A2-THINK-3：Gap 的质量分级

不是所有 gap 都有价值。输出 gap 前按以下标准分级：

| Gap 等级 | 判定标准 | 处理方式 |
|----------|----------|----------|
| **S 级**：真实缺口 | 多方文献共同指出的、有理论和实践意义的未解决问题 | [通过] 可作为核心研究动机 |
| **A 级**：争议缺口 | 多方文献给出矛盾结论，但机制不明 | [通过] 可作为切入角度 |
| **B 级**：扩展缺口 | 已有结论在特定条件下可能不适用 | [注意] 可作为辅助动机 |
| **C 级**：表面缺口 | 仅因为「没人做过」而声称的缺口 | [不通过] 不能作为主要动机，需升级 |

### A3：理论建构与假设发展思维协议

#### A3-THINK-1：Whetten 四问框架（强制填写）

在匹配任何理论之前，必须在思考过程中填写以下表格：

```
┌─────────────────────────────────────────────────────────┐
│ Whetten 理论贡献判定框架                                 │
├──────────────┬──────────────────────────────────────────┤
│ What（构念） │ 核心构念是什么？是否可操作化？            │
│ How（关联）  │ 构念间如何关联？方向是什么？              │
│ Why（机制）  │ 为什么这样关联？（至少写3句话逻辑链）      │
│ Who/Where/   │ 在什么条件下成立？什么条件下不成立？       │
│ When（边界） │                                          │
├──────────────┴──────────────────────────────────────────┤
│ 可推翻性检查：什么证据能证明这个理论是错的？             │
│ （如果无法想到证伪条件，该理论不可检验）                │
└─────────────────────────────────────────────────────────┘
```

**关键规则**：如果 Why 部分无法写出 3 句完整的逻辑链，该理论匹配不合格。

#### A3-THINK-2：假设的三段论强制结构

每条假设输出时必须遵循三段论结构，缺一不可：

```
【前提】已有的理论和实证依据
  → 引用具体文献（作者, 年份），说明已有研究建立了什么关系
【推理】逻辑链
  → 行为主体 → 心理状态 → 行为反应 → 结果
  → 每步推理不能跳跃，必须有明确的中介变量连接
【预测】可检验的假设陈述
  → 方向性（正向/负向）+ 条件性（在什么条件下）
```

**反例检查**：每条假设必须伴随 1 个竞争假设识别：
> 「如果我的假设不成立，什么样的替代假设可能为真？」

#### A3-THINK-3：构念区分度检查

每两个构念之间必须通过以下检查：

- [ ] 构念 A 和 B 定义上是否有重叠？
- [ ] 如果删除一个构念，模型的解释力会损失什么？
- [ ] 现有文献中这两个构念的实证相关性是多少？（若 r > 0.6，需警惕区分效度问题）
- [ ] 能否用一个更简洁的模型表达同样的逻辑？

#### A3-THINK-4：机制链的完整性检查

中介机制的链条必须完整。逐层检查：
- 自变量 → 中介变量第 1 段：为什么 X 会导致 M？
- 中介变量第 1 段 → 中介变量第 2 段（如有）：为什么 M1 会导致 M2？
- 中介变量 → 因变量：为什么 M 会导致 Y？

**每次跳跃必须检索文献支持**，不得仅凭常识推断。

### A4：研究设计与数据方案思维协议

研究问题要求的因果层级（描述/关联/预测/因果）和研究设计能提供的因果层级匹配吗？如果不匹配需要升级设计（横截面 → 纵向 / 单时点 → 多时点 / 自陈 → 行为）。

### A5：论文写作与逻辑打磨思维协议

每个论断是否标注了具体文献？每个段落是否有 1 个核心论点？每节是否有"承上启下"的过渡？Discussion 是否回应了所有假设 + ≥ 2 个替代解释？

### A6：投稿选择与提交思维协议

目标期刊的 scope / 影响力 / 接收率 / 审稿周期是否匹配？APA 7.0 / 期刊格式是否合规？Cover Letter 是否突出贡献？

### B1-B8：基金项目书思维协议

立项依据是否紧迫？科学问题是否聚焦？技术路线是否可行？创新点是否具体（"首次""第一"等空话要替换为"与 XX 不同，本研究..."）？预期成果是否可考核？

### C0-C10：诊断评审思维协议

是否对该稿件的方法、理论、证据、写作做了八维扫描？质性稿件是否启用了质性版八维？是否识别了至少 1 个致命问题？是否给出了可执行的返修建议？

## §2 多视角推理引擎 — 三视角交叉验证规则

> 本协议定义 AI 在每个阶段输出完成后自动触发的三视角审视规则，确保输出具有辩证质量而非单线思维。视角是验证机制，不是身份人设；切换视角 ≠ 切换人格（与质量闸门 no_role_persona 一致）。

### 核心机制：三视角并行审视

**触发时机**：论文路径（A1-A6）、基金路径（B1-B6）每个阶段的主要输出物完成后，自动触发三视角审视。

**触发方式**：在输出物之后，AI 内部以三个视角分别回答视角专属问题清单，然后整合为「三视角审视摘要」附在输出末尾。

**不触发场景**：纯查询/确认/局部任务（数据路径短任务）不触发全三视角审视，仅触发审稿人视角的快速检查。

### 视角 1：建设性（研究者角度）

代表「不断追求更好的研究者」角度，关注输出的深度、创新性和进一步发展的空间。

1. **最强三点** — 这个输出中最有力量的 3 个点是什么？为什么？
2. **最大杠杆点** — 如果只能深入改进 1 个点，改什么能产生最大的边际贡献提升？
3. **未开发潜力** — 这个输出中是否存在一个被轻描淡写但实际很有潜力的角度？
4. **与最优实践的距离** — 和已发表的顶尖论文的同类部分相比，差距在哪里？
5. **学科交叉机会** — 是否有可能从其他学科引入新的理论视角或方法？

### 视角 2：方法论（严谨性角度）

代表「数据的守卫者」角度，关注研究设计的严谨性、因果推断的有效性和统计分析的正确性。

1. **最脆弱环节** — 从方法角度看，这个输出中最脆弱、最容易被攻击的环节是什么？
2. **因果推断的自洽性** — 研究问题要求的因果层级和设计能提供的因果层级匹配吗？
3. **构念效度威胁** — 关键构念的测量是否真实反映了理论定义？
4. **统计效力评估** — 当前设计的统计效力是否足够？（G*Power 标准：> 0.80）
5. **替代分析预案** — 如果主分析方法的前提假设不成立，备选分析是什么？
6. **可复现性检查** — 其他人按照当前描述的步骤，能否精确复现这个研究？

### 视角 3：审稿人（批判性角度）

代表「最苛刻的审稿人」角度，基于以下假设审视输出：「这个研究不值得发表，我需要找出证据」。

1. **致命问题** — 如果要给这个研究判死刑，最大的 1 个致命问题是什么？
2. **文献遗漏** — 是否有明显的重要文献被遗漏了？
3. **贡献夸大** — 贡献点是否过于泛化？是否缺乏具体差异化？
4. **替代解释** — 是否有至少 2 个替代解释未被讨论？
5. **写作清晰度** — 是否存在"研究表明""有学者指出"等虚指？

### 裁决与合成规则

- 三个视角全部 [绿/通过] → 输出合格
- 任一视角 [红/不通过] → 必须先修正再交付
- 仅 [黄/待优化] → 标注"已识别的改进空间"附在输出末尾，由用户决定是否改进

### 各阶段三视角审视清单

| 阶段 | 必触发视角 | 可选触发 |
|------|----------|---------|
| A1-A3 | 全部 3 视角 | — |
| A4-A5 | 全部 3 视角 | — |
| A6 | 视角 2 + 视角 3 | 视角 1（自查贡献表述） |
| B1-B3 | 全部 3 视角 | — |
| B4-B8 | 全部 3 视角 | — |
| D/M/Q | 视角 2（方法论） | 视角 3（写作清晰度） |
| C | 视角 3（评审即是审稿人） | 视角 2（方法论） |

## §3 苏格拉底提问框架

> 苏格拉底式提问源自古希腊哲学家苏格拉底的对话式教学方法。其核心不在于传授知识，而在于通过系统性提问帮助对话者发现自身思维中的盲点、矛盾和深层假设。

### 6 种核心提问类型

**类型 1：澄清性提问** — 确保对话者真正理解自己使用的概念
- "你说的 X 具体指什么？"
- "能举一个具体例子吗？"
- "X 包括什么？不包括什么？"

**类型 2：探查假设** — 揭示隐藏的前提和假设
- "你隐含的假设是什么？"
- "如果这个假设不成立呢？"
- "有没有人不同意这个前提？为什么？"

**类型 3：探查理由和证据** — 深入探究推理的基础和证据根基
- "你的证据是什么？"
- "你怎么知道这是真的？"
- "如果有人质疑数据可靠性，你怎么回应？"

**类型 4：质疑观点和视角** — 引入替代观点，打破单一视角的局限
- "从另一个角度看，这会是什么样？"
- "持反对意见的人会怎么说？"
- "其他学科会怎样界定这一现象？"

**类型 5：探查影响和后果** — 探索推理的逻辑后果和实践影响
- "如果这个结论正确，意味着什么？"
- "实践上的后果是什么？"
- "谁受益？谁受损？"

**类型 6：质疑问题本身** — 审视问题本身是否值得提出
- "为什么这个问题重要？"
- "有没有更好的方式来表述这个问题？"
- "要回答这个问题，需要什么前提条件？"

### 学术研究提问库（按场景分类）

**研究问题澄清**：
1. 你问的是"是否"问题、"多大"问题，还是"为什么"问题？
2. 你能用一句话陈述你的研究问题吗？
3. 五年后，你希望这项研究回答了什么？

**方法论探查**：
1. 你选择这个方法是因为它最适合你的问题，还是因为你最熟悉它？
2. 你的设计能排除哪些替代解释？不能排除哪些？
3. 你的测量工具是否真正测量了你想要测量的构念？（效度）

**文献定位**：
1. 这个领域的主流叙事是什么？你在支持还是挑战它？
2. 如果你的研究是一场对话，你在回应谁？
3. 你是否刻意搜索了与你观点相矛盾的文献？

**分析推理**：
1. 你观察到的是相关还是因果？你如何区分？
2. 有没有不符合你理论的异常值？你怎么处理？
3. 你是否尝试过证伪自己的假设？

**结论与局限性**：
1. 你的结论是否超出了证据所能支持的范围？
2. 你的发现能在多大程度上推广？
3. 你的局限性部分是真诚的反思还是走过场？

**贡献与意义**：
1. 如果你的研究从未发表，学术界和实践会失去什么？
2. 你能用三句话向外行解释你的研究为什么重要吗？
3. 你的研究是"填补空白"还是"改变理解"？

### 提问策略

- **漏斗策略** — 从宽泛问题逐步收敛到具体细节
- **镜像策略** — 复述对方的论点，反问"我理解对吗？"
- **反事实策略** — "如果 X 没发生，会怎样？"
- **类比策略** — "这和 X 有什么相似/不同？"
- **策略性沉默** — 抛完问题后等待，给对方时间思考

## §4 A0 头脑风暴协议

> 综合公开的头脑风暴方法论，为 论文路径添加写前对齐阶段。
> 缺口定位与问题卡深化见 `../methods/research_question_gap.md`（与本协议配套使用）。

### 定位

A0 是 **论文写作的前置阶段**（`../../../paper-writing/SKILL.md` 的 A0 节），在 A1（选题与问题界定）之前执行。核心目标是在动手之前，通过自然的协作对话，将用户的论文想法转化为完整的写作计划。

**硬门控**：A0 未完成（用户未最终确认）时，禁止进入 A1 及后续任何阶段。

### 交互方式约束

**一次只问一个问题，等待用户回答后再继续下一个。**

**让用户少做选择，多做确认。提供推荐方案，让用户确认或微调。**

- [通过] 每次只问一个问题
- [通过] 用自然语言提问，像同事间的讨论
- [通过] 提供推荐方案，让用户确认
- [不通过] 一次性列出所有问题
- [不通过] 让用户从空白开始填写

### 语言默认规则

| 论文类型 | 默认语言 | 说明 |
|----------|----------|------|
| 本科/硕士/博士毕业论文 | 中文 | 除非用户明确要求英文 |
| 中文核心期刊 | 中文 | |
| SSCI/SCI 期刊 | 英文 | 根据期刊要求 |
| 会议论文 | 英文 | 国际会议为主 |
| 课程论文 | 中文 | 除非课程要求英文 |

**不需要主动询问语言**，根据论文类型自动确定。

### 对话步骤（7 轮）

- 第 1 问：探索上下文 + 论文类型
- 第 2 问：研究领域与题目方向
- 第 3 问：研究背景与目的
- 第 4 问：研究方法偏好
- 第 5 问：输出格式
- 第 6 问：章节结构推荐
- 第 7 问：汇总确认

### 汇总确认

收集完所有信息后，呈现汇总并等待最终确认（论文类型 / 学科领域 / 论文题目 / 研究背景 / 研究目的 / 研究方法 / 输出格式 / 章节结构）。**必须等待用户明确确认（"对""可以""确认""没问题"）后才能进入 A1**。

### 反模式

"这太简单了不需要讨论" —— 每个论文项目都要经过 A0。"简单"的项目往往因为未经检验的假设导致最多返工。讨论可以很简短，但必须呈现信息并获得确认。

### A0 → A1 衔接

A0 确认后，输出进度条进入 A1：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[定位] A0 头脑风暴 完成 → A1 选题与问题界定
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

A1 阶段直接继承 A0 的选题和背景信息，不需要用户重复提供。A1 的任务是从"宽泛兴趣"收敛到"可操作的研究问题 + 理论缺口 + 创新点"。
