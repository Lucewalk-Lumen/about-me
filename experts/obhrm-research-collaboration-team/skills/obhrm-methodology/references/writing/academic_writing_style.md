## 核心原则

### 1. 精确性
- 使用最精确的术语
- 技术术语首次出现时必须定义
- 避免无明确指代的代词（"这个""它"）

### 2. 简洁性
- 消除填充词和冗余表达
- 一句话表达一个核心意思（或紧密关联的意思）
- 复杂观点优先使用短句

### 3. 客观性
- 主张基于证据，非主观意见
- 对不确定的主张使用限制性表达
- 承认局限性和替代解释

### 4. 正式性
- 使用完整形式（"不应"而非"别"）
- 使用正式学术词汇，避免口语化表达
- OBHRM领域通常使用第三人称或"本研究"

## 学科语域调整

### 社科风格（管理世界、南开管理评论等）
```
语域：正式，论辩性强，背景驱动
人称：鼓励主动语态，可用"本研究""本文"
术语：宏观构念、政策话语、情境描述
示例："在数字化转型的背景下，组织韧性已成为企业应对环境不确定性的关键能力。"
```

### 自科风格（心理科学进展、心理学报等）
```
语域：正式，概念驱动，操作化精确
人称：主动语态为主，可用"我们"
术语：心理构念、操作化定义、统计指标
示例："本研究采用实验设计操纵任务互赖性（高vs低），考察其对合作行为的因果影响（N=120）。"
```

## 限制性表达与确定性表达

### 限制性表达（用于不确定或有限的主张）

| 强度 | 表达方式 | 示例 |
|------|---------|------|
| 弱 | "可能""或许""在一定程度上" | "这可能暗示两者之间存在相关关系。" |
| 中 | "表明""显示""似乎" | "数据表明存在正向趋势。" |
| 强 | "证实""确认""明确显示" | "证据证实两者之间存在因果关系。" |

### 何时使用限制性表达
- 需要复现验证的结果
- 来自相关数据（非实验）的因果推断
- 来自有限样本的推广
- 有替代解释的发现

### 何时不应使用限制性表达
- 报告事实数据："有效回收率为78%。"（不是"似乎为"）
- 描述方法："本研究采用主题分析法。"（不是"试图采用"）
- 已确立的事实：直接陈述

## 过渡连接词

### 递进
此外、进一步地、更重要的是、与此同时、类似地

### 转折
然而、不过、相比之下、另一方面、尽管如此、反之

### 因果
因此、由此、结果表明、进而、从而、基于此

### 举例
例如、具体而言、以...为例、其中、特别是

### 序列
首先、其次、第三、随后、最终、同时

### 总结
综上所述、总体而言、概括来说、由此可见

### 让步
尽管、虽然、诚然、固然、即使如此

## 段落构建（TEEL结构）

1. **T**（Topic）主题句——陈述该段落的核心观点
2. **E**（Evidence）证据——数据、引用、案例支撑观点
3. **E**（Explanation）解释——解读证据，连接到论证
4. **L**（Link）链接——连接下一段或回归核心论点

### 示例
> **[T]** 变革型领导对员工创新行为具有显著的正向影响。**[E]** 基于238份问卷数据的实证研究发现，变革型领导每提升1个标准差，员工创新行为提升0.32个标准差（β=0.32, p<0.01）；多时点追踪研究亦得到一致结论。**[E]** 这一发现表明，变革型领导通过激发员工的内在动机和创造力自我效能感，促进其突破常规思维模式。**[L]** 然而，该效应是否在不同权力距离文化中存在差异，仍需进一步考察。

## 常见写作错误

### 冗余表达

| 冗余 | 简洁 |
|------|------|
| 为了能够 | 以便 |
| 由于...的原因 | 因为 |
| 大量的 | 许多 |
| 在当前的时候 | 目前 |
| 值得注意的是 | 具体来看 |
| 在...的情况下 | 当...时 |
| 具有...的能力 | 可以 |
| 关于...的问题 | 关于... |
| 尽管有着...的事实 | 尽管 |

### 空泛表达

| 空泛 | 精确 |
|------|------|
| "许多研究" | "多项研究（如近三年发表于主流期刊的相关研究）" |
| "显著影响" | "提升23%的留存率" |
| "近年来" | "2020年以来"或"过去五年中" |
| "有研究者认为" | 明确指出具体研究来源（作者与年份） |
| "众所周知" | 指出具体研究来源，或直接删除 |

### 时态使用

| 部分 | 时态 | 示例 |
|------|------|------|
| 文献综述（报告发现） | 过去时 | "该研究发现..." |
| 文献综述（理论框架） | 现在时 | "社会交换理论认为..." |
| 方法 | 过去时 | "数据通过问卷调查收集..." |
| 结果 | 过去时 | "分析表明..." |
| 讨论（解释发现） | 现在时 | "这些发现暗示..." |
| 结论（启示） | 现在/将来时 | "这对...有启示 / 未来研究应..." |

## 中文学术写作注意事项

### 避免翻译腔
- 错误："被发现是"→ 正确："结果表明"
- 错误："这是因为"→ 正确："原因在于"
- 错误："在...的方面"→ 正确：直接陈述
- 错误："值得注意的是"（AI高频词）→ 正确：直接表达具体内容

### AI痕迹词检测与替换

以下表达在学术论文中高频出现，建议替换：

| AI痕迹词 | 替换建议 |
|---------|---------|
| 值得注意的是 | 删除，或改为具体内容 |
| 综上所述 | 概括来说 / 由此可见 |
| 不难发现 | 具体改为"数据分析表明" |
| 不可否认 | 根据证据 / 研究显示 |
| 旨在 | 以...为目的 / 目标是 |
| 为...提供了重要启示 | 具体说明对谁、有何启示 |
| 具有/拥有 | 有 / 表现出 |
| 研究者发现 | 直接引用具体作者 |
| 与此同时 | 同时 / 此外 |
| 深入探讨 | 分析 / 检验 / 考察 |

## 去AI化写作增强（综合学术写作规范）

> 去AI化不是把原文压短。除非明确要求缩写，不主动删减事实、数据、限定条件和解释句。研究对象、数据范围、样本口径、方法条件、指标含义、实验边界、结论限制和专有名词都应保留。语言调整只服务于表达自然、逻辑清楚和口径稳定。

### 常见AI化症状与处理

| 症状 | 表现 | 处理方式 |
|------|------|----------|
| 句式像英文直译 | "X被发现对Y有正向影响" | 改为中文常用语序："X正向影响Y" |
| 段落过度模板化 | 固定的"背景-方法-结果-意义"句组 | 取消固定节奏，保留解释句和承接句 |
| 改写后信息变少 | 删去了样本量、数据口径、方法条件 | 补回研究对象、数据范围、方法条件和结论边界 |
| 审稿回复口吻 | "该指标反映的是""不能理解为" | 改成正文叙述："本文将...作为参照" |
| 空泛拔高 | "对理论和实践具有重要启示" | 用具体指标/现象/限定替代泛化词 |
| 列表堆砌观点 | 正文使用项目符号罗列发现 | 转为连续段落，补足主语、谓语和连接成分 |

### 去AI化 ≠ 压缩

去AI化时常见的错误是过度压缩。以下信息即使让句子变长也应保留：

- **研究对象**：谁/什么被研究
- **数据范围**：样本量、时间跨度、来源
- **方法条件**：使用什么方法、什么条件下
- **指标含义**：变量怎么测量
- **结论边界**：适用范围和限制

### 自然行文原则

中文期刊论文不追求每句话都极度精简。更自然的写法：

- 先交代研究对象、资料范围或问题背景
- 再说明处理方法、结果现象和判断边界
- 句子可以略长，段落中可以有必要的承接、限定和少量重复
- 只要主语明确、关系清楚、读者能够顺着研究过程理解即可

当用户反馈"太AI""太精简""像翻译"时，处理顺序：
1. 补回必要信息（检查是否丢失方法论细节）
2. 调整为中文自然语序（先对象后判断）
3. 再收束过强判断（不要简单删词）

## 去AI化扩展模式库

> 以下模式表用于**自检与改写**，与上文中文症状表互补。学术写作仍保持克制语气，但应避免可预测的机械模式。

### 内容模式（Content Patterns）

| 模式 | 英文示例 | 中文示例 | 处理 |
|------|----------|----------|------|
| 过度强调 | "stands as a testament", "crucial role" | "作为……的证明"，"关键作用" | 改为具体作用陈述 |
| 宣传腔 | "vibrant", "breathtaking" | "充满活力的"，"令人叹为观止" | 删除或换中性词 |
| 模糊归因 | "Experts believe", "Observers note" | "专家认为"，"观察者指出" | 改为具体来源："根据[作者/年份]" |
| 肤浅 -ing 分析 | "highlighting the importance" | "强调……的重要性" | 直接说结论 |
| 套路化"挑战"段 | "Despite X, faces challenges" | "尽管……面临挑战" | 改写具体障碍 |

### 语言模式（Language Patterns）

| 模式 | 英文 | 中文 | 处理 |
|------|------|------|------|
| AI 词汇 | Additionally, crucial, delve, enhance, landscape | 此外，至关重要，深入探讨，增强，格局 | 换具体动词 |
| 系词回避 | "serves as", "represents" | "作为"，"代表" | 用"是/有/表明" |
| 破折号滥用 | 过度使用 — | 过度使用破折号 | 改用逗号或分句 |
| 强行三段式 | 把观点硬塞成三组 | 强行三段式 | 用二或四项 |
| 优雅换词 | 过度同义替换 | 过度换词 | 保持术语一致 |

### 快速评分量表（1–10，总分 50）

| 维度 | 提问 | 标准 |
|------|------|------|
| 直接性 Directness | 直接陈述还是绕圈？ | 45–50 优；35–44 良；<35 需改 |
| 节奏 Rhythm | 句式有变化还是机械重复？ | 同上 |
| 信任 Trust | 是否尊重读者、不手把手？ | 同上 |
| 真实 Authenticity | 听起来像真人还是模板？ | 同上 |
| 密度 Density | 有可删的空话吗？ | 同上 |

### 注入声音（适配学术语境）

避免 AI 模式只是半件事； sterile 无声音的写法同样显眼。学术写作中：
- **变换节奏**：短句与长句交错，段落结尾不一刀切。
- **承认复杂**：真实研究有混合发现，"本结果支持 H1 但在低自主样本中减弱"胜过"结果支持假设"。
- **具体优于模糊**：用具体发现/数值替代"具有重要意义"。
- 学术文体下**第一人称克制使用**（"本文发现"即可），但允许在讨论局限与未来方向时适度主观判断。

## 顶刊通用写作原则

> 本节汇总学术期刊通用的写作规范，与 `../reasoning/argument_frameworks.md`、Red Flags 系统一致，适用于 HRM/OB 等各类期刊。

### 证据优先（Evidence First）
不编造数据、机制、样本量或新颖性。每条主张须有来源或结果支撑——与 `../templates/verification_and_failure_modes.md` 的"无证据不得声称"同源。

### 证据阶梯（Evidence Ladder）
结果叙述按**证据强度阶梯**组织，而非按时间顺序的"实验日记"。从最强证据（假设检验/对比/消融）到补充证据层层推进。

### 章节架构要点

| 章节 | 核心结构 |
|------|----------|
| 摘要 | 背景 → 缺口 → 方法 → 关键结果 → 含义 → 边界 |
| 引言 | 领域尺度 → 瓶颈 → 既有尝试 → 未解缺口 → 本研究 |
| 方法 | 模块动机 → 设计 → 前向过程 → 技术优势 |
| 结果 | 每条主要主张绑定对比/消融/指标/压力测试证据 |
| 讨论 | 解释含义 → 与既有工作关系 → 约束与未来用途 |

### 对抗自审（Adversarial Self-Review）
投稿前运行对抗性自审：逐条假设"审稿人可能如何推翻此结论"，提前补强或限定。与诊断审稿域（审稿路径偏倚检测）互补。

### 中英意图翻译
从中文草稿生成英文时，**翻译意图与论证，而非逐句语序**。先还原中文句子的研究动作（比较/调节/中介），再用英文自然重构，避免"英式中文"腔。

> 注意：Nature 特有的极简 stylistic 要求（如极致压缩）并非 HRM 期刊通例；本技能取其**通用原则**（证据阶梯/架构/自审/意图翻译），stylistic 压缩按目标期刊调整。
