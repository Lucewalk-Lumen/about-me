## 一、中文期刊论文

### 基本格式

```
作者 (年份). 文章标题. 期刊名称, 卷号(期号), 页码. https://doi.org/xxxxx
```

### OBHRM 示例

**单作者**：
```
张三 (2024). 变革型领导对员工创新行为的影响机制：心理安全感的中介作用. 管理世界, 40(3), 120-135. https://doi.org/10.19744/j.cnki.11-1235/f.2024.0031
```

**两位作者**：
```
李四, 王五 (2023). 组织公平感对员工沉默行为的影响：领导成员交换的调节作用. 心理学报, 55(8), 945-960.
```

**三位及以上作者**：
```
赵六, 孙七, 周八, 吴九, 郑十 (2024). 远程办公对工作投入的影响：工作-家庭冲突的多层中介. 南开管理评论, 27(2), 78-92.
```

**英文期刊（OBHRM 领域）**：
```
Zhang, Y., & Liao, Z. (2024). Authentic leadership and employee voice: A moderated mediation model of psychological safety and power distance. Journal of Applied Psychology, 109(4), 580-598. https://doi.org/10.1037/apl0001153
```

### 正文引用

| 场景 | 中文文献 | 英文文献 |
|------|---------|---------|
| 单作者叙述 | 张三 (2024) 发现… | Zhang (2024) found... |
| 单作者括号 | （张三，2024） | (Zhang, 2024) |
| 两位作者叙述 | 李四和王五 (2023) | Zhang & Liao (2024) |
| 两位作者括号 | （李四、王五，2023） | (Zhang & Liao, 2024) |
| 三位及以上 | 张三等 (2024) | Zhang et al. (2024) |
| 括号三位及以上 | （张三等，2024） | (Zhang et al., 2024) |

## 二、中文专著

### 基本格式

```
作者 (年份). 书名. 出版社.
```

### 示例

```
陈春花 (2022). 组织行为学（第4版）. 机械工业出版社.
罗宾斯, 贾奇 (2020). 组织行为学（第18版）(孙健敏, 译). 中国人民大学出版社. (原著出版于2019年)
```

## 三、中文学位论文

```
作者 (年份). 论文标题（博士学位论文/硕士学位论文）. 授予单位.
```

```
刘明 (2023). 零工经济背景下平台工作者的职业认同与工作投入研究（硕士学位论文）. 北京大学.
```

## 四、中文书中章节

```
章作者 (年份). 章节标题. 见 编者 (编), 书名 (页码). 出版社.
```

```
王建 (2023). 中国情境下的领导力研究. 见 张力 (编), 组织行为学前沿 (pp. 45-78). 北京大学出版社.
```

## 五、中文与英文混合引用规则

### 参考文献列表排列

**方案 A（推荐）：中英文分列**
- 中文参考文献在前，按作者姓氏拼音或笔画排序
- 英文参考文献在后，按作者姓氏字母排序
- 用二级标题分隔："中文参考文献""English References"

**方案 B：混合排列**
- 所有文献按作者姓氏排序，中文在前或按拼音字母插入对应位置
- 遵循目标期刊要求

### 标点符号差异

| 元素 | 中文文献 | 英文文献 |
|------|---------|---------|
| 括号 | 全角（） | 半角() |
| 多作者连接 | 顿号、 | & |
| 三位及以上 | 等 | et al. |
| 页码指示 | 无 | p. / pp. |

## 六、OBHRM 常见引用错误

### 1. 作者格式

| 错误 | 正确 | 说明 |
|------|------|------|
| Da-Ming Wang (2024) | Wang, D. M. (2024) | 英文文献姓在前 |
| 张三 (2024年) | 张三 (2024) | 不加"年"字 |
| 张三和李四 (2024) | 张三、李四 (2024) | 中文用顿号，英文用 & |

### 2. DOI 格式

| 错误 | 正确 | 说明 |
|------|------|------|
| doi: 10.xxxx | https://doi.org/10.xxxx | 使用 https://doi.org/ 前缀 |
| 末尾加句号 | 末尾不加句号 | DOI/URL 后无标点 |

### 3. 翻译著作

| 错误 | 正确 |
|------|------|
| 罗宾斯，张三译 (2020) | 罗宾斯 (2020). 书名 (张三, 译). 出版社. (原著出版于2019年) |

## 七、常见 OBHRM 引用来源速查

| 来源类型 | 引用格式要点 |
|---------|------------|
| SSCI 期刊（JAP, JOM, OBHDP 等） | 标准 APA 7 英文格式，DOI 必须包含 |
| CSSCI 期刊（管理世界, 心理学报, 南开管理评论 等） | 中文格式，部分期刊要求英文翻译附在括号中 |
| 学位论文 | 标注博士/硕士、授予单位 |
| 量表来源 | 按专著或期刊论文引用，须标注原量表文献 |
| 在线预印本 | SSRN/Research Square：标注平台、DOI |
| 数据库/统计年鉴 | 标注来源机构和获取 URL |

## 八、自检清单

- [ ] 所有正文引用都有对应的参考文献条目
- [ ] 所有参考文献条目都有正文引用
- [ ] 中文用全角标点，英文用半角标点
- [ ] 三位及以上作者使用"等"或"et al."
- [ ] DOI 格式统一为 https://doi.org/xxx
- [ ] DOI/URL 末尾无标点
- [ ] 翻译著作包含原著出版年份
- [ ] 量表来源有完整引用

## 一、论文特定 APA 规则

### 标题页格式

**专业论文（投稿用）**：
```
论文标题（加粗，居中，首字母大写）
[空一行]
作者姓名
单位/机构
[空一行]
作者注（可选）
```

**学生论文（课程作业）**：
```
论文标题（加粗，居中，首字母大写）
[空一行]
作者姓名
院系，学校名称
课程编号：课程名称
指导教师
提交日期
```

### 页眉（Running Head）
- 专业论文：缩略标题（不超过 50 字符），全部大写，左对齐页眉
- 学生论文：无需页眉（APA 7 相对第 6 版的变更）

### 摘要页
- 标题："Abstract"（居中，加粗，不缩进）
- 单独一段，不缩进，150–250 词（期刊可能另有规定）
- 关键词行："Keywords:" 斜体，后跟小写关键词，逗号分隔

---

## 二、章节标题层级

| 层级 | 格式 | 示例 |
|------|------|------|
| 1 | 居中，加粗，首字母大写 | **引言** |
| 2 | 左对齐，加粗，首字母大写 | **理论框架** |
| 3 | 左对齐，加粗斜体，首字母大写 | ***建构主义视角*** |
| 4 | 缩进，加粗，首字母大写，句号结束 | **社会建构主义。** 正文继续… |
| 5 | 缩进，加粗斜体，首字母大写，句号结束 | ***维果茨基最近发展区。*** 正文继续… |

**使用规则**：
- 不得跳级（如不能从 1 级直接到 3 级）
- 引言部分不需要 1 级标题（默认即为引言）
- 同级子节至少需要 2 个并列段落

## 三、扩展引用规则

### 21 位及以上作者
列出前 19 位作者，省略号（…），最后一位作者：
```
Author, A., Author, B., ..., Author, S., ... Author, Z. (Year).
```

### 团体作者
- 首次引用：全称（缩写）— 如 World Health Organization (WHO)
- 后续引用：仅用缩写 — 如 WHO
- 参考文献列表中：写出全称

### 无作者作品
- 作者位置使用标题
- 正文引用：用短标题加引号（"短标题", Year）
- 参考文献列表：按标题第一个实词字母排序

### 个人通信
- 仅正文引用：(J. Smith, 个人通信, 2024年3月15日)
- 不列入参考文献列表（不可追溯数据）

### 经典著作
- 无需日期（广为人知的经典作品）
- 使用原始出版日期/翻译日期：(Aristotle, trans. 1925)

### 法律文献
- 法律材料遵循 *Bluebook* 格式
- 案例名称斜体：*Brown v. Board of Education* (1954)

## 四、扩展参考文献格式

### 软件/应用程序
```
作者, A. A. (年份). 软件名称 (版本 X.X) [计算机软件]. 出版者. URL
```

### 社交媒体
```
作者 [@账号]. (年份, 月 日). 帖子内容（前20字）[帖子类型]. 平台. URL
```

### 播客节目
```
主持人, A. A. (主持人). (年份, 月 日). 节目标题 (第X集) [音频播客]. 播客名称. 出版者. URL
```

### 视频网站（YouTube/B站）
```
作者 [用户名]. (年份, 月 日). 视频标题 [视频]. 平台. URL
```

### 预印本
```
作者, A. A. (年份). 预印本标题. 预印本平台名称. https://doi.org/xxxxx
```

### AI 生成内容（APA 指引）
```
引用 AI 生成文本时：
OpenAI. (2024). ChatGPT (版本 4) [大语言模型]. https://chat.openai.com
注意：在正文中描述使用的提示词。AI 输出不可追溯，
如需展示，请在附录中提供提示词和输出内容。
```

## 五、表格与图表（扩展）

### 表格格式

```
表 1

描述性标题（斜体，首字母大写）

列标题    列标题    列标题
──────────────────────────────────
行1数据   行1数据   行1数据
行2数据   行2数据   行2数据
──────────────────────────────────

注. 一般说明。特定列或单元格的说明。
a 特定标注. b 特定标注.
* p < .05. ** p < .01. *** p < .001.
```

### 图表格式

```
图 1

描述性标题（斜体，首字母大写）

[图表内容]

注. 描述和必要的解释。
改编自"标题"，作者 A.，年份，期刊名，卷号，页码
(https://doi.org/xxxxx). 版权所有年份，版权持有者。
```

## 六、数字与统计报告规范

### 统计符号
- 统计符号斜体：*M*、*SD*、*t*、*F*、*p*、*N*、*n*、*r*、*R²*
- 报告精确 *p* 值：*p* = .032（非 *p* < .05），除非 *p* < .001
- 效应量：必须报告（Cohen's *d*、η²、*r*）
- 置信区间：95% CI [下限, 上限]

### 小数位数

| 统计量 | 小数位数 |
|--------|----------|
| 比率、相关系数、推断统计 | 2 |
| 百分比 | 0 或 1 |
| 均值、标准差 | 2（或与测量精度一致） |
| *p* 值 | 3（报告精确值，除非 < .001） |

## 七、无偏见语言

### 以人优先 vs. 以身份优先
- 一般优先使用"以人优先"表达："people with disabilities"（有障碍的人）
- 尊重社群偏好："Deaf community"（大写 D）

### 性别
- 使用"they/them"作为单数中性代词
- 避免"he or she"——使用"they"
- 使用具体词汇："women and men"（女性和男性）而非"males and females"（除非指生物学性别）

### 年龄
- 使用具体范围："older adults (65+)"（65岁以上老年人）而非"the elderly"（老年人）

### 种族/族群身份
- 首字母大写：Black、White、Indigenous、Asian American
- 尽可能具体："Korean American"（韩裔美国人）而非笼统的"Asian"（亚洲人）

## 八、完整论文常见格式错误

1. **摘要与正文不一致** — 摘要先写，正文后续修改，摘要未同步更新
2. **引言有标题** — APA 7 中引言不需要"Introduction"标题
3. **参考文献悬挂缩进缺失** — 每条参考文献首行不缩进，后续行缩进
4. **"et al."句号遗漏** — "et al." 有句号，因为"al."是缩写
5. **正文中使用"&"** — 叙述文本中用"and"；"&"仅用于括号内引用和参考文献列表
6. **长引用格式错误** — ≥40 词：缩进，不用引号，引用在末尾句号之后
7. **序列逗号缺失** — APA 使用牛津逗号："A, B, and C"
8. **过度使用被动语态** — APA 7 鼓励主动语态；仅在行为主体未知时使用被动语态
