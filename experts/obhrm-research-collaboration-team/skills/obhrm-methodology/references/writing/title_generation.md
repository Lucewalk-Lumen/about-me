# 论文标题方案生成指南

> 场景触发：用户要求「起标题 / 生成标题方案 / 标题怎么起」。
> 定位：标题是论文在 PubMed/Google Scholar 的第一入口——既要被搜到，也要吸引点击。

## 一、标题四要素

任何合格标题必须包含三个信息要素：
1. **研究对象（what）**：研究的是什么；
2. **方法视角（how）**：从什么角度/用什么方法；
3. **核心贡献（so what）**：带来了什么新东西。

## 二、四种修辞类型（每种至少出 1 个方案）

| 类型 | 特征 | 适用 |
|------|------|------|
| 声明型 Declarative | 直接陈述研究发现/核心结论 | 有明确因果推断或强实证结果 |
| 描述型 Descriptive | 概括主题与范围，不揭示结论 | 综述、方法论论文、探索性研究 |
| 疑问型 Interrogative | 以研究问题本身作标题 | 理论争鸣、假设存争议 |
| 冒号型 Colon | 前段关键词/概念 + 后段内容方法 | 通用性强，各领域皆宜 |

## 三、生成约束（硬性）

1. 长度：中文 ≤ 25 字，英文 ≤ 20 词（多数 Q1 期刊上限）；
2. 关键检索词优先出现在标题**前半段**（Google Scholar/PubMed 对前 60 字符权重更高）；
3. 严禁空泛句式：「关于……的研究」「……之探讨」「A study of...」「Investigation of...」；
4. 每个方案附 2-3 句修辞策略说明（该标题在 desk review 阶段可能引发的第一印象）。

## 四、输出格式（Markdown 表格）

| 列 | 内容 |
|----|------|
| 标题方案 | 中英文各一版 |
| 修辞类型 | Declarative / Descriptive / Interrogative / Colon |
| 信息密度评分（1-10） | 标题中可独立提取的信息量 |
| 可发现性评分（1-10） | 关键检索词的位置与密度 |
| 适用期刊类型 | 目标期刊定位 |
| 引用优势与风险 | 潜在引用影响 |

## 五、配合使用

- 与 `abstract_writing_guide.md` 配套：先定标题（锚定核心贡献），再写摘要五段式。
- 标题打磨在 A0-A1 阶段完成，随论文演进可再收敛；A6 投稿前按目标期刊微风格再核一遍长度与检索词。
