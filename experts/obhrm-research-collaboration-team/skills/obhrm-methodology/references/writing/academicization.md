# 学术化表达转换（作者侧 · 三条底线）

> 通用学术化表达转换规则（三条底线 + 转换对照表），裁剪为 OBHRM 研究语境下的作者侧应用。

## 一、适用边界

- **对象**：作者手稿中**口语化 / 感受性 / 经验性**表达，需升级为学术严谨表述。典型输入："把这段口语改学术""这段话太口语了""帮我学术化一下"。
- **与既有能力区分**（三者不互相替代）：
  - **本方法（学术化转换）**：解决"表达不学术"——把每一个判断补上证据来源与限定条件。输入是有内容、但语言松的表达。
  - **humanize 域（去 AI 痕）**：解决"机器味"——去除 AI 生成文本的统计与套话特征。输入是 AI 腔文本。
  - **reviewer-tone 规范**（`../review/review_writing.md`）：解决"审稿人语气"——是**审稿意见**怎么写得专业，而非作者正文怎么写。
- **前置**：A5 成稿润色阶段或任意单段改写请求均可调用。

## 二、核心判断

> **一句话方法论**：学术化不是"换一套更高级的词汇"，而是**把每一个判断都补上它应有的证据来源和限定条件**——凡是改完之后读者仍然无法追问"你怎么知道的"，就还没有真正学术化。

## 三、三条底线原则

### 底线 1：去感受化，补证据
- **问题表征**：纯粹的主观感受判断（"挺好用的""学生很喜欢""效果不错"），读者无法核实。
- **改写动作**：补上支撑该判断的具体证据，或改写为可核实的客观描述（观察者立场、可测量指标）。
- **示例**：
  - 原：「我觉得这个方法挺好用的」→ 改：「研究者在教学实践中观察到，该方法在……方面呈现出良好的适用性」
  - 原：「员工普遍反映培训有帮助」→ 改：「培训后调研显示，X% 的参与者认为培训'有帮助'，且后续 3 个月绩效较培训前提升 Y%」

### 底线 2：去绝对化，加限定
- **问题表征**：没有数据支撑的绝对化断言（"能显著提升""极大地增强了""必然导致"）。
- **改写动作**：改写为带有限定范围与依据的表述，因果断言收紧为有限度的、留有余地的结论。
- **示例**：
  - 原：「效果特别好」→ 改：「实验班后测平均分较前测提升 X 分，且与对照班存在显著差异（p<0.05）」
  - 原：「这个方法能显著提升成绩」→ 改：「在为期 X 周的实践后，实验组在……测评中的表现优于对照组，初步表明该方法对……具有积极作用」
  - 原：「领导风格必然提升团队绩效」→ 改：「在样本情境下，变革型领导与团队绩效呈显著正相关（β=…，p<0.05），其效应受……调节」

### 底线 3：去车轱辘话，加深度
- **问题表征**：反复重申一个常识性判断，没有推进分析（"手工活动能锻炼动手能力""沟通很重要"）。
- **改写动作**：不重复常识，而深入分析具体促进了哪些**具体的、可观察的**维度或机制。
- **示例**：
  - 原：「孩子们玩得可开心了」→ 改：「游戏化教学设计激发了学生显著的参与热情，具体表现为课堂主动发言频次增加、小组协作任务完成度提升」
  - 原：「团队协作很重要」→ 改：「跨职能协作通过降低信息壁垒与重复劳动，缩短了需求交付周期，其增益在任务不确定性较高时更明显」

## 四、转换对照表（可直接套用的句式模板）

| 口语化 / 感受性表达 | 学术化转换后 | 转换逻辑 |
|---|---|---|
| "我觉得这个方法挺好用的" | "研究者在教学实践中观察到，该方法在……方面呈现出良好的适用性" | 主观判断 → 观察者立场的客观陈述 |
| "学生也挺喜欢" | "问卷调查显示，X% 的学生认为该方法'有帮助'/'愿意继续使用'，学生课堂参与度较实施前明显提升" | 感受 → 可核实的调查数据 |
| "效果特别好" | "实验班后测平均分较前测提升 X 分，且与对照班存在显著差异（p<0.05）" | 绝对化断言 → 具体数据 + 统计意义 |
| "孩子们玩得可开心了" | "游戏化教学设计激发了学生显著的参与热情，具体表现为……" | 口语情绪词 → 行为化描述 |
| "这个方法能显著提升成绩" | "在为期 X 周的实践后，实验组在……测评中的表现优于对照组，初步表明该方法对……具有积极作用" | 因果断言收紧为有限度的、留有余地的学术表述 |

> 表中示例为来源包的学科情境示例，方法本身通用；OBHRM 研究写作时把"学生/班级"替换为"员工/团队/样本"、把"教学"替换为"管理干预"即可直接套用。

## 五、双版本策略（数据缺失时）

当某一判断**暂无具体数据支撑**时，按来源包工作流，同时给出两个版本供用户选择：
- **有数据版**：用真实测量结果表述（优先，符合学术诚信）。
- **留有余地的过渡版**：用限定性、方向性表述暂代，并**明确提醒后续补充数据**，不编造数值。

> 例：原「我们的干预很有效」→ 有数据版「干预组后测较前测提升 X 分（p<0.05）」；过渡版「初步观察表明，该干预对……可能具有积极作用，待后续样本扩充后验证」。

## 六、边界（学术化 ≠ 清除个人色彩）

- 学术化**不要求**删除所有个人色彩：叙事性、案例类、反思性写作可保留研究者的视角与细节。
- 核心底线始终是：**每个判断都有证据支撑、每个结论都留有恰当限度**；分寸结合论文体例（实证 / 理论 / 案例 / 综述）灵活处理。
- **学术诚信红线**：绝不编造数据、案例或文献来"填充"证据缺口；缺证据时标注待补，而非用套话掩盖。

## 七、与既有资产联动

| 场景 | 调用 |
|------|------|
| A5 成稿语言润色 | 本方法（口语/经验性→学术严谨）+ `humanize` 域（去 AI 腔）+ `./academic_writing_style.md`（学术语体规范）三者并行 |
| 被要求"改学术"的单段请求 | 直接套用第三节三条底线 + 第四节对照表 |
| 数据缺失的判断 | 第五节双版本策略，标注待补而非编造 |
| 自检 | 第八节清单 + A5 收尾核对清单「论证连接」项 |

## 八、学术化转换自检清单

- [ ] 每一处主观感受判断是否已补证据或可核实客观描述（底线1）
- [ ] 每一处绝对化断言是否已加限定与依据，因果已收紧（底线2）
- [ ] 是否消除了反复重申的常识性车轱辘话，改写了深层分析（底线3）
- [ ] 改写后读者能否追问"你怎么知道的"——能，则已学术化；不能，则未达标
- [ ] 数据缺失处是否给了"过渡版"并标注待补，未编造数值
- [ ] 未为套话而删除合理的个人/叙事色彩（结合体例判断）
