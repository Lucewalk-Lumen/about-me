## A. AI高频词警告

以下词汇在AI生成文本中出现频率异常偏高。它们不是被禁止的——但遇到时请自问：**"这是此处最精确的词，还是我在默认使用它？"**

### 中文高频词

| 词汇 | 为何标记 | 替换建议（视语境而定） |
|------|---------|---------------------|
| 值得注意的是 | 空洞过渡，AI出现率极高 | 删除，直接表达具体内容 |
| 综上所述 | 空洞总结 | 概括来说 / 由此可见 / 具体来看 |
| 不难发现 | 预设读者认同 | 具体改为"数据分析表明""结果显示" |
| 不可否认 | 无信息量 | 根据证据 / 研究显示 |
| 旨在 | 翻译腔 | 以...为目标 / 目的是 |
| 为...提供了重要启示 | 空泛贡献 | 具体说明对谁、有何启示 |
| 深入探讨 | 过度使用 | 分析 / 检验 / 考察 |
| 与此同时 | 过渡词泛滥 | 同时 / 此外 |
| 显著改善 | 未说明方向 | 提升/降低了X（量化） |
| 发挥着重要作用 | 空泛 | 具体说明何种作用 |
| 众所周知 | 不提供来源 | 引用具体文献，或删除 |
| 极其重要 | 未说明重要程度 | 具体说明为何重要 |
| 近年来 | 空洞背景开场白 | 删除，直接切入核心问题 |
| 随着社会的发展 | 空泛无实质 | 删除，直接陈述问题 |
| 越来越受到关注 | 空泛趋势描述 | 具体说明关注程度或数据 |
| 引起了广泛关注 | 空泛套话 | 若确实广泛关注，引用文献证明 |
| 具有重要的理论意义和实践价值 | 空泛贡献 | 具体说明理论/实践贡献是什么 |
| 填补了...空白 | 滥用表述 | 明确说明填补了什么具体空白 |
| 有待进一步研究 | 必然正确的废话 | 删除，或具体说明哪些问题有待研究 |
| 由于上述原因 | 空洞过渡 | 删除 |
| 基于此 | 空洞过渡 | 可简化为 "据此"，或直接陈述结论 |
| 总的来说 | 空洞总结 | 删除或简化为 "综上" |

### 错误→正确示例

| 错误（AI空泛） | 正确（具体） |
|---------|-----------|
| "近年来，随着社会的发展，越来越多的学者关注..." | 直接陈述问题："平台零工劳动中，算法管理与自我领导的关系尚存争议。" |
| "本研究具有重要的理论意义和实践价值" | "本研究从理论上厘清算法化自我领导的构念边界，实践中可为平台零工工作过度投入干预提供参考。" |
| "本研究填补了...领域的空白" | "现有研究尚未关注算法目标内化如何转化为强迫性工作投入，本研究明确这一机制。" |
| "有待进一步研究" | "未来可在更大样本跨行业检验本研究发现。" |

### 英文高频词

| Term | Why flagged | Better alternatives |
|------|-------------|-------------------|
| delve | Overused "explore" substitute | examine, investigate, analyze |
| tapestry | Cliché complexity metaphor | network, interplay, system |
| landscape | Vague when not literal | field, domain, context |
| pivotal | Importance inflation | important, significant, key |
| crucial | Same as above | essential, critical, vital |
| foster | Vague verb | promote, develop, cultivate |
| showcase | Non-academic | demonstrate, illustrate, reveal |
| leverage | Business jargon | use, employ, utilize |
| nuanced | Often vacuous | subtle, detailed, fine-grained |
| robust | Vague quality claim | reliable, strong, rigorous |
| comprehensive | Often unjustified | thorough, extensive, detailed |
| groundbreaking | Inflation | novel, innovative, pioneering |

### 例外规则
若标记词汇是**目标学科的标准化术语**，则豁免（如统计学中的"robust estimator"）。

## B. 标点控制

### 破折号（——）
- **限制**：全篇不超过3处，推荐0-1处
- **原因**：AI文本过度使用破折号做插入说明。学术写作通常用逗号、括号或分句替代
- **修正**：替换为逗号、括号，或拆分为独立句子
- **例外**：引用原文保留原始标点

### 分号（；）
- **限制**：每1000字不超过2个
- **原因**：AI文本倾向用分号串联独立分句，而用句号更清晰
- **修正**：使用句号开始新句子。仅在紧密相关的平行结构中保留分号

### 冒号-列表连续
- **规则**：避免连续2段以上都以冒号+列表开头
- **原因**：造成单调的列举模式
- **修正**：将列表项融入正文，或合并为单一列表

## C. 空洞开头清理

直接删除以下句式开头，切入正题。

| 空洞开头 | 处理方式 |
|---------|---------|
| "在...的背景下"（无实质信息时） | 删除，直接陈述主题 |
| "值得注意的是" | 删除 |
| "值得一提的是" | 删除 |
| "在当今快速变化的..." | 删除，直接进入具体情境 |
| "不言而喻" | 若不言而喻，就不说 |
| "为了能够..." | 改为"为..." |
| "应该指出的是" | 删除，直接指出 |
| "事实上" | 直接陈述事实 |
| "归根结底" | 删除或改为"总体来看" |

### 元叙述避免

避免描述论文在做什么，而是直接做：
- "本节将讨论..." → 直接讨论
- "下段将分析..." → 直接分析
- 例外：引言中的路线图句（"第二节回顾文献；第三节描述方法"）是标准学术实践，应保留。

## D. 结构模式警告

### "三点法"强迫症
- **模式**：每个论点恰好有3个子论点，每个列表恰好有3项
- **修正**：按证据实际需要使用。2个强有力的点优于3个注水的点

### 段落长度均一化
- **模式**：所有段落长度相近（150-200字）
- **修正**：变化段落长度。短段落强调，长段落展开复杂论证

### 同义词轮换
- **模式**：同一段落内对同一概念使用3个以上不同同义词（如"员工""从业者""工作者""被试"）
- **修正**：每个概念在每个章节中选定一个术语，保持一致。术语重复是清晰，非弱点

### 二元对比滥用
- **模式**："不是X，而是Y"在全篇出现超过2次
- **限制**：全篇不超过2次

### 镜像结构
- **模式**：每个章节都有相同的内部结构（主题句→3个证据点→综合句）
- **修正**：让章节结构跟随内容需要。方法部分可以程序化；讨论部分可以探索性

## E. 句长变化检测

好的写作具有**句长自然变化**。短句产生冲击力，长句展开复杂观点，交替产生节奏。

### 检测规则
若连续5个以上句子字数都落在狭窄区间（如都为20-25字）：**标记为需审查**。

### 修正方法
- 插入短句（≤10字）打破模式
- 合并两个短句为一个复杂句
- 朗读段落——若感觉机械节拍，则需变化

### 各部分句长变化目标
- **摘要**：中等变化（事实性，稳定节奏）
- **引言**：高变化（短句吸引，长句展开）
- **文献综述**：中等（稳定分析节奏，偶有短句综合）
- **方法**：低变化可接受（程序性部分自然均匀）
- **结果**：中等（短句报告关键发现，长句详细描述）
- **讨论**：最高变化（短句强调，长句解读，超短句结论）

## 使用方式

### 写作过程中（推荐）
在每节写作后的自检步骤中应用本规则。尽早发现问题。

### 最终审稿前（备选）
若写作过程中未应用，在交付前进行全文扫描。

### 违规程度判定
- 0处违规：干净
- 1-3处违规：轻微——自检中修正
- 4处以上违规：模式问题——审查该部分的写作方式
