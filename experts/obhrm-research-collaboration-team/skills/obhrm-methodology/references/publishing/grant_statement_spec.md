# 基金声明写作规范

基金声明（Funding Statement）是学术论文中的强制性声明。无论是否获得资助，都必须明确说明。多数期刊要求投稿时提供基金信息，并在正式发表时包含正式声明。本指南涵盖中国主要基金机构格式标准、国际基金机构格式、声明模板，以及与利益冲突声明的区别。

## 1. 中国主要基金机构格式

### 1.1 国家自然科学基金（NSFC）

**基金号格式**：项目类型 + 年份 + 学部代码 + 序号

| 项目类型 | 代码 | 示例 |
|---------|------|------|
| 面上项目 | 7xx | 72072001 |
| 青年科学基金项目 | 71x | 72102001 |
| 地区科学基金项目 | 72x | 72262001 |
| 重点项目 | 7xx | 71932001 |
| 重大研究计划 | 9xx | 91924000 |

**OBHRM相关学部代码**：

| 学部代码 | 学部名称 | OBHRM相关方向 |
|---------|--------|-------------|
| G03 | 管理科学部（一般管理） | 组织行为、人力资源管理 |
| G04 | 管理科学部（宏观管理与政策） | 公共管理、劳动经济 |

**英文声明格式**：
```
This work was supported by the National Natural Science Foundation of China
(Grant No. [基金号]).
```

**中文声明格式**：
```
本研究受国家自然科学基金（项目批准号：[基金号]）资助。
```

### 1.2 国家社会科学基金（NSSFC）

**基金号格式**：年度 + 项目类别代码 + 学科分类 + 序号

| 项目类别 | 代码 | 说明 |
|---------|------|------|
| 重大项目 | 01 | 重大理论与实践问题 |
| 重点项目 | 02 | 重要研究领域 |
| 一般项目 | 03 | 基础理论研究 |
| 青年项目 | 04 | 35岁以下青年学者 |
| 后期资助项目 | 05 | 已完成书稿/论文 |

**OBHRM相关学科**：管理学、社会学、心理学、应用经济学

**英文声明格式**：
```
This work was supported by the National Social Science Fund of China
(Grant No. [基金号]).
```

**中文声明格式**：
```
本研究受国家社会科学基金（项目批准号：[基金号]）资助。
```

### 1.3 教育部人文社会科学研究项目

**基金号格式**：年度 + 项目类别 + 学科门类 + 序号

| 项目类别 | 说明 |
|---------|------|
| 重大课题攻关项目 | 重大理论和现实问题 |
| 基金项目 | 一般研究 |
| 青年基金项目 | 40岁以下 |
| 规划基金项目 | 规划期研究 |

**英文声明格式**：
```
This work was supported by the Humanities and Social Sciences Research
Project of the Ministry of Education of China (Grant No. [基金号]).
```

**中文声明格式**：
```
本研究受教育部人文社会科学研究项目（项目批准号：[基金号]）资助。
```

### 1.4 省部级基金

**常见来源**：各省市社科基金、自科基金、教育厅项目、高校科研基金

**中文声明格式**：
```
本研究受[基金全称]（项目批准号：[基金号]）资助。
```

## 3. 声明模板

### 3.1 获得资助（单一来源）

**英文**：
```
Funding: This work was supported by the [基金机构全称] (Grant No. [基金号]).
```

**中文**：
```
基金资助：本研究受[基金机构全称]（项目批准号：[基金号]）资助。
```

### 3.2 获得资助（多来源）

**英文**：
```
Funding: This work was supported by the [基金机构1] (Grant No. [基金号1]);
the [基金机构2] (Grant No. [基金号2]); and the [基金机构3] (Grant No. [基金号3]).
```

**中文**：
```
基金资助：本研究受以下基金资助：
(1) [基金机构1]（项目批准号：[基金号1]）；
(2) [基金机构2]（项目批准号：[基金号2]）；
(3) [基金机构3]（项目批准号：[基金号3]）。
```

### 3.3 未获资助

**英文**：
```
Funding: This research received no specific grant from any funding agency
in the public, commercial, or not-for-profit sectors.
```

**中文**：
```
基金资助：本研究未获得任何公共、商业或非营利机构的专项基金资助。
```

### 3.4 部分资助

**英文**：
```
Funding: This work was partially supported by the [基金机构全称]
(Grant No. [基金号]). The funder had no role in study design, data collection
and analysis, decision to publish, or preparation of the manuscript.
```

**中文**：
```
基金资助：本研究受[基金机构全称]（项目批准号：[基金号]）部分资助。
基金资助方未参与研究设计、数据收集与分析、发表决策或论文撰写。
```

## 4. 基金声明与利益冲突声明的区别

基金声明和利益冲突（COI）声明是**两个独立的声明**，不可混为一谈：

| 比较项 | 基金声明 | 利益冲突声明 |
|-------|---------|------------|
| **目的** | 披露研究资助来源 | 披露可能影响研究客观性的利益关系 |
| **内容** | 资助机构名称、基金号、资助方角色 | 经济利益、咨询关系、股权、专利等 |
| **无相关时** | 仍须声明"无资助" | 仍须声明"无利益冲突" |
| **期刊位置** | 致谢前后 | 致谢前后 |

### 利益冲突声明模板

**无利益冲突（英文）**：
```
Declaration of Interest: The authors declare that they have no known
competing financial interests or personal relationships that could have
appeared to influence the work reported in this paper.
```

**无利益冲突（中文）**：
```
利益冲突声明：所有作者声明，就本研究报告的内容而言，不存在已知
的竞争性经济利益或个人关系。
```

**存在利益冲突（英文）**：
```
Declaration of Interest: [作者姓名] has received research grants from
[机构/公司] and serves as a consultant for [公司]. The remaining authors
declare no competing interests.
```

## 5. 主要出版社格式要求

| 出版社 | 位置 | 格式要求 |
|--------|------|---------|
| **Elsevier** | 独立"Funding"节 | 资助机构名称 + 基金号 |
| **Springer Nature** | "Declarations"节下 | 含子节：Funding + COI + Ethics等 |
| **Wiley** | "Acknowledgments"或独立节 | 因期刊而异 |
| **Taylor & Francis** | "Funding"或"Disclosure"节 | 资助机构名称 + 基金号 |
| **SAGE** | "Funding"或"Declaration"节 | 资助机构名称 + 基金号 |
| **科学出版社** | 中文文章通常在首页脚注 | 基金号标注在首页脚注 |
| **中国社会科学出版社** | 首页脚注 | 基金号标注在首页脚注 |

## 6. 写作自检清单

- [ ] 所有资助来源均已列出（含校内基金）
- [ ] 基金号正确且完整
- [ ] 资助机构使用官方全称（首次提及不用缩写）
- [ ] 如无资助，明确声明"无资助"
- [ ] 基金声明和利益冲突声明分开陈述
- [ ] 英文论文使用英文声明，中文论文使用中文声明
- [ ] 多项资助按重要性或字母顺序排列
- [ ] 资助机构名称反映批准时的官方名称
- [ ] 如资助方要求特定免责声明，已逐字引用
