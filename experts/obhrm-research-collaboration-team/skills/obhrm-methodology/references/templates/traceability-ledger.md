# 可追溯账本（traceability-ledger · 稳定 ID + 工作状态机）

> 本文件把套件既有的「贡献→假设→结果→图表」可追溯矩阵从概念落成**可执行机制**：用稳定 ID 串联跨路径产物，用统一状态机标记每个对象的完成度与就绪度。
> 可追溯账本的状态机制按 OBHRM 蒸馏三落点判为**套件操作层**（换执行工具即不成立），对齐 `quality_gates.json` 的 `coherence_gates` 与 `trust_boundary`。
> 适用：跨章节 / 跨路径 / 长周期任务；单段润色、单条引用等局部任务不强制建立全部 ID。

---

## 一、稳定 ID 体系

每条跨路径产物分配**一次即固定**的 ID，不因排序变化而复用；合并/删除对象时保留变更记录。

| 对象 | 前缀 | 示例 | 说明 |
|------|------|------|------|
| 用户材料 / 上传文件 | `S` | `S001` | 用户提供的 Word/PDF/CSV/访谈稿 |
| 文献 / 引用条目 | `L` | `L001` | 与〔R-xx〕〔综述·X〕标记一一对应 |
| 主张 / 论点 | `C` | `C001` | 任一需证据支撑的断言 |
| 数据 / 数据集 | `D` | `D001` | 一手数据、二手效应量、编码表 |
| 图 | `F` | `F001` | 按图表嵌入协议编号 |
| 表 | `T` | `T001` | 按图表嵌入协议编号 |
| 导师 / 学校 / 期刊要求 | `A` | `A001` | 外部硬性约束 |
| 编辑要求 | `E` | `E001` | 投稿系统 / 编辑部指令 |
| 审稿意见 | `R` | `R1.1` | 第 1 条审稿人的第 1 点；逐条不漏 |
| 修订任务 | `V` | `V001` | 返修对照表每行 |
| 路径阶段产物 | 阶段前缀 | `A3-claim` / `B2-gap` | 可选，标注所属阶段便于回溯 |

> **位置指针纪律**：每个问题保留「位置指针 + 证据指针 + 严重度 + 解决条件 + 当前状态」。位置无法核实时写「未提供位置」，不得制造页码 / 行号 / 图号。

---

## 二、主张强度状态（claim strength）

主张在写入正式结论前须显式标注强度，与四铁律「标注无支撑」对齐：

- `evidence-backed`：当前证据可直接支持，可写入结论
- `plausible-inference`：有依据但属推断，必须降级措辞并说明边界（如「可能」「有待验证」）
- `hypothesis`：待验证假设，**不得写成结果**
- `unsupported`：当前不可写入正式结论，标「无支撑 / 缺乏直接证据」

---

## 三、工作状态机（work status）

修订 / 分析 / 实验类对象的状态：

- `VERIFIED_DONE`：存在可检查产物（修改文本 / 分析输出 / 图表 / 审批记录）
- `REPORTED_DONE_UNVERIFIED`：用户称已完成但无可核验产物，**不得等同 VERIFIED_DONE**
- `待写作` / `待分析` / `待实验`：正文 / 分析 / 实验尚未完成
- `待作者确认`：需作者确认事实 / 决定 / 产物
- `NOT_FEASIBLE`：当前设计 / 伦理 / 时间 / 数据条件不允许，须给出替代方案或主张降级

> **铁律**：只有可检查产物才能标 `VERIFIED_DONE`；「已起草回复 / 已说明将补」≠「实验 / 分析 / 稿件修改已完成」。

---

## 四、整体就绪状态（readiness）

长任务 / 投稿包 / 返修包整体状态：

- `ready_to_submit`：无阻塞项、无占位符，所有声称完成的修改均可核验
- `draft_with_placeholders`：已有可用草稿，仍有非最终占位符
- `needs_author_input`：缺少影响最终内容的作者事实 / 决定 / 产物
- `blocked`：核心证据 / 诚信 / 伦理 / 合规或必要修改未解决

> 无阻塞项与占位符时才标 `ready_to_submit`；`待作者输入` / `待补证据` / `待核验` 等占位符未关闭前不得进入提交态。

---

## 五、与既有机制的衔接

- **可追溯矩阵**：`C`/`D`/`F`/`T` 即矩阵行；`R`/`V` 即返修对照表行（链路四→五）。
- **P0/P1/P2 严重度**（见 `../skill_rules.md`）：每个 ID 的严重度用全局分级标注。
- **来源可信分级**（见 `../governance/source_trust_tiers.md`）：`L` 类文献按 M1/M2/F/U 标内容层级。
- **轻量状态账本模板**：本文件即唯一账本模板；长周期/跨路径任务可直接复用本表结构，按需拆分为 00-scope … 06-revision-brief 轻量账本（字段与本表一一对应，无需独立文件）。

---

## 六、停止规则

同一层级最多三轮；连续两轮无实质改善、关键证据缺失、专业分歧需导师/方法专家决定、或当前目标已达成时停止。停止时报告：当前状态 + 剩余问题 + 停止原因 + 一个下一步。
