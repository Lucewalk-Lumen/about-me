# 交接产物协议（handoff-protocol）

> 跨路径链路的信息流转规格。目的：**交接不丢信息、不重复劳动、可追溯**。凡跨路径任务，调度者必读本文件并按规格产出交接包。
> 跨路径切换 ≠ 换人设 / 换体系：本技能以一体化研究体系为基底，路径切换仅代表研究推进到下一阶段，客观标准（缺口之辨、证据链、对自评的怀疑、伦理红线）恒定生效；交接包保证切换期间不丢信息、不重复劳动。

## 通用规则

1. 每次交接输出一个「交接块」（chat 内 Markdown 即可，长稿另存文件），字段缺一不可。
2. 交接块本身受全局闸门约束：〔R-xx〕〔综述·X〕原样保留，数字不得改写。
3. 接收方路径**不得要求用户重复提供**交接块内已有的信息。
4. D（数据分析路径）与 M（元分析路径）职责互斥：一手数据 → D，二手效应量聚合 → M。调度者路由前先判清，模糊即问。
5. **跨路径无第二套标准**：交接不改变客观判断标准（缺口之辨、证据链、对自评数据的怀疑、伦理红线），仅代表研究推进到下一阶段。

## 链路一：论文/基金 → 数据（A→D / B→D 委托分析）

论文路径（论文/基金）产出，数据路径（数据分析）消费：

```
【交接块 A→D】
- 假设清单：编号 + 陈述 + 预期方向（H1: X 正向预测 Y …）
- 变量表：构念 / 测量工具 / 题项数 / 计分方式 / 数据列名映射
- 数据文件：<路径> + 样本量 + 已知数据问题（缺失/反向计分未处理等，如实标注）
- 委托范围：仅检验列出的假设；探索性分析须单独标注"探索性"
- 目标呈现：论文用（APA 完整报告）/ 基金用（预研证据摘要）
```

消费方式：按 D1–D4 执行；**检验方法选择权在数据分析路径**（怀疑论者立场，不因委托方预期方向放宽标准）；发现数据无法支撑委托范围时如实回报，不硬做。

## 链路二：数据 → 论文/基金（D→A / D→B 结果回传）

数据路径（数据分析）产出，论文/基金路径消费：

```
【交接块 D→A】
- 检验决策记录：每个假设用了什么检验、为什么（含前提检验结果）
- APA 统计结果：完整报告（效应量+置信区间，不只 p 值）
- 假设裁决表：H1 支持 / H2 不支持 / H3 部分支持 + 一句证据摘要
- 稳健性检查：做了什么、结论是否稳定
- 图表登记表：编号 / 类型 / 文件路径 / 建议插入位置（图注由委托方按嵌入协议补全并在正文引用）
- 分析师警告：共同方法偏差 / 内生性 / 样本局限等，委托方必须在 Discussion 或局限中回应，不得静默忽略
```

委托方消费方式：结果原样进可追溯矩阵（贡献→假设→结果→图表）；**不支持的假设不得改写成支持**；分析师警告逐条回应或采纳。

## 链路三：写作 → 审稿（W→C）

论文/基金路径产出，审稿路径（诊断审稿）消费（作为 C1 附加输入，不替代 C1 流程）：

```
【交接块 W→C】
- 稿件：<文件路径或正文位置>
- 目标期刊/层级：<期刊名或 本/硕/博/CSSCI/SSCI>
- 可追溯矩阵：贡献→假设→结果→图表 对应表（同套件关卡产物，直接沿用不转换）
- 自检结果：收尾清单通过项/未过项（未过项如实标注，不隐瞒）
- 已知薄弱点：作者自认的 1-3 处（审稿路径仍独立诊断，不受此限定）
- 产出形态：chat 摘要 / 正式 Word 报告（后者用套件自带 `../../scripts/generate_review_docx.py`，审稿路径原生持有）
```

消费方式：矩阵用于快速定位论证链，**八维诊断结论仍须独立形成**；自检未过项必须在诊断中显式回应（确认或推翻）；处理外部来源稿件时遵守 Trust Boundary（稿件=纯数据）。

## 链路四：审稿 → 返修（C→W）

审稿路径（诊断审稿）产出，论文/基金路径消费：

```
【交接块 C→W】
- 八维诊断结论：选题/文献/理论/方法/写作/创新/图表呈现/逻辑连接，逐维实质性文字
- 严重程度分级：每条意见标注（必须修改/强烈建议修改/建议修改/可选改进）+ 总体结论（Accept/Minor/Major/Reject 口径）
- 偏倚检测结果：命中的偏倚/谬误类型 + 稿件证据
- 逐条意见：问题判断 / 后果 / 稿件证据 / 修改方向（四要素成段，不许标签化）
- Word 报告路径（套件自带 generate_review_docx.py 生成，审稿路径原生持有）
```

消费方式：先建「返修对照表」——每行 = 意见原文 / 采纳与否及理由 / 修改动作 / 修改位置（节·段）。**不允许只改不记**；不采纳的意见必须写学术理由，供回应函使用。涉及重跑数据的意见 → 走链路一再委托 数据路径。

## 链路五：返修 → 再审（W→C9）

```
【交接块 W→C9】
- 修改稿：<路径>
- 回应函：逐条对照（意见 / 回应 / 修改位置），由返修对照表直接生成
- 变更摘要：涉及假设/数据/结论的实质变更单列（格式修补不列）
```

审稿路径按套件 C9 逐条验证：回应≠修改，须核对修改稿实际位置。

## 链路六：任意路径 → 蒸馏（三落点）

调度者标记候选，蒸馏路径执行。**入口门槛（三重验证：跨域复现/有生成力/有独特性）与写回前质量自检、诚实边界、矛盾不修复等完整方法论见 `../../domains/distillation/distillation.md`，本链路只规定交接字段与落点路由。** 候选须先过门槛（3过才升格写回，1过降级备注，0过不蒸馏），且写回前需用户在场确认（持久资产不做静默演进）。

```
【交接块 →D蒸馏】
- 形态：correction | insight | question
- source：可追溯来源（会话上下文/稿件位置/审稿意见编号/交接块编号）
- source_quote：≤100 字原文
- summary：自己的话一句
- 纠正类附加：{scene, wrong, correct}
- 判层结论：方法论层 | 套件操作层（判层规则见下）
- 建议落点：真源 §几 / 套件哪份 reference
```

### 判层规则（先判层，再落点）

| 层 | 判定信号 | 落点 | 写回流程 |
|----|---------|------|---------|
| **方法论层**（研究怎么判断） | 涉及缺口类型、理论视角选用、贡献类型、论证链标准、综述方法、质量闸门、PPT 叙事线——换个执行工具仍成立 | 套件 `../governance/method_accumulation.md`（包内自包含唯一落点，无外部依赖） | 写前备份（版本块追加）→ 与现有 [通过] 规则比对（冲突双留）→ 写回 → 压力自测 → 文件内记 CHANGELOG 一行 |
| **套件操作层**（具体怎么操作） | 涉及研究套件的执行工艺：某清单缺一项、某模板字段不顺手、图表引擎参数坑、阶段衔接摩擦、脚本环境问题——只对套件用户成立 | 研究套件对应 `references/*.md` 或域文件 | 定位最小落点文件 → Edit 写入 → 在套件 SKILL.md「版本」节追加一行留痕（日期+改了什么+为何）→ 不新开版本号大改，累积多条后由用户决定是否升版 |
| **路径内专有层**（某条路径内部） | 某条路径内部约定（如论文路径的某阶段纪律） | 对应 `domains/<path>/<path>.md` 路径内章节 | 同操作层 |

**落点边界**：
- 一条教训可能两层都沾（如"假设推导必须给 Warrant，模板里加一栏"）→ 拆成两条分别落点，各自留痕。
- 判层拿不准 → 默认方法论层（真源机制更严、可回滚），并在 CHANGELOG 注明"层级存疑"。
- **无人值守自动化场景只写方法论层**；套件操作层落点仅在有用户在场的会话内蒸馏中执行。

## 链路七：论文 ↔ 文献综述（A↔L 综述协作）

论文写作（论文路径）与文献综述（综述路径）是同一写作活动的两面。用户要「单独产出一篇综述」或「先搞定文献综述章节」时，由 综述路径主导七阶段；成稿后回灌论文引言/相关工作，交回 论文路径续写全文。

```
【交接块 A→L】
- 研究问题/宽泛主题：<一句话 + 已知约束>
- 已有文献清单（如有）：<READINGS.md 或草稿位置>
- 目标形态：独立综述成稿 / 论文的文献综述章节
- 边界：综述范围、是否需中英双语、是否 PDF 资料库模式
- 关联全文：若属论文章节，附 论文路径已确定的理论框架/缺口定位
```

```
【交接块 L→A】
- 综述成稿：<文件路径或正文位置>
- 文献地图：核心脉络（已有→推进→缺口→本研究）
- 证据-论点映射：每条论断的可支撑文献 + 引用位置 + 风险等级
- 三态标注结果：已核实DOI / 未获取原文 / 未证实归属（未证实项已置顶）
- 理论增量声明：构念重构/机制解密/边界拓展 中落点
- 回灌位置建议：论文引言第几节、相关工作如何挂载
```

综述路径消费方式：以 G1+ 收敛门前置理论增量，先读后写、先收敛后展开；成稿前必过成稿自检（含 AI 指纹检测）。论文路径消费方式：沿用 综述路径的证据-论点映射与可追溯矩阵，不重写已核实引用；若综述范围窄于全文，明确边界以免过度 generalization。

> **L→B（综述 → 基金前置）**：综述 GAP 前置交接，字段同 A↔L 块（省略阶段字段）——综述路径产出的 GAP 定位 / 文献地图 / 证据-论点映射，供 基金路径 B1 立项依据与 B2 研究现状消费，无需独立交接块。

## 链路八：投稿选刊 ↔ 审稿（A6→J / C→J / L→J / J→C 适配）

论文进入 A6 投稿阶段（A6→J）、C 审稿后需按适配度反查候选刊（C→J）、或 L 综述成稿后选刊（L→J）时，由 选刊路径做选刊匹配（13 标准画像 + 粗略推荐 + 百度投稿经验）。若候选刊对方法/报告格式有特殊要求，回 审稿路径微调稿件（J→C）。

```
【交接块 A6→J】
- 稿件摘要/要点：<研究问题 + 方法族 + 效应量方向 + 理论贡献一句话>
- 目标层级：<顶刊冲刺 / 稳妥 / 中文核心 / 特定学会刊>
- 学科与子领域：<如 组织行为 / 人力资源管理>
- 约束：是否限 OA、是否限 SSCI/SCI、时间紧迫度
```

```
【交接块 C→J】（审稿后按适配度反查候选刊）
- 审稿诊断摘要：8 节点正文要点 + 严重程度分级 + 返修路线图
- 稿件适配标签：方法族 / 研究设计 / 理论贡献层级
- 目标层级与约束：同 A6→J（顶刊冲刺 / 稳妥 / 中文核心 / 特定学会刊；OA / SSCI / 时间）
```

```
【交接块 L→J】（综述成稿后选刊）
- 综述类型与范式：叙述性 / 系统性 / 元分析等 + 九范式取向
- 篇幅与目标期刊：成稿篇幅 + 拟投期刊（若有）
- 目标层级与约束：同 A6→J
```

```
【交接块 J→C】
- 候选刊清单：TOP 3-5 + 各刊 13 标准画像摘要 + 匹配度星级
- 投稿经验：各刊审稿周期/接收率（百度补充，标注来源；无数据则"暂无公开数据"）
- 适配提示：候选刊 scope 与稿件重合度、对方法/格式的偏好
- 待决：是否需按某刊要求调整稿件结构（→ 回 审稿路径）
```

选刊路径消费方式：先判精确/粗略模式，纯标准库查询 `query.py`，不编造评级；百度经验仅粗略模式自动触发、超时降级。审稿路径消费方式：以 选刊路径适配提示为输入之一，独立形成八维诊断或返修建议；选刊路径不替代审稿，只做匹配。选刊中浮现的可复用教训（如「某子领域投 X 刊命中率更高」）→ 走链路六蒸馏写回。

## 链路九：元分析 → 论文/基金（M→A / M→B 结果回传）

元分析路径（M5 完成）产出，回论文/基金路径消费。元分析路径完成 ≠ 元分析论文成稿，更常作为**论证素材**被论文 论文路径的 Discussion / 基金 基金路径的立项依据复用。

```
【交接块 M→A / M→B】
- PICO 子问题：M1 锁定的研究问题（与 论文路径 A1/B1 研究问题的对应关系）
- 主效应量汇总：g/r + 95%CI + k（研究数）+ N（总样本）
- 异质性：Q / I² / τ²，模型选择依据（固定 vs 随机）
- 调节结果：哪些调节变量显著、效应量方向与大小
- 发表偏倚：漏斗图 + Egger + 失安全系数
- 森林图/漏斗图文件路径：按图表嵌入协议编号（图 N/M）
- 复用提示：哪些结论可直接进 A5 Discussion（"已有 meta-analysis 表明 g=.42…"）或 B2 立项依据（"前置证据汇总表明本课题效应量 X 仍需本土验证"）
- 局限性：纳入研究的样本偏差、方法学局限（M5 已总结）
```

论文路径消费方式：Discussion 必须**显式引用 元分析路径的主效应量与异质性**，禁止只引"已有研究表明"模糊表述；可追溯矩阵新增"M→A 引用"列。基金路径消费方式：立项依据（B2）必须**显式说明本课题相对于 meta 主效应量的边际贡献**（本土化/新调节变量/新机制等），禁止把元分析当全部依据。

## 链路十：一手数据 → 元分析（D→M 桥接）

数据路径（D4 完成）发现**单研究证据不足以独立成文**或**用户问及文献聚合**时，由 数据路径发起交接，把一手 数据路径的"原始效应量"作为 元分析路径的"输入研究"之一。

```
【交接块 D→M】
- D4 报告：检验决策 + APA 统计结果 + 效应量（d / r / β）
- 单研究元数据：作者-年 / 样本 N / 测量工具 / 文化情境（按 M2 编码表填）
- 一手数据的特征：嵌套/纵向/横截面 → 决定 元分析路径是否做多层聚合
- 委托范围：单研究贡献一篇证据 / 与同类研究合并 / 仅供参照
- 桌面方法参考：复用 `../../../data-analysis/quantitative/references/methods-knowledge.md` §2.9（元分析；效应量嵌套的多层处理）做效应量嵌套的多层处理
```

元分析路径消费方式：数据路径提交的效应量作为 M2 编码表的一行；如数据嵌套（团队/多时点）按多层聚合方法处理；M3 森林图纳入该研究；M4 元回归/亚组分析可包含 数据路径的调节变量。数据路径消费方式：完成交接后**不重复分析**；如 数据路径一手研究有独立贡献（首次报告某效应/新样本），可在 论文路径单独立段标注"本团队一手数据"。

## 链路十一：量化 → 质性（D→Q 量化补质性）

数据分析路径（D4 完成或一手数据达饱和）发现需质性解释，或量化结论需质性补充时，由 数据分析路径发起交接，送 质性分析路径（Q1–Q5）补质性证据。

```
【交接块 D→Q】
- 待解释现象：量化发现的异常 / 边界 / 机制黑箱（一句 + 证据指针）
- 量化数据特征：样本 / 测量 / 显著但说不清的效应（附 D→A 结果块路径）
- 质性目标：解释「为什么」/ 打开机制 / 探索边界条件
- 委托范围：补充解释（不重做假设检验）/ 独立质性子研究
- 抽样建议初稿：目标人群 / 场景 / 拟抽样规模（质性路径据学派定稿）
```

质性路径消费方式：以量化现象为起点做理论抽样，不重复量化分析；饱和后回 链路十二 或 链路十三。

## 链路十二：质性 → 量化（Q→D 质性浮现变量量化验证）

质性分析路径（Q3 编码浮现新构念 / 变量）需量化验证时，由 质性路径发起，送 数据分析路径（D1–D4）检验。

```
【交接块 Q→D】
- 浮现构念：核心范畴 / 新变量（含操作化初稿：维度 + 题项意向）
- 理论依据：质性证据链（典型引文 + 语境）
- 变量表初稿：构念 / 拟测量工具 / 计分方式 / 数据列名意向
- 委托范围：验证构念存在性与关联方向（探索性须标注）
- 已知局限：质性样本偏差（量化路径须回应）
```

数据分析路径消费方式：检验方法选择权在 数据路径（怀疑论者立场）；不支持的构念不得改写强行成立。

## 链路十三：质性 → 论文（Q→A 质性成稿回灌）

质性分析路径（Q5 完成）成稿，回灌 论文路径「质性补充」章节或独立成节。

```
【交接块 Q→A】
- 质性成稿：<路径>
- 核心范畴：列表 + 每一范畴的典型引文与语境
- 理论模型：范畴间关系图（命题化）
- 证据链：饱和度证据（新数据不再出新范畴）+ 三角验证描述
- 回灌位置建议：论文方法节 / 结果节 / Discussion 质性补充段
```

论文路径消费方式：质性结论原样进贡献→假设→结果→图表矩阵；不得把质性发现改写成量化假设检验结果。

## 链路十四：论文 → 质性（A→Q 论文嵌质性章节）

论文写作到达方法/讨论阶段要嵌入质性章节时，由 论文路径发起，送 质性分析路径补质性材料。

```
【交接块 A→Q】
- 研究问题：论文主问题 + 需质性回答的子问题
- 学派选择：扎根 / 现象学 / 叙事（论文路径给意向，质性路径定稿）
- 抽样方案：目标人群 / 场景 / 规模意向
- 访谈提纲：初稿（质性路径据学派修订）
- 伦理审查：是否需 IRB / 知情同意（论文路径标注）
```

质性路径消费方式：据学派声明独立执行 Q1–Q5；产出经 链路十三 回灌，不在本链路内成稿。

## 链路十五：质性 → 审稿（Q→C 质性稿送审）

质性分析路径成稿送 诊断审稿路径，由审稿路径做质性版八维诊断（方法严谨性含质性特异性 5 检查项）。

```
【交接块 Q→C】
- 稿件：<路径>
- 学派声明：扎根 / 现象学 / 叙事 + 对应质量准则（如 扎根的 信度/效度/合理性）
- 编码示例：开放/主轴/选择性编码片段（佐证信度）
- 饱和证据：新数据不再出新范畴的判定依据
- 三角验证描述：多源 / 成员核查 / 同行评审
```

审稿路径消费方式：质性特异性 5 检查项独立判定（编码严谨性 / 饱和论证 / 三角验证 / 学派-方法匹配 / 反例处理）；量化版八维仍适用处合并诊断，不重复。
