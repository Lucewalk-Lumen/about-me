## 用途

为 审稿路径诊断评审提供标准化的 0-100 分评分维度，确保对不同论文和不同评审场景下评分的一致性。适用于论文诊断、投稿前自检、模拟审稿等场景。

> **注意**：评分量表定义的是"评什么"，Agent的评分准确度受模型能力影响。评分结果应视为**序数 meaningful**（85分的论文质量高于65分），而非**基数 interpretable**（85分不等同于被录用）。

## 评分量表

所有维度 0-100 分，加权后得出综合分。

### 决策映射

| 加权平均分 | 决策建议 |
|-----------|---------|
| >= 80 | 达到投稿标准，可直接投稿 |
| 65-79 | 小修后可投稿 |
| 50-64 | 需要大修 |
| < 50 | 建议重写 |

## 维度1：原创性与理论贡献（权重 20%）

| 分值区间 | 等级 | 行为指标 |
|---------|------|---------|
| 90-100 | 优秀 | 提出新的理论框架且有实证支撑；开辟全新研究方向；贡献跨越3个以上子领域；无前人研究涉及该问题 |
| 75-89 | 良好 | 方法论创新或将现有理论成功应用于新情境；贡献明确超越增量延伸；对2个以上子领域有启示 |
| 60-74 | 合格 | 以新数据、新样本或新情境扩展现有框架；贡献清晰但属增量性质；单领域启示 |
| 45-59 | 不足 | 简单重复已有研究且变化甚微；贡献边缘化；难以回答"所以呢？" |
| < 45 | 不合格 | 无可识别的原创贡献；复制已有工作且无正当理由；纯描述无分析洞察 |

## 维度2：方法论严谨性（权重 25%）

| 分值区间 | 等级 | 行为指标 |
|---------|------|---------|
| 90-100 | 优秀 | 研究设计与研究问题完全匹配；所有效度威胁均已处理；统计方法适当且有功效分析；报告透明、可复现 |
| 75-89 | 良好 | 设计合理但有微小gap；大部分效度威胁已处理；方法适当但报告有少量遗漏；基本可复现 |
| 60-74 | 合格 | 设计可接受但存在一些效度关切；方法适当但论证不充分；部分报告缺失（如效应量、置信区间） |
| 45-59 | 不足 | 设计有显著缺陷；方法选择值得质疑；多处报告缺失；可复现性存疑 |
| < 45 | 不合格 | 根本性设计缺陷导致发现无效；方法不当；结果不可信 |

## 维度3：实证证据充分性（权重 25%）

| 分值区间 | 等级 | 行为指标 |
|---------|------|---------|
| 90-100 | 优秀 | 40篇以上参考文献，80%以上同行评审；多方法三角验证；所有主张有据可查；反面证据已承认 |
| 75-89 | 良好 | 25-40篇参考文献，70%以上同行评审；主要主张有充分证据；有一定三角验证 |
| 60-74 | 合格 | 15-25篇参考文献，60%以上同行评审；关键主张有支撑但部分gap；三角验证有限 |
| 45-59 | 不足 | 少于15篇参考文献或同行评审占比不足50%；多处主张无支撑；无三角验证 |
| < 45 | 不合格 | 文献严重不足；主要主张无支撑；过度依赖灰色文献或传闻证据 |

## 维度4：论证连贯性（权重 15%）

| 分值区间 | 等级 | 行为指标 |
|---------|------|---------|
| 90-100 | 优秀 | 问题→缺口→研究问题→方法→发现→启示的逻辑流清晰无瑕；各节层层递进；无逻辑跳跃；反论已预判 |
| 75-89 | 良好 | 逻辑流清晰但有微小gap；大部分过渡处理得当；论证总体有说服力 |
| 60-74 | 合格 | 主线可见但部分节段感觉脱节；偶尔逻辑跳跃；结论基本能从证据推导 |
| 45-59 | 不足 | 论证结构不清；显著逻辑gap；结论过度延伸至证据范围 |
| < 45 | 不合格 | 无连贯论证；各节互不相关；结论无法从证据推导；循环论证 |

## 维度5：写作质量（权重 15%）

| 分值区间 | 等级 | 行为指标 |
|---------|------|---------|
| 90-100 | 优秀 | 专业学术写作；术语精确；段落结构优秀；无语法错误；全文语域恰当 |
| 75-89 | 良好 | 良好学术写作；少量风格不一致；偶有语法问题；术语基本精确 |
| 60-74 | 合格 | 写作可接受但有待改进；部分段落冗长；偶尔术语不精确；少量语法问题 |
| 45-59 | 不足 | 低于期刊标准；频繁出现冗长/不清晰段落；术语不一致；多处语法问题 |
| < 45 | 不合格 | 写作质量不可接受；存在无法理解的段落；严重语法问题 |

## 补充维度（可选，按需启用）

### 文献整合度

| 分值区间 | 等级 |
|---------|------|
| 90-100 | 全面覆盖经典+前沿文献；识别理论脉络；精准定位论文在学术对话中的位置 |
| 75-89 | 良好覆盖；大部分关键文献已引用；文献定位合理 |
| 60-74 | 覆盖可接受但有gap；部分重要文献缺失；定位略有模糊 |
| < 60 | 文献gap显著；关键文献缺失；定位差 |

### 实践意义与影响

| 分值区间 | 等级 |
|---------|------|
| 90-100 | 对管理实践和理论均有明确启示；回应紧迫现实问题；可能影响领域方向 |
| 75-89 | 对实践或理论有良好启示；回应相关问题；有中等影响潜力 |
| 60-74 | 有一定启示但范围狭窄；相关性明确但影响有限 |
| < 60 | 实践或理论意义极小；不清楚为什么重要 |

---

## 综合评分公式

```
综合分 = (原创性 × 0.20) + (方法论 × 0.25) + (证据 × 0.25) + (连贯性 × 0.15) + (写作 × 0.15)
```

补充维度单独报告，纳入编辑综合评述叙述但不改变数值得分。

---

## 使用说明

- 评分应参照目标期刊/层级标准（管理世界80分 ≠ 普通CSSCI80分）
- 存疑时取区间中值
- 先判断属于哪个等级描述，再在该区间内微调
- 若两个维度得分矛盾（如方法优秀但写作差），应分别如实报告，不应平均拉低

## 论文类型特定评审标准

### 实证研究（问卷/实验）

| 额外评审维度 | 评审重点 |
|------------|---------|
| 假设清晰性 | 假设是否可检验、是否与理论一致 |
| 变量操作化 | 自变量/因变量/控制变量定义是否精确 |
| 内部效度 | 混淆变量是否控制（CMB、内生性） |
| 外部效度 | 结果的可推广性 |
| 统计报告完整性 | 效应量、置信区间、假设检验前提检验 |
| 结论保守性 | 结论是否超出数据支持范围 |

### 理论/概念论文

| 额外评审维度 | 评审重点 |
|------------|---------|
| 概念界定精确性 | 核心概念是否清晰界定、边界是否明确 |
| 论证逻辑结构 | 前提→推断→结论的逻辑链是否完整 |
| 反论处理 | 是否考虑并回应了可能的反对观点 |
| 理论新颖性 | 是否真正推进了理论发展 |
| 可检验性 | 理论能否生成可检验的命题 |

### 文献综述 / 元分析

| 额外评审维度 | 评审重点 |
|------------|---------|
| 检索策略 | 是否全面、可复现（PRISMA合规） |
| 纳入/排除标准 | 是否清晰、合理、一致 |
| 偏倚风险评估 | 是否评估纳入研究的偏倚风险 |
| 异质性处理 | 统计和概念异质性是否妥善处理 |
| 综合方法 | 是否超越简单计数实现批判性综合 |
| 发表偏倚 | 是否评估并讨论发表偏倚 |

### 案例研究

| 额外评审维度 | 评审重点 |
|------------|---------|
| 案例选择依据 | 为何选择此案例？代表什么？ |
| 理论抽样 vs 方便抽样 | 案例选择是否有理论依据 |
| 三角验证 | 是否使用多种数据源 |
| 情境描述厚度 | 是否有充分的"厚描述" |
| 分析可迁移性 | 分析结果能否迁移到其他情境 |
| 研究者反思性 | 是否反思研究者与案例的关系 |

### 质性研究（扎根理论/访谈）

| 额外评审维度 | 评审重点 |
|------------|---------|
| 理论抽样 | 抽样是否有理论驱动（非方便抽样） |
| 编码程序 | 开放编码→轴心编码→选择性编码过程是否透明 |
| 数据结构图 | 是否呈现完整的数据结构图和机制模型 |
| 引用密度 | 每个编码/范畴是否有充分的原始数据引用 |
| 理论饱和 | 是否达到理论饱和 |
| 情境化 | 发现是否嵌入具体情境而非抽象泛化 |

## 常见评审误区

### 审稿人应避免的偏误

| 误区 | 描述 | 如何避免 |
|------|------|---------|
| **过度批评** | 放大次要问题，忽略论文整体贡献 | 先肯定优势，再指出问题；区分主要与次要 |
| **确认偏误** | 只寻找支持自己预判的证据 | 刻意寻找论文的优点和反驳自己观点的证据 |
| **方法偏好投射** | 要求作者用"我的方法"而非评估"作者的方法" | 问"这个方法能否回答问题"，而非"我会怎么做" |
| **范式偏误** | 用量化标准评判质性研究（或反之） | 使用与研究范式匹配的评价标准 |
| **声望偏误** | 因作者机构或过往成就而放松标准 | 聚焦论文本身的质量 |
| **求新偏误** | 只重视新颖研究，低估重复研究 | 承认重复验证在科学中的重要作用 |
| **语言歧视** | 因非母语表达瑕疵而低估研究质量 | 区分"语言需要润色"与"研究质量差" |

### 建设性反馈原则

1. **具体而非笼统**："第三节第二段的因果推断缺少控制变量"优于"方法论有问题"
2. **问题+原因+建议**：每条批评都应包含"是什么""为什么""怎么改"
3. **区分必要与建议**：哪些修改是必须的，哪些是锦上添花
4. **承认不确定性**："我不确定该分析是否考虑了X"比"作者忽略了X"更准确
5. **尊重作者**：即使论文质量不佳，作者也投入了时间与努力

## 评审综合判断

> 评分权重见上方"综合评分公式"，决策映射见"决策映射"表。

**重要提醒**：
- 若任一维度处于最低等级（如方法论"不合格"），即使综合分达标也应建议拒稿/大修
- 评审意见的具体内容比数字更重要
- 需综合考虑期刊特殊情况（专刊、领域发展需要等）
