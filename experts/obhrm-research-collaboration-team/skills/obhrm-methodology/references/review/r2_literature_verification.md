# R2 强制文献验证（C3 升级版）

> 本文件将外部审稿技能的 R2 工作流适配进团队版 peer-review 路径：把「条件触发」升级为「诊断原创性/文献覆盖前**强制前置**」，并补回「[暂停] 等用户 WoS/Scopus 导出 + 四类转化」。检索机制复用本技能既有能力，不重复实现。

## 1. 强制性与跳过闸门（C5 闸门）
- **默认强制**：进入 C5 八维诊断「原创性 / 文献覆盖」维度前，必须完成 R2 检索与四类转化。
- **跳过条件**：若稿件明确**无原创性 / GAP 主张**（如纯复制、纯方法技术稿），可在 C8 自检中显式记录跳过理由；否则不得跳过。
- 检索能力复用：通过平台 WebSearch/WebFetch 获取学术 API 检索结果后用 `../../scripts/format_search_results.py` 整理 + `../methods/evidence_retrieval_protocol.md`（检索式构造、去重、双向回溯、纳入排除、时间窗、兜底均见该协议）。

## 2. 两阶段工作流

### Phase A：自动化快速扫描（Agent 执行，不依赖用户）
进入 [暂停] 暂停前，Agent 主动完成：
- 基于稿件 Keywords 构造 **≥3 组不同粒度**检索式（精确 / 宽泛 / 反向 / 交叉），每组合并核心方法词（如 "meta-analysis" / "systematic review"）。
- 每组在 **≥2 个来源**检索：Google Scholar / Semantic Scholar / PubMed-Europe PMC / 通用 WebSearch / 作者反向+前向追溯。
- **中文稿件必须并行中文库**（CNKI / 万方 / 维普 / CSSCI）——仅查英文库视为检索不完整（语言偏倚防御，对审稿人自身同样生效）。
- 整合为预报告：执行查询数、命中量、≥3 篇关键发现（作者+年份+与稿件关联判断）。

### Phase B：权威库深度检索（[暂停] 等用户导出）
输出 Phase A 预报告后 **[暂停] 暂停，请求用户**在 Web of Science / Scopus 执行检索并导出（WoS/Scopus 因反爬无法自动访问）。
- 用户提供导出结果后，Agent 合并去重、执行双向回溯与筛选。
- 中文稿件须同样在中文库执行并导出，否则四类转化「文献定位」会漏掉中文核心对话。
- **快 / 深模式**：Phase A 自动扫描即可覆盖多数「缺口声称」核验（快模式）；仅当缺口争议大、或需权威库精确引文支撑时，才进入 Phase B 深模式等用户导出。

## 3. 四类转化（检索 → 诊断判断）
将检索结果转化为四个维度的审稿判断，并**逐条对标本技能八维与 DEF-R01~06**（非外部判据）：

### 3.1 文献定位（→ 八维「文献覆盖」/「理论深度」）
- 作者声称的 gap 是否已被填补？（已被填补 → 原创性不足）
- 作者引用是否代表该子领域核心对话？（遗漏关键文献 → DEF-R05）
- 输出：文献定位 / 声称 / 验证结果(已填补·部分·空缺) / 最相关已有研究 / DEF-R05 适用性 / 定位判断。

### 3.2 已有澄清（→ DEF-R05）
- 是否存在已发表研究直接回答作者「前人未研究」的声称？
- 若未引用 → 文献综述缺陷，建议明确与 XXX(年份) 差异。
- 输出：【已有澄清】声称 / 反驳证据 / 引用状态 / 建议。

### 3.3 新意判断（→ 八维「创新程度」）
- 在同类研究中方法/理论/情境是否有独特贡献？边际性如何？
- 对照 `review_criteria.md` 新意 7 类型，给出建议原创性 / 创新程度评分区间（1–5）。
- 输出：【新意判断】贡献类型 / 差异化亮点 / 边际性 / 建议评分区间。

### 3.4 缺口识别（→ 八维「讨论与启示」/「方法论」）
- 检索发现的稿件未覆盖但应讨论的缺口（理论 / 方法 / 跨学科 / 近 2 年时效性）。
- 输出：【缺口识别】每条 缺口描述 / 严重程度 / 补充文献建议。

## 4. 检索完整性保障（去重 / 双向回溯 / 筛选 / 时间窗 / 兜底）
逐项对齐 `../methods/evidence_retrieval_protocol.md`：
- 去重：多源按 (作者+年份+标题) 归一化指纹去重，记录独立文献数。
- 双向回溯：反向(参考文献)+前向(被引) 并行，避免漏掉稿件发表后的新进展。
- 筛选：纳入与核心构念直接相关、同行评议、含可引用结论者；排除书评/社论/无关。
- 时间窗：默认近 10 年 + 领域奠基文献；近 2 年单列，用于时效性缺口判断。
- 兜底：某库 0 命中切换替代库（Scopus↔WoS↔中文库），不得静默跳过；全库 0 命中则下调「文献覆盖」评分置信度并记录。

## 5. 阶段门控（R2 → C5/C8）
R2 结束、进入 C8 前必须确认（对齐 C8 输出自检，条目以 `../../../peer-review/SKILL.md` ④ 节为唯一真源；R2 文献完整性并入「文献覆盖」节点核验）：
- [x] Phase A 自动化预检索已完成（有预报告）
- [x] 检索覆盖完整：中英文两侧库均已检索，无静默跳过
- [x] 去重、双向回溯、筛选、时间窗均已应用
- [x] 四类转化全部完成（文献定位/已有澄清/新意判断/缺口识别各有独立格式化段落）
- [x] 每条四类输出含 ≥1 条具体文献引用
- [x] 检索发现已准备就绪，供 C5 八维诊断引用（尤其「文献覆盖」「理论深度」「创新程度」与 DEF-R05）

## 6. 与 C5 诊断的衔接
四类转化产出直接服务于 C5：
- 文献定位 + 已有澄清 → 「文献覆盖」「理论深度」诊断 + DEF-R05 判定
- 新意判断 → 「创新程度」八维数值
- 缺口识别 → 「讨论与启示」「方法论」维度补充意见
