# GitHub/调试模块（GitHub Debug Module）

>  GitHub/Debug 专用策略

**触发场景**: 项目bug、error调试、issue查找、版本特定问题

## 搜索源
- **GitHub Issues**（开启与已关闭的 issue 都要查）——已知 bug 与临时解决方案的最佳来源

## 查询策略（1.1 调试辅助）
- 用英文引号包裹精确报错信息进行检索
- 查找与问题模式匹配的 issue 模板
- 重点找临时解决方案（workaround），而不仅是原理说明
- 确认是否为已有补丁或 PR 的已知 bug
- 即使不完全相同，也要查找相似 issue
- 判断该问题是否与特定版本相关
- 同时检索「库名 + 报错」与更笼统的问题描述两种组合
- 检查已关闭 issue 中的解决模式
