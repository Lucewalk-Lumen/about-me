# 中文技术社区模块（Chinese Tech Module）

> 中文技术社区专用策略

**触发场景**: 中文技术问题、国内框架、中文社区解决方案

## 搜索源（Chinese Technical Sites）
- **CSDN**（csdn.net）——国内最大的 IT 社区，技术文章与解决方案覆盖面广
- **掘金 Juejin**（juejin.cn）——高质量中文开发者社区，侧重现代技术栈
- **SegmentFault**（segmentfault.com）——中文问答平台，定位类似 Stack Overflow
- **知乎**（zhihu.com）——中文知识分享平台，含大量技术讨论
- **博客园 Cnblogs**（cnblogs.com）——中文博客平台，深度技术内容较多
- **开源中国 OSChina**（oschina.net）——中文开源社区与技术资讯
- **V2EX**（v2ex.com）——中文开发者社区，讨论氛围活跃
- **腾讯云**与**阿里云**开发者社区——偏企业级的解决方案

## 查询策略（双语研究）
- **双语检索**：同时生成英文与中文查询词
- 使用中文技术术语与常见译法（如 error 译作「报错」、solution 译作「解决方案」）
- 检索中文站点时优先使用中文关键词，从中文开发者社区获得更匹配的结果
