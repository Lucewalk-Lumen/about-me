## 一、通用统计报告检查清单

所有定量研究论文**必须**报告以下项目。评审时逐项检查：

### 1.1 描述性统计

| 项目 | 标准 | 常见遗漏 |
|------|------|----------|
| 均值（*M*） | 所有连续变量必须报告 | 仅报告总体均值，未按组别报告 |
| 标准差（*SD*） | 必须与均值配对出现 | 错误使用标准误（*SE*）代替 SD |
| 样本量（*N* / *n*） | 总样本量和分组样本量均须报告 | 分析过程中的样本流失未说明 |
| 范围 | 报告最小值-最大值或四分位距 | 完全缺失，无法判断分布特征 |
| 分类变量分布 | 报告频数（*f*）和百分比（%） | 仅报告百分比，缺失原始频数 |

### 1.2 效应量

| 项目 | 标准 | 常见遗漏 |
|------|------|----------|
| 报告义务 | **所有统计检验必须报告效应量** — APA 7.0 强制要求 | 仅报告 *p* 值，无效应量 |
| 选择合适指标 | 选择与分析方法对应的效应量指标（见第二节） | 使用不适当的效应量指标 |
| 解释 | 必须提供 Cohen 常规标准或领域特定标准 | 仅报告数字，未解释大小 |

**常用效应量指标速查：**

| 分析方法 | 效应量指标 | 小/中/大（Cohen 常规） |
|----------|-----------|----------------------|
| *t* 检验 | Cohen's *d* | 0.2 / 0.5 / 0.8 |
| 方差分析 | *eta*-squared | .01 / .06 / .14 |
| 方差分析（偏） | partial *eta*-squared | .01 / .06 / .14 |
| 相关分析 | *r* | .10 / .30 / .50 |
| 回归分析 | *R*-squared, *f*-squared | *f*-squared: .02 / .15 / .35 |
| 卡方检验 | Cramer's *V*, *phi* | *V*: .10 / .30 / .50 (*df*=1) |
| 优势比 | OR | 1.5 / 2.5 / 4.3 |

### 1.3 置信区间

| 项目 | 标准 | 常见遗漏 |
|------|------|----------|
| CI 报告 | 所有效应量和关键估计值**应该**报告 95% CI | CI 完全缺失 |
| 格式 | 95% CI [下限, 上限] | 格式不一致或使用圆括号 |
| 解释 | 描述 CI 的实际意义，而非仅统计意义 | 仅检查 CI 是否包含零，未解释宽度 |

### 1.4 统计显著性

| 项目 | 标准 | 常见遗漏 |
|------|------|----------|
| *p* 值格式 | 报告精确 *p* 值（如 *p* = .032） | 仅报告 *p* < .05 或 *p* > .05 |
| *p* < .001 | *p* 值极小时可报告 *p* < .001 | 报告 *p* = .000（统计软件原始输出） |
| 显著性水平 | 事先声明 alpha 水平 | 未说明 alpha = .05 还是其他值 |
| 多重比较 | 使用 Bonferroni、Holm、FDR 校正 | 多重比较无任何校正 |
| 不显著结果 | 必须完整报告，不得隐藏 | 选择性报告仅显著的结果 |

### 1.5 统计功效

| 项目 | 标准 | 常见遗漏 |
|------|------|----------|
| 事前功效分析 | 说明目标功效（通常 >= .80）、假定效应量、alpha、所需样本量 | 功效分析完全缺失 |
| 效应量来源 | 基于先前研究、预实验或理论预期 | 无解释地使用 Cohen 常规 |
| 工具 | 使用 G*Power、pwr 包等 | 未说明使用的工具 |
| 事后功效 | 对不显著结果报告观测功效 | 不显著结果未讨论 II 类错误风险 |
| 敏感性分析 | 报告给定 *N* 下的最小可检测效应量 | 未进行敏感性分析 |

### 1.6 缺失数据处理

| 项目 | 标准 | 常见遗漏 |
|------|------|----------|
| 缺失数据报告 | 报告每个变量的缺失数量和比例 | 未报告缺失数据情况 |
| 缺失机制 | 讨论 MCAR / MAR / MNAR | 未检验即假定 MCAR |
| 处理方法 | 说明所用方法：删除法 / 配对删除 / MI / FIML | 未说明或仅用列表删除 |
| 敏感性分析 | 比较不同缺失数据处理方法下结果的稳健性 | 仅用一种方法，未检验敏感性 |

### 1.7 假设检验

| 假设 | 适用分析 | 检验方法 | 常见遗漏 |
|------|----------|----------|----------|
| 正态性 | *t* 检验、方差分析、回归 | Shapiro-Wilk / K-S / Q-Q 图 / 偏度和峰度 | 完全未检验或仅援引 CLT |
| 方差齐性 | 独立 *t* 检验、方差分析 | Levene 检验 | 未报告或违反时未使用替代方法 |
| 线性 | 回归、相关分析 | 残差图 / 散点图 | 未检验即假定线性 |
| 独立性 | 大多数参数检验 | Durbin-Watson / 研究设计说明 | 嵌套数据未处理 |
| 多重共线性 | 多元回归 | VIF、容忍度、相关矩阵 | 未报告 VIF 或报告但未处理 |
| 残差正态性/同方差性 | 回归 | 残差图、Breusch-Pagan | 模型拟合后未检查残差 |

## 二、方法专项检查清单

### 2.1 *t* 检验（独立样本 / 配对样本）

| 检查项 | 说明 |
|--------|------|
| 报告 *t* 统计量 | *t*(df) = X.XX, *p* = .XXX |
| 独立 vs 配对 | 选择是否正确？配对设计需报告配对逻辑 |
| 效应量 | Cohen's *d*（独立）或 *d*_z（配对） |
| 假设检验 | 正态性（小样本时重要）、方差齐性（独立 *t* 检验） |
| Welch's *t* 检验 | 方差不齐时是否使用 Welch 校正？ |
| 方向性 | 单尾 vs 双尾是否有先验理论依据支持？ |

### 2.2 方差分析（单因素 / 多因素 / 重复测量）

| 检查项 | 说明 |
|--------|------|
| 报告 *F* 统计量 | *F*(df1, df2) = X.XX, *p* = .XXX |
| 效应量 | *eta*-squared、partial *eta*-squared 或 *omega*-squared |
| 事后比较 | 主效应显著时是否做了事后检验（Tukey / Bonferroni / Games-Howell）？ |
| 交互效应 | 多因素设计中是否解释了交互效应？是否检验了简单效应？ |
| 球形假设 | 重复测量时是否报告 Mauchly 检验 + Greenhouse-Geisser / Huynh-Feldt 校正？ |
| 假设检验 | 正态性、方差齐性（Levene）、组间观察的独立性 |
| 不等组样本量 | 组样本量差异较大时是否使用 Type III SS？ |

### 2.3 回归分析（线性 / 逻辑）

#### 线性回归

| 检查项 | 说明 |
|--------|------|
| 模型摘要 | *R*-squared、调整 *R*-squared、模型 *F* 检验 |
| 系数表 | *B*、*SE*、*beta*、*t*、*p*、*B* 的 95% CI |
| 多重共线性 | VIF（< 5 或 < 10，视领域惯例）、容忍度 |
| 残差诊断 | 正态性、同方差性、线性、异常值（Cook's *D*） |
| 变量选择 | Enter vs Stepwise 方法的选择依据 |
| 效应量 | *R*-squared、*f*-squared、Cohen's *f*-squared |

#### 逻辑回归

| 检查项 | 说明 |
|--------|------|
| 模型拟合 | Hosmer-Lemeshow / 卡方 / -2LL / Nagelkerke *R*-squared |
| 系数报告 | *B*、*SE*、Wald、OR、OR 的 95% CI |
| 分类准确率 | 分类表、敏感度、特异度、AUC/ROC |
| 假设 | 观察独立性、logit 线性（连续预测变量与 logit 之间的线性关系） |
| 样本量 | 每个预测变量至少 10–20 个事件（EPV 规则） |

### 2.4 结构方程模型（SEM）

| 检查项 | 标准 |
|--------|------|
| 样本量 | 通常 >= 200；或估计参数数的 5–10 倍 |
| 模型拟合指标 | **必须同时报告多个指标**（至少 4 个） |
| CFI / TLI | >= .95（良好）；>= .90（可接受） |
| RMSEA | <= .06（良好）；<= .08（可接受）；必须报告 90% CI |
| SRMR | <= .08 |
| 卡方/df | <= 3（部分学者建议 <= 2） |
| 因子载荷 | 标准化载荷 >= .50（理想 >= .70） |
| 测量模型 | SEM 之前先做 CFA（两步法） |
| 信度和效度 | CR >= .70, AVE >= .50, 区分效度（Fornell-Larcker / HTMT） |
| 修正指数 | 使用修正指数时必须有理论支持 |
| 正态性 | 多元正态性（Mardia 系数）；违反时使用稳健 ML 或 Bootstrap |

### 2.5 多层线性模型（HLM / MLM）

| 检查项 | 标准 |
|--------|------|
| 嵌套结构 | 清楚解释每一层（如：员工 → 团队 → 组织） |
| ICC | 报告组内相关系数；ICC > .05 支持使用 MLM |
| 随机效应 | 报告随机截距和（如适用）随机斜率的方差 |
| 固定效应 | 报告系数、*SE*、*t* / *z*、*p*、CI |
| 层间样本量 | 层 2 单位数（通常建议 >= 30） |
| 中心化 | 说明使用的是总均值中心化还是组均值中心化及原因 |
| 模型比较 | 使用偏差（-2LL）、AIC、BIC 比较嵌套模型 |
| 效应量 | 伪 *R*-squared（多层模型常用指标） |

### 2.6 卡方检验

| 检查项 | 说明 |
|--------|------|
| 报告格式 | chi-squared(df, *N* = XX) = X.XX, *p* = .XXX |
| 效应量 | Cramer's *V*（大于 2x2）或 *phi*（2x2） |
| 期望频数 | 所有单元格期望频数 >= 5；若有 < 5，使用 Fisher 精确检验 |
| 独立性 | 观察是否真正独立？（重复测量不适合普通卡方） |
| 残差分析 | 显著时检查标准化残差以确定哪些单元格贡献了显著性 |

### 2.7 非参数检验

| 检查项 | 说明 |
|--------|------|
| 使用理由 | 清楚说明为何不使用参数检验（如正态性违反、顺序量表） |
| 方法选择 | Mann-Whitney *U* / Wilcoxon / Kruskal-Wallis / Friedman — 是否选对了检验 |
| 效应量 | *r* = *Z* / sqrt(*N*)（Mann-Whitney）；*W*（Kendall's） |
| 报告格式 | 报告检验统计量、*p* 值、效应量 |
| 事后比较 | Kruskal-Wallis 显著后需做两两比较 + 校正 |

## 三、APA 第 7 版统计格式速查

### 3.1 数字格式

| 规则 | 正确 | 错误 |
|------|------|------|
| *p* 值无前导零 | *p* = .032 | *p* = 0.032 |
| 可超过 1.0 的统计量有前导零 | *M* = 0.75 | *M* = .75 |
| 不可超过 1.0 的统计量无前导零 | *r* = .45 | *r* = 0.45 |
| 通常保留 2 位小数 | *M* = 3.45 | *M* = 3.4 |
| *p* 值保留 2–3 位小数 | *p* = .03 或 *p* = .032 | *p* = .0321 |
| 百分比保留 0–1 位小数 | 45.2% | 45.2381% |

**不可超过 1.0 的统计量**（无前导零）：相关系数（*r*, *R*）、比率（*p* 值）、Cramer's *V*、*phi*、*eta*-squared、*R*-squared、*beta*（标准化回归系数）

**可超过 1.0 的统计量**（有前导零）：*M*、*SD*、*B*（非标准化回归系数）、Cohen's *d*、*t*、*F*、卡方

### 3.2 统计符号斜体规则

| 斜体 | 非斜体 |
|------|--------|
| *M*, *SD*, *SE* | df |
| *N*（总样本）、*n*（子样本） | SS, MS |
| *t*, *F*, *p*, *r*, *R*, *z* | OR, CI, VIF |
| *d*, *f*-squared, *eta*-squared, *omega*-squared | AIC, BIC, CFI, TLI |
| *B*, *beta* | RMSEA, SRMR |
| 卡方 | ICC |
| *U*, *W*（非参数统计量） | ANOVA, SEM, HLM |

### 3.3 统计结果报告格式示例

| 分析方法 | APA 格式示例 |
|----------|-------------|
| 独立样本 *t* 检验 | *t*(58) = 2.45, *p* = .017, *d* = 0.63, 95% CI [0.12, 1.14] |
| 配对样本 *t* 检验 | *t*(29) = -3.12, *p* = .004, *d*_z = 0.57 |
| 单因素方差分析 | *F*(2, 87) = 4.56, *p* = .013, partial *eta*-squared = .09 |
| 线性回归 | *B* = 0.34, *SE* = 0.12, *beta* = .28, *t*(95) = 2.83, *p* = .006, 95% CI [0.10, 0.58] |
| 逻辑回归 | *B* = 1.24, *SE* = 0.45, Wald = 7.59, *p* = .006, OR = 3.46, 95% CI [1.43, 8.37] |
| 卡方检验 | chi-squared(2, *N* = 150) = 8.34, *p* = .015, *V* = .24 |
| Mann-Whitney | *U* = 245.00, *z* = -2.31, *p* = .021, *r* = .29 |
| SEM 拟合 | chi-squared(52) = 78.34, *p* = .011, CFI = .97, TLI = .96, RMSEA = .045 [.018, .068], SRMR = .038 |
| HLM 固定效应 | *gamma*_10 = 0.45, *SE* = 0.15, *t*(28) = 3.00, *p* = .006 |

### 3.4 表格格式标准

| 规则 | 说明 |
|------|------|
| 三线表 | APA 表格仅有三条水平线（表头上方、表头下方、表底部），无竖线 |
| 表格编号 | 表 1、表 2…（加粗），标题在编号下一行（斜体） |
| 注释层级 | 一般注释（Note.）→ 特定注释（上标 a, b）→ 显著性（*p* < .05, **p* < .01） |
| 星号 | \**p* < .05. \*\**p* < .01. \*\*\**p* < .001. |
| 对齐方式 | 数字右对齐，小数点对齐 |

## 四、统计危险信号

以下模式在评审时应引起警觉，需进一步调查或要求作者澄清：

### 4.1 P-hacking 迹象

| 危险信号 | 描述 | 严重程度 |
|----------|------|----------|
| 多个 *p* 接近 .05 | 多个结果 *p* 值集中在 .04-.05 范围 | 高 |
| 选择性报告 | 仅报告显著结果，不显著的结果消失 | 高 |
| 模糊的分析策略 | 分析策略未事先声明，事后看像是探索性的 | 中 |
| 意外的亚组分析 | 事后分解亚组以寻找显著结果 | 中 |
| 灵活样本量 | 无预设停止规则（序列检验无校正） | 高 |
| "排除异常值" | 排除大量异常值但标准不清晰 | 中 |

### 4.2 HARKing（已知结果后假设）

| 危险信号 | 描述 | 严重程度 |
|----------|------|----------|
| 完美的假设-结果匹配 | 所有假设全部支持，无一例外 | 中 |
| 探索性分析包装为验证性 | 文献综述明显是事后构建 | 高 |
| 假设方向改变 | 原预测正向但结果为负，却声称"如预期" | 高 |
| 无预注册 | 未提供 OSF / AsPredicted 预注册链接（非强制但推荐） | 低 |

### 4.3 缺失效应量和置信区间

| 危险信号 | 描述 | 严重程度 |
|----------|------|----------|
| 完全无效应量 | 结论仅基于 *p* 值 | 高 |
| CI 完全缺失 | 无法判断估计精度 | 中 |
| CI 极宽 | CI 跨越小到大效应量，估计不精确 | 中 |
| 效应量不一致 | 报告的效应量与原始数据计算不一致 | 高 |

### 4.4 样本量问题

| 危险信号 | 描述 | 严重程度 |
|----------|------|----------|
| 无功效分析 | 样本量缺乏事先计算依据 | 中 |
| 样本过小 | 回归分析中 *N* < 10 × 预测变量数 | 高 |
| 未解释的样本流失 | 初始 *N* 与最终 *N* 差距大但无解释 | 中 |
| SEM 小样本 | *N* < 200 且无小样本校正 | 中 |
| HLM 层 2 不足 | 层 2 单位 < 30 | 中 |

### 4.5 未校正的多重比较

| 危险信号 | 描述 | 严重程度 |
|----------|------|----------|
| 多个 *t* 检验代替 ANOVA | 3+ 组比较使用多个 *t* 检验 | 高 |
| ANOVA 后无事后检验 | 主效应显著但声称组间差异无事后检验 | 中 |
| 多个因变量未校正 | 同一数据集上分别检验多个因变量无 Bonferroni 或 FDR | 中 |
| 多模型比较 | 尝试多个模型但仅报告"最好的" | 高 |

### 4.6 假设违反

| 危险信号 | 描述 | 严重程度 |
|----------|------|----------|
| 假设检验完全缺失 | 跳过正态性/方差齐性/线性检验 | 中 |
| 违反未处理 | 报告了违反但仍使用原分析 | 高 |
| 以 CLT 为借口 | "因为 *N* > 30，正态性可忽略"但未实际检验 | 低 |
| VIF 过高 | VIF > 10 但未采取行动 | 高 |

### 4.7 其他危险信号

| 危险信号 | 描述 | 严重程度 |
|----------|------|----------|
| *p* = .000 | 统计软件原始输出，应为 *p* < .001 | 低 |
| df 与 *N* 不一致 | 从自由度推算的 *N* 与报告的 *N* 不匹配 | 高 |
| 表格数字不一致 | 正文叙述与表格数值矛盾 | 高 |
| 未说明统计软件 | 未报告所用统计软件（R）及版本 | 低 |
| 因果语言 | 非实验设计（相关/问卷）使用因果推断语言 | 中 |

## 五、OBHRM 研究中的常用统计方法

### 5.1 按研究问题类型推荐方法

| 研究问题类型 | 推荐方法 | 说明 |
|-------------|----------|------|
| 两组比较（如实验 vs 对照） | 独立样本 *t* 检验 / Mann-Whitney | 取决于数据正态性 |
| 多组比较（如不同组织类型） | ANOVA / Kruskal-Wallis | 3+ 组均值比较 |
| 前后比较（如干预前后） | 配对 *t* 检验 / Wilcoxon | 同组内变化 |
| 预测分析（连续因变量） | 多元回归 | 多个预测变量对连续结果的影响 |
| 预测分析（二分类因变量） | 逻辑回归 | 如离职/留任、晋升/未晋升 |
| 嵌套数据（员工 → 团队 → 组织） | 多层 SEM（HLM / MLM） | OBHRM 数据天然具有嵌套结构（方法族 2.3） |
| 潜变量和路径分析 | SEM 总体 / 测量模型（CFA） | 测量不可观测构念（如组织氛围）（方法族 2.1 / 2.2） |
| 量表信效度检验 | 测量模型（EFA → CFA） | 量表开发或验证（方法族 2.2） |
| 分类变量关联 | 卡方 / Fisher 精确 | 交叉表分析 |
| 纵向数据 | 潜在增长模型（LGM/LGA） | 追踪员工发展轨迹（方法族 2.15） |
| 中介效应 | 中介分析（Bootstrap SEM / PROCESS） | 检验间接效应（方法族 2.6） |
| 调节效应 | 调节与响应面（含交互项回归 / 多群组 SEM） | 检验边界条件（方法族 2.7） |

### 5.2 OBHRM 研究特殊考量

| 考量 | 说明 |
|------|------|
| **嵌套结构** | OBHRM 数据几乎总有嵌套（员工 → 团队/部门 → 组织）；忽略会低估标准误，膨胀 I 类错误 |
| **共同方法偏差（CMB）** | 问卷数据中单一来源偏差是常见威胁；需进行 Harman 单因子检验或标记变量检验 |
| **选择偏差** | 员工自我选择进入组织/部门，非随机分配；考虑倾向得分匹配或 Heckman 校正 |
| **天花板/地板效应** | 满意度/敬业度量表常出现极端偏态；需检查并考虑 Tobit 模型或非参数方法 |
| **时滞设计** | 自变量和因变量同时收集会夸大相关性；推荐时间滞后设计或多波次收集 |
| **多层测量不变性** | 多群组比较时需检验测量不变性（configural / metric / scalar） |

## 六、统计报告完整度评分标准

### 评分维度与权重

| 维度 | 权重 | 满分标准 |
|------|------|----------|
| A. 描述性统计完整度 | 15% | M、SD、N、范围齐全 |
| B. 效应量报告 | 20% | 所有检验附带效应量 |
| C. 置信区间报告 | 15% | 关键估计包含 CI |
| D. 假设检验报告 | 15% | 所有统计假设已检验 |
| E. 统计功效 | 10% | 完整的事前功效分析 |
| F. 缺失数据处理 | 10% | 报告缺失数据数量和处理方法 |
| G. APA 格式正确性 | 10% | 符号、小数位、表格合规 |
| H. 无危险信号 | 5% | 未检测到第四节的危险信号 |

### 评分等级

| 等级 | 分数 | 说明 |
|------|------|------|
| 优秀 | 90–100 | 统计报告规范，所有项目完整且格式正确 |
| 合格 | 70–89 | 主要项目完整，少量遗漏不影响结论可信度 |
| 需改进 | 50–69 | 明显遗漏（如缺失效应量或假设检验），需补充 |
| 不足 | 30–49 | 多项缺失，统计报告不足以支持结论 |
| 不合格 | 0–29 | 统计报告严重不足，需大幅修改 |
