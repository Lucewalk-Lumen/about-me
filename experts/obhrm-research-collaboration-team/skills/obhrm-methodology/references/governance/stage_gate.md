## 核心概念：三态门控

每个阶段衔接不再是简单的「确认→下一个」，而是通过一个**三态门控**判断：

```
阶段输出 → [门控检查] → 
  ├─ [绿/通过] 通过：可以进入下一阶段
  ├─ [黄/待优化] 条件通过：可以继续，但需在下阶段修正特定问题
  └─ [红/不通过] 不通过：必须先在本阶段修正，不满足条件不得推进
```

**关键原则**：AI 在获得用户确认前，必须先自行通过门控检查。如果 AI 发现输出不满足通过条件，应在向用户展示输出时主动标记问题，而不是隐瞒并被动等待用户发现问题。

## 通用门控协议

### 协议 G-EXIT：任何阶段结束时的 5 个必检问题

在向用户展示输出并请求确认之前，AI 必须在思考过程中回答：

| # | 必检问题 | 如果答案为「否」 |
|---|----------|-----------------|
| 1 | 本阶段的输出物是否完整？所有要求的字段/内容都填充了吗？ | [黄/待优化] 标注缺失项，允许继续但需下阶段补充 |
| 2 | 本阶段的核心结论是否有明确的依据（文献/数据/推理），而非仅凭常识？ | [红/不通过] 需补充依据后方可推进 |
| 3 | 输出是否与前面已完成的阶段保持一致？（无矛盾、无重复、无跳跃） | [红/不通过] 矛盾必须在本阶段解决 |
| 4 | 是否存在「上一阶段可能需要修改」的信号？ | [黄/待优化] 标记信号，建议用户评估是否需要回溯 |
| 5 | 进入下一阶段前，用户是否具备了理解下一阶段所需的全部信息？ | [红/不通过] 需补充信息后推进 |

### 协议 G-ENTER：进入任何阶段时的上下文加载

进入新阶段时，AI 必须先做 3 件事：

1. **继承前阶段摘要**：用 2-3 句话概括前一阶段的核心结论（这是本阶段的输入）
2. **声明本阶段目标**：基于前一阶段结论，本阶段要回答什么问题
3. **预判风险**：基于前一阶段的质量评估，本阶段是否存在额外的风险

## A路径：论文生产门控规则

### A1→A2 选题通过门

**门控检查项**（必须全部满足方可进入 A2）：

| 检查项 | 通过条件 | 不通过时的路由 |
|--------|----------|---------------|
| G-A1-1 研究问题 | 有明确的一句话研究问题（包含情境+现象+机制+结果），不是仅描述现象 | **[红/不通过] 回溯 A1**：重写研究问题 |
| G-A1-2 七维评分 | 所有必评维度（最低：重要性、新颖性、好奇性）均 >= 3 分 | **[红/不通过] 回溯 A1**：如果任一维度 <= 2 分，选题不可行，需重新选题 |
| G-A1-3 研究谜题 | 谜题通过了紧张感 5 连问测试（来自深度思维协议 A1-THINK-3） | **[黄/待优化] 条件通过**：标记为风险点，A2 阶段需特别关注文献能否支撑谜题 |
| G-A1-4 目标层级匹配 | 选题复杂度与研究目标层级匹配（不会用 SSCI 级的方法做 CSSCI 级的题，反之亦然） | **[黄/待优化] 条件通过**：向用户说明不匹配的风险，由用户决定 |
| G-A1-5 理论视角 | 初步识别了至少 1 个理论锚点（不可仅泛泛说「基于XX理论」而无具体机制） | **[黄/待优化] 条件通过**：A3 阶段需投入更多时间做理论匹配 |

**特殊路由规则**：
- 如果 G-A1-2 重要性或新颖性 <= 2 分 → **建议放弃当前选题**，回到选题头脑风暴

**过渡提示**（替换原来的「确认后进入 A2」）：
```
选题已通过门控检查。以下是你需要在 A2 文献检索阶段回答的核心问题：

1. 你的研究谜题在文献中是否真实存在？（验证你的 puzzle）
2. 已有文献对你的研究问题提供了哪些竞争解释？
3. 你识别的那条文献对话线，近五年有哪些最新推进？

如果上述问题中的任何一个让你不确定你的选题是否成立，
建议在 A2 开始前先修正研究问题，而不是带着疑问进入文献检索。
```

### A2→A3 文献充分门

**门控检查项**（必须全部满足方可进入 A3）：

| 检查项 | 通过条件 | 不通过时的路由 |
|--------|----------|---------------|
| G-A2-1 文献证据矩阵 | 矩阵包含 >= 15 条文献记录，且至少包含 5 篇近五年文献 | **[红/不通过] 回溯 A2**：补充检索 |
| G-A2-2 文献链 | 至少 3 条清晰的文献链，每条链有「已有→推进→不足→本研究」完整结构 | **[红/不通过] 回溯 A2**：继续检索直至链完整 |
| G-A2-3 Gap 等级 | 至少有一个 S 级或 A 级 gap（来自思维协议 A2-THINK-3 的分级标准） | **[红/不通过] 回溯 A1/A2**：如果最高的 gap 只有 B 级，说明文献覆盖不够或选题 gap 不够真实，需回到 A1 修正 |
| G-A2-4 文献验证 | 所有引用的文献均来自真实检索，没有凭内部知识编造的引用 | **[红/不通过] 回溯 A2**：逐条核实 |
| G-A2-5 与选题一致性 | A2 发现的 gap 与 A1 提出的谜题一致（不应出现「检索后发现了完全不同的 gap」却未更新谜题） | **[红/不通过] 回溯 A1**：如果 gap 变了，谜题也需要更新 |

**特殊路由规则**：
- 如果 A2 检索发现选题已被充分研究（近 3 年 >= 5 篇同主题顶刊论文已发表）→ **建议切换到「差异化切入」策略**：不换题，但必须找到已有研究未覆盖的边界条件或调节变量
- 如果 A2 检索发现 A1 的理论视角已被证伪 → **回溯 A1**：更换理论视角
- 如果 A2 检索发现数据获取不可行（如需要的样本难以接触）→ **回溯 A4**：提前考虑方法论替代方案

**过渡提示**：
```
文献检索已通过门控检查。核心发现：

- 文献对话对象：[列出 2-3 个核心文献集群]
- Gap 质量：[S/A/B/C 级]
- 风险提示：[如：某条文献链的支撑不够强，A3 理论建构时需注意]

进入 A3 理论建构前，请确认：你清楚将要对话的文献具体说了什么，
并且你的 gap 不是「这个没人做过」这种 C 级 gap。
```

### A3→A4 理论可检验门

**门控检查项**（必须全部满足方可进入 A4）：

| 检查项 | 通过条件 | 不通过时的路由 |
|--------|----------|---------------|
| G-A3-1 Whetten 四问 | 每个核心理论的 What/How/Why/WhoWhereWhen 均已填写，Why 部分 >= 3 句完整逻辑链 | **[红/不通过] 回溯 A3**：补充理论推理 |
| G-A3-2 假设三段论 | 每条假设包含完整的「前提→推理→预测」结构，且每条有竞争假设 | **[红/不通过] 回溯 A3**：补充竞争假设 |
| G-A3-3 构念区分度 | 关键构念之间的区分效度已被论证（关联关系 r 明确，无 r > 0.6 的构念对） | **[黄/待优化] 条件通过**：A4 阶段需设计区分效度检验 |
| G-A3-4 可检验性 | 每条假设的核心变量可以操作化（能找到对应量表或测量方法） | **[红/不通过] 回溯 A3**：如果某个构念无法测量，替换构念或假设 |
| G-A3-5 与 A2 gap 对齐 | 理论模型回应的 gap 与 A2 识别的 gap 一致 | **[红/不通过] 回溯 A2/A3**：不一致说明理论匹配有问题 |

**特殊路由规则**：
- 如果 A3 发现理论模型与 A1 的原始研究问题不兼容 → **回溯 A1**：修改研究问题或更换理论
- 如果用户已收集数据但理论模型依赖的变量并未测量 → **切换到已有数据分析路径**：基于已有变量重新建模
- 如果 A3 产生了 > 8 条假设 → **[黄/待优化] 警告**：A4 需要考虑多重检验校正和样本量

**过渡提示**：
```
理论模型已通过门控检查。在进入 A4 研究设计前，请回答：

1. 你的每条假设对应的关键变量，用什么量表测量？（具体量表来源）
2. 你的模型中最难测量的构念是什么？有备选方案吗？
3. 你需要什么类型的数据？（横截面/纵向/实验/二手）为什么？

A4 阶段的核心任务是将你的理论承诺转化为可操作的研究方案。
```

### A4→A5 设计可行门

**门控检查项**（必须全部满足方可进入 A5）：

| 检查项 | 通过条件 | 不通过时的路由 |
|--------|----------|---------------|
| G-A4-1 样本论证 | 有 G*Power 或其他经验法则的样本量论证（power >= 0.80） | **[红/不通过] 回溯 A4**：补充样本量论证 |
| G-A4-2 内生性应对 | 标注了本研究面临的至少 3 种内生性威胁，且各有应对方案 | **[黄/待优化] 条件通过**：A5 讨论部分需承认未解决的内生性问题 |
| G-A4-3 量表来源 | 所有核心构念的量表来源已标注（作者+年份+题项数+信度引用） | **[红/不通过] 回溯 A4**：补充量表信息 |
| G-A4-4 数据可行性 | 样本来源可获取（不是理想化但无法接触的人群） | **[红/不通过] 回溯 A4**：更换样本来源或研究设计 |
| G-A4-5 与 A3 假设对齐 | 研究设计能够精确检验 A3 提出的所有假设 | **[红/不通过] 回溯 A4 或 A3**：设计不足则改设计，设计无法解决则简化假设 |

**特殊路由规则**：
- 如果 A4 发现数据获取完全不可行 → **建议暂停 论文路径**，与用户讨论替代方案
- 如果用户已有数据且与研究设计不兼容 → **切换到已有数据分析路径**

**过渡提示**：
```
研究设计已通过门控检查。在进入 A5 写作前，确认：

- 你的研究设计能否真正回答 A1 提出的问题？
- 你是否能在一个合理的期限内完成数据收集？
- 你是否有一个备用方案（万一主方案失败）？

A5 写作阶段将把你的全部前期工作转化为一篇结构完整、逻辑自洽的论文。
```

### A5→A6 写作完成门

**门控检查项**（必须全部满足方可进入 A6）：

| 检查项 | 通过条件 | 不通过时的路由 |
|--------|----------|---------------|
| G-A5-1 完整性 | 所有标准章节已完成（引言/理论/方法/结果/讨论），无空白占位符 | **[红/不通过] 回溯 A5**：补充缺失章节 |
| G-A5-2 AI 痕迹 | 已执行 AI 痕迹自检（来自思维协议 A5-THINK-2），清除了全部红线句式 | **[红/不通过] 回溯 A5**：逐段修改 |
| G-A5-3 逻辑连贯 | 引言→理论→方法→结果→讨论形成完整的逻辑链条，无断链 | **[红/不通过] 回溯 A5 或更早**：断链可能来自 A2/A3 阶段的根本问题 |
| G-A5-4 统计报告标准 | 效应量/置信区间/p 值报告符合 APA 7.0（参考统计报告标准） | **[红/不通过] 回溯 A5**：修正统计报告 |
| G-A5-5 贡献声明 | 每条理论贡献至少有文献对比（不是泛泛「丰富了」，而是「与 XX(年份)不同，本研究…」） | **[红/不通过] 回溯 A5**：重写贡献声明 |

## B路径：基金项目书门控规则

基金路径门控与 论文路径共享核心逻辑，但额外增加：

| 门控 | 专项检查 | 不通过时的路由 |
|------|----------|---------------|
| B1→B2 | 申报类型识别正确（国自科/国社科/教育部不会混淆），语言风格已切换 | **[红/不通过] 回溯 B1** |
| B3→B4 | 文献述评通过了「页面限制精炼」（如教育部 B 表 ≤ 2 页） | **[红/不通过] 回溯 B3**：压缩 |
| B4→B5 | 研究内容和技术路线可操作（不是画了大饼但无法落地） | **[红/不通过] 回溯 B4 或 B5** |
| B6→B7 | 创新点区分度清晰（不是「视角新+方法新+内容新」的老三样） | **[红/不通过] 回溯 B6**：重写创新点 |

## C路径：诊断评审门控规则

审稿路径门控的特殊之处在于：它是一个「环形路径」——诊断完成后不应该直接结束，而应该形成反馈。

| 门控 | 专项检查 | 不通过时的路由 |
|------|----------|---------------|
| C5→C8 | 诊断覆盖了所有维度，每条诊断有「事实→判断→建议」三连结构 | **[红/不通过] 回溯 C5** |
| C9→结束 | **关键**：不同路径结束方式不同 | 见下方跨路径规则 |

## 跨路径路由规则

### 规则 X-AFTER-C：审稿路径结束后的路由决策

审稿路径（诊断）完成后，不应该简单结束。根据诊断对象执行不同的路由：

| 诊断对象 | 诊断完成后的路由 |
|----------|-----------------|
| 诊断的是「新稿件」（非本技能生成的） | 生成修改路线图 → **向用户提供 论文路径入口**：「是否需要在诊断后重新生成/修改稿件？如果是，我可以直接用诊断结果作为改进输入」 |
| 诊断的是「本技能 论文路径生成后又诊断的稿件」 | 生成修改路线图 → **自动触发 论文路径回灌机制**：将诊断问题映射到对应 A1-A5 阶段，逐阶段修正 |
| 诊断的是「返修稿」 | **如果用户说「先诊断再修改」→ 自动衔接 论文路径** |
| 诊断的是「项目书」 | 生成修改路线图 → **自动衔接 基金路径回灌** |

### 规则 X-SKIP：智能跳过规则

某些条件下，允许跳过阶段，但 AI 必须明确告知跳过的风险和后果：

| 跳过场景 | 允许条件 | 必须告知的风险 | 补救措施 |
|----------|----------|---------------|----------|
| 跳过 A1，直接进 A2 | 用户已有确定的选题 | 文献检索可能没有明确的检索方向 | A2 开始时先做简化的选题评估（3 分钟版） |
| 跳过 A2，直接进 A3 | 用户已有完整的文献基础 | 可能遗漏重要最新文献 | A3 输出标注「未执行系统检索」 |
| 跳过 A4，直接进 A5 | 用户已有收集好的数据，只差写作 | 不能事后补方法论论证 | A5 方法部分需标注「数据为既有数据」 |
| 跳过 B1-B3，直接进 B4-B6 | 用户已有选题+文献部分 | 研究设计和创新点可能与前部分脱节 | 先快速审核 B1-B3 已有内容的一致性 |

### 规则 X-LOOP：回溯循环规则

当前阶段的发现可能要求修改前阶段。回溯不是失败，是正常的迭代。

| 触发条件 | 回溯目标 | 回溯深度 |
|----------|----------|----------|
| A2 文献不支持 A1 的谜题 | A1 | 修改研究问题或谜题 |
| A3 理论无法操作化 A2 的 gap | A2 或 A3 | 修改 gap 定位或更换理论 |
| A4 无法设计实验/问卷检验 A3 的假设 | A3 或 A4 | 简化假设或更换设计 |
| A5 写作时发现 A3 的假设逻辑不通 | A3 | 修正假设发展 |
| B3 文献述评发现 B2 的选题不新 | B2 | 重新选题或换切入角度 |
| C5 诊断发现根本性问题 | 对应 A/B 阶段 | 深度回溯，问题有多深回溯多深 |

### 规则 X-BACKTRACK：回溯的最大深度

```
如果回溯到 A1（选题层），确认该层状态后，重新按 A1→A2→...顺序推进。
已经通过门控的阶段可以快速通过（复用已有输出），但门控检查不可跳过。

回溯不是「推翻重来」，而是「发现前置问题 → 解决 → 继续」。
每次回溯应比上次更深，而不是在同一层反复循环。
```

## 智能过渡提示模板

每个阶段衔接时，AI 必须输出标准化的「过渡摘要」，替换原来的「确认后进入下一阶段」。

### 模板

```
---
```

## 5 步执行细则

**1. 明确产出**：阅读该阶段参考文档，确认所有输出要素。不知道规范是什么就看 `references/` 里对应的文件。

**2. 完整写出**：产出可直接使用的完整段落。如果超过 4000 字，可以分步输出，每步是完整的一节。

**3. 自检**：问三个问题——
- 该有的都写了吗？
- 每部分够详细吗？
- 有没有"大量研究表明""通常""可能"这类虚指需要替换？

**4. 标记完成**：输出「[阶段X 完成]」。

**5. 确认下一步**：
- 关键节点（B1/B2/B8/B9、A1/A5/A6、C5/C8/C9）：停下来问"A.继续 B.修改 C.暂停"，等你选择。
- 普通节点：告知下一阶段后自动推进。
- C9 终点额外问"结束 还是 改进"。

自检不过关最多改两轮，两轮后告知用户卡在哪里，问是否接受。

## B2 文献综述细则

B2 决定项目书质量。产出要求：

- 5 条以上文献脉络（按主题/时间/理论均可），每脉络 3 篇以上，说明核心发现，收尾指出不足
- 研究缺口表格：3-5 个缺口 × 对应文献 × 本研究填补思路
- 国内外对比：至少 1 段
- 引用格式全用"作者(年份)"

B2 完成后用户可选择：继续 B3 / 补充本地文献 / 联网搜索扩展。

## B→C→B 改进闭环

审稿路径诊断时，每个问题标注来源阶段（如 [B2]）。改进时按标注逐阶段修正，不整体重写。改完后跑 B9 整合去重。最多 3 轮迭代。

## 禁止事项

- 不写提纲（"文献综述应包括：1.…"）
- 不省略（"此处略""见上文"）
- 不用占位符（"[此处插入]"）
- 不一段话概括后声称完成
- 不使用"大量研究表明""学术界普遍认为""通常"等虚指

## 审稿路径诊断细则

C5 逐项诊断八个维度，每个维度给出 1-5 分 + 具体评语 + 可操作的修改建议（口径以 `../../../peer-review/SKILL.md`「诊断八维度」为准）：

1. 选题质量 — 研究问题是否清晰、有理论意义、反直觉？
2. 文献覆盖 — 文献链是否完整、是否涵盖最新研究、是否闭环到本研究？
3. 理论深度 — 假设推导是否严密、图尔敏 Warrant 是否清晰？
4. 方法严谨 — 样本论证、量表选择、CMV 处理是否充分？
5. 写作质量 — 逻辑连贯性、表述准确性、有无AI痕迹？
6. 创新程度 — 理论/方法/实践贡献是否具体可验证？
7. 图表呈现 — 含数据处是否有图/表、是否编号 + 图注(≥80字) + 正文引用？
8. 逻辑连接 — 主张-证据-文献三元是否齐备、章节/图/表是否互引、有无孤岛段落与逻辑断链？

C5 按严重程度分类排序问题，C9 提供 A.结束 B.改进 C.全文重写三个选项。
