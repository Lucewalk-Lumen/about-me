# 来源可信分级（source_trust_tiers · M1/M2/F/U）

> 本文件把「引用保真 + 四铁律·标注无支撑」落成**内容层级契约**：拿到什么层级的材料，就只能做该层级允许的动作，越级即违规。
> 来源可信分级按 OBHRM 蒸馏三落点判为**套件操作层**（依赖具体来源与权限，换执行工具不成立），与 `../ethics/ethics_guide.md` 和 `../../quality_gates.json` 的 `citation_fidelity` / `four_iron_rules` 对齐。

---

## 一、内容层级（content tiers）

| 等级 | 当前拿到的内容 | 可以做 | 不可以做 |
|------|---------------|--------|----------|
| **M1** | 可靠元数据（DOI / 作者 / 年 / 题名 / 出版源） | 核验文献身份、格式化已有字段 | 写论文结论、引语、页码、方法细节 |
| **M2** | 元数据 + 数据库原始摘要 | 转述摘要**明确写出**的研究目的 / 方法概况 / 结果 / 结论，并标注「基于摘要」 | 直接引语、页码、详细样本、方法细节、结果数值、作者限制、全文论证 |
| **F** | 可访问全文 | 核对原文位置后做内容分析、译述、引文检查 | 超出原文、忽略版本与许可证 |
| **U** | 线索 / 搜索摘要 / 冲突记录 | 记录待核验、请用户补充 | 写入正式参考文献或正文事实 |

> 全文链接存在 ≠ 全文已读取；只有实际取得并核对正文及版本后才记为 **F**。

---

## 二、强约束

- **不编引用**：引文必须真实可查；M1/M2 层级不得伪造引语、页码、详细方法或数值。
- **不归观点**：文献观点归属到具体作者 + 年份，不归到「有研究表明」。
- **标注无支撑**：M2 转述必须显式「基于摘要」；U 层级可在显著标记「来源未经确证」后引用（本库不保证其真实性，严禁编造出处）。
- **位置诚实**：直接引语 / 页码 / 详细方法 / 数值 / 作者限制必须基于 F 全文；位置无法核实写「未提供位置」，不得编造页码或行号。

---

## 三、可核验来源（可访问层，少量、按需）

仅在用户要求核验已知文献、当前任务确实需要且来源可访问时使用；每次仍检查当前响应、许可证与内容层级。访问失败时不更换为不明聚合站，不通过高频重试 / 登录绕过 / 反爬对抗继续获取。

| 来源 | 入口 | 可核验 | 风险 |
|------|------|--------|------|
| Crossref REST API | `https://api.crossref.org/works/{DOI}` | 题名/作者/DOI/出版源/日期/卷期页/许可 | 低（元数据） |
| Semantic Scholar | `https://api.semanticscholar.org/graph/v1/` | 身份/摘要/DOI/开放全文线索 | 中（TLDR 与指标不得当事实） |
| arXiv API | `https://export.arxiv.org/api/query?id_list={id}` | 预印本身份/版本/摘要 | 中（非同行评审） |
| PubMed E-utilities | `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/` | 生物医学书目元数据 | 低（元数据） |

> 模型生成的 TLDR、学科分类、影响指标**不得作为论文事实**。已知 DOI 优先查 Crossref，再按学科交叉核验。

---

## 四、不主动访问的来源

中国知网、万方、维普，以及需要学校统一身份认证 / 个人付费 / 验证码 / 机构网络的数据库；论文下载聚合站、网盘转载、来源不明镜像、搜索结果摘要。

用户需要中文论文时，提供关键词 / 同义词 / 检索式 / 年份与学科筛选建议，请用户在本人有权使用的平台检索后提供：PDF 或可阅读全文、数据库导出的标准引用记录、DOI/PMID/arXiv ID 或出版社稳定链接、题名页 / 摘要页 / 方法 / 结果 / 参考文献关键页面、学校图书馆的合法永久链接。

---

## 五、固定降级规则

1. 先检查用户是否已提供可信原文 / 引用导出 / 稳定标识。
2. 已知 DOI 优先查 Crossref；按学科再用 Semantic Scholar / arXiv / PubMed 交叉核验。
3. 只得到元数据时停在 M1；只得到摘要时停在 M2，不升级为全文证据。
4. 连续两个可信开放来源无法确认身份，或任务需要原文但只有元数据/摘要时，停止继续搜索。
5. 告知用户缺少什么并请其提供可信材料；用户无法提供时跳过该文献，或将相应段落改为「待补证据的写作框架」。
6. 不用模型记忆、相似题名、搜索摘要、二手博客或其他论文替代缺失来源。
