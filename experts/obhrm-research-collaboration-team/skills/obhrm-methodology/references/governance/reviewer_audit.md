## 填写要点（agent 引导用户时使用）

1. **六类偏倚自检**：
   - 确认偏倚：是否只引支持假设的文献？是否在数据分析时只汇报显著的？
   - 发表偏倚：是否所有分析都基于已发表研究的预期方向？
   - 幸存者偏倚：样本是否完整（中途退出 / 缺失 / 异常值剔除是否记录）？
   - 过度泛化：结论是否超出样本的适用范围（年龄/行业/国家/文化/时间段）？
   - 因果误判：横截面设计是否被解读为因果？内生性是否处理？
   - 测量偏倚：核心变量是否单源测量？是否做了多方法三角验证？
2. **逻辑谬误自检**：
   - 稻草人：是否歪曲反对意见？
   - 滑坡：是否连锁推论无证据？
   - 诉诸权威：是否以"X 说过所以对"代替证据？
   - 其他：循环论证、伪二分法、错置因果
3. **拒稿预演**：让用户扮演 3 位审稿人（理论专家 / 方法专家 / 主编），各自列出最可能拒稿的 1 条理由，agent 引导应对。
4. **贡献声明**：对照 A1 `confirmed_contribution.md` 的一句话说贡献，写出对 3 位审稿人视角的回应（即"贡献 X 在 Y 审稿人眼里是 Z"）。

## 对抗性自审五维框架（OBHRM 适配）

> **适用**：A5 初稿完成后、作为拒稿预演的结构化前置；可与「拒稿理由预演」并行填写。

以挑剔审稿人身份，从五个维度逐项预审，每维给出 `pass / needs revision / needs new data`：

| 维度 | OBHRM 适配要点 | 典型拒稿信号 |
|------|----------------|--------------|
| **① 贡献新颖性** | 是否给出新理论机制 / 新边界条件 / 中国情境制度性变量？是否超越"换样本重跑"？洞见是否非平凡？ | "与 X (20xx) 仅样本不同"；机制只是既有理论的复述 |
| **② 理论机制清晰度** | 假设是否用图尔敏 Warrant 给出"理论→假设"机制？构念定义是否清晰？术语全文一致？ | "基于 X 理论提出 H1"无机制；构念操作化模糊 |
| **③ 实证强度** | 信效度（CFA / 组合信度 / AVE）、共同方法偏差（Harman 单因子 / 标记变量）、假设检验（β/p/效应量）、样本代表性是否充分？ | 单源同源测量未处理 CMB；只报 p 不报效应量 |
| **④ 评估完整性** | 稳健性 / 替代解释 / 负向案例 / 控制变量是否覆盖？量表来源与翻译回译是否交代？关键边界条件是否检验？ | 仅报告显著路径、忽略不显著或对立证据 |
| **⑤ 方法设计合理性** | 研究设计是否匹配研究问题（实验 / 问卷 / 二手数据）？横截面 vs 纵向的因果推论边界是否声明？是否多方法三角验证？ | 横截面被解读为因果；设计无法回答所提问题 |

**执行**：每维先以论文证据自答，再标 `pass / needs revision / needs new data`；任一 `needs revision/new data` 必须回 A5（或回 A4 补数据）消除后方可进入 A6。本框架的产出可直接喂给上方「拒稿理由预演」，作为三位审稿人视角最可能被拒的论据来源。

## 不变量

- 四段结构（六类偏倚 + 逻辑谬误 + 拒稿预演 + 贡献声明）必须齐全。
- 五维框架（若填写）每维必须给出 `pass / needs revision / needs new data` 之一，不得留空；`needs *` 项必须回 A5/A4 处置。
- 六类偏倚每行"是否存在"必须勾选 `□ 否` 或 `□ 是`，不得留空。
- 拒稿预演 3 条必须全部写明"当前应对"，空白即视为未处理。
