# 稳定 ID 全链路追踪体系

> **唯一真源 = `../templates/traceability-ledger.md`（templates/traceability-ledger.md）；本文件为子集映射文档**。规范前缀体系（S=材料/L=文献/C=主张/D=数据/F=图/T=表/A=外部要求/E=编辑要求/R=审稿/V=修订/阶段前缀）以真源为准；本文件表格保留套件早期使用的旧前缀（S/E/L/R/V/F），按「一、ID 命名规则」的「规范前缀映射」列转换，两处冲突时以真源为准。

> 跨"主张 / 证据 / 文献 / 审稿意见 / 修订任务 / 图表"的统一稳定 ID + 状态机，让论文从写作到返修全程可追溯。与套件既有〔R-xx〕〔综述·X〕引用标记互补：引用标记管"文献出处的学术规范"，稳定 ID 管"论点生命周期"——一个主张从提出、找证据、被审稿质疑、到修订完成，全程用同一编号串起来。

## 一、ID 命名规则

| 前缀 | 对象 | 格式 | 示例 | 规范前缀映射 |
|------|------|------|------|-------------|
| S | 主张 / 论点 / 假设（Statement） | S001, S002… | S001: 变革型领导正向影响员工创新行为 | 旧 S（主张）→ C |
| E | 证据 / 数据结果（Evidence） | E001, E002… | E001: 表3 回归系数 β=0.42, p<0.01 | 旧 E（证据）→ D/F/T/L（按载体） |
| L | 文献（Literature） | L001, L002… | L001: Wang et al. (2023) | L（文献）→ L |
| R | 审稿意见（Review comment） | R1.1, R1.2…（R=意见序号，.后为子条） | R1.1: H2 的理论机制论证不足 | R（审稿）→ R |
| V | 修订任务（Revision task） | V001, V002… | V001: 补充 H2 的理论机制（Warrant） | V（修订）→ V |
| F | 图表（Figure / Table） | F001, F002… | F001: 表3 假设检验结果 | 旧 F（图表）→ F（图）/T（表） |

**编号原则**：全文唯一、永不复用；删除某条后该编号作废，不补位；新增条目续编。

## 二、状态机（修订任务 V 的生命周期）

| 状态 | 含义 | 流转条件 |
|------|------|----------|
| 待办 | 待处理 | 审稿意见 R 落地后建 V，初始状态 |
| IN_PROGRESS | 处理中 | 开始修改 |
| VERIFIED_DONE | 已完成且经 C5 复核 | 审稿路径 C5 逐条核验通过 |
| BLOCKED_AUTHOR | 需作者补充信息 | 缺数据/缺权限/需用户决策 |
| WONT_FIX | 经讨论不予修改 | 须记录理由 + 审稿人沟通策略 |

## 三、与套件既有体系的关系

| 既有产物 | 稳定 ID 映射 |
|---------|-------------|
| 〔R-xx〕引用标记 | 升级为 L-编号（文献层），原标记格式保留 |
| 可追溯矩阵（贡献→假设→图表→结果） | "贡献/假设"列 → S-编号；"结果"列 → E-编号；"图表"列 → F-编号 |
| 审稿路径 C→W 交接块「逐条意见」 | 对应 R-编号 |
| 返修对照表「修改动作」 | 对应 V-编号 + 状态 |
| A2 文献链（已有→推进→缺口→本研究） | 每条文献赋 L-编号，本研究推进点赋 S-编号 |

## 四、交付前闭环检查（投稿就绪判定）

- 每个 S 至少链接 1 个 E（主张有证据支撑）
- 每个 E 链接到具体 F（证据有图表位置）
- 每条 R 有对应 V（审稿意见有响应）
- 每个 V 有终态状态（VERIFIED_DONE 或 WONT_FIX+理由）
- **投稿就绪**：所有 V ∈ {VERIFIED_DONE, WONT_FIX} 且无 待办 / BLOCKED_AUTHOR

> 未达投稿就绪判定时，标 [待作者输入]，由 `../../scripts/obhrm_preflight.py` 占位符检测拦截。

## 五、使用时机（嵌入路径节点）

| 路径阶段 | 建立哪些 ID |
|---------|------------|
| A1 选题与问题界定 | S（研究问题/核心主张） |
| A2 文献检索 | L（文献）、S（文献链推进点） |
| A3 理论建构与假设 | S（正式假设 Hx → S-编号）、L（理论文献） |
| A5 论文写作 | E（实证结果）、F（图表），填可追溯矩阵 |
| C3 逐项诊断 | R（审稿意见逐条编号） |
| C5 返修闭环 | V（修订任务）、状态流转 |
| 返修再审 | V 状态从 IN_PROGRESS → VERIFIED_DONE |
