# 按刊定制退稿点（Per-Venue Rejection Points）

> 来源说明（已校正）：本文件为**框架 + 本包补充的 OBHRM 逐刊退稿点**。
> - 上游参考 `brycewang-stanford/Awesome-Journal-Skills`（含中文经管类期刊的「按刊退稿点」整理思路），但其 corpus 偏经济学/通用经管，**不能直接套用到 OBHRM**。
> - 因此本文件**不搬运该库原始条目**，而是按 OBHRM 领域重新组织：通用自检维度（学科中立）+ 本包撰写的逐刊退稿点（每条标注`适用学科`）。
> - 逐刊点依据各刊 *Guide for Authors*、近年 *Editorial* 与常见 desk-reject / reviewer 模式综合整理，**写作时须以该刊当年官方说明为准核对**（见「红线」）。
> - 本文件为**增量补充**，不改动 `../SKILL.md` 既有流程。

## 目的

投稿前先加载目标期刊的退稿点清单（期刊要求可从 journal-selection 的 journals.db 与期刊官网 Author Guidelines 获取），把最容易拒稿的维度前置到写作与自检，而不是等审稿意见回来再改。

## 适用学科标注约定

每条退稿点均标注 `适用学科`，取值：

| 标签 | 含义 |
|------|------|
| `OBHRM` | 组织行为 / 人力资源管理 / 广义管理，OBHRM 投稿通用 |
| `OB`（组织行为） | 偏组织行为/心理取向 |
| `HR`（人力资源） | 偏人力资源管理/劳资 |
| `理论` | 纯概念/理论型刊物 |
| `通用` | 跨学科管理类投稿通用自检维度，非某刊专属 |
| `经济学` | 仅适用于经济学刊物（本包一般**不**命中，保留以明示边界） |

## 使用流程

1. 用户在 `journal-selection` 选定目标刊 → 主理人加载该刊 `rejection_points` 清单（维度 + 典型退稿表述 + `适用学科`）。
2. 写作/修改阶段，将退稿点与正文逐条反向核对；命中即进入「待修」清单。
3. 定稿前「退稿点清零」作为投稿前置门控之一（与既有 stage gate 并行）。

## 通用退稿点维度（适用学科：通用／管理类投稿通用自检，非某刊专属）

| 维度 | 典型退稿表述（示例） | 本包对应自检 |
|------|----------------------|--------------|
| 理论贡献模糊 | 「贡献点不清晰 / 边际贡献不足」 | 证据矩阵主张须有显式贡献句 |
| 方法匹配度 | 「方法与问题不匹配」 | research-design 阶段门控 |
| 文献时效性 | 「文献过时 / 遗漏关键近作」 | literature-review 补检 + 新颖性门控 |
| 样本与普适性 | 「样本单薄 / 外部效度不足」 | data-analysis 稳健性矩阵 |
| 写作规范 | 「格式不符本刊要求」 | 期刊 Author Guidelines 格式门禁 |
| 伦理与声明 | 「伦理审查 / 利益冲突缺失」 | ethics_guide.md 闸门 |

> 上表为**学科中立**的通用维度，适用于 OBHRM 及相邻管理子领域；下列逐刊点在其基础上按各刊取向细化。

## 逐刊退稿点（按学科标注 · OBHRM 领域）

### 国际 SSCI / ABS（组织行为与人力资源管理）

#### Academy of Management Journal (AMJ) — 适用学科：OB（组织行为）/ OBHRM
- **理论贡献不强**：未回答「so what? / why now?」；仅复现已知关系而非拓展/修正理论。
- **增量性不足**：与已有文献的边际贡献模糊，被评「incremental」。
- **方法缺陷**：内生性 / 因果识别弱、共同方法偏差（CMV）未处理、横截单时点数据。
- **样本代表性**：便利样本、响应率低、外部效度受质疑。
- **实践意义薄弱**：缺乏 managerial relevance 论述。

#### Journal of Applied Psychology (JAP) — 适用学科：OB / HR
- **理论贡献不清晰**：关系罗列多于理论推进。
- **实践 / 社会意义不足**：JAP 强调 applied significance，纯学术趣味易被拒。
- **测量问题**：构念效度不足、CMV 未控、量表适配性差。
- **统计功效不足 / 过度拟合**：样本量小、模型过复杂。
- **机制论证弱**：mediator / moderator 假设缺乏充分理论与检验。

#### Journal of Management (JOM) — 适用学科：OBHRM（管理综合）
- **边际贡献不足**：与 AMJ 同强调 big / tight theory。
- **元分析类**：纳入标准不严、异质性未处理、出版偏倚未检。
- **理论整合松散**：多理论拼凑、缺乏统一逻辑链。

#### Personnel Psychology — 适用学科：HR（人力资源）
- **贡献边际性**：与已有 HR 研究重合度高。
- **理论贡献模糊**：描述性发现多于机制解释。
- **测量 / 方法瑕疵**：量表、实验操纵效度问题。

#### Human Relations — 适用学科：OBHRM（批判 / 阐释取向）
- **缺乏批判性 / 反思性视角**：纯实证 positivist 取向偏窄，缺政治 / 社会意涵。
- **实践相关性不足**：与管理实践脱节。
- **理论贡献与社会意涵弱**：未触及权力 / 不平等 / 制度语境。

#### Journal of Organizational Behavior (JOB) — 适用学科：OB（组织行为）
- **构念测量差**：量表效度、同源偏差。
- **横截局限**：因果推断弱、时滞设计缺失。
- **理论贡献弱**：变量关系无理论增量。

#### The Leadership Quarterly (LQ) — 适用学科：OB（领导力）
- **领导力理论贡献弱**：领导概念化不清、与已有领导理论重叠。
- **测量 / 共同方法偏差**。
- **样本偏差**：单一受访者、单一组织。

#### Academy of Management Review (AMR) — 适用学科：理论
- **非理论型文章**：AMR 只发 conceptual，实证 / 综述直接 desk-reject。
- **概念贡献模糊**：命题缺乏新意或不可检验。
- **命题不可操作**：未给出可证伪 / 可检验的命题链。

### 中文 CSSCI 管理 / OB 期刊

#### 管理世界 — 适用学科：通用／OBHRM
- **中国问题意识不足**：缺"真问题"、政策 / 实践关联弱。
- **理论贡献模糊**：描述性多于理论推进。
- **方法不规范**：识别策略、稳健性不足。

#### 南开管理评论 — 适用学科：OBHRM（管理综合）
- **理论贡献不清晰**：边际贡献表述弱。
- **方法缺陷**：内生性 / 测量问题。
- **文献时效性**：遗漏关键近作。

#### 管理科学学报 — 适用学科：通用（管理科学）
- **方法 / 模型严谨性**：推导 / 识别不足。
- **贡献边际**：与已有模型重合。

#### 心理学报 — 适用学科：OB（组织行为 / 心理）
- **实验设计 / 测量严谨**：操纵效度、信效度。
- **理论贡献**：机制解释不足。
- **重复性**：小样本、未预注册。

#### 外国经济与管理 — 适用学科：OBHRM（管理综合）
- **文献时效性**：缺最新文献。
- **理论贡献**：概念推进弱。

#### 中国人力资源开发 — 适用学科：HR（人力资源）
- **实践导向不足**：纯理论缺落地。
- **理论支撑弱**：论证松散。

> 中文刊逐刊点依各刊《投稿须知》与近年发文取向整理，须以当年官方说明为准核对。

## 红线

- 退稿点清单为**写作自检参考**，**不得当作本刊官方承诺**；尤其经济学刊（标签 `经济学`）的维度**不**套用于 OBHRM 投稿。
- 加载清单时记录来源与版本（如「本文件 v1 @ <date> / 上游 Awesome-Journal-Skills」），保证可溯源。
- 英文刊（SSCI / ABS）退稿点以期刊 *Guide for Authors* + 该刊近年 *Editorial* 为准，不套用中文刊维度；本文件逐刊点标注 `适用学科` 即为此边界。
- 每条逐刊点须带 `适用学科` 标签；未标注者视为 `通用`，不得断言为某刊专属。
