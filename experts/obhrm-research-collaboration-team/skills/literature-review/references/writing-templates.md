# 文献综述写作模板与常用语

> 基于《文献综述如何写？（万能模板+常用语）》和《文献综述写作指南：实践篇》
> 结构化数据（万能模板分节、结构框架、双语模板）见 `../knowledge/templates.json`。
> 本文的示例句与常用语均以"批判性、有理论张力、显式论证"为取向，避免公式化套话。

---

## 一、文献综述万能模板

### 整体结构

```
一、研究背景（200-300字）
二、研究现状（主体）
    第一步：概括
    第二步：分析
    第三步：整合回顾
三、结论（述评）（200-300字）
四、参考文献
```

常见框架变体主要有三种：框架一为"研究背景 → 研究现状 → 评述 → 参考文献"；框架二为"前言 → 研究现状及主要观点 → 目前研究中的不足 → 参考文献"；框架三为"目前研究的主要方向和观点 → 目前研究中的不足 → 参考文献"。选择哪种取决于综述是偏重"背景铺垫"还是"不足引出"。

---

## 二、各部分详细模板

### 1. 研究背景

目的：说明撰写本综述的原因、目的、意义、学术背景、目前状况、争论焦点、收集资料范围。要求简明扼要、重点突出、200-300 字。

**句式模板（张力导入式）**：
> 近年来，××× 已从边缘议题上升为 [领域] 的核心关切。然而，现有研究在概念边界上仍存在 [混用 / 分歧]，在经验结论上呈现 [分化 / 矛盾]，尚未回答 [关键理论问题]。因此，本文聚焦：××× 如何通过 [机制] 影响 [对象]？其作用边界又由哪些条件所界定？

**句式模板（缺口驱动式）**：
> 尽管学界已就 ××× 积累了一定实证证据，但多数研究停留在描述层面，未能解释"为何同一实践在不同边界条件下产生相反结果"。基于 [理论视角]，本文主张将 ××× 重新概念化为 [构念]，并据此整合分散的发现，识别其"前因—机制—结果"链条中的研究缺口。

写作要素清单：撰写原因、研究目的、研究意义（理论+实践）、学术背景、目前状况、争论焦点、收集资料范围。

### 2. 研究现状（主体）

**第一步：概括**——对所选文献的研究重点、研究手段及研究结论先进行概括。常用语如"现有关于 ××× 的研究已沿 [维度 A / 维度 B / 维度 C] 三条线索展开……""围绕 ×××，学界形成了 [视角一] 与 [视角二] 两类竞争性解释"。

**第二步：分析**——对文献进行分析，提炼贡献、影响、优点与不足。格式为"作者 + 年份 + 文章题目 + 观点 + 自己理解"。分析常用语包括：肯定贡献（"×× 的研究为理解 ××× 提供了 [构念 / 机制] 层面的关键视角"）；指出不足（"然而，该研究在 [边界条件 / 测量层级] 方面存在局限，使其结论的普适性存疑"）；比较差异（"与 ×× 的单向负面叙事不同，×× 揭示了 ××× 的赋能面向"）；补充拓展（"在此基础上，×× 进一步将 [变量] 纳入分析，拓展了原有的解释链条"）；质疑反思（"但该结论是否适用于 [非零工 / 传统组织] 情境，仍有待验证"）。分析维度涵盖研究方法适切性、理论基础充分性、研究设计合理性、结论可靠性与普遍性、与其他研究的一致性/矛盾性。

**第三步：整合回顾**——找出现阶段研究方法/方向存在的不足，提出改进方向。整合常用语如"尽管已有研究在 ××× 方面取得了进展，但其理论增量仍受限于 [视角碎片化 / 边界条件缺位]……""现有研究的主要缺口在于：……""未来研究可从 [构念重构 / 机制解密 / 边界拓展] 三个层次深入探讨……"。

### 3. 结论（述评）

目的：对前面论述总结，提出取舍褒贬，指出存在问题及解决方法，提出预测及今后发展方向。要求突出重点、结束整篇、200-300 字。

**句式模板（理论增量式）**：
> (1) 综合来看，××× 领域虽已形成若干共识，但其理论贡献仍显不足——多数研究停留在 [构念澄清 / 机制描述] 层面，对 [范式重构] 层次的推进有限。这一局限源于 [理论视角分散] 与 [情境单一] 的结构性约束（言简意赅地总体评价，要提纲挈领）。
> (2) 除 [机制尚未厘清] 这一根本约束外，现有综述还面临 [测量不一致 / 跨情境证据薄弱] 等短板，未来研究应优先在 [方向] 上取得突破。

述评常用语："综上所述，××× 领域的研究已从描述性积累转向机制性追问，但其在 [边界条件 / 跨情境适用性] 上仍有待深化""总体来看，××× 研究呈现从 [单一负面叙事] 向 [双刃剑 / 二元性] 视角迁移的趋势，未来应重点厘清 [构念层级与情境适配]"。

### 4. 参考文献

要求详细列举并注明篇目、著者、出处，准确无误且有典范性，不宜过多。文献类型包括专著[M]、期刊[J]、学位论文[D]、专利[P]、科技报告[R]、标准[S]、报纸文章[N]，各自有规范的著录格式（专著需出版地/出版者/出版年，期刊需卷期与起止页码等）。

## 三、综述主体部分的组织方式

- **方式一：按问题史综述**——主题的提出及历史阶段发展 → 国内外研究现状（国内/国外） → 不同学者观点分析 → 作者本人的认识和展望性意见。
- **方式二：按横向关系综述**——各方观点描述 → 各种方法比较 → 各自发展方向分析 → 优劣利弊评价 → 融合思想与借鉴启示。
- **方式三：比较综述**——全面系统认识某一专题 → 比较不同研究路径 → 作出取向预测 → 为新的研究工作选择突破口或参考依据。
- **方式四：以理论带动**——理论框架阐述 → 基于理论的文献梳理 → 理论视角下的整合分析 → 比较可靠的取向预测。

## 四、写作注意事项

### 必须做到

70% 以上的文献是近 3-5 年的；用逻辑串联文献（时间或主题顺序），避免堆砌；中西合璧（中文与优质英文文献都需阐述）；找相关性高的文献；找高水平文献（核心/EI/SCI）；使用自己的语言表述原文思想；围绕科学问题论述；先分析后结论；以问题为线索编排文献。

### 必须避免

切忌文献堆砌（"A做了X，B做了Y"式罗列）；切忌以作者为线索罗列；切忌使用作者原话（除非不这样无法表述）；切忌把每篇文献视为同等重要；切忌利用另一篇文献综述中的内容（应查原始文献）；切忌在简单罗列几个实证结果后就提假设；切忌教科书式写法（以时间顺序为线索）；切忌一上来就给结论。

### 概念介绍方法

不要以时间顺序为线索，而应基于概念的不同定义进行分析，追问定义是什么、划分出发点是什么、不同思路的合理性/不合理性、以及这些划分对之后研究的借鉴意义。

## 五、文献阅读与分类标准

分类标准可按学科领域（跨学科研究）、按学术观点/流派（理论争议较大）、按历史发展阶段（成熟主题系统梳理）、按研究方法（方法论对比）、按研究层次（个体/团队/组织）划分。

阅读顺序建议：
```
第一步：中文综述文章（快速了解课题全貌）
    ↓ （如果没有中文综述）
第二步：中文博士论文（了解定义、测量、分类、理论机制）
    ↓
第三步：英文综述文章（把握专有名词含义，准确理解国外作者观点）
    ↓
第四步：英文期刊文献（深入研究前沿进展）
```

每篇文献需记录：研究问题、研究目标、研究方法、研究结果、主要结论、存在的问题/不足、与你研究主题的关联、可用于综述的哪个部分。

## 六、文献评估要点

评估维度包括：作者论点（核心论点与阐释）、研究重要性、研究目标、研究方法（是否适切）、问题匹配度、论据核实、观点一致性、参考文献相关性、个人收获、研究评价、关联性、最新进展。

论证类型分两种：发现式论证（讨论并解释有关研究对象的已有知识，呈现与研究兴趣相关的现有知识）；支持式论证（以发现式论证为基础，对资料整合获得的知识进行分析和评论，解决研究问题，结果是论文的主题陈述）。

---

## 七、常见问题与解决方案

- 综述写成"流水账" → 按主题/流派/方法路径聚类，而非按时间罗列。
- 文献太多看不过来 → 制定纳排标准，先立边界。
- 找不到研究缺口 → 批判地精读，找矛盾观点。
- 综述与论文框架脱节 → 使用理论框架挂载审计。
- 引用查不到出处 → 采用引证完整性核查逐条核查。
- 被审稿人说"太罗列" → 注入批判性分析，发现张力。
- 术语不统一 → 术语标准化审计。
- 夸大研究贡献 → 客观语调过滤。
