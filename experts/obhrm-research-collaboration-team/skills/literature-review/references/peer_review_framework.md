# 同行评审与自审框架

> 同行评审与自审框架，结合本技能 `skills/obhrm-methodology/references/review/review_criteria.md` 与领域通用的投稿前自审、偏倚检测方法论综合整理。

---

## 一、投稿前自审工作流程

### 阶段1：初步评估

**关键问题：**
- 综述的核心研究问题或主题是什么？
- 主要发现和理论贡献是什么？
- 综述是否科学合理且有意义？
- 是否适合目标期刊？
- 是否存在明显的重大缺陷？

**输出**：2-3 句话的简要总结。

### 阶段2：逐节详细审查

#### 摘要与标题
- 摘要是否准确反映综述内容和结论？
- 标题是否具体、准确、信息丰富？

#### 引言
- 背景信息是否充分且最新？
- 研究问题是否有明确的动机和理由？
- 相关先前研究是否被适当引用？
- 文献链是否闭环（已有→推进→缺口→本研究）？

#### 主体
- 文献是否按主题而非时间罗列？
- 每段是否综合了多项研究而非逐篇介绍？
- 批判性分析是否充分（贡献与局限并重）？
- 不同研究间的关系是否指出（支持/补充/矛盾）？

#### 讨论与结论
- 结论是否有文献支撑？
- 研究局限性是否被承认和讨论？
- 未来研究方向是否具体且可操作？
- 推测是否与文献支撑的结论明确区分？

## 二、偏倚检测框架

| 偏倚类型 | 检查要点 | 综述中的常见表现 |
|----------|----------|-----------------|
| 确认偏倚 | 是否只强调支持性发现？ | 只引用支持自己观点的文献，忽略反面证据 |
| 选择偏倚 | 文献样本是否代表该领域？ | 只选近五年文献，忽略经典奠基研究 |
| 发表偏倚 | 是否缺少阴性结果？ | 只引用发现显著关系的文献 |
| 语言偏倚 | 是否只引用英文文献？ | 忽略中文核心期刊的重要发现 |
| 搜索偏倚 | 检索策略是否全面？ | 只用一个数据库，遗漏重要来源 |
| 引用偏倚 | 是否过度自引或圈子互引？ | 某个团队文献占比过高 |

## 三、逻辑谬误识别

| 谬误类型 | 表现 | 综述中的例子 |
|----------|------|-------------|
| 事后归因 | "B跟在A后面，所以A导致了B" | 理论提出在先，后续研究支持，就断言理论正确 |
| 相关=因果 | 混淆关联与因果 | 两变量相关就声称有因果关系 |
| 草率泛化 | 从小样本得出广泛结论 | 基于3-4篇研究就声称"学界普遍认为" |
| 挑选数据 | 只选择支持性证据 | 综述只讨论支持假设的文献，不提矛盾发现 |
| 诉诸权威 | 因为某大牛说了所以对 | 引用权威观点但不检验其证据基础 |
| 虚假二分 | 非此即彼 | 将不同理论框架对立起来，忽略整合可能 |

## 四、自审提示词模板

### 投稿前全面自审

```markdown
# 角色
你是一位严苛的资深学术审稿人，专注于 OBHRM 领域的综述文章评审。

# 任务
请深入阅读并分析我的综述，撰写严厉但建设性的审稿报告。

# 审查维度
1. 理论增量：综述是否推进了理论？（构念重构/机制解密/边界拓展）
2. 文献覆盖：是否遗漏了重要文献？检索策略是否系统？
3. 批判性分析：是综合而非罗列？每段是否比较了多项研究？
4. 结构完整：是否覆盖研究动机/定位/问题/框架/边界五要素？
5. 论证连接：文献链是否闭环？有无孤岛段落？
6. 语言质量：是否有AI痕迹？是否自然流畅？

# 输出
- Part 1 [审稿报告]：Summary, Strengths, Weaknesses, Rating
- Part 2 [战略建议]：具体改进建议（优先级排序）

# 输入
投稿目标：[期刊名]
综述内容：[粘贴]
```

### 快速质量检查

```markdown
# 任务
快速检查综述是否存在以下问题：

1. 理论增量：是否有明确的理论贡献声明？
2. 文献覆盖：核心文献是否遗漏？是否有 evidence-claim map？
3. 结构一致：引言的问题是否在结论中得到回应？
4. 术语一致：核心概念是否保持一致命名？
5. 论证支撑：所有结论是否有文献支撑？
6. 去AI化：是否有机械过渡词或空壳强调句？

# 输出
- 无问题：[检测通过]
- 有问题：分点列出位置和具体问题
```

## 五、审稿语气规范

### 最佳实践

- 建设性：将批评框架为改进机会
- 具体：提供具体例子和可操作建议
- 平衡：承认优点和缺点
- 尊重：记住作者投入了大量努力
- 客观：关注科学，而非科学家

### 避免事项

- 人身攻击或轻蔑语言
- 没有具体例子的模糊批评
- 要求超出范围的不必要工作
- 过度苛刻或过度宽容
