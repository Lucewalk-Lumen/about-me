# compare-research-methods — 方法对比

方法不是摆设，是你论证的一部分。方法选择不是格式要求，是论证环节——为什么是它、不是它、它解决什么、它解决不了什么。

## 适用场景

- 写文献综述里的"研究方法评述"。
- 写自己论文的方法论设计。
- 判断混合研究方法（先问卷还是先访谈）。

## 输入

```
研究问题：[在此粘贴你的研究问题]
（可选）候选方法：[问卷/访谈/实验/面板数据/日志……]
```

## 执行步骤

1. **拉三列表**：对每个候选方法列出「方法 | 能回答什么 | 回答不了什么」。
2. **选型论证**：基于研究问题判断——需要看过程还是看相关性？要宽度还是深度？相关性还是因果机制？
3. **混合方法排序**：
   - 还不知道具体环节 → 先访谈，再设计问卷。
   - 已有成熟变量，想解释机制 → 先问卷，再访谈。
4. **写盲区句**：每种方法后面补一句"它看不见什么"。

## 输出

- 方法对比表（方法 | 能回答什么 | 回答不了什么）
- 方法选择论证链（为什么选它、不选什么、它的盲区）

## 调用示例

```
请使用「方法对比」微技能，帮我比较哪些研究方法适合回答下面这个问题，并说明每种方法能回答什么、回答不了什么：
AI 写作工具如何影响研究生论文构思阶段的独立判断？

（混合方法判断）
我想做混合研究，但不确定是先问卷后访谈，还是先访谈后问卷。请用「方法对比」微技能帮我比较。
```

## 避坑提示

- "本研究采用问卷调查法和访谈法"——这句话不是短，是没说服力。
- 最能体现成熟度的写法：问卷能够呈现 X 与 Y 的统计关系，但难以揭示学生在具体情境中如何判断哪些建议可以接受、哪些需要拒绝。
