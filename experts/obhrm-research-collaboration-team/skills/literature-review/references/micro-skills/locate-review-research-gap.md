# locate-review-research-gap — 空白定位

别把"研究展望"写成客套话。"未来研究可进一步扩大样本，丰富研究方法，从多维度展开探讨"——写了等于没写。

## 适用场景

- 综述收尾、写研究展望时（完成问题锚定→模块拆解→方法对比→矛盾梳理之后）。
- 需要判断自己的 gap 是否站得住。

## 输入

```
综述综合判断：[粘贴你的综述结论/判断/展望段]
```

## 执行步骤（四问校验）

1. 前人做到哪了？（用一句话把共识和矛盾说清楚）
2. 哪一步卡住了？（理论框架缺了？方法局限？数据覆盖不到？）
3. 你准备从哪个口子切？（具体到某个模块、某个机制、某个变量关系）
4. 为什么这个口子值得切？（填空白还是解矛盾？做了之后对领域有什么推进？）

## 输出

- 具体可执行的研究 gap 陈述
- 四问逐项校验结果（缺哪一环，如何补）

## 调用示例

```
请使用「空白定位」微技能，把下面这段综述综合改成一个具体、可执行的研究空白：
AI 写作工具能提升文本生成效率，但对论文构思、论证判断、原创表达的影响仍不清楚；现有研究多用问卷，较少观察真实写作过程。

（校验模式）
请用「空白定位」微技能检查下面这段研究展望是否回答了四个问题。如果没有，请指出缺哪一环，并改写得更具体。
```

## 避坑提示

- 不要用"没人研究过/研究较少"当主要理由。真正的 gap 是"解释还没到位"：
  - 前人看到了相关关系，但没解释机制。
  - 前人讨论了短期效果，但没处理长期变化。
  - 前人关注结果变量，但忽略了过程变量。
  - 前人在某类样本中得出结论，但边界条件还没验证。
  - 前人发现了矛盾，但没有解释矛盾为什么出现。
