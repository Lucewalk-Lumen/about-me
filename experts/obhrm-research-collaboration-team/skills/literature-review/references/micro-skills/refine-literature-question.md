# refine-literature-question — 问题打磨

把"主题"变成"问题锚"。主题让人散着读，问题逼人盯着一个点读。

## 适用场景

- 开题前、正式文献检索前，手上只有一个模糊方向（如"数字素养与大学生学习效果"）。
- 已有研究问题但太宽泛、没有张力（如"人工智能工具如何影响研究生学术写作能力？"）。
- 文献越读越散，需要回到问题重新锚定。

## 输入

```
宽泛主题：[在此粘贴你的主题或研究方向]
（可选）限制条件：[学科、样本、时间范围等]
```

## 执行步骤

1. **发散**：生成 8-10 个不同角度的问题版本，要求每个问题都包含具体的"为什么/什么机制"。
2. **收缩**：在第二轮只保留 3 个最能"逼你做选择"的问题。
3. **三条判断标准**（都过才算问题立住）：
   - 这个问题能不能让我少读一批文献？
   - 这个问题能不能自然拆出 3-5 个综述小节？
   - 如果有人回答了它，我会不会觉得这篇综述有价值？

## 输出

- 问题锚候选清单（含每版的筛选标准说明）
- 推荐的问题锚（1-3 个），标注每个问题的文献筛选含义

## 调用示例

```
请使用「问题打磨」微技能，帮我把下面这个宽泛主题改成 8 个可用于文献综述的研究问题：
数字素养与大学生学习效果

（第二轮）这个问题还是太泛。请把它改成 5 个更具体的机制型问题，每个问题都要能排除一部分无关文献。
```

## 避坑提示

- 别急着选第一个顺眼的问题，最好连用两轮（发散→收缩）。
- 好的问题带条件（"不同学术训练阶段的研究生"），文献筛选更有边界。
- 写不出问题就别搜文献——搜了也是白搜。
