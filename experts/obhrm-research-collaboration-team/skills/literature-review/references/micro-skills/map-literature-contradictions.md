# map-literature-contradictions — 矛盾梳理

文献打架时，别急着和稀泥。矛盾不是麻烦，矛盾往往是入口。每一处分歧背后都藏着一个值得深挖的问题。

## 适用场景

- 不同研究结论不一致（有人说 AI 提效，有人说 AI 削弱原创能力）。
- 需要把几十篇摘要的差异拎出来（人眼容易混）。
- 写综述时想把"尚未形成一致结论"升级为有信息量的判断。

## 输入

```
冲突的研究发现：[列出 A 类/B 类/C 类研究发现]
（可选）文献摘要或笔记：[供差异维度提取]
```

## 执行步骤（梳子法）

1. **找共识**：列出不同研究、不同地区、不同方法反复验证过的结论（可踩的地基）。
2. **拆矛盾**：判断分歧可能来自——研究对象不同、样本不同、指标体系不同、时间窗口不同、工具使用方式不同。
3. **标边界**：区分"我的知识漏洞"与"前人的方法局限"；方法局限外就是贡献空间。

## 输出

- 差异维度表（按样本/方法/指标/时间窗口/主要结论整理）
- 分歧归因分析（矛盾 → 有信息量的判断）

## 调用示例

```
请使用「矛盾梳理」微技能，帮我分析下面几类相互冲突的研究发现，并判断分歧可能来自哪里：
A 类研究认为 AI 写作工具提升写作效率；B 类研究认为它削弱原创表达；C 类研究认为影响取决于学生原有写作水平。

（差异维度表模式）
请用「矛盾梳理」微技能把这些论文按样本、方法、指标、时间窗口和主要结论整理成表，并指出可能导致结论不同的原因。
```

## 避坑提示

- Skill 能告诉你"哪里不一样"，不能替你判断"这个不一样为什么重要"——后者是你自己的判断。
- 把矛盾写成"条件"而非"混乱"：少写"尚未形成一致结论"，多写"以效率为指标的研究更容易得出正向结论，关注原创性和论证质量的研究则更谨慎——说明 AI 写作工具的作用可能具有明显的任务边界"。
