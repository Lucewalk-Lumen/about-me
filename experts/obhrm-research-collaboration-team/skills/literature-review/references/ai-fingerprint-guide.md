## 一、禁用表达完整表

### 1.1 机械过渡词（禁滥堆，非禁存在）

> **重要口径**：学术综述需要逻辑连接词支撑论证，连接词本身不是AI味的来源——**无脑堆砌**才是。以下词在"真实逻辑关系 + 节制使用"前提下允许；以下情形一律禁止：每段开头套用、全文出现两次以上的 `首先…其次…最后`、每个子节末尾都 `综上所述`。推荐用法见 `../knowledge/writing_style_notes.md` 第二节。

| 类型 | 词/句 | 禁止情形 | 允许情形 |
|------|-------|----------|----------|
| 顺序过渡 | 首先、其次、最后、再次、接着、然后 | 每段套用、凑结构堆砌、无真实递进 | 确有三段并列递进，全文限用一次 |
| 补充过渡 | 此外、另外、除此之外、与此同时 | 连续多段开头重复 | 真实补充关系，克制使用 |
| 总结过渡 | 总之、综上所述、概括来说、简而言之 | 每个子节末尾都用 | 仅全文总结段用一次 |
| 时间过渡 | 接下来、随后、在此之后 | 用于逻辑（非时序）衔接 | 确为时间/流程顺序时 |

### 1.2 空壳强调句（全部禁用）

| 类型 | 禁用句式 | 替代方案 |
|------|----------|----------|
| 空壳强调 | 值得注意的是、需要指出的是 | 直接陈述事实 |
| 空壳强调 | 重要的是、必须强调的是 | 删除前缀，直接说 |
| 空壳强调 | 显而易见、不言而喻 | 用数据/引用支撑 |
| 空壳强调 | 众所周知 | 引用具体来源 |

### 1.3 空洞修饰词（无数据支撑时禁用）

| 禁用词 | 条件 |
|--------|------|
| 非常、极其、十分、相当 | 无数据支撑时禁用 |
| 显著、明显 | 无统计检验支撑时禁用 |
| 大量、许多 | 无具体数量时禁用 |
| 关键、核心 | 无论证支撑时禁用 |

### 1.4 主观引导句（正文禁用）

| 禁用句式 | 场景 |
|----------|------|
| 我认为、我觉得、我个人看法是 | 论文正文 |
| 我们可以看到 | 改为"表X显示""图N表明" |
| 不难发现 | 删除，直接陈述 |

## 二、症状-处理对照表

| 症状 | 处理方式 |
|------|----------|
| 句式像英文直译 | 改为中文常用语序：先说明对象和现象，再给判断 |
| 段落过度模板化 | 取消固定的"背景-方法-结果-意义"节奏，保留解释句和承接句 |
| 改写后信息变少 | 补回研究对象、数据范围、方法条件、指标口径和结论边界 |
| 审稿回复口吻 | 将"该指标反映的是""不能理解为"改为正文叙述，如"本文将...作为参照" |
| 空泛拔高 | 用具体指标、现象或限定替代"显著""关键""重要意义"等泛化词 |
| 等长句连续 | 长短句交替，打破节奏单一性 |
| 列表堆砌观点 | 转为连贯段落，补足主语、谓语和连接成分 |

## 三、中文期刊综述的自然行文原则

中文期刊综述不追求每句话都极度精简。更自然的写法通常是先交代研究对象、资料范围或问题背景，再说明处理方法、结果现象和判断边界。句子可以略长，段落中可以有必要的承接、限定和少量重复，只要主语明确、关系清楚、读者能够顺着研究过程理解即可。

去AI化的重点是减少模板化、翻译腔、过度概括和空泛拔高，而不是删除所有修饰语。能够说明对象、时间范围、样本口径、方法条件、指标含义、实验边界和因果关系的成分应当保留。不要把段落改成机械的"背景-方法-结果-意义"句组，也不要让每句话都呈现"对象-动作-结论"的功能句。

当用户反馈"太AI""太精简""像翻译"时，按以下顺序处理：
1. 先检查是否存在过度压缩、英文语序、模板化总结、审稿回复式表达或空泛拔高
2. 补回必要信息（研究对象、数据范围、方法条件、指标口径、结论边界）
3. 调整为中文自然语序
4. 收束过强判断
5. 不要继续简单删词

## 四、列表转段落规则

### 错误写法

```
本研究贡献如下：
- 提出新框架
- 整合已有研究
- 验证有效性
```

### 推荐写法

```
本研究在已有文献基础上提出了一种新的分析框架，将分散的研究成果整合为连贯的理论脉络。
通过对 42 篇实证研究的系统梳理，该框架在变革型领导与员工创造力的关系上展示了较好的解释力。
```

## 五、三轮质量检查

### 第一轮：结构检查

- [ ] 是否存在正文列表化（列表仅用于计划/检查清单/参数配置/操作步骤）
- [ ] 段落是否围绕单一中心
- [ ] 章节逻辑是否连续
- [ ] 是否把正文写成机械的"背景-方法-结果-意义"模板段

### 第二轮：语言检查

- [ ] 是否出现禁用过渡词
- [ ] 是否出现禁用强调句式
- [ ] 是否存在无信息量形容词堆积
- [ ] 是否出现主观化表述
- [ ] 是否存在翻译腔、英文语序或审稿回复式表达
- [ ] 是否因过度压缩丢失研究对象、数据范围、方法条件、指标口径或结论边界
- [ ] 是否用具体数据和现象支撑"提升""有效""稳定"等判断

### 第三轮：排版检查

- [ ] 是否有无意义加粗
- [ ] 段间是否统一空一行
- [ ] 标点与中英文空格是否一致
- [ ] 正文段落优先连续叙述，不用项目符号堆叠观点

## 六、AI 指纹自检维度

> 本节定义「AI 指纹检测」的可判定信号，供成稿终审（对应 closed_loop.json 中 PH3 术语标准化与客观语调过滤两项的终审子项）复核使用。AI 指纹指机器生成文本在统计与结构层面留下的规律性痕迹，可通过下列 4 个信号在无外部工具时人工判定。

AI 指纹检测关注文本的**统计规律性**而非用词对错——即便用词都合规，若句长与结构过度均匀，仍会露出机器痕迹。逐段扫描以下 4 个信号，任一命中即标注疑似并回改。

### 6.1 burstiness 低（句长方差小）

- **含义**：人类写作句长起伏大（长句夹短句），AI 文本句长趋于集中，方差偏低。
- **自查问句**：本段句子长度是否缺乏明显的长短起伏，读起来"匀速"？
- **阈值直觉**：连续 5 句句长差 < 3 字 = 疑似均匀，需插入短句或合并长句打破节奏。

### 6.2 句长均匀

- **含义**：相邻句子字数高度接近，段落呈现"等长句连续"（与二、症状-处理对照表中"等长句连续"呼应）。
- **自查问句**：本段是否连续出现多句字数几乎相同的句子？
- **阈值直觉**：一段内 ≥3 句字数落在同一 ±2 字区间 = 疑似均匀，应主动制造长短交替。

### 6.3 对称结构

- **含义**：段落或句群呈机械镜像（如每段都"先定义—再举例—后小结"，或排比式三句一组），缺乏自然的不规则推进。
- **自查问句**：相邻段落的内部结构是否高度雷同、可一一对应？
- **阈值直觉**：连续 ≥3 段套用同一"起承转合"骨架 = 对称过强，需打散固定节奏。

### 6.4 标志性短语

- **含义**：出现 AI 高频套语（与一、禁用表达完整表重叠，如"值得注意的是""综上所述""在...方面发挥着重要作用"）。
- **自查问句**：本段是否出现一、表中已列的机械过渡词、空壳强调句或空泛拔高词？
- **阈值直觉**：单段命中 ≥2 处标志性短语 = 指纹明显，逐条替换为直接陈述。

## 七、AI 指纹修复执行协议

> 第六节负责**诊断**——判定某段文字是否留有机器指纹；本节负责**修复**——检出之后如何定向改到过关。两节合起来构成"诊断（六）→修复（七）"的闭环。本节聚焦"检出 AI 指纹后如何局部改写"，与第一节禁用表（词句黑名单）、第五节三轮质量检查（通用质检）分工不同：**第五节是面向全文的通用质检，第七节是针对已检出指纹的专项修复**，需要时交叉引用而非重复照抄。

### 7.1 三条铁律

修复动手前先立三条铁律，任何一条破了都会前功尽弃：

1. **禁止用 AI 全量重写**。拿 AI 去重写一段本就由 AI 生成的文本，只会在原有机器指纹上再**叠加**一层新指纹——实测整段丢给模型重生成后，检测率不降反升，接近 100%。所有修复必须是对原文的**局部定向改写**，绝不是把整段交给模型重新生成。

2. **改动率必须 > 40%**。把"改没改够"从主观直觉变成一条量化验收线。轻度改动（约 40%）通常能把检出率压到 60-80%；改动率越高、下降越明显。若一轮改完自评改动率不足 40%，继续补充操作，不要停手。（说明：这里的改动率指相对原文发生实质改动的字符/词占比的粗略估计，供人工自评把握力度，不是精确计算，也不必逐字统计。）

3. **确定性局部替换，而非重写**。每一次只动一小处——换词序、拆句或合句、增删限定成分、调整标点节奏——保留原文大部分内容不变，改到哪里心里有数、可复现，而不是把文字整体推倒。同时确保相邻段落的句式结构、开头方式和句长不彼此雷同。**并且必须保持学术语体（register）**：去 AI 的力会天然把文本往口语化方向推，这一点要主动约束——修复后若冒出网络用语、情绪词或口语表达，就算骗过了机器检测，也过不了人审。

### 7.2 诊断信号 → 修复手法对照表

第六节四个信号逐一对应到确定性修复手法，检出哪个就用哪一行：

| 诊断信号（见第六节） | 确定性修复手法 |
|----------------------|----------------|
| burstiness 低 / 句长均匀 | 主动制造长短句交替：把一个长句拆成"长句+短句"，或把两个等长句合并为一长句；再插入一个 5-10 字的短句打破匀速节奏。 |
| 对称结构 | 打散固定的"起承转合／先定义再举例后小结"骨架；让相邻段落采用不同的推进顺序——有的先给判断再补证据，有的反过来先摆证据再收判断。 |
| 标志性短语 | 逐条替换为直接陈述（对照第一节禁用表）：如"值得注意的是 X"直接说成"X"，删去空壳前缀。 |
| （补充）翻译腔 / 等长机械句 | 改回中文自然语序：先交代研究对象与背景，再给方法、结果和边界，呼应第二节症状-处理对照表与第三节自然行文原则。 |

### 7.3 三轮修复协议

单轮往往收不干净，分三轮迭代，每轮只盯一个目标，逐轮收敛：

- **第一轮 · 破节奏**：集中处理 burstiness 低与句长均匀，长短句交替，先把最刺眼的"匀速感"消掉。这一轮不碰用词，只调句子长短与切分。
- **第二轮 · 去套语与对称**：清理标志性短语、打散对称骨架，把套语替换为直接陈述（对照第一节禁用表），让相邻段落的推进顺序错开。
- **第三轮 · 保语体与保真**：回读全段，确认没有滑向口语化（无网络用语、情绪词、口语表达），也没有在前两轮改写中丢失研究对象、数据范围、方法条件、指标口径或结论边界——一旦发现信息变少就补回（呼应第二节"改写后信息变少→补回"与第五节第二轮语言检查）。最后自评改动率，确认已 > 40%；不足则回到前两轮继续补动作。

### 7.4 结语

本协议全程纯人工／离线执行：判定信号靠眼看，改写靠手动局部替换，改动率靠人工自评，不调用任何外部检测服务、不联网、不依赖第三方工具，与本技能"零运行时外部依赖"的原则一致。
