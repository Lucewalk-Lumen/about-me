# OBHRM 研究协作团（obhrm-research-collaboration-team）

面向组织行为学与人力资源管理（OBHRM）学术研究的多智能体协作专家团。
主理人统一编排，六位领域专员分工执行，共享同一套方法论知识库与质量闸门。

- 版本：**1.0.1**
- 类型：专家团（`expertType: team`）
- 类目：09-OperationsHR
- 运行入口：`settings.json` → `obhrm-research-collaboration-team-lead`

## 使用

在 WorkBuddy 中召唤本专家后直接提问，例如：

- 帮我梳理领导力研究的核心理论与成熟量表，按理论脉络归纳主要研究缺口。
- 我要写国家自然科学基金面上项目的申报书，研究主题是数字化转型对组织韧性的影响。
- 帮我用审稿人视角模拟审稿这篇稿子，给出八维诊断和修改意见。

本专家团以单会话内嵌协作运行：主理人按需装载六位成员的角色定义（各自独立的工作流程、门控与专业规范），以对应成员的身份逐步完成各专业产出，统一汇总交付；跨阶段信息经完整交接块传递，全程遵守引用保真与质量闸门。

## 安装与运行前校验

安装：在 WorkBuddy 专家中心导入本包，或导入 `obhrm-research-collaboration-team/` 目录后重启客户端。

Python 脚本以标准库为主：文献检索整理、引证核验、封闭闭环自检、前置检查与知识库查询等核心能力**仅依赖标准库**，开箱即用；另有少量脚本依赖可选的第三方库（图表渲染 / Word 导出 / PDF 摄取），对应环节缺失依赖时会打印明确的安装提示**并以退出码 1 终止**（不静默失败），核心能力不受影响，详见下方「可选依赖」。

导入本包后由客户端自动完成结构与版本校验，无需手动运行校验脚本。如导入后提示校验失败，请查看 `CHANGELOG.md` 与本文「已知限制」小节排查。

## 安全基线

- **无硬编码密钥**：包内不含任何 API Key、令牌或口令；运行期参数经环境变量（`OBHRM_*`）外置
- **最小权限**：命令执行限包内自带脚本、浏览器自动化限学术出版域白名单（敏感域禁入）、网络出访限学术源白名单、文件写入限用户工作区——上述边界以脚本内实现为准（如 `safe_path.py`、脚本内域名白名单），详见本文「运行范围」
- **输入校验**：所有输出路径经 `skills/obhrm-methodology/obhrm_research_base/core/safe_path.py` 越界校验
- **操作审计**：审计日志已补全——`skills/obhrm-methodology/obhrm_research_base/core/audit_log.py` 提供统一 `log_event` 接口（经 `OBHRM_LOG_DIR` 可配置落盘目录），已接入各脚本（`config_manager`、`obhrm_docx_formatter` 等调用 `log_event`），受限读取与文件写出留痕溯源，便于事后追溯，详见质量闸门 `trust_boundary`
- **依赖最小化与透明化**：Python 脚本以标准库为主；可选第三方依赖见上文「可选依赖」与 `DEPENDENCIES.md`，均已在 `requirements.lock` 中**钉死精确版本**；缺失时脚本打印明确安装提示并以退出码 1 终止，不静默失败

## 已知限制

1. **检索按全词匹配**：多词短语需全部词命中，建议优先使用单词或中文关键词，或用 `Sxxx` / `Txxx` 精确检索
2. **理论库不含组织公平专题条目**：含 Adams 公平理论（T133，分配公平视角），但无「组织公平 / 程序公平 / 互动公平」（organizational / procedural / interactional justice）专题条目
3. **跨库构念检索覆盖有限**：R 方法侧仅有类别级适用性，跨库场景建议分别检索三库后由主理人汇总
4. **浏览器采集依赖外部安装**：需先安装官方 BrowserSkill 技能
