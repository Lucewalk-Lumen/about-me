# 依赖透明声明（Dependencies）

本文件集中说明 obhrm-research-collaboration-team 的全部外部依赖。目标：**所有依赖显式、可追溯**，不隐藏、不静默失败。

## 1. Python 运行时依赖（第三方包）

包内少量脚本依赖下列第三方库，均在 `requirements.lock` 中**钉死精确版本**（全部存在于 PyPI、可复现）：

| 分组 | 包 | 版本 | 用途 | 缺失行为 |
|------|---|------|------|---------|
| 绘图/图表 | matplotlib | 3.9.2 | PRISMA 流程图、理论模型图、统计图表 | 打印安装提示，退出码 1 |
| 绘图/图表 | seaborn | 0.13.2 | 图表样式 | 同上 |
| 绘图/图表 | numpy | 2.1.3 | 数值数组 | 同上 |
| 绘图/图表 | scipy | 1.14.1 | 统计 / 回归 | 同上 |
| 文档/PDF | python-docx | 1.1.2 | Word(.docx) 导出 | 同上 |
| 文档/PDF | pypdf | 6.19.0 | PDF 摄取 | 同上 |
| 文档/PDF | pdfplumber | 0.11.10 | PDF 文本提取 | 同上 |
| 文档/PDF | Pillow | 12.3.0 | 插图处理 | 同上 |

使用方式：

- **运行时前置**：如需启用上述可选增强，在宿主 Python 执行 `pip install -r requirements.lock`；脚本均在文件内以 `try/except ImportError` 守护，缺失时打印明确安装提示并以退出码 1 终止，**绝不静默失败**。
- 包内**不含**这些二进制/库，也不含任何自动安装逻辑。

> 核心检索、引文核验、知识库查询等能力仅依赖 Python 标准库，开箱即用，不在此列。这些第三方库为**可选增强**：未安装时对应环节（图表/Word/PDF）提示安装并跳过，不影响其余能力。

## 2. 外部技能依赖

| 技能 | 形态 | 是否包内置 | 部署前置 | 说明 |
|------|------|-----------|---------|------|
| `browser-skill`（官方 BrowserSkill） | 由官方腾讯 BrowserSkill 提供 `bsk` CLI + Chrome MV3 扩展 | 否（纯文本包装，不含二进制） | 需用户另行安装官方 BrowserSkill 技能，并确认 `command -v bsk` 有输出 | 浏览器采集能力来源；未安装时相关 agent 会降级并提示，不静默假定可用，并受本技能声明的浏览器域白名单约束（由脚本/使用层落实）。 |
| `tencent-docx` / `pdf` | 平台内置技能 | 否（平台自带） | 无需额外安装 | **文档输出默认路径**：DOCX 由 `tencent-docx` 生成，PDF 读取由 `tencent-docs` / `pdf` 技能完成，质量显著高于包内 python-docx / pypdf 兜底。 |
| `tencent-pptx` | 平台内置技能 | 否（平台自带） | 无需额外安装 | **PPTX 输出默认路径**（经平台内置技能落地）。 |
| 腾讯文档（表格） | 平台内置技能 | 否（平台自带） | 无需额外安装 | **XLSX 输出默认路径**（量表/数据矩阵/编码表导出为在线表格）。 |

> 说明：**文档/表格/幻灯输出默认走平台腾讯文档技能链**（`tencent-docx` / `tencent-pptx` / 腾讯文档表格 / `tencent-docs` PDF），成稿质量与协作体验优于包内本地脚本。包内 `python-docx` / `pypdf` / `pdfplumber` / `Pillow` 降为**离线兜底**：仅当环境无腾讯文档技能时降级使用，缺失即跳过并提示，不阻塞主流程。

## 3. R 脚本库

108 个 R 脚本以**纯文本**形式交付，包内不调用 R 解释器，由用户在本地运行；`renv.lock` 仅作版本记录（含 55 个 CRAN 包），非运行时依赖。其中 `jiebaR` / `RQDA` 已从 CRAN 归档、不再收安全更新，须经 CRAN Archive 安装并自行评估风险（见 `CHANGELOG.md` 已知限制）。

## 4. 网络与权限

- **网络**：仅向 4 个 HTTPS 学术源白名单发起只读 GET（策略上禁止明文 HTTP）：Crossref、Semantic Scholar、arXiv、PubMed。
- **权限**：命令执行限包内脚本、浏览器限学术出版域白名单（敏感域禁入）、文件写入限用户工作区；上述边界由脚本内实现承担（如 `safe_path.py` 与脚本内域名白名单），详见 README「运行范围」。

## 附：journals.db（期刊评级库）体量说明

- **体量**：`skills/journal-library/db/journals.db` 约 19.3 MiB（20.3 MB，20,275,200 字节，已 `VACUUM` 压缩），是整包最大单文件，占包体约 60%–65%（打包后按实际体积计）。
- **必要性**：选刊路径（13 套评级体系 / 28,241 刊 / 149,117 评级）依赖此库做本地精确查询（`query.py`），**无公开等价 API 可实时替代**，当前版本维持内置以保证选刊能力完整可用。
- **一致性**：该 DB 为只读真源，`query.py` 只读访问，不写回插件安装目录。
