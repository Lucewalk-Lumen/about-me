# 更新日志 · OBHRM 研究协作团

## 1.0.0 版本发布 🚀（2026-10-22）

首个上架版本。七位智能体覆盖组织行为与人力资源管理（OBHRM）研究从选题到投稿的完整生命周期，共享同一套方法论知识库与质量闸门。

### 团队与分工

- 主理人（沈知行 / 首席研究官）：按研究生命周期阶段路由任务、下发交接块、汇总汇编，强制引用保真与质量闸门，不代写任何成员的专业结论。
- 文献综述专家（温书恒 / Owen）：选题界定、实证缺口与理论缺口区分、七阶段综述、九种写作范式、PDF 语料摄取、证据-论点映射。
- 论文写作专家（苏晚晴 / Chloe）：全文写作、理论驱动的论证链、模型与假设推导（含图尔敏式 warrant）、问卷与量表设计、APA 7 排版、终稿去 AI 化改写。
- 基金申报专家（徐立诚 / Victor）：国自科 / 国社科 / 教育部等项目书撰写，立项依据的紧迫性与真缺口论证、技术路线可行性、层次化目标设计。
- 数据分析专家（许清越 / Iris）：定量一手分析、元分析、质性研究三分支，完整 APA 统计报告与论文图表。
- 同行评审专家（秦子谦 / Simon）：审稿人视角的八维诊断（定量版 / 质性版）、投稿稿信任边界处理、严重度分级、修改路线图与审稿报告。
- 选刊投稿专家（方致远 / Jason）：13 套期刊评级体系（ABS / ABDC / FMS / CSSCI / CSCD / FT50 / UTD24 等）精确检索与投稿策略。

### 知识库资产

- 量表库：599 个测量量表（中英变量名、构念、维度与题号区间、完整题项、计分方式、反向计分标记、取用文献）。
- 理论库：134 个理论（内容 / 作用机制 / 结构 / 应用四段正文 + 参考文献原文块）。
- R 方法库：108 个可运行的 R 分析脚本，按 19 个方法族组织，每个脚本含数据前置、环境探测、真实输出三道门禁。
- 教材库：《组织行为学精要》12 章全文与节号索引，作为概念地基与出处锚点。
- 跨库知识图谱：以构念主键串联量表、理论与 R 方法，134 个构念聚合节点。
- 概念桥接层：输入任意中英概念词，一次返回教材锚点、理论依据、可用量表与可行分析路径；库内无匹配时如实报告，不补写。
- 期刊评级库：28,241 种期刊、149,117 条评级的本地只读真源，支持 13 套评级体系的精确检索。

### 能力与纪律

- 外部文献库导入：支持 EndNote / Zotero 导出的题录与用户自备的分析总结双材料并入语料；题录内笔记自动归入注释段，不臆造未提供的全文内容。
- 引用保真：所有理论、量表、方法与文献论断须经检索取回并标注出处；来源尚未确证的条目可在显著标记「来源未经确证」后引用，本库不保证其真实性，严禁编造出处，检索输出每次附带已核验 / 待核覆盖率。
- 质量闸门：交付前按机器可读判据清单逐条核对，覆盖引用保真、方法单一真源、审稿单一真源、角色越界、严重度分级、阶段门控、逻辑连贯、信任边界等。
- 文档产出：默认经平台文档技能生成 Word / 演示文稿 / 表格 / PDF，本地脚本作为离线兜底。
- 版本更新播报：线上版本更新后用户再次召唤时，主理人主动告知本次改动；同一版本读过一次后不再重复打扰。
- 离线可用：核心检索、校验与知识库查询仅依赖 Python 标准库；可选第三方依赖缺失时给出明确安装提示并降级为 Markdown 交付。

### 已知限制

- 量表库 599 条中 12 条、理论库 134 条中 107 条来源尚未确证（正文可用），引用前须核对原始出处，补齐文献后可恢复已核验状态。
- 部分理论正文在上游导出时被字段长度上限截断，无法补齐者已在输出中标注，检索层不补写。
- R 脚本以文本形态交付，需用户在本机安装 R 与相应包后自行运行；个别包（RQDA、jiebaR）已从 CRAN 归档，须经 CRAN Archive 安装。
- 浏览器自动化能力由官方 BrowserSkill 技能提供，需用户另行安装。
