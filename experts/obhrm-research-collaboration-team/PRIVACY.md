# 隐私说明（PRIVACY）

> 适用版本：`obhrm-research-collaboration-team` 1.0.1
> 生效范围：本插件包（CodeBuddy/WorkBuddy 插件市场分发）的安装与运行期行为

本说明用于向用户说明本插件
**采集了什么、存到哪里、如何关闭、是否对外传输**。

---

## 1. 我们**不**做什么

- **不收集个人内容**：插件不会读取、上传或留存用户的论文草稿、笔记、
  文档正文、聊天记录等个人数据内容。
- **不把用户个人内容发往作者/遥测服务器**：插件不含把用户论文草稿、笔记、
  文档正文、聊天记录等个人内容上传到插件作者或遥测服务器的逻辑；无埋点、无遥测。
  **但为完成文献与题录检索，插件会向公开学术 API（如 Crossref / Semantic Scholar /
  arXiv / PubMed）及经用户授权的学术站点发起网络请求，仅携带检索所需的题录 / DOI /
  关键词，不回传用户论文正文或个人数据**；外联范围以 README「运行范围」声明的
  学术源白名单为限。
- **不申请敏感系统权限**：插件不请求通讯录、定位、麦克风、摄像头、
  短信、通话、文件系统全盘读写等敏感权限。其能力范围为：执行包内自带脚本、
  经官方 BrowserSkill 的浏览器自动化（限学术出版域白名单）、受限网络出访白名单、
  向用户工作区写入交付物；上述边界由脚本内实现（如 `safe_path.py`、脚本内域名
  白名单）与文档约定承担，不视为已获沙箱级保证。

## 2. 我们做什么（本地运行留痕）

为了便于用户事后溯源安全相关操作，插件会在**用户本机**生成一个
**可选的、仅本地**的审计日志（`audit.log`），记录以下**元数据**（事件类别为示例，实际以调用方传入为准）：

| 记录类别 | 记录内容 | 是否含 URL 全文 |
|---------|---------|----------------|
| `agent_start` | 哪个智能体/会话被启动 | 否 |
| `url_navigated` | 通过浏览器能力打开的 URL（仅 scheme+host+path） | **已最小化**（去查询串/片段）|
| `script_executed` | 执行了哪个脚本文件 | 否 |
| `file_written` | 写出了哪个文件路径 | 否（仅路径，非文件内容）|
| `permission_denied` | 被权限检查拦截的操作 | 否 |
| `network_request` | 对外请求的 URL（仅 scheme+host+path）| **已最小化**（去查询串/片段）|

**关键隐私设计**：
- 审计日志**只记录操作元数据（路径、类别、时间戳）**，**绝不记录文件内容或正文**。
- 任何 URL 在落盘前会**自动剔除查询串（`?...`）与片段（`#...`）**，因此
  token、会话 id、追踪参数等敏感片段不会被持久化。
- 日志固定写入**包目录之外**的本机可写目录，按以下优先级确定：
  1. 环境变量 `OBHRM_LOG_DIR` 指定的目录；
  2. 否则 `$XDG_STATE_HOME/obhrm/audit.log`（Linux 规范）；
  3. 否则平台等价路径：macOS `~/Library/Logs/obhrm/audit.log`、
     Windows `%LOCALAPPDATA%/obhrm/audit.log`、其余平台同 XDG。

## 3. 如何完全关闭审计日志（隐私退出）

设置环境变量后，审计日志将被**完全禁用**（不再写入任何文件）：

```bash
export OBHRM_AUDIT_OFF=1
```

- 取值 `1` / `true` / `yes` / `on` 任一即生效。
- 关闭后 `log_event()` 变为空操作（no-op），不影响插件主流程功能。
- 该开关对审计日志全局生效（唯一实现位于 `obhrm_research_base/core/audit_log.py`）。

## 4. 权限与通信加密

- **网络出访**：外联采用学术源白名单（Crossref、Semantic Scholar、arXiv、PubMed）且
  意图将外联限制在白名单内 HTTPS 端点、拒绝明文 `http://`。该约束由脚本内实现与
  文档约定承担，请勿当作已获沙箱级保证。
- **浏览器自动化**：限定学术出版域白名单，并对银行 / SSO / 密码 / OAuth / 账户 /
  登录等敏感域名禁止执行任意脚本；借用（borrow）作用域限定为白名单且最长 5 分钟。
- **命令执行**：仅允许执行插件包内 `skills/**/scripts/**/*.py`，不开放任意命令。

## 5. 如何自测验证

1. **核对网络外联范围**：本包**代码层不含直接出站请求**（全包无 `requests` / `urllib` /
   `socket` 等出站调用）。文献检索与网页阅读通过**平台内置的联网检索与网页读取能力**
   （WebSearch / WebFetch）完成，调用只携带检索词 / URL，不含用户论文正文或个人数据；
   README「运行范围」声明的学术端点（Crossref / Semantic Scholar / arXiv / PubMed），
   是本包**若需代码级外联时的允许范围上限**。请据此确认：代码未出现出站主机、未向作者服务器上传用户内容。
2. **确认审计最小化**：启用审计后，打开一个带查询串的 URL，检查
   `audit.log` 中 `url_navigated` 记录是否已去掉 `?` 之后部分。
3. **确认可关闭**：设置 `OBHRM_AUDIT_OFF=1` 运行一次操作，确认
   `audit.log` 不再增长、且不新建日志文件。
4. **确认无明文 http**：全包搜索 `http://`（大小写），命中项仅为**静态数据里的 XML 命名空间**
   （如 `http://purl.org`、`http://www.w3.org`，用于解析 EndNote/Zotero 题录，**不发起任何请求**）
   与本地回环地址 `http://127.0.0.1`（**仅用于可选、默认关闭的本地 Ollama 能力**：需用户在本机
   自行安装并启动 Ollama 后才会启用，非默认行为、非数据外传，属本机回环）。

---

如有疑问或需撤回授权，删除本机对应 `audit.log` 文件即可，无需卸载插件。
