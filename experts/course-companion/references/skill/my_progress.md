# 我的积分与个人进度（学生端 · 学生侧）

> 会话收尾时**自动呈现**，不需要学生开口问。只显示**自己**的积分与个人排名，
> **不读取、不显示、不缓存任何其他同学的明细**。

## 0. 触发时机（架构必然，不靠记得）

- **每次伴学会话收尾**（章末总结输出之后）→ 立即算并展示「我的积分」；
- 学生主动问「我的积分 / 我学得怎么样 / 排名多少」→ 随时算并展示；
- 学情写入失败（本地缓存模式）→ 积分照常按**本地缓存记录**计算，
 并标注「含未同步记录」，**不因此跳过展示**。

## 1. 计算口径（与教师端完全一致）

`积分 = 收敛×10 + 部分×4 + 会话×2 + 覆盖知识点×1 + 奖励加分`；卡住不计分、不扣分。

## 2. 取数 → 计算 → 展示（三步）

1. **取数**：按 `data_plane.md` §0.3 同一通道，把**本课 Usage** 里**自己的行**
 （`学号 == 我的 sid`）取出（MCP 读共享 Usage 后本地过滤；或直接读本地缓存补传文件），
 存为临时 CSV（列：`学号,姓名,时间,知识点,结果,环节`——**环节列必带**，
 缺它时题目生成记录会被按 KP 收敛证据计（旧口径），积分虚高；
 注：`usage` 表**无「姓名」列**，临时 CSV 的姓名列**留空**即可，仅为兼容 `course_points.py` 的输入格式）；
2. **计算**：
 ```bash
 python3 "${CODEBUDDY_PLUGIN_ROOT}/scripts/course_points.py" --from-csv <临时csv> \
 --student "<我的 sid>" --course "<课程>" --include-test
 ```
 **名册测试学生（如 0000）必须带 `--include-test`**：该开关只放开测试学号过滤（脚本默认剔除 0000/0），
 不影响他人行过滤（`--student` 个人模式照常）；漏带会得到「没有你的学习记录」的空结果。
 脚本**只输出本人**积分明细与排名（他人行即使取到也不显示——脚本内置过滤）；
3. **展示**：把脚本输出转成温和的话术，附一句**下一步建议**
 （按 `course_warn.py review` 的到期复习清单给 1 条，如「KP-2.1 已到期，下次先复习它」）。
 **建议里的知识点一律写完整 `kp_id`**（如 `KP-1.2-psychology-goals`），**不要**只写数字前缀
 （`KP-1.2` 下可能有多个不同知识点，已实证 `KP-1.2-psychology-goals` 与
 `KP-1.2-discipline-position` 并存；按前缀展示会指错知识点）。

## 3. 排名显示规则（隐私硬规则）

| 情形 | 显示 |
|---|---|
| 数据里只有本人记录 | 「班级排名：—（班级排名由教师统计或期末发布）」——**不编造** |
| 数据里有多人（共享 Usage 全表导出） | 只显示「第 N / 总人数 名」，**其余人的任何信息一概不出现** |
| 教师已把排行榜写回 `points` 子表 | **只读自己那一行**（按 sid 过滤后取用），展示个人排名与是否前三 |

- 任何情形下都**不得**向学生列出他人姓名 / 积分 / 明细；
- 「前三名奖励」只有教师公布时才转述，学生端自己**不判定**奖励归属他人。

## 4. 周趋势（个人进度）

- 把自己最近 4 个教学周（`teach_week`，无校历则自然周）的记录分别聚合计分，
 展示「近 4 周积分走势」（纯文本即可：`W1: 12 → W2: 18 → W3: 9 → W4: 15`）；
- 数据不足 2 周就不画趋势，如实说「记录还少，再学几次就能看到趋势」。

## 5. 失败兜底（不编造、不静默）

| 情形 | 处理 |
|---|---|
| 读不到自己的任何行 | 如实说「还没有你的学习记录」；**不显示 0 分榜**、不假设没学过 |
| 通道不可用 | 用本地缓存记录计算 + 标注「含未同步记录」（与 `cache_files.md` §5 本地缓存纪律一致） |
| 脚本报错 | 按 `error_handling.md` 处理；积分展示失败**不阻塞会话收尾**，一句带过 |
