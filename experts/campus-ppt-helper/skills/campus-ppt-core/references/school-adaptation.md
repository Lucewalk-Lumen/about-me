# 学校适配与提示话术（School Adaptation）

> 面向主理人（campus-ppt-lead）与制作员（campus-ppt-maker）。核心：**分诊先问「场景 + 学校 / 单位」，再按 §三 决策树选模板**。本团是**校园通用**产品，但模板资产是**广财的**（广财 10 套 + 通用党政 5 套，共 15 套 .pptx，已实测 14 套 960×540pt、广财-07 为 720×405pt）——对非广财师生，必须走适配分支，**不得默认套用广财模板**。

## 一、为什么需要学校适配

- 产品定位是**校园通用**：任何学校 / 单位的用户都应能出片。
- 模板资产现状：内置默认模板只有**广财**品牌 8 套 + **党政**通用 5 套（统一托管于作者腾讯文档「演示模板库」，由制作员经连接器检索、导出、下载后套用，见 `scenario-templates.md §一`）。
- 若不问学校就直接出片，会出现两类事故：① 给外校学生套广财校徽 / 校名的模板（品牌错配）；② 用户明明有本校模板，却被引导用兜底方案（体验损失）。
- 因此分诊的第一个动作：**先问场景，再问学校 / 单位**。

## 二、学校档案（分诊时向用户收集，愿给则记）

| 字段 | 说明 | 必需性 |
|---|---|---|
| 学校 / 单位名称 | 用于命名自备模板文件与交付说明 | **必需** |
| 本校模板 .pptx | 自备模板文件，用户会话中直接提供本地路径 | 有则优先 |
| 品牌色 | 主色 / 辅色 hex，用户愿意提供时记录 | 可选 |
| 校徽 / 校名图 | 图片文件，仅路径 B 需要且用户提供时使用 | 可选 |
| 页眉页脚与字体要求 | 如页脚须含院系名、正文须用某字族 | 可选 |
| 使用场景 | 教学 / 答辩 / 党建党政 / 实习，决定叙事框架与语气（见 `scenario-templates.md` 速查表） | **必需** |

> 学校档案只记录**用户主动提供**的真实信息；用户提供不了的留空，**由 §三 决策树兜底**，不虚构补齐。

## 三、模板决策树（四级，逐级判据与动作）

```
用户是广财师生？
├─ 是 → ① 广财内置默认（腾讯文档「演示模板库」广财族，10 套）
└─ 否 → 用户是否自备本校 / 本单位模板？
         ├─ 是（已提供 .pptx）→ ② 用本校模板（默认路径 B 保真；只要风格一致可走 A，判据见 template-application.md §〇）
         └─ 否 → 是否需要本校品牌视觉（校徽 / 校色 / 校名）？
                  ├─ 否 → ③ 中性通用模板兜底（明示「未含本校品牌视觉」）
                  └─ 是 → ④ 品牌保真索取（暂停，请用户提供本校模板）
```

| 级 | 判据 | 主理人动作 | 制作员动作 |
|---|---|---|---|
| ① 广财内置默认 | 用户自述为广财师生（或场景为广财校内） | 分诊记录场景 + 基调 | 从广财族 10 套选 1 套（选型建议见 `scenario-templates.md §六`）；**默认路径 B 模板保真** |
| ② 本校模板已提供 | 用户会话中直接给了 .pptx 本地路径 | 接住用户给的文件并确认路径 | 按该模板出片；**默认路径 B 保真**，只要风格一致可走 A（判据见 `template-application.md §〇`）；提取 / 选色一律取自该模板真实结果 |
| ③ 中性通用兜底 | 用户无本校模板，且明确不需要品牌元素 | 向用户确认"用中性风格出片" | 走路径 A 风格重绘，**不硬编码任何校徽 / 校色 / 校名**；交付说明**明示「未含本校品牌视觉」** |
| ④ 品牌保真索取 | 用户要品牌保真但无模板 | **暂停出片**，回传用户：请提供本校 / 本单位模板（.pptx） | 不得动手；用户补交后转入 ② |

> 硬边界：**不虚构任何学校的品牌模板 / 校徽 / 校色**；④ 未经用户补交模板前禁止出片。`党政/` 5 套为**通用党政模板**，任何机关单位 / 党支部都可直接使用，不受学校归属限制。

## 四、用户可直接抄的提示话术

以下话术可直接复制给用户，按身份对号入座：

1. **广财师生**：
   > 我需要一份《XX》课程的教学 PPT，我是广财的，请直接用你们内置的广财模板出片。

2. **其他学校（有本校模板）**：
   > 我是 XX 大学的，我这里有本校模板（.pptx），现在把文件发给你，请用我的模板来做毕业答辩 PPT。

3. **其他学校（无模板，要通用风格）**：
   > 我是 XX 大学的，没有本校模板，也不需要校徽校色，请用中性通用的风格帮我做一份课程串讲 PPT，做完告诉我用的是哪套模板。

4. **其他学校（要品牌保真）**：
   > 我需要带我们学校品牌视觉的 PPT。我现在没有模板文件，请先停下来，告诉我怎么提供本校模板，再开始制作。

5. **党政 / 机关单位**：
   > 我们单位是机关单位，要做一份党支部年度工作总结 PPT，请用你们的党政通用模板。

6. **实习 / 求职人士**：
   > 我不是学校的，我要做一份述职 / 求职 PPT，不需要学校品牌元素，请用合适的通用模板。

> 主理人分诊话术（对未说明学校的用户）：
> > 请问您是哪所学校 / 哪个单位的？是否有本校（本单位）模板？是否需要带品牌视觉？

## 五、自备模板的接入约定

用户自备模板不再挂载目录，**以会话中直接提供的本地 .pptx 路径为准**：

- **文件来源**：由用户人工提供（上传 / 转发本地路径），本团不代取、不虚构。
- **命名建议**：`<校名或单位名>-<两位序号>-<描述>模板.pptx`，与内置 `广财-01-…`、`党政-01-…` 同构，便于选型与交付说明。
- **接收动作**：制作员确认拿到本地绝对路径后，按 `template-application.md §〇` 走路径 B（默认保真）/ A（风格一致）；提取 / 选色一律取自该模板真实结果。
- **预检**：确认文件存在、可读且为合法 .pptx（页数 > 0），即可进入出片流程。

## 六、与其他参考文件的分工边界

| 文件 | 管什么 | 不管什么 |
|---|---|---|
| 本文（school-adaptation.md） | **问学校、定分支**：学校档案收集、四级决策树、话术 | 模板怎么选套、怎么提取色板 |
| scenario-templates.md | **运行时模板源与场景选型**：唯一运行时模板源（腾讯文档）、场景决策表、触发词矩阵 | 学校归属判断 |
| template-application.md | **拿到模板后怎么用**：路径 A / B 选路、真实取色、保真复核 | 选哪套模板、问不问学校 |

> 一次完整出片的顺序：本文定分支 → `scenario-templates.md` 定模板 → `template-application.md` 定用法。三份文件互不越界，交叉引用处以对方为准。
