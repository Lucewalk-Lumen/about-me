# 模板库指南（Template Library）

> 说明配套模板的**分发与选型**。模板资产分两类：**广财**（广财品牌模板，10 套，广财师生教学 / 校内场景默认）与**党政**（通用党建 / 党政会议模板，5 套，任何机关单位 / 党支部可用）。本团**不虚构任何学校的品牌模板**。学校归属的判断与四级分支见 `school-adaptation.md`；场景口径统一为**教学 / 答辩 / 实习 / 党建党政**四类（见 §三 场景矩阵）。

## 一、模板分发方式（腾讯文档 = 唯一运行时模板源，1.0.0 起）

安装包受 **20M 上限**约束，模板不随安装包分发。**运行时唯一模板源是腾讯文档「演示模板库」**：15 套模板以 `tencentslide` 在线幻灯片托管于作者腾讯文档，制作员经 `tencent-docs` 连接器**四级自适应取件（缓存 → 直导 → 克隆 → 人工另存）→ 下载到本地缓存**后消费——直导与克隆链路均实测通过（2026-10-07 / 2026-10-08），**无人工导出环节**。

- **调用入口**：`references/tencent-docs-template-source.md`（四级取件 + 15 套云端权威清单 + 降级口径 + 实测证据）。
- **引用路径**：制作员只从缓存 `~/campus-ppt-cache/<云端标题>.pptx` 消费；**文件名权威 = 云端清单**（用户 2026-10-07 重排编号：广财-04=蓝绿-2、05=蓝绿-3、06=夜景、07=绿色极简）。
- **缺失处理**：先按 `external-dependency-registry.md` 卡 4 预检（鉴权 READY → 枚举 15/15 → 四级取件 → 校验收尾）；任一环节四级全败即**暂停回主理人**，**不得臆造路径**。
- **旧机制作废（1.0.0）**：147 MB 配套 zip、`~/campus-ppt-templates` / `~/uptt-templates` 挂载、`CAMPUS_PPT_TEMPLATE_DIR` 环境变量、WorkBuddy 资料库人工下载渠道、IMA 候选渠道——均退出运行时链路，不再识别。
- **用户自备**：仍按 §五 直接提供本校 / 本单位 .pptx，不经腾讯文档。

## 四、广财默认说明

- **默认走路径 B（模板保真，1.0.3 起）**：凡广财师生的教学 / 校内类需求，制作员**优先从腾讯文档「演示模板库」广财族（10 套：01–10 全量，本地缓存 `~/campus-ppt-cache/`）选取**，不替换为其他模板——**默认 `slide_duplicate_slide` 深拷贝模板页保真**；仅当用户明确只要风格一致（不要母版 / 页层视觉）时才走路径 A。
- 10 套覆盖红 / 蓝 / 绿 / 深底白字 / 极简 / 科技 / 设计空间等基调，足够大多数课程与汇报；选哪套由"内容基调 + 用户偏好"决定（如庄重红 → 广财-01；科技蓝 → 广财-10；极简 → 广财-07）。
- 党建 / 党政类需求从党政族（党政-01~05）选取，**同样默认路径 B 模板保真**。

## 五、学校适配边界（硬要求）

学校归属的完整决策树与话术见 `school-adaptation.md`，此处为边界声明：

- **三分支**（对非广财师生 / 其他单位）：① 自备本校模板已挂载或已提供 → 用本校模板（按 `template-application.md §〇` 选路径 A / B）；② 无模板且不需要品牌元素 → **中性通用模板兜底出片**（路径 A 风格重绘，不硬编码校徽 / 校色 / 校名），交付**明示「未含本校品牌视觉」**；③ 要品牌保真但无模板 → 暂停索取本校模板。
- **不虚构**：本团不虚构任何学校的品牌模板 / 校徽 / 校色；未提供模板时禁止生成带该校品牌视觉的 PPT。
- `党政/` 下的 5 套为**通用党政模板**，任何机关单位 / 党支部都可直接使用；若用户单位有正式 VI / 品牌规范，应以用户自备模板为准，党政模板仅作兜底。

## 六、选型建议（给制作员）

- 先看主理人分诊记录中的"场景 / 学校（单位）/ 基调"。
- 广财师生教学 / 校内 → 广财族（腾讯文档导出缓存）；党建 / 党政 → 党政族；其他学校 / 单位 → 按 `school-adaptation.md` 决策树 ② / ③ / ④。
- 同目录下多套时，按"内容情绪"匹配（庄重 / 正式 / 科技 / 简约），并向用户说明所选模板名，便于回溯。
- 选好后，配色与字号一律从该模板主题提取，保证整篇统一（详见 official-skill-routing.md 的精确指令清单）。
