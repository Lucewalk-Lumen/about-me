# 官方技能路由（Official Skill Routing）

> 面向制作员（campus-ppt-maker）。说明如何把"结构方案 + 资料 + 模板"路由到官方 `tencent-pptx` 技能或 WPS 生成 .pptx，**禁止自带 Python/JS 生成脚本**。

## 一、总原则

- PPT 文件**一律由官方能力生成**：**默认官方 `tencent-local-office-edit` 技能（路径 B 模板保真——广财师生 / 党政单位默认套用内置品牌模板）**；仅当用户明确不要模板、或无内置模板可用（中性兜底）时才走官方 `tencent-pptx`（路径 A 风格重绘）；其次 WPS（本地或 WPS 演示）。**本团不写任何生成脚本**。
- 制作员的职责是"适配模板 + 撰写精确指令 + 调用官方技能 + 备份提醒"，不是代码生成器。
- 若运行环境未提供 `tencent-pptx` 技能，降级为 WPS / 本地 Office 手动方案，并如实说明。

### §1.0 出片第 0 步：外部依赖预检（强制，先于一切生成动作）

**未完成本步不得开始出片。** 四个依赖的预检命令与判读口径**统一以 `external-dependency-registry.md` §二 四张连接卡为准**，本文件不重复命令，避免两处漂移：

| 依赖 | 预检卡 | 缺失后果 | 缺失处置 |
|---|---|---|---|
| 官方 `tencent-pptx` + 7 份设计文件 | 卡 1 | 路径 A 不可用；**视觉美化无法留痕** | 退 WPS / 本地 Office；设计文件缺任一份即**判"未调用视觉美化" = FAIL** |
| 官方 `tencent-local-office-edit` | 卡 2 | **路径 B 不可用** | 退路径 A，**如实告知"未继承模板视觉"** |
| 官方 `browser-skill` | 卡 3 | 采集降级 | 按 `browser-skill-integration.md §五` 四级降级 |
| 腾讯文档「演示模板库」 | 卡 4 | **无模板可用，15 套引用悬空** | **暂停出片**回主理人，提示连接腾讯文档；**严禁臆造路径** |

> **`tencent-local-office-edit` 随 App 内置分发，不在技能市场**——定位命令见卡 2，**不要硬编码绝对路径**（随 App 版本变化）。
> **`pptx2image.py` 依赖 LibreOffice，本机未安装、实际不可用**，不得作为主路径；取色与出图改走 `template-application.md` 方案 B（直读 XML）/ 方案 C（`slidep`）。

## 二、能力边界：先定"套模板"走哪条路（模板保真 vs 风格重绘）

**必须先选路，再选技能**——不能对用户含糊承诺"套模板 / 基于模板母版生成"。

### 三态判定（选路前置，拿不准必须问用户）

| 三态 | 判据 | 动作 |
|---|---|---|
| **明确走 B（默认）** | 只说"做个 PPT/课件"且身份命中内置模板族（广财师生 / 党政单位）；或要"就是单位那套模板/logo 母版都在"，或自备模板要保真 | 直接走 B，不问 |
| **明确走 A** | 用户明确不要模板 / 只要"配色字体像模板、结构清晰"；或无内置模板可用（非广财且无自备模板的中性兜底） | 直接走 A，不问，交付注明"未继承模板母版" |
| **用户自带 skill** | 用户明确指定"用我装的 xx skill 生成" | 确认后路由到指定 skill，不静默用默认路径 |
| **模糊（触发确认）** | 提到模板但保真度不明 / 路径 B 依赖不可用 / 对判据拿不准 | **必须停下来问，禁止默默选默认** |

- **模糊态一次提问附推荐项**（选项一：模板保真——慢但"就是这套"；选项二：风格重绘——快但无母版装饰；选项三：你定，按推荐项）。推荐项规则：自备模板 → 荐**保真**；只说模板无保真字样（含只说"做个 PPT/课件"且命中内置模板族）→ **荐保真**；仅无内置模板可用时 → 荐重绘并如实告知"未含品牌模板"；B 依赖缺失（卡 2）→ **不荐保真且如实告知"模板保真当前不可用"**，只给重绘与"等环境/退 WPS"两个选项。
- **不答兜底**：按推荐项推进并显式标注；**B 依赖缺失不可默认推进**——能力缺失须如实降级告知，不可静默走 A 冒充。
- 依据：用户"不确定使用哪个 skill 时请待我确认"的明确诉求。完整话术与判定三因子见 `interaction-protocol.md §五`。

| 路径 | 何时走 | 路由到 | 能力边界 |
|---|---|---|---|
| **A. 风格重绘（兜底 / 轻量）** | 用户明确不要模板、只要"配色字体像模板、结构清晰"；或无内置模板可用的中性兜底 | 官方 `tencent-pptx`（`create-from-material` 读图提风格 → `create-from-scratch` 重画） | **不继承模板母版 / 版式**；成品不含模板原生母版，须在交付说明中如实标注 |
| **B. 模板保真（默认 / 重 / 强保真）** | **默认路径**：广财师生 / 党政单位套用内置品牌模板；或用户要求"就是我们单位那套模板（logo、色块、装饰、母版都在）"、自备模板要保真 | 官方 `tencent-local-office-edit`（editor_sdk，`slide_*`：**`slide_duplicate_slide`（深拷贝模板页，建页主力）** / `slide_remove_slide` / `slide_set_text*` / `slide_get_page_info` + `save_file`） | 以模板 .pptx 为底稿，**保留"页层视觉 + 母版 / 版式 / 主题"**；**禁用 `slide_add_slide` 新建页**（只带母版层，会丢光模板视觉） |

**要点**：
- 判定"是否要模板保真"由用户诉求决定；只要涉及"看起来就是我们学校 / 单位那套模板"，即走 **B**，不得用 `tencent-pptx` 冒名。
- **路径 B 的保真单位是"页"，不是"版式"**：模板视觉长在**页层**，必须 `slide_duplicate_slide` 深拷贝模板页；用 `slide_add_slide` 新建页 + 指定 layout **不继承页层视觉**，出片必然"只有文字、没有模板"。
- **保真复核必须逐页出图目视**（`slidep screenshot`），只比对母版 / 版式 / 主题会得出"假保真"结论。
- **路径 B 调用必须走三步强制流程**：`python3 <tencent-local-office-edit>/edsdk.py list` → `schema <工具名>` → `call <工具名> --json-file <payload>`；**定位该脚本见 `external-dependency-registry.md` 卡 2**（随 App 内置，勿硬编码路径）。跳过 `schema` 直接 `call` 是本团明令禁止的调用方式。
- `slidep` 只有 `create` / `upsert-dsl` / `validate` / `screenshot` / `lint` 五个子命令，`create` 生成空白稿、**无模板参数**，也无导入 / 套用模板命令；**不可**拿它冒充"套模板"（但 `screenshot` 可用于保真复核出图）。
- 两条路径的**权威步骤与依据**只以 `template-application.md §〇` 为准，本文件不重复命令，避免两处漂移。

### 视觉美化能力路由（强制"真调用"，不得只声明依赖）

官方 `tencent-pptx` 技能内**还带有一套视觉设计系统**，此前本团从未路由到它——这是"有视觉美化却没见过使用"的根因。出片前**必须**读并用：

| 官方文件（位于 `tencent-pptx/references/`） | 作用 |
|---|---|
| `story-principle.md` | 叙事与版式骨架：`STORY.md` 字段、**11 种版式速查**、版式约束、`anti_pattern`、role/rhythm/visual_role、视觉锚点 |
| `design-principle.md` | 设计通用法则：**A/B/C 三区母版**（DSL 画布默认 1280×720px）、密度与容器填充率、视觉锚点、色彩面积分配 |
| `designs/design-principle.{academic,consulting,redgold}.md` | 三个领域分支（学术 / 职场咨询 / 红金政务），各含结构层 + 常量值层 |
| `create-from-scratch.md` / `create-from-material.md` | 生成流程与 Step4 风格场景适配表 |

**路由动作（两步，缺一不可）**：

1. **Step 4 风格场景适配**（关键词路由，官方三态：完全命中 / 软降级命中 / 多行命中 / 全表无命中）。本团默认映射：教学与答辩 → `academic`；实习 → `consulting`；党建党政 → `redgold`。
2. **产出两份留痕文件**：`STORY.md`（逐页 `layout`/`role`/`rhythm`/`visual_role`/`anti_pattern`）与 `DESIGN.md`（设计分支 id + A/B/C 三区具体 px + 密度/留白/配色硬指标）。

**冲突优先级链（官方原文）**：**用户显式指令 ≻ 命中分支结构层 ≻ 通用法则**。
- 用户给出的具体 hex / 字体家族 / 页数 / 比例 / 装饰增减**覆盖**分支常量值，但**仅作用于被显式指定的项**；
- 分支的**结构层（版式分类、字号阶梯比例、色彩面积分配、装饰白名单结构、自检条件）禁止改造**；
- 同向冲突取更严格者（通用"强调色 ≤10%" vs 分支"≤5%" → 取 5%）。

> **判定"是否真调用了视觉美化"**：交付物中必须存在 `STORY.md` 与 `DESIGN.md`，**缺任一份 = 未调用**，质检按 FAIL 处理。
> 版式的选择与轮换规则见 `layout-selection.md`；其中**路径 B 的版式池受模板限制**（实测单套 1–14 种，平均 7.6 种），须先清点再承诺。

## 三、何时用 tencent-pptx / 何时用 WPS / 何时本地 Office

| 决策因子 | 选 tencent-pptx | 选 WPS | 选本地 Office（PowerPoint） |
|---------|----------------|--------|---------------------------|
| 环境可用性 | 已安装/可调用官方 tencent-pptx 技能 | 用户环境为 WPS 演示，或 tencent-pptx 不可用 | 用户明确用 PowerPoint 且需精细控制 |
| 模板来源 | 腾讯文档「演示模板库」导出下载的 .pptx 均可载入 | WPS 对 .pptx 兼容好，可直接用导出的模板 | 同左 |
| 复杂图表/动画 | 官方技能支持常规图表与克制动画 | WPS 支持基础图表，高级动画有限 | 全功能 |
| 批量/自动化 | 适合"给指令即出片" | 适合用户在 WPS 内二次编辑 | 适合深度定制 |

**默认路由**：用户未指定且 `tencent-local-office-edit` 可用 → **模板保真（路径 B，套用内置品牌模板）**；用户明确不要模板或无内置模板可用、且 `tencent-pptx` 可用 → `tencent-pptx`（路径 A 风格重绘）；用户说"我用 WPS"或两条路径的官方技能均不可用 → WPS；用户要 PowerPoint 精细控制 → 本地 Office。

## 四、交给官方技能的精确指令清单（必须写全）

制作员转给官方技能（或用户在 WPS/PowerPoint 中执行）的指令，须包含：

1. **页面清单与顺序**：逐页页码、章节、结论式标题、核心要点（≤5）、对应资料 `S 编号`。
2. **模板 / 母版**：明确模板本地路径（模板经腾讯文档「演示模板库」检索、导出、下载到缓存目录，如 `~/campus-ppt-cache/广财-02-蓝色风景模板.pptx`，四步流程见 `tencent-docs-template-source.md`），并**写明所选路径**——路径 A（`tencent-pptx` 风格重绘）只能"取其配色/字体/版式结构为设计规范"，**不沿用其母版与页层视觉**；路径 B（`tencent-local-office-edit`）须**深拷贝模板页**（`slide_duplicate_slide`）才保留**页层视觉（logo / 色块 / 装饰 / 图形）+ 原始母版与版式**。两条路径的标准步骤见 `template-application.md §〇`。模板默认见 scenario-templates.md。
3. **配色色值**：取自模板主题色（**须先按 `template-application.md` 提取真实主题色**，提取结果见该文件 §五/§六；每个 hex 须可追溯），**禁止硬编码新增色**；若模板无明确色值，标注"不新增色，沿用模板既有配色"——**不要写成"沿用主题"**（路径 A 不继承主题，只是照色值重绘）。
4. **字号层级**：**七级 T1–T7**（页标题 / 小标题 / 正文 / 注释 / 图注 / 数据来源 / 页码），**逐级写该套模板的实测值**（取值表见 `body-typography-standard.md` 附录 A；禁止写与模板无关的通用值）；另附换行预算（正文框 `cx` → 单行安全字数）。
5. **版式（每页可不同）**：逐页给出 `layout` 名称 + `role` + `rhythm` + `visual_role` + `anti_pattern`；遵守轮换规则（相邻不重复 / 非对称 ≥40% / 连续 2 页对称必打断 / `N卡片横排` ≤2 页且 Hero 禁用 / 同款版式 ≤40%）。规则见 `layout-selection.md` §五/§六/§七。每页 `layout` 取值须按 `layout-selection.md` §3.3 四维范式（`layout` + `signature` + `vars` + `typography`）展开，缺任一维即版式选择不完整。
6. **视觉美化留痕**：声明所用**设计分支 id** 与 A/B/C 三区 px；确认 `STORY.md` 与 `DESIGN.md` 均已产出。
7. **图表规格**：每处图表的类型（柱状/折线/饼/树图等）、数据来源（S 编号）、强调点（如"高亮模块A"）、系列色取自模板主题、去噪要求（去网格线/3D/多余图例）。
8. **配图**：每页图片来源级别（P1–P5）、目标框 x/y/w/h（**pts**，含等比换算）、图注与数据来源行；**路径 B 只传本地绝对路径**。
9. **动画克制**：默认"淡入/推进"等稳重切换；**禁用弹跳、旋转、炫光类缓动**；动画服务于信息，不炫技。
10. **字体**：优先模板内置字体；跨平台（WPS/Keynote）场景改通用字体（如思源/系统默认），避免缺失。详见 SKILL.md 平台速查。
11. **形状定位方式（签名定位）**：指令与版面直改中引用形状一律按**原文签名**（形状 name + 类型 + x/y/cx/cy）定位，**严禁硬编码形状 id**——id 是会话级的（重开文件即漂移，实测 `000084` → `00007b`）；删页后新页序号 ≠ 原页序号，须维护页码映射表（新页序 → 原页序）。详见 `deck-gotchas.md` §九第 6 条与 `template-application.md` §〇已知限制 3。

## 五、指令转译示例（片段）

```
请基于模板 ~/campus-ppt-cache/广财-02-蓝色风景模板.pptx 生成 12 页 .pptx：
- 路径：A（风格重绘，tencent-pptx；不继承模板母版，交付说明须注明）  ／  B（模板保真，tencent-local-office-edit；**深拷贝模板页**，保留页层视觉 + 模板原始母版与版式）——二选一，写明
- 配色：取模板真实主题色（先按 template-application.md 提取 §五/§六 结果），不硬编码新色
- 字号：标题 32 / 正文 18 / 注释 12
- 页面：P1 封面"广财《XX》期末串讲"；P2 结论标题"考纲 80% 分值集中 3 模块"，要点[模块A40%/B25%/C15%]，出处 S1；…（逐页）
- 图表：P5 柱状图展示模块占比（数据 S1），强调"模块A"，去 3D/网格线
- 动画：仅"淡入/推进"，禁用弹跳旋转
- 字体：沿用模板，跨平台导出用通用字体
- 形状定位：按原文签名"矩形 13"，不按 id
```

## 六、禁止项（硬红线）

- **禁止**编写 Python（python-pptx 等）/ JS 生成脚本。任何"我写脚本生成"均违规。
- **禁止**硬编码无关色值、新增渐变/发光/毛玻璃风格。
- **禁止**在终稿留 Lorem ipsum 或"待补充"残桩（除非已在质检 WARN 标注）。
- **禁止**虚构品牌模板（非广财须用户自备）。

## 七、破坏性操作与备份

- 覆盖原文件、压缩媒体、批量替换模板前，**必须提醒用户先备份**。
- 生成后给出文件路径、页数、模板来源、需用户自测项（字体嵌入、动画在目标端表现）。

## 八、与质检衔接

- 制作说明须可被质检员"指令遵从性 / 规则遵从性"逐项核对（模板、配色、字号、动画、备份提醒）。
- 若官方技能返回异常，如实记录"待复核"，不谎称"官方校验通过"。
