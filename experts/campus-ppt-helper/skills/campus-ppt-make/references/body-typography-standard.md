# 正文样式与文字层级标准（Body Typography Standard）

> 面向制作员（campus-ppt-maker）、设计师（campus-ppt-content-architect）与质检员（campus-ppt-qa）。
> 解决**"模板有了、字还是乱的"**这类问题：字号拍脑袋、层级只有三级、长句把文本框撑穿、中英混排一塌糊涂。
> **本文件的每一个字号都有配套模板实测依据**（附录 A 立行实测 13 套；广财-02/03 与 01/04 同母版——**旧包编号判定，云端重排后对应关系未验证**；沿用同母版代表套口径，运行时仍以所选模板 run 级实测为准），**禁止在指令里出现无法溯源的数值**。

## 一、铁律：字号必须从模板提取

| 规则 | 说明 |
|---|---|
| **禁止拍脑袋** | 不得写"标题 32pt / 正文 18pt / 注释 12pt"这类**与本套模板无关**的通用值。 |
| **逐套提取** | 选定模板后，先提取该模板的**真实字号层级**，再据此排版；不同模板层级不同（广财-07 正文 14pt，广财-09 正文 10pt，两者不可互换）。 |
| **未提取不落字** | 提取失败（模板损坏 / 无 slide）时，暂停并回主理人，**不得**用默认值硬写。 |
| **口径写进指令** | 制作员给官方技能的指令中，"字号层级"一节必须写成**取自模板的真实值**，并注明提取来源（模板文件名 + 页号）。 |

### §1.1 提取命令（选路径 B 时同时是"读结构"步骤）

**手法一：直读 XML 数字号频次**（零依赖，本机可用）。把下面存成 `typescale_scan.py`，再 `python3 typescale_scan.py "<模板绝对路径>"`：

```python
import re, zipfile, collections, sys
p = sys.argv[1]
with zipfile.ZipFile(p) as z:
    slides = [n for n in z.namelist() if re.match(r"ppt/slides/slide\d+\.xml$", n)]
    c = collections.Counter()
    for n in slides:
        c.update(re.findall(r'<a:(?:r|defR|endParaR)Pr[^>]*\bsz="(\d+)"', z.read(n).decode("utf-8")))
for k, v in sorted(((int(k) / 100.0, v) for k, v in c.items()), reverse=True):
    print("%6.1f pt x%d" % (k, v))
```

> 该脚本**自包含**，零依赖，可直接复制使用；它统计的是"显式写在 run 上的字号"，即 §二 各档位的取值来源。

**手法二：读实际生效字号与画布**（路径 B 必做补充）。XML 只统计"显式写在 run 上的字号"；**封面 / 章节页字号常继承母版或版式，会被漏掉**（党政-05 即属此类）。因此选定模板后还要：

```bash
python3 edsdk.py list                                   # 先验通
python3 edsdk.py schema slide_get_info                  # 查参数（调用前必做）
python3 edsdk.py schema slide_get_page_info
python3 edsdk.py call slide_get_info    --json-file <payload>   # 画布与页数
python3 edsdk.py call slide_get_page_info --json-file <payload> # 逐页形状、实际字号、x/y/cx/cy
```

> **实测口径**：
> - `slide_get_info` 返回 `{"slide_count":9, "w_pt":720, "h_pt":405, ...}` —— **字段名是 `slide_count`，不是 `page_count`**；`w_pt` / `h_pt` 即画布尺寸（见 §5.0）。
> - `file_id` **就是文件的绝对路径**（`open_file` 回执形如 `model ready for file_id=/path/to/x.pptx`），不需要另外解析 id。
> - `open_file` 必须带 `wait=true`，否则返回时模型尚未就绪，后续读结构会拿到空值。
> - `slide_get_page_info` 返回的真实文本框坐标与尺寸（**尤其是框宽 `cx`**）是 §五 容量预算的计算依据，**必须取**。
> - `slide_duplicate_slide` 默认把副本插在**源页之后**（`page_indexes=[3]` → 副本成为 index 4），删页与回填时要按插入后的新索引操作。

## 二、七级文字层级（T1–T7）

| 层级 | 名称 | 用途 | 实测区间 | 广财默认 | 党政默认 | 加粗 |
|---|---|---|---|---|---|---|
| **T1** | 页标题 | 内容页顶部的**结论式标题** | 24–36pt | 28pt | 28–32pt | 是 |
| **T2** | 小标题 | 页内分栏 / 卡片标题 | 16–24pt | 16pt | 20pt | 是 |
| **T3** | 正文 | 要点句、段落 | 12–20pt | **12pt** | 16pt | 否 |
| **T4** | 注释 | 正文补充、括注、口径说明 | 10–12pt | 11pt | 11pt | 否 |
| **T5** | 图注 | 图 / 表下方说明行 | 10–14pt | 11pt | 11pt | 否 |
| **T6** | 数据来源 | 图 / 表下角出处行 | 9–11pt | 9pt | 9pt | 否 |

> **T3 的 12pt 有硬证据**：广财-01/02/04/05 的示例正文里直接写着模板作者的规格原文——"字号12，字体微软雅黑，行间距1.2，段后6磅"（**旧包编号**，云端重排后对应关系未验证，见附录 A 映射状态注）。这是模板自带的口径，**优先于任何推断**。

## 三、行距与段间距（实测口径）

| 项 | 广财模板实测 | 党政模板实测 | 用法 |
|---|---|---|---|
| 行距（`lnSpc`） | 1.0 / 1.2 为主；广财-07、08 为 1.5 | 1.5 为主；党政-05 为 1.3 | **继承模板原值**，不主动改；正文密集页允许在模板区间内取靠上值 |
| 段前（`spcBef`） | 模板中普遍未设 | 未设 | 不主动加 |
| 段后（`spcAft`） | 0pt 或 **6pt**（广财-01/02/03/04/05 示例正文明确写"段后6磅"） | 0pt / 5pt / 7.2pt | 沿用模板值；多段正文沿用 6pt |

> **禁止**为了"看起来透气"给正文临时加大行距——行距变化会把下方元素顶出边界，是本团已发生过的溢出根因之一。

## 四、中英混排字族

| 场景 | 规则 |
|---|---|
| 中文 | 沿用模板 run 级 `a:ea` 字族；**不得替换**（广财-01–07 为微软雅黑；广财-06/09/10 为思源黑体系；党政系列为思源黑体 / 思源宋体系） |
| 西文 / 数字 | 沿用模板 run 级 `a:latin`；无显式值时跟随模板主题 `majorFont/minorFont`（**不要**因为主题显示 Calibri 就改成 Calibri——中文模板的 ea 字族才是观感主导） |
| 中英同段 | **不手工切分字体**；由模板的 `a:ea` + `a:latin` 双槽位自动分工。手工设 `<a:rFonts>` 会破坏模板字体继承 |
| 数字 / 百分比 | 与所在层级同字号，**不单独放大**（除非模板本身有"大号数字"版式） |
| 全角 / 半角 | 中文正文用全角标点；`%`、度数、单位用半角；中英之间不加空格 |

> 实测口径：内置模板的 `a:ea` 字族已落库（附录 A 立行 13 套；广财-02/03 与 01/04 同母版——**旧包编号判定，云端重排后对应关系未验证**，沿用代表套口径），制作员**直接抄用，不做判断**。

## 五、容量与换行预算（防文本框被撑宽）

**这是本团已发生的真实事故**：`slide_set_text` 写入一段长文本后，文本框宽度由 `cx` 245pt 涨到 **706pt**，横穿版面，正文互相重叠。
`<a:bodyPr>` 与模板逐字段一致（`wrap="square"` + 相同内边距），因此**不能靠"参数没改"来免责**——必须做**主动预防**。

> **归因状态（诚实标注）**：`cx` 由 244.7pt 膨胀至 706pt 为 **已验证**（实测）；文本框普遍带 `spAutoFit` 为 **已验证**（读模板 XML 确认 13 套模板的文本框绝大多数含 `<a:spAutoFit/>`）；但"长文本必然触发撑宽"的**精确机制尚未完全归因**（未验证：是 autofit 重算、还是编辑器重新测量布局）。因此本文给的是**预防性上限**，不是因果定论——**按此执行可规避该事故**。

### §5.0 先确认画布尺寸（**15 套模板并不统一**）

| 模板 | 画布（pt） | 16:9 |
|---|---|---|
| 广财-01 / 02 / 03 / 04 / 05 / 06 / 08 / 09 / 10 | **960 × 540** | 是 |
| **广财-07-绿色极简模板** | **720 × 405** | 是（等比缩小 0.75×） |
| 党政-01 / 02 / 03 / 04 / 05 | **960 × 540** | 是 |

> **广财-07 是 15 套中唯一的 720×405pt**。**同样的 pt 值在 720 宽的画布上观感更大**：广财-07 的 14pt 正文，视觉上≈ 960 宽画布上的 18.7pt。**因此"跨模板比字号大小"没有意义，必须逐套取实测值**（这正是 §一 铁律的由来）。
> 画布尺寸取法：解包 `ppt/presentation.xml` 读 `<p:sldSz cx cy>`（1pt = 12700 EMU），或 `slide_get_page_info`。

### §5.1 预算公式（中文字符）

```
可用宽(pt)   = 文本框 cx − 左边距 − 右边距          # editor_sdk 默认左右各 7.2pt
单行中文上限 = 可用宽(pt) ÷ 字号(pt)                # 1 个全角汉字宽 ≈ 1 em = 字号
安全上限     = floor(单行中文上限 × 0.9)            # 留 10% 余量
```

示例（广财-07 内容页正文框，实测 `cx` = **244.7pt**，字号 14pt）：

```
可用宽 = 244.7 − 7.2 × 2 = 230.3pt
单行上限 = 230.3 ÷ 14 = 16.4  → 16 字
安全上限 = 14 字
```

> **公式已被模板自身验证**：广财-07 slide4 的正文框实测 244.7 × 60.6pt、字号 14pt、行距 1.5，框内示例文本 41 个汉字 —— 按上式 41 ÷ 16.4 ≈ 2.5 → 3 行，3 行 × 14pt × 1.5 = 63pt，与实测框高 60.6pt 相差 +3.9%（autofit 容差内），**公式可直接使用**。

**中英混排口径（半角 0.5 当量）**：上式按"1 个全角汉字宽 ≈ 1 em"折算；中英 / 数字混排时按**字符宽度当量**累加：

| 字符类别 | 宽度当量 |
|---|---|
| 全角字符（汉字 / 中文标点，如 `，。、；：`） | 1 |
| 半角字符（ASCII 字母 / 数字 / 空格 / 半角标点，如 `A`、`1`、`%`） | 0.5 |

单行占用 = Σ(字符宽度当量) × 字号 ≤ 可用宽。

算例（广财-07 内容页正文框：可用宽 230.3pt、字号 14pt → 单行当量上限 16.4、安全上限 14）：

- 混排句"模块A占比40%，共12个考核点"共 16 字符 = 全角 10（9 汉字 + 1 中文逗号）+ 半角 6（`A` `4` `0` `%` `1` `2`）→ 当量 = 10 × 1 + 6 × 0.5 = **13 ≤ 14**，合规；
- 若按"数字符个数"会得到 16 > 14 而**误判超限**——混排文本一律按当量折算，**不数字个数**。

> **同源口径**：`runtime-gate-thresholds.md` §二 字数门规定「半角数字 / 字母 / 空格按 0.5 字计，全角按 1 字计」；本节容量预算沿用同一当量（半角标点同按 0.5 档折算）。**容量预算与字数统计共用同一把尺**——同一段文本在两处的折算结果必须一致，避免两处口径漂移。

### §5.2 换算速查表（以 `cx` = 244.7pt 为例，中文字符数）

| 字号 | 单行上限 | 安全上限 | 适用层级 |
|---|---|---|---|
| 28pt | 8 | 7 | T1 页标题 |
| 20pt | 11 | 10 | T2 小标题 |
| 16pt | 14 | 12 | T2 / T3 |
| 14pt | 16 | 14 | T3 正文 |
| 12pt | 19 | 17 | T3 正文 |
| 11pt | 20 | 18 | T4 / T5 |
| 9pt | 25 | 23 | T6 数据来源 |

> 其他模板按 §5.1 公式重算；`cx` 从 `slide_get_page_info` 取。**禁止直接把本表搬到框宽不同的模板上。**
> 参考：广财-07 其他常用框宽（实测）——卡片正文 219.7pt、小标题 145.9pt / 159.1pt / 173.4pt、大号编号 55.7pt、页眉标题 159.9pt。
> 本表按中文字符数计；**中英 / 数字混排文本按 §5.1 当量折算后查表**（与字数门同一把尺）。

### §5.3 硬性动作

1. **文本自带换行**：交给 `slide_set_text` 的字符串里**主动插入 `\n`**，每行 ≤ 安全上限。
2. **不依赖自动换行**：不要指望渲染器帮你折行——路径 B 下 `spAutoFit` 行为不受控。
3. **写后复核框宽**：改字后重取 `slide_get_page_info`，确认目标形状 `cx` **未超出模板原值**（允许 ±5%）。
4. **超限即回退**：`cx` 增大超限 → 删短文本或加 `\n`，**不回退字号**（改字号会再次破坏层级）。

### §5.4 写入后框宽已膨胀：WRAP 三步复位（直改 OOXML）

**适用场景**：① 写后复核（§5.3 第 3 / 4 条）发现 `cx` 超限，且框已被 `spAutoFit` 撑宽；② 预判：模板正文占位符默认 `wrap="none"` 的，写长文案前即应按**横向**容量预算（坑点全文见 `deck-gotchas.md` §十二，本处不复制）。

**三步复位（顺序不能换）**：

1. **复位**：把 `a:ext.cx` / `a:ext.cy` 改回模板原值；
2. **换行**：设 `<a:bodyPr wrap="square">`；
3. **自适应**：设 `<a:bodyPr><a:normAutofit/></a:bodyPr>`。

**关键坑点**：

- **事后单独设 `wrap="square"` 无效**——框已被撑大，必须先复位几何（第 1 步）再谈换行；
- 对 `wrap="none"` 形状，容量须按**横向**判：`x + 文案当量 × 字号 ≤ 同排下一元素 x − 15pt`（当量口径见 §5.1；`15pt` 为同排元素最小间隙参考值，见 `runtime-gate-thresholds.md` §三）；**完成三步复位后**，才可用纵向「字/行 × 行数」判据。

> 本动作属**直改 OOXML**（大文件 / 版面微调通道，见 `deck-gotchas.md` §十六）：改前备份整文件，每次从干净源还原再打补丁（保证幂等）；只动 slide 级 XML，不碰母版 / 版式 / 主题。

## 六、`slide_set_text_property` 批量回填规范（路径 B 必做）

`slide_set_text` **会重置字符级样式**（字号、加粗、字体全丢）。因此改字后**必须**回填：

| 步骤 | 动作 | 参数要点 |
|---|---|---|
| 1 | 取形状 id | `slide_get_page_info`（**形状 id 是会话级的**：重开文件后 `000084` 可能变 `00007b`，必须重取） |
| 2 | 逐层回填 | `slide_set_text_property`：`shape_id` + `index`（起始位置，UTF-16 码元）+ `count`（**-1 = 到末尾**）+ `font_size` / `bold` |
| 3 | 分组提交 | 同一字号 / 粗细的段落**合并成一次调用**，批量原子提交，减少中途失败面 |
| 4 | 复核 | 再取一次 `slide_get_page_info`，比对各段字号是否与模板一致 |
| 5 | 目视 | `slidep screenshot <file> --page-index <i> --out <png>` 逐页看图 |

> `index` / `count` 按 **UTF-16 码元**计（**非** Unicode 码点、**非** 字节），中文与 emoji 之外的常规汉字为 1，代理对为 2。分段回填时**先算清偏移**，算错会改到相邻段落。

## 七、文字溢出验收口径（可执行）

出片后**逐页**执行，任一项不满足即判 FAIL：

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 框宽未膨胀 | 目标形状 `cx` ≤ 模板原值 × 1.05 |
| 2 | 框高未越界 | 形状 `y + cy` ≤ 页面高度（**先读该模板 `p:sldSz`**：14 套为 540pt，**广财-07 为 405pt**，见 §5.0） |
| 3 | 元素不重叠 | 同页文本框两两**无交叠**（允许模板自带的刻意叠压） |
| 4 | 层级完整 | 该页出现的字号**均落在 T1–T7 或特殊页型区间内**，无孤立异常值 |
| 5 | 目视 | `slidep screenshot` 出图后**逐页目视**，肉眼无截断 / 重叠 / 出界 |

> **"结构 / 语义层一致"不能替代目视**——本团已有"只比母版层 ⇒ 假保真"的事故前例。凡声称"排版无溢出"，必须附逐页出图。
