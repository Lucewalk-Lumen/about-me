### §1.1 设计分支路由（官方三态 + 本团默认映射）

官方路由是**关键词匹配**，结果分三态：**完全命中**（分支结构层 + 常量值层均生效）/ **软降级命中**（仅结构层生效，常量值层由 query 与 STORY.md 改写）/ **多行命中**（取命中最多者）/ **全表无命中**（universal-only 原创）。
冲突优先级链：**用户显式指令 ≻ 命中分支结构层 ≻ 通用法则**。（例：通用"强调色 ≤10%" vs 分支"≤5%" → 取 5%。）

本团的**默认映射**（用于设计师与制作员快速对齐，非替代官方关键词路由）：

| 本团场景 | 默认分支 |
|---|---|
| 教学 / 答辩 | `academic`（学术风：蓝白浅灰、证据化配图、撑满优先） |
| 实习 | `consulting`（职场咨询：Navy 主导、Action Title、结构图优先、左对齐纪律） |
| 党建党政 | `redgold`（红金政务：朱橙红 + 金点缀、美术层与内页分离、中文优先） |

> **判定"是否真调用了视觉美化"**：交付物中**必须存在** `STORY.md`（逐页五字段）与 `DESIGN.md`（含设计分支 id + A/B/C 三区 px 值 + 密度/留白/配色硬指标）。**缺任一份 = 未调用视觉美化 = FAIL**。
> **设计分支不得混用**；用户显式给出的 hex / 字体 / 页数 / 比例**优先于**分支常量值，但**分支的结构层（比例、阶梯、版式分类、自检）不可改动**。
> **注意两套画布不要混**：官方 DSL 画布默认 **1280×720 px**（设计源，A/B/C 三区默认值来自此）；而配套模板是 **960×540pt**（广财-07 为 **720×405pt**，是 15 套中**唯一** 720×405 的模板）。路径 B 落位一律按**模板 pt 画布**（见 `body-typography-standard.md` §5.0）。已将广财-07 线性升到 960×540（×4/3），标准 deck 与视觉门禁均以 960×540 为基准。

### §1.2 留痕不等于合规：十四条可复算断言 + 伴生门禁 `check_visual.py`

**教训**：曾出现留痕文档齐备、几何门 / 字数门 / 页型门三关全绿，但版面仍不合规的情形：
根因：留痕解决的是"有没有读官方设计系统"，**不解决"版面算不算合规"**。所以判据必须再加一层：**十四条断言（A1–A14）+ 演讲者备注门 AN 全部可复算、且必须逐页通过**。

| 断言 | 阈值 | 治的是哪类"不好看" |
|---|---|---|
| **A1** 字号下限 | 无可见文字 < **12pt**（模板 T7 密排正文值） | 为塞内容把字压小 |
| **A2** 无静默压缩 | 名义字号所需行高 ≤ 框内高；否则 `normAutofit` 会**悄悄压字**。行高模型须含**字体固有行高系数 1.2**（见下方"A2 漏检修复"） | 同一页冒出 10/11/12/14 四种实际字号 |
| **A3** 版心对齐 | 每页左对齐文本块的不同左边缘 ≤ **4** 个（1pt 归并） | 全片各页各排各的，无版心 |
| **A4** 标题下死带 | 标题栏底到最高内容元素顶的空白 ≤ **48pt**（仅内容页） | 标题与内容之间一条大空带 |
| **A5** 兄弟对齐 | 同行带且横向不重叠的文本块：顶差 ≤ 1pt、高差 ≤ 2pt | 四宫格/双栏块高低不齐 |
| **A6** 元素重叠 | 可见形状两两不得重叠；**仅"无文字装饰件叠文字"（色块/圆环+编号）豁免** | 文字压图、图被覆盖 |
| **A7** 锚点尺度 | 每页 ≥1 个元素字号 ≥ 正文基准(12pt) 的 **2.5 倍** | 通篇一样大，无视觉落点 |
| **A8** 图表文字对比 | 图表被实色装饰件覆盖 ≥80% 时，图表内文字色对底色的 WCAG 对比度 ≥ **3:1** | 深字压深底，图表标签读不出 |
| **A9** 行数越界 | **无 autofit** 的块，按名义字号算出的行高 > 框内高即告警 | 框装不下、文字溢出框外 |
| **A10** 图表禁入装饰形 | 任一**无文字且可见的装饰形状**（**有实色填充 `a:solidFill`，或**有可见描边 `a:ln` 带 `srgbClr`/`schemeClr` 且 `w>0`）不得**整体包裹**图表（四边均落入该形状内，2pt 容差） | 即"柱形图放在圆里"——装饰圆环/底盘不得作图表容器 |
| **A11** 数字阶梯锚点 | 巨型单独数字（纯 `\d+`、字号 ≥ **36pt**）须有相邻（≤150pt·画布比）的**非数字短标签**（框宽 ≤320pt·画布比） | 裸数字无语义（历史上金字塔 1/2/3 即此类；该金字塔已整组删除，见 §1.3 决策 5） |
| **A12** 无外部引用 | 页面正文不得出现：外链 / 脚注 / 参考文献 / **来源标注**（"X来源：""出处""［1］"等） | 成品可独立使用，来源/出处移入备注或省略 |
| **A13** 页内竖向空洞 | 内容页**同一栏内纵向相邻**的两个内容块之间的空白 ≤ **56pt·RF**；**块内**留白不计 | 删掉金字塔后 P4 中部留下 92pt 空带——A4 只管标题栏下的死带，管不到页面中部 |
| **A14** 内容区填充度 | 内容页 B 区内容墨迹底边距 B 区下沿 ≤ **72pt·RF**（A14a 页尾留白）；任一**内容栏**墨迹底边进度 ≥ B 区高 **70%**（A14b 栏内进度）；按**文本实际占用高度**（行数×行距×FONT_LINE×字号）计，不按框高 | "内容只铺半页、下半页全空"与"双栏一高一低"——A4/A13 只管空带，没有页面填充度的正向判据 |
| **AN** 演讲者备注 | 目录页（role=toc）须有**非空演讲者备注**（时间安排与配比等移入此处，不落正文） |

> **A6 的豁免必须收窄**：早期版本把"完全包含"整体豁免，于是**两个完全重合的文本框**（面积比 = 100%）被当成"刻意叠压"放行，门报 OK 而几何门报 232pt² 重叠。
> 正确口径：**只有一侧不带文字**才算刻意叠压。"装饰件 + 文字"放行，"文字 + 文字"一律 FAIL。
> **A8 / A9 是针对该盲区新增的**：A1–A7 只读**形状**文字，**图表部件内的排版是渲染器算的**，此前完全在盲区里；A2 又只管 `normAutofit`，于是"无 autofit 的图注框装不下而溢出"也漏掉了。
> **A10 漏判修复**：A10 原先只认带 `a:solidFill` 的装饰形，于是 P6 那个**未填充、只有描边的圆环**（272×272pt）被整体跳过，门禁报 PASS 而圆环**仍在页面上**——这是**门禁本身漏判**，不是 deck 合规。修复：`check_visual.py` 新增 `visible_decor()`，判"可见"= **实色填充 或 可见描边**二者居其一；A10 改用 `visible` 而非 `fill` 过滤。**违规样本已验证**：对未修复的 deck，门禁现在会打印 `A10 图表被装饰形状 #描边形 整体包裹`。
> **A8 反向漏判修复（与 A10 同源）**：删掉圆环后，图表落到**浅色页面**上，而类别轴标签仍是删除前为"压深底"而改的**白色**——白字压 `#EEEEEE`，对比仅 **1.16:1**，肉眼几乎不可读；A8 却因"无装饰覆盖"整体跳过判 PASS。根因与 A10 相同：**把"装饰件存在"当作判定的前提**，装饰一撤就失明。修复：A8 改判"图表文字对**实际底色**"——有装饰覆盖时取装饰实色，否则取**母版页底色**（`PAGE_BG_LIGHT`，直接读 `<p:bg>`）。同时把辖区收窄到**坐标轴/标题**文字，**数据标签（`<c:dLbls>`）除外**（它压在系列填充上，系列色多为 schemeClr，静态不可解析；本片数值标签白字压深蓝柱≈4.8:1，本就正确）。
> **A13 新增**：删掉 P4 金字塔后，页面**中部**留下 92pt 竖向空带——A4 只管标题栏下方的死带，**管不到页面中部**，于是"删了元素却没人重排"这件事在门禁里没有判据。A13 补这一格：内容页同一栏内纵向相邻两块之间的空白 ≤ 56pt·RF；判法为**分栏栅格**（纵向找两端都有内容的内部空带）。
>
> **A2 静默压缩漏检修复**：A2 旧公式 `need = 行数 × 行距倍数 × 字号` **漏掉字体固有行高系数 1.2**，使 `normAutofit` 把 14pt 正文压到约 12.6pt 仍报 PASS——即用户反复退回"页面难看"的真实根因（与 A10/A8 同源：门禁通过 ≠ 事实合规）。实证发现：微软雅黑 150% 行距下**实际行距 = 1.5 × 1.202 ≈ 1.803 × 名义字号**，旧公式少算 20% 卡在容差内漏检。修复：新增 `FONT_LINE = 1.2`，`need = 行数 × line_pct × FONT_LINE × 字号`（A2 与 A9 同改）。**违规样本验证**：修复后门禁可判红。
>
> **教训**：**门禁通过 ≠ 事实合规**。A10、A8、A2 三次事故是同类错误——**断言的判定模型与实际渲染器不一致**。A10/A8 是"判定前提依赖被删对象"，A2 是"公式漏掉渲染器的固有行高系数"，二者都导致门禁 PASS 而事实不合规。因此立下两条强制步骤，缺一即该断言不得计入"已执行"：
> 1. **违规样本验证**：每新增一条断言，必须拿一份**已知违规**的样本跑一遍，确认门禁**确实报 FAIL**；改造既有断言时同样要做（A8 就是这样才发现自己漏判）。
> 2. **反向自检**：凡断言里出现"当存在 X 时才判"的前提，必须回答"**X 被删掉之后呢**"，并为该情形补一条判定分支。
>
> **A10 / A11 / A12 / AN 是整改新增**：A10 禁"柱形图置于圆内"、A11 强制金字塔数字加锚点文字、A12 清理页面外部引用（**覆盖**旧"来源行必留"约定，见 §1.3）、AN 把目录页"时间安排与配比"移入备注。门禁直接读 `p:sldSz`，`RF/AF` 按画布自适配，**720×405 与 960×540 同判**。

**伴生门禁脚本 `check_visual.py`**（**出片期伴生工具，不随安装包分发**）：
- **真实位置**：出片期伴生脚本 `check_visual.py`（与 `check_content_scope.py` 同级，见 `external-dependency-registry.md` 卡 5）。
- **预检**：`python3 <路径> <产出件.pptx>` → **退出码 0 = 十四条断言 A1–A14 + 备注门 AN 逐页通过**，非 0 时逐条打印"页 / 断言编号 / 实测值 / 阈值 / 命中元素"。
- **判读口径**：**exit 0 = 已调用视觉优化**；非 0 = 未通过，须按打印项精修后复跑。**缺脚本时降级**：按本表 §1.2 阈值表人工逐页核对，并在交付说明标注「未验证（缺运行时门禁）」。
- **门禁 C10** 常态检查本文件是否齐备 15 项（A1–A14 + AN）、已登记 `check_visual.py`、留痕判据与三态路由均在文（见 `external-dependency-registry.md` §七）。

| 12 | 排版太多空白（2026-10-14 用户反馈） | 新增 **A14 内容区填充度**（A14a 页尾留白 ≤72pt·RF + A14b 内容栏底边进度 ≥70%），按**文本实际占用高度**计（防空大框虚报）；「删元素后留白外推页尾」规则以 A14a 为上限，超限必须通栏重排/放大标题补位。**违规样本已验证**：删 P5 下半内容 → A14a 判红 277.5pt + A14b 四栏 36% 判红；删 P4 左栏底部两块 → A14b 第 1 栏 67% 判红且 A14a 正确沉默；合规章片 deck_v11 七页全绿 |

**由决策 5 派生的通用规则（去重装饰）**：**同一页不得并列两个语义重复的图形**。当页面已有一张承载某语义的图表 / 图像时，不得再叠加**同义**的结构图 / 装饰图（反例：右上角已有「三维驱动 → 三阶进阶映射」图，又在中段叠一座表达同一映射的金字塔）。判据：两图形语义重叠即**删除其一**，保留信息更完整者；删除后若页面缺视觉锚点（A7）或留下空带，用**已有元素**（放大标题 / 通栏重排）补位，**不得**引入新的装饰元素。

**由 A13 派生的通用规则（删元素后的留白归属）**：删除页内元素（金字塔 / 装饰图 / 冗余图形）后，腾出空白**必须外推页尾**，不得留页面中段（页尾留白 = "本页到此为止"；中段留白 = "少了东西"）。执行：① 下方块整组上提；② 若撞右侧元素，**按原比例**缩小或整组位移腾通道（不得改比例 / 拉伸）；③ 余白归页尾，**不得**靠加高文本框、放大字号行距或新增装饰"填满"。即按此执行（左栏统一 14.4pt 节奏、三正文框精确名义尺寸、右栏配图顶边对齐左栏首正文块，中段不留空洞）。

> **A14a 收紧（1.0.3）**：「余白归页尾」以 **A14a 阈值**为限——页尾留白 ≤ **72pt·RF**（约 B 区高 22%）。腾出空白超过该上限时，**不得整段推给页尾**（那正是用户反馈的"排版太多空白"），必须用**已有元素**补位：通栏重排 / 标题升档承担锚点 / 配图顶边下延，只允许 ≤72pt·RF 的收尾留白。判据由 `check_visual.py` A14 逐页复算，B 区下沿取 C 区边界（画布高×495/540），页码/页脚条不计入内容墨迹。

**外部引用清理（硬规则，覆盖旧"来源行必留"约定）**：**页面正文不得出现任何外部引用**——外链、脚注、参考文献、来源标注（"数据来源：""案例来源：""出处""［1］"等）一律删除。来源/溯源信息改入**演讲者备注**或省略，**绝不**上屏。门禁 **A12** 逐页扫描并 FAIL。
> 此规则**覆盖** `page-content-contract.md` 旧版"正文页必须有来源行（缺则 FAIL）"的要求：学术溯源在采集/资产阶段仍须可追（见 `source-hygiene.md`），但**成品页面不再强制上屏来源行**。
> **与占位符规则的调和**：点 4 的"删除占位符"指清理模板脚手架/水印类残留；封面 `×××` 属**合法的待填字段**，**保留在封面正面上屏、不迁入演讲者备注**。占位符为刻意保留字段，非待清理脚手架。



## 二、正文内容排版（页内怎么排）

### §2.1 A/B/C 三区与安全区

官方设计总则把页面分三区（DSL 画布 1280×720px 下的默认值，须在 `DESIGN.md` 落成具体 px）：

| 区 | DSL 设计源（1280×720px） | 广财模板实落（960×540pt，×0.75 线性） | 内容 |
|---|---|---|---|
| **A · 标题块** | 0–120px | **0–90pt** | 主标题（24–30pt bold，即 32–40px ×0.75） |
| **B · 内容区** | 120–660px | **90–495pt** | **一切正文、图表、配图、卡片**；禁止挤占 A/C 区 |
| **C · 页脚条** | 660–720px | **495–540pt** | 左项目名 / 全局水印 + 右页码 `NN / TOTAL`（10–11pt 灰字） |

> **画布基准**：已将广财-07 的 720×405pt 线性升到 **960×540pt**（×4/3）；本表以 960×540 为实落基准，括号内给出 DSL 设计源 px 与 ×0.75 换算关系。门禁 `check_visual.py` 不写死画布，直接读 `p:sldSz` 并以 `RF=画布高/405`、`AF=画布面积/(720×405)` 自适配阈值，两套画布同判（见 §1.3）。

| 规则 | 说明 |
|---|---|
| **先划禁区** | 模板页层装饰（页眉色条、logo、页脚、大号编号、装饰图形）的包围盒为**禁入区**（见 `media-standard.md` §5.1）。正文**一律不进禁区** |
| 三区稳定 | **同类内容页之间的标题位置、页码位置必须保持稳定**，"禁止逐页随机发挥"（官方原文）。封面 / 章节过渡 / 结束页允许自定义版式 |
| 对齐 | **同页只用一种对齐基准**；左对齐时各栏文本左边缘对齐到同一垂直基准线（`consulting` 分支明确**禁居中海报感**） |
| 留白 | 元素间距 ≥ 12pt；窄栏内禁两端对齐。注意分支差异：`academic` **撑满优先，留白不是主要手段**；通用法则常规页留白 ≤35%——该上限由 **A14** 两条可复算判据落地（尾留白 ≤72pt·RF、内容栏进度 ≥70%），**引用 ≠ 断言** |
| 视觉重量 | 相邻两页最大元素面积比 **> 1.5:1** 或版式结构明显不同，否则判"单调"（轮换判定见 `layout-selection.md` §五） |

### §2.2 要点组织（正文内部结构）

| 要点条数 | 推荐组织 | 排版要点 |
|---|---|---|
| 1–2 条 | 陈述式（一段或两段） | 不编号；直接成段，段间 6pt |
| 3 条 | **三栏** 或 **1 大 2 小（非对称）** | 栏内小标题（T2）+ 正文（T3）；三栏等宽仅在模板本身是等宽版式时使用 |
| 4 条 | **四宫格（2×2）** 或 **非对称双栏（各 2 条）** | 四宫格须有明显分隔（模板自带的分隔形状或留白），禁纯靠间距 |
| 5 条 | **左标题 + 右内容**（列表型） | 编号用模板自带编号形状；序号与文本基线对齐 |
| ≥6 条 | **拆分到两页** | 超 5 条即拆页，禁止靠缩字号硬塞 |

> **要点 ≤ 2 行**（设计师规则不变）；**同页要点长度差异不宜超过 2 倍**，否则视觉失衡。

### §2.3 正文与配图 / 图表的共生排版

| 情形 | 排版方式 |
|---|---|
| 图证观点（evidence） | 图占一栏（≥35% 宽），文字另一栏；**图注在图下方**（T5），数据来源再下一行（T6） |
| 图为主角（anchor） | 图占 ≥40% 面积；文字**不超过 3 行**，且不得压在图主体上 |
| 多图同页 | **上限 2 张**（含图表）；顶边或中线对齐 |
| 图表 + 洞察 | 图表为主体 + **洞察标注框**（一句话结论，用 T2 字号），**禁止**把结论塞进图表角落小字 |

### §2.4 正文排版的明文禁止

- 禁**等宽卡片横排**用于承载数据（数据进图表或巨型数字版式）。
- 禁**50:50 等分双栏**做对比（用非对称 60:40 / 65:35）。
- 禁同页出现**两种以上**字号层级混排（除 T1–T7 的正常递进）。
- 禁为填满版面而拉伸行距或字号（`body-typography-standard.md` §三）。
- 禁**连续 ≥ 2 页**使用对称版式（对称打断规则见 `layout-selection.md` §五）。
