# 页面内容类型契约（Page Content Contract）

> 面向内容架构师（campus-ppt-content-architect）、制作员（campus-ppt-maker）、质检员（campus-ppt-qa）、主理人。
> **本契约是"这一页该放什么"的唯一权威依据**，优先于任何"内容丰满度"指标。冲突时以本契约为准。
> 每条规则都来自一次**实际被用户退回**的缺陷，不是预防性猜测——缺陷编号沿用 §六 台账。

## 〇、总则：页型先于文案

**一句话**：每页先有页型，再有文案。**没有页型的页面不允许写入任何正文。**

三条不可让渡的原则：

1. **索引页不承载内容**：封面 / 目录 / 章节过渡页是**索引与元信息**页，不是内容页。它们的作用是"告诉读者这是什么、往哪走"，不是"告诉读者知识"。把内容塞进索引页，等于在地铁站牌上印论文。
2. **字数上限不是下限**：契约给的是**上限**。正文页还有下限（**一律 ≥ 200 字**，经裁定维持），**索引页没有下限**——封面 40 字是合格的，塞到 110 字是错的。
3. **同一条信息全片只讲一次**：跨页重复（尤其"主线：…"这类贯穿行）一律删除，除非它承担**导航**职能且仅出现在目录页（见 §二 · 目录）。

## 一、页型总表

| # | 页型 | 定位 | 字数上限 | 必填元信息 | 版式角色 |
|---|---|---|---|---|---|
| 1 | **封面** | 元信息 | **≤ 90 字** | **主讲人 + 联系方式** + 机构 + 日期 | Hero |
| 2 | **目录** | 索引 | **≤ 60 字** | 页标题（如"串讲大纲"） | 索引 |
| 3 | **章节过渡** | 索引 | **≤ 30 字**（+1 行导语时 ≤ 50） | 章节号 + 章节标题 | 节奏锚点 |
| 4 | **正文-案例** | 内容 | 200–260 字 | 案例出处（**可溯源、不强制上屏**，见 §二） | 内容 |
| 5 | **正文-证据** | 内容 | 200–260 字 | 数据来源（**可溯源、不强制上屏**，见 §二） | 内容 |
| 6 | **正文-并列** | 内容 | 200–260 字 | 无（并列项须同构） | 内容 |
| 7 | **结尾** | 行动指令 | **≤ 90 字** | 机构 + 日期（建议） | 收束 |

> 字数按"页内所有可见文字之和"统计（含标题、图注；来源标注默认不上屏，见 §二）。**半角数字/字母/空格按 0.5 字计。**

## 二、逐型契约（允许 / 禁止 / 依据）

### 1 · 封面

| | 内容 |
|---|---|
| **允许** | 主标题；副标题（可选，一句话点题）；**主讲人**；**联系方式**；机构；日期；logo |
| **落位** | **主讲人 + 联系方式**置于封面**左下**署名区；**机构 + 日期**置于**右下**（沿用模板签名行）。两侧**同一基线、同高对齐**（门禁 A5：同行块 y 差 ≤1pt、高差 ≤2pt） |
| **禁止** | 课程主线 / 讲授时长 / 教学方式；目录式要点罗列；任何正文段落；任何"本讲怎么用"式说明 |
| **依据** | 缺陷 D1：封面出现「主讲：课程组｜时长：90 分钟｜方式：案例 + 题型 + 自检」与「主线：定位 → 案例 → 题型 → 证据 → 自检」，而**主讲人与联系方式缺失** |

**为什么**：封面只回答三个问题——**这是什么课 / 谁讲 / 怎么找到他**。时长、方式、主线都是"讲完才知道有没有做到"的信息，属于场外信息，写在封面等于让读者在门口读使用说明书。

**主讲人 + 联系方式的写法**：

```
主讲人：<实际授课教师姓名>
联系方式：<邮箱 / 办公地点 / 答疑渠道>
```

> **演示件与外发稿的例外**：当**无法核实**主讲人真实姓名时（如模板演示件），**必须用显式待填标记**（如 `主讲人：×××`），并在交付说明 + 演讲者备注中登记为**待替换字段**；**严禁**为了让封面"好看"而编造一个姓名。参见 `source-hygiene.md`。
> 此时可用组织身份兜底：`主讲人：人力资源管理课程组（授课教师）`——**组织名是真实字段，编造姓名不是**。

### 2 · 目录

| | 内容 |
|---|---|
| **允许** | 页标题；英文副题；**目录条目（序号 + 章节名）**；页码（可选）；仅作导航用途的**一行**主线（可选） |
| **禁止** | 正文段落；说明性小标题（"本讲怎么用""考前必须掌握"式）；时间安排 / 分值配比表；学习目标；任何成段文字 |
| **依据** | 缺陷 D2：目录页左栏被塞入「本讲怎么用」（68 字）+「考前必须掌握」（44 字）两段正文，右栏被塞入「时间安排与建议配比」12 块 |

**为什么**：目录的唯一职能是**让读者建立空间感**——一共几章、现在要看哪一章。一旦出现成段文字，读者的眼睛会在"找我关心的那一章"与"读这段说明"之间反复横跳，两件事都做不好。

**「时间安排」等场外信息的正确归宿**：优先放入**演讲者备注**（`slide_set_notes_text`）。若用户明确要求保留在页面上，则**新增一个页型为「本讲说明」的独立页**，不得寄生在目录页——寄生即违反本契约。

### 3 · 章节过渡页

| | 内容 |
|---|---|
| **允许** | 章节号（巨型数字）；**章节标题**；至多 **1 行**导语（≤20 字，且须为用户确认要保留时）；模板自带的装饰（色块 / 分割） |
| **禁止** | 学习产出（"学完本章要能"）；关键问题；导航明细（1.1 / 1.2 / 1.3 条目）；导语正文段落；任何内容块 |
| **依据** | 缺陷 D3：章节过渡页被塞入「学完本章要能」（40 字）+「关键问题」（48 字）+「本章导语」标签与正文（53 字）+ 导航 3 条（53 字），页面已有 **11 个文本形状** |

**为什么**：章节过渡页的作用是**换气**——它在大段内容之间制造一个呼吸点，让读者知道"上一章结束了"。它上面任何多于"章节号 + 标题"的文字，都在削弱这个换气效果。

**导航明细（1.1/1.2/1.3）去哪**：它们属于**章节首页**（正文页），不属于过渡页。若该章确实需要预告知小节目录，应在紧接着的第一个正文页以"小节目录"版式承载。

### 4 / 5 / 6 · 正文页（案例 / 证据 / 并列）

| | 内容 |
|---|---|
| **允许** | 页标题（结论式）；3–5 个支撑点（每个含结论句 + 依据）；图表 / 配图 / 图注；**来源标注（可选，不强制上屏）** |
| **下限** | 正文页 **≥ 200 字**（一律，不因是否含图而放宽——经裁定维持；见 `content-condensation-standard.md §三`） |
| **禁止** | 与页型不符的元信息；凭空编造的数据（采集阶段须可溯 `source-hygiene.md`，成品页面不强制标注来源）；未凝练的素材原文（直接粘贴采集回来的段落） |
| **来源标注（可选）** | 案例出处 / 数据来源**不再强制上屏**：用户要求"成品可独立使用"，页面正文不得出现来源标注（门禁 **A12** 逐页 FAIL）。确需溯源时移入**演讲者备注**或在交付记录留痕；**不得编造**来源。此条**覆盖**本契约旧版"缺来源行即 FAIL"的硬要求 |
| **依据** | 缺陷 D4（图文重叠 / 配图排版不当）、D5（图表被覆盖）——两页均属**正文页内**的落地缺陷，与页型无关，由几何门 + 出图目视把关 |

**正文页扩充"合法弹药"只有三种**：
1. 把支撑点从 3 个补到 5 个（**须不同质**）；
2. 把每个支撑点从"结论句"补到"结论句 + 依据"；
3. 补**同构**的第 4/5 个并列项。

> 把索引页的字搬到正文页不算数——**页型不同，字数不可跨页调拨**。

### 7 · 结尾页

| | 内容 |
|---|---|
| **允许** | 结束语（巨字）；**行动指令**（读者接下来做什么）；机构 + 日期；联系方式（可选，便于会后联系） |
| **禁止** | 任何新知识点；要点复述（`STORY.md` P8 反模式）；"感谢聆听"式空洞致谢之外的内容堆砌 |
| **依据** | 结尾页原有"复习提示 + 结束语"属合格用法，予以保留 |

## 三、页型 → 字数上限速查（架构师动笔前必查）

```
封面      ≤ 90    （无下限；40 字合格）
目录      ≤ 60    （无下限）
章节过渡  ≤ 30    （+1 行导语 ≤ 50）
正文页    200–260 （有下限 200）
结尾      ≤ 90
```

> **上限的物理依据**：上限取"该页型版式可容字数的 70–85%"，留换行抖动余量；具体反算见 `body-typography-standard.md` 容量与换行预算。上限**不是**"能塞多少就塞多少"。

## 四、架构师动笔前检查单（逐页打勾，缺项禁止进入成稿）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 每页已标注页型 | 七个之一，无"未定" |
| 2 | 每页已查字数上限 | 引用 §三 值 |
| 3 | 封面有主讲人 + 联系方式 | 两字段均在；无编造姓名（占位须登记） |
| 4 | 目录无正文段落 | 页内最长文本块 ≤ 12 字 |
| 5 | 章节过渡页 ≤ 30 字 | 仅章节号 + 标题（含下标数字） |
| 6 | 每条信息全片只出现一次 | 无跨页重复的长句（导航行除外） |
| 7 | 正文页来源标注（可选） | 门禁 A12 逐页查"无来源标注上屏"；如需溯源移入备注，不强制上屏 |
| 8 | 正文页 ≥ 200 字 | 且来源为凝练后文案，非采集原文粘贴 |

## 五、门禁（C9 + `check_content_scope.py`）

本契约由两道门执行：

- **静态门 C9**（`preflight_scanner.py`）：检查包内是否**存在本契约**、是否被 `SKILL.md` 索引、七类页型是否齐备、是否同批存在 `content-condensation-standard.md`；防止契约被删或失联。
- **运行时门 `check_content_scope.py`**：对**具体 pptx** 逐页断言页型契约。脚本**不入安装包**（下发物为纯文档插件，包内禁 `.py`，见安全线 S1），其**伴生位置登记在 `external-dependency-registry.md`**。断言如下：

| 页型 | 断言 | 阈值 |
|---|---|---|
| 封面 | 必含「主讲人」；**禁含** 主线 / 时长 / 方式 | 关键词命中 |
| 目录 | 最长文本块 ≤ 12 字（即无正文段落） | 12 |
| 章节过渡 | 页内总字数 ≤ 30，且最长块 ≤ 14（无内容块） | 30 / 14 |
| 正文页 | 页内总字数 ≥ 200 | 200 |
| 结尾 | 页内总字数 ≤ 90 | 90 |
| 全片 | 无跨页重复长句（≥14 字且含 `→` 的导航行豁免） | — |

> **门禁不可用时怎么办**：若伴生脚本在本机不可得，**须按本表逐项人工核对**，并在交付记录中把该项标为 **「未验证」**——**不得**标成"通过"（`source-hygiene.md` 三态标注纪律）。
> **为什么必须单列一关**：几何门查"形状打不打架"、字数门查"够不够多"，两者**结构上都无法**发现"目录页出现了正文段落"。用户退回意见指向的正是这一类——**门禁必须能覆盖用户实际会指出的错误类型，否则"全绿"是假的**。

## 六、缺陷台账（每条规则的外部依据）

| 编号 | 缺陷 | 典型表现 | 定级 | 处置 |
|---|---|---|---|---|
| **D1** | 封面出现「主讲 / 时长 / 方式」与「主线」，且缺主讲人与联系方式 | 「应该是主讲人，联系方式，为什么出现主讲、主线」 | **P0** | §二 · 封面 |
| **D2** | 目录页出现两段正文 + 时间安排表 | 「目录上为什么要有文字」 | **P0** | §二 · 目录 |
| **D3** | 章节过渡页出现学习产出 / 关键问题 / 导语 / 导航明细 | 「这一页是小节标题，不应该有内容」 | **P0** | §二 · 章节过渡页 |
| **D4** | 案例页内容重叠、配图排版不当 | 「内容重叠，图片排版不当」 | **P1** | 几何门 + 配图重制（`media-standard.md`） |
| **D5** | 证据页图表被覆盖 | 「图被覆盖」 | **P1** | 图表重配（`media-standard.md`） |
| **D6** | 根因：内容被"采集后直接铺开"，未做逐页凝练 | 「很有可能是一开始找了信息和内容，没有对内容进行总结的」 | **P0** | `content-condensation-standard.md` |

> **D1–D3 与 D6 同源**：都在"先找内容、后想页型"的顺序下必然发生。修 D1–D3 是治症状，落 `content-condensation-standard.md` 五步法才是治根因。

## 七、演进与同步

新增页型时，**必须同批更新**：本文件 §一 总表 → §二 逐型契约 → §三 速查 → §四 检查单 → `check_content_scope.py` 断言 → `SKILL.md` 参考索引 → `CHANGELOG.md`。六处不同步即视为契约未生效。
