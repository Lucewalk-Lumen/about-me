# 版式选择标准（Layout Selection）

> 面向设计师（campus-ppt-content-architect）为主，制作员（campus-ppt-maker）与质检员（campus-ppt-qa）按引用查阅。
> 解决"**每一个正文页用哪种版式**"的规划问题：版式库、路径 B 版式族清点、轮换规则、内容与版式匹配、逐页角色与节奏、视觉锚点 L1/L2/L3。
> 本册是原 layout-and-visual-standard 的**规划侧**；**页内排版（A/B/C 三区、要点组织）与视觉断言门禁见配套册 `visual-execution.md`（campus-ppt-make）**。
> 配套：`page-content-contract.md`（页型）、`content-condensation-standard.md`（凝练）、`body-typography-standard.md`（字号，campus-ppt-make）、`visual-execution.md`（排版与视觉门禁，campus-ppt-make）。

## 〇、"版式"在两条路径下的含义完全不同（先分清，否则规则会互相打架）

| | **路径 A 风格重绘**（官方 `tencent-pptx`） | **路径 B 模板保真**（官方 `tencent-local-office-edit`） |
|---|---|---|
| 版式来源 | **自由构造**。官方提供 11 种版式（见 §三），可任意组合 | **模板自带**。只能 `slide_duplicate_slide` 深拷贝模板已有的版式页（见 §四） |
| 每页能否不同版式 | **可以**，11 种随意轮换 | **取决于模板提供几种**：实测 1–14 种，**平均 7.6 种**（见附录 A） |
| 版式数量不足时 | 不存在此问题 | **必须**在交付说明写明"本模板仅提供 N 种内容页版式"，并三选一：**① 接受重复并说明**；**② 改路径 A**；**③ 模板页内"版式不改、正文页可调"的页内风格重绘**（保版式外壳、仅重排正文内容，口径见 CHANGELOG）。**不得默默重复** |
| Hero / 节奏 / anti_pattern 规则 | 全部适用（§五/§七） | 全部适用，但受模板版式池约束 |

> **铁律**：**不许承诺"每页都不同版式"却不看模板有几版式**。选路径 B 前，先做 §四 的版式族清点；清点结果显示版式种数 < 页数时，**要么接受重复并说明，要么改走路径 A，要么在模板页内以"版式不改、正文页可调"做页内重绘**，不得默默重复。

## 三、版式库（路径 A 可用全集，共 11 种）

> 来源：官方 `story-principle.md` 的版式速查。**非对称版式使用比例必须 ≥ 40%**。

### §3.1 对称版式（5 种）

| 版式 | 适用场景 | 典型结构 | 约束 |
|---|---|---|---|
| `全屏视觉+大标题` | 封面、章节过渡页 | 全屏实拍底图或模板自带主视觉 + 居中大标题（**禁用装饰渐变大图**） | — |
| `N卡片横排` | 功能对比、并列概念（2–4 卡片） | 等宽卡片横向排列 | **全篇最多 2 页**；**Hero 页禁用** |
| `图表+洞察` | 数据分析页 | 图表 / 表格主体 + 洞察标注框 | — |
| `居中金句/巨型数字` | 核心观点、里程碑页 | 居中大字 + 装饰 | — |
| `上下分栏` | 对比、before/after | 上下两区 | 对比优先用非对称双栏 |

### §3.2 非对称版式（6 种，优先使用）

| 版式 | 适用场景 | 典型结构 |
|---|---|---|
| `左大图+右侧文字` | 视觉叙事页、产品展示 | 左图占 55–65% + 右文字卡片 |
| `全幅图+骑线文字` | Hero 页、封面、叙事高潮 | 全幅背景图 + 文字骑入占图面 30–45% |
| `非对称双栏` | 对比论述、主次信息 | 宽窄比 60:40 或 65:35 |
| `巨型数字+洞察` | 数据冲击页 | 锚点数字占视觉重心 + 小字洞察环绕 |
| `上大图+下方卡片` | 产品 / 场景展示 | 上半大图 55–65% + 下半卡片 |
| `左标题+右内容` | 数据密集型、列表型 | 左侧色块标题栏 30–35% + 右内容区 |

### §3.3 版式预设四维范式（1.0.3）

**核心纪律：版式选择必须展开为四维预设——给一个版式名不等于完成版式选择。** 指令中每页 `layout` 字段必须能展开为以下四维，缺任一维 = 版式选择不完整：

| 维 | 字段 | 内容 | 取值来源 |
|---|---|---|---|
| 1 | `layout` | 结构：分区 / 栏比 / 锚点位置 | §三 版式库（路径 A 共 11 种） |
| 2 | `signature` | 签名：路径 B = 从模板哪页深拷贝；路径 A = 构造签名 | 签名 = 形状名 + 类型 + 几何（x/y/cx/cy）；定位纪律见 `official-skill-routing.md` §四 |
| 3 | `vars` | 色板变量：该版式各槽位主 / 辅 / 强调色 | 全部来自模板提取（`template-application.md` §三 / §六） |
| 4 | `typography` | 字号阶梯：该版式各槽位的 T 级映射与实测值 | `body-typography-standard.md` 附录 A |

**判据**：质检按"指令遵从性"逐页核对——每页 `layout` 缺任一维，**WARN 起档**。

## 四、模板自带版式族清点（路径 B 的硬约束）

路径 B 下**版式池 = 模板已存在的示例页**。选定模板后**必须先清点**，不得假设"模板有无限版式"。

### §4.1 清点方法（可执行）

对模板 `ppt/slides/slideN.xml` 逐页统计形状构成（形状类型 + 同类数量），按"结构桶"分族（同类 1 个 / 2 个 / 3–4 个 / 5+ 个；同类 ≥50 个视为纯装饰点阵，不计入结构）。**同族 = 同一版式**。
版式种数依模板实测清点确定。

### §4.2 实测结论（15 套，见附录 A）

- **内容页版式族：单套 1–14 种，平均 7.6 种**（155 个内容页 → 114 个版式族）。
- **4 套模板只有 2–3 种**（广财-01 / 02 / 06 等），**广财-06 仅 1 种** → 这些模板**做不到"每页不同版式"**。
- **5 套模板有 11–14 种**（广财-08 / 09 / 10、党政-03 / 04）→ 可满足多数页数需求。

> **决策规则**：若"每页不同版式"是用户的硬要求，且目标模板版式种数 < 计划页数，则**必须**：
> ① 改选版式更丰富的模板（附录 A 中版式种数 ≥ 计划页数的）；或
> ② 改走路径 A（自由构造）；或
> ③ 明示用户"本模板仅 N 种版式，会重复使用"，取得同意后再出片。
> **三条任选其一，不许沉默重复。**

## 五、版式轮换规则（"每个正文页可以不同版式"的落地约束）

| 规则 | 内容 |
|---|---|
| **相邻不重复** | 任意相邻两页版式必须不同（**含非对称版式之间**也不得相邻重复） |
| **非对称配额** | 非对称版式占比 **≥ 40%** |
| **对称打断** | **连续 ≥ 2 页对称版式 → 第 2 页必须改为非对称** |
| **卡片限流** | `N卡片横排` 全篇 **≤ 2 页**；Hero 页禁用 |
| **同款上限** | `左大图+右侧文字` 与 `非对称双栏` 合计出现次数 **≤ 全篇页数的 40%** |
| **重量差异** | 相邻两页最大元素面积比 **> 1.5:1** 或版式结构明显不同 |
| **Hero 间隔** | Hero 页不相邻，两 Hero 之间至少 1 个 Supporting 页 |

> 路径 B 下若版式池不足导致"相邻必重复"，属**模板限制**：须在交付说明写明，并把**文字层级 / 配图 / 视觉重量**作为差异补偿手段（不能说"做不到就算了"）。

## 六、版式与内容必须匹配（禁"想用某版式就硬凑内容"）

| 内容类型 | 最佳版式 | 必须避免 |
|---|---|---|
| 核心数据 / KPI | `巨型数字+洞察` | `N卡片横排`（数据装等宽卡片） |
| 产品 / 场景展示 | `左大图+右侧文字` / `上大图+下方卡片` | 50:50 等分双栏 |
| 观点 / 金句 | `居中金句/巨型数字` | 装进引言卡片 |
| 对比论述 | `非对称双栏`（60:40 / 65:35） | `上下分栏`（等分） |
| 流程 / 步骤 / 架构 | 非对称版式 | `N卡片横排` |
| 视觉叙事 / Hero | `全幅图+骑线文字` | 标题 + 装饰小图 |
| 数据密集列表 | `左标题+右内容` | 等宽四卡 |
| 趋势演进 / 概念对比 | `非对称双栏` | 左右等分双栏 |

### §6.1 `anti_pattern` 逐页必填（不是空话）

设计师**每页必须写 `anti_pattern`**，且必须是基于本页 `role` / `rhythm` / `layout` 的**具体禁止项**：

- Hero 数据页 → `禁止等宽卡片横排；禁止把核心数字塞进图表卡角落；禁止角标图顶替主视觉`
- 章节过渡页 → `禁止四卡片预览；禁止铺满正文段落`
- 产品展示页 → `禁止 50:50 等分双栏；禁止把产品图缩小成角标`

> 写"避免单调""注意美观"这类空泛表述 = **不合格**，质检判 WARN；连续两页空泛 = FAIL。

## 七、页面角色与叙事节奏（逐页必填三字段）

| 字段 | 取值 | 规则 |
|---|---|---|
| `role` | `hero` / `supporting` / `transition` | Hero 占全篇 **20–30%**（10 页 2–3、15 页 3–4）；**封面与结束页默认 hero**；Hero 不相邻 |
| `rhythm` | `peak` / `valley` / `transition` | 连续 ≥ 3 页同为 valley → 必须插入 peak 或 transition；章节切换处用 transition |
| `visual_role` | `anchor` / `atmosphere` / `evidence` | Hero 页的 `visual_role` 默认 **anchor**，否则该 Hero 不成立 |

> **含关键数据的页**，`description` 必须写成"**数据 + 判断**"两段式（只摆数字不给判断 = 信息板，不是汇报稿）。
> 每页 `layout` 取值按 **§3.3 四维范式**展开——只给版式名、缺任一维即版式选择不完整。

## 八、视觉锚点与 L1/L2/L3

| 层级 | 含义 | 面积要求 |
|---|---|---|
| **L1 主视觉** | 页面叙事主体 | 按设计分支：academic 双栏 ≥35% / 大图 ≥50%；consulting ≥40%；redgold 内页 ≥30–50% |
| **L2 支撑图** | 与正文并排的证据图 | 标注实际占位尺寸 |
| **L3 角标** | 母版徽标，全篇位置一致 | 不得顶替 L1 |

- 每页 `visual` 字段**至少给出 L1/L2/L3 之一**；纯结构页（目录、对照表）允许仅 L3。
- **视觉锚点硬要求**：每页 ≥1 个视觉锚点（≥40% 内容区面积的图，或巨型数字，或大色块）。**无锚点 = 必须补充**。
- **L1 视觉类型全篇统一**（如学术分支的"论文截图 / 真实摄影 / 流程 / 显微图"），单类占比 ≥60%；**禁止装饰渐变大图**，亦禁止 3D / 卡通 / 二次元 / 营销插画。
