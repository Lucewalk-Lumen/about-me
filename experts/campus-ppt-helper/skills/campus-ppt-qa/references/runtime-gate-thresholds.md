# 运行时门禁阈值标准（Runtime Gate Thresholds）

> 面向质检员（campus-ppt-qa）+ 制作员（campus-ppt-maker）。**四道运行时质量门判据的单一权威**：几何门 / 字数门 / 页型门 / 视觉门。
> 页型门与视觉门的断言正文分别在 `page-content-contract.md` §五 与 `visual-execution.md` §1.2，本文**不复制、只交叉引用**；几何门与字数门的判据此前**只存在于伴生脚本内**，本文固化全文——使「他机缺失 → 人工核对」有完整凭据，而不是只能标「未验证」。
> 所有阈值来自 2026-10-06~07 样片实测与用户裁定，**不是预防性猜测**；每条判据都能回溯到一次真实退回。

## 〇、四门总览与执行顺序

| 门 | 判据所在 | 伴生脚本（不入包） | 退出码 | 回答的问题 |
|---|---|---|---|---|
| 几何门 | 本文 §三 | `$HOME/WorkBuddy/工具开发/outputs/_contentfix/check_geom.py` | 0=通过 | 形状**坏没坏**（重叠 / 出界 / 贴边） |
| 字数门 | 本文 §二 | `$HOME/WorkBuddy/工具开发/outputs/_contentfix/measure.py` | 0=通过 | 内容**够不够**（正文页信息量下限） |
| 页型门 | `page-content-contract.md` §五 | `$HOME/WorkBuddy/工具开发/outputs/_contentfix/check_content_scope.py` | 0=通过 | 这页**对不对**（页在做自己该做的事） |
| 视觉门 | `visual-execution.md` §1.2 | `$HOME/WorkBuddy/工具开发/outputs/_visopt/check_visual.py` | 0=通过 | 版面**好不好看**（A1–A14 + AN 可复算断言） |

**执行顺序固定为「几何 → 字数 → 页型 → 视觉」**：先坏没坏，再够不够，再对不对，再好不好看。跳序会浪费修复轮次——几何已坏的页，字数与页型结论都不可信。

四门脚本均以**包外绝对路径伴生**（插件为纯文档下发物，安全线 S1 禁 `.py`），登记见 `external-dependency-registry.md` #20/#21/#23/#24 与卡 5 第 3 步。

**执行时机矩阵（谁、在什么时候、跑哪几门）**——与模式档位（`interaction-protocol.md` §六）配套，是「先自检、后质检」闭环的调度表：

| 执行角色 / 时机 | 几何门 | 字数门 | 页型门 | 视觉门 |
|---|---|---|---|---|
| 制作员出片后自检（轻 / 重两模式均执行） | **必跑**，退出码 0 为门 | **必跑**，退出码 0 为门 | 不跑 | 轻模式 `check_visual.py` 在则必跑（退出码 0 为门，制作侧建造纪律，高于质检底线）；重模式必跑 |
| 质检员 · QA-lite（轻模式） | **必跑（底线）** | **必跑（底线）** | 不跑 | 不作为阻塞门：`check_visual.py` 在则跑，审美类结论判 WARN、不阻塞交付 |
| 质检员 · 四维全检（重模式） | 必跑 | 必跑 | **必跑** | **必跑 + 逐页 slidep 出图目视** |

三条配套纪律：

1. **制作员自检不是四维质检**，是出片接口的建造侧把关——几何坏 / 字数缺的回流成本全在下游，回传前自跑两道门是最便宜的质量投资；
2. **QA-lite 的两道底线门与制作员自检同口径**（同一把尺子量两次）：制作员放行而质检员判红 = 自检放水，记入留痕并回查自检是否真跑；
3. **缺脚本时一律走 §一 降级人工核对**，结论只能标「未验证」，不得标「通过」；恢复脚本后以退出码复跑为准。

## 一、降级人工核对流程（四门通用）

1. 按卡 5 第 3 步预检：`test -f` 四门脚本路径，记录哪门缺。
2. **缺哪门，就按本文 §二/§三（或交叉引用文档）对该门判据逐页人工核对**——阈值以本文与交叉引用文档为凭据。
3. 核对结果**只能标「未验证」，不得标「通过」**；恢复脚本后必须重跑该门退出码为准。
4. **每轮修复后重跑全部门禁**（含未修的门）——修 A 破 B 是实测发生过的事故（见 `deck-gotchas.md` §十七）。
5. 任一门有任一条断言不满足 → 该门 FAIL → 进入下方「FAIL 流转入口」。

### FAIL 流转入口（哪条断言红 → 怎么走）

门禁非 0 时的标准回流路径，四步缺一不可：

1. **定位**：按门禁打印项取「页 / 断言编号 / 实测值 / 阈值 / 命中元素」，质检报告**原样引用断言编号**——只写"视觉门 FAIL"而不到断言，等于没有定位，制作员无法精修；
2. **派单**：精修指令经主理人回传制作员（协作铁律：成员禁直连）；制作员按断言编号回查本文 §二/§三 或交叉引用文档的判据全文精修；
3. **复跑全部门禁**：精修后**四门全跑**（含未修的门）——单门复绿就回传是常见偷工，修 A 破 B 的事故正是这么漏过去的；
4. **闭环判定**：四门退出码全 0 → 回质检员复检原 FAIL 项；**第 3 轮复验仍 FAIL → BLOCK**，升重模式或报用户裁定（预警阈值见 `task-state-resume.md`）。

## 二、字数门判据（measure.py 固化全文）

**统计口径**：页内所有可见文字之和（含标题、图注；来源标注默认不上屏，见 `page-content-contract.md` §二）；**半角数字 / 字母 / 空格按 0.5 字计**，全角按 1 字计。

| 页型 | 下限 | 上限 | 说明 |
|---|---|---|---|
| 正文-案例 / 正文-证据 / 正文-并列 | **≥ 200 字** | 建议 ≤ 260 字（判定宽容至 260×1.3） | 用户 2026-10-07 裁定「应该维持」，含图页不豁免 |
| 封面 / 目录 / 章节过渡 / 结尾 | **不设下限** | 由页型门管（见 `page-content-contract.md` §一） | 索引与收束页塞正文即页型门 FAIL |

**指标演进教训（判据为什么是现在这样）**：

- v1 几何包围盒覆盖率 → 被「空大框」骗过（220×111pt 的框只放 15 字，覆盖率照样高），已废弃；
- v2 字数 + 要点密度 → 方向对，但**给目录页与章节页也设下限 110–190 字**——这正是「把正文塞进索引页」的**制度性诱因**（见 `page-content-contract.md` §六 D2/D3）；
- v4 曾试「含图页下限降到 120」两档方案，**用户 2026-10-07 裁定回退**：正文页一律 ≥200 字。

**输出口径**：逐页「字数 / 目标区间 / 达成率 / 要点数 / 要点密度」+ 正文页合计与平均（对照基线：样片原 93 字/页）。要点判据：长度 ≥6 且非纯数字/百分号的文本块。

## 三、几何门判据（check_geom.py 固化全文）

**用法**：`python3 check_geom.py [产出件.pptx] [画布宽pt] [画布高pt]`。默认画布 720×405（广财-07 实测值）；**其余 14 套模板为 960×540，必须显式传参**（画布不统一，见 `deck-gotchas.md` §二）。

**检测对象**：页内**有文字**的形状（`p:sp` / `p:pic` / `p:graphicFrame` 的 `txBody` 非空；无文字形状不参与——装饰不是几何缺陷主体）。

| 编号 | 断言 | 阈值 |
|---|---|---|
| G1 | 文字重叠：同排两文本块相交宽与相交高**同时**超过容差 → 重叠 | `TOL = 6pt` |
| G2 | 出画布：`x < -1` 或 `y < -1` 或 `x+w > 画布宽+1` 或 `y+h > 画布高+1` | 容差 1pt |
| G3 | 贴边：未出界，但 `min(左边距, 上边距, 右边距, 下边距) < EDGE` | `EDGE = 10pt` |

**诊断参考值**：同排元素最小间隙 `GAP = 15pt`（不判 FAIL，供人工核对时参考）。该 15pt 同时是 `body-typography-standard.md` §5.4 `wrap="none"` 横向判据的间隙值——容量预算侧与几何门同一口径。

**实现纪律（检测器自身的三条教训，缺一则结论不可信）**：

1. **必须递归 `<p:grpSp>`**：目录条目、金字塔层级等藏在 group 内，只扫顶层会漏检（v1 教训）；
2. **xfrm 按形状类型取直接子路径**：`p:sp` / `p:pic` → `p:spPr/a:xfrm`；`p:graphicFrame` → `p:xfrm`。用 `.//` 递归查找会命中嵌套 group 内的 xfrm，**同一形状被重复计入**（v2 一次报 61 处、其中 49 处为误报）；
3. **组内形状坐标须换算到绝对坐标系**：按 group 的 `off/ext/chOff/chExt` 做线性映射后再判重叠与出界。

**为什么目视替代不了几何门**：`slidep screenshot` 会把出界文字**裁剪掉**——渲染图看着正常，pptx 文件几何已坏，换到 PowerPoint / WPS 打开会看到文字冲出页面（见 `deck-gotchas.md` §十四）。

## 四、页型门（交叉引用，判据在页型契约）

断言表全文见 `page-content-contract.md` §五，伴生脚本 `check_content_scope.py`（登记 #20）。核心断言速览：

- **封面**：必含「主讲人」+「联系方式」；禁含主线 / 时长 / 方式（**「方式」前 2 字为「联系」时豁免**——防止误杀「联系方式」）；
- **目录**：最长文本块 ≤ 12 字（即无正文段落）；
- **章节过渡**：页内总字数 ≤ 30 字，且最长块 ≤ 14 字；
- **正文页**：页内总字数 ≥ 200 字（与本文 §二 同源）；
- **结尾**：≤ 90 字；
- **全片**：禁跨页重复长句（≥14 字的句子出现 ≥2 次即告警，导航行豁免）。

## 五、视觉门（交叉引用，判据在视觉执行标准）

十四条视觉断言 A1–A14 + 备注门 AN 全文见 `visual-execution.md` §1.2，伴生脚本 `check_visual.py`（登记 #21）。核心断言速览：

- **A1** 字号下限：无可见文字 < 12pt；**A2** 无静默压缩（normAutofit 压字要报「实际会被压到约 Npt」）；
- **A3** 版心对齐：每页左对齐文本块的不同左边缘数 ≤ 4；**A4** 死带：标题栏底到最高内容元素顶空白 ≤ 48pt；
- **A5** 兄弟对齐：同行带 y 差 ≤1pt、高差 ≤2pt；**A6** 元素重叠：两个带文字的框一经重合即 Fail；
- **A7** 锚点尺度：每页 ≥1 个元素字号 ≥ 正文基准 2.5 倍；**A8** 图表文字对比 ≥3:1（对实际落点底色）；
- **A9** 行数越界；**A10** 图表禁入装饰形；**A11** 数字阶梯锚点（巨型单独数字须相邻非数字标签）；
- **A12** 无外部引用（外链 / 脚注 / 参考文献不上屏）；**A13** 页内竖向空洞 ≤56pt·RF；
- **A14** 内容区填充度（1.0.3 新增，仅 case/evidence/parallel/content 页）：**A14a** 页尾留白——B 区内容墨迹底边距 B 区下沿 ≤ **72pt·RF**；**A14b** 栏内进度——任一**内容栏**墨迹底边进度 ≥ B 区高 **70%**。均按**文本实际占用高度**（行数×行距×FONT_LINE×字号）计，不按框高；
- **AN** 目录页须有非空演讲者备注。

**画布无关性**：长度类阈值按 `RF = 画布高/405`、面积类按 `AF = 画布面积/(720×405)` 缩放，同一版式在 720×405 与 960×540 下判定一致；字号类阈值为绝对 pt 不随画布变。

> 已知边界（诚实声明）：A1–A7 只读形状文字；图表部件内部排版、主题色 `schemeClr` 静态解析、`<c:dLbls>` 数据标签不在门内——细节见 `visual-execution.md` §1.2 与脚本 docstring。
