# 配图、图表与表格标准（Media Standard）

> 面向采集员（campus-ppt-collector）、设计师（campus-ppt-content-architect）、制作员（campus-ppt-maker）与质检员（campus-ppt-qa）。
> 解决**"页面全是字、没有一张图"**这类问题：没人负责找图、图源不许可、图文不匹配、图片落位压到模板装饰、图表能力零路由。
> 本文与 `source-hygiene.md`（来源分级 L1–L4）、`body-typography-standard.md`（图注 / 数据来源字号）配套使用。

## 一、责任分工（先定"谁负责"，否则永远没人做）

| 环节 | 责任人 | 具体动作 | 产出 |
|---|---|---|---|
| **图像需求** | 设计师 | 页面清单表中标注每页 `配图` 字段（内容 / 类型 / 有无） | 页面清单"配图"列 |
| **图像采集** | 采集员 | 按需求找**真实可溯源**图片，附来源 URL + 许可 + 抓取时间 | 采集报告"图像来源表" |
| **图表数据** | 采集员 | 采集图表所需**原始数据**（不是截图），标明单位与口径 | 采集报告"数据摘录" |
| **落位与生成** | 制作员 | 按 §五 落位规范调用 `slide_add_image` / `slide_add_chart` / `slide_add_table` | 成品 + 指令清单 |
| **核验** | 质检员 | 逐图核：来源、许可、水印、变形、遮挡、标注 | 四维质检报告 |

> **铁律**：**没有"图像需求"就不许找图**；**没有来源就不许用图**。两句话分别封住"乱配图"和"配假图"。

## 二、配图来源分级（与 `source-hygiene.md` 的 L1–L4 对齐）

| 级别 | 来源 | 许可 | 使用规则 |
|---|---|---|---|
| **P1 用户提供** | 用户上传的本地文件 / 资料库文件 | 用户自有 | **最优先**；直接使用，无需额外标注 |
| **P2 官方公开** | 学校官网、官方公众号、政府网站、政策文件附图 | 公开可用（注意转载范围） | 可用；**必须标注出处**（机构 + 页面 URL + 抓取时间） |
| **P3 模板自带** | 所选模板 `ppt/media/` 内嵌图片（校徽、装饰图） | 随模板授权 | **零风险首选**：可直接复用；**不得删改**（见 `deck-gotchas.md §二`） |
| **P4 授权图库** | 明确标注免费商用 / CC0 的图库（如 Unsplash、Pexels） | 按站点许可 | 可用；**须核对许可条款**，要求署名的必须署名 |
| **P5 AI 生成** | 兜底方案 | 自生成 | **必须先穷尽 P1–P4**；生成结果**必须标注「AI 生成·非实拍」** |

### §2.1 硬性禁令

- **禁止**使用带水印的图库预览图（`deck-gotchas.md §四`）。
- **禁止**使用无署名来源的搬运图（L4）。
- **禁止**把 AI 生成图当作真实照片使用（如"我校校门实景"用 AI 图 → **FAIL**）。
- **禁止**用图片替代本可表格化的数据（数据一律进真图表或真表格，见 §六）。
- **禁止**为掩盖水印而裁剪（官方生成图自带的评估水印属正常，**不得裁**）。
- **禁止**把 `http/https` 远程 URL 交给 `slide_add_image`：该工具**不取远程字节**，会直接报错 `-32603 AddImage failed: … remote URLs (http/https) are not supported`（**实测：明确报错，非静默丢图**）。图片必须先落地为本地文件。

### §2.2 AI 生成兜底流程（P5 启用条件）

```
需要配图
  ├─ 用户提供？      → 有则用 P1，结束
  ├─ 官方公开有？    → 有则用 P2（记出处），结束
  ├─ 模板自带够用？  → 够则用 P3，结束
  ├─ 授权图库有？    → 有则用 P4（核许可），结束
  └─ 以上全无 → P5：AI 生成 + 标注「AI 生成·非实拍」 + 在图注说明用途
```

> P5 是**最后一档**，不是默认档。采集员报告中须写明"已检索 P1–P4 均未命中"的**检索证据**（检索词 + 检索站点 + 时间）。

## 三、图文匹配（判断"该不该有图"）

| 内容类型 | 是否配图 | 配什么 |
|---|---|---|
| 概念 / 定义 | 可选 | 示意图、类比图（优先**自绘简图**而非找图） |
| 数据 / 占比 / 趋势 | **必须** | 图表（柱 / 线 / 饼），**不是**截图 |
| 结构 / 流程 / 层级 | **必须** | 流程图、层级图、组织图 |
| 时间 / 历程 | 建议 | 时间线 |
| 实景 / 现场 / 人物 | 有则配 | 真实照片（P1/P2/P4） |
| 政策 / 文号 / 条例 | 可选 | 文件封面缩略图或条文截图（**须清晰可辨**） |
| 纯观点 / 金句 | **不配** | 大字排版即可，配图反而稀释 |
| 封面 / 章节页 | **必须**（模板自带即可） | 沿用模板页层视觉，**不加额外图** |

> **每页图数上限**：正文页 **≤ 2 张**（图表也算）。超过则拆页。**每页至少要有 1 个非文字元素**（图表 / 图形 / 图片）——这是"全字页"的判罚线。

## 四、图注与署名（字号见 `body-typography-standard.md` T5/T6）

| 项 | 规则 |
|---|---|
| 图注位置 | 图 / 表**下方居中或左对齐**，与图形间距 4–6pt |
| 图注格式 | `图 N  说明文字` （图注不加粗、不加句末句号） |
| 表注格式 | `表 N  说明文字` （**表题在表上方**，表注在表下方） |
| 数据来源 | 独立一行，位于图注下方，格式 `数据来源：<机构>，<版本/时间>`；用 **T6 字号（9–11pt）**。**覆盖条款**：若用户要求"成品可独立使用"（如整改场景），来源标注**不再强制上屏**，改入**演讲者备注**或省略（门禁 **A12** 逐页 FAIL 上屏来源；见 `page-content-contract.md` §二 / `layout-selection.md` §1.3） |
| 图片署名 | P2/P4 来源须在来源行标注：`图片来源：<机构/站点>（<许可>）`；同上，用户要求成品可独立使用时移入备注或省略 |
| AI 生成 | 来源行须写 `图片来源：AI 生成·非实拍`（**若上屏**；成品可独立使用时改入备注） |
| 占位 | 采集缺失时写 `数据来源：待补充（采集员待核）`，**不得**编造机构名 |

## 五、落位规范（图片放哪、多大、会不会打架）

### §5.1 安全区与不打架原则

| 规则 | 说明 |
|---|---|
| **先读画布** | 15 套模板中 **广财-07 为 720 × 405pt，其余 14 套为 960 × 540pt**（见 `body-typography-standard.md` §5.0）。**同一张图在广财-07 上会显得大 0.75 倍**，落位尺寸须按画布换算，不可跨模板直接套用 |
| **必让区** | 模板页层已占用的区域（页眉色条、logo、页脚、装饰三角、大号编号）**一律避让**。页层装饰是模板本体，**不删、不压**（见 `deck-gotchas.md §二`） |
| 安全边距 | 四边各留 **≥ 24pt**（960×540 画布上约 0.85cm；**720×405 画布上按 ≥ 18pt**）；不得贴边出血（除模板本身设计的出血图） |
| 文字优先 | 图片不得覆盖任何文字框；需要叠压时**先确认模板原有叠压关系**，新加图**不做叠压** |
| 纵向对齐 | 多图同页时**顶边对齐**或**中线对齐**，不随手摆 |
| 留白 | 图文之间留 **≥ 12pt** 呼吸间距 |

> **获取必让区的办法**：选定模板后，用 `slide_get_page_info` 读该页形状清单与坐标，把"页层非占位符形状"的包围盒标为禁入区，**再**给图片算位置。禁止"先放图再看哪被压"。

### §5.2 等比与裁剪

```
目标框 (w₀, h₀) 与原图 (W, H)
缩放比 r = min(w₀ / W, h₀ / H)          # 取小 → 保证完整不裁
实际尺寸 w = W × r,  h = H × r
居中偏移 x = x₀ + (w₀ − w) / 2,  y = y₀ + (h₀ − h) / 2
```

- **不要只定 `w`**：`slide_add_image` 会**自动按原图比例修正宽高**（见 §6.4），你给的 `w` 可能不被采纳，导致图上不去/留白不均。**必须把按上式算好的 `w` 与 `h` 一起传入。**
- 需要"填满裁切"时：先按 `r = max(...)` 缩放，再裁切溢出部分；**裁切不得切掉主体信息**。
- 落位后**复核实测几何**：`slide_get_page_info` 读回 x/y/w/h，确认落在目标框内（允许 ±5%）。

### §5.3 无图兜底（必做）

某页图片最终拿不到时：

1. **首选**：改用与主题一致的**完整无图版式**（模板自带的无图内容页）。
2. **次选**：用该页文字重构为**图示化布局**（卡片 / 分栏 / 流程箭头），由**模板自带的形状**拼装。
3. **兜底**：改为纯文字版式并**删掉图片占位框**。

> **绝不留空图占位框**（`deck-gotchas.md §四`）。缺图必须在交付说明中如实列出，**不得**用空白框冒充。

## 六、图表与表格能力（此前包内零路由，现补齐）

### §6.1 工具清单（editor_sdk，路径 B 可用）

| 工具 | 用途 | 关键点 |
|---|---|---|
| `slide_add_chart` | 新建图表（柱/条/线/面积/饼/散点/雷达等 20 种） | **数据内嵌**，成品自包含；返回 `shape_id` 供后续改图表 |
| `slide_update_chart_data` | 替换数据（**保持原图表类型不变**） | 用于"先搭好样式，再灌真实数据" |
| `slide_change_chart_type` | 换图表类型 | 与上一条配合做样式微调 |
| `slide_update_chart_title` / `_legend` / `_axis` / `_gridlines` / `_data_labels` | 标题 / 图例 / 轴 / 网格线 / 数据标签 | 逐项可选，省略即保留原值 |
| `slide_update_chart_series_style` | 单条系列配色 / 标记 | **一次一条系列**；标记仅对线/散点/雷达生效 |
| `slide_update_chart_trendline` | 趋势线 | 增 / 改 / 删 |
| `slide_get_chart_info` | 读已存在图表的结构 | 改图表前先读 |
| `slide_add_table` | 新建空表（n 行 × m 列） | **只建空表**，列宽行高**均分** |
| `slide_set_cell_text` | 写单元格文字 | 单格写入；多格需多次调用 |
| `slide_set_cell_style` | 单元格样式补丁 | 省略即保留 |
| `slide_get_table_info` | 读表格行列与行高列宽 | 改表前先读 |
| `slide_merge_table_cells` / `slide_unmerge_table_cells` | 合并 / 取消合并单元格 | 合并后内容取左上格 |
| `slide_insert_table_rows` / `_cols`、`slide_delete_table_rows` / `_cols` | 增删行列 | `index` 是**插入间隙位置**，非现有行号 |

### §6.2 坐标单位（官方描述自相矛盾，**已实测定案**）

`slide_add_chart` 的工具**说明首段**写"Coordinates and dimensions are in **pixels at 96 DPI**"，但其**参数说明**逐项写"in **points** (1pt = 12700 EMU)"。两者**互相矛盾**。

**实测定案（720 × 405pt 广财-07 模板）**：

| 工具 | 传入 | 落盘实测 | 单位结论 |
|---|---|---|---|
| `slide_add_image` | x=20 y=300 w=120 h=68 | x=**20.0** y=**300.0** w=**63.4** h=**68.0** | **points**（w 被按原图比例修正，见 §6.4） |
| `slide_add_chart` | x=300 y=250 w=380 h=130 | x=**300.0** y=**250.0** w=**380.0** h=**130.0** | **points**（若为 px@96dpi，380px 应落 285pt） |
| `slide_add_table` | x=20 y=380 w=300 h=60 | x=**20.0** y=**380.0** w=**300.0** h=**60.0** | **points** |

> **结论**：三者**统一使用 points**。`slide_add_chart` 描述首段的 "pixels at 96 DPI" **系官方文档笔误**，与参数说明冲突时**以参数说明为准**。
> **仍建议**首次调用后 `slidep screenshot` 出图核对——不是为验证单位，而是为检查是否压到页层装饰。

### §6.3 画布尺寸（先读再算坐标）

用 `slide_get_info` 直接读，不要靠解包：

```
slide_get_info(file_id) → {"slide_count":9, "w_pt":720, "h_pt":405, "w_emu":9144000, "h_emu":5143500}
```

> **字段名是 `slide_count`**（不是 `page_count`）。`w_pt` / `h_pt` 即画布 pt 尺寸，直接用于坐标校验（见 `body-typography-standard.md` §5.0）。

### §6.4 图片会**自动保持原图比例**（实测）

`slide_add_image` 传入 `w`/`h` 后，工具**按原图长宽比修正**实际尺寸——实测请求 `w=120 h=68`，落盘为 `w=63.4 h=68.0`（保持原图比例，以 `h` 为约束）。

- **好处**：不会把图拉伸变形，`deck-gotchas.md §四` 的"变形"问题在路径 B 下由工具自带规避。
- **代价**：**你给的 `w` 可能不被采纳**，图片实际宽度小于预留框 → 版面留白不均。
- **正确做法**：先按原图比例算出**目标框**（§5.2 公式），再把算好的 `w`/`h` 一起传入；不要只定 `w` 让工具去推 `h`。

### §6.5 保存后的文件内部落点（**验收脚本必读**）

经 editor_sdk 保存后，**包内路径与常规 Office 不一致**：

| 内容 | 常规 Office 落点 | **editor_sdk 保存后落点** |
|---|---|---|
| 图片媒体 | `ppt/media/` | **`ppt/slides/media/`** |
| 图表 | `ppt/charts/` | **`ppt/slides/charts/`** |

> **这是"媒体丢失"误判的唯一根因**：本次验证初次按 `ppt/media/` 统计，得到"media: 0"，**误以为图片全丢**；实际 12 项媒体完整存在于 `ppt/slides/media/`。
> ⇒ **验收 / 自检脚本统计媒体数时，必须同时扫 `ppt/media/` 与 `ppt/slides/media/`；统计图表扫 `ppt/slides/charts/`。**
> 另：`p:pic` 的变换在 `a:xfrm`，而 **`p:graphicFrame`（图表 / 表格）的变换在 `p:xfrm`** —— 用 `a:xfrm` 读图表几何会读不到。

### §6.3 配色

- 图表系列色**一律取自模板真实主题色**（`slide_get_themes` 或 `theme1.xml`），按系列顺序取；**禁止**用 Office 默认色板（`4472C4` 一族）。
- 中文语境下的**涨跌色**：涨用红、跌用绿（本团默认中国股市惯例；非金融场景不适用）。
- 图表背景默认**透明**（`transparent: true`），让模板底图透出；**不要**填白块盖住模板装饰。

## 七、质检员检查清单（并入四维·任务完成度 与 事实辨别性）

- [ ] 每页是否**至少 1 个非文字元素**？出现"全字页" = WARN；结构方案标了配图却缺失 = FAIL
- [ ] 每张图片的**来源级别**是否可查（P1–P5）？来源行是否齐全？无来源 = FAIL（**覆盖条款**：若用户要求"成品可独立使用"，上屏来源不再强制，改入**演讲者备注**或省略，由门禁 **A12** 逐页 FAIL 上屏来源，不由本项判 FAIL；见 `layout-selection.md` §1.3）
- [ ] 是否出现 **P5 未标注「AI 生成·非实拍」**？出现 = FAIL
- [ ] 是否出现**水印 / 变形 / 空占位框**？出现 = FAIL
- [ ] 图片是否**避让页层装饰**、是否压到文字？压到 = FAIL
- [ ] 图表数据是否可回溯到采集报告的 S 编号？无出处 = FAIL
- [ ] 图表系列色是否取自模板主题（非 Office 默认）？不符 = WARN
- [ ] 图注 / 数据来源文本是否齐全且字号为 T5 / T6？不符 = WARN（**覆盖条款**：同上，用户要求"成品可独立使用"时，上屏来源文本可移入备注或省略，本项不再据此判 WARN，改由 A12 守门）
- [ ] **图片是否已落地为本地文件**（非远程 URL）？早期实测传远程 URL 会报 `-32603` → 交付物中若含远程引用 = FAIL
- [ ] **媒体统计是否同时扫了 `ppt/media/` 与 `ppt/slides/media/`**？只扫前者会**漏掉**内嵌媒体、误得"媒体 0"（见 §6.5）→ 统计口径错 = 结论无效，不得据此判 FAIL
- [ ] 图片落位后是否**复核过实测 x/y/w/h**（`slide_get_page_info`）？未复核且声称"避让无冲突" = 不得通过
