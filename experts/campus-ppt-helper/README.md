# 校园演示帮手团（Campus PPT Helper Team）

覆盖**教学 / 答辩 / 实习 / 党建党政**四类场景的校园演示专家团，提供"信息采集 → 资料检索 → 结构策划 → 官方技能制作 → 四维质检"端到端协作。**广东财经大学（广财）师生开箱即用**（内置 10 套广财品牌模板）；**其他学校 / 单位**按 §三「学校适配与模板获取」的三条路径使用（自带本校模板 / 通用模板兜底 / 暂停索取本校模板）。

> 本专家团**不自带任何生成脚本**：PPT 文件一律由官方能力生成——**默认官方 `tencent-local-office-edit` 技能（模板保真，套用内置品牌模板）**；用户明确不要模板或无内置模板可用时，才走官方 `tencent-pptx`（风格重绘）或 WPS。安装包内不含 `.py` / `.js` / 构建产物，保证干净可分发。

## 二、工作流程

```
分诊（主理人）
  └─> 采集（采集员：browser-skill 爬虫，多源交叉；含配图/案例/图表数据）
       └─> 检索 + 结构（检索员定封装；设计师**先定页型与每页字数上限、再定逐页版式与节奏**，并标每页配图与案例需求）
            └─> 制作（制作员：调用官方视觉美化能力，产出 STORY.md + DESIGN.md；官方 tencent-pptx / WPS 生成；七级字号 + 版式轮换 + 配图/案例落位）
                 └─> 质检（质检员：四维质检，含版式轮换与视觉美化留痕 → 不通过则精修 → 复验）
```

顺序铁律：**先资料 → 后结构（先页型与字数上限、后版式）→ 再制作 → 最后质检**。资料没采全就定结构会偏题，**未定页型就写文案会让封面/目录/章节页失去页型**，结构没定就制作是给错误内容化妆，制作没完就质检无意义。

> **配图 / 案例 / 图表数据与文字资料同权限**：四类都是"资料"，必须在采集阶段采回并带出处，不得留到制作阶段"边做边找"。设计师的页面清单表必须填 `配图` 与 `案例` 两列（可填"无"，不得留空）。

## 三、学校适配与模板获取

分诊第一步：主理人会先问「**场景 + 学校 / 单位**」，再按下面的渠道与分支选择模板路径。

### 1. 模板获取渠道（如实声明）

| 渠道 | 说明 | 性质 |
|---|---|---|
| 腾讯文档「演示模板库」 | 15 套模板（广财族 10 套 + 党政族 5 套）统一托管于作者腾讯文档「演示模板库」；制作员经腾讯文档连接器**四级自适应取件**（本地缓存复用 → 直连导出 → 生成副本后导出 → 引导用户「另存为副本」）并下载到本地缓存 `~/campus-ppt-cache/` 后套用，**无需手动下载任何模板包**；包内仅含 15 套模板定位清单（`templates/gdufe-template-manifest.json`，内嵌模板 id 与链接），不随安装包分发二进制 | **唯一运行时模板源（必需）** |

### 2. 三分支决策

- **广财（广东财经大学）师生** → 直接使用内置广财族 **10 套（全量）**品牌模板（红色风景 01、蓝色风景 02、蓝绿风景 03/04/05、夜景深底白字 06、极简 07、蓝灰 08、蓝色设计空间 09、蓝色校园科技风 10），制作员经腾讯文档「演示模板库」自动取件套用，无需自备模板——**默认路径 B 模板保真**（`slide_duplicate_slide` 深拷贝模板页，保留 logo / 色块 / 母版视觉）。
- **其他学校 / 单位** → 按下述三分支处理。
  1. **已自备本校 / 本单位模板**：会话中直接提供本校模板 .pptx 文件 → 以本校模板制作。
  2. **没有模板且不需要品牌元素** → 以**中性通用模板兜底**出片（路径 A 风格重绘，不硬编码任何校徽 / 校色 / 校名），交付时**明示「未含本校品牌视觉」**。
  3. **要求品牌保真但没有模板** → 暂停制作，向用户索取本校模板后再继续。
- **党建 / 党政场景** → 内置党政族 **5 套通用党政模板**（党支部工作总结、主题党课、党纪学习教育、年终总结、三中全会通用），**任何单位均可用**，不限于广财。

**硬边界**：不虚构任何学校的品牌模板 / 校徽 / 校色 / 校名。选模板决策表见 `skills/campus-ppt-core/references/scenario-templates.md`。

### 3. 可直接抄的提示话术

- **广财师生**：「我是广财的学生/老师，帮我做一份《XX》课程的教学课件，用内置广财模板」。
- **其他学校有模板**：「我是 XX 学校的学生，我把本校模板 .pptx 文件发给你，按本校模板帮我做答辩 PPT」。
- **其他学校无模板（通用兜底）**：「我是 XX 学校的，没有本校模板也不需要校徽校色，用通用模板帮我做课程汇报 PPT，并注明未含本校品牌视觉」。
- **其他学校要保真**：「我需要和我校官方模板完全一致的视觉，但我手头暂时没有模板文件，请告诉我怎么提供」。
- **党政单位**：「我们是单位党务部门，用内置党政模板做一份党支部年度工作总结 PPT」。
- **实习求职**：「帮我做一份求职 / 述职 / 实习汇报 PPT，用职场风格模板」。

**"套模板"的两种口径（务必分清）**：官方 `tencent-pptx` 技能对模板的处理是**提取风格**（配色 / 字体 / 版式结构），最终以空白稿重画，**不继承模板母版 / 版式 / 页层视觉**；若用户要求**模板保真**（"看起来就是我们单位那套模板"，logo / 色块 / 装饰都在），改走官方 `tencent-local-office-edit`（本地编辑器，`slide_*` 工具，以模板 .pptx 为底稿、**`slide_duplicate_slide` 深拷贝模板页**）。两条路径的选择规则与可执行步骤见 `skills/campus-ppt-make/references/template-application.md §〇`。

## 三之二、外部依赖连接登记（引用 ≠ 连接）

本团正文引用的外部能力（官方技能、连接器、外部工具、模板源）已在共享参考库（1.0.2 起按角色拆为 `campus-ppt-core / collect / media / design / make / qa` 六个小技能包）**全量登记**。**写了名字只算"引用"**；只有登记了「真实位置 + 可执行预检 + 判读口径 + 缺失降级」四项才算**"已建立连接"**；**未登记的外部依赖名视为未连接，按缺陷处理**。

- 全量登记见 `skills/campus-ppt-make/references/external-dependency-registry.md`：**24 项外部依赖总表** + **五张预检连接卡** + 模板获取流程（腾讯文档导出）+ 未连接引用定级。
- **出片第 0 步是强制预检**：制作员工作流第 1 步已插入该步骤，**四卡未全过不得出片**。

> **依赖连接状态**：已登记 **24 项**外部依赖，其中 **22 项已连接**；未连通 2 项均为「模板转图 / 离线出图」的备选通道（本机未装对应渲染组件），主用的逐页出图通道（官方编辑器渲染）正常，**不影响出片**。
> **模板库规模**：腾讯文档「演示模板库」共 **15 套**（广财族 10 套 + 党政族 5 套；14 套 960×540pt、广财-07 为 720×405pt），由制作员取件到本地缓存 `~/campus-ppt-cache/` 后套用。
> **路径 B 模板保真链路现已可用。**

## 四、启用方式

1. **普通对话调用**：直接在 WorkBuddy 中 @ 本专家团或描述 PPT 需求，主理人会分诊并调度。
2. **复杂 / 跨域任务开启团队协作**：当用户任务跨域或复杂（例如"采某课程资料 + 定结构 + 出 30 页课件 + 质检"）时，主理人会**明确建议开启"智能体团队管理 / 多智能体协作"**，并说明开启路径。
   - 在 WorkBuddy 设置或会话入口启用"智能体团队管理（多智能体协作）"后，主理人即可通过 TeamCreate 建立团队并调度成员。
   - 若运行环境**未提供** TeamCreate / Agent 工具（如被当作独立专家直接调用），每位成员按降级规则**自行完成并直接输出成品**，不会出现"无法建团队"类噪音。

> 覆盖升级与回滚步骤见 `UPGRADE.md`。

## 五、边界与红线

- **不虚构**：资料、数据、配图、案例均须有真实出处；**不虚构任何学校的品牌模板 / 校徽 / 校色**——广财模板为内置事实，其他学校 / 单位的品牌模板须用户自备，本团一律不编造。
- **通用兜底须明示**：为没有模板的学校 / 单位以中性通用模板出片时，交付说明必须明示「未含本校品牌视觉」，不得暗示使用了该校官方视觉。
- **配图不虚构**：优先真实来源；AI 生成图仅作兜底，且必须标注「AI 生成·非实拍」；禁止用 AI 图冒充真实照片，禁止使用带水印或无署名的 L4 图。
- **案例不虚构**：只允许可溯源真实案例（L1–L3）；采不到标「待补充」并回传，**不得编造**，也**没有 AI 生成兜底档**（AI 生成的"案例"就是编造）。
- **字号不拍脑袋**：指令中的每一级字号必须可追溯到该套模板的实测值（`skills/campus-ppt-make/references/body-typography-standard.md` 附录 A），写通用值视为违规。
- **视觉美化不许只声明依赖**：必须真调用官方视觉设计能力，交付物须含 `STORY.md`（逐页 layout/role/rhythm/visual_role/anti_pattern）与 `DESIGN.md`（设计分支 + A/B/C 三区 px + 密度/留白/配色硬指标）；缺任一份即判未调用。
- **版式不许虚假承诺**：路径 B 下版式数受模板限制（实测单套 1–14 种、平均 7.6 种），版式种数不足计划页数时应**换模板 / 改路径 A / 明示会重复**三选一，不得口头承诺"每页不同版式"却交付重复版式。
- **外部依赖不许只声明**：引用官方技能 / 工具 / 资料库时，必须在 `external-dependency-registry.md` 登记真实位置与预检命令；**未登记 = 未连接**，按缺陷处理。新增依赖须同批更新四处（登记表总表 → 连接卡 → README 前置依赖清单 → CHANGELOG）。
- **破坏性操作先备份**：覆盖原文件、压缩媒体、批量替换模板前，制作 / 质检须提醒先备份。
- **P0 红线（交付物层面）**：禁 emoji 图标装饰、禁 AI 模板套路（渐变 / 发光 / 毛玻璃）、禁 Lorem ipsum 占位、禁硬编码色值、禁弹跳缓动（本条约束**交付的 PPT**；团队自身 Markdown 文档中的箭头/序号/分隔符不算装饰图标）。
- **干净打包**：安装包仅含成员定义、共享参考库、头像图片、15 套模板定位清单与必需配置文件（纯文档 + 图片，不含任何脚本与构建产物）；模板二进制经腾讯文档「演示模板库」在线获取，不随安装包分发。
