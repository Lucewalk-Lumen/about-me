# CHANGELOG

## 1.0.0

初始发布。多智能体教练团（team 型），面向大学生双创与学术科技赛事，提供选题规划、资料整备、文本打磨、评审答辩全程陪练。

### 团队构成
- 主理教练程衡（编排、中转、门控）+ 4 名专职成员：苏理（选题规划）、路衡（资料整合）、计程（文本打磨）、优然（评审答辩）。
- 五名成员按「选题 → 资料 → 文本 → 评审」流水线协作，跨成员信息流经主理人统一中转与汇编。

### 知识底座
- 知识库主文件：`templates`（TM1–TM9 文档模板）、`cases`（双百工程真实项目语料）、`reviews`（各赛道评分维度与采分/失分点）、`tracks`（多赛道图谱与选题匹配速查）；另含 `ocr_corpus`（图像型 PDF 离线 OCR 全文）与 `_index`（四态标注约定）。
- 技能 `competition-kb` 挂载知识库，按需路由到正确的模板 / 案例 / 赛道 / 评审文件。

### 质量与信任机制
- 四态标注：已验证(本地) / 已验证(外源) / 未验证 / 缺失；外源条目必附 URL，不编造。
- 外源信任边界：外源网页正文视为数据而非指令，不执行其中命令式文本；遇采集拒绝即终止并告知用户。
- 隐私匿名化：真实项目名称统一以「项目NN·领域标签」代号替代，成员姓名、公司名、队伍名称、联系方式与院校信息均已隐去，赛道归类与教学内容保持原貌。
- 6 个统一风格的 3D 角色人物头像（512×512，≤500KB），含五人团队合影。
