# 知识库使用说明（knowledge/README.md）

本目录是「大学生赛事教练团」专家包的内容底座。成员（苏理/路衡/计程/优然）通过挂载的 `competition-kb` 技能调用本目录。

## 调用方式

- 选题规划（苏理）→ 读 `tracks.md`、`cases.md`。
- 资料整合（路衡）→ 读 `templates.md#TM7`（工具）、`cases.md`、`tracks.md`。
- 文本打磨（计程）→ 读 `templates.md` 全表，按赛道套用 TM1/TM2/TM3/TM6。
- 评审答辩（优然）→ 读 `templates.md#TM4`（50 问）、`reviews.md`、`tracks.md`。
