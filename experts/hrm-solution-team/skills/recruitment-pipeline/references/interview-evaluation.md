# Five-Dimension Interview Evaluation

> 标准定义：候选人五维评分算法、决策矩阵、报告格式。引用方：recruitment-pipeline。

## 评估输入

1. JD 文字 → 解析岗位要求（名称/级别/薪资范围/必需技能/加分项/年限）
2. 简历（PDF/Word）→ 解析候选人信息
3. 面试记录（可选）→ 面试官评价

## 五维评分

| 维度 | 权重 | 评分标准 |
|------|:----:|---------|
| 技术能力 technical | 25% | JD 技能 vs 候选人技能掌握度 |
| 专业经验 professional | 20% | 年限、行业、项目规模匹配 |
| 学习能力 learning | 20% | 成长速度、技术广度、主动性 |
| 岗位匹配 role_fit | 20% | 职责理解、文化契合、薪资匹配 |
| 稳定性 stability | 15% | 跳槽频率、职业规划清晰度 |

## 综合得分计算

```python
weights = {
    'technical': 0.25, 'professional': 0.20, 'learning': 0.20,
    'role_fit': 0.20, 'stability': 0.15
}
overall = round(sum(score[dim] * weights[dim] for dim in weights), 1)
```

## 决策矩阵

| 综合评分 | 风险 | 建议 | 说明 |
|:--------:|:----:|------|------|
| ≥ 8.0 | 低 | 建议录用 | 优质候选人，尽快 Offer |
| 7.0-7.9 | 中 | 条件录用 | 基本合格，有条件通过 |
| 6.0-6.9 | 中 | 条件录用 | 有短板，需谨慎评估 |
| < 6.0 | 高 | 不建议录用 | 不符合要求 |

**条件录用典型情形**：评分 7.0-7.9 有可改进短板 / 个别技能可培训补足 / 期望薪资需协商 / 管理经验不足但技术优秀 / 试用期需重点考察。

## 报告结构

```markdown
## 面试评估报告 — [候选人]
### 岗位信息（名称/薪资范围/要求年限）
### 候选人信息（姓名/学历/年限/当前职位）
### 五维评分表（维度/评分/说明）
### 综合评分（X.X/10）
### 风险评估（绿/黄/红 + 具体项）
### 录用建议（类型 + 综合判断 + 匹配度分析 + 录用条件 + 试用期考察重点）
```

## 星级映射

| 分数段 | 星级 |
|--------|------|
| 9-10 | 5/5 优秀 |
| 7-8.9 | 4/5 良好 |
| 5-6.9 | 3/5 一般 |
| 3-4.9 | 2/5 较差 |
| 1-2.9 | 1/5 差 |

## 使用纪律

- 先解析再评分，不凭印象打分
- 评分必须附说明文字（为什么给这个分）
- 录用建议只是建议，最终录用决策属于人类 DRI
- 涉及薪酬承诺转交 compensation-strategy
