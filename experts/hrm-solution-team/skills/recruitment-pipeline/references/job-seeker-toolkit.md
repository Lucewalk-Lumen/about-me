# 求职者侧工具集（Job-Seeker Toolkit）

> 标准定义：面向求职者（候选人）的一站式求职方法论——简历优化、简历自评量规、JD 技能匹配、求职信、面试准备、薪资谈判、Offer 对比、求职追踪、电梯演讲、跟进邮件、模拟面试。引用方：recruitment-pipeline（路由关键词已含 写简历/美化简历/面试准备/模拟面试）。
>
> 适用场景：用户以「求职者」身份发起请求（优化我的简历 / 帮我模拟面试 / 谈薪资 / 对比 Offer / 写求职信 / 做职业决策）。

## 1. 概述

本笔记补足本团「雇主视角」主导能力之外的**候选人视角**工具集，使 recruitment-pipeline 在收到求职者侧请求时也能给出专业输出。覆盖：简历优化 + 面试陪练 + 薪资谈判 + 职业规划 + 10 维度简历自评 + JD 匹配 + 求职信 + Offer 对比 + 求职追踪 + 电梯演讲 + 跟进邮件 + 分轮模拟面试。

**核心理念**：站在候选人一边把「从简历到 Offer」跑通；所有输出须与雇主侧标准（ATS 友好、STAR、量化）对齐，避免教候选人"绕过硬指标"。

## 2. 简历优化（与 `resume-guidelines.md` 衔接）

- **三大原则**：STAR 法则（情境-任务-行动-结果）/ 数据化（"提升 30%" 优于"业绩好"）/ 关键词匹配 JD 过 ATS
- **结构顺序**：个人信息 → 求职意向 → 核心优势(3-5) → 工作经历(倒序,STAR) → 项目经历(STAR) → 教育 → 技能证书
- **交付模板**：`templates/resume-template.md` + `templates/resume-template.html`（ATS 友好版式，投递存 PDF，文件名 `姓名_岗位_简历.pdf`）
- **量化纪律**：每条成就以动词开头 + 具体行动 + 量化结果；避免"优秀的/热情的"等主观形容词

## 3. 简历自评量规（10 维度 / 100 分，S~D 等级）独特

> 与雇主侧 `resume-quality.md`（R1-R5 诊断）互补：本量规供**候选人自我体检**，维度更细、可自测打分。

| # | 维度 | 权重 | 评分要点 |
|---|------|------|---------|
| 1 | 联系信息完整 | 10 | 电话/邮箱/可点击链接齐全且无错 |
| 2 | 求职意向清晰 | 10 | 目标岗位+城市+到岗时间明确 |
| 3 | STAR 覆盖度 | 12 | 关键经历是否 STAR 化、有结果 |
| 4 | 量化程度 | 12 | 百分比/数量/时间等可验证数字 |
| 5 | 关键词匹配 | 12 | 与目标 JD 核心词命中率 |
| 6 | 结构逻辑 | 10 | 倒序、层级清晰、无断档 |
| 7 | 技能呈现 | 8 | 精通/熟悉/了解分级 + 证书 |
| 8 | 教育相关 | 6 | 专业相关课程/荣誉突出 |
| 9 | 排版整洁 | 5 | 一页(应届)/1-2 页(有经验)、无错字 |
| 10 | 成果聚焦 | 5 | 个人贡献可区分、非团队笼统 |

- **等级**：≥90 S / 80-89 A / 70-79 B / 60-69 C / <60 D
- **输出**：逐维得分 + 最弱 2-3 维改进建议（回链 `resume-guidelines.md`）

## 4. JD 技能匹配 / 差距分析 独特

输入：目标 JD 文本 + 候选人简历 → 输出：

```
| 技能要求 | JD 要求 | 简历匹配 | 缺口 |
|----------|---------|----------|------|
| 技能A | 必需 | [OK] 有项目佐证 | — |
| 技能B | 必需 | [!] 提及无佐证 | 补项目/证书 |
| 技能C | 加分 | [X] 缺失 | 评估是否硬伤 |
```

- 区分「必需 vs 加分」，避免候选人盲目补无关技能
- 对"投了没回复"痛点：先用本分析定位匹配度 < 60% 的岗位，优先补强或调整投递策略
- 匹配度 ≥ 80% 的岗位，输出"面试准备重点"衔接 §5

## 5. 面试准备

### 5.1 高频问答模板

| 问题 | 结构 | 红线 |
|------|------|------|
| 自我介绍(1-2min) | 我是谁+做过什么+带来什么+为什么选你 | 不超时、紧扣岗位 |
| 优点 | 选 3 个岗位相关优点，各用案例支撑 | 避免空泛形容词 |
| 缺点 | 真实非致命缺点+正在改进+效果 | 不暴露岗位硬伤 |
| 离职原因 | 职业发展/寻求挑战/行业变化（正面） | 不抱怨前司/薪资/人际 |
| 薪资期望 | "据经验与市场，范围 X-Y；更看重平台，可协商" | 不先亮底牌 |

### 5.2 行为面试（STAR 实战）

- 公式同 §2；每个项目追问 PEARL（问题-顿悟-行动-结果-学习）与"还有吗？"收尾
- 必含「最大失败」反思题，看成长型思维
- 区分"表达结构化"与"内容有深度"，不被话术骗

### 5.3 情景/技术题

- 回答框架：背景→方案选择(对比)→实施→结果(量化)→反思
- 应急：快速止损→信息收集→定位→解决→复盘预防

### 5.4 模拟面试（分轮，10 题/轮）独特

| 轮次 | 重点 | 陪练要点 |
|------|------|---------|
| HR 轮 | 动机/文化匹配/稳定性 | 自我介绍+优缺点+离职+职业规划 |
| 技术轮 | 专业深度+实战 | 按岗位技术栈抽 10 题+项目深挖 |
| 终面 | 战略/潜力/价值观 | 业务理解+反向提问设计 |

- 每题给：考察点 + 参考回答要点 + 常见误区 + 难度
- 陪练后输出「做得好 / 待改进 / 下一步行动」复盘卡

## 6. 薪资谈判

- **四原则**：先摸市场（多渠道行情）/ 让对方先开价 / 综合看 package（月薪+年终+股票+福利）/ 有备选更从容
- **话术**：对方先开价→"据经验与市场我期望 X-Y，考虑到核心价值是否有空间"；压价→"若月薪难调，年终或股票可否补偿"
- 锚定依据：回链 `compensation-band.md` 市场对标 + §3 自评

## 7. Offer 对比（决策矩阵）独特

```
| 维度 | Offer A | Offer B | 权重 |
|------|---------|---------|------|
| 年薪总包 | | | 30% |
| 成长空间 | | | 25% |
| 业务/岗位价值 | | | 20% |
| 团队/上级 | | | 15% |
| 工作生活 | | | 10% |
```

- 输出加权总分 + 非量化因素提示（如通勤、稳定性）
- 谈判未决项单列，回链 §6

## 8. 求职信 / 电梯演讲 / 跟进邮件 独特

- **求职信**：开场表明岗位+来源 → 1 段核心匹配经历(量化) → 为什么是这家公司 → 行动呼吁；中英双语可选
- **电梯演讲(30-60s)**：我是谁+我能解决什么问题+差异化；用于社交/内推场景
- **跟进邮件**：面试后 24h 内发感谢信，引用具体话题显诚意；模板见 `../templates/interview-prep-template.md` §七

## 9. 求职追踪（Application Tracker）

- 本地结构化记录：`公司 | 岗位 | 状态(投递/笔试/面试/Offer/拒) | 时间 | 下一步`
- 状态机：投递→笔试→一面→二面→终面→Offer/归档；超时未跟进自动标"待行动"
- 目的：避免"投了没回复"黑箱，支撑 §4 匹配度复盘

## 10. 职业决策框架

- 六因素加权：行业前景 / 公司发展 / 岗位价值 / 薪资福利 / 学习成长 / 工作生活
- 阶段权重：早期(0-3y)学习成长>行业>薪资；中期(3-7y)岗位价值>薪资>公司；后期(7y+)行业>公司>工作生活
