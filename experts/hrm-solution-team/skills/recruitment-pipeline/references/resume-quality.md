# Resume Quality Diagnosis R1-R5

> 标准定义：简历诊断五阶段流水线。引用方：recruitment-pipeline。

## 流水线总览

```
R1 AI痕迹检测 → R2 诊断评分 → R3 JD匹配解读 → R4 STAR改写 → R5 ATS优化+报告
```

## R1：AI 痕迹检测与拦截

**8 大特征**（命中 4+ 即拦截，标记"疑似 AI 生成，需人工复核"）：
1. 模板化措辞（"本人具备良好的…能力"高频复用）
2. 空洞形容词堆砌（无量化支撑的"卓越/丰富/深入"）
3. 缺乏具体数字与结果（只有职责没有成果）
4. 句式高度对称工整（排比泛滥）
5. 通用技能罗列（与岗位无关的技术清单）
6. 缺失时间线或时间线矛盾
7. 项目描述无 STAR 结构（无情境/任务/行动/结果）
8. 语言风格突变（前后不一致）

## R2：6+4 维诊断评分

**6 个基础维度**（各 0-10 分）：
1. 内容完整性（教育/经历/技能/联系方式是否齐全）
2. 量化程度（数字、百分比、规模的使用密度）
3. 成果导向（是否写结果而非职责）
4. 语言精炼度（冗余词占比）
5. 逻辑一致性（时间线、职位递进）
6. 关键词覆盖（与目标岗位关键词匹配）

**4 个岗位权重维度**（按目标岗位调整）：
1. 技术栈匹配
2. 行业经验
3. 职级匹配
4. 稳定性信号

**评分规则**：基础维度平均分 × 0.6 + 岗位权重维度平均分 × 0.4 = 诊断总分（0-10）。

## R3：JD 匹配解读

- **布尔逻辑**：必需项（AND）与加分项（OR）分别计算命中率
- **三级分类**：满足 / 部分满足（有替代经验）/ 不满足
- **可视化**：按能力项输出匹配度条形

## R4：STAR 改写与去 AI 化

**STAR 结构**：Situation（情境）→ Task（任务）→ Action（行动）→ Result（结果，带量化）。

**去 AI 化替换表**：
| 高频 AI 痕迹词 | 改写方向 |
|----------------|---------|
| 具备良好的…能力 | 具体到工具/方法/成果 |
| 负责…相关工作 | 主语明确 + 动词 + 结果 |
| 积累了丰富的经验 | 量化：主导 N 个项目 |
| 熟练掌握 | 给出使用年限/深度等级 |
| 团队合作能力强 | 举例：跨部门协调 N 方 |

## R5：ATS 格式优化与报告

- 标准字体、无表格/图片（ATS 解析友好）
- 时间倒序、明确职位头衔
- 关键词对齐 JD（技能名原样出现）
- 输出 Word 诊断报告（分维度得分 + 改写建议 + 优化后版本）

## 使用纪律

- **不得跳过 R1 直接评估**：疑似 AI 简历必须先拦截再评分
- 改写保留候选人真实经历，不编造成果
- 诊断报告须给出可执行修改点，不空泛打分
