# China Labor Compliance Baseline (25+ topics)

> 标准定义：劳动人事合规诊断主题范围、法规基线来源、风险分级。引用方：labor-compliance。
> 注意：基线版本日期为 2026-07。法规会更新，形成最终法律结论前须核验最新全文、效力状态、生效日期与地方适用性。

## 覆盖主题（25+）

劳动合同 / 书面合同 / 试用期 / 工时 / 休息休假 / 加班工资 / 工资支付 / 最低工资 / 社会保险 / 工伤保险 / 带薪年假 / 女职工保护 / 员工手册 / 公示程序 / 民主程序 / 解除终止 / 经济补偿 / 竞业限制 / 保密 / 劳务派遣 / 招聘 / 就业歧视 / 医疗期 / 平台用工 / 劳动争议 / 证据留存

## 法规基线来源（官方白名单）

- 国家法律法规数据库（flk.npc.gov.cn）
- 国家行政法规库
- 人力资源和社会保障部（MOHRSS）
- 最高人民法院 / 最高人民法院公报

## 支持格式与模式

- 格式：PDF（文本层）/ DOCX / TXT / Markdown / CSV / JSON
- 模式：单文件、批量（`--batch`）、递归目录（`--recursive`）、路径清单（`--input-list`）
- PDF 必须为文本层；扫描件/纯图片需先 OCR（当前不内置 OCR）

## 风险分级

| 级别 | 含义 | 动作 |
|------|------|------|
| **P0** | 致命/紧急：法定冲突、条款无效 | 立即暂停、升级、整改 |
| **P1** | 高：法定合规冲突、行政监管或重大劳动争议暴露 | 标记整改 + 条款改写 |
| **P2** | 中：程序/证据/地方适配/措辞不清 | 警告 + 建议优化 |
| **P3** | 低：优化或清晰度问题 | 通过 + 记录 |
| **Info** | 监测提醒或背景提示 | 记录 |

## 高风险事项（必须法务复核，标记 `legal_review: "required"`）

解除终止 / 裁员 / 竞业限制 / 孕产期员工 / 工伤 / 医疗期 / 劳务派遣 / 集体争议

## 文档类型范围

劳动合同、员工手册、薪酬制度、考勤制度、奖惩制度、保密协议、竞业限制协议、劳务派遣文件、平台用工协议。

## 交叉校验职责

| 来源 Agent | 校验点 |
|-----------|--------|
| 招聘管道 | 录用条件合法（试用期≤6月、无就业歧视条款） |
| 绩效评估 | PIP/不胜任解除是否满足法定程序 |
| 薪酬策略 | 工资支付/加班费/社保基数是否合规 |
| 组织规划 | 裁员方案是否满足法定程序 |
| 人才发展 | 培训协议/服务期条款是否符合劳动法 |

## 使用纪律

- **不得编造**法规条文编号、官方 URL、生效日期或法律引用
- 文本提取不完整时诊断必须标记为"初步结果"
- 地方规则可能有差异时标记"需要地方适配"
- 不提供规避法定义务的条款
