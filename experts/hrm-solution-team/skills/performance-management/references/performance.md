# Performance System Design (KPI/OKR/Calibration)

> 标准定义：绩效体系设计、评估流程、强制分布校准。引用方：performance-management。

## KPI 设计（SMART 五维验证）

- Specific 具体 / Measurable 可量化 / Achievable 可实现 / Relevant 相关 / Time-bound 有时限

## OKR 设计（O + 3×KR）

```
Objective：鼓舞人心的方向
KR1 / KR2 / KR3：可量化的关键结果
```

## 固浮比参考

| 人群 | 固定 | 浮动 |
|------|------|------|
| 普通员工 | 80% | 20% |
| 销售人员 | 60% | 40% |
| 高管 | 50% | 50% |

## 评估流程

1. **启动自评**：关键成果（STAR）+ 目标回顾（达成/超越/未达）+ 成长与挑战 + 下周期目标
2. **经理评估**：整体评级（1-5）+ 优势（附事例）+ 发展领域（附指导）+ 发展计划（技能/当前/目标/行动）
3. **校准会准备**：评级分布 vs 公司目标 + 晋升候选人名单（姓名/当前级别/提议级别/理由）
4. **反馈原则**：具体 / 聚焦行为非性格 / 发展计划可执行

## 强制分布目标

| 评级 | 占比目标 |
|------|---------|
| 5 卓越 | ~5% |
| 4 优秀 | ~20% |
| 3 达标 | ~60% |
| 2 待改进 | ~10% |
| 1 不达标 | ~5% |

## 校准输出

```markdown
## 绩效校准 — [团队] — [周期]
### 评级分布
| 评级 | 人数 | 占比 | 公司目标 |
### 晋升候选人
| 姓名 | 当前级别 | 提议级别 | 理由 |
```

## PIP 触发

- 绩效评估为"不达标"时输出 PIP 触发标志
- 生成绩效改善计划建议
- **标记"需劳动合规 Agent 审查"**（PIP/不胜任解除涉及法定程序）

## 使用纪律

- 不对个人输出"开除"建议（仅 PIP 标志 + 转 labor-compliance）
- 不将绩效评级直接与薪酬挂钩（转 compensation-strategy）
- 反馈聚焦行为而非性格
