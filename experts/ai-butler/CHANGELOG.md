# 变更日志 · 教师工作台

> 本文件格式遵循 CodeBuddy 官方更新日志规范；版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## 1.1.4 版本发布 🚀（2026-10-02）

一次以**安全加固**为主的小版本升级：修复三处可被利用的注入缺陷、补齐纵深防御、并清理若干实现层瑕疵。**无数据结构变更、无接口变更、无用户可见功能变更**，可直接覆盖更新；仍建议先在「设置 → 导出 JSON」备份。

### 新增

- **版本更新播报**：线上更新后您再次召唤时，管家会主动告知本次改了什么；同一版本读过一次后不再重复打扰。

### 修复

- **标签可触发脚本执行（高危）**：给任务、分类打标签时，标签文字里的引号等字符没被正确转义，构造出的标签在点击时可能执行任意脚本，含撇号的正常标签（如 `O'Brien`）也会报错、筛选失效。现已按不同场景分别正确转义，含引号与括号的标签也能正常点击。
- **云同步可被投毒执行任意脚本（高危）**：从云端拉取数据时，部分本机专属配置（含云同步地址与校历附件）曾被整包接受，任一掌握同步口令的设备（或弱口令被离线爆破）都能借此让受害者在下次保存时加载攻击者脚本，且该页与本地桥同源、可读到桥凭据。现改为**逐项只保留本机配置**，敏感项一律不从云端继承；校历附件改为隔离运行且只接受图片。
- **分类名可触发脚本执行**：分类名可随云同步进入，此前部分显示位置未转义。现已在各处显式转义，并对分类名称与颜色做导入侧收敛（长度、去危险字符、颜色白名单），云端拉取后同样净化一次。
- **多项可编辑字段显示未转义**：任务估时与实际用时、顺延次数、原定日期、优先级显示这几处由您编辑或可经导入/同步进入的字段直接拼进页面，异常内容可能破坏显示或注入。已统一转义，优先级另加白名单归一。

### 优化

- **新增内容安全策略作为第二道防线**：桥在同源托管工作台时下发安全策略，禁止嵌入与基址劫持、限定框架来源；仅放开 https（供您自配的云同步使用）与同源，未配置云同步时不加载任何外部脚本；网络连接仅放行本机回环与（可选）https 云端；已逐条对照工作台真实请求与显示方式核对，不会误伤既有功能。
- **云同步口令强度提升**：口令派生迭代次数由 12 万提升至 60 万（OWASP 对该算法的建议下限），提高离线爆破成本；旧云端密文按其随包记录的迭代值解密，**升级不影响既有数据**。
- **桥写入鉴权改为恒定时间比较**：写请求的令牌校验此前用普通字符串比较，现与读接口、签名校验一致，消除计时侧信道。
- **桥注入工作台的凭据改用安全转义**：注入前先做一次转义兜底，即使将来凭据来源变化也不可能跳出脚本字符串。
- **审计日志性能优化**：此前每个请求落审计时都会重新施加一次文件权限（Windows 下等于每次都额外调用一次系统命令），属无谓热路径开销；现改为在加固**成功时**才记为已完成，仅首次创建时施加一次；失败则保留重试（不静默放弃加固），兼顾性能与安全。
- **原子写精简一次冗余权限操作**：临时文件在改名后即被丢弃，对其单独加固是多余的；保留对最终文件的加固即可。
- **限流窗口提取为常量**，消除散落的魔法数字；注释与实现对齐（审计实际覆盖读/写/拒绝/凭据操作）。

### 规范

- 版本号全域对齐 1.1.4（清单 / 运行时 / 元数据 / 界面 / 缓存）。
- 更新日志改为官方 CodeBuddy 格式，历史条目一并重写。

> 本版所有改动均向后兼容：云端密文、桥协议、自动化模板、工作台数据格式均无变化，老用户覆盖更新即可。

## 1.1.3 版本发布 🚀(2026-09-25)

### 修复

- 管家指令正文超出平台长度上限被静默截断，导致「对话式速记」等段落实际从未生效；现拆为「正文 + 分片」，长细则移入 `references/` 按需读取。
- 桥启动日志无条件宣称文件权限已加固，而 Windows 上这一说法并不成立；现如实报告加固结果。
- 版权声明与本包 MIT 许可冲突，现与许可文件对齐。
- 工作台多处可交互元素键盘无法触达，现补齐 `tabindex` / `role` / `aria-label`。
- 浅色主题下主按钮白字对比度不足；现加深配色，各主题文字对比度均达 WCAG AA 正文级。
- 本地桥生成凭据时未走原子写，与数据文件不一致，现统一。
- 清理随文件分发的开发信息与过时表述；消除重复内容；清理无引用者的死代码。

### 新增

- 全局键盘操作：`Ctrl`/`⌘+K` 或 `/` 聚焦搜索、`Esc` 逐层关闭浮层、`Enter`/`Space` 激活可点元素。
- 无障碍：`aria-live` 播报区、地标角色、勾选框状态同步、尊重系统「减少动态效果」偏好。
- 本地桥响应补齐安全响应头。
- README 新增「相关文档」入口。
