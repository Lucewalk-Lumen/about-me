# Teacher Workbench

> 版本与变更历史见 [CHANGELOG.md](CHANGELOG.md)。

通用 AI 专家：为高校教师提供**教师工作台**——上课、会议、科研与日常办公事务一屏打理（纯本地单文件 HTML，离线可用、PWA 安装、默认零云端；单 Agent 专家包，附 WorkBuddy 插件清单；跨平台）。

> **前置条件**：本地桥依赖 **Node ≥ 18**（`node -v` 可查）。未安装时工作台仍可离线打开，但播报、速记回写与自动化等需桥的能力不可用。

## 这是什么

一个通用 AI 专家（单 Agent 专家包，附 WorkBuddy 插件清单）。载入后在对话中说「打开我的工作台」即可唤起管家；工作台 HTML 随本包分发（`assets/teacher-workbench.html`），无需联网、数据存于浏览器 localStorage。覆盖办公、上课、会议、科研等日常场景，一个工作台全打理。

## 核心能力

- **四大栏目**：今天待办、灵感速记、项目跟进、每周复盘
- **任务管理**：全字段编辑、全局搜索、灵感一键转任务、深色模式
- **AI 自动化**（WorkBuddy 平台集成）：每日晨间播报 / 每周周报 / 备份提醒
- **数据安全**：JSON 导出/导入、容量预警、v1→v2 无损迁移
- **教学日历**：学期设置、文本/图片/PDF/.ics 导入，任务显示「第 N 周」
- **个性化**：8 主题、8 图标、10 背景、8 页头装饰、分类管理
- **PWA 离线**：manifest + service worker + 图标，可「添加到主屏幕」

## 单文件一体化

工作台为**一枚 HTML 文件**（`assets/teacher-workbench.html`）：

- **默认纯本地离线**：数据存浏览器 localStorage，**零网络请求**。
- **推荐打开方式（安全）**：先启本地桥 `node bridge/teacher-workbench-bridge.js`，再访问 **`http://127.0.0.1:18765/`**。桥会**同源托管工作台**，localhost 为浏览器安全上下文、`crypto.subtle` 可用（桥签名 / 云同步 E2E / 向量时钟全部生效），且强 token 由服务端注入页面、无需跨源暴露；读接口（`/latest` `/inbox` `/db`）须带 `Authorization: Bearer <token>`，`GET /token` 仅作回环兜底、首次引导返回当前强 token（同源托管主路径已由服务端注入，无需跨源获取；引导后不再回吐）。
- **也可直接打开**：双击 `assets/teacher-workbench.html`（`file://`）。此时 Chrome 下 `crypto.subtle` 可能为 `undefined`（安全上下文限制），桥签名 / 云同步 / 向量时钟将自动降级（数据仍通过本地桥落盘），如需完整安全能力请改用上面的桥同源地址。
- **可选云同步**：在「设置 → 云同步」填写 CDN/SDK 地址与环境 ID 即激活多设备同步；未配置时完全离线。
- 云同步 SDK 按需从用户提供的地址加载，不随包分发。

## 设计语言（视觉规范）

图标采用「胶囊 + 记忆」语义，与工作台整体设计系统（青绿→蓝渐变、圆角、柔和层次）保持一致：

- **胶囊（capsule）**：白色竖向圆角胶囊，象征「任务 / 数据的封装容器」。
- **记忆（memory）**：胶囊中央的青绿书签（bookmark）标记，象征 AI 对用户偏好、输入与历史的记忆与召回。
- **品牌渐变**：背景沿用 `#0f766e → #0891b2` 青绿到蓝的线性渐变，保持产品识别度。
- **输出尺寸与适配**：
  - `icon-192.png`（192×192，PWA）
  - `icon-512.png`（512×512，PWA）
  - `icon-maskable-512.png`（512×512，全幅背景 + 中央安全区，适配各启动器遮罩）
  - `apple-touch-icon.png`（180×180，iOS 主屏幕）
  - `icon.svg`（矢量源，作 favicon，小尺寸更清晰）

## 使用方式

1. **对话唤起**：说「打开我的工作台」「今天有什么待办」「帮我出周报」等 → 管家用默认浏览器打开工作台（跨平台 `open`/`start`/`xdg-open`，localStorage 全功能可用）。如需完整安全能力（桥签名 / 云同步 E2E / 向量时钟），建议经 `http://127.0.0.1:18765/` 同源访问（先启本地桥）。
2. **自动化**：说「开启每日晨间播报」→ 管家在 WorkBuddy 平台创建定时自动化。
3. **数据操作**：所有数据在工作台内完成（localStorage 自动保存）；备份导出 JSON 文件。
4. **安装为 APP**：浏览器 / WorkBuddy 内「添加到主屏幕」，获得独立 PWA 体验。

## 安装与跨平台

- **通用专家（含插件清单）**：本包以 `.codebuddy-plugin/plugin.json` 声明版本、显示名与挂载关系，同时保留 `package.json` + `agents/ai-butler.md` 描述版本与行为，可作为通用单 Agent 专家载入兼容运行时，也可经标准插件清单接入插件市场。
- **跨平台运行（需 Node ≥ 18）**：工作台为单文件 HTML（任意浏览器）；本地桥为零依赖 Node 脚本，须已安装 **Node ≥ 18**（`node -v` 可查）。macOS / Linux 可直接运行，Windows 需 WSL / Git-Bash 等 POSIX 兼容环境（管家自启脚本依赖 `curl` / `lsof` / `kill` / `nohup` / `uname`），或手动执行 `node bridge/teacher-workbench-bridge.js`。桥自身路径统一用 `os.homedir()` + `path.join()`，无硬编码 POSIX 路径。
- **包 ID 不变**：本包平台注册 ID 始终为 `ai-butler`（不可变），更新仅涉及显示名（花名「启明星」/ `Lucian`、职称「教师工作台」）或内部修复。平台不会将其识别为新专家包，老用户**无需重装**，直接覆盖更新即可；更新前建议先在工作台「设置 → 导出 JSON」备份。
- **权限与隔离**：目标目录可写，无需 `sudo`；安装后建议统一为目录 `755` / 文件 `644`，macOS 上清除 `com.apple.quarantine` 隔离标记，避免资源被系统拦截。

## 键盘操作与无障碍

工作台全流程可纯键盘操作，无需鼠标：

| 按键 | 作用 |
|------|------|
| `Ctrl` / `⌘` + `K`，或 `/` | 聚焦全局搜索（`/` 仅在非输入框内生效） |
| `Esc` | 逐层关闭当前浮层：模态框 → 备份菜单 → 通知面板 → 搜索结果 |
| `Enter` / `Space` | 激活当前聚焦项（导航、勾选框、标签、搜索结果等） |
| `Tab` / `Shift+Tab` | 在导航、按钮、勾选框、标签之间移动焦点（有清晰焦点环） |

无障碍支持：`role="main"` 主内容地标与 `role="search"` 搜索地标；状态提示经 `aria-live` 播报区朗读；
勾选框 `aria-checked` 与选中态自动同步；并遵循系统「减少动态效果」偏好（自动关闭过渡与动画）。

## 数据安全

- 所有数据仅存于用户浏览器 localStorage，**默认不上传任何服务器**。
- 云同步需用户主动开启并自行配置环境 ID 与 SDK 地址（运行时索取）；开启时要求设置**端到端加密口令**，数据在浏览器内用 AES-GCM 加密后才上传，云端只存密文、无密钥，口令仅驻本机内存、不上传不落盘。
- 本地桥（127.0.0.1 回环）采用强随机 token + HMAC 签名防重放，落盘文件仅当前用户可读写（macOS / Linux `chmod 600/700`，Windows `icacls` 限制属主）并保留审计日志。
