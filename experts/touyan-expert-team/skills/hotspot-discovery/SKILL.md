# 热点扫描与机会发现引擎

> 跨平台：文中命令统一 `python3`，Windows 上解释器名通常为 `python`。

## 一、定位与触发条件

当用户提出以下意图（或无明确意图）时触发本 Skill：
- "最近市场有什么值得研究的？"
- "有什么方向值得看？"
- "不知道买什么，帮我看看"
- "市场有什么机会？"
- "帮我扫一下热点"
- 用户首次对话且未指定任何标的/方向
- 用户表达"不知道从哪开始"

## 二、三重信号验证模型

每个推荐方向必须至少命中 2 个信号维度：

| 信号维度 | 具体指标 | 数据来源 |
|---------|---------|---------|
| 政策信号 | 近期重磅政策/文件、部委表态、地方试点 | 联网搜索 + eastmoney-mx（新闻搜索） |
| 资金信号 | 板块资金净流入 TOP、北向加仓方向、龙虎榜活跃板块 | akshare-finance-data |
| 事件催化 | 行业大会、产品发布、财报季节点、订单/中标公告 | 联网搜索 + eastmoney-mx |

**三重验证逻辑**：
```
政策+资金 → 强信号（机构提前布局政策方向）
政策+事件 → 中信号（催化在前，资金待验证）
资金+事件 → 中信号（市场已反应，需判断持续性）
三重共振  → 最强信号（值得重点研究）
```

## 三、数据获取流程

### Step 1：市场全景扫描

```bash
# 板块资金流 TOP20
python3 scripts/main.py sector-flow --sector_type industry --top 20

# 北向资金近 10 日趋势
python3 scripts/main.py north-flow --days 10

# 涨停复盘（看连板/首板集中方向）
python3 scripts/main.py zt-pool --date {latest_trade_date}
python3 scripts/main.py strong-pool --date {latest_trade_date}
```

### Step 2：政策与事件扫描

- 东方财富新闻搜索：近 7 日政策类新闻
- 联网搜索：国务院/发改委/工信部近期政策动态
- 行业大会/展会/重要会议日程

### Step 3：交叉验证与方向筛选

将资金 TOP 板块 ↔ 近期政策方向 ↔ 事件催化做交叉验证：
1. 资金流入 TOP 板块中，哪些有政策支持？
2. 近期政策方向中，哪些已被资金验证？
3. 即将到来的催化事件，涉及哪些方向？

筛选标准：至少命中 2 个信号维度才纳入推荐。

## 五、输出约束

1. **精简为先**：推荐 3-5 个方向，不做信息轰炸
2. **每个方向一句话逻辑**：用户 3 秒内能判断是否感兴趣
3. **信号可溯源**：每个推荐必须附具体数据/政策/事件依据
4. **代表标的仅供参考**：强调"方向研究入口"而非"荐股"
5. **风险信号必列**：不只说机会，也要警示当前需回避的方向
6. **不做确定性判断**：用"值得研究""值得关注"而非"一定涨""建议买入"

## 七、定时场景支持

本 Skill 适合作为定时任务的数据提供层：
- 每日盘后扫描 → 识别新出现的资金/事件信号
- 每周汇总 → 周度投研简报中"本周新增关注方向"部分
- 配合周度 cron job 使用更顺手

## 八、数据准确性约束

1. 板块资金数据必须来自 akshare，不得用联网搜索数字代替
2. 政策信息必须标注发布日期和发布机构
3. "代表标的"只列明确属于该方向的公司，不猜测
4. 数据缺失/接口失败时明确告知"该维度数据暂时无法获取"
5. 历史数据不冒充当日数据，标注数据截至时间
