# 行业/主题研究引擎

## 一、定位与触发条件

当用户提出以下意图时触发本 Skill：
- "XX行业/概念值不值得配置"
- "帮我研究下XX方向"
- "XX最近很火，能不能投"
- "XX产业链拆解"
- "哪些行业值得关注"

## 二、5 大分析模块

### 模块 1：政策梳理

**分析内容**：
- 近 6-12 个月相关国家/地方政策汇总
- 政策支持力度评估（强支持/温和支持/中性/收紧）
- 政策落地节奏判断（已落地/正在落地/预期中）
- 补贴/税收优惠/准入门槛变化
- 监管风向（鼓励/规范/限制）

**输出格式**：
```
📋 政策环境评估
━━━━━━━━━━━━━━━━━━━━
支持力度：⭐⭐⭐⭐☆（强支持）

近期关键政策：
• {日期} — {政策名称} | 影响：{具体影响}
• {日期} — {政策名称} | 影响：{具体影响}
• ...

政策趋势判断：[一句话总结政策方向]
风险信号：[是否有收紧/退坡迹象]
```

**分析框架**：

```
  ├─ 供需格局：供不应求 / 平衡 / 过剩
  └─ 议价能力：强 / 中 / 弱
  │
中游（制造/集成/平台）
  │
  ├─ 关键玩家：...
  ├─ 竞争格局：寡头 / 集中 / 分散
  └─ 壁垒高度：高 / 中 / 低
  │
下游（应用/终端/消费）
  │
  ├─ 关键玩家：...
  ├─ 市场空间：...
  └─ 渗透率：...
```

**A 股标的映射**：每个环节列出 2-3 家代表性上市公司

### 模块 3：资金验证

**追踪指标**：
- 板块近 30 日资金净流入/流出趋势
- 北向资金对该板块的持仓变化
- 融资余额变化
- ETF 规模变化（有对应 ETF 时）
- 龙虎榜活跃度

**数据来源**：akshare-finance-data / eastmoney-mx

**输出格式**：
```
💰 资金验证
━━━━━━━━━━━━━━━━━━━━
30日资金趋势：净流入 / 净流出 / 震荡
北向资金态度：加仓 / 减仓 / 持平
融资情绪：乐观 / 中性 / 悲观

资金信号判断：
• 主力态度：[描述]
• 散户情绪：[描述]
• 资金共识度：高 / 中 / 低
```

### 模块 4：估值横比

**比较维度**：
- 板块当前 PE/PB vs 历史分位（近 3 年/5 年）
- 板块 PE vs 全市场中位数
- 板块内个股估值分布（哪些偏贵/哪些便宜）
- PEG 比较（成长性估值）

**输出格式**：
```
📊 估值评估
━━━━━━━━━━━━━━━━━━━━
板块PE(TTM)：XX | 历史分位：XX%（3年）/ XX%（5年）
板块PB：XX | 历史分位：XX%

估值判断：
• 整体水位：偏低 / 合理 / 偏高 / 极度偏高
• 性价比排序：[列出板块内估值洼地]
• 风险提示：[估值过高的标的]
```

### 模块 5：催化剂识别

**催化剂类型**：
- 业绩催化（财报超预期、订单放量）
- 政策催化（新政出台、补贴落地）
- 事件催化（行业大会、产品发布、技术突破）
- 资金催化（纳入指数、ETF 发行）
- 情绪催化（市场主题轮动、叙事升级）

**输出格式**：
```
⚡ 催化剂日历
━━━━━━━━━━━━━━━━━━━━
近期（1个月内）：
• {事件} — 催化强度：⭐⭐⭐ | 受益标的：...

中期（1-3个月）：
• {事件} — 催化强度：⭐⭐ | 受益标的：...

远期（3-6个月）：
• {事件} — 催化强度：⭐ | 受益标的：...
```

## 三、5 因子打分模型

对筛选出的候选标的进行量化打分：

| 因子 | 权重 | 评估内容 | 评分标准 |
|------|------|---------|---------|
| 行业景气度 | 25% | 政策支持 + 需求增长 + 产能周期 | 高景气10分 / 中5分 / 低2分 |
| 资金趋势 | 25% | 30日主力+北向+融资方向 | 三者一致10分 / 二者一致7分 / 分歧4分 |
| 催化确定性 | 20% | 近期催化剂数量和强度 | 强催化10分 / 中催化6分 / 无催化2分 |
| 估值安全性 | 15% | PE/PB历史分位 + PEG | 分位<30%为10分 / 30-70%为6分 / >70%为3分 |
| 技术形态 | 15% | 趋势 + 均线 + 量价配合 | 多头排列10分 / 整理6分 / 空头3分 |

**总分计算**：加权总分 = Σ(因子得分 × 权重) / 10 × 100

**评分解读**：
| 分段 | 含义 | 建议 |
|------|------|------|
| 80-100 | 高度值得关注 | 可纳入重点研究池 |
| 60-79 | 有配置价值 | 适度关注，等待催化 |
| 40-59 | 中性 | 观望为主 |
| 0-39 | 暂不推荐 | 等待转机 |

## 六、数据准确性约束

1. 资金数据必须来自 akshare / eastmoney-mx，不得用联网搜索数字代替
2. 估值数据标注计算基准日期
3. 政策信息需标注发布日期和发布机构
4. 产业链映射的公司需确认仍在上市交易状态
5. 联网搜索仅用于政策文件和行业新闻，不用于精确数字
6. 打分模型各因子的数据来源需分别标注
