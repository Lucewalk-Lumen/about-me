# 对比决策引擎

## 一、定位与触发条件

当用户提出以下意图时触发本 Skill：
- "A和B选哪个？"
- "寒武纪和海光信息对比下"
- "这几只票帮我比一比"
- "同属XX概念，哪个更好"
- "帮我做个对比决策"

## 二、对比分析框架

### 2.1 可比性确认

执行对比前先确认：
- 标的是否属于同行业/同概念/同级别市值
- 如不可比（如大盘蓝筹 vs 小盘成长），先告知差异再做分类对比

### 2.2 六维对比模型

| 对比维度 | 对比指标 | 数据来源 |
|---------|---------|---------|
| 成长性 | 营收增速（近3年）、净利增速、研发占比趋势 | eastmoney-mx / akshare |
| 盈利质量 | ROE、毛利率、经营现金流/净利匹配 | eastmoney-mx / akshare |
| 估值水平 | PE(TTM)、PB、PEG、历史分位 | akshare / eastmoney-mx |
| 资金认可度 | 北向持仓变化、机构持仓比例、融资余额趋势 | akshare |
| 催化与节奏 | 近期催化事件、业绩兑现节点 | 联网搜索 + eastmoney-mx |
| 风险暴露 | 解禁压力、质押比例、估值泡沫、政策风险 | akshare + 联网搜索 |

### 2.3 定性差异分析

在定量对比之上，增加定性判断：
- **核心逻辑差异**：两家公司的投资逻辑本质区别是什么？
- **确定性 vs 爆发力**：哪个更适合追求稳定收益？哪个弹性更大？
- **所处阶段差异**：哪个处于业绩兑现期？哪个还在预期阶段？
- **市场共识度**：哪个分歧更大（分歧=预期差机会）？

## 四、多标的对比（≥3 只）

当对比标的 ≥ 3 只时：
1. 先输出完整多维对比表
2. 按"综合评分"排序（复用 industry-theme-research 的 5 因子模型）
3. 给出 TOP 2 的详细差异化分析
4. 其余标的给出"一句话淘汰/保留理由"

## 五、数据准确性约束

1. 财务指标必须来自 eastmoney-mx / akshare，标注报告期
2. 估值数据标注计算基准日期
3. 北向/机构持仓标注数据截至日期
4. 不对确定性做绝对判断（"一定比B好"），用比较级和前提条件表述
5. 数据缺失时标注"暂无数据"，不影响已有维度的输出
6. AI 判断与客观数据明确区隔
