# 策略生成引擎

## 一、定位与触发条件

当用户提出以下意图时触发本 Skill：
- "我有XX万，怎么配置？"
- "帮我配个组合"
- "资金怎么分配"
- "给我一个投资方案"
- "XX风险偏好，怎么买"
- "这几个方向怎么配比"

## 二、策略生成五步法

### Step 1：风险画像确认

在生成策略前，必须确认以下要素（未提供时用默认值或追问）：

| 要素 | 默认值 | 说明 |
|------|--------|------|
| 可投资金额 | 必须用户提供 | 影响分散度和标的选择 |
| 风险偏好 | 中等 | 保守/中等/激进 |
| 投资周期 | 中期(3-12月) | 短期/中期/长期 |
| 已有持仓 | 无 | 避免重复配置同方向 |
| 投资目标 | 资产增值 | 增值/保值/高弹性 |

**风险偏好矩阵**：

| 风险偏好 | 最大单票仓位 | 行业集中度上限 | 止损线 | 预期年化 |
|---------|------------|--------------|--------|---------|
| 保守 | 15% | 30% | -8% | 8-15% |
| 中等 | 25% | 50% | -12% | 15-30% |
| 激进 | 40% | 70% | -20% | 30%+ |

### Step 2：行业配置

基于当前市场环境和用户风险画像，确定行业配比：

**配置逻辑**：
- 核心仓位（60-70%）：景气度高+资金验证+确定性强的方向
- 卫星仓位（20-30%）：有催化预期但尚未完全验证的方向
- 防御仓位（0-20%）：低估值/高股息/逆周期品种（保守型必配）

**数据支撑**：
- 行业景气度：akshare 板块资金流 + 联网搜索行业数据
- 资金验证：akshare 北向/主力资金方向
- 估值水位：akshare/eastmoney-mx 板块估值分位

### Step 3：标的精选

每个行业配置方向内，精选 2-3 只标的：

**筛选标准**（5 因子）：
| 因子 | 权重 | 评估 |
|------|------|------|
| 基本面质量 | 25% | ROE、现金流、营收增速 |
| 估值安全性 | 25% | PE 分位、PEG |
| 资金认可度 | 20% | 机构/北向/融资 |
| 催化确定性 | 15% | 近期事件/业绩节点 |
| 流动性 | 15% | 日均成交额（需满足资金进出） |

**流动性门槛**：
- 资金量 <50万：日均成交额 >5000万
- 资金量 50-200万：日均成交额 >1亿
- 资金量 >200万：日均成交额 >3亿

### Step 4：买入节奏

根据市场位置和标的状态，给出分批买入建议：

**通用节奏模型**：
```
首次建仓：总仓位的 30-40%（确认趋势/支撑位）
第二次加仓：30%（回调到位 / 突破确认）
第三次加仓：30%（业绩/催化兑现）
```

**节奏调整因子**：
- 市场在高位 → 建仓比例降低，分批更分散
- 市场在低位 → 建仓比例可提高
- 个股已突破 → 追涨仓位要轻，等回踩
- 个股在底部 → 可适当左侧布局

### Step 5：风控红线

每个策略必须包含明确的风控规则：

| 风控类型 | 规则 |
|---------|------|
| 个股止损 | 亏损达到 X% 必须减仓/清仓 |
| 行业止损 | 单行业亏损达到 X% 减半仓位 |
| 总组合止损 | 总亏损达到 X% 降为半仓 |
| 利润保护 | 盈利 >X% 后回撤 Y% 止盈 |
| 时间止损 | 持仓超过 N 个月无起色则重新评估 |
| 仓位上限 | 单票不超过总资金 X% |
| 相关性控制 | 同概念标的合计不超过 X% |

## 四、特殊场景处理

### 小资金（<10万）

- 集中持有 2-3 只，不过度分散
- 优先选流动性好、确定性高的标的
- 降低换手频率，减少交易成本影响

### 大资金（>100万）

- 适当分散，5-8 只标的
- 注意流动性约束（日成交额 > 资金/20）
- 考虑分批建仓对市场的冲击

### 已有持仓

- 先评估已有持仓的质量
- 新配置与已有持仓形成互补而非重叠
- 给出"调仓建议"而非"全新配置"

## 五、数据准确性约束

1. 估值和财务数据必须来自 akshare/eastmoney-mx
2. 具体金额/比例基于用户提供的资金量精确计算
3. 不承诺具体收益率（"保证赚XX%"是红线）
4. 预期收益用区间表达，标注实现前提
5. 风控红线是建议参考，用户可根据自身情况调整
6. 市场环境判断标注分析时点，不预测未来走势
