# 公司深度研报生成引擎

## 一、定位与触发条件

当用户提出以下意图时触发本 Skill：
- "帮我做一份XX的深度研报"
- "拉5年周期看XX"
- "XX值不值得长期持有"
- "系统性分析一下XX"
- "像机构研究员一样看透XX"
- "分析下xx，适合xxx"

## 二、8 大分析维度

### 维度 1：财务全景（5 年趋势）

**分析内容**：
- 营收规模及增速趋势
- 归母净利润及增速趋势
- 经营性现金流与净利润匹配度
- ROE/ROIC 变化趋势
- 毛利率/净利率变化
- 资产负债率及偿债能力
- 研发投入占比（科技公司必选）

**数据来源**：东方财富财务数据接口 / AKShare
**输出格式**：趋势表格 + 关键拐点标注 + 一句话总结

```
┌─────────────────────────────────────────────────────┐
│ 5年财务全景                                           │
├────────┬───────┬───────┬───────┬───────┬───────────┤
│ 指标    │ 2021  │ 2022  │ 2023  │ 2024  │ 2025(E)  │
├────────┼───────┼───────┼───────┼───────┼───────────┤
│ 营收(亿)│       │       │       │       │           │
│ 净利(亿)│       │       │       │       │           │
│ ROE(%)  │       │       │       │       │           │
│ 现金流  │       │       │       │       │           │
└────────┴───────┴───────┴───────┴───────┴───────────┘
📌 关键发现：[一句话总结最重要的财务变化]
```

### 维度 2：资产解剖

**核心资产**（有形）：
- 产能/产线/工厂
- 专利组合（数量+质量+核心专利）
- 客户合同/订单
- 土地/矿产等有形资源

**隐形资产**（无形但有价值）：
- 品牌价值与定价权
- 生态位（行业中的不可替代性）
- 数据壁垒/网络效应
- 管理层能力与行业人脉
- 政府关系/牌照稀缺性

**分析方法**：
1. 从财报附注提取无形资产明细
2. 联网搜索专利数据库
3. 分析客户集中度和粘性
4. 判断竞争者复制该资产组合的难度

**输出格式**：
```
核心资产清单：
• [资产1] — 价值判断 + 竞争壁垒评估
• [资产2] — ...

隐形资产发现：
• [隐形资产1] — 为什么这是壁垒 + 变现路径
• [隐形资产2] — ...

资产组合竞争力评分：X/10（附评分依据）
```

### 维度 3：5 年变化复盘

**追踪维度**：

| 变化类别 | 追踪内容 | 数据来源 |
|---------|---------|---------|
| 市场环境 | 行业规模、政策环境、竞争格局变化 | 行业报告 + 联网搜索 |
| 客户结构 | 前五大客户变化、客户集中度、新客户拓展 | 年报 + 公告 |
| 管理层 | CEO/CFO/CTO 变动、核心技术人员流动 | 公告 + 新闻 |
| 股东结构 | 控股股东、十大股东、机构持仓变化 | 股东数据 |
| 战略方向 | 主营业务调整、新业务布局、并购动作 | 公告 + 新闻 |

**输出格式**：时间线叙事 + 关键转折点标注
```
2021: [起点状态描述]
  ↓ [关键变化事件]
2022: [状态变化]
  ↓ [关键变化事件]
2023: [状态变化]
  ...
📌 核心变化总结：[从A到B，驱动力是什么]
```

### 维度 4：分析师观点汇总

**收集内容**：
- 近 6 个月主流券商研报评级（买入/增持/中性/减持）
- 目标价区间
- 核心看多逻辑
- 核心看空逻辑
- 主要分歧点

**输出格式**：
```
分析师共识：
• 覆盖券商数量：X 家
• 评级分布：买入X / 增持X / 中性X / 减持X
• 目标价区间：¥XX - ¥XX（均值 ¥XX）

看多派核心逻辑：
1. ...
2. ...

看空派核心逻辑：
1. ...
2. ...

最大分歧点：[一句话描述市场最大分歧]
```

### 维度 5：未来展望

**分析框架**：
- 行业天花板与公司市占率提升空间
- 第二/第三增长曲线识别
- 管理层指引与战略规划
- 技术路线演进方向
- 国产替代/全球化等结构性机会

**输出格式**：确定性分级
```
高确定性（已在兑现）：
• ...

中确定性（有信号但未完全验证）：
• ...

低确定性（愿景阶段）：
• ...
```

### 维度 6：风险清单

**风险分类**：
| 风险类型 | 评估要素 |
|---------|---------|
| 估值风险 | 当前PE/PB分位、vs 历史 vs 同行 |
| 业绩风险 | 盈利预测下调可能性 |
| 政策风险 | 监管方向、补贴退坡 |
| 竞争风险 | 新进入者、替代技术 |
| 管理层风险 | 治理结构、关联交易 |
| 流动性风险 | 解禁压力、质押比例 |
| 宏观风险 | 利率、汇率、地缘政治 |

**输出格式**：风险矩阵（影响程度 × 发生概率）
```
⚠️ 高风险（高影响 × 高概率）：
• ...

🔶 中风险（高影响×低概率 或 低影响×高概率）：
• ...

🔵 低风险（关注即可）：
• ...
```

### 维度 7：事件日历

**追踪事件类型**：
- 财报发布日（年报/季报）
- 限售股解禁日
- 分红派息日
- 行业政策窗口期
- 产品发布/行业大会
- 期权/股权激励行权条件判定日

**输出格式**：未来 6-12 个月时间线
```
📅 事件日历（未来6个月）
━━━━━━━━━━━━━━━━━━━━
2026.06 — [事件] | 影响：[正面/负面/中性]
2026.07 — [事件] | 影响：[...]
...
━━━━━━━━━━━━━━━━━━━━
🔑 最关键的催化节点：[哪个事件最可能改变市场对公司的定价]
```

### 维度 8：行业对标

**对标内容**：
- 同行业可比公司清单（3-5 家）
- 核心指标横向对比（营收增速/ROE/PE/市占率）
- 竞争优劣势对比
- 各公司所处发展阶段判断

**输出格式**：
```

| 市占率 | | | | | |

```

## 四、渐进式交付策略

1. **第一轮输出**：8 个维度各给 3-5 句精华摘要 + 核心结论
2. **用户追问**：展开指定维度的完整分析
3. **横向扩展**：对标公司批量生成
4. **时间更新**：下一季度自动刷新数据，对比变化

## 五、数据准确性约束

1. 财务数据必须来自 eastmoney-mx / akshare，不得用联网搜索结果代替
2. 每个数据点标注来源和取数时间
3. 预测数据（如"2025E"）必须标注为市场一致预期，注明来源
4. 数据缺失 → 标注「暂无可用数据」，不影响其他维度输出
5. 分析师观点需标注所属券商和发布日期
6. AI 分析段落与客观数据段落明确区隔
