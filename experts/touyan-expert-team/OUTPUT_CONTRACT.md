# 输出契约 + 质量评分（包级单一真源）

> 本文件定义 `touyan-expert-team` **所有对外研究产出的标准结构与质量评分**。目标：让每份报告都「可审计、可溯源、可比对」。
> 制定依据：阶段 1 调研发现 G3（缺显式输出契约与质量评分）、G4（溯源/可审计不足）、G7（决策边界模糊）。
> 技能级副本（如 `skills/kline-candlestick-reader/references/OUTPUT_CONTRACT.md`，kline 技能）为本文件的技能级细化，冲突以本文件为准。
> 质量评分按本 rubric 对报告打 0–100 分。

---

## 1. 标准报告结构（所有交付物须包含以下章节）

1. **数据说明**：标的、市场/类型、周期、区间、复权、来源、样本数量、数据质量。
2. **当前状态**：一句话条件化概括当前结构与所处位置。
3. **关键事实**：基本面 / 技术面 / 资金面分维度呈现（视场景取舍）。
4. **风险点**：至少 3 条风险或不确定性。
5. **后续观察清单**：至少 3 条需跟踪的信号 / 价位 / 事件。
6. **免责声明**：明确「不构成投资建议、收益承诺或买卖指令」。

---

## 2. 溯源四要素（每条带时间属性的数据 claim 必须带）

| 要素 | 示例 |
|------|------|
| 来源 | `AkShare` / `东方财富公开接口` / `market_data_guard.py quote` / `联网搜索（摘要）` |
| 取数时间 / 交易日期 | `截至 2026-10-15 15:00 收盘` / `交易日期 2026-10-14` |
| 校验状态(status) | `ok` / `partial` / `missing` / `unverified` / `error` |
| 置信度 | `高（多源一致）` / `中（单源）` / `低（待核实）` |

> 示例：`贵州茅台 600519.SH 收盘 ¥1,500.00，涨跌幅 +1.2%（来源：market_data_guard.py quote，交易日期 2026-10-15，status=ok，置信度：高）。`

---

## 3. 质量评分 Rubric（0–100）

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 数据可验证性 | 25 | 是否全部来自可验证源；缺失是否显式标注而非补数；status 是否如实返回 |
| 溯源完整度 | 20 | 四要素（来源/时间/状态/置信度）覆盖比例 |
| 交叉验证 | 20 | 多视角（基本面/技术面/资金面）是否互证；冲突是否显式呈现而非掩去 |
| 结构合规 | 15 | 是否符合 §1 六段结构、是否含免责声明 |
| 风险与边界 | 20 | 是否标注高风险边界；是否守住「不指令 / 不承诺」红线 |

- **≥ 80 分**：可直接交付；**60–79**：可交付但需在风险点标注改进项；**< 60**：退回补全溯源/守门后再交付。
- 评分器输出逐维度明细与违规项（`violations`），供 agent 自检与门禁校验。

---

## 4. 红线（硬约束，对应 G7）

- 不输出买卖 / 加仓减仓指令、不给出仓位比例、目标价、止损位。
- 不做「必涨 / 必跌 / 稳赚 / 一定突破」等确定性预测或收益承诺。
- 文末必附免责声明；所有结论仅作研究参考，决策权与风险在用户。
- 跨角色任务由主理人（`touyan-expert-team-lead`）汇编交付，成员不得互相直连或越权替用户决策。

---

## 5. 禁止表达（清洗清单）

- 「可以买 / 应该卖 / 建议加仓 / 仓位几成 / 目标价 / 止损位」。
- 「明天会涨 / 一定突破 / 稳了 / 保本 / 这是确定性机会 / 风险很小」。
- 未说明来源就引入基本面、公告、资金流、北向资金、龙虎榜或盘口结论。
- 把搜索摘要 / AI 解读当作原始来源（须区分「原文事实」与「解读」）。
