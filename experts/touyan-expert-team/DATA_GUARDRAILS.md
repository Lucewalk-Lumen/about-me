# 数据守门契约（包级单一真源）

> 本文件是 `touyan-expert-team` **数据可靠性守门**的包级单一真源（single source of truth）。
> 所有 agent 与取数型 skill（`astock-report`、`akshare-stock`、`akshare-finance-data`、`eastmoney-mx-skills-suite`、`mx-stocks-screener`、`kline-market-data`、`us-market-data`、`strategy-backtest`、`claw-stock` 等）均须遵守本契约。
> 各 skill 内部的技能级副本（如 `skills/kline-candlestick-reader/references/DATA_GUARDRAILS.md`）为本契约的技能级细化，冲突以本文件为准。
>
> 制定依据：阶段 1 调研发现 G1（A 股财务数据幻觉率约 10%、协同幻觉相互放大）、G5（降级纪律不一致易静默回退/伪造）。

---

## 1. 七项校验（任何取数前必做）

调用原始行情/财务/资金接口前，逐项完成以下检查，任一项不确定即降级：

| # | 校验项 | 具体动作 |
|---|--------|----------|
| 1 | 时间 | 区分自然日 / 交易日 / 盘中快照 / 盘后 / T-1；不得把「最近可得」写成「今日实时」 |
| 2 | 字段 | 年报核心字段按 `YYYY-12-31` 精确匹配；缺失字段保持 `missing`，不按 0 填充 |
| 3 | 分页 | 全市场区间统计须完整遍历，未遍历完只返回 `partial`，不得冒充全市场 |
| 4 | 单位 | 每股 / 每 10 股换算核对（如分红「每 10 股派 X 元」→ 每股税前现金分红） |
| 5 | 口径 | 避免把第三方结构化表的不同口径数字当成核验结果（如中国平安 2022 年报口径冲突） |
| 6 | 去重 | 同标的多源返回须去重，避免重复计数 |
| 7 | 异常值 | `HTTP 200` 但业务为空 / 返回 HTML / 限流 / 字段报错 / 代码歧义 → 降级为「待核实」 |

---

## 2. status 约定（所有取数脚本统一返回结构化状态）

```
status ∈ { ok | partial | missing | unverified | error }
```

- `ok`：单源校验通过或多源一致 → 可输出确定数字。
- `partial`：仅覆盖部分样本（如区间涨幅未完整遍历）→ 只报部分，不得冒充全市场。
- `missing`：字段缺失 → 输出「暂缺」，不补 0。
- `unverified`：单源 / 冲突 / 过期 → 输出「待核实」，不报确定值。
- `error`：接口/依赖不可用 → 输出失败摘要，走降级协议。

**硬规则**：只有 `status=ok` 才能输出确定价格、涨跌幅、资金流等实时数值；其余状态必须显式说明「暂无可验证数据」。

---

## 3. 标注规范（缺失即显式，严禁补数）

| 情形 | 正确表述 |
|------|----------|
| 拿不到可验证数据 | 「暂未获取 / 待核实」 |
| 单源或来源冲突 | 「暂缺，待多源核验」 |
| 字段缺失 | 「该字段缺失（missing）」 |
| 依赖未安装 / 接口不可用 | 「当前无法给出确定数据，请稍后重试或以交易所/券商终端为准」 |

**禁止**：用 AI 搜索、新闻段落、模型推断、历史日 K、昨日收盘价、示例值、占位符补齐实时价格或资金数值。

---

## 4. 降级协议（P0 红线，对应 G5）

当 `MX_APIKEY` 未配置或 AkShare / 东方财富接口不可用时：

1. **主动说明**：明确告知用户「需要什么凭证 / 哪个依赖不可用，以及如何配置」。
2. **给出双选项**：
   - （A）用户去配置后重试（如申请 `MX_APIKEY` 并写入环境变量）；
   - （B）改用公开接口（东方财富公开 K 线 / `akshare-finance-data` 公开接口）+ 联网搜索的免凭证降级方案。
3. **绝不**：静默回退、用旧缓存冒充实时、伪造数据、假装成功。

> 反模式清单（门禁 `guardrail_gate.py` 会扫描）：`静默`、`伪造`、`补数`、`绕过守门脚本`、`用网页搜索冒充当前价`、`假装实时`、`无来源`。

## 5. 高风险边界（先确认口径再输出）

停牌、退市整理、ST/*ST、北交所、涨跌停、龙虎榜、北向暂停披露、指数边界（如中证 1000/500/300 边界样本）、异常主体（康美药业、乐视网等）——
先调用对应守门子命令（`index-boundary` / `entity-risk`）或显式标注口径不确定性，再输出，不得当作普通样本。

## 7. 美股取数补充口径（v0.1.7 新增，A 股口径之外的市场特例）

美股实时报价与 K 线统一走 `us-market-data` 的两个脚本（`fetch_us_quote.py` / `fetch_us_kline.py`），**status=ok 纪律与 A 股完全一致**，另有以下市场特例：

| # | 口径 | 规则 |
|---|------|------|
| 1 | secid 前缀 | `105.`=纳斯达克、`106.`=纽交所、`107.`=美交所；A 股代码（6 位数字）传入美股脚本必须被拒绝并提示改用 `kline-market-data` |
| 2 | 价格精度 | 报价字段按接口返回的 `f59` 小数位动态缩放（美股实测 `f43=345240, f59=3 → 345.24`）；**不得硬编码 ÷100**（A 股口径），也不得手动补位 |
| 3 | 时区 | 报价时间必须双标注：美东时间（`quote_time_et`，含 EDT/EST）+ UTC；**不得把美东时间当作北京时间**；K 线日期为美股交易日 |
| 4 | 盘中状态 | 输出必须带 `session_status`（trading / pre_market / after_hours / closed / closed_weekend）；非盘中时报价为收盘/延时价，必须显式说明，不得表述为「实时价」 |
| 5 | 交易日历 | A 股与美股假日不同；跨市场对比分别取数、分别标注各自交易日期，不得混排同一时间轴 |
| 6 | 执行边界 | 美股**无实盘执行**（EMTL 仅 A 股）；任何「帮我买/卖美股」请求须明确拒绝并说明边界 |
| 7 | 财报口径 | 美股财务为东方财富/妙想汇总口径（非 SEC 原文）；引用时标注口径，缺失维度标「暂缺」 |

> 回测（`strategy-backtest`）的输入数据同样受本契约约束：CSV 必须来自上述取数脚本或用户粘贴，回测结果必须带 disclaimer（简化假设披露），不得表述为收益承诺。
