# 企业落地方法论判据 16 条（fde-handbook-judgments）

> 出处：进化三部曲 · FDE 系列《FDE 落实手册》（原文全文直读，判据为方法论口径）。
> 引用纪律：判据可经 `references/source-mapping.md` 回溯；涉数字处一律按「示例口径」标注，不作事实断言。

| # | 判据 | 要点 | 出处 |
|---|---|---|---|
| 1 | 三层楼模型 | 一楼生产（物）/ 二楼运营（事和钱）/ 三楼指挥（判断）；FDE 干三楼 | 素材1 §一 |
| 2 | 一条环四要素 | 触发 / 执行 / 决策 / 反馈；任一要素缺失各有后果：无触发环不启动，无执行落不了地，无决策兜不住异常，无反馈环合不上 | 素材1 §二 |
| 3 | 环排序公式 | 评分 =（频次 × 单次耗时 × 规则化程度）÷ 风险，分高先做；确定性计算由 `skills/loop-scoring/scripts/score.py` 实现 | 素材1 §三 |
| 4 | 分数低即停三信号 | 低频高风险 / 规则说不清 / 出错不可逆；命中即「先不做」 | 素材1 §三 |
| 5 | 四问自证 | 谁触发 / 谁决策 / 谁执行到底 / 环怎么合上；答不全不算闭环 | 素材1 §二、§八 |
| 6 | 写回授权四级 | 只看 → 给建议 → 人点头后写 → 限额内自己写；逐级签字 | 素材1 §三 |
| 7 | 甲方五样 | 拍板的人 / 三把钥匙 / 写回的签字 / 停工线 / 接班的人 | 素材1 §五 |
| 8 | 乙方五样 | 楼层图 + 流程清单 / 接线积木 / 上一单的环 / 蒸馏手艺 / 后方 + 退场日期 | 素材1 §七 |
| 9 | 两周日志蒸馏法 | 学员每天只记三件事：在等什么 / 在传什么 / 在判断什么；两周后蒸馏卡点 | 素材1 §七 |
| 10 | 五步演进 | 一个人 → 一个岗位 → 一条环 → 一张网 → 一家公司 | 素材1 §四 |
| 11 | 四条安全规矩 | 权限最小化 / 高危操作人工确认 / 可回滚 / 全程留痕 | 素材1 §五 |
| 12 | 知识库交付验收思路 | 真实提问抽样作答，达到双方约定的通过率才算交付（原文示例口径为抽样 20 题、答对 85% 以上——属示例口径，进包须明示，不作行业标准） | 素材1 §七 |
| 13 | 三考核数 | 考核「环了多少」而非「做了多少」：自动流转率 / 异常率 / 复发率 | 素材1 §四 |
| 14 | 环会腐烂 | 执行环外长进化环；异常沉淀回规则库 / 经验库 | 素材1 §四 |
| 15 | 老系统零改动 | 老系统一行不改；智能体用独立账号，不绕过原有认证 / 权限 / 日志 | 素材1 §三 |
| 16 | 验收成本定律 | 一个环节 AI 进步多快，由验收一次的成本决定；验收成本高的环节放慢推进节奏 | 素材1 §三 |
