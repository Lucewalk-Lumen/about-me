# 失败场景与降级策略

> 结构借鉴 OBHRM `research-collector/references/failure_paths.md`
> （按阶段分节 + 「失败场景 / 触发条件 / 处理方式」 + 交付清单）。

## 总原则（两条，不可违背）

1. **零静默丢弃**：任何一条文献都必须归入某个 tier；
   四类之和 == 记录总数，不等即 exit 5。宁可标注为"降级/无内容"，也不能悄悄丢掉。
2. **可选能力失败不阻塞主流程**：R 缺失、某来源失败、某可选输入缺失，
   一律降级继续并**显式说明**，绝不以"分析失败"呈现。
   只有"必需输入不可用"才返回非 0 退出码。

## 一、接入阶段

| 失败场景 | 触发条件 | 处理方式 | 退出码 |
|---|---|---|---|
| 源库路径不存在 | `.enl` 找不到 | 明确报错 + 提示检查移动硬盘是否连接 | 1 |
| EndNote 正在运行（持锁） | `-wal`/`lsof` 命中 | **自动切影子副本继续分析**，报告标注 `endnote_busy_detected: true` | 0 |
| 源库损坏 | `PRAGMA quick_check` 失败 | 提示用 EndNote 的 Repair 功能修复 | 6 |
| 旧版文本格式（EndNote ≤18） | 非 SQLite | 明确指引：需 EndNote 20+ 的 SQLite 库 | 2 |
| 写源库被拒绝 | SQLite 只读 | **这是设计如此，不是错误**：源库全程只读 | 0 |

## 二、解析 / 导入阶段

| 失败场景 | 触发条件 | 处理方式 | 退出码 |
|---|---|---|---|
| 格式无法识别 | 内容嗅探无匹配 | 列出所有支持格式 + 建议改用 RIS/EndNote XML/BibTeX | 2 |
| CNKI 加密导出（`.es6`） | 头部 `XCNKI_ENCRYPT` | **明确报错并指引**，绝不静默返回 0 条 | 2 |
| `.xls` 缺 xlrd | ImportError | 提示 `pip install 'xlrd>=2.0'`（xlrd 2.x 只支持 .xls） | 8 |
| `.xlsx` 被当作 `.xls` | 扩展名与内容不符 | 提示改用 openpyxl 或先另存 .xls/.csv | 2 |
| 某来源解析失败 | 单个文件异常 | **跳过该来源、其余照常合并**，在 `failures` 中记录 | 0（其余成功时） |
| 全部来源均失败 | 无一条成功 | 明确报错 | 2 |
| 编码非 UTF-8 | 解码失败 | 按 UTF-8→GB18030→GBK→BIG5 逐级尝试，兜底 replace | 0 |
| 标题/摘要为空 | 字段缺失 | 归入 `empty` tier 并**计数**，不丢弃 | 0 |
| 无摘要的题录来源（如 GB7714 引文列表） | 该来源无摘要字段 | 全落 `fallback_title` 降级层，报告提示"该来源无摘要，正文分析不可用" | 0 |
| 年份缺失 | `year` 为空 | 记为 None，时效性的"缺失年份占比"如实统计 | 0 |

## 三、分析阶段

| 失败场景 | 触发条件 | 处理方式 | 退出码 |
|---|---|---|---|
| sklearn / jieba 缺失 | ImportError | `doctor.py` 报环境不满足 | 8 |
| 文献数过少 | K 稳健性检验 < 20 篇 | 拒绝执行并说明样本不足 | 4 |
| `--k` 越界 | 不在 4~40 | 报参数错误 | 4 |
| K 稳健性不足 | 相邻 K 的 ARI < 0.40 | **不报错**，判定为"不稳定"并建议改为报告跨 K 稳定主题 | 0 |
| 缺失关键词的文献 | 无 keywords | 靠标题+摘要兜底（`build_corpus` 的 hybrid 分支） | 0 |
| R 或 igraph 缺失 | `sna_r.py` 探测失败 | **自动回退纯 Python**，`backend=python-fallback` + 给出安装命令 | 0 |
| R 运行超时 | > 300s | 回退纯 Python 并在 `reason` 中说明超时 | 0 |
| R 脚本报错 | 非 0 退出 | 回退纯 Python | 0 |
| 网络节点过多导致慢 | n > 3000 | 提示降低 `--node-df` 或提高 `--min-edge` | 0 |

## 四、交付阶段

| 失败场景 | 处理方式 |
|---|---|
| 报告写入失败（权限/路径） | 报出具体路径与原因；建议更换 `--out` 目录 |
| 某可选输入 JSON 缺失 | 对应章节**不渲染**，其余章节照常（如无 dup.json 则不显示重复检测） |
| 三线表所需数据缺失 | 只生成数据完备的表（如无 evolution 则跳过"主题×年份"表） |
| 综述骨架缺某维度 | 标注"未提供该维度"，骨架其余部分仍可用 |

## 五、交付清单

正常路径：
1. `report.html` —— 自包含单文件报告（`file://` 可直开，无外网依赖）
2. `sanxian.html` —— 中文期刊三线表（可选，`--sanxian`）
3. JSON 产物 —— `topics / network / evolution / reading / dup / age / author_topic / robust_k / sna_r`
4. `refs.json` —— 多来源归一化产物（可被下游任意脚本直接消费）
5. `SKELETON.md` —— 综述骨架（由 `member-a` 消费上述 JSON 生成）

下游消费：
- 综述写作：把 `topics.json` + `author_topic.json` 交给 `skills/review-skeleton`
- 稳健性引用：`robust_k.json` 的"稳健性检验矩阵"可直接进论文对应小节
- 投稿用表：`--sanxian` 输出可直接粘入 Word

## 六、退出码速查

| 码 | 含义 | 对用户怎么说 |
|---|---|---|
| 0 | 成功（含所有降级） | 正常；若报告含降级提示，如实转述 |
| 1 | 源库不可用 | 请检查移动硬盘是否连接、路径是否正确 |
| 2 | 格式不支持 | 请先按指引导出为 RIS / EndNote XML / BibTeX |
| 3 | 文件锁占用 | 已自动改用副本；如需最新数据请关闭 EndNote 后重扫 |
| 4 | 参数错误 | 请检查 `--k` / 阈值取值范围 |
| 5 | 计算失败 | 请附日志反馈（属未预期缺陷） |
| 6 | 库损坏 | 请用 EndNote 的 Repair 功能修复 |
| 7 | 派生库写入失败 | 请检查工作目录权限与磁盘空间 |
| 8 | 环境不满足 | 请先运行 `doctor.py`，按提示安装依赖 |
