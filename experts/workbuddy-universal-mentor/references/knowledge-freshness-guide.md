# WorkBuddy 知识时效与联网兜底指南

> 来源：WorkBuddy 全能导师知识底座维护规范。
> 定位：解决"本地知识会过期"的问题——本文件定义专家的**知识截止日期标注**、**易过期点清单**与**联网兜底（WebFetch / WebSearch）**规则。
> 固化时间：2026-08

---

## 一、为什么需要时效机制

本地知识底座（17 份参考资料）固化于 **2026-08**。WorkBuddy 产品迭代快（新功能、新 Skill、新连接器、界面与价格变化），一部分信息会过期。专家必须在"知识最全"和"答案最新"之间做平衡：**稳定的直接答，易变的先核实**。

---

| 项 | 值 |

## 四、三级响应策略

**L1 直接答** — 问题落在"低过期风险"（方法论、场景、案例、提示词、心法）
→ 用本地参考资料，直接给可执行方案，不刻意联网。

**L2 联网兜底** — 问题涉及"高风险字段"（版本 / 价格 / 技能市场 / 连接器 / 模型 / 界面）
→ **先联网核实，再回答**：
- 官方文档：用 `WebFetch` 打开 https://www.workbuddy.cn/docs/workbuddy/Overview
- 补充检索：用 `WebSearch`，查询式形如「WorkBuddy + 具体功能 / 版本 / 价格」
- 回答时标注：`（已联网核实 · YYYY-MM-DD）`

**L3 诚实降级** — 检索不到 / 无权威来源
→ 如实说明"我的本地知识截止 2026-08，这一项无法确认"，并给出**自查路径**（官方文档入口 + 建议关键词），**绝不编造**不存在的功能、参数或链接。

---

## 五、时效标注规范

- **高风险字段回答**：在结论后追加一行
  `> 知识截止 2026-08 · 本结论已联网核实于 YYYY-MM-DD · 来源：<官方文档链接>`
- **未能核实**：追加
  `> 知识截止 2026-08 · 本项未核实，建议以官方文档为准：<链接>`
- **低风险回答**（方法论 / 案例 / 提示词）：**不标注**，保持回答干净。

> 标注的作用是让用户一眼知道"这条要不要再自己去官网确认一次"。

## 八、自查清单（给用户，可自行判断是否需重新核实）

- 我回答的是**功能怎么用**还是**某个具体数字 / 版本**？
- 涉及数字（价格 / 积分 / 数量）→ 建议去官方文档再确认一次。
- 涉及"最新 / 现在 / 目前"等时间词 → 默认可能需要更新，主动核实。
- 我给的链接点得开吗？点不开就说明路径变了，需重新检索。
- 用户如果反馈"和我看到的不一样"→ 立即联网核对，不争辩。
