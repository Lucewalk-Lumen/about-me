## 一、内容运营：从"能出稿"到"能运营"

### 1.1 内容运营 5 个环节（人机分工）

| 环节 | 人负责 | WorkBuddy 负责 |
|---|---|---|
| 定位与选题 | 定方向 / 受众 / 调性 | 生成选题库、痛点矩阵、热点借势 |
| 内容生产 | 判断好坏、补真实案例 | 出初稿、改写、多平台适配 |
| 素材包装 | 定封面风格基调 | 生成封面文案 / 配图 / 标题矩阵 |
| 分发排期 | 定节奏与优先级 | 生成内容日历、跨平台改写 |
| 数据复盘 | 决策下一步 | 归因分析、下篇优化建议 |

> 核心：**创意与判断留给人，重复劳动交给 AI。** 效率瓶颈几乎不在拍摄剪辑，而在文案与选题。

### 1.2 内容日历与选题库（一次搭好，长期复用）

```
你是我的内容运营搭档。我的账号定位是【___】，目标用户【___】，
主平台【公众号/小红书/视频号/抖音/B站】，更新频率【每周 X 篇】。
请先生成一份 4 周内容日历：①按「痛点型/经验型/热点型/故事型/工具型/转化型」分类
②每周含 3 个选题 + 1 个转化型内容 ③每个选题标注最佳平台与内容形式
④输出为表格（周次 | 日期 | 选题 | 类型 | 平台 | 形式 | 目的）。输出为表格。
```

### 1.3 批量生产流水线（选题库 → 批量出稿 → 分轮优化 → 排期）

| 步骤 | 指令模板（原样可抄） |
|---|---|
| 1 出选题库 | 基于我的定位和受众，一次性生成 30 个选题，分热点型 / 产品型 / 信任型三类，各附 2 个标题方向。 |
| 2 批量出初稿 | 按下列选题逐条出 300-600 字初稿，语气真实、第一人称、短句为主；一次给 5 条，用二级标题分隔。 |
| 3 分轮优化 | 第 1 轮只改标题、第 2 轮只改开头钩子、第 3 轮只加互动结尾，逐轮聚焦一个维度。 |
| 4 排期发布 | 把定稿按平台与时间排成发布表（日期 | 平台 | 标题 | 状态）。 |

> 关键心法：**先出 70 分初稿，再迭代到 90 分**；一次说清所有要求，比反复推倒重来高效得多。

### 1.4 多平台一稿多发

```
你是一名多平台内容编辑。请把下面这篇内容改写成 4 个版本：公众号版、小红书版、
视频号口播版、抖音短视频版。要求：保留核心观点；按平台调整标题、开头、语气、
长度和互动方式。
```

| 平台 | 特征 | 内容要点 |
|---|---|---|
| 公众号 | 长文，搜索 + 订阅 | 深度、结构清晰、配图 |
| 小红书 | 图文，搜索驱动，长尾强 | 300-800 字，短句 + emoji + 分段 |
| 抖音 | 短视频，算法驱动 | 前 3 秒钩子，15-60 秒 |
| 视频号 | 社交推荐，熟人传播 | 生活化，标题引发分享欲 |
| B站 | 中长视频，弹幕文化 | 5-15 分钟深度 + 观点 |

### 1.5 数据复盘迭代

```
你是一名内容增长分析师。这是我近 5 篇内容的数据：曝光【】点击率【】完播率【】
点赞【】收藏【】评论【】转发【】发布时间【】平台【】选题【】。
请：①找出表现最好/最差的规律 ②从选题、标题、开头、结构、情绪价值、互动设计、
发布时间 7 个角度给下阶段优化建议 ③给出下一周的选题方向建议。
```

## 二、知识库建设：把资料变成"越用越准"的资产

### 2.1 为什么知识库是内容人的"第二大脑"

散落的文章、素材、SOP、爆款样本如果只存在文件夹里，等于没用。知识库的作用是：**AI 生成内容时能自动引用你的资料、贴合你的风格**，越用越准。知识库质量取决于三点：覆盖度、新鲜度、结构化。

### 2.2 三种主流方案对比

| 方案 | 适合谁 | 优点 | 注意 |
|---|---|---|---|
| WorkBuddy + ima 知识库 | 个人 / 小团队 | 上传即结构化（分类 / 标签 / 摘要），生成内容自动引用 | 质量取决于资料覆盖度，需定期清理过时内容 |
| WorkBuddy + Obsidian | 已有 Markdown 笔记库的人 | 就地重构目录 / 补双向链接 / 统一标签 / 生成索引 | 操作前备份 vault；链接需人工微调 |
| 企业知识库 | 团队 / 公司 | 统一沉淀 SOP、模板、案例，新人快速上手 | 需设权限与维护责任人 |

### 2.3 个人知识库搭建 4 步

1. **建库**：创建知识库，按主题分文件夹（如 选题 / 文案 / 素材 / SOP / 案例）。
2. **上传**：把历史文章、爆款样本、模板、SOP 批量上传，AI 自动结构化（分类 / 标签 / 摘要 / 关联推荐）。
3. **引用**：生成内容时要求"参考知识库中的《XXX》，保持我的风格"。
4. **迭代**：定期删过时内容、补新样本，保持新鲜度。

### 2.4 知识库自动学习与迭代

```
请帮我设置：①每天早上 9 点抓取【AI 行业 Top10 新闻】生成知识卡片入库
②每周检测一次超过 6 个月未更新的条目，标记为「待更新」
③每月生成一份知识库迭代报告，列出新增 / 更新 / 待清理条目，等我确认后再执行更新。
```

> 避坑：信息源人工筛选；**务必保留"人工确认"环节**，避免错误内容自动入库污染知识库。

### 2.5 知识库质量三要素与避坑

| 要素 | 不合格表现 | 改进 |
|---|---|---|
| 覆盖度 | 提问答非所问 | 补上传相关主题资料 |
| 新鲜度 | 引用过时信息 | 定期清理 + 自动标记待更新 |
| 结构化 | 资料杂乱无法定位 | 分文件夹 + 统一命名 + 标签体系 |

## 三、教程重构（知识付费）：把文章变成学员课程

### 3.1 场景

把已发布的零散文章 / 资料，重构为**结构化学员教程**（付费课程 / 手册），要求体例统一、去标识化、可直接交付。

### 3.2 四步法（先提炼模板，再批量套用）

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 提炼模板 | 先精读 1 篇文章，梳理出标准结构，形成**可复用模板** | 模板先行，避免每篇体例不一 |
| 2 批量套用 | 用统一模板重构其余文章，保持章节 / 语气 / 格式一致 | 逐篇套用，注意风格不漂移 |
| 3 去标识化 | 删除原作者、原出处等无关信息 | 版权与品牌清洁，避免混淆 |
| 4 交付成型 | 导出 PDF，**嵌入原文插图**，保留示例完整性 | 图片不可丢，示例需完整 |

### 3.3 单篇结构模板（可直接复用）

```
标题
一句话价值（读者读完能得到什么）
适用人群
前置准备（工具 / 账号 / 素材）
正文步骤（1 → 2 → 3，每步一个动作 + 一句结果）
指令模板 / 提示词（可复制代码块）
常见坑（3-5 条）
验收标准（怎么算做对了）
延伸阅读 / 下一步
```

### 3.4 批量套用指令模板

```
你是课程编辑。下面是一篇原始文章【粘贴或引用文件】。
请按我给定的「学员教程模板」重构：
①保留原文的全部方法、步骤、数据、示例，不得删减有效信息
②删除原作者姓名、原公众号/来源等标识信息
③统一语气为第二人称教学口吻，术语保留原样
④步骤改为「动作 + 结果」短句；指令类内容放进代码块
⑤标注原文插图应插入的位置（用 [图：说明] 占位）
输出为结构化 Markdown。
```

### 3.5 IMA 知识库引用（@ima:）

文章源存放在 IMA 知识库时，可用 `@ima:` 前缀引用对应文件，专家 / Agent 直接读取后重构，无需手动复制粘贴：

```
请读取 @ima:【文章标题】，按学员教程模板重构为一份 PDF 教程，并嵌入原文插图位置。
```

### 3.6 避坑表

| 坑 | 现象 | 规避 |
|---|---|---|
| 版权 / 混淆 | 教程里残留原作者信息 | 第 3 步强制删除所有来源标识 |
| 丢图 | 导出 PDF 后原文插图丢失 | 用 [图：说明] 占位并在导出时嵌入 |
| 体例漂移 | 每篇结构不一样 | 模板先行，批量套用，逐篇比对 |
| 信息丢失 | 重构后精简过度 | 明确"不得删减有效信息" |
| 版本混乱 | 改到最后不知哪版 | 保留"原稿 → 重构稿"对照 |

## 四、关键指令模板合集（可直接复制）

**① 定位与选题**
```
你是一名资深新媒体选题策划。我的账号定位【】；目标用户【】；平台【】；
希望给人的感觉【专业/真实/有趣/犀利/温暖】。请生成 30 个选题：
①分痛点型、经验型、热点型、故事型、工具型 ②每个说明用户为什么会点
③给出适合的平台和形式 ④输出表格。
```

**② 批量出稿**
```
按下列选题逐条出 300-600 字初稿：语气真实、第一人称、短句为主、开头 30 字内给痛点，
结尾留一个互动问题。一次给 5 条，用二级标题分隔。
```

**③ 内容日历**
```
请生成 4 周内容日历：每周含 3 个选题 + 1 个转化型内容，标注平台、形式、目的，输出表格。
```

**④ 数据复盘**
```
你是一名内容增长分析师。这是我的 5 篇内容数据【】。请找出规律，从选题/标题/开头/
结构/情绪/互动/发布时间 7 个角度给优化建议，并给出下周选题方向。
```

**⑤ 知识库引用生成**
```
请参考知识库中的《XXX》风格，围绕【主题】生成一篇内容，保持我的语气与结构习惯。
```

**⑥ 教程重构**
```
按「学员教程模板」重构【文章】，保留全部有效信息，删除原作者信息，
统一教学口吻，指令放代码块，标注插图位置，输出 Markdown。
```
