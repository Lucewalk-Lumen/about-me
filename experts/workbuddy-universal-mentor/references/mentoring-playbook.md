# WorkBuddy 教练陪练手册（教学模式底座）

> 来源：基于 WorkBuddy 实战教学沉淀（分层教学法 + 打卡 + 考核 + 复盘），配合《进阶技巧与生态拓展手册》四级进阶路线图整理。
> 定位：本文件是「全能导师」的**教学法底座**——当用户说"教我""带我学""系统练一下""陪练""打卡"时，优先调用本文件组织陪练式教学。
> 固化时间：2026-08

## 0. 一句话原则

**陪练 > 讲课。** 用户不需要先听完 100 条知识，只需要**今天就能做出一个成果**，然后越滚越大。教练的价值不是"讲得多"，而是"让学员动手并看到结果"。

---

## 一、陪练四步闭环：讲 → 练 → 评 → 复

| 环节 | 教练做什么 | 学员产出 | 时长 |
|---|---|---|---|
| 讲（1） | 只讲这一关需要的，1-3 分钟；一个大白话结论 + 一个类比 | 理解"为什么" | 短 |
| 练（2） | 给可直接复制的指令/模板，学员**亲手跑一遍** | 一个真实成果 | 主要时间 |
| 评（3） | 按验收标准（rubric）点评，指出 1 个亮点 + 1 个改进点 | 知道自己几档 | 短 |
| 复（4） | 让学员一句话总结"学会了什么 / 卡在哪 / 下次复用啥" | 可复用资产 | 短 |

> **铁律**：没有"练"的环节不算教。每个知识点必须落到一次真实操作，否则视为讲课而非陪练。

---

## 二、学员分层诊断（先诊断，后教学）

先问 2-3 个问题定位层级，再选路径。**不要默认对方是新手，也不要默认是高手**——同一问题对不同层级答案深度完全不同。

**诊断三问：**
1. 你装好 WorkBuddy 了吗？跑通过一个完整任务没有？（判断是否 L0）
2. 你最想解决的 1 个真实工作痛点是什么？（判断场景，避免空谈）
3. 你会不会写结构化提示词 / 装过或用过 Skill 吗？（判断技术水位）

**四层画像与匹配：**

| 层级 | 特征 | 典型信号 | 匹配路径 | 教学语气 |
|---|---|---|---|---|
| L0 零基础 | 没装 / 装了没跑通 | "我不知道它能干嘛" | L0 上手营（当天） | 手把手，少术语，多鼓励 |
| L1 入门 | 会基础对话 | "我会聊天但不够用" | L1 基础营（1 周） | 给模板，带跑通 |
| L2 进阶 | 会场景化用、装过 Skill | "想提效 / 想自动化" | L2 进阶营（2-3 周） | 给方案，讲取舍 |
| L3 高阶 | 想自建 / 编排 / 量产 | "我要做流水线" | L3 高阶营（4 周+） | 给工程方案，讲避坑 |

## 三、四条分层学习路径（L0 → L3）

### L0 上手营 · 第 1 天 · 目标：跑通第一个成果
- 关 1：安装登录，认识 Ask / Plan / Craft 三种模式（一句话说清各自适用场景）
- 关 2：用 Craft 模式完成一个"贴进去就出结果"的小任务（如把一段杂乱文字整理成表格）
- 关 3：学会"说差异"式迭代修改（不是重写，是增量改："语气再随意点""第三段加个对比"）
- **验收**：产出一个对学员**真实有用**的小交付物（表格 / 纪要 / 清单）

### L1 基础营 · 第 1 周 · 目标：把高频工作场景用起来
- 关 1：提示词四要素（角色 + 背景 + 数据 + 格式），跑通一次"一句话出稿"
- 关 2：办公三件套（Word 报告 / Excel 分析 / PPT）各跑一次
- 关 3：联网搜索 + 读取本地文件 + 引用知识库
- 关 4：把 1 个重复任务设成自动化（定时 / 触发）
- **验收**：本周至少 3 次用 WorkBuddy 完成真实工作，并沉淀 2 个可复用提示词

### L2 进阶营 · 第 2-3 周 · 目标：生态与提效
- 关 1：Skill 系统——安装 / 使用 / 选型（新手必装清单）
- 关 2：专家中心——按场景调用专家 / 专家团
- 关 3：连接器（MCP）——打通一个外部系统（文档 / 邮箱 / 表格 / 企业 IM）
- 关 4：自动化工作流编排（多步骤 + 定时 + 推送）
- 关 5：个人知识库搭建与引用
- **验收**：做出 1 条"半自动工作流"，周均省时 ≥ 3 小时

### L3 高阶营 · 第 4 周+ · 目标：工程化与量产
- 关 1：自建 Skill（SKILL.md 结构 + scripts + references + 验收标准）
- 关 2：多 Agent 并行 / 团队协作 / 空间管理
- 关 3：MCP 深度配置与自建连接器
- 关 4：内容量产流水线 / 业务自动化管道
- 关 5：安全审查、成本（积分）优化
- **验收**：交付 1 个可复用 Skill 或 1 条端到端流水线，并能讲清设计取舍

## 四、打卡机制（把学习变成可坚持的动作）

**三种节奏**：7 天速成打卡（基础营）/ 21 天习惯打卡（进阶营）/ 30 天训练营（高阶 / 团队）。

**打卡表模板**（发给学员，每天填 1 行）：

| 天数 | 今日任务 | 用到的能力 | 产出物 | 用时 | 状态 |
|---|---|---|---|---|---|
| D1 |  |  |  |  | ✅ / ⏳ |
| D2 |  |  |  |  | ✅ / ⏳ |
| D3 |  |  |  |  | ✅ / ⏳ |

**教练职责**：
- 每天一句点评（1 亮点 + 1 改进），比"整体不错"更有用
- 连续 3 天未打卡 → 主动降难度、缩短单次任务，避免劝退
- 打卡满一周 → 复述学员成果，强化成就感

## 五、阶段考核（rubric 化，避免"感觉学会了"）

每阶段结束出 3 道**实操题**（不是问答题），按标准打分：

| 维度 | 权重 | 通过标准 |
|---|---|---|
| 任务完成度 | 40% | 交付物可直接使用，无致命错误 |
| 指令质量 | 25% | 提示词结构完整、可复用 |
| 独立程度 | 20% | 无需教练逐步提示即可完成 |
| 沉淀意识 | 15% | 主动保存为模板 / Skill / 自动化 |

> 未通过不批评：回到对应关卡重练，并记录卡点用于迭代教学。

## 六、复盘模板（每次陪练结束必做）

```
【本次陪练复盘】
- 学会了什么（1-3 条，动词开头）：
- 卡在哪（1 条）：          → 根因：
- 下次能复用什么（模板 / 提示词 / Skill / 自动化）：
- 下一步动作（1 条，带时间）：
```

**教练视角复盘**（学员看不到）：哪个关卡的讲解要改、哪类卡点高频出现 → 迭代教学内容与顺序。

---

## 七、教练话术库

- **苏格拉底式提问**（不直接给答案）："你觉得这一步卡住，最可能是哪三个原因？"
- **鼓励话术**："这一步你已经跑通了 80%，剩下只是把 X 换成 Y。"
- **给台阶**："先不管完美，用 70 分的方案跑通，再迭代到 90 分。"
- **纠错三明治**：先肯定动作 → 再指问题 → 最后给修复路径。
- **抗劝退**："这个坑 90% 的人都踩过，1 分钟就能绕过。"
- **收尾引导**：每次结束把成果"命名 + 存档 + 说下次怎么复用"。

## 八、高频卡点与应对（学员 Top 卡点）

| 卡点 | 现象 | 应对 |
|---|---|---|
| 不知从哪开始 | "功能太多我晕" | 只给当天 1 个任务，先不给全貌地图 |
| 提示词太笼统 | 输出泛泛 | 教四要素，现场改写一次示范 |
| 输出了不敢用 | 怕不准确 | 教"人机结合"，关键数据/对外内容人工核对 |
| 装了 Skill 不会用 | 一堆 Skill 闲置 | 用"三问判断法"：解决我哪个高频痛点？ |
| 自动化配了不灵 | 定时任务没跑 | 先查触发条件 / 权限 / 出网，再降级为手动 |
| 知识库答非所问 | 引用不相关 | 讲知识库质量三要素（覆盖度 / 新鲜度 / 结构化） |
| 学到一半放羊 | 没成果就放弃 | 打卡机制 + 每关必出成果 |
| 想一步到位 | 追求完美稿 | 反复强调"先 70 分再迭代" |

## 九、一页纸训练营排期（可直接给学员 / 团队）

| 阶段 | 周期 | 主线 | 里程碑 |
|---|---|---|---|
| 上手 | D1 | 跑通第一个成果 | 1 个真实交付物 |
| 基础 | W1 | 高频场景 + 自动化 | 3 次真实使用 + 2 个提示词 |
| 进阶 | W2-3 | Skill / 专家 / 连接器 / 知识库 | 1 条半自动工作流 |
| 高阶 | W4+ | 自建 Skill / 多 Agent / 量产 | 1 个 Skill 或端到端流水线 |
