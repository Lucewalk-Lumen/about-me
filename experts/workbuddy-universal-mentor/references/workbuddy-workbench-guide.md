# WorkBuddy 工作台搭建指南（资料库 · 页面能力）

> 来源：WorkBuddy 官方「资料库」（library）能力定义 + 外部实战文章（掘金 / 今日头条 / IMA 知识库）整合。
> 定位：教用户用 WorkBuddy 的**资料库**搭工作台 / 看板 / 收集表 / 汇报页——从 0 到发布分享的完整链路。
> 固化时间：2026-08（外部检索核对于 2026-10）。⚠️ 资料库界面与按钮位置可能随版本变化，**具体入口以实际界面与官方文档为准**。

## 0. 一句话认知

**工作台 = 用「资料库」把 文档 + 数据表 + HTML 页面 + 链接 + 文件 组合起来的工作中心。**
核心机制是 **HTML 页面 ⇄ 数据表 双向同步**：改表格里的数据，页面自动跟着变；在页面上填内容，数据表自动写回。所以工作台"活"的关键不是画得多好看，而是**数据只维护一处**。

---

## 一、先搞清楚：资料库的 5 种对象 + 2 个机制

| 对象 | 官方类型 | 用途 |
|---|---|---|
| 📄 在线文档 | doc | 写需求、记笔记、沉淀 SOP，支持协作编辑 |
| 🗂 数据表 | database | 结构化表格，可增删改查、导入 CSV，像迷你数据库 |
| 📊 页面 | page (web) | HTML 单页 / 看板 / Dashboard / 收集表 / 汇报页 |
| 🔗 链接 | link | 把任意网页剪藏成可检索的收藏，留档不丢 |
| 📦 网盘 | drive | 上传本地文件、附件，集中归档 |

**两个关键机制：**
- **文件夹**：做目录树，把上面 5 种对象组织成"工作台"的骨架。
- **page ↔ database 关联绑定**：让页面实时读数据表——**这是工作台"活起来"的核心**，只需维护数据表，看板自动同步。

---

## 二、两种空间：个人空间 vs 团队空间

| 空间 | 适合 | 说明 |
|---|---|---|
| 个人空间（我的资料 / 默认「我的文档」） | 个人工作台 | 只有自己可见 / 可用 |
| 团队空间 | 团队协作 | 多人共用、协同编辑、共享数据 |

> 判断：给自己用 → 个人空间；给团队 / 同事 / 家人共用 → 团队空间。**空间选错后期迁移麻烦**，一开始就想清楚。

## 三、工作台长什么样（结构示意）

```
我的工作台/                    ← 根文件夹（总入口）
├── 待办与任务（数据表）        ← 结构化数据
├── 项目跟踪（数据表）          ← 结构化数据
├── 工作台看板（页面）          ← 关联绑定上面两张表，实时展示
├── 技术笔记/（文件夹）
│   └── 开发 SOP（文档）
└── 常用链接（链接收藏）
```

关键关系：**看板页面 → 关联绑定 → 数据表**，数据一处维护、多端同步。

## 四、7 步搭好工作台（核心流程）

全程用**自然语言**告诉 WorkBuddy 即可，它会调用资料库能力帮你落地：

| 步骤 | 你说的话（可直接复制） |
|---|---|
| 1 建根文件夹 | 在资料库里建一个叫「我的工作台」的文件夹。 |
| 2 建待办数据表 | 在「我的工作台」下建一张「待办与任务」数据表，字段：任务名、负责人、优先级、状态、截止日、备注。 |
| 3 建项目/资产跟踪表 | 再建一张「项目跟踪」表，字段：项目名、类型、当前阶段、风险等级、负责人、更新时间。 |
| 4 建看板页面 | 做一个「工作台看板」页面，展示待办按状态分布、项目阶段概览，风格简洁。 |
| 5 关联绑定（关键） | 把「工作台看板」页面和「待办与任务」「项目跟踪」两张数据表做关联绑定。 |
| 6 沉淀知识文档 | 在「我的工作台」下建「笔记」文件夹，先放一篇「XX SOP」文档。 |
| 7 剪藏常用链接 | 把这几个网页剪藏到「我的工作台」：【官网 / 行情 / 后台地址】。 |

✅ 完成后你只维护数据表，看板自动同步。

## 五、核心提示词模板（最重要）

**① 万能起手式（一句话搭工作台）**
```
请使用资料库的能力帮我制作一个【工作台名称】，需要实现数据在线存储和双向同步。
```

**② 详细需求模板（推荐，效果更好）**
```
请使用 WorkBuddy 资料库能力帮我搭一个【工作台名称】：
- 我的身份/角色：
- 我要它管理的事：
- 需要的数据表及字段：
- 页面要展示哪些统计/图表：
- 风格偏好（简洁/商务/活泼，主色）：
要求数据在线存储、页面与数据表双向同步，搭好后给我编辑链接和发布链接。
```

**③ 数据看板（已有表格 → 网页看板）**
```
把这个表格生成一个 HTML 数据看板，展示【指标1】【指标2】的趋势和占比，
支持筛选，风格简洁商务。
```

**④ 收集表**
```
用资料库做一个【活动报名/信息收集】收集表页面：字段【姓名/电话/单位/需求】，
提交后写入数据表，我能在后台看到所有提交记录。
```

**⑤ 汇报页**
```
把这份数据做成一个汇报页：顶部 3 个指标卡，中间 2 张图表，底部结论，
配色用【品牌色】，可发布成链接分享。
```

**⑥ 一键做同款（省事）**
```
打开「更多 → 应用灵感 → 个人工作台」，选一个模板点「一键做同款」，再让 AI 把示例数据换成我的。
```

## 六、修改与迭代（三种方式）

| 方式 | 适合 | 做法 |
|---|---|---|
| 手动改 | 改字色 / 字号 / 换图 / 配色 | 资料库 → 找到 HTML 文件 → 右上角「编辑」，点两下就改完，不烧积分 |
| AI 改 | 复杂模块重排、加新板块 | 直接说需求：「加一个筛选功能」「改一下统计口径」「配色改成橙色系」 |
| 一起改 | 和同事 / 家人协作 | 实时协同编辑，互相看得见光标 |

## 七、发布与分享

搭好后会得到**两个链接**，用途不同：

| 链接 | 形态 | 用途 |
|---|---|---|
| **编辑态链接** | workbuddy.cn /space/d/... | 协作编辑、继续改 |
| **发布态链接** | workbuddy.link/p/... | 直接发给别人查看 / 使用 |

- **发布为网站**：资料库 → 找到 HTML 文件 → 右上角「分享」→ 发布为网站（无需服务器 / 域名）。
- **邀请协作编辑**：把链接发给对方并设为可编辑权限。
- ⚠️ **权限提醒**：非 WorkBuddy 用户打开发布链接可以**查看**，但**写操作**（如表单提交）会被拦截——发布前先说明，别承诺对方一定能提交。

## 八、能搭什么：工作台 / 轻应用场景清单

| 场景 | 典型工作台 |
|---|---|
| 个人效率 | 待办管理、习惯打卡、记账理财、日程纪要 |
| 项目管理 | 需求 / 任务跟踪、风险看板、进度汇报页 |
| 客户与业务 | 客户跟进表、销售漏斗、库存进销存 |
| 内容运营 | 自媒体选题库 + 发布排期看板、账号数据看板 |
| 经营分析 | 经营数据看板、财务指标看板 |
| 团队协作 | 活动策划页、信息收集表、周会看板 |
| 学习成长 | 备考计划台、课程进度台 |
| 生活家庭 | 家庭日程台、给长辈做的简易使用台 |

> 智能 CSV 还能把合同、发票、图片、设计稿等文件放进单元格，随页面同步显示。

## 九、避坑与最佳实践

1. **先想清"要管哪件事"**，再动手——别一上来堆功能。
2. **数据放数据表，页面只做展示**——只维护一处，减少重复劳动。
3. **个人 vs 团队空间一开始就选对**（迁移麻烦）。
4. **页面与表格务必做"关联绑定"**，否则看板是"死"的。
5. **非 WorkBuddy 用户的写操作会被拦截**，涉及收集 / 提交要先说明。
6. **界面与按钮位置可能随版本变化**（如「一键可视化」「分享」入口），以实际界面为准。
7. **超出资料库页面范畴的**（自带构建 / 部署工具链的完整前端工程、需要后端的应用）→ 不属于工作台能力，另走开发流程。
