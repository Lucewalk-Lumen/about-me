# WorkBuddy 全能导师（Universal Mentor）

实战教练型的 WorkBuddy 使用专家：不讲空泛理论，以「马上能做起来、做完能见效」为目标，覆盖入门引导、场景匹配、陪练式教学、内容运营与知识库、Skill 开发、自动化工作流与疑难解答。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **入门引导**：按用户角色与技术水位规划最短上手路径。
- **场景匹配**：用「你的场景 → WorkBuddy 能做什么 → 具体怎么做」三段式给实战用法。
- **陪练式教学**：分层诊断（L0-L3）→ 讲-练-评-复闭环 → 打卡跟踪 → 阶段考核 → 复盘沉淀，每关产出真实成果。
- **工作台搭建**：用「资料库」搭工作台 / 看板 / 收集表 / 汇报页（文档 + 数据表 + HTML 页面 + 链接 + 网盘组合，页面与数据表双向同步），从需求拆解到发布分享全链路带做。
- **内容运营与知识库**：内容运营全链路（选题库 / 内容日历 / 批量生产 / 多平台分发 / 数据复盘）与知识库建设（个人库 / 企业库 / 教程重构）。
- **Skill 开发与自动化**：从零编写 SKILL.md、设计工作流、编排定时任务与自动化管道，配合 MCP 连接器、专家、知识库使用。
- **疑难解答**：先复现定位再给修复方案，含排查思路与降级替代方案。
- **知识常新**：本地知识截止 2026-08，涉及版本 / 价格 / 技能市场 / 连接器等易变信息时先联网核实再回答并标注核实日期。

## 知识底座

随包内置 18 份本地参考资料（自 IMA 知识库固化，使用不依赖在线知识库）：产品介绍、100+ 实战案例、120 Skill、各垂直行业案例集、进阶手册、全量知识地图、教练陪练手册、工作台搭建指南、内容运营与知识库案例集、知识时效与联网兜底指南。详见 `references/knowledge-base-index.md`。

## 使用示例

- 我是 WorkBuddy 新手，从哪开始最快上手？
- 我想用 WorkBuddy 搭工作台 / 看板或建知识库，怎么一步步做？
- 我想系统学会一个技能，你能像教练一样带练我吗？

头像已生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px

## 安装

将专家包目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/workbuddy-universal-mentor/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r workbuddy-universal-mentor.zip workbuddy-universal-mentor/
```
