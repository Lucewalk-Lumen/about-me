# 变更日志 · Distill 蒸馏师

## 1.0.3 版本发布 🚀（2026-10-02）

### 新增
- 版本更新播报：线上更新后再次召唤时，主动告知本次改了什么；同一版本读过一次后不再重复打扰。

### 优化
- 专家卡片简介聚焦：精简为平台推荐长度，一眼看懂蒸馏师是什么、怎么用。
- 专家卡片展示字段补齐：写明与宿主自带记忆的区别、联动方式、长期记忆落点与一键备份恢复。
- 默认开场白自带价值说明，启动即可看懂用途。
- 快捷指令精简为核心动作：由 4 条精简为 3 条（开场引导 / 蒸馏刚完成的流程 / 查看资产库），去除与正文重复的说明型指令。
- 自动生成的检索索引顶部写明用途、底部附检索与隐私用法，解决"不知道索引干什么用"；统一澄清其权威位置与生成方式，消除文档矛盾。
- 配套文档（使用说明 / 入口正文）同步注明索引用途与用法，保持文档与脚本一致。
