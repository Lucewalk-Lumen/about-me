> 本文件用于告诉使用者「本次更新了什么」。每次会话首条消息，主理人（齐帮办）会主动输出精简版提示，完整内容见本文件。

## v1.1.2 本次更新了什么（2026-10-13）

本次更新聚焦「找人更快、协同更清楚」，要点如下：

### 新增
- **成员职能分组**：八位专家按教学产出价值链分为内容生产组、课件与呈现组、记录与技能组，按「要产出什么」快速定位该找谁。
- **成员能力清单**：一张表看清每位专家「擅长什么、什么时候调它」，覆盖案例、课程、论文、课题、纪要、课件、语音、技能制作八类诉求。
- **单 agent 直调路由表**：「问法 → 调谁」速查——只写案例、只做课件、只整纪要等单一诉求可直达对应专家，综合需求仍由主理人编排。

> 完整变更历史见 `CHANGELOG.md`。

## v1.1.1 本次更新了什么（2026-10-02）

本次更新聚焦「结论更可信 + 协同更稳 + 更省心」，要点如下：

### 新增
- 主理人新增「**全网爬虫验证**」确认门禁：凡结论依赖外部事实、政策、数据或引用的任务，先弹出是否执行全网跨源核验，确认后再做，避免片面结论。

### 优化
- 知识库改为**按需可选**：仅在你要求参考团队既往成果时检索，不阻塞主流程；统一路径并增加缺失兜底，杜绝静默失败。
- 复合意图与跨成员协作链改为**显式编排**，先完成上游再触发下游；内容产出后可主动衔接语音合成。
- 统一各成员头像与中英文命名口径，修正一处职业头衔混用。
- 办公文档生成**优先复用本机已装办公软件**，不强制下载任何办公套件；本地无可用二进制时回退离线生成或平台内置技能。

### 修复
- 修复课件大量编辑导致插件崩溃：编辑运行时改为幂等，重复编辑不再复制界面元素与事件监听；撤销历史按体积封顶，避免含大图课件触发内存溢出使所有任务中止。
- 修复原生演示文稿图表数值异常导致整份文件中断：异常数值改为安全占位后继续生成。
- 清理脚本中装饰性符号与缺少超时的子进程调用，消除潜在的长时间挂起与误判。
- 修复自检脚本 `verify.py` 在 Python 3.9 下把标准库导入误判为「无法解析」、误报 34 项并阻断发布的问题：改为动态判定可解析模块并补全兜底名单，门禁恢复全绿。
- README 补充「联网边界」说明：明确 crawler / Edge TTS 语音合成 / setup 装依赖会联网，其余本地完成。

### 合规修正（重要）
- `categoryId` 由误用的 **`15-Education`**（**非官方枚举**，会导致平台官方校验器报错、包无法加载）修正回官方 **12 类枚举**中的 **`12-IndustryConsultant`**（行业咨询 / 专业顾问），与同系列 `course-tutor` 包保持一致。
