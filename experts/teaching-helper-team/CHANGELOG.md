- 成员职能分组与成员能力清单、单 agent 直调路由表，补齐协同可观测性面板

## 1.1.1 版本发布 🚀(2026-10-02)

### 新增
- 主理人新增「全网爬虫验证」确认门禁：收到任务提示后，凡结论依赖外部事实、政策、数据或引用，先弹出是否执行全网爬虫验证，确认后再以浏览器自动化做跨源检索与交叉核验，避免片面结论。

### 优化
- 知识库改为按需可选：仅在用户要求参考团队既往成果时检索，不阻塞主流程；各场景统一知识库路径并增加缺失兜底，杜绝静默失败。
- 复合意图与跨成员协作链改为显式编排，先完成上游再触发下游；内容产出后可主动衔接语音合成。
- 统一各成员头像与中英文命名口径，修正一处职业头衔混用。
- 办公文档生成优先复用本机已装办公软件，不强制下载任何办公套件；本地无可用二进制时回退离线生成或平台内置技能。

### 修复
- 修复课件大量编辑导致插件崩溃的问题：编辑运行时注入改为幂等，重复编辑不再复制界面元素与事件监听；撤销历史按体积封顶，避免含大图课件触发内存溢出使所有任务中止。
- 修复原生演示文稿构建中图表数值异常导致整份文件生成中断的问题，异常数值改为安全占位后继续生成。
- 清理脚本中装饰性符号与缺少超时的子进程调用，消除潜在的长时间挂起与误判。
- 修复自检脚本 `verify.py` 在 Python 3.9 下把标准库导入（`__future__` / `unicodedata` / `ipaddress` / `posixpath` / `dataclasses` 等）误判为「无法解析 import」、误报 34 项并以退出码 1 阻断发布：改为按当前解释器动态判定可解析模块，并补全 3.9 标准库兜底名单，门禁恢复 0 FAIL / 退出码 0。
- README 新增「联网边界（隐私知情）」说明，明确 crawler 联网抓取、Edge TTS 语音合成会将文本发往微软端点、setup 从 PyPI 镜像拉依赖，其余能力本地完成。

## 1.0.2 版本发布 🚀(2026-09-25)

### 优化
- 行业分类对齐至教育培训，使团队与业务场景更匹配。
- 主理人改为先声明能力状态并推进用户任务，不再等待运行环境完全就绪。
- 八位成员统一补齐结构化回传契约与接单边界，主理人新增回传超时兜底与分阶段协作可见性输出。
- 推荐提示词改为跨成员协作任务，与默认开场提示保持一致。
- 统一初始化耗时对外口径，并规范化展示名与装饰符号。
- 自检能力扩展至更多断言，覆盖推荐提示词协同度、成员回传契约与多方互校、降级矩阵与初始化可恢复性等。

### 修复
- 修复初始化中断后难以恢复的问题，补充分批与续装能力，提升运行环境就绪的健壮性。
- 修复外部命令调用缺乏超时与进程树清理导致的长时间挂起。
- 修复若干跨平台路径与自检误报问题。

## 1.0.1 版本发布 🚀(2026-09-19)

### 修复
- 修复 Windows 上运行时环境无法创建的问题，涵盖托管解释器探测与应用商店别名误识别。

- 修复爬虫安全校验与响应拼接，并修正材料提取来源说明路径。
- 修正自检跨平台误报，补齐与官方校验器对齐的硬规则。
- 清理文档重复表述，移除文献蒸馏中无引用的冗余文件。

## 1.0.0 版本发布 🚀(2026-09-08)

### 新增
- 九位教学专家协同：课程建设、案例写作、论文辅导、课件制作、纪要整理、智能体构建、语音合成、课题申报。
- 五类基础能力：材料提取、爬虫采集、素材总结、知识库、长文整合，由主理人按需编排。
- 统一质量门禁：去 AI 味与引用保真作为所有文本生成的最后一道基础。
- 一键初始化运行时依赖；办公文档优先委托平台官方技能出片，HTML 单文件课件为主路径。
- 新增教育课题申报、教材章节批量扩充、文献深度蒸馏三项能力。
- 运行前自检覆盖结构、引用、版本、依赖、命名、导入、字段与命令行引用等。
