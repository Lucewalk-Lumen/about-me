# 输出模板集

> 本文档包含所有阶段的标准输出模板。当技能需要输出格式化内容时，加载本文档的对应章节。

## 阶段1输出模板：选题评估报告

> **使用说明：** 本模板为通用范式，所有选题评估必须按此格式输出。

```markdown
## 选题评估报告

**选题名称：** [用户提供的选题]

---

### 一、五维度评估

| 维度 | 评分 | 说明 |
|------|------|------|
| 案例可获得性 | X/6 | [具体说明：企业是否可及、数据/访谈能否获得] |
| 问题具体性 | X/6 | [具体说明：问题是否明确、范围是否适中] |
| 对策可操作性 | X/6 | [具体说明：对策是否能针对具体问题] |
| 实践价值 | X/6 | [具体说明：对其他同类企业是否有参考价值] |
| 创新点 | X/6 | [具体说明：视角/对象/方法/交叉是否有新意] |

**总分：** XX/30

---

### 二、评级与建议

**评级：** [绿/通过]优秀 / [黄/待优化]良好 / [橙/需修改]需修改 / [红/不通过]不建议

**优点：**
1. [具体优点]
2. [具体优点]

**问题：**
1. [具体问题]
2. [具体问题]

**建议：**
1. [具体建议]
2. [具体建议]

---

### 三、下一步

[根据评级给出下一步建议]
```

## 阶段3输出模板：文献检索指导

> **使用说明：** 阶段3步骤1，按此格式输出检索指导。

```markdown
## 文献检索指导

**专业：** [专业名称]
**选题方向：** [具体方向]

---

### 一、检索关键词

**中文关键词：**
- 主关键词：[关键词1]、[关键词2]、[关键词3]
- 扩展关键词：[关键词4]、[关键词5]

**英文关键词：**
- 主关键词：[keyword1]、[keyword2]、[keyword3]
- 扩展关键词：[keyword4]、[keyword5]

---

### 二、数据库推荐

**中文数据库：**
- 中国知网（CNKI）：https://www.cnki.net
- 万方数据：https://www.wanfangdata.com.cn
- 维普资讯：https://www.cqvip.com

**英文数据库：**
- Web of Science：https://www.webofscience.com
- ScienceDirect：https://www.sciencedirect.com
- Google Scholar：https://scholar.google.com

---

### 三、筛选标准

| 标准 | 要求 |
|------|------|
| 发表时间 | 近5年（2019-2024）优先 |
| 期刊等级 | 核心期刊、CSSCI、SSCI |
| 被引次数 | >10次（中文）、>20次（英文） |
| 文献类型 | 期刊论文、会议论文、学位论文 |

**建议检索数量：** 17-23篇（中文期刊10-12篇 + 英文期刊5-8篇 + 硕士论文2-3篇）

---

### 四、检索式示例

**CNKI高级检索：**
```
SU='人才流失' * SU='中小企业' * (FU='人力资源' + FU='员工关系')
```

**Web of Science检索：**
```
TS=("turnover" OR "employee turnover") AND TS=("SME" OR "small business")
```

---

[注] **下一步：**
请根据上述指导自行检索文献，找到文献后告诉我，我帮你整理和撰写文献综述。
```

[注] **确认：**
