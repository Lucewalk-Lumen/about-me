# 文献检索与整理指导

## 文献驱动四步法（核心协作流程）

本技能与用户的文献协作采用"四步法"：

```
1. 检索指导 → 2. 提取确认 → 3. 撰写综述 → 4. 交付确认
```

### 步骤1 检索指导

技能向用户提供定制化的文献检索方案（关键词、数据库、筛选标准），用户自行在知网等数据库检索。

### 步骤2 提取确认

用户提供文献后，技能先整理归类并确认：

```
[文档] [作者1]([年份]) → 用在"国内研究·原因"部分，核心观点：[薪酬是主要因素]
[文档] [作者2]([年份]) → 用在"国内研究·对策"部分，核心观点：[三维留人机制]
[文档] [作者3]([年份]) → 用在"国外研究"部分，核心观点：[心理契约视角]
...

确认无误我开始写？
```

确认后再进入写作阶段，避免方向偏差。

### 步骤3 撰写综述

严格依据用户提供的文献撰写，每条论述标注引用来源[1][2]...
- 不凭空捏造文献 — 每条引用必须来自用户提供的文献
- 不添加用户未提供的文献
- 文献不足处留白标注"[此处需补充X方向文献]"

结构：国内研究现状 → 国外研究现状 → 文献述评

### 步骤4 交付确认

输出正文 + 引用来源对照表，确认：
- "哪里需要改？"
- "哪里缺文献，需要补充检索？"

根据用户反馈修改，直到满意。

## 文献检索基本流程

### 第一步：选择检索数据库

**中文数据库（优先）：**
1. **中国知网（CNKI）** - https://www.cnki.net/
   - 最权威的中文学术数据库
   - 包含期刊、硕士论文、博士论文、会议论文
   - 推荐使用学校图书馆账号登录（免费）

2. **万方数据** - https://www.wanfangdata.com.cn/
   - 期刊、学位论文、会议论文
   - 部分文献与知网重复，部分独有

3. **维普网** - https://www.cqvip.com/
   - 中文期刊为主
   - 部分期刊知网没有

**英文数据库（可选）：**
1. **Google Scholar** - https://scholar.google.com/
   - 免费，覆盖面广
   - 可以检索到英文文献

2. **Web of Science** - 需要通过学校账号
   - 高质量英文期刊
   - 适合查找经典文献

### 人力资源领域重点资源

**中文核心期刊（人力资源方向）：**
- 《中国人力资源开发》 — 人力资源领域最权威期刊
- 《人力资源管理》 — 实务导向，案例丰富
- 《管理世界》 — 综合性管理期刊，含人力资源方向
- 《南开管理评论》 — 高质量管理研究（含案例研究）
- 《管理评论》 / 《管理学报》 — 综合管理类

**常见人力资源硕士论文学位授予单位：**
- 重点搜索：各高校管理学院、商学院、MBA中心的硕士论文
- 知网检索时勾选"学位论文"类型，可获得完整论文结构参考

**英文人力资源期刊（如需外文文献）：**
- *Human Resource Management* (Wiley)
- *International Journal of Human Resource Management* (Taylor & Francis)
- *Personnel Psychology* (Wiley)
- *Journal of Organizational Behavior* (Wiley)

**经典人力资源理论（文献综述中可引用）：**
- 马斯洛需求层次理论 (Maslow, 1943)
- 赫茨伯格双因素理论 (Herzberg, 1959)
- 亚当斯公平理论 (Adams, 1965)
- 弗鲁姆期望理论 (Vroom, 1964)
- 社会交换理论 (Blau, 1964) — 常用于解释员工-组织关系

> [附] 提示：经典理论引用年份较早是正常的，但核心文献（期刊/学位论文）优先选近5年。

### 市场营销领域重点资源

**中文核心期刊（市场营销方向）：**
- 《市场营销》 — 市场营销领域最权威期刊
- 《管理世界》 — 综合性管理期刊，含市场营销方向
- 《中国工业经济》 — 产业与营销研究
- 《商业经济与管理》 — 商业与营销实务
- 《销售与市场》 — 实务导向，案例丰富

**常见市场营销硕士论文学位授予单位：**
- 重点搜索：各高校商学院、管理学院、市场营销系的硕士论文
- 知网检索时勾选"学位论文"类型，可获得完整论文结构参考

**英文市场营销期刊（如需外文文献）：**
- *Journal of Marketing* (American Marketing Association)
- *Journal of Marketing Research* (American Marketing Association)
- *Marketing Science* (INFORMS)
- *Journal of Consumer Research* (University of Chicago Press)

**经典市场营销理论（文献综述中可引用）：**
- STP理论 (Segmentation, Targeting, Positioning) — 市场细分与定位
- 4P营销组合理论 (McCarthy, 1960) — 产品、价格、渠道、促销
- 4C理论 (Lauterborn, 1990) — 顾客、成本、便利、沟通
- 品牌资产理论 (Aaker, 1991 / Keller, 1993)
- 顾客关系管理理论 (Berry, 1983 / Reichheld, 1996)

> [附] 提示：经典理论引用年份较早是正常的，但核心文献（期刊/学位论文）优先选近5年。

### 第二步：确定检索关键词

**检索关键词要分层次：**

**核心词（必须包含）：**
- 你的研究主题，如"人才流失""绩效管理""员工满意度"

**扩展词（可以组合）：**
- 同义词：如"人才流失"="员工离职"="人员流失"
- 相关词：如"人才流失"+"中小企业""制造业"

**组合检索式（以"人才流失"为例）：**
1. "人才流失" AND "中小企业"
2. "员工离职" AND "影响因素"
3. "人才流失" AND "对策"

**技巧：**
- 用AND连接两个词（同时包含）
- 用OR连接同义词（包含任意一个）
- 用"引号"锁定词组（精确匹配）

---

### 第三步：筛选文献

**筛选标准：**

| 标准 | 要求 | 说明 |
|------|------|------|
| 时间 | 近5年（2021-2026） | 保证时效性 |
| 类型 | 核心期刊、硕士论文 | 保证质量 |
| 相关性 | 与选题直接相关 | 不相关的不要 |
| 被引次数 | >10次（可选） | 高质量文献 |

**文献数量要求：**
- 中文期刊论文：10-12篇
- 英文期刊论文：5-8篇
- 硕士论文：2-3篇（作为补充，非必须）
- **总计：17-23篇（其中期刊论文15-20篇）**

> 注意：期刊论文（包括中英文）不能低于15篇。硕士论文可以作为补充，但不算在期刊论文数量内。

---

### 第四步：阅读与整理

**阅读顺序：**
1. 先读摘要（了解主要内容）
2. 再读结论（了解主要发现）
3. 最后读分析方法（如有需要）

**整理方式：**

建立一个文献整理表（Excel或Word）：

| 编号 | 作者 | 年份 | 题目 | 主要观点 | 使用方法 | 备注 |
|------|------|------|------|----------|----------|------|
| [1] | 作者 | 年份 | 题目 | 核心观点 | 方法 | 核心文献 |
| [2] | ... | ... | ... | ... | ... | ... |

**整理时注意：**
- 记录文献的**核心观点**，不是全文抄写
- 标注**与你的研究相关的部分**
- 记录**引用格式**（作者、年份、题目、期刊、页码）

## 文献综述写作框架

> [附] 章节结构要求见 `references/core/thesis-structure-guide.md`（绪论·文献综述部分）

### 标准结构

```
1. 国内研究现状
   1.1 关于[主题1]的研究
   1.2 关于[主题2]的研究
   1.3 关于[主题3]的研究

2. 国外研究现状
   2.1 关于[主题]的研究
   2.2 主要理论视角

3. 文献述评
   3.1 已有研究成果
   3.2 研究不足
   3.3 本文的研究切入点
```

### 写作示例（以"人才流失"为例）

```markdown
### 1. 国内研究现状

国内学者围绕中小企业人才流失问题开展了深入且系统的研究，已形成较为完善的理论体系与实践指导框架。

**（1）关于人才流失原因的研究**

[作者1]（[年份]）在对[数量]家中小企业的案例研究中发现，薪酬待遇缺乏竞争力与职业发展空间受限是导致人才流失的两大核心动因[1]。

[作者2]（[年份]）从企业管理视角切入，指出除了经济因素外，企业文化建设缺失、管理风格不当也是人才流失的重要诱因[2]。

**（2）关于人才流失影响的研究**

[作者3]（[年份]）研究了人才流失对企业的影响，发现关键人才流失会导致招聘成本上升[百分比]、团队稳定性下降、客户流失等问题[3]。

**（3）关于人才流失对策的研究**

[作者4]（[年份]）提出，企业应建立多维度的留人机制，包括薪酬激励、职业发展、企业文化三个方面，该机制在多个企业案例中得到验证[4]。

综合来看，国内研究普遍认为，人才流失是多因素交织的复杂问题，其解决路径需综合考量薪酬激励、职业发展、企业文化建设及管理机制等多个维度。

### 2. 国外研究现状

国外学者对人才流失（Employee Turnover）的研究起步较早，形成了较为成熟的理论体系。

[作者A]（[年份]）提出了人才流失的价格模型，认为工作满意度、组织承诺、工作机会是影响流失的主要因素[5]。

[作者B]（[年份]）进一步拓展了研究，指出心理契约违背是导致人才流失的重要心理机制[6]。

### 3. 文献述评

已有研究在人才流失的原因、影响和对策方面取得了丰富成果，为本研究提供了理论基础和实践参考。但现有研究仍存在以下不足：

第一，以大型企业为案例的研究较多，针对中小企业的深入研究相对不足；

第二，定量研究较多，基于具体企业的案例分析较少；

第三，对策建议较为笼统，缺乏针对具体企业问题的可操作性方案。

基于此，本研究以A公司为案例，深入分析其人才流失问题的具体表现和原因，并提出有针对性的对策建议，试图为填补上述研究空白做出贡献。
```

## 参考文献格式规范

### GB/T 7714-2015 格式

**期刊文献格式：**
```
[序号] 作者. 题目[J]. 期刊名, 年份, 卷(期): 起止页码.
```

示例：
```
[1] 作者. 题目[J]. 期刊名, 年份, 卷(期): 起止页码.
```

**硕士论文格式：**
```
[序号] 作者. 题目[D]. 学校所在地: 学校名称, 年份.
```

示例：
```
[2] 作者. 题目[D]. 城市: 学校, 年份.
```

**外文文献格式：**
```
[序号] Author. Title[J]. Journal Name, Year, Volume(Issue): Pages.
```

示例：
```
[3] Author. Title[J]. Journal Name, Year, Volume(Issue): Pages.
```

## 常见错误

### 错误1：凭空捏造文献

[不通过] "作者（2024）指出..."（如果没有这篇文献）

[通过] 必须先检索文献，再引用

### 错误2：文献综述变成作者列表

[不通过] 
```
[作者1]（[年份]）研究了人才流失。
[作者2]（[年份]）也研究了人才流失。
[作者3]（[年份]）研究了影响。
```

[通过] 
```
国内学者围绕人才流失原因开展了研究。[作者1]（[年份]）指出薪酬是主要因素...[作者2]（[年份]）进一步提出...综合来看...
```

### 错误3：引用格式不规范

[不通过] "[1] 作者. 题目. 年份."

[通过] "[1] 作者. 题目[J]. 期刊名, 年份, 卷(期): 页码."

### 错误4：文献太老

[不通过] 引用2000年的文献（除非是经典理论）

[通过] 优先引用近5年的文献，经典理论可以用老文献
