## 六阶段门控总览

```
阶段0 启动诊断 → [门控G0] → 阶段1 选题评估 → [门控G1]
  → 阶段2 选题优化 → [门控G2] → 阶段3 文献综述 → [门控G3]
    → 阶段4 论文写作 → [门控G4] → 阶段5 修改定稿 → [门控G5]
```

---

## 阶段 0→1 诊断通过门

| 检查项 | 通过条件 |
|--------|----------|
| G-S0-1 四问完整 | 专业/学位/选题状态/案例来源 全部已知 |
| G-S0-2 路由正确 | 根据选题状态正确路由到下一阶段 |

### 特殊路由

| 选题状态 | 路由 |
|----------|------|
| 没方向/需生成 | → 阶段1（先生成选题，再评估） |
| 有方向/已定 | → 阶段1（直接评估） |

---

## 阶段 1→2 选题通过门

| 检查项 | 通过条件 |
|--------|----------|
| G-S1-1 五维度全评 | 五个维度全部有评分 |
| G-S1-2 案例可行性 | 案例可获得性 ≥ 3 分（否则建议换题） |
| G-S1-3 评级判断 | 评级已确定（[绿/通过]/[黄/待优化]/[橙/需修改]/[红/不通过]） |

### 路由

| 评级 | 路由 |
|------|------|
| [绿/通过] 优秀(24-30) | **跳过阶段 2**，直接进入阶段 3 |
| [黄/待优化] 良好(17-23) | → 阶段 2 优化 |
| [橙/需修改] 需修改(10-16) | → 阶段 2 优化 |
| [红/不通过] 不建议(0-9) | 建议换题 → 阶段 1 |

---

## 阶段 2→3 优化完成门

| 检查项 | 通过条件 |
|--------|----------|
| G-S2-1 再评估 | 优化后的选题重新评估得分 ≥ 17 |
| G-S2-2 学生确认 | 学生同意优化后的选题 |

---

## 阶段 3→4 文献充分门

| 检查项 | 通过条件 |
|--------|----------|
| G-S3-1 文献数量 | 已检索 17-23 篇（含中英） |
| G-S3-2 文献质量 | 无凭空捏造的文献 |
| G-S3-3 文献分布 | 覆盖概念/关系/方法/实践四个层次 |

---

## 阶段 4→5 写作完成门

| 检查项 | 通过条件 |
|--------|----------|
| G-S4-1 章节完整 | 五章全部完成 |
| G-S4-2 原因-对策对应 | 第四章对策与第二章原因一一对应 |
| G-S4-3 学生确认 | 每章经学生确认 |
| G-S4-4 图表嵌入（实证型） | 含数据/结果的章节均有图或表，编号连续、图注≥80字、正文显式引用（详见 `figure-and-table-embedding-protocol.md`） |

---

## 阶段 5→定稿 修改完成门

| 检查项 | 通过条件 |
|--------|----------|
| G-S5-1 四层修改 | 结构/内容/表达/格式 全部完成 |
| G-S5-2 重复率 | 重复率预期在允许范围内 |
| G-S5-3 表达自然化 | 已执行语言自然化策略 |
| G-S5-4 最终检查 | 错别字/图表/打印版式 已检查 |
| G-S5-5 优化建议已输出 | 定稿前已给出 ≥2 条结构化优化建议（位置+改法，非空话），见 `mentoring-example-benchmarks.md` Taxonomy |

## 智能过渡提示模板

### 阶段 0→1

```
---
[清单] 诊断完成：专业[XX]，学位[XX]，选题[有方向/没方向]，案例[可及/不可及]

接下来进入阶段 1 选题评估。我会从五个维度评估你的选题——
其中最重要的是：你能进入这家企业做调研吗？
如果是，你的选题就成功了一半。

[如没方向] 我先根据你的专业推荐几个选题方向供你参考。
---
```

### 阶段 1→2（需优化时）

```
---
[图] 选题评估完成：评分 [XX]/30，评级 [[黄/待优化]/[橙/需修改]]

这个选题的方向是对的，但在 [具体维度] 上还有提升空间。
接下来进入阶段 2 选题优化——我不会给你换一个新题，而是帮你在现有题目基础
上，把范围缩小、把问题聚焦、让论文更有针对性。
---
```

### 阶段 4→5

```
---
[注] 初稿完成。五章结构如下：[简述各章节核心内容]

接下来进入阶段 5 修改与定稿。修改按四层进行：
1. 先看结构——章节之间逻辑是否通顺？
2. 再看内容——论证是否充分？数据是否支撑结论？
3. 再看表达——有没有 AI 味太重的地方？
4. 最后看格式——引用、排版、图表（编号/图注/正文引用是否到位，详见figure-and-table-embedding-protocol）。

我们一层一层来。
---
```
