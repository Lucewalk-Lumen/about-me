# figure-and-table-embedding-protocol — 让"结果呈现不缺图、图不悬空"

> 本文档按本科管理学论文场景，规定figure-and-table-embedding-protocol（编号 / 图注 ≥80 字 / 正文引用）。
> 解决的问题：学生论文常见"有数据没图""图有编号但正文从不引用""图注只有一句话"三类硬伤。

---

## 0. 先判断：这篇论文需要图吗？

| 论文类型 | 是否需要图 | 典型图表 |
|----------|-----------|----------|
| 实证研究（问卷/实验/二手数据） | **必须** | 描述统计条形图、信效度热图、回归/简单斜率图、假设检验结果 |
| 案例+问卷混合 | 视数据量 | 问卷部分用条形/饼图，案例部分可少图 |
| 纯案例分析（问题诊断+对策） | 可选 | 用流程图/结构图替代数据图即可，不必硬凑 |

> 纯案例分析论文不必为了"显得专业"硬塞数据图。本协议的编号/图注/引用规则对所有图（含流程图）同样适用。

---

## 1. 图表登记表（Figure Register）

每生成一张图，立刻登记，避免写作用漏引用：

| 图号 | 类型 | 归属章节 | 文件 | 图注状态 | 正文引用 |
|------|------|----------|------|----------|----------|
| 图1 | 条形图 | §3.2 描述统计 | 产出/条形图.pdf | [ ] | [ ] |
| 图2 | 简单斜率图 | §4.3 假设检验 | 产出/简单斜率图.pdf | [ ] | [ ] |

> 表与图分开编号：图1/图2…，表1/表2…。章节内顺序编号即可（不必按全局序号强排）。

---

## 2. 编号规则

- 全文图统一前缀 **"图N"**，表统一前缀 **"表N"**，N 从 1 起递增。
- 章节内引用用"如图1所示""见表2"，跨章节用"第三章图1"。
- 编号在定稿前可临时，但**定稿后必须连续无跳号**。

---

## 3. 图注规范（APA7，中文 ≥80 字）

图注不是"图1 满意度得分"，而要交代：**这张图说了什么、数据从哪来、关键统计值是多少**。

[通过] 合格图注（示例）：
> 图1 不同薪酬公平感分组下的员工满意度均值（N=312）。误差棒表示 95% 置信区间。高公平感组（M=4.21, SD=0.58）显著高于低公平感组（M=3.34, SD=0.71），t(310)=2.87, p<0.01，Cohen's d=0.53，属中等效应。

[不通过] 不合格图注：
> 图1 满意度得分。

**图注自检**：是否含 N / 变量名 / 关键统计量（均值、显著性、效应量）？缺任一即不合格。

---

## 4. 正文必须显式引用（关键！）

生成图 ≠ 完成。每一张图都必须在正文里被**点名引用**，否则图是悬空的：

```markdown
如图1所示，高薪酬公平感组的满意度均值（M=4.21）显著高于低分组（M=3.34），
这一差异在统计上显著（p<0.01），为假设 H1 提供了初步支持。
```

> 禁止"见图"式甩图——必须紧跟一句**对图的解读**，把图和你的论点连起来。

---

## 5. 调图表引擎出图

实证论文出图走 `scripts/chart_engine.py`（可选依赖，详见 SKILL.md 图表引擎段）：

```bash
# 需在含 matplotlib 的环境中运行（如技能自带 venv）
python scripts/chart_engine.py 简单斜率图 '{"x":[1,2,3,4],"low_y":[2,3,4,5],"high_y":[1,2,3,4]}' --output ./产出/
python scripts/chart_engine.py --list     # 查看 9 种支持类型
```

出图后：登记到 §1 表格 → 写 ≥80 字图注 → 在正文点名引用。

---

## 6. 完成判定清单（每章收尾用）

- [ ] 含数据/结果的章节都至少有一张图或表
- [ ] 每张图/表都有连续编号
- [ ] 图注 ≥80 字，含 N/变量/关键统计量
- [ ] 正文对每张图都有显式引用 + 一句解读
- [ ] 图表登记表与本文字节一致（无漏引、无跳号）
