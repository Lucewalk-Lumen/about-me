# Agent 提示词模板库

本文件提供 textbook-chapter-expansion 各阶段使用的 Agent 提示词模板。
使用时将 {{占位符}} 替换为实际值，并补充任务相关的具体细节（文件路径、章节名、教材特有术语等）。

---

## 一、扫描 Agent 模板（阶段1，三路并行）

三个扫描 Agent 均以 `run_in_background=true` 启动，要求各自把完整报告写入独立文件。

### 1. 原稿对比（scan-original）

```
你在分析一本{{教材名}}。该教材经过多轮修订，当前版本为{{版本号}}（分{{册数}}册）。

任务：将原始稿与当前版本对比，找出丢失或仍未补齐的内容。

原始稿位置：{{原始稿路径}}
当前版本：{{当前版本路径，可多个}}
参考清单：{{MAPPING.md 或其他变更清单路径，如存在}}

对比方法：
1. 按章节逐段比对原始稿与当前版本，找出原始稿中有、当前版本缺失的段落
2. 结合参考清单中列出的四类丢失内容（政策坐标/技术底座/拓展案例/原理细节），确认是否仍有遗漏
3. 对每处缺失记录：所在章节、缺失内容要点、预估字数

输出：将完整报告写入 {{报告输出路径}}，包含缺失点清单（章节/位置/要点/预估字数）。
```

### 2. 素材库扫描（scan-materials）

```
你在分析一本{{教材名}}，当前处于{{版本号}}补充阶段。

任务：扫描素材库，识别尚未被教材引用的高价值内容。

素材库位置：{{素材库目录路径}}（包含 {{子目录结构，如官方手册/实战案例PDF/公众号文章/政策文件等}}）
教材当前版本：{{教材路径，可多个}}
已有内容概要：{{补充内容概要清单路径，如存在}}

扫描方法：
1. 遍历素材库全部文件，提取每份素材的核心内容
2. 与教材正文交叉比对，筛出尚未被引用的素材
3. 按价值分级：第一梯队（数据权威/案例典型/与教材主线直接相关）、第二梯队（参考性强/可作拓展阅读）
4. 为每个素材估算可新增字数，并建议注入的目标章节

输出：将完整报告写入 {{报告输出路径}}，包含素材清单（名称/来源/核心内容/梯队/预估字数/建议章节）。
```

### 3. 章节厚度分析（scan-chapters）

```
你在分析一本{{教材名}}，分为{{册数}}册（{{版本号}}阶段）。

任务：识别内容过薄、需要扩充的章节。

教材文件：
- 上册：{{上册路径}}（{{行数}}行）
- 下册：{{下册路径}}（{{行数}}行）

章节字数目标：{{如每章 8,000 字}}

分析步骤：
1. 定位全部章节标题（如 "## 第 N 章"），确定每章行号范围
2. 逐章统计字数（中文字符数）
3. 对照目标字数分级：极薄（< 目标值 30%）、偏薄（< 目标值）、达标
4. 对每章标注缺失模块：缺实训、缺拓展案例、缺原理细节、缺思政融入
5. 输出完整的章节厚度统计表

输出：将完整报告写入 {{报告输出路径}}，包含章节厚度统计表与优先扩充建议。
```

## 二、章节扩充 Agent 模板（阶段3，每章一个）

每个待扩充章节启动一个独立 Agent（后台并行）。**Agent 只负责生成内容并写入独立文件，严禁直接修改教材正文。**

```
你需要为《{{教材名}}》的第{{N}}章"{{章节名}}"大幅扩充内容。

**当前状态**：第{{N}}章只有约{{当前字数}}字，需要扩充到{{目标字数}}+字。
**当前章节位置**：{{文件名}}，从第{{起始行}}行到第{{结束行}}行（"## 第 {{N}} 章"到"---"分隔线）
**当前章节结构**：
- {{小节名}}（约{{字数}}字）
- {{小节名}}（约{{字数}}字）
- ...

**扩充目标**：增加约{{扩充字数}}字，使总字数达到{{目标字数}}+
**扩充方向**：
1. 增加完整实训场景 {{个数}} 个：{{场景名称}}。每个实训需含：任务目标、操作步骤（5-8步）、提示词模板、评价观测点
2. 增加拓展案例 {{个数}} 个：{{案例方向}}。案例需有真实背景、数据或出处
3. {{其他方向：代码示例/原理讲解/思政融入等}}
4. 保持与既有小节结构衔接，可新增小节但不要破坏原有编号逻辑

**风格与术语要求**：
- 风格与教材正文一致：面向{{读者对象}}，语言{{正式/口语化}}，多用具体步骤而非抽象描述
- 全文使用教材指定术语：{{术语清单，如工具名、概念名}}
- 涉及数据或外部信息时标注来源（〔来源：...〕）

**输出要求**：将扩充内容（不含原章节已有内容）写入文件 {{输出文件路径}}，
文件内按小节用 ## 标题组织。不要修改教材正文文件。
```

---

## 三、使用要点

- 扫描 Agent 报告文件建议放在工作区 outputs/ 下；扩充 Agent 输出文件用 ch{N}_expanded.md 命名，便于脚本批量注入
- 扩充 Agent 提示词中的"当前章节位置"（行号范围）在启动前用 `grep -n "^## 第.*章"` 现查，保证准确
- 若多个章节结构相似（如都有"思政融入"），提示词中注明各自的注入锚点约束（行号范围），避免后续注入错位
