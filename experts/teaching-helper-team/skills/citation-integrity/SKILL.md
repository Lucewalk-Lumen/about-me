# 引用保真校验清单
> **归属**：质量门禁层（quality）——引用保真校验清单，全团文本交付前必读

本清单只管一件事：**这条引用是不是真的存在，它是不是真说过你写的那句话。**

`deai-rules` 管文字读起来像不像人写的，`long-manuscript-core` 管长稿结构稳不稳，这两者都不检查引用的真伪。一篇文字通顺、结构完整、参考文献全是编的论文，在前两道门禁下可以完整通过。本清单补的就是这个缺口，与前两者互不替代、同时生效。

## 为什么这道门禁必须存在

AI 生成学术引文的伪造率不是小概率事件。Nature 子刊 Scientific Reports 2023 年的实证研究显示，ChatGPT 生成的学术引文中 30%-55% 是假的。原因是模型对"具体文献"记不清时会做**合理化补全**——它不是在撒谎，它是在填空，而填出来的东西格式完美、看起来极其可信。

两类使用者面对的风险不一样：

| 使用者 | 典型场景 | 最致命的后果 | 最容易犯的错 |
|--------|---------|-------------|-------------|
| 学生（本科/研究生毕业论文） | AI 帮忙补文献综述、凑参考文献条数 | 答辩现场或查重抽查命中假引用，直接认定学术不端，论文作废 | 无意识信任——格式规范就默认是真的，从没打开过原文 |
| 教师（教学案例、课程思政案例、课程材料） | 案例里引政策条文、行业数据、获奖记录 | 案例入库/申报被查出虚构文件名或数据，影响个人学术声誉 | 赶进度——检索不到就写成"据研究表明""相关数据显示" |

学生这一侧尤其要强调：**你没有"我不知道它是假的"这个免责空间**。署名在论文上的是你，核验责任就在你。

## 规则来源与冲突消解（SSOT）

本文件是教学帮帮团引用保真规则的**单一事实来源**，本文件即该标准在教学场景的落地展开。各技能包内的引用规则均为下游派生：

| 层级 | 文件 | 定位 |
|------|------|------|
| L0 权威层 | `skills/citation-integrity/SKILL.md`（本文件） | 引用保真通用规则，全团适用 |
| L1 派生层 | `skills/thesis-mentor/references/core/academic-citation-standard.md` | 学位论文的**引用格式与来源限定**细则；格式层，不得放宽本文件的核验要求 |
| L1 派生层 | `skills/case-writer/references/case-reference-standard.md` | case-writer **引用标记与参考文献著录**统一标准（合并 A/B/D 三条模板路径）；格式层，锚定本文件，更严不更宽 |
| L1 派生层 | `skills/case-writer/references/source-integrity.md` | 教学案例**来源采集与资料检索**细则；采集层，不得放宽本文件的核验要求 |


**冲突消解规则**：

1. L1 与 L0 冲突时，一律以 L0 为准。
2. L1 只做增量约束（更严），不得放宽 L0。放宽必须先改 L0。
3. 与 `deai-rules` 的关系：去 AI 味是风格级操作，**引用保真优先级高于一切去 AI 改写**。改写时禁止顺手删改引用标记、参考文献条目与统计数字。

## 第零层：四条铁律

下表左列是四条铁律的原文表述（交付前 0 violations），中右两列是教学场景的落地口径。

| 铁律 | 原文表述 | 学生写毕业论文 | 教师写教学案例 |
|------|---------------|---------------|---------------|
| 一、不编引用 | 不捏造不存在的文献、作者、年份或统计数字 | 参考文献表里的每一条，你都必须能在数据库里检索到它本身；没读过、查不到的，一条都不许进表——哪怕它"看起来应该存在" | 不虚构政策文件名、发文字号、行业数据、获奖记录、企业公开数字 |
| 二、不归观点 | 观点必须归到具体作者与年份，不得张冠李戴 | 写"张三（2021）认为……"前，你必须在张三 2021 那篇里找到这句话；不许写"有研究表明""学界普遍认为"这类无主语归属 | 不把行业观点安到具体企业或专家名下；教师自己的判断注明"基于笔者教学实践观察" |
| 三、标注无支撑 | 无文献支撑的论断须显式标注"无支撑" | 找不到支撑就明写 `〔无可靠来源，待核实〕`，不许静默留着，也不许临时编一个支撑上去 | 同上，用本包统一标记 `〔无可靠来源，待核实〕`；不许用"大量""显著""普遍"这类模糊断言顶替可标注来源 |
| 四、不超范围 | AI 产出仅为辅助，不得超范围代表作者作出学术承诺或投稿决定 | AI 不替你担保文献真实性、不替你判断能否通过答辩、不替你决定投哪本刊；超出你提供材料范围的发挥，AI 必须主动报告而不是悄悄补全 | AI 不替教师担保政策表述的时效性与准确性，不替教师作出案例可申报、可入库的判断 |

四条铁律**交付前 0 violations**。

## 第一层：条目核验（一条引用怎么算核过）

### 核验四问

对参考文献表里的**每一条**，依次回答四个问题。**四问全过才算"已核实"**，任一问不过即进入第三层标注处置。

1. **它存在吗**——把标题加英文引号做精确检索，能不能在对应数据库命中这一条本身。
2. **它是这么写的吗**——作者、年份、刊名、卷期、起止页，逐字段与检索结果对上，不是"差不多"。
3. **你引的那句话是它说的吗**——打开原文（PDF 或全文页），定位到具体的页码或段落，确认这个论断确实出自这里。
4. **你把它归给谁了**——正文里的观点归属（谁在哪一年说的）与原文的作者、年份一致。

> 第 3 问是学生最容易跳过、也最容易翻车的一问。**条目是真的，不等于那句话是真的**。AI 常见的做法是找一篇真实存在的文献，然后编一句符合你论点的话挂在它名下。只查前两问等于只做了一半。

### 核验入口对照表

| 文献类型 | 首选核验入口 | 核到什么程度算过 |
|---------|-------------|----------------|
| 中文期刊论文 | CNKI / 万方 / 维普，标题精确检索 | 标题、作者、刊名、年卷期、起止页五项全对上 |
| 中文学位论文 | CNKI 学位论文库 / 学校图书馆目录 | 作者、授予单位、学位年度对上；页码以原文 PDF 为准 |
| 英文期刊论文 | 先访问 `https://doi.org/<DOI>`，再用 Crossref 或 Google Scholar 交叉检索 | DOI 能解析，且落地页的标题与作者与条目完全一致 |
| 会议论文 | ACM DL / IEEE Xplore / 会议官网论文集 | 会议全称、届次、年份、页码对上 |
| 学术专著与教材 | 国家图书馆联机目录 / 出版社官网 / ISBN 检索 | 书名、作者、出版社、版次、ISBN 对上；引用具体观点须给章节或页码 |
| 政策文件 | 发文机构官网原文（教育部、人社部、国务院等） | 文件全称、发文字号、发布日期三项对上，且是现行有效版本 |
| 统计数据 | 统计年鉴原书 / 机构官方报告原文 | 指标口径、统计年份、表号或页码对上 |
| 新闻报道与商业行业报告 | 原发媒体或发布机构官网 | **不得作为学术论证支撑**；教学案例中仅可作背景素材，且须标注来源与检索日期 |

### 单条核验记录（最小字段）

核验过程不能只在脑子里过，要留痕，否则第二天你自己也说不清哪条查过。每条至少记这几个字段：

```
序号 | 正文出现位置 | 条目原文 | 类型 | 核验入口 | Q1 存在 | Q2 字段 | Q3 原文落地 | Q4 归属 | 状态 | 处置
```

`状态` 三取一：`已核实` / `未获取原文` / `未证实归属`（定义见第三层）。`处置` 列在状态非"已核实"时不得为空。

## 第二层：AI 编造引用的九个特征

下面九条是识别信号，用来决定"先查哪几条"，**不是判定依据**。命中任一条即列为高风险优先核验；判定仍以第一层核验四问为准。

| 编号 | 特征 | 长什么样 | 一眼识别法 |
|------|------|---------|-----------|
| F1 | DOI 解析失败或指错 | `10.xxxx/yyyy` 访问后 404，或跳转到一篇完全不相干的文章 | 把 DOI 拼到 `https://doi.org/` 后面直接点开，30 秒见分晓 |
| F2 | DOI 前缀与出版社对不上 | 一篇 Elsevier 期刊的文章挂了 Springer 的 DOI 前缀 | 同一本刊的历史文献 DOI 前缀应当一致，找该刊另一篇真文献比对前缀 |
| F3 | 卷期与年份不闭合 | 写"2019 年，第 45 卷第 3 期"，但该刊 2019 年实际是第 41 卷 | 期刊卷号逐年递增，查该刊官网任一年份的卷号，往前往后一推就知道 |
| F4 | 作者张冠李戴 | 真实存在的作者 + 真实存在的期刊 + 编造的标题 | 最难识别也最常见。搜到作者本人不算过关，必须搜到**这一篇** |
| F5 | 标题过于贴题 | 标题与你正文的论点严丝合缝，像是照着你的句子倒推出来的 | 越是"完美契合"越可疑，真实文献很少这么恰好 |
| F6 | 刊名嫁接或虚构 | 把领域内两本刊的名字拼在一起，或造出"某某管理评论"这类似是而非的刊名 | 到中国知网期刊导航或期刊官网确认这本刊存在且现刊在办 |
| F7 | 页码区间异常 | 一篇综述给了 3 页，一篇研究简报给了 40 页；或起止页超出该期总页数 | 按文章类型估页数，明显不合常理的单拎出来查 |
| F8 | 中英体例夹生 | 中文文献配了英文 DOI 体例，或英文文献给了 CNKI 链接 | 体例混搭往往是模型把两条记忆缝在一起了 |
| F9 | 时间线倒挂 | 引用某理论的"首创"文献，年份却晚于引用它的后续研究；或早于该理论提出年份 | 把同一理论的几条引用按年份排一下，逆序的立刻现形 |

**成簇规律（重要）**：编造引用极少单独出现。**同一段落、同一批 AI 生成内容里只要查实一条是假的，其余条目必须整批重查**，不要抽样。

## 第三层：三态标注与处置

核验结果落到三态之一。三态定义见下表，门控动作一致。

| 状态 | 含义 | 门控动作 |
|------|------|---------|
| 已核实 | 条目存在、字段一致、原文已获取、观点归属已证实（核验四问全过） | [绿/通过] 可进入成稿，可作为论证支撑 |
| 未获取原文 | 条目确实存在，但原文未取得，无法核对你引的那句话（Q1/Q2 过，Q3 未过） | [红/不通过] 置于稿件顶部待办清单，**不得作为正文论证支撑** |
| 未证实归属 | 已见原文，但该观点是否出自该作者尚未证实（Q3 过，Q4 未过） | [红/不通过] 标注待核实，**观点不得归到该作者名下** |

**串联规则**：所有"未获取原文 / 未证实归属"项统一列在稿件顶部的待核实清单。存在任一 [红/不通过] 项时，不得声称"参考文献已核对完毕"，不得进入交付。

### 文内标记语法（全包统一）

沿用本包已有标记，不新造符号：

- 无可靠来源，暂时查不到：`〔无可靠来源，待核实〕`
- 政策/文件来源：`〔来源：《文件全称》，发布机构，年份〕`
- 数据/统计来源：`〔来源：机构/报告名，年份；检索日期 YYYY-MM-DD〕`
- 教师主观经验：`基于笔者教学实践观察`（不套用来源标记）

### 核不出来的四条处置路径

按优先级从上往下试，**不许原地编一个支撑**：

1. **换检索式再试一次**——中文标题查不到就用英文标题、作者姓名加关键词、DOI 反查，三种方式都零命中才算未命中。
2. **换一条真文献替代**——去数据库找一篇真实的、能支撑同一论点的文献，替换掉原条目。这是最推荐的路径。
3. **改写论断**——把依赖该出处的表述改成不需要外部支撑的写法（如改为对本研究数据的描述），删掉该引用。
4. **显式标注保留**——确实无法替代且论断必须保留时，标 `〔无可靠来源，待核实〕`，同时进顶部待核实清单。**这是待办不是终态**，交付稿正文中此类标记必须为 0。

## 第四层：交付门槛

交付前逐项过，任一项不过即打回。

| 检查项 | 判据 | 不过怎么办 |
|--------|------|-----------|
| 条目存在率 | 参考文献表 100% 条目通过核验四问 Q1、Q2 | 存在未命中条目即删除或替换，不得留在参考文献表里 |
| 原文落地率 | 直接引语、具体数字、关键结论 100% 落到具体页码或段落（Q3） | 落不到即按第三层四条处置路径处理 |
| 归属正确率 | 正文观点归属 100% 与原文作者、年份一致（Q4） | 张冠李戴的改归真实作者，或删除该论断 |
| 待核实项清零 | 交付稿正文中 `〔无可靠来源，待核实〕` 计数为 0 | 未清零则不得标记为交付物，退回处置 |
| 编号一致性 | 正文引用编号与参考文献条目一一对应、连续、无孤条 | 见下方 `deai_preflight.py` 联动 |
| 与去 AI 味门禁联动 | `deai-rules` 的 `deai_preflight.py` 中 `MISSING_REFERENCE`（P0）与 `UNCITED_REFERENCE`（P1）清零 | 运行 `python skills/deai-rules/scripts/deai_preflight.py <稿件>` 修到清零 |

**双门禁次序**：先过本清单（引用真伪），再过 `deai-rules`（文字风格）。次序不能反——去 AI 味改写会动文字，改完再核引用等于白核。

## 批量作业法：一篇论文 30 条参考文献怎么走一遍

给学生的可执行流程。逐条盲查 30 遍是最慢的做法，按下面五步走。

**第一步：建表（约 15 分钟）**
把参考文献表复制进一张表格，列头用第一层的"单条核验记录"字段。序号按正文出现顺序排，不要按字母重排——后面回改正文时好定位。

**第二步：排优先级，先查高风险的**
不要从第 1 条查到第 30 条。先把下面四类挑出来插到最前面：

- AI 帮你补的条目（你自己没检索过的）
- 英文文献（学生最难核、编造率最高）
- 你只看过摘要没看过全文的
- 支撑核心论点的（第二章现状、第四章对策的关键依据）

其余的（你自己下载过 PDF 的、导师给的）放后面，通常一遍就过。

**第三步：按类型分批查，不要逐条切换入口**
中文期刊的十几条连着在 CNKI 里查完，英文的连着用 DOI 加 Crossref 查完，政策文件连着在官网查完。同一入口连续作业比来回切数据库快一倍以上。

**第四步：设时间盒**
单条 3 分钟查不出来，直接判"未命中"填进状态列，进入第三层处置，不要在一条上死磕。30 条按这个节奏，正常 1.5 到 2 小时能走完一轮。

**第五步：收口**
- 状态列不得有空格，30 行必须 30 个状态。
- 出现任一"未命中"，同段落、同批次的其余条目整批重查（见 F 系列成簇规律）。
- 汇总一份顶部待核实清单，逐条写处置结论。
- 最后跑一遍 `deai_preflight.py`，确认编号一致性。

> 核验登记表按 `skills/_shared/DATA-CONTRACT.md` 的命名规范落盘到 `data/pipeline/working/`，命名 `{task_id}_revise_{skill}-citation.md`，供后续阶段与答辩前复查回溯。

## 借口与事实

学生在核验环节最常说的几句话，以及为什么它们站不住。

| 常见说法 | 事实 |
|---------|------|
| "AI 给的格式很规范，应该是真的" | 格式规范恰恰是模型最擅长的部分。格式正确不等于文献存在 |
| "作者我搜到了，是真人" | 真作者加假标题是最常见的编造形态（F4）。搜到人不算过，必须搜到那一篇 |
| "知网搜不到，可能是外文库收录的" | 换英文标题和 DOI 再查一次。两种入口都零命中，即按未命中处理 |
| "就一两条查不到，不影响大局" | 抽查命中一条即可认定学术不端。比例不构成理由 |
| "老师应该不会去查参考文献" | 查重系统与答辩委员会都会抽查引文，这是常规动作 |
| "先写着，最后统一查" | 最后统一查在实践中等于不查。写一条查一条，或每写完一章清一次 |
| "这个观点大家都这么说，不用找出处" | "大家都这么说"就是四铁律第二条禁止的无主语归属。要么找到具体作者和年份，要么标注无支撑 |

## 执行流程

1. **建表**：把参考文献表转成核验登记表，按正文出现顺序编号。
2. **排序**：按第四步优先级把高风险条目提前。
3. **核验**：逐条走核验四问，用核验入口对照表选数据库，命中 F1-F9 任一特征的条目重点查。
4. **标注**：结果落三态，非"已核实"的填处置列，并汇总到稿件顶部待核实清单。
5. **处置**：按四条处置路径清空待核实项。
6. **门禁**：过第四层交付门槛六项；再交给 `deai-rules` 做风格门禁。
7. **回报**：向主理人回传时说明总条目数、已核实数、处置方式，不得只说"引用已核对"。

## 附录：一页速查卡

# 引用保真校验清单（速查卡）

本卡是**一页速查入口**，与正文同为全团 L0 权威层，不新增也不放宽任何要求。完整规则（核验四问、AI 编造引用九特征、三态标注处置、批量作业法、交付门槛）见本文件正文对应章节，冲突时以本文件正文为准。

适用范围：凡产出中出现文献引用、政策条文、行业数据、获奖记录或任何带出处的数字，交付前必须逐条过本卡。

## 三项硬条件（缺一不可）

每一条引用同时满足以下三项，才允许写进交付稿：

| 条件 | 判定标准 | 不满足时 |
|------|---------|---------|
| 一、真实存在 | 该文献/文件/数据本身确实存在，能在数据库、官网或正式出版物中定位到实体，不是"看起来应该存在" | 整条删除，或降级为〔无可靠来源，待核实〕 |
| 二、可核实 | 他人能按你给的信息独立复现检索路径：文献有可检索的题名与作者，政策有发文机关与文号，数据有机构与报告名 | 补齐可检索信息；补不齐即标注待核实 |
| 三、引用格式与出处一致 | 文内标注、参考文献条目、原始出处三者信息完全对得上：作者、年份、题名、期刊/机构、卷期页码、DOI 均不矛盾 | 以原始出处为准修正，不得反向改写出处迁就已写内容 |

三项条件的检验顺序不可颠倒：先确认存在，再确认可核实，最后核对格式。跳过前两项直接美化格式，是最常见的失效方式。

## 四条铁律

下列四条为此处教学与论文场景的落地口径，**交付前 0 violations**。

1. **不编引用**——不捏造不存在的文献、作者、年份、期刊或统计数字。学生：参考文献表每一条都要能检索到本体，没读过、查不到的一条都不进表。教师：不虚构政策文件名、发文字号、行业数据与获奖记录。
2. **不归观点**——观点必须归到具体作者与年份。写"张三（2021）认为……"之前，必须在张三 2021 那篇里找到这句话；禁止"有研究表明""学界普遍认为"这类无主语归属。教师自身判断注明"基于笔者教学实践观察"。
3. **标注无支撑**——找不到支撑就显式标注，不许静默留着，更不许临时编一个支撑补上。
4. **不超范围**——AI 产出仅为辅助，不替作者担保文献真实性，不替作者作出答辩、投稿、案例入库或申报的判断；超出用户所给材料范围的内容必须主动报告，不得悄悄补全。

## 待核实标注规则

无法核实的条目**必须显式标注**，统一使用标记：`〔无可靠来源，待核实〕`

- 标注位置紧跟该论断或引用之后，不得只在文末统一说明。
- 标注是**临时状态而非终态**：交付前必须清零——要么补到可核实，要么删除该论断。带着待核实项交付，视同未过门禁。
- 禁止用模糊表述替代标注：出现"大量""显著""普遍""据研究表明""相关数据显示"而无具体出处的，一律按无支撑处理。

## 严禁编造清单

以下内容一经发现即退回重做，不接受"格式先占位、后面再补"的理由：

- 编造作者姓名，或把真实作者安到并非其所著的文献上
- 编造出版年份，或为凑时效性把旧文献改写为近三年
- 编造期刊名、卷期页码、DOI、ISBN、会议名称
- 编造政策文件名、发文机关、发文字号、生效日期
- 编造统计数字、样本量、调查机构、获奖记录

DOI 与官方链接必须是可直接打开验证的完整地址，不得凭格式规律推导拼接。

## 交付前动作

1. 参考文献表逐条过三项硬条件，标记每条状态：已核实 / 待核实 / 应删除。

3. 待核实项清零。
4. 去 AI 味改写与引用保真冲突时，**引用保真优先**：改写过程禁止顺手删改引用标记、参考文献条目与统计数字。
