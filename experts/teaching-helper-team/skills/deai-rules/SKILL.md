# 去AI味四层规则库
> **归属**：质量门禁层（quality）——全团门禁，挂主理人 lead


> 教学帮帮团所有专家交付前必须执行本规则库。**去AI味不等于压缩**：研究对象、数据口径、样本量、方法条件、结论边界、专有名词、引用标记一律保留，只砍 AI 病灶。

## 规则优先级与冲突消解（SSOT）

本文件是全团去AI味规则的**单一事实来源（Single Source of Truth）**。原 L1 镜像层（minutes-organizer）与 L2 增量层（case-writer）已并入本文件「第三层：文体专用规则」，不再维护下游派生副本：

| 层级 | 文件 | 定位 |
|------|------|------|
| L0 权威层 | `skills/deai-rules/SKILL.md`（本文件） | 通用规则 + 文体专用规则（第三层），全团唯一 SSOT |
| 领域细化层 | 各技能的教材/讲义质检细则（如 `skills/course-builder/references/textbook-quality/`） | 教材质检评分体系的领域细化，只增不减，不得与 L0 冲突 |

**冲突消解规则**：

1. 领域细化层与 L0 冲突时，**一律以 L0 为准**。
2. 文体确需放宽某条 L0 约束时，必须在下方「文体豁免登记表」显式登记后方可生效；未登记的放宽视为缺陷。
3. 领域细化层禁止出现 L0 没有的新规则；新规则一律先入 L0。

### 文体豁免登记表

| 豁免项 | 适用文体 | L0 原文 | 豁免后口径 | 理由 |
|--------|---------|---------|-----------|------|
| 破折号 | 教学/思政案例 | 破折号（——）全篇 0 处 | **案例叙述正文 0 处**；人物直接引语内允许保留说话人原有停顿 | 案例的引语需保留现场口语节奏，强行替换会失真 |

> 除上表所列，其余标点与词表约束在所有文体下等同 L0，无豁免。

## 第一层：英文通用规则（24 类英文 AI 高频模式）

- 意义/遗产/趋势膨胀词：stands/serves as、testament、pivotal role、underscores、setting the stage for
- 知名度强调：independent coverage、leading expert、active social media presence
- -ing 结尾浅析：highlighting/underscoring/symbolizing/reflecting
- 促销广告语言：boasts a、vibrant、nestled、breathtaking、must-visit
- 模糊归因：Industry reports、Experts argue、Some critics
- 提纲式 Challenges 段落
- AI 高频词汇：Additionally/align with/crucial/delve/emphasizing/fostering/garner/interplay/intricate/landscape/pivotal/showcase/tapestry/testament/underscore/vibrant
- 回避系动词：serves as/stands as/marks/boasts 代替 is/are
- 否定排比：Not only...but、It's not just X, it's Y
- 三点法（rule of three）强迫症
- 同义替换循环（elegant variation）
- 假区间（from X to Y 中 X/Y 不在同一量纲）
- 破折号滥用（em dash）
- 加粗滥用、内联标题竖排列表、标题 Title Case、emoji 装饰、弯引号
- 聊天机器人残留：I hope this helps、Of course!、Certainly!
- 知识截止免责声明：as of [date]、Up to my last training update
- 谄媚语气：Great question!、You're absolutely right
- 填充短语：In order to→To、Due to the fact that→Because、has the ability to→can
- 过度限定、泛泛积极结论

改写后必须：**注入灵魂**——有观点、节奏变化（长短句交错）、承认复杂性、具体化感受、允许一点"乱"。

## 第二层：中文通用规则（deai-rules 实战版）

### AI 高频词（删除/替换）
| AI 痕迹词 | 处理 |
|---------|------|
| 值得注意的是 | 删除，直接表达具体内容 |
| 综上所述 | 概括来说、具体来看、总体而言 |
| 不难发现 | 数据分析表明、结果显示 |
| 不可否认 | 根据证据、研究显示 |
| 旨在 | 以...为目标、目的是 |
| 为...提供了重要启示 | 具体说明对谁、有何启示 |
| 深入探讨 | 分析、检验、考察 |
| 与此同时 | 同时、此外 |
| 显著改善 | 提升/降低了X（量化） |
| 发挥着重要作用 | 具体说明何种作用 |
| 众所周知 | 引用具体来源，或删除 |
| 近年来 / 随着社会的发展 | 删除，直接切入 |
| 越来越受到关注 / 引起了广泛关注 | 删除 |
| 填补了...空白 | 明确具体空白 |
| 有待进一步研究 | 删除或具体化 |
| 基于此 | 据此，或直接陈述结论 |

### 标点控制（强制）
- 破折号（——）：全篇 0 处
- 分号（；）：每 1000 字 ≤2 个
- 避免连续 2 段以上冒号+列表

### 空洞开头清理
删除：在...的背景下、在当今快速变化的...、不言而喻、事实上、应该指出的是、值得一提的是

### 结构模式警告
- 三点法强迫症 → 按证据实际需要 2/3/4 点
- 段落长度均一化 → 短段强调、长段展开
- 镜像结构 → 不每章结构相同
- 二元对比"不是X而是Y" → 全篇 ≤2 次

### 四类高频病灶（改稿实战逐条排查）
| 病灶 | 典型表现 | 处理 |
|------|---------|------|
| 1. 镜像对仗句 | "一方面…另一方面""其一…其二…其三"密集成对 | 打散为长短不一的自然陈述 |
| 2. 段段升华收尾 | 每段结尾都拔高到"意义/价值/启示" | 删多余升华，仅真正需要处升华一次 |
| 3. 空转动词 | "进行分析""加以说明""予以考察" | 换落地实义动词："分析了""考察了" |
| 4. 万能指代开头 | 段首高频"上述""这一""该"起句 | 直接点名所指对象或重述关键名词 |

### 句长变化
连续 5 句以上字数同区间（如 20-25 字）时，插入短句（≤10 字）或合并复杂句。

## 第三层：文体专用规则

### 案例文体（L1/L2 门禁）
- **L1 硬性（任一项不通过必须改）**：一级禁用词零命中（赋能/打造/助力/彰显/旨在/具有重要意义/迈出了关键一步/绘就/构筑/夯实/影响深远/成效显著/可圈可点/亮点纷呈）、无套话开头（在当今…的时代/随着…的不断发展/毋庸置疑/总而言之）、无公式化结尾（实现了…的有机统一/为…提供了坚实保障/必将…）、无连续三段排比
- **L2 风格（明显不通过建议改）**：具体事件/人切入、长短句交替、关键引语/对话、矛盾或两难、像真人在讲真事
- 二级慎用（每段最多 1 次）：此外/然而/因此/与此同时/值得注意的是/不难发现/不是A而是B/既是…也是…；双引号堆砌（真实引语用「」）
- **结构陷阱（改稿逐条排查）**：大段加粗+bullet 堆砌（正文用叙述，关键句自然浮现）；每段句长与结构高度一致（长短句交错，允许一句成段）；只写成功/流水账/重叙事轻分析（须有问题/冲突/两难）；"下面就来介绍…"等元评论（删）
- **改味手法（改最少、效果最大）**：禁用词→具体动作/数字（"成效显著"→"到 2025 年合作场次破千"）；情感告知→动作（"他很紧张"→"他的手在抖"）；套话开头→具体事件切入（从一场直播/一个人/一个数开始）；公式化结尾→场景/判断收尾（"陈航把笔丢在白板中间"而非"实现了效率与公平的统一"）

### 纪要与综述文体（TEEL 强制）
- 每段 TEEL：T 主题句（段首核心判断）+ E 证据 + E 解释（因果/递进）+ L 衔接（连下一段或回归论点）
- 禁止"事实A。事实B。事实C。"平行罗列
- 句间连接词自然融入：因此/由此/进而/然而/不过/尽管/诚然

## 第四层：量化诊断层

> 本层提供数据级诊断信号，作为前三层规则匹配的辅助定位手段。规则层判定优先；量化指标用于定位「感觉有机器味但规则未命中」的灰色段落。

### 统计信号

| 指标 | 人类区间 | AI 区间 | 用途 |
|------|---------|---------|------|
| 突发性 burstiness | 0.5-1.0 | 0.1-0.3 | 句长变化是否充分 |
| 型符比 TTR | 0.5-0.7 | 0.3-0.5 | 词汇多样性是否过低 |
| 句长变异系数 | 高 | 低 | 句式是否单一 |
| 三元组重复率 | 低 | 高 | 是否模板化重复 |

诊断方法：通读后计算上述指标，落入 AI 区间的段落重点排查前三层规则；指标仅作定位辅助，不单独判定不合格。

### 三级词汇体系

- **Tier 1 必删**：delve、tapestry、vibrant、crucial、robust、seamless、groundbreaking、leverage、synergy、transformative；中文对应：赋能、打造、助力、深耕、生态、织锦、充满活力
- **Tier 2 视密度处理**：furthermore、paradigm、holistic、utilize、facilitate；中文对应：至关重要、深入探讨、格局、旨在、综上所述
- **典型短语**：「In today's digital age」「plays a crucial role」「serves as a testament」；中文：「在……的背景下」「标志着……的重要时刻」「致力于」

### 中文适配降权

英文专属模式在中文中自动降权：标题 Title Case、弯引号差异。尊重中文标点与引号习惯（真实引语用「」）。

## 交付门槛：五维质量自评

> 交付前对成稿执行五维自评（各 10 分，满分 50），与 deai_preflight.py 确定性预检形成「量化自评 + 确定性预检」双门禁。

| 维度 | 评判要点 |
|------|---------|
| 直接性 | 是否直陈而非绕弯；禁用词是否清零 |
| 节奏 | 句长是否长短交错；有无连续 5 句同区间 |
| 信任度 | 是否点名来源或删掉无据论断；有无模糊归因 |
| 真实性 | 有无观点、承认复杂性、允许一点「乱」 |
| 精炼度 | 填充短语是否清除；有无空转金句 |

**门槛**：45-50 分可交付；35-44 分继续打磨；低于 35 分重新修订。

## 应用场景与调用模式

| 调用模式 | 触发条件 | 输出 |
|---------|---------|------|
| 粘贴模式 | 用户直接粘贴文本要求去 AI 味 | 先重写完整文本，再附改动摘要（按模式类别列原文→改后对照） |
| 文件模式 | 用户提供文档文件要求改写 | 只改正文，代码块/frontmatter/数据/链接保持原样；对话报告改动摘要，不整篇回贴 |
| 嵌入模式 | 作为其他专家交付流程的内嵌门禁 | 只输出最终文本，门禁结果计入交付检查 |

去 AI 味是横切门禁（挂主理人，全团适用）。案例 L1/L2 门禁、纪要 TEEL 等文体专用规则已统一并入本文件「第三层：文体专用规则」，不再分散于各专家内部维护；本规则库同时承担 L0 通用门禁与文体专用规则，是唯一 SSOT。

## 可执行预检（deai_preflight.py）

本门禁配套一个**零依赖** Python 预检脚本 `scripts/deai_preflight.py`，把上面的文档规则变成机器可跑的检查，适合在交付前对成稿做一次性体检。

**检查项与严重级：**

| 代码 | 严重级 | 含义 |
|------|--------|------|
| PLACEHOLDER | P0 | 未关闭占位符：`AUTHOR_INPUT_NEEDED`、`[TODO]`、`[待补...]`、`待核验` |
| OVERCLAIM | P1 | 无边界强化主张：首次证明 / 填补了空白 / 完全证明 / 必然导致 / 普遍适用 / unprecedented / proves that / always / never |
| VAGUE_LANGUAGE | P2 | 空泛或模板化表达：具有重要意义 / 不言而喻 / 毋庸置疑 / 值得注意的是 / it is worth noting that / plays a crucial role |
| HEADING_JUMP | P2 | 标题层级跳级（如 H2 直接跳到 H4） |
| DUPLICATE_CAPTION | P2 | 图/表题注编号重复 |
| MISSING_REFERENCE | P0 | 正文引用〔n〕缺参考文献条目 |
| UNCITED_REFERENCE | P1 | 参考文献未在正文引用 |

**运行方式：**

```bash
# 文本模式（人类可读）
python skills/deai-rules/scripts/deai_preflight.py draft.md
# JSON 模式（流水线集成）
python skills/deai-rules/scripts/deai_preflight.py draft.md --json
# 严格模式（P1/P2 也判失败，退出码 1）
python skills/deai-rules/scripts/deai_preflight.py draft.md --strict
```

**退出码：** `0`=PASS（或无问题）；`1`=存在 P0（或严格模式下存在任何问题）；`2`=输入文件不存在。脚本无任何第三方依赖，可直接用系统 Python 运行。

> 预检只做确定性文本体检，不验证研究事实、统计或版式；最终仍须结合上方 L0/L1/L2 文档规则与人工复核。

## 执行流程
1. **扫描**：通读成稿，标出一级禁用词、套话开头、公式化结尾、连续排比、四类病灶
2. **量化诊断**：对疑似段落计算统计信号并比对三级词汇，定位灰色机器味
3. **改味**（改最少、效果最大）：禁用词→具体动作/数字；情感告知→动作；套话开头→具体事件切入；公式化结尾→场景/判断收尾
4. **注魂**：补具体感官细节、对话、矛盾；允许不完美与真实张力
5. **门禁判定**：L1 任一项不通过必须改；L2 明显不通过建议改；五维自评 ≥45 分且 deai_preflight.py PASS 方可交付

## 引用保真（与去AI味联动，不可妥协）
- 交付材料必须**原样保留**〔R-xx〕〔综述·X〕等原始引用标记，禁止 AI 顺手清理引用或编造数字
- 不编引用 / 不归观点 / 标注无支撑〔无可靠来源，待核实〕/ 不超范围
- 学术术语（构念、理论谱系、调节效应等）予以保留，只砍病灶不做内容压缩
