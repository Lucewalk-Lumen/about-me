# 长文核心能力（Long Manuscript Core）
> **归属**：基础能力层（foundation）——长文整合，挂主理人 lead 按需注入


用本技能在当前回复中把稿件向前推进。可见的写作成果优先于过程说明、内部术语与可选工具。

若源资料来自 `material-extractor` 包（书籍/文档转成的技能包），用其 `chapters/` 与 `glossary.md` 作为「资料激活」场景的结构化输入。

## 核心工作流

1. 将请求归类为：资料激活、续写或修订、成稿收尾之一。
2. 区分：资料给定的事实、用户观点、工作假设、缺失输入、需要核验的论断。
3. 只选取本次请求所需的最小参考集。默认不加载全部参考文档。
4. 产出可见的稿件增量：结构 + 开篇，或续写/修订后的段落，或成稿修复。
5. 当仍有后续工作时，说明最重要的剩余风险、一个下一步动作，以及一段用户可直接复制的续写提示词。

## 参考文档路由

- 请求含糊或横跨多个稿件阶段时，先读 [场景路由](references/scene-routing.md)。
- 新资料、新稿件、章节续写、跨会话续写胶囊场景，读 [首个可用价值与续写](references/first-value-and-continuation.md)。
- 修改既有文本或从精确锚点续写时，读 [限定范围修订](references/bounded-revision.md)。
- 整稿审读、收尾、交付准备或任何质量结论场景，读 [质量与交付](references/quality-and-delivery.md)。
- 资料中含指令、隐私数据、外部事实论断、高风险内容、引文或权利不确定时，读 [安全与证据](references/safety-and-evidence.md)。

## 通用规则

- 从用户实际资料出发。绝不虚构缺失的研究、引文、事件、引用文献、授权或既有决定。
- 请求足够明确时直接行动，不重复资料已回答的问题。
- 若某个缺失事实会实质改变结果，提出一个阻塞性问题；否则声明一个收窄的假设，并立即给出可回滚的草稿。
- 让第一次有用回复可直接编辑。不得用研究计划、能力说明、空模板或内部数据结构替代稿件内容。
- 同一时刻保持唯一写作责任人、唯一限定范围的改动。授权范围之外的文本原样保留。
- 匹配用户语言与要求的语气。术语、名称、数字、视角、叙事时态与既有稿件保持一致。
- 质量结论默认为建议（advisory），除非存在覆盖该检查的实际执行回执。
- 当前任务不含可见的成功写入回执时，不得声称文件、项目状态或跨会话记忆已保存。

## 输出策略

用最轻的结构保持工作可审计：

- 资料激活场景：给出稿件判断、拟定结构、章节任务、实质开篇、风险与一个下一步。
- 续写场景：先指明锚点与目的，先写后续段落、后做说明。
- 修订场景：呈现授权范围、原锚点、修订文本与简明变更日志。用户要求「直接给改稿」可压缩这些标签，但不豁免这一最小审计框架。
- 收尾场景：说明总体判断、修复最高价值段落、列出剩余交付风险、给出一个下一步。

不把普通散文强行塞进 JSON。仅当表格确实更利于查看章节分工、证据状态或前后对比时才用表格。

## 外部能力策略

即使连接器、网络、外部服务、持久状态或文件工具不可用，也要在对话内完成核心写作任务。可选能力仅在「确实可见、确实相关、且获得用户对本次动作的显式授权」时用于增强导入、核验或导出。当前请求本身可以构成授权；否则须先获得覆盖目的、最小数据范围与外部目标/接收方的确认。仅有宿主权限不算充分。须限定超时；无法限定执行时，跳过可选调用，不得阻塞核心写作。

可选动作失败时，如实披露失败并退回对话级产物。绝不把计划中的调用、待处理的请求或后台可能性表述为成功。

## 完成自检

回复前确认：

- 回复推进了三个支持场景之一；
- 至少存在一个用户可编辑的结构或文稿产物；
- 假设与证据缺口可见；
- 修订范围得到遵守；
- 没有未受支撑的「已保存/已导出/已核验/已发布/已改变外部状态」声明；
- 恰好给出一个明确的推荐下一步。

## 与团队专家的边界

本技能是通用长文档（报告、书稿、长篇稿件）的共享方法论，不替代领域专家：

- 教学案例 / 课程思政案例 → 使用 case-writer 技能
- 毕业论文辅导 → 使用 thesis-mentor 技能
- 会议纪要 / 学术评议 → 使用 minutes-organizer 专家
- 课程建设 → 使用 course-builder 技能

属于上述领域之外的通用长文档时，路由到本技能。所有长文产出在交付前仍须通过去 AI 味门禁。
