# 引用保真与资料来源（Source Integrity）

本文件规定案例资料的采集与标注规范。阶段 1（资料采集）**必须**遵循。

## 0. 方法论：先提炼标准，再映射流程

知识库与网络资料**不直接拼进案例**，而是先加工成"撰写标准"，再由标准驱动工作流：

```
桌面案例知识库 + 网络检索
        │
        ▼
  【提炼标准】结构标准 / 评分口径 / 思政融入规范 / 案例模板
        │
        ▼
  【映射到工作流】阶段 0 分流 → 阶段 1 采集 → 阶段 2 撰写 → 阶段 3 自查 → 阶段 4 交付
```

即：先有"标准"（what good looks like），再让标准落到五阶段流程（how to produce it）。
本技能 `references/` 下的 framework 文件即"标准层"；`SKILL.md` 工作流即"流程层"。

## 1. 桌面"案例知识库"定位（通用指针，不列具体文件）

知识库路径：团队统一知识库位于 `~/.workbuddy/wiki-knowledge/`（由 `knowledge-wiki` 技能管理）；此外可额外挂载用户目录 `~/Desktop/案例知识库` 作为补充案例素材。若任一目录不存在，跳过该来源并继续，不得静默失败或编造。

> 仅作通用指引，**不逐条列举文件名**（避免与具体机器上的文件强绑定）。撰写前进入该目录，
> 按下面三类按需取用；重点吸收其"标准与结构"，而非照搬具体表述。

| 类别 | 内容性质 | 用途 |
|------|----------|------|
| 写作标准类 | 教学案例写法、课程思政案例撰写标准、国赛/示范课参考 | 定结构与评分口径（提炼"标准层"） |
| 案例范式类 | 若干真实获奖/入库案例全文 | 作少样本范式，借鉴叙事节奏与思政融入方式（不抄内容） |
| 案例模板类 | 标准案例"使用说明/教学说明"模板 | 作为案例骨架参考（见第 2 节） |

## 2. 知识库中的案例模板（标准骨架，必须参考）

知识库含权威案例库的"使用说明/教学说明"模板，其固定结构即本技能的教学案例骨架来源。
撰写教学案例时，优先对齐以下两套模板的**结构**（非文件名）：

- **中国管理案例共享中心"教学案例使用说明"模板**：
  教学目的与用途 → 讨论思考题 → 分析思路 → 理论依据与分析 → 关键要点 → 建议课堂计划。
- **清华大学案例库"教学说明"模板**：
  案例概要 → 在课程中的定位 → 学习目标 → 相关阅读材料 → 讨论问题 → 分析思路 →
  理论依据与分析 → 关键要点 → 教学建议。

> 映射关系：上述"教学目的与用途/学习目标"≈本技能"教学目标"；"分析思路+理论依据+关键要点"
> ≈"成效分析+经验总结"；"建议课堂计划/教学建议"≈思政案例的"教学设计"。教学案例走此骨架；
> 课程思政案例在此外叠加"思政元素映射 + 两段式命名 + 三维目标 + 教学反思"（见
> `references/sizheng-case-spec.md`）。

## 3. 网络检索指引（补全政策与数据）

下列方向**必须**联网检索最新表述，避免用过时效提法：

- **顶层政策**：立德树人、三全育人、课程思政建设、教育强国建设规划纲要（2024–2035）、
  《关于深化新时代学校思想政治理论课改革创新的若干意见》、二十大报告关于教育/科技/人才论述。
- **精神谱系**：工匠精神、科学家精神、企业家精神、教育家精神、劳动精神、奋斗精神。
- **学科前沿数据**：所写主题对应的行业/管理研究最新数据，优先引自权威机构（教育部、人社部、
  权威期刊/年鉴）。
- **检索关键词示例**：`课程思政 案例 撰写 标准 2025`、`教育强国建设规划纲要 课程思政`、
  `组织行为学 课程思政 融入 案例`、`领导力 教学案例 申报`。

> 检索到的每条政策/数据，在案例正文中以 `〔来源：…，发布机构，YYYY-MM-DD〕` 标注；
> 若检索无果或存疑，标注 `〔无可靠来源，待核实〕`，**不得编造**。

## 4. 来源标注规范（文内格式）

> 文内标记四式与参考文献著录格式已统一至 **`references/case-reference-standard.md`**（case-writer 引用与著录 L1 统一标准，锚定 `citation-integrity` L0 SSOT，合并 A/B/D 三条模板路径）。本文件 §4 仅补充「桌面知识库引用」特例，其余以统一标准为准，避免多处定义漂移。

- 文内标记四式（政策/文件、数据/统计、网络新闻机构报告、无可靠来源）及 `[N]` 参考文献著录：见 `references/case-reference-standard.md`。
- 桌面知识库引用（本文件特有）：`〔来源：桌面案例知识库 / 某类资料（如"获奖案例全文"）〕`

## 5. 红线（违反即退回）

- 禁止虚构任何数字、政策条文、文件名、获奖记录、文献出处。
- 禁止把检索不到的内容写成"据研究表明……"而不给来源。
- 禁止用"大量""显著""普遍"等模糊断言替代可标注的来源数据（除非明确为教师主观教学经验，
  并注明"基于笔者教学实践观察"）。
- 禁止把知识库某篇具体案例的内容整段照搬当作自己案例——只借结构、不抄内容。
