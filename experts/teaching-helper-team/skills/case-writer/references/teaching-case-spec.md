# 教学案例结构规约（路径 A · 专属）

> 本文件只规定路径 A 的**结构骨架**与**撰写顺序**。质量判定（九特性 / 八要素 / 四特质含单一中心问题 / 四避坑 / 自查清单 / 中立客观 / 篇幅 / 理论锚点）一律见 **`references/case-quality-base.md`**（共享质量底座，单一事实来源）。
> 撰写前配合 `assets/teaching-case-template.md` 使用。

## 1. 核心定义

> 教学案例 = 真实教学（或育人）场景 + 典型教学问题 + 完整处置过程 + 专业教学反思。
> 它是课后复盘，不是课前预设（教案），不是全盘实录（教学实录），不是说理议论文（论文）。

## 2. 必含五模块（强制）

| 模块 | 内容要求 |
|------|----------|
| 案例背景 | 场景、学情、困境（时间/地点/课程/年级/学生基础/核心教学问题产生的环境）。 |
| 教学目标 | 本案例想解决什么、达成什么（知识/能力/价值可分层，但以"问题解决"为主线）。 |
| 实施过程 | 案例主体。问题呈现 → 应对过程 → 细节转折；平实叙事，客观还原，有冲突与调整。 |
| 成效分析 | 即时效果——学生反应、行为变化、目标达成度；可用可标注的数据/反馈佐证。 |
| 反思评析 | 可复制、可推广的方法论；自我反思（不足与优化方向）；对同类教学的启示。**用教师视角**写，但须与正文中立叙述区分。 |

> 课程思政类教学案例，在上述模块中自然嵌入"思政元素映射"（见 `references/sizheng-elements.md`），不必另起炉灶，但在"教学目标""反思评析"中要点明价值引领目标。

## 3. 五步撰写框架（推荐行文顺序）

1. **案例背景**：场景 + 学情 + 困境（简洁入题，不面面俱到）。
2. **案例主题**：一个清晰聚焦的核心主题（例：《巧用情境设问，破解课堂发言畏难》）。
3. **案例描述**：核心主体，拒绝流水账；只写问题呈现、应对过程、细节转折。
4. **案例评析**：结合新课标/学科理论/育人理念做专业解读；亮点、根源、为何有效、不足（运用 `references/case-quality-base.md` 的**理论锚点**）。
5. **案例反思与启示**：自我反思（不足/遗憾）+ 教学启示（可复制方法、推广意义）。

## 4. 口吻与分层（重要）

- **案例正文（背景/目标/实施/成效）**：中立客观叙述，用"我/我们/学生"还原真实情境，但不把主观评价演绎进事实描述。
- **反思评析**：可用教师视角做专业判断与自我反思；价值判断须注明"基于笔者教学实践观察"或引第三方。
- 思政融入"润物无声"：价值点从专业内容自然生长，不喊口号、不堆砌政治术语、不生硬插入。

## 5. 自查清单（阶段 3 门禁，通用项见底座）

- [ ] 五模块齐全且逻辑连贯。
- [ ] 有真实、典型、含问题的事件（聚焦单一中心问题），非平铺直叙。
- [ ] 实施过程具体（问题→应对→转折），非流水账。
- [ ] 成效有依据（可标注数据/反馈），非空话。
- [ ] 反思评析提炼出可复制方法论 + 自我反思（教师视角，与正文分层）。
- [ ] 引用保真 + 过 deai 门禁（通用项见 `references/case-quality-base.md` 第七節）。
