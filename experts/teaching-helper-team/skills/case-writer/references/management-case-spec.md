# 工商管理案例结构规约（路径 D · 专属）

> 本文件只规定路径 D 的**结构骨架**与**命名/编号规则**。质量判定（九特性 / 八要素 / 四特质含单一中心问题 / 四避坑 / 自查清单 / 中立客观 / 篇幅 / 理论锚点）一律见 **`references/case-quality-base.md`**（共享质量底座，单一事实来源）。
> 撰写前配合 `assets/management-case-template.md` 使用。

## 1. 核心定义

> 工商管理案例 = 真实组织情境 + 典型管理问题 + 完整处置过程（含冲突与两难）+ 可供课堂讨论的开放结局。
> 它是叙事化的教学素材（案例正文），不是课前预设（教案），不是全盘实录，不是说理议论文。

## 2. 必含四模块（强制）

| 模块 | 内容要求 |
|------|----------|
| 案例背景 | 组织来龙去脉：创立/规模/结构/产品/战略/关键数据，为冲突铺垫可信底座（须含 ≥3 个可核查数字）。 |
| 案例描述 | 案例主体。冲突升级 → 决策/行动 → 转折；具名人物 + 身份、直接引语（用「」）、具体数字、两难选择。 |
| 成效分析 | 即时效果——决策结果、组织/人员变化、目标达成度；**好与坏都写**，可用可标注的数据/反馈佐证〔来源：…〕。 |
| 反思评析 | 可复制方法论 + 自我反思（不足与优化方向）+ 对同类教学的启示。**用教师/作者视角**写，但须与正文中立叙述区分。 |

> 与路径 A 一致：反思评析并入正文末段，**不再另交独立的"教学说明"**。

## 3. 五步撰写框架（推荐行文顺序）

1. **案例背景**：组织来龙去脉，含可核查数字，为冲突铺垫可信底座。
2. **案例主题**：一个清晰聚焦的核心管理问题（单一中心问题，不发散多主题）。
3. **案例描述**：冲突升级 → 决策/行动 → 转折；具名人物、引语、具体数字、两难选择。
4. **案例评析**：结合新课标/学科理论/管理框架做专业解读（亮点、根源、为何有效、不足），运用 `references/case-quality-base.md` 的**理论锚点**。
5. **案例反思与启示**：自我反思（不足/遗憾）+ 教学启示（可复制方法、推广意义），按路径 A 处理，并入正文末段。

## 4. 命名规则（封面标题 · 已发布内容）

- 主标题采用「**主体名：核心定位**」形式（例：《东方公司：中层管理者的夹心困境》）。
- 本部分属**已发布内容**，仅保留标题命名规则；不附机构、编号、作者、日期、版权及掩饰声明等元信息。
- 编号规约见下节，沿用中文数字式，与前文（路径 A/B 模板）保持一致。

## 5. 编号规则（与前文一致 · 中文数字式）

- 全文统一使用**中文数字式**：`一、` `二、` `三、` ……（与路径 A/B 模板一致）。
- 示例：`一、公司背景` → `二、{发展章节主题一}` → `三、{发展章节主题二}` → `尾声`。
- 不再提供"数字式（0 引言 / 1 背景）"备选，避免与 A/B 不一致；全文编号风格须一致，不得混用。

## 6. 口吻与分层

- **案例正文**：立场中立客观，不单方面歌功颂德；观点鲜明的内容引用第三方表述。
- **反思评析**：可用教师/作者视角做分析与自我反思，但须标注理论来源、不杜撰。
- 主角企业内部叙事数字属"案例情境"，不杜撰来源；引用外部标杆须标真实来源〔来源：…〕。

## 7. 自查清单（阶段 3 门禁，通用项见底座）

- [ ] 四模块齐全且逻辑连贯。
- [ ] 有真实、典型、含问题的事件（聚焦单一中心问题），非平铺直叙。
- [ ] 案例背景含 ≥3 可核查数字；案例描述含冲突 → 决策 → 转折。
- [ ] 反思评析提炼可复制方法论 + 自我反思（教师视角，与正文分层，并入正文末段）。
- [ ] 八要素齐全（通用项见 `references/case-quality-base.md` 第二節）。
- [ ] 编号统一为中文数字式，未混用数字式。
- [ ] 引用保真：数据/政策/外部标杆带 `〔来源：…〕` 标记；无编造；无支撑处标注待核实。
- [ ] 口吻中立客观，过 deai 门禁（通用项见底座第七節）。
