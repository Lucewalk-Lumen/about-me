# 思政元素映射与政策锚点（Sizheng Elements & Policy Anchors）

写课程思政案例时，用本文件把"专业知识点"映射到"思政元素"，并核对最新政策表述。
**政策表述须结合阶段 1 网络检索更新**，不得使用过时提法。

## 1. 思政元素映射表（知识点类型 → 元素 → 融入方式 → 素材方向）

| 专业知识点类型（示例） | 可融思政元素 | 融入方式 | 案例素材方向 |
|------------------------------|--------------|----------|--------------|
| 领导力 / 追随力 | 责任担当、家国情怀、以身作则 | 故事导入、榜样力量 | 新人管理者转型、危急时刻的担当 |
| 团队与协作 | 集体观念、协作意识、包容 | 项目式/分组学习 | 跨专业团队攻坚、冲突化解 |
| 组织文化与变革 | 改革创新、系统思维、奋斗精神 | 比较导入、情境导入 | 企业转型中的文化重塑 |
| 人力资源（招聘/绩效/薪酬） | 公平公正、职业伦理、诚信 | 问题创设、事件导入 | 公平录用、反歧视、绩效公正 |
| 创新创业 / 企业家精神 | 企业家精神、社会责任、实干 | 事件导入、热点对比 | 硬科技创业、乡村振兴创业 |
| 组织行为（激励/沟通） | 以人为本、工匠精神、求真 | 故事/情境导入 | 一线员工成长、匠心育人 |

> 通用元素库（可跨学科复用）：民族精神、时代精神、科学精神、人文素质、工匠精神、科学家
> 精神、企业家精神、教育家精神、劳动精神、奋斗精神、诚信、和谐、创新、进取、制度敬畏、
> 环境保护、珍惜生命、团队协作、探索精神。

## 2. 价值目标词库（写"价值目标"时优先选用，避免空泛）

家国情怀、社会责任感、工匠精神、科学精神、职业伦理、团队协作、文化自信、创新思维、
辩证思维、底线思维、规则意识、敬业精神、奉献精神、实事求是。

## 3. 政策锚点（须联网核对最新表述）

下列为常见锚点，**撰写前必须用 WebSearch 检索当年最新表述与文号**，并在文中标注来源：

- 立德树人根本任务、三全育人（全员全程全方位育人）。
- 课程思政建设相关文件与会议精神。
- 《教育强国建设规划纲要（2024–2035）》（如适用）。
- 二十大报告关于"教育、科技、人才"三位一体的论述。
- 社会主义核心价值觀（富强民主文明和谐；自由平等公正法治；爱国敬业诚信友善）。
- 精神谱系：工匠精神 / 科学家精神 / 企业家精神 / 教育家精神 / 劳动精神 / 奋斗精神。
- 专业相关：新工科、新文科、新农科、新医科建设导向（按学科选取）。

> 检索示例：`教育强国建设规划纲要 课程思政 2025`、`工匠精神 教育家精神 最新表述`。
> 凡引用，标注 `〔来源：文件/报告名，发布机构，年份；检索 YYYY-MM-DD〕`。

## 4. 融合"度"的把握

- 价值点从专业内容自然生长，避免"为思政而思政"。
- 一个案例聚焦 1–2 个核心思政元素即可，贪多则散。
- 用"学生的真实变化/反馈"佐证价值引领成效，胜过直接下结论。
