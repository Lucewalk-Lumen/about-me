# 课程思政案例结构规约（路径 B · 专属）

> 本文件只规定路径 B 的**结构骨架**与**命名/目标规则**。质量判定（九特性 / 八要素 / 四特质含单一中心问题 / 四避坑 / 自查清单 / 中立客观 / 篇幅 / 理论锚点）一律见 **`references/case-quality-base.md`**。
> 撰写前配合 `assets/sizheng-case-template.md` 与 `references/sizheng-elements.md`（思政元素映射）使用。

## 1. 标准组成（四部分）

课程思政教学案例由四部分构成：**案例基本信息 → 案例教学目标 → 案例主要内容 → 教学设计**，并附**教学反思**。

| 用户要求模块 | 本范式落点 |
|--------------|------------|
| 案例背景 | 案例基本信息（命名+对应章节）+ 主要内容中"问题/情境铺垫" |
| 教学目标 | 案例教学目标（知识/能力/价值三维） |
| 实施过程 | 案例主要内容 + 教学设计（导入·方法·考核） |
| 成效分析 | 教学效果（学生收获/达成度）+ 教学反思中的效果评估 |
| 经验总结 | 教学反思（优势/不足/改进）+ 可推广经验 |

## 2. 案例命名（两段式，强约束）

- 前段：以知识点中蕴含的**思政要素价值要义**命名（可适当引申修饰，与专业结合）。
- 后段：该具体知识点命名。
- 主副标题结合，题意清晰、耳目一新，**字数 ≤ 25 字**为宜。
- 例：`努力付出，终有回报——无氧酵解的产能过程`；示例：`以身作则，方聚人心——新员工领导力转型的情境课堂`。

## 3. 案例教学目标（三维，须支撑课程思政总目标）

- **知识目标**：具体、可测的专业知识点。
- **能力目标**：运用知识解决实际问题的能力。
- **价值目标**（核心）：家国情怀、社会责任感、工匠精神、科学精神、职业伦理、团队协作、文化自信等——须与本章节知识点对应，体现习近平新时代中国特色社会主义思想、社会主义核心价值观、"三全育人"理念。

## 4. 案例主要内容（6 选取原则，至少契合 2–3 项）

1. 学科专业相关；2. 职业发展要求；3. 热点时事对比；4. 历史与现实分析；5. 家国情怀培养；6. 实践体验挖掘。
> 思政元素映射表与政策锚点见 **`references/sizheng-elements.md`**（知识点 → 思政元素 → 融入方式 → 素材方向；政策表述须联网核对最新）。

## 5. 教学设计（三要素）

- **案例导入**（5 法选宜）：问题创设 / 事件导入 / 故事导入 / 情境导入 / 比较导入。要求"有预设但不突兀"，忌生硬插入。
- **教学方法**：讲·查·做·演·论多元形式；案例式/启发式/探究式/项目式/情景模拟/比较式；可协同教学。现代信息技术增强时代感。
- **考核评价**：诊断性评价 + 形成性评价 + 终结性评价，以评促达成。

## 6. 教学反思

总结内容与方法优势/不足、学生参与接受度，提出改进与后续教学保留经验。

## 7. 价值引领"润物无声"（口吻分层）

- **案例正文**：中立客观叙述，价值点从专业内容自然生长，不喊口号、不堆砌政治术语、不生硬插入。
- **教学目标/反思**：可明示价值目标与引领成效，但须以"学生的真实变化/反馈"佐证，胜过直接下结论。
- 一个案例聚焦 1–2 个核心思政元素即可，贪多则散。

## 8. 自查清单（阶段 3 门禁，通用项见底座）

- [ ] 两段式命名 ≤ 25 字，前段为思政价值要义、后段为知识点。
- [ ] 教学目标三维齐全，价值目标明确且与知识点逻辑对应。
- [ ] 主要内容契合 ≥2 项选取原则，思政映射点清晰（见 `references/sizheng-elements.md`）。
- [ ] 有教学设计（导入方式 + 教学方法 + 考核评价），导入不生硬。
- [ ] 成效分析有学生收获/达成度佐证（可标注来源）。
- [ ] 教学反思含优势、不足、改进。
- [ ] 引用保真 + 过 deai 门禁（通用项见 `references/case-quality-base.md` 第七節）。
