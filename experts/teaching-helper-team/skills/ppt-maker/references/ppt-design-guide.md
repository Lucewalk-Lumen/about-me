## 设计原则

### 核心理念

大学教学课件是辅助教学而非替代教学的工具。优秀课件应遵循：

1. **聚焦**——每页一个核心知识点，避免信息过载
2. **可视化**——能用图表表达的，不用纯文字
3. **层次化**——通过字号、颜色、空间区分信息层次
4. **适度性**——课件是讲台不是教材，要点精炼不堆砌
5. **交互性**——设置讨论、练习、提问等互动页面
6. **可编辑**——输出文字与图表均可编辑，便于后续微调

### 信息密度控制

| 页面类型 | 文字量上限 | 要点行数 | 说明 |
|----------|-----------|---------|------|
| 标题页 | 1行 | 1行 | 章节标题+副标题 |
| 知识讲解页 | 80字 | 4-6行 | 核心要点+关键术语 |
| 案例展示页 | 60字+图表 | 3-4行 | 案例描述+图表分析 |
| 讨论互动页 | 30字 | 1-2个问题 | 问题+讨论提示 |
| 练习测试页 | 50字+题目 | 1题 | 题目+选项/答题区 |
| 小结页 | 100字 | 5-8个要点 | 本节/本章核心归纳 |

> 单页超50字要警惕，用图表/图示替代大段文字。

## 金字塔原理与Action Title

### 金字塔原理梳理逻辑主线

开工前用金字塔原理梳理课件逻辑：

1. **结论先行**——首页或标题页点明本课核心结论
2. **MECE分组**——内容分组做到互不重叠、完全穷尽
3. **自上而下**——从核心结论逐层展开支撑论据
4. **一页一主题**——每页只讲一件事，所有内容支撑该页主题

### Action Title 原则

每页标题不是描述性的，而是结论性的观点：

| 描述性标题（避免） | Action Title（推荐） |
|-------------------|---------------------|
| 算法复杂度分析 | 快速排序的平均时间复杂度为O(n log n) |
| 市场营销概述 | 4P理论是营销策略的核心框架 |
| 实验结果 | 温度升高10°C，反应速率提高2.3倍 |
| 章节总结 | 本章核心：树的遍历有三种方式且各有适用场景 |

### 逻辑主线检查

```
本课核心结论是什么？
  → 支撑结论的2-3个论据是什么？
    → 每个论据需要哪些数据/案例/图表？
      → 对应到哪些PPT页面？
```

## 数据可视化规范

### 图表选择与使用

| 图表类型 | 适用场景 | 使用限制 | 设计要点 |
|----------|---------|---------|---------|
| **柱状图** | 比较不同类别的数值 | 按数值排序（时间序列除外） | Y轴从0开始；类别名简短 |
| **饼图** | 展示比例构成 | 不超过6个切片 | 从大到小排列；标注百分比 |
| **折线图** | 展示趋势变化 | 不超过3-4条线 | 线条颜色区分明显；标注关键点 |
| **散点图** | 展示两个变量的关系 | 标注相关系数 | 避免数据点过密 |
| **表格** | 精确数据对比 | 行数≤7，列数≤5 | 关键数据加粗或标色 |
| **流程图** | 展示过程/步骤 | 步骤≤8个 | 决策分支明确 |
| **概念图** | 展示知识结构 | 节点≤15个 | 层级清晰，关系标注 |

### 数据呈现原则

1. **不编造数据**——公司数据、市场数据、客户案例绝不虚构；缺失时要求用户提供或明确标注"假设数据"
2. **标注来源**——引用数据必须注明出处
3. **单位明确**——坐标轴、表格数据必须标注单位
4. **重点突出**——用颜色/标注突出关键数据点

## 内容到幻灯片的映射方法

### 从教案到课件的标准映射流程

```
教案教学过程 → 提取每环节核心内容 → 确定页面类型 → 设计页面内容 → 安排动画/交互
```

### 教案环节与PPT页面的对应关系

| 教案环节 | PPT页面序列 | 页面数（90分钟课） |
|----------|------------|-------------------|
| 课前导入 | 标题页 + 导入情境页/问题页 | 2-3页 |
| 新知讲解（知识点1） | 概念页 + 图示页 + 示例页 | 3-5页 |
| 新知讲解（知识点2） | 概念页 + 对比页 + 示例页 | 3-5页 |
| 实践应用 | 练习页/案例页 + 讨论页 | 2-3页 |
| 拓展深化 | 拓展内容页 + 前沿动态页 | 1-2页 |
| 总结 | 小结页 + 知识结构图页 | 1-2页 |
| 作业布置 | 作业说明页 | 1页 |
| **合计** | | **15-22页** |

### 知识点到页面的转换规则

| 知识类型 | 推荐页面形式 | 设计要点 |
|----------|------------|---------|
| 概念定义 | 定义页（术语+解释+图示） | 突出核心术语，配简洁图示 |
| 原理/理论 | 流程图/原理图页 | 用箭头/标注展示因果关系 |
| 方法/步骤 | 步骤分解页 | 编号步骤+每步要点 |
| 对比分析 | 对比表页 | 左右/上下对比，突出差异 |
| 案例 | 案例展示页 | 简述背景+关键数据+分析要点 |
| 公式推导 | 分步推导页 | 逐行展示，配动画逐行出现 |
| 实验操作 | 流程图+实物图页 | 步骤清晰，配关键操作标注 |

## 不同课型PPT结构模板

### 模板一：理论讲授型

适用于概念密集的理论课。

```
1. 章节标题页（章节名+本节主题+授课人）
2. 学习目标页（3-5条本课目标）
3. 导入页（问题/情境/案例引入）
4. 知识结构页（本节知识地图）
5-N. 知识讲解页（每个知识点2-3页：概念→图示→示例）
N+1. 知识对比页（与已学知识的对比表）
N+2. 应用案例页（真实场景应用）
N+3. 课堂讨论页（1-2个讨论问题）
N+4. 本节小结页（要点归纳+知识结构图）
N+5. 课后作业页
```

### 模板二：研讨型

适用于研讨课、案例分析课。

```
1. 主题页
2. 背景介绍页（案例背景/问题背景）
3. 讨论问题页（3-5个递进问题）
4. 分组安排页（分组方式与讨论要求）
5. 讨论展示页（各组汇报用模板）
6-N. 理论支撑页（研讨过程中需要引用的理论知识）
N+1. 多视角对比页（不同观点/方案的对比）
N+2. 教师点评页（关键观点总结与深化）
N+3. 拓展思考页（延伸问题与下次课预告）
```

### 模板三：实验/实践型

适用于实验课、上机课、实训课。

```
1. 实验标题页
2. 实验目的页
3. 实验环境/工具页（所需器材/软件/数据）
4. 实验原理页（简明扼要）
5. 实验步骤页（分步骤流程图+关键操作标注）
6. 注意事项页（安全/易错点提醒）
7-8. 操作演示页（关键步骤截图/视频）
9. 记录要求页（数据记录表格/报告要求）
10. 拓展实验页（选做内容）
11. 实验总结页
```

### 模板四：项目驱动型

适用于课程项目、综合实践。

```
1. 项目主题页
2. 项目背景与目标页
3. 项目要求页（功能需求/技术指标/交付物清单）
4. 项目流程页（阶段划分与时间节点）
5. 团队组建页（分组方式与角色分工）
6. 技术路线页（推荐技术方案与备选方案）
7. 评价标准页（评分细则rubric）
8. 阶段汇报模板页
9. 常见问题与资源页
```

### 模板五：翻转课堂型

```
课前：
1. 课前学习任务页（视频/阅读材料清单+学习目标）
2. 知识检测页（课前小测3-5题）

课中：
3. 答疑解惑页（收集课前问题，集中解答）
4. 深化讨论页（基于课前知识的进阶问题）
5-N. 应用实践页（案例分析/问题解决/项目实践）
N+1. 成果展示页
N+2. 反思总结页
```

## 视觉设计系统

### 配色方案

| 学科类型 | 主色推荐 | 辅色 | 背景 |
|----------|---------|------|------|
| 理工科 | 深蓝/深灰 | 浅蓝/橙色点缀 | 白色/浅灰 |
| 文社科 | 深绿/深棕 | 米色/暖灰 | 白色/米白 |
| 医学 | 深红/深蓝 | 浅绿/浅红 | 白色 |
| 经管 | 深蓝/深红 | 金色/灰色 | 白色 |
| 艺术 | 可用高对比配色 | 视内容而定 | 视风格而定 |

通用原则：主色1种 + 辅色1-2种，不超过3种颜色；确保文字与背景对比度≥4.5:1。

### 教室规模与字号关系

不同教室规模下，PPT最小可读字号不同：

| 教室类型 | 容纳人数 | 最远距离 | 正文最小字号 | 标题最小字号 | 说明 |
|---------|---------|---------|-------------|-------------|------|
| 小教室 | ≤40人 | 6m | 20pt | 28pt | 标准配置即可 |
| 中教室 | 40-120人 | 10m | 24pt | 32pt | 避免使用14pt以下字号 |
| 大阶梯教室 | 120-300人 | 15m | 28pt | 36pt | 图表标注不低于18pt |
| 报告厅 | >300人 | 20m+ | 32pt | 40pt | 尽量减少文字，多用图表 |

**快速判断法**：在电脑上全屏预览PPT，退到3米外，能看清正文字号即为合格（模拟最后排学生视角）。

### 无障碍设计

确保PPT内容对色觉障碍学生友好：

| 设计要素 | 要求 | 检查方法 |
|---------|------|----------|
| 对比度 | 正文与背景对比度≥4.5:1（WCAG AA标准） | 使用在线对比度检查器验证 |
| 色盲友好 | 不仅用颜色区分信息，加文字标注或图案 | 灰度模式下检查是否仍可区分 |
| 红绿对比 | 避免红绿配色作为唯一区分手段 | 红绿色盲是最常见色觉障碍 |
| 字体大小 | 全屏后退3米可读 | 正文不低于20pt |
| 图表标注 | 数据标签直接标注，不仅依赖图例颜色 | 柱状图直接在柱上方标数值 |
| 动画 | 动画速度不低于0.3秒，避免闪烁 | 快速闪烁可能引发光敏反应 |

### 字体规范

| 元素 | 中文字体 | 英文字体 | 字号 |
|------|---------|---------|------|
| 章节标题 | 黑体/思源黑体 | Arial Bold | 36-44pt |
| 页面标题 | 黑体/思源黑体 | Arial Bold | 28-32pt |
| 正文要点 | 黑体/思源黑体 | Arial | 20-24pt |
| 图表标注 | 宋体/思源宋体 | Times New Roman | 14-18pt |
| 备注/脚注 | 楷体 | Italic | 12-14pt |

### 版式原则

- **对齐**：同页元素左对齐或居中对齐，不混用
- **留白**：页面四周留出至少1cm空白，内容占比不超过70%
- **分组**：相关内容靠近排列，不同主题间用空行或分隔线区分
- **一致性**：同类页面保持相同版式（标题位置、要点符号、图标风格）

### 动画使用建议

| 场景 | 推荐动画 | 注意事项 |
|------|---------|---------|
| 要点逐条展示 | 淡入/擦除 | 避免飞入等花哨效果 |
| 流程图分步呈现 | 出现/擦除 | 确保逻辑顺序正确 |
| 公式推导 | 出现 | 逐行显示，配合讲解节奏 |
| 对比内容 | 淡入 | 左右同时或先左后右 |
| 图表数据 | 擦除/淡入 | 数据系列逐个出现 |

原则：动画服务于教学逻辑，不为动而动；整份课件动画风格统一。

## 课件生成流程

### 生成课件的标准流程

1. **选定输出路径**：按本技能决策流（HTML 单文件优先 / 传统 .pptx 备选）确定方案；HTML 方案读取 `references/html-deck-spec.md` 了解技术规范，`references/style-presets.md` 选定风格预设
2. **确定内容大纲**：根据教案/课程内容，按本指南的映射方法确定页面清单
3. **选择模板**：根据课型选择对应模板（本文件中的五种模板之一）
4. **编写内容**：为每页编写具体文字内容，确保Action Title
5. **调用生成器生成**：将页面清单整理为 deck spec JSON，按本技能技术规范用 `build_deck.py`（HTML）或 `build_pptx.py`（.pptx）生成
6. **检查与调整**：检查页面数、信息密度、视觉一致性；HTML 方案可在浏览器内直接拖拽/改字微调

### 课件内容准备清单

生成PPT前，准备好以下内容清单：

```
课件信息：
- 课程名称：[名称]
- 章节/课时：[章节]
- 授课人：[姓名]
- 总页数：[X]页
- 课型：[理论讲授/研讨/实验/项目/翻转]

页面清单：
1. [页面类型] | [Action Title] | [核心内容要点]
2. [页面类型] | [Action Title] | [核心内容要点]
...
N. [页面类型] | [Action Title] | [核心内容要点]
```

将此清单连同本指南的设计规范，交由本技能生成器（`build_deck.py` / `build_pptx.py`）生成。

## 课件模板智能推荐

>
> **教案模板联动**：课件模板选定后，对应的教案设计模板详见 [course-design-frameworks.md](../../course-builder/references/course-design-frameworks.md) §教学设计模板选择矩阵。（智能模板推荐系统）方法论。

根据课程特征自动推荐最适合的课件模板，减少手动选型的时间成本。

### 推荐评分维度与权重

| 评分维度 | 权重 | 匹配逻辑 |
|---------|------|---------|
| **课型匹配** | 35% | 课件模板标注的适用课型与当前课程课型是否一致 |
| **页数匹配** | 25% | 模板的推荐页数范围与课程时长匹配度 |
| **风格匹配** | 20% | 模板风格与课程受众（学术/应用/通识）的匹配度 |
| **使用频率** | 10% | 历史使用频率越高，适度加分（利用已有经验） |
| **多样性** | 10% | 避免连续推荐同类模板，保证风格多样性 |

### 课件模板库

| 模板ID | 模板名称 | 适用课型 | 推荐页数 | 风格 | 适用受众 |
|-------|---------|---------|---------|------|---------|
| `theory-lecture` | 理论讲授型 | 理论讲授 | 20-40页 | 学术严谨 | 本科/研究生 |
| `seminar-discussion` | 研讨讨论型 | 研讨课 | 15-25页 | 开放互动 | 研究生/高年级本科 |
| `lab-instruction` | 实验指导型 | 实验课 | 10-20页 | 操作清晰 | 本科 |
| `project-based` | 项目驱动型 | 项目实践 | 25-45页 | 任务导向 | 本科/研究生 |
| `flipped-class` | 翻转课堂型 | 翻转课堂 | 15-30页 | 自学引导 | 本科 |
| `case-study` | 案例分析型 | 案例教学 | 20-35页 | 叙事分析 | MBA/专业硕士 |
| `review-summary` | 复习总结型 | 复习课 | 10-20页 | 精炼概括 | 所有层次 |
| `introduction` | 导论入门型 | 新生导论 | 15-25页 | 亲切易懂 | 大一新生 |

### 推荐流程

```
1. 输入课程上下文：课型、课时、受众层次、主题领域
2. 对模板库中每个模板计算五维度加权总分
3. 按总分排序，输出 Top-3 推荐
4. 每个推荐附匹配理由（命中哪些维度）
5. 用户选择后，将模板结构交由本技能生成器生成
```

### 冷启动推荐

当无历史使用记录时（首次使用），仅依据前三个维度（课型 35% + 页数 25% + 风格 20% = 80% 权重）推荐，使用频率和多样性维度权重归零。

### 推荐输出格式

```markdown
## 课件模板推荐结果

### 推荐方案 1：理论讲授型（得分 0.92）
- 匹配理由：课型完全匹配（+0.35）、页数范围匹配 40分钟课时（+0.25）、风格适合本科受众（+0.20）
- 模板结构：导入→概念定义→原理推导→案例演示→练习→总结→作业
- 推荐页数：25-35页

### 推荐方案 2：案例分析型（得分 0.78）
```

## 图片与视觉纪律

> 原则：**纪律是生成前必读、生成后逐项自检**。

### 图片比例规范（永远用标准比例，不用原图奇葩比例）

| 场景 | 推荐比例 | 写法/说明 |
|------|---------|-----------|
| 左文右图 主图 | 16:10 或 4:3 | `.frame-img.r-16x10` / `.r-4x3`（ppt-maker 中对应 image 页型 `max-height` 约束） |
| 图片网格（多图对比） | 统一 | 同组必须同高，不用手写不同 height |
| 小型面板组 | 统一 | 同组同高 `h-16/h-18` |
| 左小图 + 右文字 | 1:1 或 3:2 | `.r-1x1` / `.r-3x2` |
| 全屏主视觉 | 16:9 | `.r-16x9` |
| 信息图/截图再设计 | 16:9 或 16:10 | 必须 `.fit-contain`，避免文字/标注被裁切 |
| 图文混排小插图 | 3:2 或 3:4 | `.r-3x2` / `.r-3x4` |

### P0 视觉红线

1. **图片只允许裁底部，左右和顶部绝对不能切**——`object-fit:cover + object-position:top center`；信息图必须 `fit-contain`。
2. **大标题字号不能超过屏宽/单字密度**——对应 ppt-maker 密度上限（知识讲解页 ≤80 字）与 `--check` 字号下限（正文 ≥20pt）。
3. **字体分工**：标题衬线、正文非衬线（magazine 系预设）；或全黑体/全宋体（教学系预设）——按 `style-presets.md` 选型，不混用。
4. **图片不要 `align-self:end` 贴底**——非 grid/flex 容器中无效，图会掉到文档流末尾堆底；ppt-maker 中图片页用固定 `max-height` + `margin:0 auto` 居中。
5. **亮页面配暗 WebGL = 灰蒙蒙**（主题切换没生效）——ppt-maker 中 T 键换肤后必须逐页核对背景/文字对比，跑 `--check` 对比度断言。
6. **不用 emoji 作功能图标**——对应 release_pack P0 门禁。
7. **视觉 + 代码双核对**——验收不只肉眼：`build_deck.py --check` + 产物断言（html-deck-spec 12 条）双跑。
8. **整个 deck 全是 light 无节奏**——长 deck 建议用 section 页分隔 + 预设签名装饰（academic/ink/aurora 已落地）制造节奏。
