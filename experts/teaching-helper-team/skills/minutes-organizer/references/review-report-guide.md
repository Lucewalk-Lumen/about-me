# 学术综述报告体裁指南

> 会议纪要（复述型）之上的**升格产物**。当用户要的不是"记录讲了什么"，而是"把一场会议写成一篇可读的学术主题综述报告"时，走本指南。触发信号：用户提到"综述报告""主题综述""学术报告""按主题重组""详尽版/上万字""放回研究脉络"等。

## 一、纪要 vs 综述报告：定位区别

| 维度 | 会议纪要（标准路径） | 综述报告（本指南） |
|------|---------------------|-------------------|
| 目的 | 忠实记录每位报告人讲了什么 | 呈现学科当前的问题域与学理格局 |
| 组织线索 | 按主题—汇报人（发言顺序） | **按议题重组**，跨报告人聚合 |
| 深度 | 复述内容，不概括压缩 | 观点梳理 + **学理定位 + 缺口评述** 三层 |
| 骨架 | 分场标题 + 汇报人段落 | 摘要+关键词 / 编号章节 / 结论讨论 / 附录 |
| 语气 | 客观转述 | 学术评述，有判断、有批判 |

> 两者不是替代关系。综述报告通常**以纪要为素材底稿**，在其上做重组与升格。若素材尚未成纪要，先走标准路径产出内容底稿，再按本指南升格。

## 二、核心方法：按议题重组

不按发言顺序，而是先从素材中归纳出若干**议题主题**，把分属不同报告人的相关观点归入同一主题下讨论。

**操作步骤：**
1. 通读全部报告内容，提炼 5-8 个贯穿性议题（如"AI对职能的重构""变与不变的实证""服务国家战略的路径"）。
2. 为每个议题建一个章节，把相关报告人的观点**编织**进去——同一议题下可含多位报告人，同一报告人的内容也可拆到多个议题。
3. 章节内先给议题的核心张力/命题（如"变与不变"），再引入各报告人观点作为对该命题的不同侧面回应。
4. 章节之间用"承上启下"过渡句衔接（"如果说本节勾勒的是趋势判断，那么下一节提供的是趋势背后的数据底座"）。

## 三、每主题三层展开（强制）

综述报告的每个议题，不能停在"某某说了什么"，必须三层递进：

1. **观点梳理**：客观呈现报告人的核心主张、概念、数据、案例。保留研究对象、样本量、数据口径、专有名词。
2. **学理定位**：把观点放回既有研究脉络——它接续/呼应/挑战了哪个理论传统。
   - 例："这一构念接续了无边界职业生涯理论（Arthur & Rousseau）和职业生涯建构理论（Savickas），新意在于把AI对劳动过程的渗透纳入考量。"
3. **缺口评述**：指出该观点的证据基础与边界——是系统实证还是理论构想，适用范围如何。
   - 例："需要指出的是，这类判断主要建立在案例观察与产业趋势之上，其适用范围和边界条件还缺乏系统的实证检验。"

## 四、证据分级（结论部分强制）

综述报告须在结论处**区分观点的成熟度**，提醒读者审慎引用：

- **证据扎实**：以系统数据/元分析支撑的判断（"如唐宁玉的三套数据、王永贵的元分析，证据相对扎实"）。
- **理论构想**：新概念、新框架，尚待量表开发与实证检验（"若干新概念如'生态型职业生涯'仍属理论构想，其构念效度有待检验"）。
- **趋势判断**：基于案例观察与产业趋势，一般性存疑（"关于AI替代速度的判断多建立在案例之上，其边界条件需进一步验证"）。

## 五、学术骨架（标准结构）

```
标题（主标题：凝练命题 + 副标题：会议全称主题综述）
摘要（250-400字：会议背景 + 核心命题 + 主要发现 + 局限提示）
关键词（4-6个）
一、引言（会议背景 + 本文组织原则 + 素材缺口说明 + 议题预告）
二~N、按议题分章（每章三层展开 + 章间过渡）
末章、结论与讨论（命题收束 + 变/不变或核心线索归纳 + 证据分级 + 未来方向）
附录一、报告人索引（表格：报告人 | 单位 | 报告主题 | 对应章节）
附录二、主要数据与来源说明（转引数据逐项列出，标注"未独立核验，正式发表前复核"）
附录三、待核实事项（录音乱码段、数据年份、引用文献出处、职务单位）
```

## 六、诚信与边界（继承纪要规范，更严格）

- **不编造**：录音缺失/乱码段明确标注，不补写（"该报告后段录音识别质量较差，仅据可辨识片段整理，细节有待核对"）。
- **数据转引须标注**：现场展示的数据未经独立核验，附录二统一声明"正式发表前建议逐项复核"。
- **引用文献留待补全**：正文可提及理论出处（Peng & Nisbett 1999 等），附录三列明"若需列入正式参考文献应补齐完整出处"。
- **姓名/职务校正**：沿用纪要规范，用官方议程校正 ASR 错误。

## 七、去AI化与 TEEL（全程适用）

综述报告的行文同样受全团去AI味门禁 `skills/deai-rules/SKILL.md`（含四类高频病灶）与 `teel-structure.md` 约束。综述报告篇幅长、议论密度高，尤其要防：
- 每章结尾段段升华（病灶2.）——多数章节用"引出下一节"的过渡收束，仅结论章升华。
- 章节内镜像结构——每章的三层展开顺序可依内容微调，不必章章"梳理→定位→缺口"死板对齐。
- 学理定位处的空转动词（病灶3.）——"接续了""检验了""推进了"，不用"进行了对接"。

## 范例锚点

一份完整的高质量综述报告范例：约 11500 字，八节正文 + 三附录，学术主题综述体裁，按议题重组、三层评述、证据分级俱全。可作为"好长什么样"的对标基准（体裁、结构、语气、评述深度）。
