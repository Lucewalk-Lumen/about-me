# 研究设计

## 评审在看什么

评审看研究设计时的问题是："你打算怎么做，做出来我信不信？"

他判断三件事：
1. 你的研究目标是否明确、可测量（不是"提高教学质量"这种不可验证的目标）
2. 你的方法是否匹配你的问题（不是随便列一堆方法名称）
3. 你的技术路线是否可操作（不是画一个好看的流程图但落不了地）

## 方法论：IMRaD 逻辑 + 方法-问题匹配

**IMRaD**（Introduction-Methods-Results-and-Discussion）是学术论文的基本逻辑。申报书的研究设计本质上是"提前写Methods"——你要让评审相信：如果按这个设计做，能产出可信的结果。

**方法-问题匹配原则**：每一种研究方法必须回答"它用来解决本研究中的哪个具体问题"。不存在"因为别人都用了所以我也用"的方法。

## 章节结构

### （一）研究目标

**总目标**（一句话）+ **分目标**（3-4条）

规则：
- 总目标与课题名称直接对应
- 分目标用"动词+对象+标准"格式，可验证
- 禁止使用不可测量的动词："提高""促进""加强"→ 改为"构建""开发""验证""比较"

| 不可验证（禁止） | 可验证（正确） |
|----------------|-------------|
| 提高学生英语写作能力 | 开发一套适用于初二学段的分层写作支架工具，并通过准实验验证其对学生语篇逻辑性的影响 |
| 促进教师专业发展 | 形成一套校本教研中"课例研究+反思日志"的操作流程，并评估其对教师教学设计能力的改变 |
| 探索有效教学策略 | 比较三种分层作业模式（难度分层/兴趣分层/混合分层）对学生作业完成率和正确率的差异效应 |

### （二）研究内容

3-5个研究模块，逻辑递进。

组织原则：
- 各模块之间是递进关系（调查→设计→实施→评估），不是并列罗列
- 每个模块一句话说清"做什么"+"产出什么"
- 模块之间不交叉（MECE：互不重叠、完全穷尽）

示例结构：
```
研究内容一：初中英语学困生写作困难的类型诊断（调查摸底）
  → 产出：学困生写作错误类型分布数据 + 困难归因分析

研究内容二：分层写作支架的设计与开发（工具构建）
  → 产出：A/B/C三层写作支架任务库

研究内容三：分层写作支架的教学实施与效果验证（准实验）
  → 产出：实验组/对照组前后测数据 + 效果量分析

研究内容四：实施条件的校本化调适（实践修正）
  → 产出：修订后的操作手册 + 教师使用反馈
```

### （三）研究方法

每种方法写三要素：**方法名称 + 用来做什么 + 具体怎么做**

| 方法 | 用来解决什么 | 具体操作 |
|------|------------|---------|
| 文献研究法 | 梳理分层教学理论框架 | 检索CNKI/Web of Science近5年文献，按主题编码归类 |
| 问卷调查法 | 诊断学困生写作困难类型 | 自编《初中英语写作困难调查问卷》，对4个班186名学生施测，Cronbach's α≥0.7 |
| 准实验法 | 验证分层支架的教学效果 | 实验组（2个班）使用分层支架，对照组（2个班）常规教学，干预16周，前后测对比 |
| 行动研究法 | 迭代优化支架设计 | 每4周一次"计划-行动-观察-反思"循环，根据学生反馈调整支架难度 |
| 访谈法 | 理解效果背后的机制 | 每层抽取3名学生+2名教师半结构化访谈，主题编码分析 |

**禁止的写法**：
> 本研究采用文献研究法、问卷调查法、实验法、访谈法等多种方法。

这种写法等于什么都没说。评审要看到的是"为什么用这个方法""这个方法对应哪个研究内容"。

### （四）技术路线

用文字描述研究的逻辑流程（如需配图，用文字说明图的结构）：

```
文献研究 + 理论建构
    ↓
问卷开发 + 前测诊断（研究内容一）
    ↓
分层支架设计（研究内容二）← 文献+诊断结果
    ↓
准实验教学实施（研究内容三）← 16周干预
    ↓  ↑↓ 行动研究循环（每4周迭代）
后测 + 访谈 + 效果分析
    ↓
操作手册定稿 + 校本化建议（研究内容四）
```

## 级别差异

| 要素 | 市级 | 省级 | 国家级 |
|------|------|------|--------|
| 研究目标 | 1个总目标+2-3个分目标 | 需有理论目标+实践目标 | 需明确学科知识贡献 |
| 方法论证 | 说清怎么做即可 | 需论证"为什么用这个方法而不是别的" | 需方法论层面的适切性论证 |
| 样本设计 | 本校即可 | 需多校或区域样本 | 需有代表性的抽样方案 |
| 技术路线 | 文字描述即可 | 建议配流程图 | 需有严谨的实验设计（控制变量等） |
| 数据分析 | 说"用SPSS"即可 | 需说明具体分析策略 | 需预设统计方法+效应量标准 |

## Before / After

### 示例1：研究目标

**Before**：
> 本课题旨在提高初中英语学困生的写作水平，促进教育公平。

**After**：
> 本课题总目标：开发一套基于语篇能力诊断的初中英语分层写作支架工具，并通过为期一学期的准实验验证其对学困生语篇逻辑性的改善效果。
>
> 分目标：
> （1）建立初二英语学困生写作困难的类型学分类框架；
> （2）设计A/B/C三层差异化写作支架任务库（每层不少于12个任务单元）；
> （3）通过准实验比较分层支架教学与常规教学对学生连接手段多样性（T-unit中连接词类型数）的差异效应；
> （4）形成可供同类学校直接使用的《分层写作支架操作手册》。

### 示例2：研究方法

**Before**：
> 本研究主要采用行动研究法，辅以问卷调查法和访谈法。

**After**：
> （1）问卷调查法——用于研究内容一（困难诊断）。自编《初中英语写作困难调查问卷》，涵盖词汇提取、句法组织、语篇连贯、写作动机四个维度，对笔者所带初二年级4个班（共186人）进行整群施测。问卷经信效度检验后使用（Cronbach's α≥0.70，KMO≥0.75）。
>
> （2）准实验法——用于研究内容三（效果验证）。选取同质班级4个，随机分为实验组（2个班，使用分层支架）和对照组（2个班，常规写作教学），干预周期16周。以"语篇连接手段多样性指数"和"写作成绩"为因变量，控制教师变量（同一教师执教）。
>
> （3）行动研究法——贯穿研究内容二至四。每4周为一个"计划→行动→观察→反思"循环，根据学生作业表现和课堂观察调整下一轮支架设计。共计划4个循环。

## 常见死法

| 死法 | 为什么会被毙 | 怎么救 |
|------|------------|--------|
| 目标用"提高""促进" | 不可测量，评审无法判断你做没做到 | 换为"构建""开发""验证""比较" |
| 方法只列名称 | 等于没说 | 每个方法跟"解决什么问题"+"具体操作" |
| 方法堆砌（列了七八种） | 贪多嚼不烂，评审怀疑你哪个都做不深 | 精选3-4种，每种有明确分工 |
| 研究内容并列无递进 | 看不出逻辑，像拼盘 | 改为"调查→设计→实施→评估"递进链 |
| 样本设计不现实 | "随机选取全国100所学校"——一线教师做不到 | 写你能实际操作的（本校/本区/合作校） |
| 技术路线只有图没有文字 | 图是示意，评审要看具体逻辑 | 图+文字说明并行 |
