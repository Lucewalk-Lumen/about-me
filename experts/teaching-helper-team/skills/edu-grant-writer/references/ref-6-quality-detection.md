# 质量检测规则

## 检测定位

本检测是"自审工具"——帮教师在提交前发现自己看不到的问题。不是正式评审，不保证立项，不认定学术不端。

检测原则：
1. 有据必依：指出的每个问题必须引用原文，不做主观臆断
2. 分级处理：按严重程度分红/黄/绿，让用户优先处理致命问题
3. 改进导向：不只说"这里有问题"，必须给出具体修改建议
4. 适配级别：市级课题不用国家级标准卡（比如不要求CSSCI论文）
5. 不擅自修改：检测只输出报告，修改需用户确认后才执行

## 检测流程

```
接收材料 → 识别类型和级别 → 执行检测 → 输出报告 → 询问是否修改
```

### 输入校验

收到材料后先检查：
- 文本是否完整（<500字无法有效检测 → 提示补充）
- 是否为教育类课题（非教育类 → 仅做结构层面通用检测，标注局限性）
- 级别是否明确（不明确 → 根据内容推断，向用户确认）

## 检测维度

### 一、反模式检测

以下是评审专家"一看就烦"的高频问题。逐项扫描，命中即标注。

| # | 反模式 | 判断规则 | 严重度 |
|---|--------|---------|:------:|
| 1 | **万能描述** | 把课题名称换掉，这段话仍然成立（如"提高教学质量，促进学生全面发展"） |  |
| 2 | **数据过于完美** | 出现正好85%、93.72%、正好100份回收等"巧合"数字，且无采样说明 |  |
| 3 | **闭环强迫症** | 每段都是"总-分-总"结构，零跳跃零犹豫，读起来像流水线产品 |  |
| 4 | **外文文献堆砌** | 外文文献占比异常高（>40%）但正文中无实质引用或讨论 |  |
| 5 | **成果时间矛盾** | 立项3个月就"已发表2篇核心论文"，或"已完成全部实验" |  |
| 6 | **政策贴标签** | 列了3个以上政策文件但无一与选题有逻辑关联 |  |
| 7 | **方法堆砌** | 列了5种以上研究方法但无一对应具体研究内容 |  |
| 8 | **创新点虚高** | 声称"填补国内空白""开创性研究"但文献综述显示已有大量同类研究 |  |
| 9 | **目标不可测** | 研究目标全部使用"提高""促进""加强"等不可验证动词 |  |
| 10 | **保障空话** | 保障条件仅写"领导重视""条件充分"无具体措施 |  |

### 二、AI生成痕迹检测

五项快速筛查，每项计1分：

| # | 筛查项 | 判断方法 |
|---|--------|---------|
| 1 | 句式均匀度 | 连续3段以上长度高度一致（方差极小） |
| 2 | 连接词密度 | "首先/其次/再次/最后"或"不仅/而且/同时"高频堆叠 |
| 3 | 具体细节缺失 | 无具体时间/地点/数字/人名/校名的段落占比>60% |
| 4 | 虚词堆砌 | "重要意义""关键作用""核心价值""不可替代"密度异常 |
| 5 | 闭环完美 | 每段都是总-分-总，零跳跃零犹豫，无个人化表达 |

**分级判断**：

| 分数 | 等级 | 判断 |
|:----:|:----:|------|
| 0-1 |  | 大概率人类写作 |
| 2-3 |  | 可能有AI润色，标注位置+给改进建议 |
| 4-5 |  | 高度疑似AI生成，建议重写相关段落 |

**AI润色 vs AI生成 的区分**：
- AI润色（）：内容有具体信息（数据、案例、方法细节），但语言被过度规范化 → 建议加入个人化表达
- AI生成（）：内容空洞、通用、无具体信息 → 核心问题，必须用真实素材重写

**对疑似AI段落的改进建议**：
- 注入具体细节：加入时间、地点、校名、班号、学生人数
- 打破句式均匀：长短句交替，偶尔用疑问句或省略句
- 替换连接词：把"首先/其次/最后"换成自然过渡
- 加入个人判断：用"笔者认为""在教学实践中观察到"等主观标记
- 保留不完美：允许一处未完全解决的问题存在，不必每段都闭环

### 三、政策匹配度

检查申报书是否对接当前教育政策方向。

**十五五教育科研重点方向（2026-2030）**：

| # | 方向 | 命中判断 |
|---|------|---------|
| 1 | 教育强国建设 | 强/弱/未 |
| 2 | 数字化转型与智慧教育 | 强/弱/未 |
| 3 | 基础教育扩优提质 | 强/弱/未 |
| 4 | 职业教育产教融合 | 强/弱/未 |
| 5 | 乡村教育振兴 | 强/弱/未 |
| 6 | 教育评价改革 | 强/弱/未 |
| 7 | 教师队伍建设 | 强/弱/未 |
| 8 | 体美劳教育 | 强/弱/未 |
| 9 | 科学教育与创新人才培养 | 强/弱/未 |
| 10 | 家校社协同育人 | 强/弱/未 |

计分：强命中+10/项，弱命中+5/项，满分100。
-  ≥70：高度契合
-  30-69：部分相关
-  <30：偏离方向，建议调整选题角度

注意：政策匹配不是"贴标签"。命中要求申报书中有逻辑论证说明本研究与该方向的关联，而非仅在背景中提一句政策名称。

### 四、真实性抽查

随机抽取3-5处进行核查：

| 抽查对象 | 核查方法 |
|---------|---------|
| 文献引用 | 作者+年+标题是否可检索到；引用内容是否忠于原文 |
| 政策文件 | 文号+发布时间是否准确；是否已废止 |
| 数据出处 | 是否标注来源、时间、口径；自我采集数据是否有方案说明 |
| 前期成果 | 列举的论文/课题/获奖是否可查证；时间线是否合理 |

无法验证的标注"待核实"，建议用户自行确认。不直接判定为"造假"。

### 五、级别适配检查

对照主文件中的"级别适配原则"表，检查申报书是否达到目标级别的评审期待：

- 市级：实践价值是否突出？校本特色是否明确？
- 省级：是否有文献对话？是否有区域推广性？
- 国家级：是否有理论贡献？方法是否严谨？

常见问题：
- 用市级写法报省级（缺文献综述深度、缺理论框架）→ 
- 用国家级标准写市级（过度理论化、样本设计超出能力）→  建议降格

### 六、结构完整性

检查必备模块是否齐全：

| 模块 | 申报书必备 | 缺失严重度 |
|------|:--------:|:--------:|
| 选题依据/问题提出 | 是 |  |
| 文献综述/研究现状 | 是（省级以上） | / |
| 核心概念界定 | 是 |  |
| 研究目标与内容 | 是 |  |
| 研究方法与技术路线 | 是 |  |
| 创新点 | 是 |  |
| 实施计划与时间安排 | 是 |  |
| 预期成果 | 是 |  |
| 研究基础与保障条件 | 是 |  |
| 经费预算 | 是（省级以上） |  |
| 参考文献 | 是 |  |

## 检测后处理

报告输出后，询问用户：
> 以上是检测结果。是否需要我逐条帮你修改？
> - 全部修改 → 我按优先级从最高开始
> - 只改严重问题 → 我只处理项
> - 我自己改 → 结束

用户确认后，返回 Phase 1 对应章节执行修改。修改完成后建议再次检测（仅检测修改过的部分）。

## 免责声明

检测报告末尾附加：
> 本报告为AI辅助自审工具，仅供参考。检测结果不等同于正式评审意见，不作为学术不端认定依据。最终评审结果以官方评审委员会为准。
