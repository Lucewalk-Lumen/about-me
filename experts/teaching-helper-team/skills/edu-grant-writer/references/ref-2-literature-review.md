# 文献综述

## 评审在看什么

评审看文献综述时脑子里只有一个问题："你凭什么说这个问题没人解决过？"

他判断的依据：
1. 你是否真的了解这个领域已有的研究（不是只看了两三篇就下结论）
2. 你是否能指出已有研究的不足（不是"前人研究很好但是不够"这种废话）
3. 你的课题是否恰好填补了那个不足（逻辑闭环）

## 方法论：CARS 模型（Create A Research Space）

Swales (1990) 的 CARS 模型将文献综述转化为三个"动作"：

```
Move 1：建立领地（Establishing a Territory）
  → 这个领域为什么重要，已经有哪些研究

Move 2：制造缺口（Establishing a Niche）
  → 但是，已有研究在XX方面存在不足/空白/矛盾

Move 3：占据缺口（Occupying the Niche）
  → 因此，本研究要做XX来填补这个空白
```

**对教师的翻译**：文献综述不是"读书笔记列表"。不是"张三说了什么、李四说了什么、王五说了什么"。是你在跟已有研究"对话"——先承认他们做了什么，再指出他们没做到什么，最后引出你要做什么。

## 章节结构

### 组织方式：按主题，非按作者

错误结构（按作者罗列）：
```
张三（2020）研究了……
李四（2021）发现……
王五（2022）提出……
```

正确结构（按主题/论点组织）：
```
关于分层教学的实施路径，已有研究主要从三个角度展开：
一是基于学生能力分组的……（张三，2020；李四，2021）
二是基于任务难度梯度的……（王五，2022）
三是基于动态调整机制的……（赵六，2023）
```

### 述评分离原则

"述"是铺垫，"评"才是核心。每一组文献后面必须跟你的判断。

| 只有述（不合格） | 述+评（合格） |
|----------------|-------------|
| 张三（2020）对分层作业进行了实证研究，发现分层作业能提高学生成绩。 | 张三（2020）的实证研究表明分层作业对学业成绩有正向影响，但其样本仅限于初三毕业班，且"分层"依据仅为考试分数，未考虑学习风格差异。这意味着其结论向非毕业年级的推广性有待验证。 |

### 段落结构

每段遵循：
```
主题句（本段讨论什么维度）
→ 已有研究做了什么（述，2-4篇文献）
→ 不足/空白/矛盾（评）
→ [可选] 对本研究的启示
```

### 收尾：研究空白总结

文献综述最后一段必须明确收束：
```
综上所述，已有研究在[XX方面]取得了丰富成果，但在以下方面仍存在不足：
（1）……
（2）……
基于此，本研究拟从[XX角度]切入，聚焦[具体问题]，以期……
```

## 级别差异

| 要素 | 市级 | 省级 | 国家级 |
|------|------|------|--------|
| 文献量 | 5-10篇即可 | 15-25篇 | 30篇以上 |
| 外文文献 | 不强制 | 建议有2-3篇 | 需有系统性外文文献 |
| 理论框架 | 可不单列 | 需明确理论视角 | 需与理论传统对话 |
| 述评深度 | 指出"做得不够"即可 | 需分析"为什么不够" | 需指出方法论层面的局限 |
| 时效性 | 近5年为主 | 近5年≥60% | 近5年≥60% + 经典文献 |

## 文献检索执行规则

当需要为用户检索文献时：

1. 用 WebSearch 检索，关键词组合：
   - 中文：[核心概念A] + [核心概念B] + [学段] + "实证研究"/"教学设计"
   - 英文：[concept A] + [concept B] + "empirical study" / "intervention"
2. 优先选择：CSSCI/北大核心期刊论文、硕博学位论文、教育部课题成果
3. 每条文献记录：作者、年份、标题、来源、与本研究的关系（一句话）
4. 无法验证真实性的标注"待核实"
5. 检索结果按主题分组呈现给用户，不按时间排列

## Before / After

### 示例1：文献综述开头

**Before（教师原始表述）**：
> 关于分层作业，国内很多学者都进行了研究。我在中国知网上搜到了很多相关论文。总的来说，分层作业是一种有效的教学方式。

**After（申报书表述）**：
> 近五年来，分层作业研究呈现三个主要方向：一是分层标准的精细化，从单一成绩分层走向多维能力诊断（陈XX，2021；刘XX，2023）；二是作业形式的多样化，强调书面作业与实践性作业的组合设计（王XX，2022）；三是技术赋能下的个性化推送，依托学习分析实现"一生一策"（张XX等，2024）。

**转化要点**：
- "很多学者"→ 具体三个方向 + 具体文献
- "我搜到了很多"→ 删除（检索过程不写进综述）
- "总的来说有效"→ 删除（这是结论不是综述）

### 示例2：制造缺口

**Before**：
> 但是，已有研究还有一些不足，需要进一步研究。

**After**：
> 然而，上述研究存在两个明显缺口：第一，实证研究多集中于小学语数学科（占比约70%），初中学段的分层作业实证数据严重不足；第二，已有分层标准多依赖终结性考试成绩，缺少对学生学习过程数据（如作业完成路径、错误类型分布）的利用。本研究正是针对这两个缺口展开。

**转化要点**：
- "还有一些不足"（空话）→ 具体哪两个缺口
- 有数据支撑（"占比约70%"）
- 最后一句把缺口和本研究对接

### 示例3：述评结合

**Before**：
> 李四（2022）研究了初中英语分层作业的设计策略，提出了分层设计的原则。

**After**：
> 李四（2022）基于行动研究提出了初中英语分层作业的"三级弹性设计"原则（基础巩固层/能力提升层/拓展挑战层），为一线教师提供了可操作的设计框架。但该研究的"分层"依据仅为月考成绩排名，未纳入学生的学习策略差异和动机水平；且研究周期仅一个学期，缺少对分层作业长期效果的追踪数据。

**转化要点**：
- 先肯定贡献（"提供了可操作的设计框架"）
- 再指出具体局限（不是"不够深入"，是具体哪里不够）
- 局限要指向自己的研究（"未纳入学习策略差异"→ 我的研究纳入了）

## 常见死法

| 死法 | 为什么会被毙 | 怎么救 |
|------|------------|--------|
| 按作者罗列（张三说…李四说…） | 没有"评"，看不出你的思考 | 按主题/论点重组，文献是论据不是主角 |
| "前人研究取得了丰硕成果，但仍有不足" | 万能废话，什么课题都能用 | 具体说出"哪个方面""什么不足""为什么不足" |
| 文献全是10年前的 | 说明你不了解当前进展 | 近5年≥60%，经典文献可保留但需标注 |
| 外文文献堆砌 | 列了5篇英文但内容跟论点无关 | 外文文献必须与论证直接相关，否则删掉 |
| 综述结尾没有收束 | 评审看完不知道"所以你要做什么" | 最后一段必须明确：空白是什么→本研究填哪个 |
| 把综述写成教材（介绍概念发展史） | 评审不需要你科普 | 只梳理与本研究直接相关的研究脉络 |
