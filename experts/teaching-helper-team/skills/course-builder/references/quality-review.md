## 三层质检体系

对教学设计产出物（教案、教材、课件内容）进行分层质量检查：

> **分层体系说明**：本节为通用框架，适用于所有类型产出物。教材/讲义的专用深化规则（句级S1-S6、段级P1-P4、章级C1-C5、一致性B0-B3及评分模型）详见 [textbook-quality/](textbook-quality/) 目录：
> - 句级去AI味规则：[textbook-quality/quality-s.md](textbook-quality/quality-s.md)
> - 段级/章级规则：[textbook-quality/quality-plc.md](textbook-quality/quality-plc.md)
> - 评分体系与审校框架：[textbook-quality/quality-check.md](textbook-quality/quality-check.md)

| 层级 | 检查内容 | 严重程度 | 处理方式 | 适用产出物 |
|------|---------|---------|---------|-----------|
| **S层（结构层）** | 目标-评价-活动对齐、章节逻辑递进、知识覆盖完整 | 阻断级 | 必须修复后才能交付 | 教案、课程大纲、教材 |
| **P层（专业层）** | 学术语义准确性、概念定义规范、引用格式、数据可靠性 | 严重 | 应修复，标注待改项 | 所有产出物 |
| **C层（表达层）** | 语言流畅性、术语一致性、排版格式、可读性 | 建议 | 列出建议，用户决定 | 所有产出物 |

### 质检执行顺序

```
S层（必须通过）→ P层（应通过）→ C层（建议优化）
```

S层不通过时，不继续P/C层检查，先修复S层问题。

## S层检查清单（结构层）

### 教案/课程大纲S层检查

- [ ] **目标可观测**：每条教学目标使用布鲁姆动词，可观测、可评价
  - 检查：是否含"理解""掌握""体会"等不可测词？
  - 修复：改为"能独立完成X""能区分A与B""能用自己的话解释Y"

- [ ] **目标-评价对齐**：每条课程目标至少对应一种评价方式
  - 检查：列出目标与评价的对应矩阵，是否有目标无评价？

- [ ] **目标-活动对齐**：每个教学活动标注了对应的目标
  - 检查：是否有活动无法对应到任何目标？如有，该活动为装饰，删掉

- [ ] **章节逻辑递进**：章节间有清晰的逻辑关系（并列/递进/总分）
  - 检查：能否用一句话说清章节间的逻辑？

- [ ] **知识覆盖完整**：知识点覆盖了课程目标要求的所有内容
  - 检查：对照课程目标，是否有目标要求但未涉及的知识点？

- [ ] **考核层次匹配**：考核方式与目标的认知层次匹配
  - 检查：目标层次为"评价"但考核只有选择题？需要增加论述/论文类评价

- [ ] **时间分配合理**：各教学环节时间与内容量匹配
  - 检查：核心环节时间占比是否过低？导入和总结是否过长？

### 教材S层检查

- [ ] **章节结构完整**：每章含导语、学习目标、正文、小结、习题
- [ ] **知识递进逻辑**：前序章节为后续章节提供必要基础
- [ ] **内容与目标一致**：正文内容覆盖本章学习目标要求
- [ ] **习题覆盖度**：习题覆盖本章所有重要知识点
- [ ] **无遗漏核心内容**：对照课程大纲，教材内容无缺失

### 课件S层检查

- [ ] **逻辑主线清晰**：能说清本课核心结论及支撑论据
- [ ] **一页一主题**：每页只讲一件事，内容支撑该页主题
- [ ] **页面序列完整**：导入→讲解→实践→总结→作业的环节齐全
- [ ] **知识点覆盖**：教案要求的知识点在课件中均有对应页面

## P层检查清单（专业层）

### 学术语义准确性

- [ ] **概念定义准确**：无歧义、无错误表述
  - 检查：对照权威教材或学科标准，概念表述是否一致？

- [ ] **术语首次标注**：专业术语首次出现标注英文原词
  - 检查：全书/全课件术语标注是否一致

- [ ] **术语一致性**：全书同一术语不混用近义词
  - 检查：如"算法"不与"方法"混用，"模型"不与"模式"混用

### 引用与数据

- [ ] **引用格式统一**：参考文献格式一致（GB/T 7714）
- [ ] **数据准确可靠**：引用数据注明出处，无过时数据
- [ ] **公式正确**：数学公式、物理公式推导无误
- [ ] **图表数据准确**：图表中的数据与正文一致

### 内容时效性

- [ ] **无已废弃理论**：不引用已被学界否定的理论或方法
- [ ] **无过时信息**：引用的标准、法规、数据为最新版本
- [ ] **前沿性**：适当融入学科最新进展

### 课程思政（如适用）

- [ ] **融入自然**：思政元素与专业知识自然融合，无生硬说教
- [ ] **元素准确**：思政元素表述准确，无误导性内容

## C层检查清单（表达层）

### 语言质量

- [ ] **语言流畅**：无病句、无口语化表述、无生硬翻译腔
- [ ] **无AI写作痕迹**：无空洞排比、过度修饰、万能套话（详见AI痕迹检测）
- [ ] **可读性**：内容深度与教学对象匹配，不过浅也不过深
- [ ] **启发性**：关键知识点后有思考引导

### 排版格式

- [ ] **字体统一**：正文、标题、图表标注字体一致
- [ ] **编号连续**：章节、图表、公式编号无跳号、无重号
- [ ] **图表规范**：所有图表有编号和标题，格式统一
- [ ] **页边距统一**：全文页边距一致

### 课件特有检查

- [ ] **Action Title**：每页标题是结论性观点而非描述性标题
- [ ] **信息密度**：每页文字量在限制范围内（见 [ppt-design-guide.md](../../ppt-maker/references/ppt-design-guide.md)）
- [ ] **视觉一致**：配色、字体、图标、留白全课件统一
- [ ] **数据可视化规范**：图表符合使用规范（排序、切片数、线数限制）

## 内容安全检查

在产出物交付前，执行内容安全预检，识别潜在敏感内容并分级处理。

### 风险规则分类

| 风险类别 | 风险等级 | 检测关键词/模式 | 处理方式 |
|---------|---------|----------------|---------|
| **自伤自残** | 高（阻断） | 自杀、自残、kill myself、suicide | 阻断交付，必须改写或删除 |
| **暴力违法** | 高（阻断） | 制作炸弹、爆炸物、枪支改造、weaponize | 阻断交付，必须改写或删除 |
| **仇恨言论** | 高（阻断） | 种族灭绝、仇恨言论、hate speech | 阻断交付，必须改写或删除 |
| **欺诈犯罪** | 中（警告） | 诈骗脚本、洗钱、伪造证件、phishing kit | 标注警告，建议人工复核并改写为合规表达 |

### 检查流程

```
1. 全文扫描上述风险关键词
2. 命中高等级风险 → 状态=blocked，阻断交付
3. 命中中等级风险 → 状态=warn，标注待改
4. 无命中 → 状态=passed，通过
```

### 处理原则

- **阻断级**：内容必须改写或删除后才能进入后续质检流程，不可跳过
- **警告级**：标注位置和命中类别，建议人工复核，改写为合规的学术表达后继续
- **教学场景豁免**：当内容涉及风险话题是为了**批判、防范或学术分析**目的时（如心理学课程讨论自杀干预），应标注教学用途说明，经用户确认后可保留，但仍需确保表述方式具有明确的学术/教育框架

## 时效性与高风险内容验证

对产出物中涉及时间敏感信息和高风险主题的内容，执行专项验证。

### 时间锚检测

对正文中包含时间敏感词的语句，检查是否附带时间锚（时间标注或来源链接）。

**触发检测的时间敏感词**：

| 类别 | 检测词 |
|------|-------|
| 时态词 | 最新、当前、目前、今年、截至、as of、latest、current |
| 年份引用 | 含 19XX / 20XX 年份的表述 |

**合规的时间锚**：

- 显式时间标注：`[时间: YYYY-MM-DD]`
- 来源链接：`https://` 开头的 URL
- 出处标注：注明"来源""出处"等字样

**检查规则**：凡含时间敏感词但无时间锚的语句，标记为"时间锚缺失"，提示补充时间标注与来源。

**示例**：
```
[不通过] "最新的研究显示，深度学习模型参数量已突破万亿。"
   → 缺少时间锚，无法判断"最新"的时效基准

[通过] "截至2025年3月，最大的公开模型参数量已突破万亿 [时间: 2025-03]（来源：arXiv:2503.xxxxx）。"
   → 时间锚完整，可追溯
```

### 高风险主题双源验证

对涉及以下高风险主题的内容，要求至少有两个独立来源相互印证：

**高风险主题关键词**：

| 主题领域 | 关键词 |
|---------|-------|
| 定价信息 | 价格、pricing、费率 |
| 法规合规 | 法规、监管、合规、政策 |
| 版本信息 | 版本、version |
| 技术模型 | 模型、model |

**验证规则**：
- 识别产出物中涉及上述高风险主题的陈述
- 每个高风险陈述必须有 ≥2 个独立来源（不同 URL）支撑
- 仅有单一来源的高风险陈述标记为"来源不足"，提示补充验证

### 方法时效性检测

对产出物中引用的方法论、技术方案、最佳实践，检测是否存在"方法漂移"：

| 检测维度 | 触发条件 | 判定 |
|---------|---------|------|
| **时间漂移** | 距该方法论最后更新时间 >30 天（快速演进领域）或 >180 天（一般领域） | 建议复核方法是否仍为主流 |
| **负向反馈** | 用户对该领域内容的负向反馈（标记为"过时""非主流"等）累计 ≥2 条 | 建议重新调研 |
| **连续修正** | 同一领域的产出物连续被人工修正 ≥3 次 | 表明方法可能存在系统性偏差，需重新审视 |

**处理方式**：触发任一条件时，标注"方法时效性存疑"，建议执行反思式修订流程（见第10节）。

## AI痕迹检测

检查以下AI写作常见特征并标注修改建议：

> **唯一 SSOT 声明**：全团去AI味规则以 `quality/deai-rules` 为**单一事实来源（SSOT）**，是所有文本生成交付前的最后统一门禁。本节的通用词表与 `deai-rules` 第二层「中文通用规则」、第四层「三级词汇体系」同源，交付前必须过 `deai-rules` 门禁。
>
> **教材专用深化**：教材/讲义的句级去AI味详细规则（S1首句具体性、S2消灭冗余修饰、S3短句优先、S4连接词降频、S5 buzzword黑名单、S6标点符号纪律）见 [textbook-quality/quality-s.md](textbook-quality/quality-s.md)；段/章/篇级规则（P/C/B层）见 [textbook-quality/quality-plc.md](textbook-quality/quality-plc.md)。二者为教材质检评分体系的领域细化，与 `deai-rules` 冲突时**以 `deai-rules` 为准**。

### 检测词库

| 特征类型 | 典型表现 | 修改方向 |
|---------|---------|---------|
| **空洞排比** | "不仅...而且...更..." 三连；"既...又...还..." | 删除冗余，保留一个最贴切的关系 |
| **过度修饰** | "极其重要的""非常关键的""不可或缺的" | 改为具体说明为何重要 |
| **万能套话** | "在当今时代背景下""随着...的发展""众所周知" | 直接切入主题 |
| **假设性结尾** | "这值得我们深思""留给读者思考" | 改为具体结论或行动建议 |
| **模式化过渡** | "接下来我们来看""下面讨论" | 自然过渡或直接陈述 |
| **虚假全面** | "综上所述...总而言之...由此可见" 三连总结 | 选一个最贴切的，直接归纳 |
| **过度对仗** | 强行制造对仗句式，内容空洞 | 改为自然陈述 |
| **无信息举例** | "例如，在计算机领域有广泛应用" | 改为具体案例 |
| **万能形容词** | "高效的""智能的""创新的" 不加限定 | 改为具体指标或对比 |

### 检测流程

```
1. 全文扫描上述特征词
2. 标注每处命中（位置 + 特征类型 + 原文）
3. 生成修改建议（原文 → 建议修改）
4. 统计命中次数与分布
5. 若命中密度 > 5处/千字 → 标记为"AI痕迹明显"，建议整体改写
```

### 修改原则

- **不破坏原意**：修改只改表达方式，不改内容含义
- **保留术语**：专业术语不降级为外行用语
- **保持风格**：修改后的文字与上下文风格一致
- **适度修改**：并非所有命中都需修改，少量通用表达可保留

## 写作风格保持

当基于教师提供的已有教案、教材或课件样本进行内容扩写或续写时，需先学习样本的写作风格画像，确保新内容与样本风格一致。


### 风格画像五维度

| 维度 | 分析对象 | 关键指标 |
|------|---------|---------|
| **词汇偏好** | 高频词、偏好短语、回避短语 | 高频词 Top-200、偏好短语 Top-100 |
| **句式偏好** | 句长、句长方差、常见句式模式、复杂度 | 平均句长（字符）、复杂度评分（0-10） |
| **语气偏好** | 情感倾向、正式程度、表达强度 | 正面/中性/负面；正式/中性/口语；高/中/低 |
| **格式偏好** | 段落风格、标题风格、列表风格 | 缩进/紧凑/标准；编号/标准；紧凑/详细/标准 |
| **修辞偏好** | 比喻、排比、举例标记 | 修辞手法使用频率与类型 |

### 风格学习流程

```
1. 收集教师已有作品样本（教案/教材/课件文本，≥500字符/篇）
2. 逐一分析五个维度的风格特征
3. 计算统计量（移动平均，学习率 0.1）
4. 生成风格画像 JSON，保存为风格基准
5. 后续内容生成时参照画像进行风格适配
```

### 风格适配规则

在生成新内容或修改已有内容后，按以下规则检查并适配风格：

| 适配维度 | 适配规则 |
|---------|---------|
| **词汇适配** | 新内容中的高频词与样本偏好词表对比，偏差 >30% 时提示风格偏移 |
| **句长适配** | 新内容平均句长超出样本基线 ×1.5 倍时，拆分长句（在连接词"因此/但是/而且"处拆分） |
| **语气适配** | 正式程度：正式风格去除口语语气词（吧/呢/啊）；口语风格可保留。表达强度：低强度风格将感叹号替换为句号 |
| **格式适配** | 段落风格：缩进风格为新段落添加缩进；紧凑风格减少空行。标题风格：编号风格统一编号格式 |
| **修辞适配** | 检查样本是否偏好使用比喻/举例，新内容中修辞手法密度与样本一致 |

### 风格偏移检测

当新内容与风格画像出现以下偏移时，标注警告：

| 偏移信号 | 判定阈值 | 处理 |
|---------|---------|------|
| 句长偏移 | 新内容平均句长 > 样本基线 ×1.5 或 < ×0.5 | 标注"句长偏移"，建议调整 |
| 正式度偏移 | 样本为正式风格，新内容出现 ≥3 个口语语气词 | 标注"正式度下降"，建议修正 |
| 词汇偏移 | 样本偏好短语在新内容中命中率 <30% | 标注"词汇风格偏移"，建议参考样本词汇 |
| 修辞缺失 | 样本频繁使用举例但新内容无举例 | 标注"修辞风格不一致"，建议补充实例 |

### 风格报告格式

```markdown
## 风格分析报告

### 概要
- 样本数：X 篇
- 平均句长：X 字符
- 整体复杂度：X.XX / 10
- 情感倾向：正面/中性/负面
- 正式程度：正式/中性/口语

### 词汇特征
- Top-10 高频词：[词列表]
- Top-5 偏好短语：[短语列表]

### 句式特征
- 平均句长：X 字符
- 句长方差：X.XX
- 复杂度评分：X.XX / 10
- 常见句式模式：[模式列表]

### 语气特征
- 情感：正面/中性/负面
- 正式度：正式/中性/口语
- 强度：高/中/低

### 格式特征
- 段落风格：缩进/紧凑/标准
- 标题风格：编号/标准
- 列表风格：紧凑/详细/标准

### 修辞特征
- 修辞手法数量：X
- 比喻使用：X 处
- 举例标记：X 处
```

## 产出物验证规范

对每类产出物执行结构化验证，确保格式规范、字段完整、符合模板要求。


### 验证维度

| 维度 | 检查内容 | 严重程度 |
|------|---------|---------|
| **分隔符检查** | 产出物是否包含规定格式的分隔标记 | 错误（缺失则不通过） |
| **必需字段检查** | 模板规定的必需字段是否全部存在 | 错误（缺失任一则不通过） |
| **格式模式检查** | 产出物的格式是否符合预定义的正则模式 | 错误（不符合则不通过） |
| **可选字段检查** | 模板建议的可选字段是否存在 | 警告（缺失不阻断，但提示建议补充） |

### 课程建设产出物验证模板

| 产出物类型 | 必需字段 | 可选字段 |
|-----------|---------|---------|
| **课程大纲** | 课程名称、课程目标、教学章节、评价方式、学时分配 | 先修课程、参考教材、思政融入点 |
| **教案** | 课程信息、教学目标、教学重难点、教学过程、板书设计、作业布置 | 学情分析、教学反思、拓展资源 |
| **教材章节** | 章节标题、学习目标、正文、本章小结、习题 | 导语、拓展阅读、案例分析 |
| **课件** | 课件标题、章节信息、核心知识点页、总结页、作业页 | 互动设计页、案例分析页、拓展资源页 |
| **教学评价方案** | 评价目标、评价方式、评价标准、成绩构成 | 评价时间表、反馈机制 |
| **质检报告** | 检查日期、检查范围、S/P/C层结论、问题清单、修改建议 | 复检记录、修订追踪 |

### 验证结果结构

```json
{
  "valid": true,
  "type": "教案",
  "errors": [],
  "warnings": [],
  "info": ["[x] 字段检查通过: 教学目标", "[x] 字段检查通过: 教学过程"]
}
```

- `valid`：整体是否通过（无 error 即为 true）
- `errors`：阻断级问题列表（缺失必需字段、格式不符等）
- `warnings`：非阻断级建议（缺失可选字段等）
- `info`：逐项检查的通过确认

### 白名单机制

对于教师明确指定可豁免的字段（如某些课程不需要板书设计），可加入白名单，验证时跳过该字段的检查。

### 批量验证

对一批产出物（如一整套课程的全部教案）执行批量验证时：
1. 逐一验证每个产出物
2. 统计通过率：`通过数 / 总数`
3. 汇总所有错误和警告
4. 输出批量验证报告，按产出物分组列出问题

## 反思式修订流程

当质检发现问题或检测到方法漂移信号时，启动反思式修订流程，确保修订有据可依而非随意改写。


### 问题信号检测

在产出物文本中扫描以下六类信号，判断是否需要触发补检（补充检索验证）：

| 信号类型 | 检测模式 | 含义 | 是否触发补检 |
|---------|---------|------|-------------|
| **时效信号** | 含"最新、当前、近年来、最近、发布、更新" | 内容涉及时效性信息 | 是 |
| **版本/日期信号** | 含"vX.X、XXXX年、XXXX-XX-XX、Q1-Q4" | 引用了特定版本或日期 | 是 |
| **不确定性信号** | 含"不确定、可能、似乎、印象中、估计、应该是" | 表述存在不确定性 | 是 |
| **数值事实信号** | 含百分比、万/亿、同比、增长率等数值 | 涉及具体数据，需核实 | 是 |
| **方法更新信号** | 含"更先进、最佳实践、换一种方法、优化方法、主流做法" | 可能涉及方法迭代 | 是 |
| **年份回声信号** | 同一年份出现 ≥2 次 | 该年份可能是核心时间基准 | 是 |

### 修订决策树

```
检测到信号？
├── 是 → 是否需要补检？
│   ├── 时效/版本/数值/方法信号 → 需要补检：生成检索计划，补充来源
│   ├── 不确定性信号 → 需要补检：查找可靠来源消除不确定性
│   └── 年份回声信号 → 需要补检：核实该年份的准确性
│       └── 补检完成 → 仅改写受影响片段，必须附修正依据
└── 否 → 可直接微调措辞，不触发补检
```

### 焦点关键词提取

补检时，从问题文本中提取焦点关键词用于检索：

1. 去除标点和停用词（我们、这个、可以、需要、进行、一个、已经、以及、如果）
2. 按词频排序，取 Top-6 作为检索关键词
3. 根据信号类型确定检索意图：
   - 方法更新信号 → 检索意图为"method"（查找最新方法）
   - 数值事实信号 → 检索意图为"fact"（核实数据准确性）
   - 其他信号 → 检索意图为"fallback"（通用检索）

### 修订规则

| 场景 | 修订规则 |
|------|---------|
| **触发补检** | 仅改写受影响的段落，不扩大修改范围；每处修改必须附修正依据（来源URL、出处页码等） |
| **未触发补检** | 可直接微调措辞（如修正错别字、调整语序），无需附来源 |
| **方法漂移** | 重新调研该方法论的当前状态，确认是否已过时；若已过时，更新为新方法并标注更新时间 |
| **年份回声** | 核实核心年份的准确性，如年份有误则全文统一修正 |

### 修订后复检

修订完成后，对修改部分执行复检：
1. 重新扫描问题信号，确认信号已消除
2. 检查修改是否引入新的信号（如新增了未标注来源的数值）
3. 确认修改内容与上下文风格一致（参见第8节"写作风格保持"）

## 内容分类标注体系

对产出内容进行分类标注，辅助质量评估和修订决策：

### 分类标签

| 标签 | 含义 | 处理方式 |
|------|------|---------|
| `[准确]` | 经核实，内容准确可靠 | 原文保留 |
| `[需核实]` | 待核实准确性，可能有误 | 标注待核实，提示用户确认 |
| `[需补充]` | 内容不完整，需补充信息 | 标注缺口，提示用户补充 |
| `[需精简]` | 内容冗余，需精简 | 标注精简方向 |
| `[AI推断]` | 无材料来源，为AI推断 | 标注来源，提示用户核对 |
| `[过时]` | 内容可能已过时 | 标注，提示用户更新 |

### 标注格式

在内容旁标注标签，格式：`内容原文 [标签: 具体说明]`

示例：
```
二叉搜索树的查找时间复杂度为O(log n) [需核实: 最坏情况为O(n)，需注明]
该算法由Dijkstra于1959年提出 [准确]
```

### 修订优先级

```
1. 先修内容安全阻断项——不修不能交付
2. 再修S层（阻断级）——不修不能交付
3. 再修P层（严重）——影响专业性
4. 触发补检的时效/方法问题——补充来源后修订
5. 最后优化C层（建议）——提升可读性
6. AI痕迹——根据密度决定整体改写还是逐处修改
7. 风格偏移——参照风格画像适配
```

### 修订后复检

修订完成后，对修改部分进行复检，确保：
- 修改未引入新的S/P层问题
- 修改后的内容与上下文风格一致
- 修改未破坏原有正确内容
- 反思式修订的信号已消除（参见第10节）

## 扩写中的事实标注体系


在教材/教案内容扩写过程中，对新增的事实性表述执行标注，区分有来源支撑和无来源支撑的内容。

### 标注规则

| 内容类型 | 标注方式 | 要求 |
|---------|---------|------|
| **有素材支撑的数据/引语/案例** | `[MAT-xxx]` 或团队约定编号 | 须能对应到素材库或检索记录的编号 |
| **无素材支撑但需保留的表述** | `[作者观察]` 或 `[行业共识（待补证）]` | 不得伪装为已引用事实 |
| **无法标注又声称可核验的句子** | 删除或改为上述两类之一 | 精修阶段必须处理 |

### 扩写后抽检

扩写完成后，执行事实无出处抽检：

1. 扫描所有新增段落
2. 检查每条事实性表述是否有 `[MAT-xxx]` 标注或 `[作者观察]` 标注
3. 无标注的事实性表述 → 标记为"事实无出处"告警
4. 统计无出处率：`无标注事实数 / 新增事实总数`
5. 无出处率 >20% → 标记为"来源不足"，建议补充素材

### 标注示例

```markdown
二叉搜索树的平均查找时间为 O(log n) [MAT-001: 《数据结构(C语言版)》, 严蔚敏, p.230]

红黑树在实际数据库索引中比AVL树更常用 [作者观察: 基于主流数据库实现趋势]

B+树是大多数关系型数据库的首选索引结构 [行业共识（待补证）: 需补充具体数据库产品引用]
```
